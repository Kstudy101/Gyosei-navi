千葉市の住宅用設備等脱炭素化促進事業補助金（次世代自動車）は、**住宅用太陽光発電を併設する場合**に電気自動車（EV）、プラグインハイブリッド自動車（PHV）、V2H充放電設備を導入した市民（法人を除く）へ、購入費用の一部を補助する市の制度です。令和8年度はEV/PHVが太陽光併設で**上限10万円**、太陽光＋V2H併設で**上限15万円**、V2H本体は経費の**10分の1・上限25万円**です。

## この記事の結論

- EV/PHVは**太陽光併設が必須**。太陽光のみ併設なら**上限10万円**、太陽光＋V2H併設なら**上限15万円**
- V2Hは本体購入費の**1/10（上限25万円）**。申請時に太陽光とEV/PHVの導入が条件
- 受付は**令和8年5月1日〜令和9年1月29日**（必着・予算終了次第終了）。事後申請で、完了前の受付は不可
- 同じ要綱の[住宅向け設備補助](/subsidy/energy/chiba-shi-jutaku-datsutanso-hojo)・集合住宅の充電設備とは別ページ・別枠

## 1. 対象者・支給条件

### 対象者の共通条件

- **個人**（法人は対象外）
- 補助対象設備を導入した住宅に、千葉市の住民基本台帳上の住所があること
- 市税（延滞金含む）の滞納がないこと
- 導入費用を負担して設備を所有すること（所有権留保付きローンや一定条件のリースを含む）
- 同一設備について市の他の補助金を申請していないこと

### EV・PHVの主な条件

| 項目 | 内容 |
|---|---|
| 車両 | 新車の四輪EVまたはPHV（小型・大型特殊車両を除く） |
| 車検証 | 用途「乗用」・自家用。燃料の種類がEVは「電気」、PHVは「ガソリン・電気」または「軽油・電気」 |
| 登録時期 | 初度登録年月および交付年月日が申請年度の**4月〜1月**。交付年月日は**4月1日〜1月15日** |
| 使用関係 | 使用の本拠＝導入住宅の住所。使用者＝申請者 |
| 国の対象車 | 次世代自動車振興センターが令和6年度以降の国補助対象としている車種 |
| 太陽光 | 申請日までに太陽光が設置され、発電電力を当該車両に充電できること（新設・既設問わず） |
| 太陽光＋V2H枠 | 上記に加え、申請日までにV2Hが使用できる状態であること（新設・既設問わず） |
| 回数 | 導入する住宅において、設備の種類ごとに**1人1回** |

中古車（中古輸入車の初度登録を含む）は対象外です。

### V2H充放電設備の主な条件

- 申請日までに、自ら居住する市内住宅であること
- **太陽光が設置されていること**（新設・既設問わず）
- **EVまたはPHVが導入されていること**（新規・既導入を問わないが、乗用・自家用の四輪で、使用の本拠がV2H設置住宅の住所と同一）
- 国の令和6年度以降補助で、次世代自動車振興センターの対象機器であること
- 同一住宅・同一世帯で同種の市補助金を受けていないこと（要綱別表3）

## 2. 支給額・計算方法

| メニュー | 補助額 | 公式ページの残り受付目安（2026年8月20日更新） |
|---|---|---|
| EV/PHV（太陽光併設） | **上限10万円** | 約30件 / 約60件 |
| EV/PHV（太陽光＋V2H併設） | **上限15万円** | 約7件 / 約10件 |
| V2H充放電設備 | 補助対象経費（**本体購入費**）の**1/10**・**上限25万円** | 約20件 / 約20件 |

補助対象経費は消費税等を除き、国その他団体の補助金を充当している場合はその額も差し引きます。算定額が実支出より大きい場合は実支出が上限で、千円未満は切り捨てです。

## 3. 申請方法・必要書類

申請は**補助事業の完了後**です。受付期間は**令和8年5月1日（金）から令和9年1月29日（金）**まで。期間外の日付が入った申請や到着分は受け付けません。予算がなくなり次第終了し、先着順（同日に予算超過した場合は抽選）です。

申請方法は次の3通りです。

1. **オンライン申請**（公的個人認証＝マイナンバーカードが必要）
2. **郵送**
3. **窓口持参**（平日9時〜17時、土日祝・年末年始除く）
