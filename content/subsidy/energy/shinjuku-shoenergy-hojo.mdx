新宿区の省エネルギー及び創エネルギー機器等補助制度とは、太陽光発電・エコキュート・エネファーム・高反射率塗装・断熱窓・蓄電池システムの6種類の機器をまとめて対象にする区独自の補助制度です。他区の多くの制度と異なり、**施工と支払いを全額完了した後に申請する「事後申請型」**という特徴があります。

<SubsidyInfoCard />

## この記事の結論

- 6種類の機器を対象にした**うちわ型の補助制度**で、機器ごとに補助額が異なる
- 蓄電池システムは**蓄電容量1kWhあたり10,000円、上限10万円**（太陽光発電またはエネファームとの常時接続が条件）
- 事前申請ではなく、**工事・支払いを終えてから申請する**仕組み。年4回の受付期間があり、予算上限に達すると期の途中でも打ち切られる

## 1. 対象者・支給条件

対象となるのは、新宿区内に住所を有し、当該個人住宅に自ら使用する目的で補助対象機器を設置・施工し、全額の支払まで完了している人です。集合住宅に住所を有する人は、断熱窓を設置・施工した場合に限り対象になります。

蓄電池システムは、次の2条件をどちらも満たす必要があります。

- 一般社団法人環境共創イニシアチブ（SII）が補助対象機器として指定しているもの、または同等と認めるもの
- 太陽光発電システム、または家庭用燃料電池（エネファーム）と常時接続されていること

過去に同一の機器区分で本制度の補助を受けたことがある場合、中古品・リース機器を導入した場合、施工完了日と支払完了日の間が1年を超える場合は対象外です。

## 2. 支給額・計算方法（個人住宅向け6種類）

| 対象機器 | 補助額 |
|---|---|
| 太陽光発電システム | 公称出力1kWあたり100,000円（上限300,000円） |
| CO2冷媒ヒートポンプ給湯器（エコキュート） | 定額100,000円 |
| 家庭用燃料電池（エネファーム） | 定額100,000円 |
| 高反射率塗装（屋根・屋上） | 施工面積1m²あたり2,000円（上限200,000円） |
| 断熱窓 | 設置・施工費用（税抜）の25%（上限100,000円） |
| 蓄電池システム | 蓄電容量1kWhあたり10,000円（上限100,000円） |

## 3. 申請期間・受付状況

令和8年度は申請受付期間を4期に分けています。補助対象期間（機器の完了日）は全期共通で令和8年4月1日〜令和9年3月12日です。

| 期 | 受付期間 | 状況 |
|---|---|---|
| 第1期 | 令和8年5月25日〜7月31日（必着） | 終了しました |
| 第2期 | 令和8年8月17日〜10月16日（必着） | 受付中 |
| 第3期 | 令和8年11月2日〜12月25日（必着） | - |
| 第4期 | 令和9年1月12日〜3月12日（必着） | - |

2026年9月14日時点、第2期の交付決定予定率は24%（予算残率76%）です。期間内でも各期の予算上限に達した場合、その日をもって受付終了となります。

## 4. 申請方法

<Checklist items={["機器の設置・施工を行い、代金の全額支払いを完了する（この制度は完了後に申請する仕組み）", "交付申請書と添付書類（施工完了後の写真など）を用意する", "環境対策課窓口へ持参、または郵送で申請する（申請受付期間内に到着した分が対象）", "書類が揃っているものから順に審査される"]} />

太陽光発電システムや高反射率塗装は、施工完了後の写真が添付書類として必要です。足場の解体前に撮影するなど、施工業者と事前に打ち合わせておく必要があります。
