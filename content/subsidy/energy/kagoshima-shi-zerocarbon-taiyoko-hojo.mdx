鹿児島市のゼロカーボン推進支援事業（太陽光）補助金は、市民・共同住宅・事業所などが太陽光発電システムやHEMS、蓄電池などを導入する費用の一部を市が補助する制度です。個人住宅では太陽光が出力1kWあたり1万5千円（上限15万円）、HEMSが1万円、蓄電池・家庭用燃料電池・V2Hが各5万円です。

<Callout type="warning">
鹿児島市公式ページでは、個人住宅・共同住宅・事業所などの太陽光発電システム等の補助は**令和8年8月25日に予算額へ到達し受付終了**と告知されています。2026年9月21日時点で受付が続いているのは、**トラックへの太陽光発電システム設置に係る補助のみ**です。最新の受付状況は必ず公式ページで確認してください。
</Callout>

## この記事の結論

- 個人住宅の太陽光は**1万5千円/kW・上限15万円**（**HEMS同時新設が必須**）
- HEMSは**1万円**、蓄電池・エネファーム（家庭用燃料電池）・V2Hは**各5万円**（太陽光+HEMS同時新設が条件）
- **交付決定前の着工は対象外**（事前申請制）。窓口持参のみで、支所・郵送・メール申請は不可
- 個人住宅など主要な区分は**令和8年8月25日に受付終了**。残るのはトラック向け太陽光のみ
- 国などの他補助金との**併用は可能**（チラシ記載）

## 1. 対象者・支給条件

補助を受けるには、市税の滞納がなく、設置工事等を**鹿児島市内に本社・営業所を有する事業者**が行うことが前提です（申請時の工事請負・売買契約書等で確認。確認できない場合は商業登記簿謄本や営業証明などの写しが必要）。これまでに同一区分で市から同種の補助金を受けている場合は対象外です。

区分ごとの主な要件は次のとおりです。

| 区分 | 主な要件 |
|---|---|
| 個人住宅（店舗等併用住宅を含む） | 自ら所有する個人住宅に対象システムを設置・所有する者、または設置済み住宅を購入する者。実績報告日に当該市内住宅へ住民票があること（やむを得ず住民票がない場合は、生計を一にする親族が住民票を有していること等の例外あり） |
| 個人住宅（貸与） | 自ら所有する貸与住宅に設置・所有する者等。実績報告日に当該住宅または市内事業所へ住民票・所在があること。居住者がいることが条件 |
| 共同住宅 | 分譲の管理組合または貸与住宅の所有者など。共用部分のみでの使用が対象 |
| 事業所 | 自ら所有する建物に自らの使用目的で太陽光を設置・所有し、実績報告日に市内に事業所・営業所がある事業者 |
| トラック | 車検証上の使用者であり、使用の本拠が市内、燃料が軽油の貨物自動車に太陽光を設置する事業者 |

設備側の主な条件は次のとおりです。

- **太陽光発電システム**: 全量売電でないこと。個人・共同住宅はパネル合計出力とパワーコンディショナ出力のいずれか小さい方が**10kW未満**。未使用品
- **HEMS**: 家電の電力使用量を個別計測・制御できること（蓄電池のみの制御は対象外）。見える化機能とECHONET Lite規格。未使用品
- **リチウムイオン蓄電池**: SII登録品。未使用品
- **家庭用燃料電池**: FCA登録品。未使用品
- **V2H充放電設備**: CHAdeMO V2H protocol認証合格品。未使用品
- **電気自動車用充電設備（共同住宅）**: 同時設置の太陽光から給電できること。所定認証・規格適合、複数口、未使用品

個人住宅では、太陽光の補助を受けるために**HEMSの同時設置が必要**です。HEMS・蓄電池・家庭用燃料電池・V2H・充電設備の**単体設置は対象外**です。

## 2. 補助額・計算方法

| 対象システム | 補助額 | 条件の要点 |
|---|---|---|
| 太陽光（個人住宅） | 1万5千円/kW・上限15万円 | HEMSと同時新設 |
| 太陽光（共同住宅） | 1万5千円/kW・上限15万円 | — |
| 太陽光（事業所） | 1万5千円/kW・上限30万円 | 出力20kW超は上限額適用 |
| 太陽光（環境管理事業所） | 3万円/kW・上限60万円 | 出力20kW超は上限額適用 |
| 太陽光（トラック） | 補助対象経費の1/4以内・上限15万円 | 令和8年度に新設された区分 |
| HEMS（個人住宅） | 1万円 | 太陽光と同時新設 |
| リチウムイオン蓄電池（個人） | 5万円 | 太陽光+HEMS同時新設 |
| 家庭用燃料電池（個人） | 5万円 | 太陽光+HEMS同時新設 |
| V2H充放電設備（個人） | 5万円 | 太陽光+HEMS同時新設 |
| EV用充電設備（共同住宅） | 補助対象経費の1/2以内・上限5万円 | 太陽光と同時新設 |

補助金の額に1,000円未満の端数がある場合は切り捨てます。補助対象経費には、太陽電池モジュール・架台・パワーコンディショナ・付属品・工事費など（システムごとにチラシの表で定義）が含まれます。

処分制限期間は、太陽光発電システム**17年**、リチウムイオン蓄電池・家庭用燃料電池**6年**、HEMS・V2H・電気自動車用充電設備**5年**です。期間内の処分には事前の市の承認が必要で、補助金返還が生じます。

## 3. 申請方法・必要書類

この補助金は**事前申請制**です。市が送付する交付決定通知書を受け取る前に設置工事へ着手（建売の場合は住宅の引渡し）すると、補助金は交付されません。不備のない申請を受け付けてから交付決定まで、おおむね**2週間程度**かかります。

申請書類の受付は、市役所開庁日の午前8時45分から午後4時30分までです。**支所での申請や郵送・メール・FAXでの申請はできません**（実績報告書の提出は郵送でも可能）。制度上の申請期間は令和8年4月13日から令和9年3月31日までですが、予算到達で早期終了します。

## 4. 注意点・よくある誤解

- **個人住宅等はすでに受付終了**しています。2026年9月21日時点で残っているのはトラック向けのみです
- 「蓄電池だけ買えば補助が出る」は誤りです。個人向けの蓄電池・エネファーム・V2Hは**太陽光とHEMSの同時新設**が条件です
- 交付決定前の契約・着工は補助対象外です
- 窓口持参以外の申請方法は原則使えません
- 国等の補助金との併用は可能と案内されていますが、各制度の要件は別途確認が必要です
- 同一区分で過去に市の同種補助を受けている場合は対象外です
