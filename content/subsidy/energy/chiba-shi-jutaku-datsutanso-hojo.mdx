千葉市の住宅用設備等脱炭素化促進事業補助金（住宅向け）は、市内の住宅に太陽光発電や蓄電池、エネファーム、ZEH+、窓の断熱改修などを導入した市民（法人を除く）に、設置費用の一部を補助する制度です。令和8年度は太陽光が1kWあたり1万円（上限4.5万円）、蓄電池が上限7万円など、設備ごとに定額が決まっています。

## この記事の結論

- 太陽光は**1万円/kW・上限4.5万円**（既築のみ。申請時に蓄電池またはV2Hの設置が必須）
- 蓄電池は**上限7万円**（申請時に太陽光の設置が必須）
- エネファーム・ZEH+は各**上限10万円**、窓断熱は**経費の1/4・上限8万円**（既築のみ）
- 申請は**事後**。受付は**令和8年5月1日〜令和9年1月29日必着**、予算終了で早期終了
- 次世代自動車・集合住宅充電設備は**別制度ページ**

## 1. 制度の背景

千葉市は家庭の地球温暖化対策と電力の強靭化を目的に、住宅用の再エネ・省エネ設備導入を補助しています。所管は環境局環境保全部脱炭素推進課です。交付要綱は令和8年4月17日改正施行で、太陽光の算定式・上限やZEH+の扱い、窓断熱の対象範囲などが令和7年度から変更されています。

本記事は公式ページ「住宅用設備等脱炭素化促進事業補助金（住宅向け）」と令和8年度パンフレット・交付要綱に基づき、住宅設備メニューを整理します。EV・PHV・V2Hや集合住宅の充電設備は別案内のため扱いません。

## 2. 対象者・支給条件

共通して次を満たす必要があります（パンフレット・要綱別表3）。

1. 申請者が個人であること（法人は対象外）
2. 設備の導入費用を負担して所有すること（所有権留保付きローンや、一定条件のリースを含む）
3. 設備を導入した市内住宅に申請者が居住していること（住民基本台帳で確認）
4. 市税（延滞金を含む）の滞納がないこと
5. 共有名義などの場合は全所有者の同意があること
6. 同一住宅・同一設備名で過去に市の同種補助金を受けていないこと（別世帯や、エネファーム・蓄電池で財産処分制限期間経過後の交換・増設などの例外あり）
7. 設備が未使用品であり、要綱・パンフレットの仕様に適合すること

設備ごとの主な追加条件は次のとおりです。

| 設備 | 住宅 | 工事・引渡期間の目安 | 併設条件 |
|---|---|---|---|
| 太陽光発電 | 既築のみ | 開始・完了が令和8年2月1日〜令和9年1月29日 | 申請日までに適合する蓄電池またはV2Hが設置済み |
| ZEH+ | 新築・建売・既築 | 引渡日または完了日が同左期間 | 国のZEH+補助書類でZEH+と示されること（通常のZEHは対象外） |
| エネファーム | 新築・建売・既築可 | 開始・完了（新築等は引渡し）が令和8年4月1日〜令和9年1月29日 | 停電時自立運転機能付きで協会登録機器 |
| 蓄電池 | 新築・建売・既築可 | 同上 | 申請日までに太陽光が設置済み |
| 窓の断熱改修 | 既築のみ | 開始・完了が令和8年4月1日〜令和9年1月29日 | 1室単位で外気に接する全窓を断熱化。ガラスのみ交換は対象外 |

## 3. 支給額・計算方法

| 対象設備 | 補助額 | 備考 |
|---|---|---|
| 太陽光発電システム | 1万円×太陽電池モジュール最大出力（kW、小数第3位四捨五入）、上限4.5万円 | 千円未満切捨て。実支出が算定額未満なら実支出 |
| ZEH+ | 上限10万円 | |
| 家庭用燃料電池（エネファーム） | 上限10万円 | |
| 定置用リチウムイオン蓄電システム | 上限7万円 | |
| 窓の断熱改修 | 補助対象経費の1/4、上限8万円 | 税抜経費から国等補助金相当額を控除した額が対象経費 |

複数設備の同時申請は可能です。次世代自動車版の設備との同時申請もパンフレット上は可能とされていますが、申請先案内は設備カテゴリごとに分かれる点に注意してください。

公式ページ（更新日2026年8月20日）時点の残り受付目安は、太陽光約155件/約200件、ZEH+約65件/約80件、エネファーム約110件/約150件、蓄電池約360件/約460件、窓断熱約70件/約100件です。最新の残数は市ホームページで確認してください。

## 4. 申請方法・必要書類

申請は**補助事業の完了後**に行います。方法はオンライン・郵送・窓口の3通りです。

1. 提出書類を準備する（オンライン申請では申請書様式自体はフォーム入力で代替）
2. オンライン（公的個人認証＝マイナンバーカード）、郵送、または窓口（平日9時〜17時）で提出
3. 書類不備がないことを市が確認した日が受付日になる
4. 交付決定兼額確定通知は、市が書類を受けた後おおよそ8週間で発送

## 5. 注意点

- **事後申請**のため、工事前の予約受付ではありません。納期遅延で完了が遅れると受付期間に間に合わない可能性があります。
- 受付期間外の日付の申請書や到着分は受け付けられません。予算終了で早期終了します。
- 虚偽記載や不正があった場合、交付決定は取り消されます。
- 「市と一緒に無償で蓄電池を設置できる」などとたたる訪問販売には注意してください。市はそうした無償設置事業を行っておらず、蓄電池は設置した人への補助金交付です。
- 本記事の対象外: 次世代自動車関係（`ev_hojo.html`）、集合住宅充電設備関係（`shugo_ev_juden_hojo.html`）。
