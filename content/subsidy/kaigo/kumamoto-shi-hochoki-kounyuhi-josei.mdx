熊本市の高齢者補聴器購入費助成（正式名称：熊本市難聴高齢者介護予防促進事業）とは、聞こえづらさに不安を感じている高齢者の補聴器購入費用の一部を、上限3万円まで助成する制度です。令和8年6月1日から受付が始まっており、65歳以上で聴力や所得などの要件を満たす方が対象になります。

<SubsidyInfoCard />

## この記事の結論

- 助成額は**上限3万円**（補聴器の購入額が3万円未満の場合は、その購入額が上限）
- 対象は熊本市に住民登録がある**65歳以上**で、両耳の聴力レベルが原則30dB以上、身体障害者手帳（聴覚障害）の交付対象外、市民税非課税世帯または生活保護受給中など複数の要件をすべて満たす方
- **交付決定通知書（給付券）が届く前に購入した補聴器は対象外**。申請から購入までの順番を間違えないことが重要

## 1. 制度の目的と実施状況

この事業は、聞こえづらさから日常生活に不安を感じている高齢者が適切な補聴器を装用できるよう費用の一部を助成し、コミュニケーション能力の維持・向上や、フレイル（心身が弱った状態）予防・社会参加につなげることを目的としています（実施要綱第1条）。

実施要綱は令和8年4月24日に制定され、令和8年6月1日から受付が始まりました。要綱は令和8年8月3日にも改正されていますが、具体的にどの条文がどう変わったかは公式資料からは特定できません。本記事は改正後の最新の要綱内容にもとづいて作成しています。

## 2. 対象者・支給条件

次の要件を**すべて**満たす方が対象です。

| 要件 | 内容 |
|---|---|
| 居住 | 熊本市の区域内に居住し、住民基本台帳に記録されていること（DV被害者等は例外規定あり） |
| 年齢 | 申請時点で65歳以上 |
| 聴力 | 両耳の聴力レベルが原則30dB以上で、かつ身体障害者手帳（聴覚障害）の交付対象とならないこと |
| 医師の判断 | 補聴器の装用により聴力に一定の効果が期待できると医師が判断していること |
| 所得 | 市民税非課税世帯に属している、または生活保護を受給中であること |
| その他 | 補聴器装用開始後のアンケートに回答できること、介護予防事業への参加に積極的に努めること |
| 再申請 | 過去にこの事業の助成を受けている場合、助成決定日から5年を経過していること |

市民税が非課税かどうかは、世帯員全員の所得状況をもとに熊本市が確認します。非課税となる具体的な所得の基準額までは公式資料に明記されていないため、自分が対象になるか不安な場合は各区福祉課に確認してください。

## 3. 助成額・計算方法

助成金の交付額は**3万円を上限**とし、補聴器の購入額が3万円未満だった場合は、その購入額が上限になります（実施要綱第3条）。つまり一律3万円がもらえるのではなく、「実際の購入額」と「3万円」を比べて低いほうが助成額になる仕組みです。

| 購入額 | 助成額 |
|---|---|
| 3万円以上の補聴器を購入 | 3万円 |
| 2万円の補聴器を購入 | 2万円 |

医師意見書の作成手数料、集音機、補聴器の付属品、修理・メンテナンス費用は助成の対象外で、自己負担になります。

## 4. 申請方法・必要書類

申請から補聴器の購入までは、次の順番で進みます。**交付決定通知書（給付券）が届く前に補聴器を購入すると、助成の対象外になる**ので注意してください。

給付券の有効期間は、交付決定日から**6か月**です（様式第6号）。有効期間内に決定業者で購入する必要があります。
