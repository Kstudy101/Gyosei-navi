高松市の寝たきり高齢者等紙おむつ給付事業とは、在宅の寝たきり・認知症高齢者（原則要介護3〜5）や、一定の要件を満たす過活動膀胱の高齢者に対し、紙おむつ・尿取りパッドを**現物**で給付し、住所エリアに応じて**2か月分ずつ**自宅などへ配達する市独自の制度です。介護保険の住宅改修費とは別の、介護保険外サービスです。

<SubsidyInfoCard />

## この記事の結論

- 対象の中心は**市内在住65歳以上**で**寝たきり又は認知症**、原則**要介護3〜5**、**生計中心者の市民税非課税**、**施設未入所**などの要件をすべて満たす方
- 給付は現金ではなく、**タイプ別の月あたり枚数**（例: Aタイプはテープ止めパンツ30枚＋尿取りパッド昼60・夜30）
- 配達は偶数月／奇数月エリアに分け、**2か月分ずつ**
- 申請窓口は**長寿福祉課**（郵送可。寝たきり・認知症枠は電子申請あり）

## 1. 対象者・支給条件

公式ページによると、身体の状況で要件と給付内容が異なります。**両方の対象でも、どちらか一方のみ**申請できます。

### 寝たきり又は認知症の方

次の**すべて**に該当していること。

| 区分 | 内容 |
|---|---|
| 居住・年齢 | 市内に住所を有する**65歳以上** |
| 身体状況 | **寝たきり又は認知症**の状態 |
| 要介護度 | 原則、**要介護3〜5**の認定を受け、その効力の有する期間にある |
| 税要件 | 属する世帯の**生計中心者の市民税が非課税** |
| 生活形態 | **介護保険施設に入所していない**／短期入所を**1か月に16日以上**利用していない |

特例で次の方も支給できる場合があります。

- **要介護2で認知症**の方（主治医意見書の「認知症高齢者の日常生活自立度がⅢa以上」かつ「尿失禁にチェックがある」）
- 要介護認定を受けておらず、**3か月以上入院**しており、常時おむつが必要であることを**医師が証明**した方（証明書様式は長寿福祉課）

### 過活動膀胱の方

次の**すべて**に該当していること。

| 区分 | 内容 |
|---|---|
| 居住・年齢 | 市内に住所を有する**80歳以上** |
| 症状 | 過活動膀胱による尿失禁及び夜間頻尿が**6か月以上**継続（申請書に医師の証明が必要） |
| 税要件 | 属する世帯の**生計中心者の市民税が非課税** |
| 生活形態 | 介護保険施設に入所していない／短期入所を1か月に16日以上利用していない |

## 2. 給付内容・配達

1か月あたりの枚数は公式ページで次のとおりです（詳細は「申請上の注意」裏面参照と記載）。

### 寝たきり又は認知症の方

| タイプ | 内容（月あたり） |
|---|---|
| A | テープ止めパンツ（**30枚**）と尿取りパッド（昼用**60枚**＋夜間用**30枚**）のセット |
| B-1 | はきおろしパンツ（**45枚**）と尿取りパッド（昼用**30枚**＋夜間用**30枚**）のセット |
| B-2 | はきおろしパンツ（**45枚**） |
| C-1 | 尿取りパッド昼用（**120枚**） |
| C-2 | 尿取りパッド夜間用（**60枚**） |

### 過活動膀胱の方

尿取りパッド（昼用**30枚**）。

### 配達の仕組み

お届け先住所により、**偶数月配達エリア**と**奇数月配達エリア**に分かれ、**2か月分ずつ**市内の自宅等へ配達します。町名別エリア一覧・新規申請の初回配達月（令和8年度）は公式PDFで案内されています。

給付タイプや配達先の変更は、**配達月の前月15日**まで（土日祝の場合は直前の開庁日）に長寿福祉課へ連絡します。施設入所や短期入所16日以上利用など、対象外になった場合は速やかに連絡してください。未開封の不要なおむつは引き取りできる場合があります。

## 3. 申請方法

高松市の寝たきり高齢者等紙おむつ給付事業は、原則要介護3〜5で税・在宅要件を満たす高齢者などに、タイプ別枚数の紙おむつ等を現物給付し2か月分ずつ配達する市独自の制度です。最新の対象要件・受付期間・配達エリアは、必ず高松市公式ページまたは長寿福祉課で確認してください。
