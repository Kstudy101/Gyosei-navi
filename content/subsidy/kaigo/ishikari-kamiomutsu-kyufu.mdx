石狩市の「紙おむつ給付サービス」（事業名: 石狩市寝たきり高齢者等紙おむつ給付事業）は、在宅で紙おむつを必要とする方へ、紙おむつを自宅まで配達する**現物給付**の市事業です。現金の購入費助成ではなく、必要な枚数を隔月で届ける仕組みです。

<SubsidyInfoCard />

## この記事の結論

- **自宅配達の現物給付**。申請書注記では「1月に必要とする枚数を**隔月**で給付」
- 対象は在宅で紙おむつを使う方のうち、寝たきり度B以上・認知症自立度3a以上・重度障害者手帳等の要件に該当する方
- 申請書類（申請書・調査票・令和8年度メーカー希望用紙など）は市公式サイトからダウンロード可能。窓口は高齢者支援課

## 1. 対象者・支給条件

各種サービス案内ページでは、自宅で日常生活を営む上で紙おむつを利用しており、次のいずれかに該当する方が対象とされています。

| 区分 | 要件 |
|---|---|
| 寝たきり（高齢） | 65歳以上で、要介護認定に係る調査結果等における寝たきり度が**B以上**、かつ排泄において一部介助または全介助が必要と認められた方 |
| 認知症 | 40歳以上で、要介護認定に係る調査結果等における認知症高齢者の日常生活自立度が**3a以上**、かつ排泄において一部介助または全介助が必要と認められた方 |
| 身体障害 | 身体障害者手帳1級または2級で、**3歳以上**の寝たきり状態等の方 |
| 知的障害 | 療育手帳A判定で、**3歳以上**の寝たきり状態等の方 |

案内ページ末尾には、「記載の対象要件を満たさない場合でもサービスの利用が認められる場合があります」とあり、個別判断の余地が示されています。詳細は高齢者支援課へ確認してください。

申請書には生活保護受給の有無欄と、納税状況・介護保険認定情報の照会同意欄があります。一方で、住民税課税世帯を一律除外するといった所得要件の明文は、案内ページ・申請書本文には確認できませんでした。

## 2. 支給内容

| 項目 | 内容 |
|---|---|
| 給付形態 | 紙おむつの**自宅配達**（現物） |
| 給付サイクル | **隔月**で、1か月に必要とする枚数を給付（申請書注記） |
| 選択品目（令和8年度希望用紙） | パンツタイプ（はくタイプ）／テープタイプ／フラットタイプ（平おむつ）／尿とりパッド 等。用紙上は希望を**1つだけ○** |
| 上限円・固定枚数 | 一般向け案内ページに定額・固定枚数の公開表記なし（希望用紙に市記入の「枚まで支給可能」欄あり） |

令和6年度の介護保険事業進捗資料では、本サービスは**令和3年度より市町村特別給付で実施**していると記載されています。

## 3. 申請方法

| 項目 | 内容 |
|---|---|
| 主な書類 | 紙おむつ給付事業申請書、調査票（介護支援専門員・市保健師用）、メーカー希望用紙（令和8年度）、必要に応じて利用者異動届 |
| 入手先 | [申請書ダウンロード／高齢者・介護保険](https://www.city.ishikari.hokkaido.jp/kurashi/hoken/1001826/1002593.html) |
| 調査票 | 介護支援専門員または市保健師が記入する様式（家族だけでは完結しない点に注意） |
| 受付窓口 | 福祉部 高齢者支援課（総合保健福祉センター「りんくる」1階） |
| 問い合わせ | 電話 0133-72-6121／ファクス 0133-72-1165／Eメール koureisyas@city.ishikari.hokkaido.jp |

郵送可否や電子申請の可否は、紙おむつ個別の案内としては確認できませんでした。申請書ダウンロードページ全体の注意では、電子申請可能な手続きを除き窓口での手続きとされています。提出方法は申請前に高齢者支援課へ確認してください。

## 4. 近くにある関連制度（別制度）

同じ「各種サービス」案内には、紙おむつ以外にも次の在宅サービスが並んでいます（詳細・自己負担は各案内を確認）。

- **配食サービス**: 月〜金で夕食配達と安否確認（自己負担あり）
- **緊急通報サービス**: 固定電話に通報装置を設置（課税状況に応じて自己負担）
- **理容サービス**／**ふとんクリーニングサービス**／**外出支援サービス**

本記事は紙おむつ給付に限定しています。また、障がい福祉の日常生活用具としての紙おむつ（医師意見書様式が別ページに掲載）は別制度です。

## 5. 注意点・確認事項

- 国の介護保険給付（福祉用具貸与など）とは別の、石狩市の事業です
- 「必ず給付される」「誰でも受け取れる」制度ではありません。調査票等に基づき市が可否を判断します
- 自己負担の有無は紙おむつ欄に明文がなく、本稿では断定していません
- 支給量・対象・様式は改定され得るため、申請前に最新の公式案内を確認してください
