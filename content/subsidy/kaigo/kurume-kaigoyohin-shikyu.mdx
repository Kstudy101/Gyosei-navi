久留米市の介護用品支給事業とは、在宅の要介護高齢者の福祉・衛生向上のため、紙おむつ購入費の一部を市が助成する制度です。現金ではなく、月額3,000円分の介護用品給付券を交付し、登録事業者の配達または購入店での利用に充てます。

<SubsidyInfoCard />

## この記事の結論

- 助成は**月額3,000円の介護用品給付券**（要介護3・4・5で同額）
- 対象は**要介護3以上**かつ**住民税非課税世帯**の在宅の市介護保険被保険者（生活保護受給中は対象外）
- 申請は**ケアマネージャー経由**で長寿支援課または総合支所へ

## 1. 対象者・支給条件

次の条件を**すべて**満たす人が利用できます。

| 区分 | 内容 |
|---|---|
| 保険 | 久留米市の介護保険被保険者であること |
| 要介護度 | 要介護3、要介護4または要介護5の認定があること |
| 利用事由 | 身体上または精神上の理由により、おむつが常時必要と判断されること |
| 世帯の税 | 住民税非課税世帯に属すること |
| 居住・介護 | 在宅で介護を受けていること |
| 生活保護 | 生活保護を受給していないこと |

生活保護を受給中の人は本事業の対象外です。生活支援第１課・第２課へ相談するよう案内されています。また、要件を満たす場合でも対象外となることがあるため、詳細は長寿支援課（0942-30-9038）で確認してください。

## 2. 支給額・利用方法

紙おむつ購入代金の一部として、**月額3,000円の介護用品給付券**が交付されます。要介護度による金額差はありません。

| 項目 | 内容 |
|---|---|
| 助成額 | 月額3,000円分の介護用品給付券 |
| 受け取り | 登録事業者が自宅へ配達（直接購入店での購入可） |
| 対象品目 | 尿取りパッド、介護用パンツタイプ・テープ止めタイプ・フラットタイプの紙おむつ |

配達できる校区は事業者ごとに異なります。市が公開する令和8年度登録事業者・配達地域の一覧で確認してください。

北九州市のおむつ給付サービスは要介護度別に月6,000〜7,000円の助成限度を設け、限度内の自己負担を原則10％とする設計です。久留米市は**定額3,000円の給付券**であり、金額の単純比較だけでは制度の違いが分かりにくい点に注意してください。

## 3. 申請の流れ

1. 担当のケアマネージャーに相談する（いない場合は地域包括支援センターへ）
2. 「介護用品支給事業利用申請書」を用意する
3. 長寿支援課または総合支所の市民福祉課へ申請する
4. 支給決定後、給付券を利用して紙おむつを受け取る

支給決定後に要件を満たさなくなった場合は、資格喪失届の提出と介護用品給付券の返却が必要です。変更がある場合は変更届を提出します。
