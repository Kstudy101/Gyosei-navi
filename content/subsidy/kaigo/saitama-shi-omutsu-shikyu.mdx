さいたま市重度要介護高齢者紙おむつ等支給事業とは、常時おむつを使用している在宅の要介護高齢者に対し、月額6,000円（税込）を上限とした紙おむつ等支給利用券を毎月支給する制度です。利用券は参加事業者（宅配業者・薬局）への注文に使い、紙おむつ・尿とりパッド・おしりふき・使い捨て手袋などと引き換えます。

## この記事の結論

- 支給額は**月額6,000円（税込）が上限**で、超えた分は自己負担になる
- 対象は市内在住65歳以上・**要介護3(排尿または排便の介助等が必要な場合に限る)・4・5**で、介護保険料段階第1〜5段階など複数条件を満たす人
- 利用者本人の申請は**毎月24日締め切り**で通年受け付けており、「事業者登録の新規受付終了」とは無関係

## 1. 対象者・支給条件

対象は、さいたま市内に居住する65歳以上の高齢者のうち、常時おむつを使用する人で、次の要件をすべて満たす人です。

| 区分 | 内容 |
|---|---|
| 居住・年齢 | さいたま市内に居住する65歳以上（さいたま市の介護保険被保険者） |
| 要介護度 | 要介護3・4・5のいずれか。ただし要介護3は、要介護認定の認定調査票で「排尿」または「排便」の項目が「介助」または「見守り等」に該当する場合に限る |
| 介護保険料段階 | さいたま市介護保険条例第3条第1項第1号〜第5号に該当（第1段階〜第5段階） |
| 保険料 | 介護保険料を滞納していない |
| 生活保護 | 生活保護法による保護を受けていない |
| 施設入所 | 介護保険施設（地域密着型介護老人福祉施設含む）に入所していない |
| 入院 | 病院または診療所への入院が3か月を超えていない |

実施要綱では、このほか中国残留邦人等支援給付を受けていないことも要件に挙げられています。要件の該当有無を自分で判断しづらい場合は、お住まいの区の高齢介護課高齢福祉係に相談するのが確実です。

## 2. 支給額・計算方法

紙おむつ等の支給は、月額6,000円（税込）を上限とした「紙おむつ等支給利用券」の交付という形で行われます。現金給付ではありません。

| 項目 | 内容 |
|---|---|
| 支給上限額 | 月額6,000円（税込） |
| 支給方法 | 紙おむつ等支給利用券を交付。利用者が参加事業者（宅配業者・薬局）の商品カタログから商品を選び、利用券と引き換えに直接注文 |
| 支給品目 | 紙おむつ、尿とりパッド、おしりふき、使い捨て手袋など |
| 利用券の交付枚数 | 年間最大12枚（月1回） |
| 上限超過分 | 利用者の自己負担 |

利用券は現金化できず、月をまたいでの繰り越しもできません。毎月の上限額（6,000円）の範囲内で商品を選ぶ必要があります。

### 事業者向けの「登録受付終了」との違いに注意

さいたま市の事業者向けページには「令和8年度紙おむつ等支給事業の新規受付は終了しました（登録受付期限 令和7年11月28日まで）」という案内があります。これは、宅配業者・薬局が「参加事業者」としてさいたま市に登録するための申請受付が終了したという意味です。**利用者（市民）本人が紙おむつ等の支給を申請する手続きとは別物**で、利用者の申請は毎月24日締め切りで引き続き受け付けています。両者を混同しないよう注意してください。
