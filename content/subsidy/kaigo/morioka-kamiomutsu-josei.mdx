盛岡市の在宅要介護高齢者紙おむつ助成事業とは、要介護3〜5で市県民税非課税等の要件を満たす在宅の高齢者に対し、月1枚・額面3,000円の紙おむつ助成券を交付する市独自の制度です。現金給付ではなく、市登録の取扱事業者で紙おむつ等と引き換える助成券方式です。

<SubsidyInfoCard />

## この記事の結論

- 助成は**紙おむつ助成券（月1枚・額面3,000円）**で、対象品目は紙おむつ・尿とりパッド
- 対象は**要介護3〜5**の在宅高齢者で、要介護3のみ排尿・排便の介助要件が追加される。あわせて、床に伏す状態または失禁の状態が6か月以上継続していることも要件
- 申請は**毎月15日締切**（郵送は締切日必着）で、年度ごとの更新申請が必要

## 1. 対象者・支給条件

次の要件をすべて満たす方が対象です。

| 区分 | 内容 |
|---|---|
| 年齢・保険 | 盛岡市の介護保険被保険者で65歳以上 |
| 施設入所 | 地域密着型介護老人福祉施設・介護老人福祉施設・介護老人保健施設・介護医療院・特別養護老人ホームのいずれにも入所していない |
| 入院 | 申請日において医療機関に入院していない |
| 心身の状態 | 1日中ほとんど床に伏している状態が6か月以上継続（または継続見込み）、または心身の障害・疾病等により失禁の状態が6か月以上継続（または継続見込み）のいずれかに該当 |
| 要介護度 | 要介護3、要介護4または要介護5 |
| 税 | 申請者本人及び同居者の前年分（1〜5月の申請は前々年分）の市県民税が非課税 |
| 他制度 | 生活保護を受けていない、中国残留邦人等支援給付を受けていない |
| 保険料 | 介護保険料を滞納していない |
| 重複給付 | 他の制度により紙おむつに係る給付を受けていない |

要介護度に関しては、要介護4・5の方はこの追加要件なしで対象となりますが、**要介護3の方は、要介護認定の認定調査票の「排尿」または「排便」の項目が「介助」または「見守り等」に該当する場合に限り**対象となります。

## 2. 助成内容・対象品目

助成は現金ではなく、**紙おむつ助成券**の交付です。

| 項目 | 内容 |
|---|---|
| 交付枚数 | 1人につき月1枚 |
| 助成券の額 | 3,000円（消費税・地方消費税込み） |
| 3,000円未満で使用した場合 | 使用額が助成額（差額の返還・次回への繰り越しは不可） |
| 額面を超えた分 | 自己負担 |
| 対象品目 | フラット型紙おむつ、テープ止め型紙おむつ、パンツ型紙おむつ（リハビリパンツを含む）、尿とりパッド |

助成券は市に登録された取扱事業者に提出し、有効期間内に額面金額を限度として紙おむつ等と引き換えます。譲渡・換金・転売・貸付・担保提供は禁止されています。

## 3. 申請方法・必要書類

申請者は対象者本人または家族です。年度ごとに交付申請が必要で、継続して利用する場合も毎年度の更新申請が求められます。

<Checklist items={["盛岡市在宅要介護高齢者紙おむつ助成事業利用申請書及び同意書（様式第1号）"]} />

申請の締切は**毎月15日**（15日が閉庁日の場合は次の開庁日）です。郵送で提出する場合は締切日必着となります。必要書類に不足や記入漏れがある場合は受付できず、締切までに整わないと翌月扱いになることがあります。窓口での申請可否を含む具体的な提出方法は、盛岡市保健福祉部長寿社会課へ事前に確認してください。審査後、承認・不承認が通知されます。

盛岡市公式ページには年度の予算上限や受付終了に関する記載はなく、毎月15日締切のサイクルで通年運用されています。ただし、年度途中で運用が変わる可能性もゼロではないため、申請時期が近い場合は事前に問い合わせ先へ確認することをおすすめします。

申込先・問い合わせ先は次のとおりです。

- 盛岡市保健福祉部長寿社会課
- 郵便番号: 〒020-8530 盛岡市内丸12-2
- 電話: 019-603-8003
- FAX: 019-653-2839

なお、次のいずれかに該当する場合は資格喪失の届出が必要です。

- 受給者が死亡したとき
- 受給者が引き続き1か月を超えて医療機関に入院したとき
- 上記の対象者の要件を満たさなくなったとき
