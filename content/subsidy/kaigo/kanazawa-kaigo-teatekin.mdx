金沢市介護手当金の支給とは、65歳以上のねたきりまたは重度認知症の高齢者を在宅で3か月以上常時介護している家族に対し、月額5,000円を年3回（4月・8月・12月）に分けて支給する制度です。

<SubsidyInfoCard />

## この記事の結論

- **65歳以上のねたきり・重度認知症の高齢者**を在宅介護する家族が対象
- **月額5,000円、年3回（4月・8月・12月）支給**（年間合計15,000円）
- 要介護者は**要介護4または5**（重度認知症は要介護3でも可）
- 介護者の就労要件：**無職または週6時間以内の内職等**
- 転出・施設入所があった場合は支給対象外

## 1. 対象者

### 介護を受ける方（要介護者）の要件

| 要件 | 内容 |
|---|---|
| 年齢 | 65歳以上 |
| 状態 | ねたきりまたは重度の認知症 |
| 要介護度 | **要介護4または5**（重度認知症の場合は要介護3でも可） |
| 居住 | 金沢市に住所を有すること |
| 在宅 | 基準日時点で在宅にいること（施設・病院入所者は除外） |

### 介護する方（介護者）の要件

| 要件 | 内容 |
|---|---|
| 続柄 | 配偶者または3親等以内の親族 |
| 介護期間 | 基準日時点で在宅で**3か月を経過して常時介護**していること |
| 就労状況 | 無職、または1週間で6時間を超えない範囲での内職等、自宅での自営業または農作業 |

## 2. 支給内容

| 項目 | 内容 |
|---|---|
| 支給額 | 月額**5,000円** |
| 支給回数 | 年**3回** |
| 支給月 | **4月・8月・12月** |
| 基準日 | 各支給月の1日（4月1日・8月1日・12月1日）時点で要件を満たすこと |
| 年間合計 | **15,000円** |
