越谷市の在宅介護者福祉手当とは、在宅の要介護4または5の高齢者を家族等で常時介護している主たる介護者に対し、市が月額5,000円（2人以上介護の場合は1万円）を支給する制度です。公式ページの更新日は2026年7月8日です。

<SubsidyInfoCard />

## この記事の結論

- 支給額は**月額5,000円**（2人以上を介護している場合は**月額1万円**）
- 対象は**市内住所**があり、在宅の**65歳以上・要介護4または5**の方を**常時介護**している**主たる在宅介護者**
- 支給は**年3回（4月・8月・12月）**に、それぞれ**4か月分をまとめて**振込
- 要介護者が**施設・病院等に入っている場合は受給不可**

## 1. 対象者・支給条件

次の条件を満たす主たる在宅介護者が対象です。

| 区分 | 内容 |
|---|---|
| 介護者 | 市内に住所を有する、主たる在宅介護者 |
| 要介護者 | 在宅している**65歳以上**で、**要介護4または5**の方 |
| 介護の程度 | **常時介護**していること（申請時に介護保険サービスの利用状況を確認） |
| 除外 | 要介護者が**施設・病院等に入っている場合**は受給不可 |

「常時介護」の具体的な回数・時間の数値基準は原文に記載がありません。申請時に介護保険サービスの利用状況を尋ねて判断する、と案内されています。

主たる介護者側の所得制限（非課税要件など）や同居必須の明記も原文にはありません。該当するかは高齢福祉課で確認してください。

### 他自治体の類似制度との違い

世田谷区・長崎市などの家族介護慰労金は**年額10万円**かつ介護保険サービス原則未利用が要件になる例が多い一方、越谷市は**月額5,000円（年換算6万円）**で、介護保険サービス未利用を絶対条件としては書いていません。要介護度は越谷市も**要介護4・5**に限定されています。

## 2. 支給額・支給時期

| 項目 | 内容 |
|---|---|
| 支給月額 | 5,000円 |
| 2人以上を介護する場合 | 月額1万円 |
| 支給月 | 年3回（**4月・8月・12月**） |
| 支給単位 | 各回とも**4か月分をまとめて**支給 |

## 3. 申請方法・必要書類

資格認定申請書のほか、次のものが必要です。

- 要介護者の介護保険被保険者証
- 申請月の介護保険サービスの利用状況がわかるもの（利用状況を把握していれば不要）
- 主たる介護者の普通預金口座の振込先がわかるもの
- 主たる介護者の住所を確認できる資料の写し（**住民票が市外にあるときのみ**）

公式ページでは申請書（Word）と記入例（PDF）、電子申請の案内もあります。問い合わせ・申請先は高齢介護部高齢福祉課（第二庁舎1階、電話048-963-9187、FAX048-963-9199）です。

## 4. 受給中の届出

次の場合は異動届の提出が必要です。

- 要介護者が亡くなったとき
- 施設に入所したとき
- 3ヵ月以上入院したとき
- 本市の住民でなくなったとき
- 要介護認定が要介護3以下になったとき
- 常時介護の基準を満たさなくなったとき
- 手当の受給を辞退するとき
- 介護している方の住所・氏名等の変更、振込先口座の変更、その他申請内容の変更

また、受給中の方は**毎年6月に現況届**を提出する必要があります。対象者には毎年6月頃に通知が送付されます。
