豊島区の「高齢者紙おむつ等支給」「高齢者おむつ購入費等助成」とは、要介護1以上の高齢者を対象に、在宅なら紙おむつ等を現物で支給し、医療機関に入院中なら購入費を現金で助成する、区独自の2つの制度です。生活場所によってどちらか一方の制度を使う仕組みで、同じ月に両方を受けることはできません。

## この記事の結論

- **在宅**の方は「高齢者紙おむつ等支給」（現物、**月80点=8,000円相当が上限**）、**入院中**の方は「高齢者おむつ購入費等助成」（現金、**月8,000円が上限**）が対象
- どちらも対象は**要介護1以上**だが、所得段階の範囲は助成（第1〜8段階）のほうが支給（第1〜5段階）より広い
- 令和7年9月分から両制度とも上限額が引き上げられ（支給は70点→80点、助成は7,000円→8,000円）、**同月内の併給は不可**

## 1. 2つの制度の違い

豊島区には在宅高齢者向けの介護用品支給に関して、互いに排他的な2つの制度があります。

| 項目 | 高齢者紙おむつ等支給 | 高齢者おむつ購入費等助成 |
|---|---|---|
| 給付形態 | 現物（カタログから選択して配布） | 現金（口座振込） |
| 対象の生活場所 | 在宅（有料老人ホーム・グループホーム含む） | 医療機関に入院中 |
| 要介護度 | 要介護1以上（第2号被保険者含む） | 要介護1以上（第2号被保険者含む） |
| 介護保険料所得段階 | 第1〜5段階 | 第1〜8段階 |
| 月額上限 | 80点=8,000円相当（令和7年9月分〜。改定前70点） | 8,000円（令和7年9月分〜。改定前7,000円） |
| 併給 | 相互に併給不可（同月内） | 相互に併給不可（同月内） |

特別養護老人ホーム・介護老人保健施設・介護医療院に入所している方は、どちらの制度も対象外です。医療機関に入院中の方は「高齢者紙おむつ等支給」の対象外ですが、「高齢者おむつ購入費等助成」の対象になる場合があります。

## 2. 高齢者紙おむつ等支給（在宅・現物）

次のすべてを満たす方が対象です。

1. 要介護認定「要介護1以上」（第2号被保険者含む）
2. 介護保険料所得段階が第1〜5段階
3. 常時紙おむつ等が必要
4. 在宅（有料老人ホーム・グループホームは在宅扱い。特養・老健・介護医療院入所者、医療機関入院中の方は対象外）
5. 生活保護制度の扶助を受けていない

**1か月80点（8,000円相当分）を上限**に、常時紙おむつ等が必要な在宅の方へ月1回紙おむつ等を配布します。令和7年9月分から支給上限が70点から80点（8,000円相当分）に引き上げられました。「高齢者おむつ購入費等助成」を同月内に受けている場合は併給できません。

申請の流れは「高齢者紙おむつ等支給申請書」を高齢者総合相談センターへ提出し、区が要介護度・所得段階等を審査後、決定通知または却下通知が郵送されます。決定通知に同封されたカタログの中から希望の商品を注文する仕組みです。

## 3. 高齢者おむつ購入費等助成（入院中・現金）

次のすべてに該当する方が対象です。

1. 要介護認定「要介護1」以上（第2号被保険者含む）
2. 介護保険料所得段階が第1〜8段階
3. 常時紙おむつ等が必要
4. 医療機関に入院している（特養・老健・介護医療院入所者は除く）
5. 生活保護制度の扶助を受けていない

**1か月8,000円を上限**に、入院中のおむつ購入費等を申請月の分より助成します。令和7年9月分から助成上限が7,000円から8,000円に引き上げられました。「高齢者紙おむつ等支給事業」を同月内に受けている場合は併給できません。

申請は「高齢者おむつ購入費等助成申請書」を住まいの地域の高齢者総合相談センターへ提出します（申請日時点で入院していることが条件で、電子申請サービスも利用可能）。必要書類は本人の振込口座が確認できる書類（通帳コピー等）で、本人以外の口座を希望する場合は委任状、成年後見人が申請する場合は本人確認証と発行6か月以内の登記事項証明書が必要です。
