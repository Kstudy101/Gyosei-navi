宮崎市の「高齢者等居宅介護住宅改修補助事業」は、介護保険の住宅改修費（上限20万円）を超えた費用や保険対象外の工事費用の一部を補助する市独自の制度です。世帯の所得税額に応じて補助率が4割〜10割に設定されており、所得の低い世帯ほど手厚い支援が受けられます。

<SubsidyInfoCard />

## この記事の結論

- 介護保険の住宅改修費（20万円）を**超えた費用**と**保険対象外工事費用**を補助
- 補助率: 生活保護世帯は**10割**〜所得税40,001〜70,000円世帯は**4割**
- 1住宅あたりの補助上限: **20万円**（上限まで繰り返し申請可）
- **工事着工前**の事前申請が必須

## 1. 対象者

以下の**すべての要件**を満たす方が対象です。

1. 宮崎市内に住所がある
2. 介護保険法で**要支援または要介護**状態と認定されている
3. 要介護者等と生計を一にする親族・同居人の前年分所得税額の合計が **7万円以下**
4. 介護保険の住宅改修給付対象工事の場合は、介護保険の**支給限度基準額（20万円）まで使い切った**方

<Callout type="warning">
平成12年4月1日以降に「宮崎市重度障がい者住宅改修費助成事業」の補助を受けた方は、この事業の補助を受けられません。
</Callout>

## 2. 補助率（世帯の課税状況による）

| 区分 | 補助率 |
|------|--------|
| A 生活保護世帯 | **10割** |
| B 市民税・所得税ともに非課税 | **9割** |
| C 市民税課税・所得税非課税 | **8割** |
| D 所得税1円〜5,000円以下 | **7割** |
| E 所得税5,001円〜15,000円以下 | **6割** |
| F 所得税15,001円〜40,000円以下 | **5割** |
| G 所得税40,001円〜70,000円以下 | **4割** |

補助率は、申請月が1〜5月の場合は前々年分、6月以降の場合は前年分の所得税額に基づいて判定されます。

## 3. 対象工事・限度額

| 工事種類 | 限度額 | 対象の要介護度 |
|----------|--------|-------------|
| 手すりの取付け | 20万円 | 要支援1,2・要介護1〜5 |
| 段差の解消 | 20万円 | 要支援1,2・要介護1〜5 |
| 床または通路面の材料変更 | 20万円 | 要支援1,2・要介護1〜5 |
| 引き戸等への扉の取替え | 20万円 | 要支援1,2・要介護1〜5 |
| 洋式便器等への便器の取替え | 20万円（介護保険分含む） | 要支援1,2・要介護1〜5 |
| 移動・介護に必要なスペース確保 | 20万円 | 要支援2・要介護1〜5 |
| 浴室改修（付帯工事含む） | 20万円 | 要支援2・要介護1〜5 |
| 浴槽取替え | 20万円 | 要支援2・要介護1〜5 |
| 給湯設備 | 10万円 | 要支援2・要介護1〜5 |
| 配管 | 5万円 | 要支援2・要介護1〜5 |
| シャワー水栓 | 5万円 | 要支援2・要介護1〜5 |
| 給水栓取替え | 5万円 | 要支援2・要介護1〜5 |

1住宅あたりの総限度額は **20万円**。上限まで達していなければ、複数回申請可能です。

## 4. 申請の流れ

<Checklist items={["1. ケアマネジャー・施工業者と改修内容を協議", "2. 工事着工前に市へ事前申請（書類一式提出）", "3. 市が審査・補助決定通知書を送付", "4. 工事実施", "5. 工事完成後30日以内に事後申請（領収書原本等提出）", "6. 補助金の交付"]} />

### 事前申請の主な書類

- 補助金等交付申請書
- 同意書兼誓約書（税資料閲覧用）
- 住宅改修が必要な理由書
- 見積書・カタログ
- 図面（平面図・立面図）
- 施工前写真

詳細な書類様式は宮崎市公式ページからダウンロードできます。
