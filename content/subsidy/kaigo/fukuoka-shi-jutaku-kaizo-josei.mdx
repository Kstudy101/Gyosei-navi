福岡市の住宅改造助成とは、身体機能が低下した高齢者がいる世帯が住宅を高齢者向けに改造するとき、工事費の一部を市が助成する独自制度です。介護保険の住宅改修費給付とは別立てで運用されています。

<SubsidyInfoCard />

## この記事の結論

- 助成上限は**30万円**。介護保険料段階に応じた助成率（**10〜100％**）を乗じて支給額が決まる
- **介護保険の住宅改修対象工事は原則対象外**。対象にする場合でも本助成では**10万円が限度**
- **着工前の事前申請**が必須で、原則**1世帯1回**

## 1. 対象者・支給条件

次のすべてに該当する人、またはその人が属する世帯の生計中心者が対象です。

- 福岡市内に居住する**65歳以上**の高齢者
- 介護保険で**要支援1・2**または**要介護1〜5**の認定を受けていること
- 介護保険第1号被保険者保険料の所得段階が**第1段階〜第8段階**であること

第9段階以上（本人が市民税課税で所得300万円以上）は助成対象外です。

## 2. 対象工事

高齢者の自立を助け、または介護者の負担を減らす工事が対象です。訪問調査のうえ、身体状況に応じて必要な工事が選ばれます。

| 改造箇所 | 内容の例 |
|---|---|
| 玄関・廊下 | 拡幅 |
| 居室 | 間仕切りの変更・撤去 |
| 階段 | 階段昇降機（リフト） |
| 浴室 | 浴槽の取替、浴室の拡張（介護者が入れない場合等） |
| 便所 | 温水洗浄便座（排泄処理が不可能な場合のみ） |
| 洗面所 | 車椅子対応洗面台 |
| 屋外 | 通路整備、屋外手すり（屋内手すりは介護保険） |
| その他 | 水栓の変更 |

段差解消目的の浴槽取替、通路整備、屋外手すりなど（公式ページの★印）は、介護保険の利用が優先されます。介護保険住宅改修費の給付対象工事は、原則として本助成の対象外です。

## 3. 支給額・計算方法

支給額は「工事に要した額」と「助成上限額30万円」のうち低い方に、次の助成率を掛けた額です。

| 介護保険料段階 | 階層の目安 | 助成率 |
|---|---|---|
| 第1段階【A】 | 生活保護受給者、市民税世帯非課税の老齢福祉年金受給者など | 100％ |
| 第1段階【B】 | 市民税世帯非課税 | 90％ |
| 第2・3段階 | 市民税世帯非課税 | 90％ |
| 第4・5段階 | 本人が市民税非課税 | 60％ |
| 第6・7段階 | 本人が市民税課税で所得200万円未満 | 35％ |
| 第8段階 | 本人が市民税課税で所得200万円以上300万円未満 | 10％ |
| 第9〜15段階 | 本人が市民税課税で所得300万円以上 | 対象外 |

第1段階の【A】【B】は、この事業独自の区分です。介護保険住宅改修の対象工事を本助成で扱う場合は、**10万円が限度**になります。
