姫路市の在宅高齢者介護手当とは、要介護度の高い在宅高齢者を居宅で介護している親族に対し、市が月額10,500円を支給する制度です。所得制限はありません。介護保険の住宅改修費（全国共通）とは別の、姫路市独自の現金給付です。

<SubsidyInfoCard />

## この記事の結論

- 支給額は**月額10,500円**（所得制限なし）。認定後は**申請の翌月から**支給
- 介護を受ける側は**満65歳以上・要介護3〜5**で、**6ヶ月以上ねたきり**（または問題行動のある認知症）。**重度障害者（児）介護手当**の対象者は除く
- 申請者（介護する側）は**市内住所・同居・扶養義務のある親族**で、**現に介護**し**介護報酬を受けていない**こと
- 通所系サービスの合計利用が**平均して月16日以上**だと対象外
- 申請は**郵送または持参**（メール・ファクス不可）

## 1. 対象者・支給条件

支給を受けるには、**在宅高齢者側**と**介護する方（申請者）側**の両方の要件を満たす必要があります。概要PDFおよび申請書に整理されています。

### 在宅高齢者の要件

次のすべてを満たす方が対象です。

| 区分 | 内容 |
|---|---|
| 年齢・他手当 | **満65歳以上**で、**重度障害者（児）介護手当**の対象となっていないこと |
| 要介護度 | 介護保険の要介護認定で**要介護3〜5** |
| 状態 | **6ヶ月以上ねたきり**（要介護2以下から要介護3以上になった場合は、要介護3以上となってから**6ヶ月間の経過が必要**）、または**問題行動のある認知症** |
| 通所系サービス | デイサービス、ショートステイ、デイケア、（看護）小規模多機能型居宅介護等の通所系サービスの合計利用日数が、**平均して月に16日以上**の場合は対象外（利用実績を基に平均） |

詳細は高齢者支援課へ問い合わせるよう案内されています。

### 介護する方（申請者）の要件

| 区分 | 内容 |
|---|---|
| 住所 | **姫路市内に住所**があること |
| 同居 | 対象の在宅高齢者と**同居**していること |
| 続柄 | **民法第877条**により扶養義務のある親族であること |
| 実態 | **現に介護**していること |
| 報酬 | **介護報酬を受けていない**こと |

振込先口座は、申請者（介護する方）名義の口座です。

## 2. 支給額

| 項目 | 内容 |
|---|---|
| 支給額 | **月額10,500円** |
| 所得制限 | **なし** |
| 支給開始 | **申請の翌月**から |

審査結果は申請日の翌月にハガキで通知されます。

## 3. 申請方法・必要書類

公式ページでは、申込先へ**郵送または持参**するよう案内されています。**メール・ファクスでは受け付けていません**。

| 項目 | 内容 |
|---|---|
| 必要書類 | 申請用紙、手当振込先となる**申請者名義口座の通帳コピー**（口座番号等の記載ページ） |
| 様式 | 公式ページに申請書PDF・喪失届PDFを掲載 |
| 受付場所 | 高齢者支援課のほか、支所・家島事務所・駅前市役所・出張所・サービスセンター・保健福祉サービスセンター |

申請書PDFの表題には「郵送のみ」とある一方、公式ページ本文と概要PDFは「郵送または持参」と書いています。持参可否の最新運用は窓口で確認してください。

## 4. 受給資格の喪失

次のいずれかに該当する場合は受給資格を失います。該当が確実になった時点で**喪失届**を提出します。手続きが遅れると返還金が発生することがあります。

- **3ヶ月を超えて**病院または老人保健施設に入院（入所）した場合
- **月の半分を超える日数**において介護保険の通所サービスを利用し、かつ今後もその利用状況が見込まれる場合
- **老人ホームに入所**した場合
- その他、支給要件に該当しなくなった場合（概要PDF）

## 5. 他自治体の類似制度との違い

長崎市・那覇市・世田谷区などの家族介護慰労金は、**年額・要介護4/5・市民税非課税・介護保険サービス原則未利用**という型が多いです。姫路市の在宅高齢者介護手当は次の点で異なります。

- **月額10,500円**の定額（年額一括ではない）
- **所得制限なし**
- 要介護度は**要介護3〜5**まで含む
- 通所系は一律禁止ではなく、**平均月16日未満**なら申請の余地がある

同じ現金給付でも、判定の軸が「サービス未利用・非課税」型ではなく「同居親族による在宅介護＋通所日数」型です。
