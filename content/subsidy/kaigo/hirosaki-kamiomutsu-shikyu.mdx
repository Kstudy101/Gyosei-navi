弘前市の「ねたきり高齢者等への紙おむつ支給」は、在宅で生活する寝たきり高齢者などへ、紙おむつまたは尿とりパッドを年3回自宅へ配送する**現物支給**の市独自事業です。現金の購入費助成ではなく、業者が指定住所（弘前市内に限る）へ直接届けます。

<SubsidyInfoCard />

## この記事の結論

- **年3回**（4月・8月・12月）に自宅配送。1回あたり**テープ止めタイプ134枚**または**尿とりパッド320枚**のいずれか一方
- 対象は在宅の寝たきり高齢者などで、**住民税課税世帯・生活保護受給世帯・施設入所者・長期入院者は対象外**
- 申請は随時。申請者は主に介護している親族。窓口は介護福祉課または岩木・相馬総合支所の民生課

## 1. 対象者・支給条件

市内に住所があり、在宅（自宅）で生活する方のうち、次のいずれかに当てはまる場合が対象です。

| 区分 | 要件 |
|---|---|
| 寝たきり（高齢） | 満65歳以上の寝たきりの方 |
| 認知症による常時失禁 | 満65歳以上で、要介護4・5に相当する認知症により常時失禁状態にある方 |
| 身体障害 | 身体障害者手帳1級または2級の交付を受けている寝たきりの方 |
| 知的障害 | 療育（愛護）手帳Aの交付を受けている寝たきりの方 |

次に該当する場合は対象になりません（申請ページの記載）。

- 住民税課税世帯
- 生活保護受給世帯
- 施設入所者
- 長期入院者

介護保健福祉ガイドブック（令和8年6月作成）でも、住民税課税世帯と生活保護受給世帯は対象外と明記されています。施設入所・長期入院の除外は申請ページ側で確認できます。

## 2. 支給内容

現金ではなく、紙おむつ・パッドそのものが届く仕組みです。

| 項目 | 内容 |
|---|---|
| 回数 | 年3回（4月・8月・12月） |
| 配送 | 指定住所へ業者が直接配送（**弘前市内に限る**） |
| 選べる品目（いずれか一つ） | テープ止めタイプ紙おむつM / テープ止めタイプ紙おむつL / 尿とりパッド |
| 1回あたりの枚数 | テープ止めタイプ **134枚**、尿とりパッド **320枚** |
| 手数料 | 無料 |

品目は毎回「一つ」を選ぶ形式です。MとLの両方や、おむつとパッドの同時選択は案内されていません。

## 3. 申請方法

| 項目 | 内容 |
|---|---|
| 申請時期 | 随時 |
| 申請者 | 親族（主に介護している方）。代理提出は支給対象者の身体状況がわかる人 |
| 提出方法 | 申請書を受付窓口へ持参 |
| 添付書類 | 身体障害者手帳、療育（愛護）手帳A（該当する場合） |
| 受付窓口 | 弘前市役所 介護福祉課／岩木総合支所 民生課／相馬総合支所 民生課 |
| 受付時間 | 午前8時30分〜午後5時（土日祝・年末年始を除く） |
| 問い合わせ | 介護福祉課 高齢福祉係（電話 0172-40-7114） |

申請書と記入例は市公式サイトの申請ページからPDFでダウンロードできます。印刷はA4（感熱紙不可）と案内されています。

郵送での提出可否は、申請ページ本文に明記がありません。窓口持参が基本案内なので、郵送を希望する場合は高齢福祉係へ事前確認してください。

## 4. 近くにある関連制度（別制度）

同じ「お年寄りの福祉」「介護保険以外の在宅サービス」の案内には、紙おむつ以外にも次の市事業が載っています（詳細は各原文・ガイドブックを確認）。

- **家族介護慰労金支給事業**: 在宅で中重度の要介護者を日常的に介護する家族へ、条件を満たせば年額10万円
- **緊急通報システム事業**: 緊急時通報用のシステム・ペンダントを貸与（利用料あり。生活保護世帯は無料）
- **はり・きゅう・マッサージ施術料助成**: 満65歳以上向け受療券（1枚500円×5枚、年度内1回）

本記事は紙おむつ支給に限定しています。家族介護慰労金や緊急通報を検討する場合は、介護福祉課の該当係へ直接確認してください。

## 5. 注意点・確認事項

- 本制度は国の介護保険給付（福祉用具など）とは別の、弘前市の独自事業です
- 「必ず支給される」「誰でも受け取れる」といった制度ではありません。課税状況や在宅要件を市が確認したうえで決まります
- 支給枚数・配送月・対象外条件は令和8年6月作成のガイドブックおよび2026年9月22日時点の申請ページに基づきます。内容は改定され得るため、申請前に最新の公式案内を確認してください
