函館市の「家族介護用品給付事業」は、在宅の要介護高齢者等を介護する家族へ、紙おむつなどの介護用品と引き換えできる**利用券**を交付する市の事業です。現金の購入費助成ではなく、登録事業者の店舗で利用券と商品を交換する仕組みです。

<SubsidyInfoCard />

## この記事の結論

- **月額5,000円上限**の利用券。超過分は自己負担
- 対象品目は**紙おむつ・尿取りパッド・お尻拭き・使い捨て手袋**
- 要介護3〜5の方を在宅介護する**市民税非課税世帯**の家族向け。入院・施設入所や要介護者の生活保護受給は対象外
- 申請は郵送または高齢福祉課・各支所。決定までおおむね2週間程度

## 1. 対象者・支給条件

市公式の案内ページ・ちらしでは、次の要件を**すべて**満たす家族が対象とされています。

| 区分 | 要件 |
|---|---|
| 住所 | 申請する家族および要介護者が函館市に住所を有すること |
| 所得（家族） | 申請家族およびその配偶者が市民税非課税世帯であること |
| 所得（要介護者） | 要介護者およびその配偶者が市民税非課税世帯であること |
| 扶養 | 申請家族および要介護者が、市町村民税課税者の税法上の扶養親族等ではないこと |
| 要介護度 | 要介護者が要介護3・4・5で、かつ介護用品（オムツ等）が必要な状態であること |
| 生活場所 | 在宅で介護していること（入院・施設入所は対象外） |
| 生活保護 | 要介護者が生活保護受給者でないこと |

実施要綱では、介護用品使用者側にも市民税非課税・配偶者非課税・生活保護除外などの要件が整理されています。課税状況の参照年度は申請日の属する年度分で、4月・5月申請は前年度分とする旨も要綱にあります。

「介護用品が必要な状態」の判定は、要介護4以上は必要性ありとみなし、要介護3の場合は認定調査票の排尿・排便項目（全介助・一部介助・見守り等）などを用いると要綱に定められています。個別判断の詳細は高齢福祉課へ確認してください。

## 2. 支給内容

| 項目 | 内容 |
|---|---|
| 給付形態 | 登録事業者で介護用品と引き換えできる**利用券** |
| 上限額 | **月額5,000円**（超過分は自己負担） |
| 対象品目 | 紙おむつ／尿取りパッド／お尻拭き／使い捨て手袋 |
| 対象外の例 | 防水シーツなど床や布団に敷くもの（対象商品案内） |
| 利用回数 | 一月に1枚・1回のみ。おつりや翌月への繰越しは不可 |
| 初月分 | ピンク色の利用券は初月または翌月のいずれかで使用可（対応マニュアル） |

商品名の指定はなく、上記品目に該当するかはパッケージ表示等で判断すると事業者向けマニュアルにあります。登録事業者一覧（令和8年5月時点のPDF）は市公式ページから確認できます。

利用券は利用者（介護している家族）本人のみが使用でき、代理人への預け・代理使用はできないと案内されています。介護者に同行して購入する場合は問題ないとされています。

## 3. 申請方法

| 項目 | 内容 |
|---|---|
| 書類 | 家族介護用品給付申請書（別記第2号様式） |
| 提出 | 郵送、または市役所2階 高齢福祉課窓口・各支所 |
| 郵送先 | 〒040-8666 函館市東雲町4番13号 函館市保健福祉部高齢福祉課 |
| 審査 | 申請後、介護状況等の聞き取りのため市から電話 |
| 通知 | 申請からおおむね2週間程度で決定通知または却下通知 |
| 給付期間 | 申請月から同一年度内の3月まで（3月申請は15日まで・要綱） |
| 問い合わせ | 高齢福祉課 家族介護支援・認知症担当（電話 0138-21-3081／Eメール kazoku-kaigo@city.hakodate.hokkaido.jp） |

申請書・廃止届・対象商品案内・事業の流れのPDFは、[介護者を支えるサービス](https://www.city.hakodate.hokkaido.jp/docs/2014030500049/)のページから入手できます。転入などで市が要介護認定資料や課税状況を持っていない場合は、申請者側が前住地から資料を取得して提出する必要があると要綱にあります。

## 4. 近くにある関連制度（別制度）

同じ「介護者を支えるサービス」案内には、家族介護用品以外にも次の市事業が載っています（詳細は各原文を確認）。

- **家族介護慰労事業**: 条件を満たす家族へ慰労金**10万円**を支給
- **家族介護者交流事業**: 日帰り交流（利用料無料）
- **家族介護者のための相談窓口**: 家族介護支援員による相談（無料）
- **介護マーク**の配付

本記事は家族介護用品給付事業に限定しています。慰労金や相談窓口を検討する場合は、同じ担当（家族介護支援・認知症担当）へ確認してください。

## 5. 注意点・確認事項

- 国の介護保険給付（特定福祉用具販売など）とは別の、函館市の事業です
- 「必ず給付される」「誰でも受け取れる」制度ではありません。要件確認と聞き取りのうえ市が可否を判断します
- 利用券の限度額に満たない購入でもおつりは出ず、翌月への繰越しもできません
- ちらし・対象商品PDFのファイル名に「R6」が残っているものがあります。申請前に公式ページの最新資料を確認してください
- 要件・上限額・取扱事業者は改定され得るため、最新の公式案内を優先してください
