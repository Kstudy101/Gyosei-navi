川口市のねたきり高齢者等紙おむつ支給事業とは、在宅で常時おむつを必要とする高齢者・障害者等に対し、市が指定カタログから選んだ紙おむつを毎月1種類支給する制度です。自己負担は種類に関わらず月1,300円で、配送時に業者へ支払います。

<SubsidyInfoCard />

## この記事の結論

- 支給は**カタログから1種類**を選択する現物支給（現金給付ではない）
- 自己負担は**月1,300円一律**（配送時に配送業者へ支払い）
- おおむね65歳以上の場合は**本人が市県民税非課税**であることが必須（令和3年4月以降）
- 申請は配送**前月末まで**、配送は**翌月10日〜月末**（原則市内）

## 1. 対象者・支給条件

川口市内に住所があり、常時おむつを使用している次のいずれかに該当する方が対象です（概要PDF）。

| 区分 | 内容 |
|---|---|
| (1) 高齢者 | おおむね65歳以上で常時臥床または認知症等で失禁状態にあり、**本人が市県民税非課税**である者 |
| (2) 身体障害者 | 18歳以上で身体障害者手帳の交付を受け、常時臥床の状態にある者 |
| (3) 知的障害者 | 18歳以上で療育手帳の交付を受け、常時臥床の状態にある者 |
| (4) その他 | 上記のほか、特に市長が必要と認めた者 |

### 対象外となる施設入所者

次の施設に入所している方は対象外です。

- 養護老人ホーム、特別養護老人ホーム
- 救護施設
- 障害者支援施設
- 介護老人福祉施設、介護老人保健施設、介護療養型医療施設
- 地域密着型介護老人福祉施設

### 市県民税非課税要件の追加（令和3年4月〜）

厚生労働省通知に基づき、令和3年4月1日から支給要件が変更され、おおむね65歳以上の区分では**本人が市県民税非課税であること**が追加されました。課税されている方は対象外です。

## 2. 支給内容・自己負担

| 項目 | 内容 |
|---|---|
| 支給品 | 令和8年度カタログの中から希望のものを**1種類のみ** |
| 自己負担 | **月1,300円**（種類問わず一律） |
| 支払方法 | 配送時に、配送業者へ直接支払い |
| 配送時期 | 配送前月末までに申請した分を、**翌月10日〜月末**に配送 |
| 配送範囲 | 原則市内のみ |
| 継続配送 | 変更・一時中断の連絡が無い場合は、前月と同じ商品を配送 |

配送日・配送時間の指定はできません。一度配送した商品の返品・交換にも応じられません。一時中断から1年以上経過した再開は、改めて申請書の提出が必要です。

## 3. 申請方法・必要書類

申請先は長寿支援課（障害福祉関連は障害福祉課も案内あり）です。窓口提出のほか、郵送・ファックス・LoGoフォームでも受け付けています。
