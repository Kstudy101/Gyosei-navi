下関市の介護用品支給事業とは、介護を必要とする在宅の高齢者を常時介護している家族などに対し、紙おむつ等の介護用品を登録事業者が自宅へ配達し、その費用の一部を市が助成する制度です。介護保険の住宅改修とは別の、市独自の在宅支援です。

<SubsidyInfoCard />

## この記事の結論

- **要介護3・4・5**の在宅高齢者を、**同居または同一敷地内**で常時介護する**住民税非課税世帯**の介護者が対象
- 支給品は**紙おむつ・尿取りパッド・手袋・お尻拭きシート**
- 費用は**1期（2カ月）あたり1万円が限度**。市が**9割助成**、自己負担は**1割**
- 申請は**長寿支援課**へ（郵送可）。利用希望の**登録事業者**を申請時に選ぶ

## 1. 対象者・支給条件

公式ページによると、次の(1)〜(4)の**いずれも**満たす65歳以上の高齢者と、同居または同一敷地内に居住して常時介護している**住民税非課税世帯**の方が対象です。

| 区分 | 内容 |
|---|---|
| (1) 居住・生活形態 | 市内に住所を有し、**在宅**で生活していること |
| (2) 要介護度 | 要介護認定の結果が**要介護3・4または5** |
| (3) 生活保護 | 生活保護法第6条第1項の被保護者**でない**こと |
| (4) 所得 | **住民税非課税世帯**に属していること |

実施要綱では、申請者である介護者にも住民税非課税世帯であることと市内住所が求められます。住民税の判定基準日は申請書受理日で、4月1日〜6月30日の申請は前年度、7月1日〜3月31日の申請は当該年度の課税状況によります。

### 対象外となる場合

公式ページでは次が対象外とされています。

- **入院中**の方
- **有料老人ホーム・ケアハウス・グループホーム等**に入居・入所されている方

利用開始後に入院・入所・死亡などで要件を欠いた場合は、実施要綱に基づき登録事業者への通知と廃止届が必要です。

## 2. 支給内容・自己負担

| 項目 | 内容 |
|---|---|
| 支給品 | 紙おむつ、尿取りパッド、手袋、お尻拭きシート |
| 費用限度 | 要介護高齢者1人につき**1期あたり1万円** |
| 市の助成 | 限度額の範囲内で費用の**9割**（1円未満切り捨て） |
| 自己負担 | 費用と助成額の差額（**1割**）。登録事業者へ支払い |
| 期の単位 | 4月から2カ月ごと（1期=4・5月 … 6期=2・3月） |
| 配達 | 登録事業者へ直接注文し、自宅へ配達 |

現金の給付ではなく、登録事業者が用品を配達し、市が事業者へ助成額を支払う仕組みです。限度額を超える利用分の扱いは公式ページ本文に詳細がないため、長寿支援課または登録事業者に確認してください。

## 3. 申請方法・必要書類

所定の申請書を**長寿支援課**へ提出します（**郵送可**）。ページ下部から申請書・実施要綱・配達可能地域一覧表をダウンロードできます。

実施要綱では、介護者および要介護高齢者が属する世帯全員の直近の住民税課税状況を証する書類の提出が求められます。課税状況の確認に同意する書類を出せば、この提出は不要になる場合があります。

申請書記入の際に、**利用を希望する登録事業者を決める**必要があります。登録事業者と配達可能地域は「介護用品支給事業配達可能地域一覧表」で確認してください。
