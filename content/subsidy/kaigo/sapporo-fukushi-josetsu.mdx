札幌市の福祉除雪事業とは、自力で除雪することが困難な高齢者や障がいのある方の世帯に対し、地域協力員が自宅出入口から玄関先までの通路を除雪する制度です。現金を支給する助成金ではなく、除雪作業そのものを提供する「現物給付型」の制度で、積雪地域である札幌市ならではの冬季生活支援策です。利用には課税状況に応じた少額の負担金（5,000円〜10,000円、生活保護世帯は無料）がかかります。

## この記事の結論

- 令和8年度（2026年度）の**申込期間は8月12日（水）〜9月14日（月）ですでに終了**。相当な理由がある場合のみ区社会福祉協議会への相談で個別対応の余地がある
- 除雪の対象は**出入口幅約1.5m・敷地内通路約80cm**の1か所のみで、車庫やロードヒーティング部分・排雪は対象外
- 利用者負担金は一冬あたり**市民税非課税世帯5,000円／課税世帯10,000円／生活保護世帯は無料**

## 1. 対象者・支給条件

対象となるのは、次の3つの条件をすべて満たす世帯です。

1. 道路に面している一戸建て住宅に居住している（入院中・施設入所中は対象外）
2. おおむね500m以内に、除雪を援助できる子または子の配偶者が居住していない
3. 世帯全員が、以下の5つの類型のいずれかに該当し、自力での除雪が困難と認められる

| 類型 | 内容 |
|---|---|
| (1) | 要介護1以上、または重度（1・2級）の身体障がいのある方だけで構成される世帯 |
| (2) | 要支援1・2で介護保険サービスを継続利用している方だけで構成される世帯 |
| (3) | 介護保険の認定は受けていないが、介護予防・生活支援サービス事業を継続利用している方だけで構成される世帯 |
| (4) | (1)に該当する方を専ら介護し、除雪が困難と認められる70歳以上の方だけで構成される世帯 |
| (5) | 市社会福祉協議会が特に認める世帯（重度の知的・精神障がい、中度の肢体不自由など個別事情を診断書等で判断） |

二世帯住宅などで道路に面した出入口部分を共有している場合は、1つの世帯とみなされます。なお、前年度（令和7年度）に利用していて要件に変更がない世帯は、令和8年度の新しい要件に該当しなくても引き続き利用できる経過措置があります。

## 2. 除雪の内容・実施期間

除雪してもらえる範囲は限定されています。

| 項目 | 内容 |
|---|---|
| 出入口 | 道路に面した出入口、幅おおむね1.5m |
| 敷地内通路 | 出入口から玄関先までの通路部分、歩行に支障のない程度（目安約80cm） |
| 対象箇所数 | 出入口部分1か所のみ |
| 対象外 | 車庫前、ロードヒーティング使用部分 |
| 排雪 | 行わない（除雪した雪は敷地内に堆積） |
| 実施日・時間 | 道路の新雪除雪が行われた日に1日1回。時間指定は不可で、正午ごろまでに実施（大雪等では遅れる場合あり） |
| 実施期間 | 令和8年12月1日（火）〜令和9年3月20日（土） |

## 3. 利用者負担金

負担金は世帯の課税状況に応じて一冬あたりの定額です。

| 世帯区分 | 負担金（一冬あたり） |
|---|---|
| 市民税非課税世帯 | 5,000円 |
| 市民税課税世帯 | 10,000円 |
| 生活保護世帯 | 無料 |

## 4. 申込方法・申込期間

令和8年度の申込期間は**令和8年8月12日（水）〜9月14日（月）**でした。この記事の作成時点（原文取得日：2026年9月20日）では、すでに申込期間が終了しています。

申込期間を過ぎてからの受付は原則行っていませんが、次のような相当な理由があり期間中に申し込めなかった場合は、お住まいの区の社会福祉協議会へ早めに相談すると個別に対応してもらえることがあります。

- 申込期間中に入院していた
- 申込期間後に一戸建て住宅へ転居した、または他市・他区から一戸建て住宅に転入した
- 申込期間後に世帯構成や身体状況に変化があった

決定または非該当の通知は11月中旬以降に届きます。通知にあたり、除雪が自力で可能かどうかや近隣に子等が居住していないかについて、民生委員・児童委員や区社会福祉協議会職員が確認に訪れる場合もあります。地域協力員の調整が難しい地域では、申し込んでも利用できないことがあります。

令和9年度（2027年度）以降の申込スケジュールは、記事作成時点で公式発表がなく未確認です。令和8年度は8月中旬（8月12日）から申込期間が始まりましたが、これが今後も同時期に繰り返される保証はありません（※編集部の推測です）。利用を検討する場合は札幌市または各区社会福祉協議会の最新の案内を確認してください。

## 5. 制度を支える地域協力員について

福祉除雪は、近隣住民や企業・団体などの「地域協力員」がボランティア的に除雪を担う仕組みで成り立っています。令和8年度からは、この地域協力員に支払われる活動費が1世帯あたり21,000円から23,000円に増額されました。この活動費は制度の運営を支える協力員側への支払いであり、利用者（除雪を受ける世帯）が直接受け取る給付金ではない点に注意してください。
