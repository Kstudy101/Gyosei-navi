静岡市の高齢者紙おむつ支給制度とは、在宅高齢者の生活確保と介護者の負担軽減のため、高齢者紙おむつ引換券を支給する市独自の制度です。現金給付ではなく、静岡薬業組合加盟店（薬局等）で紙おむつと引き換える仕組みです。

<SubsidyInfoCard />

## この記事の結論

- 支給は**紙おむつ引換券**で、月額は要介護度により**1,500円分〜6,500円分**
- 対象の基本は**要介護4以上**。要介護1〜3は認定調査票の要件を満たせば対象（**窓口で判定**）
- 窓口申請は**2027年3月31日**まで、電子申請は**2027年2月28日**まで

## 1. 対象者・支給条件

次の条件を**すべて**満たす方が対象です。

| 区分 | 内容 |
|---|---|
| 居住・生活 | 月の半分以上を自宅で生活している65歳以上で、紙おむつを必要とする方 |
| 施設 | 有料老人ホーム、グループホーム、サービス付き高齢者向け住宅、養護老人ホーム、軽費老人ホーム、特別養護老人ホーム等に入所中の方は対象外 |
| 要介護度 | **要介護4以上**の認定を受けた方。要介護1〜3の方は、要介護認定調査票の要件を満たしていれば対象（窓口で確認・判定） |
| 所得 | 生活保護世帯、またはすべての世帯員が市民税非課税である世帯に属する方 |
| 他制度 | 各区の障害者支援課で紙おむつ券を受給していない方 |

2021年3月31日時点で既に紙おむつ引換券を支給されている方には、従来の判定基準が適用されます。詳細は窓口で確認してください。

要介護1〜3の認定調査票でどの項目が要件になるかなど、公式ページにない細部は本記事では断定しません。該当の有無は、お住まいの区の高齢介護課（または蒲原出張所）で確認してください。

## 2. 支給額・計算方法

支給は現金ではなく、**紙おむつ引換券**です。要介護度ごとの月額は次のとおりです。

| 要介護度 | 月額（引換券） |
|---|---|
| 要介護1・要介護2 | 1,500円分 |
| 要介護3 | 5,500円分 |
| 要介護4 | 6,000円分 |
| 要介護5 | 6,500円分 |

静岡薬業組合加盟店（薬局等）で、本人に合った紙おむつと引き換えます。交換できる品目は次のとおりです。

- 大人用紙おむつ
- 大人用パンツ型紙おむつ
- 尿取りパッド

いずれも「**医療費控除**」と表示があるものに限ります。上記以外の商品には使えません。配達の可否や配達料の有無は、各取扱店への確認が必要です。

令和8年度の取扱店名簿（2026年7月31日時点）は市の公式ページで公開されています。引換券の**利用期限は令和9年3月31日**です。

## 3. 申請方法・必要書類

サービス利用を希望する方、または既に利用決定を受けておむつ券の継続受取を希望する方は、窓口または電子申請（LoGoフォーム）で申し込みます。

### 申請期限と受付開始日

| 区分 | 期限・開始日 |
|---|---|
| 窓口申請の期限 | 2027年3月31日まで |
| 電子申請の期限 | 2027年2月28日まで（3月1日以降は窓口） |
| 4月〜6月分の受付開始 | 2026年4月1日 |
| 7月〜9月分の受付開始 | 2026年7月1日 |
| 10月〜12月分の受付開始 | 2026年10月1日 |
| 1月〜3月分の受付開始 | 窓口は2026年1月4日、電子は2026年1月1日 |

なお、2021年3月31日までに支給決定され、かつ介護度1・2の方の継続申請は「身体状況等確認リスト」の結果によって決定するため、**電子申請はできません**。窓口での手続きが必要です。
