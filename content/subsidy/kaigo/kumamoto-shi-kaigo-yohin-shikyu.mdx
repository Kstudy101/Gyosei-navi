熊本市の高齢者介護用品支給事業とは、在宅の重度要介護高齢者の福祉を支えるため、紙おむつなどの介護用品を市が現物で支給する独自制度です。支給の上限は月額6,250円で、現金での支給や補助はありません。

<SubsidyInfoCard />

## この記事の結論

- 支給は**月額上限6,250円の現物**（紙おむつ等10種類）。現金給付はない
- 対象は**要介護4または5**、本人・介護家族とも**市民税非課税**、かつ**在宅**
- 相談は**ささえりあ**またはケアマネジャー、申請提出は**各区役所福祉課**

## 1. 対象者・支給条件

実施要綱第2条および市コールセンターFAQによると、次の条件を満たす必要があります。

| 区分 | 内容 |
|---|---|
| 本人の居住 | 熊本市内に居住し、住民基本台帳に記録されていること |
| 要介護度 | 要介護4または要介護5の認定を受けていること |
| 介護家族 | 現に介護を行っている家族が市内に居住し、住民基本台帳に記録されていること |
| 税要件 | 本人および介護家族が属する世帯の市町村民税が非課税であること |
| 生活の場 | 在宅であること（入院・施設入所時は対象外となり得る） |

FAQでは、40歳以上65歳未満で特定疾病に該当する方も対象に含まれると案内されています。配達先は熊本市内に限られます。

## 2. 支給額・品目・受け取り方

| 項目 | 内容 |
|---|---|
| 支給上限 | 月額6,250円 |
| 支給方法 | 現物支給（現金での支給・補助なし） |
| 対象品目 | 紙おむつ等10種類 |
| 配送 | 原則として2か月分を一括配送 |
| 支給単位 | 1か月単位 |

令和8年度の事業者募集ページでも、市が指定する10種類の品物を取り扱う事業者を対象に公募していることが確認できます。自己負担額の有無は実施要綱・仕様書に定額負担の記載がないため、ここでは断定しません。最新の取扱いは高齢福祉課で確認してください。

同市内の補聴器購入費助成（上限3万円）とは別制度です。紙おむつ等の現物支援を探す場合は本事業、難聴高齢者の補聴器購入を探す場合は補聴器助成を参照してください。

## 3. 申請の流れ

1. 近くのささえりあ（熊本市高齢者支援センター）または担当ケアマネジャーに相談する
2. 必要書類を整え、各区役所福祉課（高齢福祉班）へ申請する
3. 市が審査し、支給を決定する（有効期間は決定日から1年）
4. 登録事業者から紙おむつ等が居宅へ配送される（原則2か月分一括）

継続する場合は更新申請が必要です。転居、施設入所、3か月以上の入院、世帯の課税化、要介護度の変更などがあった場合は資格を失うことがあり、入院・入所時は高齢福祉課への連絡と、場合により廃止届の提出が求められます。
