文京区の高齢者おむつ支給・費用助成とは、常時紙おむつを必要とする高齢者等を対象に、区が実物の紙おむつを配送する「現物支給事業」と、入院・入所先が指定するおむつの購入費を助成する「費用助成事業」を組み合わせて実施する制度です。どちらの制度も対象要件はほぼ共通しており、紙おむつを現物で受け取れる環境かどうかで利用する制度が分かれます。

<SubsidyInfoCard />

## この記事の結論

- 対象は文京区内在住で、**要介護3以上**に認定され常時おむつを使用している人、または**満65歳以上で医療保険入院中**の人（令和7年4月1日より40歳以上＋医師の意見書でも対象）
- **現物支給**は31種類の紙おむつから**45点まで**（下限20点）を月1回配送、費用負担は月額**500円**（生活保護世帯は免除）
- **費用助成**は入院・入所中のおむつ代を**月上限4,000円**まで助成。同一月に現物支給と費用助成の**併用は不可**

## 1. 対象者・支給条件

文京区内に住所を有する人で、次のいずれかに該当する場合が対象です。

<Checklist items={["介護保険で原則要介護3以上に認定され、常時おむつを使用している", "紙おむつの持込ができる病院に医療保険により入院し、常時おむつを使用している満65歳以上である"]} />

令和7年4月1日より、上記2つの要件に該当しない40歳以上の人も、所定の「医師の意見書」を提出することで対象になります。既に要介護3以上で支給を受けている人が要介護2以下になった場合は、医師の意見書の提出は不要です。

次に該当する人は対象外です。

- 特別養護老人ホーム、介護老人保健施設、介護医療院、介護療養型医療施設に入所している人
- 文京区心身障害者紙おむつ支給事業によりおむつ支給を受けている人
- 身体障害者手帳または愛の手帳をお持ちの64歳以下の人

紙おむつの持込ができない病院や有料老人ホーム・グループホーム等に入院・入所している場合は、現物支給ではなく費用助成の対象になります。

## 2. 支給額・計算方法

### 高齢者紙おむつ現物支給事業（現物給付型）

| 項目 | 内容 |
|---|---|
| 支給内容 | 31種類の紙おむつから45点まで組み合わせて選択（下限20点） |
| 配送 | 月1回、指定場所へ配送 |
| 費用負担 | 月額500円（生活保護世帯は免除） |
| 超過分の負担 | 45点を超えた分は1点につき100円 |
| 配送料 | 文京区内・都内（島しょ除く）の病院は無料／23区内500円／23区外900円 |

### 高齢者おむつ代費用助成事業（現金助成型）

| 項目 | 内容 |
|---|---|
| 対象費用 | 紙おむつの持込ができない病院・有料老人ホーム・グループホーム等での入院・入所中のおむつ代 |
| 助成上限 | 月あたり4,000円 |
| 助成開始 | 申請書を受理した月から（さかのぼっての助成は不可） |
| 振込時期 | 請求書類到着から概ね1か月後 |

同一月に現物支給と費用助成の両方を受けることはできません。また、費用助成の申請は年度ごとで、次年度も継続して入院・入所している場合は再度の申請が必要です。

## 3. 申請方法・必要書類

いずれの制度も、高齢福祉課窓口または最寄りの高齢者あんしん相談センター（地域包括支援センター）窓口、もしくは郵送で申請します。

<Checklist items={["高齢者紙おむつ支給申請書（現物支給）または高齢者おむつ費用助成申請書（費用助成）に記入する", "支給対象者の介護保険被保険者証（またはマイナンバーカード等の本人確認書類）を用意する", "支給対象者の認印を用意する", "要介護2以下の場合は所定の「医師の意見書」もあわせて提出する", "費用助成の場合、助成決定後は病院・施設等が発行する領収書（コピー可）を添えて請求する"]} />

必要書類や意見書の様式は、事前に高齢福祉課へ確認することをおすすめします。
