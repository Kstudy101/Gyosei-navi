広島市「地域猫活動支援事業」は、地域の理解と合意のもとで特定の飼い主がいない猫（地域猫）を適切に管理する町内会等の活動団体に対し、**不妊去勢手術の実施や捕獲器の貸し出し**などを行う市の支援です。現金で手術費の一部を振り込む定額助成ではなく、**現物支援型**として案内されており、円単位の現金助成額は公式ページ・実施要領に記載がありません。

<SubsidyInfoCard />

## この記事の結論

- 対象は**地域猫活動を行う町内会等の活動団体**。個人の飼い猫向け定額助成としては案内されていない
- 支援の中心は**不妊去勢手術の実施**と**捕獲器の貸し出し**（ほか助言・現地調査・ボランティア紹介など）
- **現金助成額の円表示は公式になし**
- 令和7年度から、手術支援の承認期間は**申請年度の3月31日まで**

## 1. 対象者・対象となる猫

実施要領では、活動団体を「地域猫活動を行う町内会等」、地域猫を「特定の飼い主がいない猫で、地域住民の認知と合意が得られ、適切に管理することでこれ以上数を増やさず一代限りの生を全うさせる猫」と定義しています。

| 項目 | 内容 |
|---|---|
| 申請者 | 活動団体の代表者（動物愛護センターへ申請） |
| 対象の猫 | 広島市内の地域猫（特定の飼い主がいない猫） |
| 個人・飼い猫 | 本制度の案内対象外（飼い猫向け定額助成の記載なし） |

案内ページでは、申請書類に問題がなければ**申請後1週間程度で承認**されるとされています。

<Callout type="warning">
飼い猫の室内飼育・不妊去勢・所有者明示・終生飼養は、制度説明ページで飼い主へのお願いとして呼びかけられていますが、それ自体が本支援の給付対象になるわけではありません。
</Callout>

## 2. 支援の内容（現物支援）

実施要領第4条に定める支援は次のとおりです。

| 区分 | 内容 |
|---|---|
| 合意形成・助言 | 地域猫活動の方法の助言、啓発資料の提供、現地調査への職員派遣、説明会の実施 |
| 手術・器材 | **地域猫の手術の実施**、**捕獲器の貸し出し** |
| 人材 | ボランティアの紹介 |
| その他 | センター長が必要と認める支援 |

**申請者へ支払う「1頭あたり○円」などの現金助成額は、案内ページ・実施要領のいずれにも記載がありません。** 自己負担の有無や市の負担単価は原文で確認できないため、断定せず窓口へ確認してください。

## 3. 手術の実施場所（令和7年度の整理）

実施要領第8条および制度説明ページの「令和7年度からの変更事項」によると、手術場所は次のように分かれます。

| 区分 | 手術場所 |
|---|---|
| 新規申請団体の申請猫・年度当初に申請した猫 | 市長が指定する動物病院 |
| 年度途中で追加した手術対象猫 | 動物愛護センター |
| 令和4年6月14日以前に申請があった町内会等 | 従来どおり動物愛護センター |

手術を行う動物病院が決まったら、病院と連絡して予約調整を行い、手術後は野良猫をもとの場所に戻して一代限りの見守り活動を行う流れが案内されています。

## 4. 承認期間・更新・報告

| 項目 | 内容 |
|---|---|
| 承認期間 | 承認日から**当該年度の3月31日まで**（令和7年度からの変更。変更前は3年間） |
| 翌年度分 | 翌年度に手術したい猫は**3月末日まで**に申請 |
| 途中追加 | 変更届と対象猫一覧で追加。追加猫の手術はセンター |
| 活動報告 | **翌年度5月末まで**に活動報告書を提出 |
| 完了・取下げ | 手術完了報告書／支援承認取下げ願 |
