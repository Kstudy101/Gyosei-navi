世田谷区は、「飼い猫」と「飼い主のいない猫」の両方を対象とした猫の不妊・去勢手術費補助制度を設けています。いずれも**手術前の事前申請が必須**ですが、飼い主のいない猫向けには「地域（町会・自治会等）への事前説明」という、他区にはない特有の要件があります。

## この記事の結論

- 世田谷区は**飼い猫**と**飼い主のいない猫**、どちらにも補助制度がある
- **どちらも手術前の事前申請が必須**（事後申請は補助不可）
- 補助額は飼い猫: 去勢**3,000円**・不妊**6,000円**、飼い主のいない猫: 去勢**10,000円**・不妊**20,000円**
- 飼い主のいない猫向けは**町会・自治会等への事前説明**が申請条件の一つ

## 1. 2つの制度の違い

| 項目 | 飼い猫向け | 飼い主のいない猫向け |
|---|---|---|
| 対象の猫 | 区民の飼い猫で、獣医師が手術可能と診断した猫 | 世田谷区内に生息する飼い主のいない猫 |
| 対象者 | 世田谷区民 | 世田谷区内在住で、区内の飼い主のいない猫の世話をしている方 |
| 補助額（去勢・オス） | **3,000円** | **10,000円** |
| 補助額（不妊・メス） | **6,000円** | **20,000円** |
| 特別要件 | なし | 猫が生息する地域の町会・自治会等の会長（または役職者）への事前説明が必要 |
| 識別措置 | なし | 不妊・去勢手術済みの識別措置（耳カット等）への同意が必要 |
| 申請タイミング | **手術前の事前申請が必須** | **手術前の事前申請が必須** |
| 申請から通知まで | 約2週間 | 約2週間 |
| 手術期限 | 交付決定から90日以内（年度末は3月31日まで） | 交付決定から90日以内（年度末は3月31日まで） |

## 2. 共通の補助の流れ

<Callout type="warning">
補助金は申請者の口座には振り込まれません。東京都獣医師会（世田谷支部）が代理受領する仕組みで、動物病院窓口で**補助額を差し引いた金額**を支払います。予算がなくなり次第、受付を締め切ります。

## 3. 飼い主のいない猫向けの特記事項

世田谷区の「飼い主のいない猫」向け制度には、他区と異なる要件があります。

**町会・自治会等への説明が必要**  
申請時に、猫が生息する地区の町会・自治会等の会長（または役職者）に、猫の存在と不妊去勢手術の取り組みについて事前に説明する必要があります。説明内容は申請書（副本）に記入します。会長等への説明が難しい場合は、周辺の複数の区民への説明で代替できる場合もあります。

**令和5年度以降: 譲渡が成立した猫向けの追加制度**  
飼い主のいない猫を不妊・去勢手術後に新たな飼い主に譲渡した場合、別途「新たな飼い主への引渡しが完了した飼い主のいない猫の不妊・去勢手術及び医療的処置費用補助」という上乗せ制度が利用できる場合があります。詳細は世田谷保健所にお問い合わせください。
