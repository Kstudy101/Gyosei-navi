神戸市の地域猫活動支援とは、神戸市人と猫との共生推進協議会が、地域猫活動団体などによる野良猫の捕獲・病院への搬入等を協議会の計画に基づいて行う場合に、不妊去勢手術費用を負担する仕組みです。個人の飼い猫向けの定額助成ではなく、地域でルールを決めて野良猫を適正管理するTNR（捕獲→不妊去勢→元の場所へ戻す）活動を支える制度です。

## この記事の結論

- 費用負担の主体は**神戸市人と猫との共生推進協議会**（2017年施行の「神戸市人と猫との共生に関する条例」に基づき設立）
- 対象は**地域猫活動団体などが、協議会の計画に基づいて野良猫の捕獲・病院搬入等を行う場合**
- 公式ページは「不妊去勢手術費用を負担」と案内するが、**円額・上限額の記載はない**
- 活動団体の登録条件は**活動地域の明確化・2名以上・自治会等の同意**。有効期間は**7月1日〜翌年6月30日**（毎年手続き）

## 1. 地域猫活動とは

公式ページによると、地域猫活動とは、地域の理解のもとで野良猫の不妊去勢手術を行い、地域住民などの有志が適正給餌・給水、ふん尿の管理など、その野良猫の管理を地域でルールを決めて適正に行う取り組みです。野良猫の数と地域の猫によるトラブルを減らすことを目的とし、神戸市も推進しています。

世話をする野良猫には不妊去勢手術を受けさせ、耳先にV字カットをしてもらうよう案内されています。V字カットがあれば、これ以上子猫を増やさない猫であることが一目でわかり、猫にとっても繰り返しの捕獲・手術を避けられます。

## 2. 対象・支援内容

| 項目 | 内容 |
|---|---|
| 実施主体 | 神戸市人と猫との共生推進協議会 |
| 支援内容 | 協議会が不妊去勢手術費用を負担 |
| 対象場面 | 地域猫活動団体などが、協議会の計画に基づいて野良猫の捕獲や病院への搬入等を行う場合 |
| 申込書類 | 地域猫活動等への支援申込書（PDF／WORD） |

円額・上限・負担割合は公式ページ本文に記載がありません。既に協議会から支援を受けた団体で追加の管理票が必要な場合は、申込書によらず直接協議会へ連絡するよう案内されています。

## 3. 地域猫活動団体の登録

神戸市には、責任をもって地域猫活動を行う団体を登録する制度があります。登録団体には腕章及びビブスが交付されます（希望する団体のみ）。

| 登録条件 | 内容 |
|---|---|
| 活動範囲 | 活動を行う地域の範囲が明確であり、管理する猫が把握されていること |
| 体制 | 活動は2名以上による団体を構成して行うものであること |
| 同意 | 活動について、活動地域の自治会等又は管理者の同意を得ていること |
| 受付窓口 | 衛生監視事務所 |
| 有効期間 | 7月1日（7月1日以降に登録したものは登録日）〜翌年6月30日 |
| 更新 | 毎年手続きが必要 |

必要書類は次のとおりです。

- 登録申請書（前年度から継続して登録する場合は不要）
- 活動報告書（前年度から継続して登録する場合のみ必要）

前年度の活動内容は、6月30日までに衛生監視事務所へ活動報告書を提出するよう求められています。
