熊本県の「飼い主のいない猫の避妊去勢手術支援事業」とは、県内（熊本市内を除く）に生息する飼い主のいない猫の避妊去勢手術を、熊本県動物愛護センターの獣医師が無料で実施する県直営の制度です。ただし令和8年度分は、手術枠がすべて埋まったとして、令和8年9月30日（水曜日）をもって依頼受付が停止されると案内されています。

<SubsidyInfoCard />

## この記事の結論

- 令和8年度は手術枠の満了により、令和8年9月30日（水曜日）で依頼受付が停止されます（県ページ更新日2026年9月17日）。すでに枠が埋まっているため、「募集中」の制度ではありません。
- 対象は熊本市を除く県内で、2人以上の成人による活動組織・グループです。個人単独や同一世帯のみのグループは対象外です。
- 費用は無料ですが、捕獲器の貸出しは県では行われず、猫は捕獲器に入れて搬入する必要があります。
- 熊本市内の猫は、別に熊本市の事業が用意されています。

## 1. 受付停止の経緯

県の案内では、実施期間は令和8年4月から令和9年3月まで、依頼受付期間は令和8年4月17日（金曜日）から令和9年2月26日（金曜日）までと定められていました。

しかし、予定していた手術枠がすべて埋まったため、令和8年9月30日（水曜日）をもって依頼受付を停止すると告知されています。受付期間の終了日（令和9年2月26日）を待たず、枠の満了で前倒しに停止された形です。手術は事前予約制で、予約枠が埋まり次第、受入れを断る場合があるとも案内されています。

なお、今回確認した資料には令和8年度の予算額や手術枠の総数の記載はなく、これらは未確認です。

## 2. 対象者・対象猫

| 区分 | 内容 |
|---|---|
| 対象エリア | 熊本県内（熊本市内を除く）。熊本市在住者を含むグループも対象外 |
| 対象者 | 飼い主のいない猫を減らすという活動目的を共有し、活動地域の頭数や生息個体情報等を継続的・適正に管理できる、2人以上の成人による活動組織またはグループ |
| 対象外の対象者 | 同一世帯のみで構成される活動組織・グループ、個人単独 |
| 対象猫 | 県内（熊本市内を除く）に生息する飼い主のいない猫 |
| 対象外の猫 | 飼い猫、手術実施済みの猫（さくら猫等） |

「成人」の要件は県のページに記載されています。けが・病気をしている、元気がない、体重1.2kg未満等で手術に適さないと判断された場合は、受付をした後でも手術せずに返還されます。手術済みの印として、返還時にはさくら耳（耳先のカット）の状態になります。

## 3. 内容・費用・依頼頭数

| 項目 | 内容 |
|---|---|
| 内容 | 避妊去勢手術 |
| 場所 | 熊本県動物愛護センター「アニマルフレンズ熊本」（宇城市松橋町東松崎701-4） |
| 費用 | 無料 |
| 依頼頭数の上限 | 原則、1つの活動組織・グループにつき10頭まで（10頭以上を希望する場合は、予約状況に応じて可能な場合があるため動物愛護センターへ連絡） |

市町村への補助金ではなく、県が手術を直接行う現物の支援です。保健所が依頼書の受付や猫の一時預かり・返還を担い、市町村へは依頼状況が情報提供されます。

## 4. 手続き・当日の流れ（令和8年度の受付時の内容）

依頼書類を、主たる活動地域を所管する保健所へ提出する方式でした。

<Checklist items={["避妊去勢手術支援依頼書（第1号様式）", "活動地域の見取図及び管理している猫の一覧（第1号様式別紙1）", "飼い主のいない猫の避妊去勢手術支援依頼に係る確認書（第1号様式別紙2）"]} />

依頼書提出後に内容が変わる場合は、変更依頼書（第2号様式）等の提出が求められます。流れは次のとおりです。

1. 依頼書類を保健所へ提出する。
2. センターから手術実施日等の連絡がある。
3. 手術日の前日までに猫を捕獲し、指定された時間・場所へ搬入する。
4. 動物愛護センターで手術が行われる。
5. 手術日の翌日に、指定された時間・場所で猫を引き取る。
6. 引取後、猫を元の場所へ戻す。

手術日は基本的に水曜日です。搬入は手術日の前日、引取は手術日の翌日で、やむを得ない事情により日程が変更・中止となる場合があります。具体的な日付の一覧は、確認した資料には記載がなく未確認です。

搬入時の注意点として、次が案内されています。

- 猫は捕獲器に入れて搬入する（キャリーバッグ等では受付不可）。
- 本人確認ができる書類（運転免許証、保険証等）を持参する。
- 動物愛護センターおよび保健所では捕獲器の貸出しは行っていない。貸出しを行っている市町村等もあるため、お住まいの市町村等に確認する。

## 5. 熊本市の事業との違い

熊本市内の猫は、この県事業ではなく熊本市の事業が対象です。両者は対象エリアが重ならない別々の制度です。詳しくは[熊本市の飼い主のいない猫の不妊去勢手術の記事](/subsidy/pet/kumamoto-shi-neko-funinkyosei)をご覧ください。

| 項目 | 熊本県の事業（本記事） | 熊本市の事業 |
|---|---|---|
| 対象エリア | 県内（熊本市を除く） | 熊本市内 |
| 依頼できる人 | 2人以上の成人の活動組織・グループ | 1人あたりの予約（4頭まで） |
| 頭数 | 原則1グループ10頭まで | 1人4頭まで |
| 実施場所 | 県動物愛護センター（宇城市） | 熊本市動物愛護センター |
| 捕獲器の貸出 | 県は行わない | センターからの貸出しあり（台数に限りあり） |
| 申込先 | 主たる活動地域の保健所へ依頼書を提出 | 市動物愛護センターへメールまたは電話 |

## 6. 未確認事項と関連する県の別事業

次の点は、今回確認した資料の範囲では確認できていません。

- 令和8年度の予算額・手術枠の総数
- 令和9年度以降の継続の可否
- 県内の市町村が独自に設けている猫の不妊去勢助成の有無
- 令和6・7年度の市町村別実績（県のページに掲載されているが、内容は未確認）

県は別事業として、地域猫の導入に取り組む自治会等の活動費に対する「地域猫活動支援補助金」を実施していると案内しています。交付には自治会等からの事前の申請が必要とされていますが、金額や条件は今回確認しておらず、未確認です。詳細は熊本県動物愛護センターなどの公式窓口でご確認ください。ペット関連の制度全体は[ペット関連補助金の完全ガイド](/subsidy/pet/pet-hojokin-kanzen-guide)も参考になります。
