港区は、生活保護受給世帯・児童扶養手当受給世帯・一定の所得基準を満たす世帯を対象に、小中学生の学用品費・給食費などを補助する就学援助制度を実施しています。

<SubsidyInfoCard />

## この記事の結論

- 対象は生活保護受給世帯、児童扶養手当受給世帯、または所得基準額以下の世帯
- 支給項目は学用品費・柔道着補助など**11項目**
- 令和8年度の申請期限は**令和8年4月17日**（期限後も年度内随時受付、最終期限は令和9年3月31日）

## 1. 対象者・所得基準額

港区に居住し、小中学校（義務教育学校・中等教育学校前期課程を含む）に通う子どもの保護者が対象です。次のいずれかに該当する必要があります。

- 生活保護受給世帯
- 児童扶養手当受給世帯
- 前年（令和7年1〜12月）の総所得金額等が所得基準額に該当する世帯

港区外に居住している場合やインターナショナルスクール等（学校教育法第1条に非該当）の在籍者は対象外です。

### 所得基準額の目安（令和8年度、モデルケース）

| 世帯構成 | 目安額 |
|---|---|
| 2人（母30歳・子小1） | 約301万円以下 |
| 3人（父35歳・母30歳・子小2） | 約362万円以下 |
| 4人（父40歳・母35歳・子中1・子小3） | 約436万円以下 |
| 5人（父40歳・母40歳・子3人） | 約511万円以下 |
| 6人（父45歳・母40歳・祖母70歳・子3人） | 約554万円以下 |

<Callout type="warning">
所得基準額は生活保護基準をもとに算出した「目安」であり、家族構成・年齢・18歳未満の子どもの数によって世帯ごとに変わります。目安を超えていても審査を希望する場合は申請可能です。
</Callout>

## 2. 支給項目

| 項目 |
|---|
| 学用品・通学用品費 |
| 給食費 |
| 修学旅行費 |
| 修学旅行事前指導金 |
| 校外学習費 |
| 移動教室費 |
| 夏季学園費 |
| 卒業記念アルバム費 |
| 新入学学用品費等 |
| 運動用具費（体育実技用具費・柔道着） |
| クラブ活動・部活動費 |

港区立学校は給食費無償化のため給食費（②）は支給対象外、移動教室費（⑥）・夏季学園費（⑦）は無償化対象のため支給なし、修学旅行費（③）も原則費用負担がないため支給なしです。

### 柔道着補助の特例

中学生が柔道の授業を受けるために4月以降に柔道着を購入した場合、上限6,500円が支給されます。対象は中学1年生の準要保護認定者に限られ、購入時の領収書が必要です。

## 3. 申請方法・スケジュール

<Checklist items={["オンライン申請（区ホームページ／専用サイト）または書面申請書を提出する", "令和8年度分はオンライン令和8年4月17日23時59分まで、書面も同日必着", "審査結果は7月中旬頃、保護者宛に郵送予定", "支給は学期ごとにまとめて7月・12月・3月の各月下旬に実施（港区立学校以外の認定者は初回8月下旬実施）"]} />

期限後も年度内は随時申請を受け付けており、最終申請期限は令和9年3月31日17時までです。
