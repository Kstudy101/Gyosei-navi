長野市の就学援助制度は、市立・県立・国立の小・中学校に通うお子さんの就学にあたり、経済的にお困りのご家庭へ学用品費や給食費、修学旅行費などの一部を援助する制度です。所得の目安は2人世帯で約163万円、4人世帯で約254万円です。年度途中の申請も受け付けており、最終受付は令和9年3月15日までです。

## この記事の結論

- 所得めやすは**2人世帯約163万円・3人約215万円・4人約254万円**（5人約304万円・6人約343万円・7人約406万円）
- 援助費目は学用品費等・給食費・修学旅行費・新入学学用品費・体育実技用具費・オンライン学習通信費・通学費など（定額または実費）
- **年度途中も申請可**（最終令和9年3月15日）。当初は各学校へ4月末まで
- 令和9年度小学校入学前支給は**合計75,930円**（新入学64,300円＋小1学用品費11,630円）。申請は令和8年10月1日〜令和9年1月31日

## 1. 対象者・認定基準

対象は、市立・県立・国立の小・中学校に通学するお子さんの保護者です。次のいずれかに該当する場合に援助を受けられます。

| 区分 | 内容 |
|---|---|
| （1） | 市民税非課税世帯 |
| （2） | 児童扶養手当受給世帯（児童手当・特別児童扶養手当ではない） |
| （3） | 前年の所得額が所得基準額を下回る世帯 |
| （4） | 災害・疾病・失業等により生計に著しい変化が生じ、生活が困難であると認められる世帯 |

### 所得基準額（目安）

| 世帯人数 | 所得基準額 | （参考）収入目安額 |
|---|---|---|
| 2人 | 約163万円 | 約259万円 |
| 3人 | 約215万円 | 約334万円 |
| 4人 | 約254万円 | 約386万円 |
| 5人 | 約304万円 | 約447万円 |
| 6人 | 約343万円 | 約496万円 |
| 7人 | 約406万円 | 約575万円 |

- 「所得額」は、給与所得者なら源泉徴収票の「給与所得控除後の金額」、事業所得者なら収入から必要経費を差し引いた金額。同一世帯員の所得は合算します
- 住民票上は別世帯でも同居している場合は、原則として同一世帯とみなします
- 給与所得または公的年金所得がある方は、所得額から**10万円を差し引いた金額**で審査します
- 所得基準額を下回っていても、生活実態などにより認定にならない場合があります
- 国の動向により基準額が変動する場合があります

（4）に該当する場合は、申請書の申請理由欄で「3.その他経済的に困っている」に○をし、具体的理由欄に内容を記入します。疾病や失業で前年より収入が大きく減った場合は、直近の収入状況をもとに審査され、離職票や給与明細などの写し提出を求められることがあります。

## 2. 受けられる援助費

| 費目 | 内容・支給の目安 |
|---|---|
| 学用品費等 | 定額。8月（4〜9月分）・12月（10〜3月分）。入学前支給を受けた場合は対象外 |
| 学校給食費 | 保護者が負担する給食費実費に直接充当（保護者口座への振込なし）。**小学校は給食無償化のため原則対象外**。中学校は公会計化に伴い就学援助費から直接支払（認定までは支払い、認定後に保健給食課から還付） |
| 修学旅行費・校外活動費（宿泊あり） | 実費（上限あり）。該当学年のみ。校外活動費（宿泊あり）は中学校のみ |
| 小学校新入学学用品費 | 定額。4月30日までに申請した1年生のみ。入学前支給済みは対象外 |
| 中学校新入学学用品費 | 定額。入学前支給は3月時点で認定の小学6年生、入学後支給は4月30日までに申請した1年生。入学前支給済みは対象外 |
| 体育実技用具費 | 実費。小学校はスキー・スケート用具レンタル費、中学校は授業で使う柔道・剣道用具購入費 |
| オンライン学習通信費 | 定額。8月（4〜9月分）・12月（10〜3月分） |
| 通学費 | 実費。通学距離が一定以上の場合のみ（他の通学費助成を受けている場合は対象外） |

- 国立・県立学校へ通う場合は、長野市教育委員会事務局総務課へ直接申請します。受けられる援助費は学用品費等・修学旅行費等・新入学学用品費・体育実技用具費・オンライン学習通信費です（給食費は対象外）
- 生活保護受給中は**修学旅行費のみ**就学援助の対象で、それ以外は教育扶助から支給されます（就学援助の申請は不要）
- 就学援助は各費目相当額を支給する制度であり、**学校納付金を免除するものではありません**
- 学校納付金に未納がある場合、援助費を学校へ直接支払うことや援助を打ち切ることがあります
- 支給後に市外転出や世帯状況の変化で受給世帯でなくなった場合、援助費の返還を求められることがあります
- 通常年度の学用品費等・新入学学用品費・オンライン学習通信費の**具体的な定額金額**は、今回参照した公式ページ・リーフレットには掲載されていません。最新額は教育委員会総務課学務担当（Tel 026-224-8597）または在籍校へ確認してください

## 3. 申請方法・スケジュール

### 新規申請（令和8年度）

1. 就学援助申請書（1学校1家庭につき1部）に必要事項を記入する
2. お子さんの通学している小・中学校へ提出する（様式は各学校・教育委員会総務課窓口、または市ホームページから入手）
3. 年度当初申請の場合、審査結果は**7月上旬頃**に学校経由で通知

- 当初の提出目安は**4月末日まで**
- 年度途中も随時受付。**最終受付は令和9年3月15日**（5月以降は毎月15日が締め切り）
- 申請時期により援助対象期間・支給費目・金額が変わります
- 本年1月1日時点で長野市に住民登録がなかった方は、6月中旬以降に1月1日時点の住所地市区町村から課税内容証明書（18歳以上の世帯員全員分）を取得して提出します
- 所得申告が済んでいないと審査できません

### 継続申請

前年度に認定を受けていた世帯には、4月中に各学校から継続申請の案内があります。小学校入学前に新入学学用品費の支給を受けた場合や、市立中学校へ進学した場合は、入学校から案内があります。

## 4. 令和9年度小学校入学前支給

令和9年度に小学校へ入学予定のお子さんがいる家庭向けに、入学前に次の費目を支給する制度があります。

| 費目 | 支給額 |
|---|---|
| 新入学児童学用品費 | 64,300円（定額） |
| 小学校第1学年の学用品費 | 11,630円（定額） |
| **合計** | **75,930円（定額）** |

- 対象条件（すべて該当）: 令和9年3月1日現在で長野市内に住所（見込み含む）／令和9年4月から市内の**国立または公立**小学校に入学予定（**私立は対象外**）／認定基準に該当
- 申請期間: **令和8年10月1日〜令和9年1月31日**（当日消印有効。期限後は受付不可）
- 支給日: 令和9年3月上旬予定。保護者の指定口座へ振込
- 申請先: 教育委員会総務課（郵送可）。学校や支所では受付しません。電子申請（ながの電子申請サービス）も利用できます
- 本制度で支給を受けた費目は、入学後の令和9年度就学援助では重複支給されません
- 入学後〜中学校卒業までの就学援助は、認定基準に該当すれば別途毎年度の申請が必要です

## 5. フリースクール利用料助成との関係

長野市には、就学援助を受けている世帯を対象にフリースクール等民間施設の利用料を助成する別制度があります。就学援助の認定が前提条件になるため、フリースクール助成を検討する場合は、まず就学援助の申請・認定状況を確認してください。詳細は関連記事「フリースクール利用料助成」を参照してください。
