福岡市は、経済的な理由で学用品代などの支払いに困る世帯を対象に、市立・国県立の小・中学校児童生徒の保護者へ学用品費・入学準備金などを支給する就学援助制度を実施しています。

<SubsidyInfoCard />

## この記事の結論

- 入学準備金は**小学校1年生64,300円・中学校1年生81,000円**（認定月が4月の世帯）
- 学用品費等は年額で小学校約**13,230〜15,500円**、中学校約**25,040〜27,310円**（4月認定の場合、各学期末に分割支給）
- 市立通学世帯には**オンライン学習通信費 年額15,000円**（1世帯あたり）もある
- 令和8年度の申請期限は**令和9年3月31日**（オンライン・窓口・郵送）

## 1. 対象者・支給条件

対象は次のいずれかに当てはまる世帯です（保護者である父母が同じ要件に該当している必要があります。ひとり親家庭等を除く）。

1. 生活保護の廃止・停止を受けたが、現在も経済的に困っている世帯
2. 市・県民税が非課税、または減免の適用を受けている世帯
3. 国民年金または国民健康保険の保険料の全額減免を受けている世帯（育児期間における保険料免除措置を除く）
4. 職業安定所登録の日雇い労働者、または1か月以内に生活福祉資金貸付制度の貸付を受けた方
5. ひとり親家庭等で児童扶養手当を受けている方
6. 市県民税の課税所得金額が基準額以下の世帯

通学先のイメージは次のとおりです。

| 通学先 | 扱い |
|---|---|
| 福岡市立の小・中学校（特別支援学級含む） | 対象（学校窓口・教育支援課・郵送・オンラインで申請可） |
| 国・県立の小・中学校（市内居住） | 対象（教育支援課窓口または郵送。学校窓口では申請不可） |
| 私立の小・中学校 | 支給対象外 |
| 特別支援学校 | 別の支援制度（学校に確認） |
| 生活保護受給中 | 申請不要（保護費から相当額支給） |

<Callout type="warning">
要件1〜6に該当しない場合でも、リストラ・廃業・疾病・災害など特別な事情で令和8年中の収入が減少した方は、令和8年中の収入で審査できる場合があります。この経路はオンライン・学校・郵送では手続きできず、教育委員会教育支援課（TEL 092-711-4693）への個別相談が必要です。住宅・自動車購入や教育費増加などの支出増は対象外です。
</Callout>

### 所得基準（要件6・令和8年6月1日以降申請）

16歳未満の子どもの人数（平成22年1月2日〜令和8年1月1日生まれ）に応じた、令和8年度市県民税の課税所得金額の上限です。

| 16歳未満の子の人数 | 基準額 |
|---|---|
| 1人 | 1,165,000円 |
| 2人 | 1,519,000円 |
| 3人 | 1,982,000円 |
| 4人 | 2,365,000円 |
| 5人 | 2,895,000円 |
| 6人 | 3,206,000円 |

## 2. 支給項目・金額（認定月が4月の場合）

主な費目は次のとおりです。認定月によって支給額が変わる点に注意してください。

| 費目 | 小学校 | 中学校 | 備考 |
|---|---|---|---|
| 学用品費等（年額） | 1年 13,230円／2〜6年 15,500円 | 1年 25,040円／2〜3年 27,310円 | 各学期末（7・12・3月）に分割 |
| 入学準備金 | 1年 64,300円 | 1年 81,000円 | 認定月が4月の世帯のみ |
| オンライン学習通信費 | 世帯あたり年15,000円 | 同左 | 市立のみ。子の人数にかかわらず1世帯 |
| 修学旅行費 | 6年・実費（上限26,180円） | 2年・実費（上限62,300円） | 参加時点で受給中であること |
| 社会科見学費 | 5年・実費 | 援助対象外 | 参加後に学校報告経由で支給 |
| 校外活動費（宿泊） | 全学年・実費（上限3,690円） | 全学年・実費（上限6,210円） | 同上 |
| 卒業アルバム代等 | 6年・実費（上限11,000円） | 3年・実費（上限10,000円） | 購入時点で受給中であること |
| 体育実技用具費（柔道着） | 援助対象外 | 全学年・実費（上限7,650円） | 市立のみ |
| 通学費 | 距離2km以上など | 距離3km以上など | 市立のみ。詳細は学校へ |
| 災害給付金 | 必要と認められる額 | 同左 | 学用品等再購入費 |

<Callout type="info">
令和8年度の詳細ページ・チラシに**給食費**の支給費目は記載されていません。給食費の扱いが気になる場合は、通学している学校または教育支援課に直接確認してください。
</Callout>

## 3. 申請方法・スケジュール

<Checklist items={[
  "要件1〜6のどれに当たるか確認し、必要な証明書類を用意する（要件2・5・6は原則不要の場合あり）",
  "オンライン申請、学校事務室、教育支援課窓口、郵送のいずれかで申請する",
  "振込先口座の通帳またはキャッシュカードの写しを用意する（継続申請で口座変更なしなら不要）",
  "令和9年3月31日必着までに申請する（8月以降申請は原則として申請月から認定）"
]} />

| 申請方法 | 期間・注意 |
|---|---|
| オンライン | 令和8年3月1日10時〜令和9年3月31日（6月配布チラシでは6月1日10時開始と案内） |
| 窓口（学校・教育支援課） | 令和8年3月2日〜令和9年3月31日（土日祝・年末年始除く） |
| 郵送 | 同上期間・必着。宛名に【就学援助申請書 在中】と記載 |

審査に使う税の年度と支給開始月の目安は次のとおりです。

| 申請時期 | 審査に使う税 | 認定・支給 |
|---|---|---|
| 令和8年5月末まで | 令和7年度市県民税 | 4月分から |
| 令和8年6〜7月 | 令和8年度市県民税 | 4月分から |
| 令和8年8月以降 | 令和8年度市県民税 | 申請月から |

市外から転入した場合、転入前の月以前は認定・支給されません（転入前の市町村に相談）。

## まとめ

福岡市の就学援助は、入学準備金（最大81,000円）と学用品費・修学旅行費などを組み合わせて、小・中学校の教育費負担を抑える市独自の制度です。申請は毎年度必要で、令和8年度分は令和9年3月31日まで受け付けています。最新の申請窓口・必要書類は公式ページで確認し、判断に迷う場合は教育委員会教育支援課（TEL 092-711-4693）へ問い合わせてください。
