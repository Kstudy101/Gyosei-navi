豊島区は、国公立の小・中学校に通う子どもの保護者へ、学用品や入学支度金などの**就学援助費**を支給しています。生活保護受給世帯（要保護）に加え、支給要綱の認定基準を満たす世帯（準要保護）も対象です。区立小中学校では授業料・教科書・給食費等は原則無料ですが、補助教材費や移動教室費などは保護者負担があり、その一部を区が援助します。

## この記事の結論

- 所得目安（モデルケース）は2人世帯で**約335万円**、3人**約380万円**、4人**約445万円**、5人**約470万円**、6人**約505万円**以下（世帯の合計所得）
- 入学支度金は小学校**91,600円**、中学校**101,000円**（4月認定）
- 通常申請期限は**令和8年4月30日**。以降も随時だが、認定は申請月から

## 1. 対象者・所得の目安

次のすべてに当てはまる必要があります。

1. お子さまが**国公立**の小・中学校へ通学していること
2. **豊島区内に在住**していること
3. 次のいずれかに該当すること
   - 生活保護を受給している（要保護）
   - 生活保護は受けていないが、支給要綱の認定基準を満たす（準要保護）

### 所得の目安（新入学の手引きのモデルケース）

| 世帯人数 | 家族構成例 | 合計所得金額 |
|---|---|---|
| 2人 | 35歳・7歳 | 約335万円以下 |
| 3人 | 45歳・45歳・9歳 | 約380万円以下 |
| 4人 | 40歳・12歳・7歳 | 約445万円以下 |
| 5人 | 45歳・45歳・14歳・9歳 | 約470万円以下 |
| 6人 | 70歳・45歳・45歳・12歳・7歳 | 約505万円以下 |

<Callout type="warning">
金額は家族構成や世帯員の年齢等により各世帯で変わります。あくまでモデルケースの目安です。令和8年度お知らせでは円建ての一覧ではなく「支給要綱の認定基準」と案内されています。該当するか分からない場合でも申請できます。
</Callout>

## 2. 支給される費用

令和8年度の費目別支給額表およびお知らせに掲載の主な内容は次のとおりです。

| 費目 | 対象 | 支給内容（例） |
|---|---|---|
| 入学支度金 | 小1（4月認定） | 91,600円 |
| 入学支度金 | 中1（4月認定）／小6の中学進学分 | 101,000円 |
| 学用品費 | 小学1年 | 年額27,600円 |
| 学用品費 | 中学1年 | 年額39,200円 |
| 学習応援費（R8新設） | 小学・全学年 | 年額14,000円 |
| 学習応援費（R8新設） | 中学・全学年 | 年額13,000円 |
| 校外活動費 | 学年により異なる | 年450円〜6,390円程度 |
| 移動教室費 | 学年により異なる | 上限5,000〜36,000円（実施後） |
| 修学旅行費 | 中3 | 上限73,000円（実施後） |
| クラブ活動費 | 中学（4〜7月認定） | 1,230円 |
| 体育実技用具費 | 中学・柔道剣道 | 上限7,860円 |
| 卒業アルバム代 | 小6／中3 | 上限16,000円／10,000円 |
| インフルエンザ予防接種費 | 中3 | 実費（領収書提出） |
| 学校給食費 | 区立以外で保護者負担がある場合 | 実費相当額 |

支給時期の目安は**8月上旬・11月上旬・1月上旬・3月上旬／下旬**など費目により異なります。

<Callout type="info">
豊島区立の小中学校は給食費無償化のため、区立在籍者への就学援助からの学校給食費支給はありません。区立以外の国公立に通い保護者負担がある場合のみ、実費相当額を支給します。生活保護受給中は、学用品費・入学支度金・校外活動費・移動教室費・クラブ活動費・体育実技用具費・学校給食費など生活保護費の対象費目は就学援助からは支給されません。
</Callout>

入学支度金は一度限りです。入学前に支給を受けた場合や、他自治体で既に入学支度金を受けた場合は入学後の支給対象外です。特別支援学校へ入学する場合、入学前支給は対象外ですが、入学後4月中に就学援助を申請して認定されれば、就学奨励費との差額支給の案内があります。

## 3. 申請方法・期限

### 申請方法

1. **電子申請** — [令和8年度就学援助費受給申請（LoGoフォーム）](https://logoform.jp/form/gXWR/824732)
2. **書面申請** — 「令和8年度就学援助のお知らせ」（申請書）に記入し、学務課学事グループへ持参または郵送

申請書は公式ページからダウンロードできるほか、教育委員会（本庁舎7階）、総合窓口課（本庁舎3階）、東・西区民事務所にも置いてあります。**就学援助は毎年度の申請が必要**です。

令和8年1月2日以降に豊島区へ転入した方は、マイナンバー利用同意書を提出すると添付書類の一部を省略できます。令和8年1月1日現在の住所が豊島区の方は、同意書の提出は不要です。

### 申請期限

- 通常期限: **令和8年4月30日（木曜日）**（郵送は当日消印有効）
- 5月以降も随時受付（**認定は申請月から**。一部費目が対象外になる場合あり）

### 入学前の入学支度金

従来は入学後支給だった入学支度金を、負担軽減のため**入学前の3月下旬**にも支給します。対象は、世帯合計所得が認定基準内で、申請時および翌年度4月以降も豊島区在住、翌年度4月に国公立の小・中学校へ入学する世帯です。案内PDFは公式の就学援助ページから入手できます。
