岐阜市の就学援助は、経済的な理由で就学が難しい児童生徒の保護者に対し、学用品費や給食費、修学旅行費などを市が援助する制度です。対象は市内の国公立小・中学校または義務教育学校に在籍する児童生徒の保護者で、申請は在籍校を通じて行います。翌年4月に国公立の小学校または義務教育学校へ入学予定の児童がいる保護者には、入学準備に必要な学用品費の一部援助もあります。

## この記事の結論

- 対象は**市内国公立の小中・義務教育学校**に通う児童生徒の保護者（経済的理由で就学が困難な世帯）
- 所得制限の目安は、例えば**2人世帯247万円程度・4人世帯345万円程度**（世帯全員の所得・家族構成により異なる）
- 援助費目は学用品費・給食費・修学旅行費など。**定額の円単価は公式ページに未掲載**
- 申請は**毎年度・在籍校へ提出**。年度途中申請も可だが、さかのぼり支給はなし
- 新入学予定者向けは**11月初旬のお知らせ**から申込（結果は2月下旬通知）

## 1. 対象となる世帯

公式ページでは、大きく次の2類型が示されています。

### 1. 前年度または当該年度に次の措置を受けた世帯

| 事由 |
|---|
| 生活保護法に基づく保護の停止または廃止 |
| 市民税が非課税または減免 |
| 個人事業税が減免 |
| 固定資産税が減免（家屋新築による減額などの軽減措置は除く） |
| 国民年金保険料の免除（一部免除含む。夫婦の場合はそれぞれ必要） |
| 国民健康保険料の減免または減額（国民健康保険法第81条） |
| 児童扶養手当の支給（児童手当・特別児童扶養手当とは異なる） |
| 生活福祉資金の貸付 |

### 2. 上記に当てはまらなくても、経済的に困っていると認められる世帯

- 職業安定所登録の日雇労働者
- 保護者の死亡・病気などにより急激に収入が減った世帯
- 前年の所得（収入から必要経費を控除した後の金額）から、経済的に困っていると認められる世帯

### 所得制限額の目安（例）

所得制限額は**世帯全員の所得**で、家族構成や年齢により異なります。下表は公式ページに掲載されている目安です。

**在籍児童生徒向け**

| 家族数 | 家族構成の例 | 所得制限 |
|---|---|---|
| 2人家族 | 親（40歳）・子（9歳） | 247万円程度 |
| 3人家族 | 親（40歳・38歳）・子（9歳） | 302万円程度 |
| 3人家族 | 親（38歳）・子（9歳・13歳） | 306万円程度 |
| 4人家族 | 親（40歳・38歳）・子（7歳・9歳） | 345万円程度 |
| 5人家族 | 親（40歳・42歳）・子（7歳・9歳・13歳） | 377万円程度 |

**新入学用**

| 家族数 | 家族構成の例 | 所得制限 |
|---|---|---|
| 2人家族 | 親（35歳）・子（6歳） | 247万円程度 |
| 3人家族 | 親（35歳・38歳）・子（6歳） | 303万円程度 |
| 4人家族 | 親（35歳・38歳）・子（6歳・9歳） | 345万円程度 |
| 5人家族 | 親（35歳・38歳）・子（6歳・9歳・13歳） | 377万円程度 |

<Callout type="info">
審査前の問い合わせでは、世帯ごとの認定基準額を個別に案内できないことがあります。迷う場合は、まず在籍校で申請手続きを進めてください。
</Callout>

## 2. 支給対象となる費用

| 費目 | 支給方法 |
|---|---|
| 学用品費、通学用品費、自転車保険料分（許可者のみ）、新入学児童生徒学用品費（1年生のみ） | 定額支給 |
| 校外活動費、PTA会費、卒業アルバム代、GPS通信費（小1〜3のうち該当者）、生徒会費（中学校のみ）、クラブ活動費（中学校のみ） | 実費支給（上限あり） |
| 修学旅行費、給食費 | 実費支給 |

<Callout type="warning">
定額支給の円単価や、実費支給の上限額は公式ページに掲載されていません。最新の単価は在籍校または学校安全支援課で確認してください。生活保護世帯については、教育扶助で賄われない一部の費目（修学旅行費、通学用品費のうちGPS通信費）のみが就学援助の対象です。
</Callout>

### 支給時期（在籍中の方）

| 予定時期 | 対象 |
|---|---|
| 8月末 | 4〜7月分 |
| 9月末 | 4〜7月に実施した校外活動・修学旅行分 |
| 2月中旬 | 9〜12月分 |
| 翌年度4月末 | 1〜3月分 |

振込日が決まると、学校を通じて通知されます。新入学予定者向け（新入学児童生徒学用品費・学用品費）は**2月下旬予定**で、教育委員会から直接通知されます。入学前に支給を受けなかった場合でも、入学後の申請で認定されれば8月末に支給を受けられます。

## 3. 申請方法

### 在籍中の児童生徒

1. 在籍する小中学校または義務教育学校で申請書を受け取る
2. 必要事項を記入して学校へ提出する
3. 前年所得を理由に申請する場合は、事前に所得の申告を済ませる（前年中に所得がない人でも、税法上の控除対象配偶者・扶養親族を除き税の申告が必要）

<Checklist items={["在籍校で申請書を受け取る", "所得申告が済んでいるか確認する（所得事由で申請する場合）", "申請書を在籍校へ提出する", "認定通知を待つ（7月中旬・12月上旬・2月中旬。学校経由）"]} />

- **毎年度の申請が必要**です
- 兄弟姉妹が小中学校それぞれに在籍する場合は、**両方に申請**が必要です（同一校なら1枚で可）
- 年度途中からの申請もできますが、**支給対象は申請日以降**で、さかのぼり支給はありません
- 認定された場合は学校経由で通知、却下された場合は保護者あてに直接通知されます

### 小学校・義務教育学校への入学予定者

11月初旬に「就学援助制度のお知らせ」が郵送されます。記載のインターネットサイトから申し込むか、同封の申請書に自署で記入し、返信用封筒で提出します。審査結果は**2月下旬**に保護者へ直接通知されます。

## まとめ

岐阜市の就学援助は、市内国公立の小中・義務教育学校に通う世帯向けに、学用品費・給食費・修学旅行費などを援助する市の制度です。所得制限の目安や対象事由は公式ページで確認でき、申請窓口は在籍校です。定額の円単価は公式ページに出ていないため、金額の詳細は学校または学校安全支援課（学事係: 058-214-2316 など）へ確認してください。
