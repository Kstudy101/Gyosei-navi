未来まなび応援金（就学援助制度）とは、経済的な理由で就学が困難な名古屋市内の児童生徒の保護者に対し、学用品費・入学準備金・修学旅行費・学校給食費などを支給する名古屋市の制度です。

<SubsidyInfoCard />

## この記事の結論

- 対象は①生活保護受給世帯、②令和7年4月2日以降の生活保護停止・廃止世帯、③令和7年11月以降の児童扶養手当受給世帯、④所得が基準額以下の世帯のいずれか
- 所得基準額は世帯人数2人322万8千円〜6人541万9千円（7人以上は1人ごとに46万2千円加算）。物価高騰等を踏まえ当面の間引き上げ中
- 入学準備金は小学校64,300円・中学校81,000円。このほか学用品費等・オンライン学習通信費・卒業アルバム代等・学校給食費なども支給対象
- 対象期間は令和8年9月分〜令和9年8月分。**3月は申請受付を行わない**
- 令和8年9月より電子申請フォームでの受付に移行

## 1. 対象者・所得基準

未来まなび応援金の対象は、名古屋市在住の児童生徒で、次の1〜4のいずれかに該当する場合です。

| 区分 | 該当理由 |
|---|---|
| 1 | 生活保護法に規定する要保護者 |
| 2 | 生活保護が停止または廃止された（令和7年4月2日以降） |
| 3 | 児童扶養手当が支給された（令和7年11月以降） |
| 4 | 所得が基準額以下（各世帯員の令和7年中の総所得から10万円を差し引いた額の合算が下表以下） |

### 所得基準額（区分4で申請する場合）

区分4「所得が基準額以下」で申請する場合の所得基準額は、次のとおりです。

| 世帯人数 | 所得基準額 | 年収目安 |
|---|---|---|
| 2人 | 322万8千円 | 470万4千円 |
| 3人 | 346万2千円 | 500万4千円 |
| 4人 | 420万0千円 | 592万8千円 |
| 5人 | 488万6千円 | 676万3千円 |
| 6人 | 541万9千円 | 735万5千円 |
| 7人以上 | 1人増すごとに46万2千円加算 | — |

<Callout type="warning">
名古屋市は、物価高騰等を踏まえ、当面の間この所得基準額を引き上げて運用しているとしています。今後の基準額の変更については、名古屋市の公式案内で最新情報を確認してください。
</Callout>

## 2. 支給内容・金額

支給される費目・金額・時期は次のとおりです（令和8年9月分〜令和9年8月分）。

| 費目 | 対象学年 | 金額 | 支給時期 |
|---|---|---|---|
| 学用品費等 | 小1 | 1学期5,670円／2学期4,320円／3学期3,240円 | 6/1頃・10/26頃・1/25頃 |
| 学用品費等 | 小2〜6 | 1学期6,680円／2学期5,040円／3学期3,780円 | 同上 |
| 学用品費等 | 中1 | 1学期10,690円／2学期8,200円／3学期6,150円 | 同上 |
| 学用品費等 | 中2・3 | 1学期11,560円／2学期9,000円／3学期6,750円 | 同上 |
| オンライン学習通信費 | 全学年（タブレット家庭学習実施校のみ） | 1学期6,250円／2学期5,000円／3学期3,750円 | 同上 |
| 入学準備金 | 小学校入学前（小1）／小6（中1入学前） | 小学校64,300円／中学校81,000円 | 2/25頃（該当により6/1頃） |
| 卒業アルバム代等 | 小6・中3 | 実費額 | 3/31頃 |
| 学校給食費 | 中学生（スクールランチ実施校、鳴海中学校除く） | 実際に飲食した金額 | 月次 |
| 野外活動費 | 小5・中2 | 実費額 | 実施後約3ヶ月 |
| 修学旅行費 | 小6・中3 | 実費額 | 実施後約3ヶ月 |
| 通学交通費 | 小4km以上・中6km以上 | — | 7月・10月・1月 |
| 学校生活管理指導表文書費 | アレルギー等該当者 | 実費額（上限3,000円） | 月次 |
| 学校病医療費 | 該当者 | 学校長から医療機関へ直接支払い | — |

<Callout type="warning">
生活保護受給世帯は、修学旅行費・学校病医療費のみが支給対象です。それ以外の費目は生活保護費（教育扶助）に含まれるため、重複しては支給されません。
</Callout>

学校病医療費のみ、保護者への直接支給ではなく、学校長から医療機関へ直接支払われる仕組みになっています。

## 3. 申請方法・受付状況

未来まなび応援金は、外部リンクの電子申請フォームで申請します。名古屋市は令和8年9月より、この電子申請フォームでの受付に移行しました。

- 月末23時59分までに不備なく申請の受付が完了した月（申請月の初日に対象校へ在籍していない場合は翌月）から認定されます。
- **3月は申請受付を行いません。**
- オンライン申請が難しい場合は、子どもが在籍する学校に相談できます。

<Callout type="warning">
未来まなび応援金は3月の申請受付を行っていません。年度の途中で申請を検討している場合は、この点に注意してください。
</Callout>

このほか、次の3種類の特例申請があります。

| 特例申請 | 内容 |
|---|---|
| 海外所得 | 住民登録がなく、海外で所得を得ている場合 |
| 家計急変 | 生計維持者の傷病・解雇・倒産により家計が急変した場合 |
| 被災 | 天災等により被災した場合 |
