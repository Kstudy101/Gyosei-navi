就学援助制度は、同一生計の家族全員の前年所得が市の基準以内である家庭に対し、学用品費・修学旅行費・学校給食費などの一部を助成する新潟市の制度です。令和8年度からは電子申請（e-NIIGATA）が始まり、所得に応じた4階層の支給率（100%・75%・50%・25%）と、年額4,000円の市独自制度奨励費が特徴です。

企業向けの「企業参加型奨学金返済支援事業」とは別制度です。本記事では小・中学生の保護者が直接申請する就学援助を扱います。

## この記事の結論

- 対象は、子が新潟市に住民登録しているか市立小・中・中等教育学校前期課程に在籍し、同一生計の前年所得が基準以内の家庭
- **支給率は所得階層で100%・75%・50%・25%の4段階**（基準の1.3倍超は対象外）
- 学用品費等は小1が年13,230円、小2〜6が年15,500円、中1が年25,040円、中2〜3が年27,310円（これにPTA会費・市独自奨励費などが加わる）
- 令和8年度は電子申請開始。早期期限は4月30日だが、以降も随時受付（**申請した月から開始・遡及なし**）

## 1. 対象となる家庭

次の両方を満たす家庭が対象です。

1. お子様が**新潟市に住民登録**している、または**新潟市立**の小学校・中学校・中等教育学校前期課程に在籍している
2. 同一生計の家族全員の前年所得の合計が、新潟市の定める基準以内である

同一生計の家族には、単身赴任中の保護者や、住民票上世帯分離している祖父母・叔父・叔母等も含みます（水回りを共用しない二世帯住宅などで別生計と認められる場合あり。光熱水費の明細等が必要）。

<Callout type="warning">
生活保護を受けている家庭は、就学援助では**修学旅行費のみ**が対象です。手続きは修学旅行実施後に学校から案内があり、就学援助の申請は不要です。特別支援学校に在籍するお子様は新潟県の特別支援教育就学奨励費の対象のため、市の就学援助には申請できません。
</Callout>

## 2. 所得階層と支給率

認定基準額に対する所得の倍率で階層が分かれ、各費目の支給基本額に支給率を乗じた額が支給されます。

| 階層 | 世帯所得の範囲 | 支給率 |
|---|---|---|
| 第1階層 | 就学援助認定基準額×1.0倍以下 | 100% |
| 第2階層 | 基準額×1.0倍超〜1.1倍以下 | 75% |
| 第3階層 | 基準額×1.1倍超〜1.2倍以下 | 50% |
| 第4階層 | 基準額×1.2倍超〜1.3倍以下 | 25% |
| 援助対象外 | 基準額×1.3倍超 | ― |

### 第4階層に該当する場合の所得目安（一例）

公式ページ・令和8年度お知らせに掲載の「認定となる世帯所得の目安」から、第4階層（上限側）の例です。持ち家と借家で目安が異なります。

| 世帯人数・構成例 | 持ち家 | 借家 |
|---|---|---|
| 2人（母・小学1年） | 約224万円 | 約296万円 |
| 3人（父母・小学1年） | 約256万円 | 約328万円 |
| 4人（父母・小学4年・小学1年） | 約316万円 | 約388万円 |
| 5人（父母・小学4年・小学1年・4歳児） | 約353万円 | 約425万円 |
| 6人（父母・小学4年・小学1年・祖父・祖母） | 約417万円 | 約489万円 |

表はあくまで一例で、家族の年齢構成などにより異なります。基準内か分からなくても申請すれば教育委員会が審査します。

### 所得基準を超えても第4階層になる場合

所得基準を超えていても、次のいずれか（お知らせの①〜⑧）に該当し証明書を提出すれば、**第4階層（25%支給）**として認定されます。

- 障がい者・ひとり親・寡婦を理由に市民税が非課税
- 災害などによる市民税・固定資産税の減免、個人事業税の減免
- 国民年金保険料の免除、国民健康保険料の減免または猶予
- 児童扶養手当の支給（児童手当・特別児童扶養手当とは別）
- 生活福祉資金による貸付（償還期間を除く）

## 3. 援助の内容と金額

領収書の提出は不要です。所得階層の支給率を乗じた額が支給されます。5月以降に認定された場合、学用品費等・PTA会費・卒業アルバム代・市独自奨励費などは認定月以降の月数で月割りになります。

### 小学校

| 費目 | 支給基本額 | 支給時期 |
|---|---|---|
| 学用品費・通学用品費・校外活動費（宿泊なし） | 1年 13,230円／年、2〜6年 15,500円／年 | 8月・1月・3月 |
| PTA会費 | 年額 3,450円 | 8月・1月・3月 |
| 卒業アルバム代 | 6年 年額 11,000円 | 8月・1月・3月 |
| 新入学生徒学用品費（中学入学準備） | 2月時点で認定の6年生 年額 81,000円 | 3月 |
| 修学旅行費 | 実費（上限あり） | 精算後の8月・1月・3月のいずれか |
| 校外活動費（宿泊あり） | 2月時点で認定の5年生 年額 3,690円 | 3月 |
| 市独自制度奨励費 | 年額 4,000円 | 8月・1月・3月 |
| 医療費 | 医療券による治療費 | 随時 |

### 中学校・中等教育学校前期課程

| 費目 | 支給基本額 | 支給時期 |
|---|---|---|
| 学用品費・通学用品費・校外活動費（宿泊なし） | 1年 25,040円／年、2〜3年 27,310円／年 | 8月・1月・3月 |
| 生徒会費 | 年額 5,550円 | 8月・1月・3月 |
| PTA会費 | 年額 4,260円 | 8月・1月・3月 |
| 卒業アルバム代 | 3年 年額 10,000円 | 8月・1月・3月 |
| 修学旅行費 | 実費（上限あり） | 精算後の8月・1月・3月のいずれか |
| 校外活動費（宿泊あり） | 6,210円を限度とした実費 | 精算後の1月または3月 |
| 市独自制度奨励費 | 年額 4,000円 | 8月・1月・3月 |
| 学校給食費 | 実費（牛乳代含む。弁当持参は対象外） | 8月・1月・3月 |
| 医療費 | 医療券による治療費 | 随時 |

令和8年度お知らせでは、学校給食費は小・中とも保護者負担額を援助対象とし、日本スポーツ振興センター共済掛金の保護者負担額**460円**の免除（5月1日時点で認定されている場合など条件あり）も記載されています。**新潟市立以外の学校**に通う場合は、給食費・医療費・同共済掛金は対象外です。

<Callout type="info">
就学援助に認定されても、学校徴収金や給食費の引き落とし・納付書請求は止まりません。援助費の振込（年3回）と徴収月（年9回）は別タイミングです。
</Callout>

## 4. 申請方法・期限

令和8年度から**電子申請**での受付が始まりました。

1. [新潟市オンライン申請システム（e-NIIGATA）](https://lgpos.task-asp.net/cu/151009/ea/residents/procedures/apply/1ee53435-09e9-46d2-b916-430a6941a5d0/start)から申請（利用者ID登録が必要）
2. 電子申請が難しい場合は、紙の申請書を郵送（教育委員会学務課または在籍校で入手、公式ページからもPDFダウンロード可）

区役所・出張所では申請書を受け付けていません。

令和8年度お知らせ上の早期期限は次のとおりです。

- 電子申請: **2026年4月30日（木）23時59分**まで
- 郵送申請: **2026年4月30日（木）**まで（消印有効）

5月1日以降も随時受け付けますが、**申請した月から援助開始**となり、それ以前の月分には遡りません。就学援助の申請は毎年必要です。

審査結果通知の目安は、4・5月申請が7月下旬、6〜8月申請が9月下旬、9月以降申請が概ね申請から2か月後です。
