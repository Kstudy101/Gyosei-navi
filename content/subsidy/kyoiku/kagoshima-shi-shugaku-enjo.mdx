就学援助制度とは、児童生徒の就学に必要な経費を負担することが困難な家庭の保護者に対し、学用品費・学校給食費などを援助する鹿児島市の制度です。前年の所得状況などをもとに判定し、認定後に費目ごとの援助を受けられます。

<SubsidyInfoCard />

## この記事の結論

- 対象は市内在住で、市立小・中または鹿児島大学教育学部附属小・中に通う児童生徒の保護者
- 令和8年度の所得基準例は2人世帯2,071,200円、4人世帯2,928,800円（R8〜R10で段階的引下げ予定）
- 学用品費は学年により年13,230〜27,310円。給食費は実費。新入学学用品費は小6入学前支給63,000円など
- 毎年度申請が必要（自動更新なし）。当初提出は令和8年4月20日、以後も年度途中申請可

## 1. 対象者・認定基準

対象は、**鹿児島市内に住所を有し**、鹿児島市立小・中学校または鹿児島大学教育学部附属小・中学校に在学する児童生徒の保護者（現に監護している方）で、同居している方を含む**令和7年度合計所得金額**が、世帯人員別の認定所得基準額以下の方です。

| 世帯人員 | 令和8年度 認定所得基準額 |
|---|---|
| 2人世帯 | 2,071,200円 |
| 3人世帯 | 2,647,200円 |
| 4人世帯 | 2,928,800円 |
| 5人世帯 | 3,213,600円 |
| 6人世帯 | 3,693,600円 |
| 7人世帯 | 4,202,400円 |
| 8人世帯 | 4,640,800円 |

- 住民票上は別世帯でも同居していれば同じ世帯とみなして判定
- 二世帯住宅などで玄関・光熱水費メーターが別々など、客観的に別世帯とみなせる場合は含めない
- 単身赴任者や市外の学校に在学する学生は、住所が異なっても同じ世帯とみなす
- 給与所得者は、令和7年分源泉徴収票の「給与所得控除後の金額」から10万円（10万円未満ならその金額）を引いた額を参考にする
- 非認定後でも、倒産・リストラなどの家計急変で今年の収入が大幅に減少する場合は再審査を受けられる場合がある

<Callout type="warning">
市は就学援助を持続可能に続けるため、令和8年度から令和10年度にかけて所得基準額を段階的に引き下げる方針です。今後の基準は毎年の案内で確認してください。
</Callout>

生活保護を受けている方は、修学旅行費と医療費について援助を受けられます（その他の費目は生活保護制度側で支給）。

## 2. 援助の内容と金額

援助費は医療費を除き**事後支給**が原則です。認定後も校納金等はいったん学校へ納めます。

| 費目 | 内容・金額 | 支給時期の目安 |
|---|---|---|
| 学用品費等 | 小1:13,230円／年、小2〜6:15,500円／年、中1:25,040円／年、中2〜3:27,310円／年 | 各学期末（7月・12月・3月）に分けて支給 |
| 給食費 | 保護者が負担する実費 | 各学期末（7月・12月・3月） |
| 新入学学用品費（入学前） | 小学校6年生:63,000円（中学入学前の3月） | 入学前（3月） |
| 新入学学用品費（入学前未受給・4月認定のみ） | 小1:57,060円、中1:63,000円 | 1学期末 |
| 修学旅行費 | 参加した場合の旅行費用の一部（限度額あり） | 実施後 |
| 校外活動費 | 宿泊を伴う校外活動の交通費・見学料等の実費（年1回） | 実施後 |
| 体育実技用具費 | 柔道または剣道の用具実費（中学校で1回、限度額あり） | 購入後 |
| 通学費 | 徒歩片道が小学生4km以上・中学生6km以上で公共交通を利用する場合の交通費（定期券またはIC乗車券） | 実績確定後 |
| 医療費 | むし歯・結膜炎・中耳炎・慢性副鼻腔炎など学校病の治療費 | 各医療機関へ直接支給（市立小・中のみ） |

私立小中学校や特別支援学校へ進学する場合、新入学学用品費は支給対象外です。小学校6年生ですでに就学援助を受けている場合、中学入学前の新入学学用品費について追加申請は不要と案内されています。

## 3. 申請方法

<Checklist items={["年度当初に学校から配布される「就学援助制度のお知らせ」と「就学援助申請意思確認書兼申請書」を確認する", "引き続き希望する場合も確認書兼申請書を提出する（自動更新ではない。児童生徒1人につき1枚）", "振込口座は申請者（保護者）名義。通帳の写し等を貼付する", "令和8年1月1日時点で市外住所だった場合は、住所地市町村発行の令和8年度所得額証明書を学校へ提出する", "市民税が未申告の場合は市民税の申告を行う"]} />

令和8年度のお知らせでは、確認書兼申請書の学校提出期限は**令和8年4月20日（月）**です。この日までに提出した方には、7月上旬に学校を通じて審査結果が通知されます。期限後の年度途中申請も可能ですが、認定月は提出月となり、援助費は認定月以降分のみです。

新小学1年生向けの入学前新入学学用品費については、案内・申請書が保護者へ郵送され、教育委員会総務課へ提出する別ルートがあります（令和8年4月入学分の提出期限は令和8年1月30日、支給予定日は令和8年3月19日・1人あたり57,060円）。当該入学前受付は終了済みのため、以降は在学中の就学援助申請の案内に従ってください。
