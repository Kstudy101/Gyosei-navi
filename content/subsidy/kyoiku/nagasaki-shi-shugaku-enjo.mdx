長崎市の就学援助とは、経済的な理由で学用品代や給食費などの支払いに困る世帯を対象に、小・中学校で必要な経費の一部を市が支給する制度です。返済の必要はありません。

<SubsidyInfoCard />

## この記事の結論

- 新入学用品費は**小学校1年生64,300円・中学校1年生81,000円**
- 学用品費等は年額で小学校約**11,630〜13,900円**、中学校約**22,730〜25,000円**（学期ごとに分割支給）
- **給食費・修学旅行費・校外活動費**は実費相当（市立以外は一部上限あり）
- 令和8年度の随時申請は**令和8年4月16日〜令和9年3月15日**（電子申請）

## 1. 対象者・支給条件

対象は、小・中学校に通う児童生徒の保護者で、次のいずれかに該当し、教育委員会が援助の必要があると認めたかたです。

### 所得要件

令和7年中の世帯員全員の合計所得金額が、下表の基準額以下であること（添付書類は不要）。

| 世帯人数 | 基準額（所得額） |
|---|---|
| 2人 | 2,256,000円 |
| 3人 | 2,677,000円 |
| 4人 | 2,991,000円 |
| 5人 | 3,426,000円 |
| 6人 | 3,999,000円 |
| 7人 | 4,594,000円 |
| 8人 | 5,172,000円 |
| 9人 | 5,417,000円 |
| 10人 | 6,196,000円 |
| 11人 | 6,510,000円 |

世帯員とは、原則として住民票に記載されている世帯員および同一住所の世帯員をいいます。源泉徴収票と比較する場合は「給与所得控除後の金額」を確認します。

### その他の要件（主なもの）

| 申請理由 | 添付書類 |
|---|---|
| 生活保護が停止または廃止された | 添付不要 |
| 世帯員全員の市民税が非課税 | 添付不要 |
| 市民税・個人事業税・固定資産税・国保税が減免（天災など） | 減免の種類により通知書が必要 |
| 国民年金掛金が減免された（令和8年7月以前または4分の1免除は対象外） | 免除申請承認通知書 |
| 児童扶養手当を受けている（全部支給停止は対象外） | 原則添付不要 |
| 生活福祉資金を借りた（令和8年の借入に限る） | 貸付決定通知書 |
| 職業安定所登録の日雇労働 | 日雇労働被保険者手帳 |
| 特別の事情（離職・長期療養・転職・同一勤務先での減収・災害） | 離職票・収入見込証明書・り災証明書など |

<Callout type="warning">
生活保護を受給している場合は申請できません。また、申請は毎年度必要です。小学校入学前に新入学用品費の支給を受けたかたも、入学後に給食費などの援助を希望する場合は令和8年度で改めて申請してください。
</Callout>

通学先の扱いは次のとおりです。

| 通学先 | 扱い |
|---|---|
| 市立の小・中学校 | 対象（医療費・通学費・オンライン学習通信費を含む） |
| 私立・県立・国立の小・中学校（市内在住） | 対象（医療費・通学費は支給なし。給食費等は上限あり） |
| 特別支援学校 | 対象外 |
| 生活保護受給中 | 申請不可 |

長崎市から他市町村の小中学校へ通う場合、またはその逆の場合は、長崎市と他市町村の両方に申請します。

## 2. 支給額・援助内容（令和8年度）

支給額は令和8年度の場合です。変更になる場合があります。

| 費目 | 小学校 | 中学校 | 備考 |
|---|---|---|---|
| 新入学用品費 | 1年 64,300円 | 1年 81,000円 | 入学前3月に支給。未支給なら入学直後4月認定時のみ入学後支給可 |
| 学用品費等 | 1年 11,630円／2〜6年 13,900円 | 1年 22,730円／2・3年 25,000円 | 7月・9月・1月に学期分を分割 |
| 給食費 | 実費相当 | 同左 | 市の給食費会計へ納付または保護者へ支給。市立以外は上限あり |
| 修学旅行費 | 実費相当 | 同左 | 実施後。市立以外は上限あり |
| 校外活動費 | 交通費・見学料の一部 | 同左 | 社会科見学・宿泊学習など。実施後 |
| 体育実技用具費 | — | 柔道着上限7,650円／剣道用具上限52,900円 | 授業で柔道・剣道をする場合。学校へ支給 |
| 通学費 | 片道4km以上の定期券代 | 片道6km以上の定期券代 | 市立の指定校・公共交通機関のみ。特別支援学級（通級除く）は距離不問 |
| 医療費 | 特定疾病の治療代・薬代 | 同左 | 市立のみ。受診前に医療券の申請が必要 |
| オンライン学習通信費 | 市貸与モバイルルーター利用時の経費 | 同左 | 市立のみ |

## 3. 申請方法・必要書類

令和8年度は電子申請が案内されています。

| 区分 | 申請時期 | 申請方法 |
|---|---|---|
| 当初申請（4月認定分） | 2月16日〜4月15日17時まで | 長崎市電子申請サービス（当初用フォーム） |
| 随時申請（5月以降認定分） | 4月16日以降（お知らせPDFでは令和9年3月15日まで） | 長崎市電子申請サービス（随時用フォーム） |

提出物の目安は次のとおりです。

<Checklist items={["通帳の写し（口座情報のページ。無い場合はキャッシュカードの写し可）", "審査に係る必要書類（申請理由ごとの添付書類。所得要件のみの場合は原則不要）", "電子申請時は必要書類の写真を添付"]} />

インターネット環境がない場合や外国語での申請を希望する場合は、教育委員会学務課へ連絡します。申請内容の再確認や追加提出を求められることがあり、登録メールの確認が必要です。不備のまま期限までに補正されないと不認定になることがあります。

審査結果は学校を通じて書面で通知されます。当初申請は6月中旬から下旬、随時申請は審査完了後に随時お知らせがあります。
