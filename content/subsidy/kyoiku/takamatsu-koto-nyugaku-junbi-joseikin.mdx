高松市高等学校等入学準備助成金とは、経済的理由で高等学校等への進学が難しい世帯の保護者に対し、高松市が対象生徒1人あたり35,000円を返済不要で支給する制度です。ただし、この記事で扱う令和8年4月入学予定者向けの募集は、申請期限（令和7年12月15日）をすでに過ぎ、審査結果通知も発送済みで**終了**しています。

<SubsidyInfoCard />

## この記事の結論

- 支給額は対象生徒1人あたり35,000円（返済不要）。支給時期は令和8年3月6日（金曜日）。
- 令和8年4月入学予定者向けの申請期限は令和7年12月15日で終了済み。審査結果通知は令和8年2月13日付で発送済み（未着なら2月20日までに学校教育課へ連絡が必要だった）。
- 「高松市高等学校入学準備金貸付制度」（返済が必要な貸付制度）とは併用不可。次年度分の募集情報は本記事執筆時点で未公表。

## 1. 対象者・支給条件

次の（1）〜（4）をすべて満たす生徒の保護者が対象です。

| 要件 | 内容 |
|---|---|
| （1）住所要件 | 令和7年11月1日時点で高松市に住所を有する生徒の保護者 |
| （2）受験（進学）要件 | 令和8年度に高等学校等（高等学校、中等教育学校の後期課程、高等専門学校、特別支援学校の高等部）への入学を予定し、入学選考・受験の出願を行うこと。中高一貫校等で同一学校内から進学見込みの者を含む |
| （3）成績要件 | 中学校3年生（4月〜12月）の評定平均が3.0以上 |
| （4）経済要件 | 下記6区分のいずれかに該当 |

経済要件（4）は次のいずれかです。

| 区分 | 要件 | 備考 |
|---|---|---|
| ア | 生活保護の停止または廃止をされた方 | 生活保護受給中・停止中の方は事前に生活福祉課（087-839-2343）へ相談のうえ申請 |
| イ | 市民税の非課税世帯の方 | 世帯全員が非課税であること |
| ウ | 児童扶養手当の支給を受けている方 | 児童手当・特別児童扶養手当は対象外 |
| エ | 国民年金の掛金の減免を受けている方 | 世帯全員が減免を受けていること。厚生年金の方は非該当 |
| オ | 世帯の所得の合計が、生活保護基準の1.3倍以下の方 | 生活保護基準は世帯構成・世帯員の年齢で変わるため学校教育課へ要問合せ |
| カ | 令和7年1月以降に、特別な事情により家計が急変した方 | 離職・休職等。詳細は学校教育課へ問い合わせ |

## 2. 支給額・計算方法

支給額は対象生徒1人あたり35,000円で、返済は不要です。加算や上限区分などはなく、一律の定額支給です。支給時期は令和8年3月6日（金曜日）とされています。

## 3. 申請方法・必要書類（令和8年4月入学予定者向け・すでに終了）

申請方法は、電子申請（外部フォーム）または学校教育課窓口（高松市役所10階、平日8時30分〜17時、祝日除く）での紙申請のいずれかでした。申請期限は令和7年12月15日（月曜日）で、電子申請は12月16日午前0時以降は受け付けられませんでした。

審査結果通知は令和8年2月13日（金曜日）頃の発送予定とされており、実際に同日付で発送済みです。申請済みの方に郵送で通知され、令和8年2月20日までに届かない場合は学校教育課（087-839-2616）へ連絡するよう案内されていました。

## 4. 注意点：貸付制度との併用不可・次年度分は未公表

「高松市高等学校入学準備金貸付制度」（返済が必要な貸付制度）との併用はできません。両方の制度に申し込み、どちらも認定となった場合は、最終的にいずれか一方を選ぶ必要があります。

なお、次年度（令和9年4月入学予定者向け）の募集開始時期や要項変更の有無は、2026年9月時点の公式ページに記載がなく未確認です。最新の募集状況は、下記の窓口または高松市公式ページで直接確認してください。
