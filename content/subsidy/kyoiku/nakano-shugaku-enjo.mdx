中野区は、国立または公立の小・中学校に通う子どもの保護者へ、学用品や給食費などの**就学援助費**を支給しています。生活保護受給世帯（要保護）に加え、これに準ずると認められる世帯（準要保護）も対象です。

<SubsidyInfoCard />

## この記事の結論

- 所得目安は2人世帯で**約331万円**、3人**約360万円**、4人**約439万円**、5人**約485万円**、6人**約557万円**（前年の合計所得）
- 新入学学用品費は小学校**91,600円**、中学校**101,000円**
- 通常申請期限は**令和8年4月24日**。以降も随時だが、受付月分からの認定（最終は令和9年3月10日）

## 1. 対象者・所得の目安

次のいずれにも当てはまる必要があります。

1. **中野区内に住んでいる**こと（区外居住は対象外）
2. 子どもが**国立または公立**の小・中学校に在籍していること
3. 次のいずれかに該当すること
   - 現在、生活保護を受けている（要保護）
   - 生活保護は受けていないが、同一生計の世帯全員の前年合計所得の合算が就学援助基準額に満たない（準要保護）

### 就学援助基準額の目安（前年所得）

| 世帯人数 | 認定基準（目安） |
|---|---|
| 2人 | 約331万円 |
| 3人 | 約360万円 |
| 4人 | 約439万円 |
| 5人 | 約485万円 |
| 6人 | 約557万円 |

<Callout type="warning">
金額は世帯構成員の数・年齢等により各世帯で変わります。あくまで目安です。上表を超える場合でも審査を希望する場合は申請できます。給与所得または公的年金所得がある場合は、合計所得金額から最大10万円を控除して審査します。
</Callout>

審査の対象となる所得は、前年（令和7年＝2025年1月〜12月）の合計所得金額です。個別の基準額を申請前に計算してもらうことはできません。

## 2. 支給される費用

主な費目と金額（区立小・中学校向けの支給表）は次のとおりです。

| 費目 | 対象 | 支給内容 |
|---|---|---|
| 学用品費 | 小・全学年 | 4月1,390円、その他月1,300円（年合計15,690円） |
| 学用品費 | 中・全学年 | 4月2,620円、その他月2,530円（年合計30,450円） |
| オンライン学習通信費 | 小・中・全学年 | 月額1,000円（年合計12,000円） |
| 新入学学用品費 | 就学予定者または小1 | 年1回91,600円（1年生は4月当初認定者が対象） |
| 新入学学用品費 | 小6または中1 | 年1回101,000円（1年生は4月当初認定者が対象） |
| クラブ活動費 | 小4〜6 | 年1回240円（4月当初認定） |
| クラブ活動費 | 中・全学年 | 年1回1,230円（4月当初認定） |
| 卒業アルバム代 | 小6・中3 | 実費（上限11,000円） |
| 給食費 | 小・中・全学年 | 実費（教育委員会から学校へ直接支給） |
| 医療費 | 小・中・全学年 | 実費（教育委員会から医療機関へ直接支給） |
| 通学費 | 特別支援学級在籍・通級 | 実費（年2回） |

区立学校の支払月は**8月・12月・3月**です（学用品費・オンライン学習通信費など）。新入学学用品費は随時、卒業アルバム代は3月または4月です。

<Callout type="info">
令和8年度、中野区立学校では保護者から費用を徴収せずに修学旅行・移動教室・校外活動・校内鑑賞教室を実施するため、これらの費目は就学援助からは支給されません。区立学校の全児童・生徒向けに別制度「区立学校の教育に関する費用負担補助」があります（所得制限なし）。
</Callout>

生活保護を受けている場合は、生活保護費の対象となる費目（学用品費、オンライン学習通信費、新入学学用品費、給食費、クラブ活動費、通学費）は就学援助から支給されません。新入学学用品費は、入学前に他自治体を含む支給を受けている場合も対象外です。

国立・都立や区外公立に通う場合は、支給時期が前期（10月）・後期（翌年4月）の2回になるなど扱いが異なります。詳細は学校区分ごとのお知らせPDFを確認してください。

## 3. 申請方法・期限

### 申請方法

1. **電子申請**（おすすめ） — [令和8年度 就学援助申請（LoGoフォーム）](https://logoform.jp/form/Trw5/1427538)
2. **書類申請** — 申請書に記入し、必要資料を添えて学務課（区役所7階）へ持参または郵送

**学校では申請を受け付けません。** 申請書は学務課窓口と学校にありますが、提出先は学務課です。お子さん一人につき一件の申請が必要です。

### 申請期限

- 通常期限: **令和8年4月24日（金）必着**
- 以降も随時受付（認定は申請受付月から。一部費目が対象外になる場合あり）
- 最終申請期限: **令和9年3月10日**（期限内でも最終登校日以降は不可）

### 所得の確認

- 令和8年1月1日時点で中野区内居住: 教育委員会が所得確認調査を行うため、所得確認書類の提出は原則不要（未申告の人がいると非認定になるため、所得がなかった人も申告が必要）
- 同日時点で他自治体居住: 課税・非課税証明書（合計所得金額記載）またはマイナンバー利用同意書を提出

4月申請分は、所得が判明する6月中旬に当初認定を審査し、結果を郵送で知らせます。当初認定なら4月まで遡って支給します。
