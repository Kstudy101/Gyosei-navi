就学援助制度とは、経済的な理由により市立小・中学校への就学でお困りの保護者に対し、学用品費・新入学学用品費・修学旅行費などを援助する京都市の制度です。令和8年度は、小学校の給食無償化に加え、中学校給食費も市が直接支払うため保護者負担はありません。

<SubsidyInfoCard />

## この記事の結論

- 所得基準の目安は2人世帯1,820,200円、4人世帯2,792,700円など。児童扶養手当受給や生活保護関連でも対象になり得る
- **新入学学用品費は小学64,300円・中学81,000円**（入学前及び4月認定の新1年生のみ）
- **小・中とも給食費の保護者負担なし**（小学校は無償化、中学校は市が業者へ直接支払い）
- 申込みは各学校で随時。新規の年度当初認定希望は**5月15日まで**、継続は**5月31日まで**が案内されている

## 1. 対象者・認定基準

対象は、京都市立小学校・中学校・小中学校に通学している児童生徒の保護者で、次のいずれかに該当する方です。

| 区分 | 内容 |
|---|---|
| ① 生活保護（教育扶助 受給） | 学校に申込書のみ提出 |
| ② 生活保護（教育扶助 非受給） | 同上 |
| ③ 生活保護の停止・廃止 | 令和7年4月1日以降。世帯変更による廃止は除く |
| ④ 児童扶養手当の受給 | 所得審査で否認定でも、受給中であれば認定可（証書の写し提出） |
| ⑤ 経済的理由（所得要件） | 世帯の合計所得が所得基準額以下 |
| ⑥ その他特別な事情 | 火災・地震・水害等に罹災した場合など。学校に相談 |

### 所得基準額（令和8年度）

| 世帯人数 | 所得基準額 |
|---|---|
| 2人 | 1,820,200円 |
| 3人 | 2,331,200円 |
| 4人 | 2,792,700円 |
| 5人 | 3,219,200円 |
| 6人 | 3,573,600円 |
| 7人以上 | 1人増すごとに354,400円加算 |

妊婦・産婦（出産後6か月以内）・70歳以上・母子・父子世帯・障害のある方（身体障害者手帳1〜3級、精神障害者手帳1・2級又は療育手帳Aと同程度）・入院・在宅の長期療養者（3か月以上）・22歳未満の子が3人以上いる世帯については、1項目または1人につき**23万円**を所得基準額に加算できます。年齢は令和8年4月1日時点です。

<Callout type="info">
所得審査で否認定でも、年度途中の収入激減・失業・廃業などの家計急変により認定できる場合があります。該当する方は学校に相談してください。
</Callout>

## 2. 援助の内容（令和8年度）

| 費目 | 小学校 | 中学校 | 支給時期の目安 |
|---|---|---|---|
| ①学用品費・通学用品費・校外活動費（遠足等） | 1年: 各6,670円／2〜6年: 各7,805円（前期・後期） | 1年: 各12,530円／2・3年: 各13,665円（前期・後期） | 7月頃・12月頃から随時 |
| ②校外活動費（宿泊を伴うもの） | 実費（一部対象外あり） | 同左 | 9月頃から随時 |
| ③体育実技用具費 | 授業用で全員購入の用具の実費（種類・金額に制限あり） | 同左 | 11月頃から随時 |
| ④新入学学用品費 | 64,300円 | 81,000円 | 入学前申込: 3月上旬〜中旬／入学後: 5月頃から随時 |
| ⑤学校給食費 | 無償化により保護者負担なし | 市が業者等へ直接支払い、保護者負担なし | — |
| ⑥通学費 | 実費（距離要件・限度額あり） | 同左 | 年3回 |
| ⑦修学旅行費 | 22,690円以内 | 57,910円以内（航空機利用時は60,910円以内） | 9月頃から随時 |
| ⑧医療援助費 | 対象疾病の医療費（市が医療機関へ直接支払い、保護者負担なし） | 同左（むし歯は中学生のみ。小学生は学童う歯対策等のため保護者負担なし） | — |
| ⑨災害共済掛金 | 免除（市が直接支払い） | 同左 | — |
| ⑩学校生活管理指導表等作成費 | 実費（上限3,300円） | — | 9月頃から随時 |
| ⑪卒業アルバム費 | 実費（上限11,000円） | 実費（上限10,000円） | 3月頃から随時 |

<Callout type="warning">
生活保護（教育扶助）を受給中の方は、①のうち校外活動費（小1,710円・中2,330円、12月頃から随時）および⑦〜⑨が対象です。新入学学用品費④の対象は「入学前及び4月認定の新1年生のみ」です。
</Callout>

## 3. 申請方法・認定のタイミング

- 申込みは**各学校で随時受付**（土日・祝日等の学校休業日を除く）
- 申請書類は学校で配布、または市のホームページから印刷可能
- 認定にあたってマイナンバー制度を活用（所得調査のため）
- 保護者名義の通帳の写しなど、必要に応じて追加書類あり

### 新規申込み

| 申込日 | 審査の所得 | 認定期間 |
|---|---|---|
| 4月1日〜5月15日 | 令和6年所得 | 令和8年4月1日〜6月30日 |
| 5月16日〜6月30日 | 令和6年所得 | 申込月の1日〜6月30日 |
| 7月1日〜令和9年3月31日 | 令和7年所得 | 申込月の1日〜令和9年6月30日 |

年度当初からの認定を希望する場合は**5月15日まで**の申込みが案内されています。4月〜6月末までに申し込んだ場合、7月以降の審査・認定について再度の申込みは不要です。転入生は転入日から1か月以内の申込みで認定されれば、転入日からの認定となります。

### 継続申込み

前年度に認定された方の認定期間は**令和8年6月30日で終了**します。継続を希望する場合は**5月31日まで**に申し込み、認定期間は令和8年7月1日〜令和9年6月30日（令和7年所得で審査）です。
