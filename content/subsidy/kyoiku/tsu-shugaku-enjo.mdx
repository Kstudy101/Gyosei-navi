津市の就学援助（就学に必要な費用の援助）は、義務教育の費用負担で困っている家庭に対し、学用品費や給食費、修学旅行費などを援助する市の制度です。新入学を控えた世帯向けには、入学前に支給する新入学用品準備金もあります。

<SubsidyInfoCard />

## この記事の結論

- 所得めやすは**2人世帯約200万円・4人世帯約310万円**など（世帯構成で異なる目安）
- **新入学用品準備金**は小学校入学**57,060円**・中学校入学**63,000円**（令和8年度案内）
- 援助費目は学用品・給食費（実費）・修学旅行費（実費）・校外活動費・学校病の医療費・オンライン学習通信費など
- 入学前支給の締切（令和7年12月23日）は経過済みだが、**就学援助本体は随時申請可**。4月10日までの申請で4月認定なら入学後に同額支給あり
- 申請は在籍校または学校教育課（学務担当）。問い合わせ電話は059-229-3245

## 1. 対象者

津市内に在住し、次のいずれかの学校に在籍する子どもの保護者が対象です。

- 津市内の市立・国立の小学校・中学校・義務教育学校
- 三重県立みえ四葉ヶ咲中学校（学びの多様化学校コースのみ）

次のいずれかに該当する場合に援助の対象になります。

### （1）前年度または当該年度に次のいずれかに該当する人

- 生活保護法に基づく保護を停止または廃止された人
- 市民税が非課税の人
- 児童扶養手当の支給を受けている人（**児童手当は対象外**）

### （2）その他、子どもの就学に当たり経済的な理由で困っている人

（1）に該当しない場合は、世帯の合計所得金額が認定基準内かどうか審査します。

### 世帯所得の目安

| 世帯人数 | 世帯の合計所得金額（目安） |
|---|---|
| 2人 | 約200万円 |
| 3人 | 約260万円 |
| 4人 | 約310万円 |
| 5人 | 約330万円 |

生計同一世帯の人数・年齢・居住形態等により認定基準額は異なります。上表はあくまで目安です。

## 2. 援助される費用

| 費目 | 内容 |
|---|---|
| 学用品・通学用品費 | 教育委員会が定める額 |
| 学校給食費 | 実費（教育委員会から在籍校の口座へ直接振込） |
| 新入学用品費等 | 新たに1学年に入学した場合。準備金を受けた場合は支給なし |
| 新入学用品準備金 | 次年度に就学予定の場合（入学前支給あり） |
| 校外活動費 | 宿泊あり・なしそれぞれ年1回まで。教育委員会が定める額 |
| 修学旅行費 | 年1回・実費 |
| 医療費 | 学校から治療指示があった学校病（虫歯・結膜炎・中耳炎など）の治療費 |
| オンライン学習通信費 | 家庭でのオンライン学習に係る通信費。教育委員会が定める額の範囲内 |

国立・県立学校に就学している場合は、援助される費用が一部異なります。生活保護受給世帯については、就学援助からの支給は**医療費と修学旅行費のみ**です。

学用品・通学用品費などの円単価一覧は公式ページに掲載されていません。金額は在籍校または学校教育課へ確認してください。

## 3. 新入学用品準備金（入学前支給）

令和8年4月に市内の市立・国立の小中学校・義務教育学校へ入学予定の保護者向けに、入学前に新入学用品準備金を支給する案内があります。

| 区分 | 支給額 |
|---|---|
| 小学校および義務教育学校前期課程の入学予定者 | **57,060円** |
| 中学校入学予定者および義務教育学校後期課程の進級予定者 | **63,000円** |

- 支給日: 令和8年3月9日（月曜日）予定
- 支給方法: 申請者（保護者）の口座へ振込
- 入学前支給の提出期限: 令和7年12月23日（火曜日）

期限を過ぎた場合でも、**令和8年4月10日（金曜日）まで**に令和8年度の就学援助費を申請し、4月からの認定となれば、入学後に同額を新入学用品費として支給します。就学援助の申請自体は4月10日以降も受け付けています。

入学前支給の申請は、令和8年度の就学援助費給付申請を兼ねます。準備金を受けた人は継続して令和8年度の就学援助が受けられ、入学説明会などで案内される申請書の再提出は不要です。

## 4. 申請方法

通常の就学援助は、「就学援助費給付申請書」を在学している学校または教育委員会事務局学校教育課で受け取り、必要事項を記入のうえ、在学している学校（新1年生は入学後に通学する学校）へ提出します。

新入学用品準備金（小学校入学予定）は、就学時健康診断の案内と一緒に送付される申請書を学校教育課または各教育事務所へ提出（郵送可）します。

郵送先: 〒514-0035 津市西丸之内37番8号 津市教育委員会事務局 学校教育課 学務担当 宛

令和7年1月2日以降に津市へ転入した人は、転入前の住民登録地（令和7年1月1日現在）で発行される「令和7年度（令和6年分）所得・課税証明書」の添付が必要です（コピー可）。
