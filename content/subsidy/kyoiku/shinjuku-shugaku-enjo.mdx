新宿区は、経済的な理由により就学が困難と認められる世帯を対象に、小中学生の学用品費・修学旅行費などを援助する就学援助制度を実施しています。生活保護受給世帯だけでなく、失業等により所得が著しく減少した場合も申請できる点が特徴です。

<SubsidyInfoCard />

## この記事の結論

- 対象は生活保護受給世帯、または所得基準額以下の世帯（失業等による減少も対象）
- 支給項目は学用品費・修学旅行費など**10項目**
- 所得の目安は2人世帯で約297万円〜6人世帯で約516万円（令和7年分所得基準）
- 7月末日までに申請すれば4月1日まで遡って認定される

## 1. 対象者・所得の目安

新宿区に住所を有し、学校教育法第1条に規定する小学校・中学校・義務教育学校・中等教育学校前期課程に在学している児童・生徒の保護者（または生徒本人）が対象です。次のいずれかに該当する必要があります。

- 現在、生活保護を受けている方
- 令和7年4月以降に生活保護が停止または廃止となり、引き続き支援を必要とする方
- 令和7年分の世帯全員の所得額の合計が基準金額以下の方
- 失業等により所得が著しく減少した方

インターナショナルスクール等（学校教育法第1条に規定する学校でないもの）の在籍者は対象外です。

### 所得基準額の目安（令和8年度、モデルケース）

| 世帯人数 | 家族の年齢構成（モデルケース） | 基準金額の目安 |
|---|---|---|
| 2人 | 35歳・7歳 | 約297万円 |
| 3人 | 35歳・35歳・7歳 | 約364万円 |
| 4人 | 40歳・40歳・13歳・7歳 | 約441万円 |
| 5人 | 40歳・40歳・13歳・7歳・4歳 | 約466万円 |
| 6人 | 65歳・40歳・40歳・13歳・7歳・4歳 | 約516万円 |

<Callout type="warning">
上記はあくまで「目安」です。基準金額は世帯人数や家族の年齢構成等により異なります。世帯員数は令和8年4月1日現在の住民登録状況によります。また、失業等により所得が著しく減少した場合は、上記基準を超えていても申請できます。
</Callout>

## 2. 支給項目

| 項目 | 支給方法 | 備考 |
|---|---|---|
| 学用品費 | 定額 | |
| 新入学学用品費 | 定額 | 4月1日認定の方。入学前支給を受けた方は対象外 |
| クラブ活動費 | 定額 | |
| 校外教授費（遠足・社会科見学等） | 実費 | |
| 移動教室参加費 | 定額 | |
| 修学旅行費 | 実費 | |
| 卒業アルバム費 | 定額 | |
| 医療費 | 実費 | 学校から治療指示のあった方 |
| 通学費 | 実費 | 特別支援学級のみ、距離要件あり |
| 英語キャンプ費 | 定額 | 新宿区立学校在籍の方のみ |

<Callout type="info">
生活保護を受けている方は、学用品費・新入学学用品費・クラブ活動費・通学費の4項目については、福祉事務所から支給されます。就学援助としての重複支給はありません。
</Callout>

就学援助は、学校等に支払う費用そのものが免除される制度ではありません。学校から納付の案内があった場合は、まず学校の指示に従って納付してください。

## 3. 申請方法・スケジュール

申請方法はお子さまの就学先により異なります。援助を希望する場合は、毎年度申請が必要です。

### 新宿区立小学校・中学校に在学している場合

<Checklist items={["学校で申請書を受け取る", "必要事項を記入し、金融機関の通帳のコピーを申請書裏面に貼付する", "学校へ提出する（窓口・郵送・電子申請は不可）", "7月末日までに提出すれば、4月1日（または転入日）まで遡って認定"]} />

### 新宿区立学校以外（国立・公立・私立等）に在学している場合

<Checklist items={["区ホームページから申請書（就学援助費受給希望調査票兼申請書）をダウンロードする", "必要事項を記入し、金融機関の通帳のコピーを申請書裏面に貼付する", "学校運営課窓口へ持参・郵送・または電子申請で提出する"]} />

審査結果は郵送で通知されます。支給金額・支給時期は認定日やお子さまの学年等により異なるため、認定後の通知で確認してください。
