就学援助とは、小学校・中学校（義務教育学校を含む）に就学する子どもの保護者で、学用品や給食などの費用に困っている家庭へ、神戸市が費用の一部を援助する制度です。神戸市在住であることが前提で、所得制限があります。認定後は年数回に分けて指定口座へ支給され、希望すれば学校長口座への振込もできます。

## この記事の結論

- 所得めやす（総所得）は**2人世帯176万1千円・3人223万4千円・4人266万4千円**（8人以上は7人基準に1人あたり45万5千円加算）
- **学用品費・通学用品費**は小学1年11,630円、小学2〜6年13,900円、中学1年22,730円、中学2・3年25,000円（年間予定額）
- **新入学児童生徒学用品費**は小学1年64,300円、中学入学時（小学6年の入学前支給または中1）81,000円
- 神戸市立の場合、**給食費は現物支給**。随時申請は**2027年2月5日（消印有効）まで**

## 1. 対象者・認定基準

神戸市在住で、小学校・中学校または義務教育学校に在籍している児童生徒の保護者のうち、次のいずれかに該当する場合が対象です。

| 区分 | 内容 |
|---|---|
| 1 | 生活保護を受けている |
| 2 | 児童扶養手当を受けている（特別児童扶養手当は対象外） |
| 3 | 家族全員の前年の総所得合計が基準額以下となる |
| 4 | 上記1〜3以外で、失業や勤め先の業績悪化などにより、2026年の所得が基準額以下となる見込み |

### 基準額（総所得金額）

世帯人数には所得のない子どもも含めます。

| 世帯人数 | 基準額（総所得） |
|---|---|
| 2人 | 176万1千円 |
| 3人 | 223万4千円 |
| 4人 | 266万4千円 |
| 5人 | 304万8千円 |
| 6人 | 361万7千円 |
| 7人 | 412万3千円 |
| 8人以上 | 7人世帯の所得に1人増えるごとに45万5千円を加える |

<Callout type="info">
寡婦・ひとり親控除（27万円）、障害者控除（特別40万円／普通27万円・1人あたり）、医療費控除など、要件に当てはまる特別控除を差し引いた金額を基準額と比較します。給与所得・年金所得は税制改正の影響を考慮し、総所得額より最大10万円を控除します。単身赴任の保護者や同居の祖父母などは、原則として同一世帯として合算します。
</Callout>

要保護（生活保護受給）の場合、教育扶助で支給されない**給食費・医療費・修学旅行費**が就学援助の対象です。

## 2. 援助の内容（令和8年度・年間予定額）

下記は年間予定額です。年度途中認定の場合は月単位計算のため予定額より少なくなります。**通学費・自転車通学費・給食費・医療費は神戸市立の小・中・義務教育学校に通う場合のみ**支給されます。

### 小学校（義務教育学校前期課程を含む）

| 費目 | 金額・内容 |
|---|---|
| 学用品費・通学用品費 | 1年11,630円／2〜5年13,900円／6年13,900円 |
| 卒業アルバム代等 | 6年生のみ11,000円 |
| 校外活動費 | 年間2,100円 |
| 新入学児童生徒学用品費 | 1年64,300円／6年81,000円（中学校入学前支給） |
| 体操服費・水泳着費 | 1年生のみ5,350円 |
| 泊を伴う校外活動費 | 上限3,690円（在学中1回） |
| 修学旅行費 | 上限22,690円（在学中1回） |
| 通学費 | 実費額相当 |
| 給食費 | 現物をもって支給 |
| 医療費 | 対象の学校病に医療券を発行 |

### 中学校（義務教育学校後期課程を含む）

| 費目 | 金額・内容 |
|---|---|
| 学用品費・通学用品費 | 1年22,730円／2・3年25,000円 |
| 卒業アルバム代等 | 3年生のみ10,000円 |
| 校外活動費 | 年間3,310円 |
| 新入学児童生徒学用品費 | 1年生のみ81,000円 |
| 体操服費・水泳着費 | 1年生のみ5,970円 |
| 泊を伴う校外活動費 | 上限6,210円（在学中1回） |
| 修学旅行費 | 上限59,000円（在学中1回） |
| 通学費 | 実費額相当 |
| 自転車通学費 | 上限4,730円 |
| 体育実技用具費 | 実費（柔道上限7,650円／剣道上限52,900円。学校一括購入時） |
| 給食費 | 現物をもって支給 |
| 医療費 | 対象の学校病に医療券を発行 |

新入学児童生徒学用品費の扱い：

- **小学校**：4月から認定されている小学1年生のみ（入学前支給対象者は除く）
- **中学校**：小学6年生の3月に入学前支給。中学1年の4月から新たに認定された生徒は中1で支給

支給時期の目安（内容PDF）：学用品費等は7月・12月・3月頃、給食費は各学期末頃、修学旅行費・校外活動費などは実施月の翌々月頃など。費目ごとの詳細は公式の「就学援助の内容」PDFを確認してください。

## 3. 申請方法・期間

| 区分 | 期間 | 認定の起点 |
|---|---|---|
| 定期申請 | 2026年4月1日（水）〜2026年5月19日（火）（消印有効） | 認定されれば原則4月1日から |
| 随時申請 | 2026年5月20日（水）〜2027年2月5日（金）（消印有効） | 申請書提出月から |

- **電子申請**：スマート申請システム「e-KOBE」で新規・変更・辞退が可能
- **郵送申請**：市立は学校配布の「新規申請 受付のお知らせ」を参照。私立・国立・県立は各種様式から申請書をダウンロードして郵送
- 提出先：〒650-0044 神戸市中央区東川崎町1丁目3-3 神戸ハーバーランドセンタービル ハーバーセンター4階／神戸市教育委員会事務局 学校経営支援課 学事計画係
- 5月19日までに申請した方への結果通知は7月以降。それ以降の申請は申請からおおむね3か月以内に通知

継続申請の提出状況は、市公式ページに掲載される「提出状況確認用番号」一覧で確認できます。「申請する」で受け付けている場合、4月配布の新規申請書（ピンク色）の再提出は不要です。
