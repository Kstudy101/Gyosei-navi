福井県高校生等奨学給付金とは、年収目安490万円相当までの世帯の高校生等を対象に、授業料以外の教育費（教科書費・教材費・学用品費・通学費など）を支援する返還不要の給付型支援金です。世帯の所得区分に応じて年額32,300円〜143,700円（全日制・定時制の場合）が支給されます。

<SubsidyInfoCard />

## この記事の結論

- 返還不要の**給付型**。年収目安**490万円**相当までの世帯が対象
- 所得区分は4段階（生活保護世帯／非課税世帯／所得割105,500円未満世帯／所得割182,500円未満世帯）で、**金額が異なる**
- 全日制・定時制の非課税世帯は年額**143,700円**が最も高い
- 通信制は全日制・定時制より支給額が低く設定されている
- 入学時は「前倒し給付」（年額の4分の1）を受け取れる

## 1. 対象者・支給条件

次の要件をすべて満たす高校生等（生徒本人ではなく保護者等の要件を含む）が対象です。

<Checklist items={["保護者等が福井県に居住し、福井県に住民票があること", "次の(2)所得区分のいずれかに該当すること", "日本国籍、特別永住者、永住者、日本人の配偶者等、永住者の配偶者等、定住者（将来永住意思認定者）、家族滞在（小中卒業・就労定着意思認定者）のいずれかであること"]} />

特別支援学校高等部の生徒、児童養護施設に入所している生徒は、この制度とは別の支援制度の対象となります。

### 所得区分（4段階）

| 区分 | 内容 | 年収目安 |
|---|---|---|
| (ア) | 生活保護（生業扶助）世帯 | — |
| (イ) | 道府県民税＋市町村民税所得割額の合計が0円（非課税）世帯 | — |
| (ウ) | 同合計が105,500円未満の世帯 | 約270〜380万円 |
| (エ) | 同合計が182,500円未満の世帯 | 約380〜490万円 |

所得割額は、保護者等全員の令和8年度（令和7年分所得に基づく）道府県民税・市町村民税所得割額の合計で判定します。前倒し給付の場合は前年度（令和7年度）の課税状況で確認します。

### 判定基準日

原則として**令和8年7月1日現在**の状況で判定します。ただし前倒し給付は**令和8年4月1日現在**の状況で判定します。

### 支給回数の上限

高校生等1人につき年1回、通算3回まで（定時制・通信制は4回まで）支給されます。保護者の一方が県外に居住する場合は、生活の本拠地となる都道府県でのみ申請できます。

## 2. 支給額・計算方法

### 全日制・定時制（令和8年度、年額）

| 所得区分 | 年額 |
|---|---|
| 生活保護世帯 | 32,300円 |
| 非課税世帯（所得割0円） | 143,700円 |
| 所得割105,500円未満世帯 | 47,900円 |
| 所得割182,500円未満世帯 | 35,930円 |

### 通信制（令和8年度、年額）

| 所得区分 | 年額 |
|---|---|
| 生活保護世帯 | 32,300円 |
| 非課税世帯（所得割0円） | 50,500円 |
| 所得割105,500円未満世帯 | 16,830円 |
| 所得割182,500円未満世帯 | 12,630円 |

### 前倒し給付

入学時に負担が大きい4〜6月分に相当する金額として、**給付年額の4分の1**を前倒しで受け取れます。ただし判定は令和8年4月1日時点の状況で行うため、実際の支給は4月以降になります。

## 3. 申請方法・必要書類

申請方法は在学する高校の種類によって異なります。

| 在学先 | 申請方法 |
|---|---|
| 福井県内の公立高校 | 学校を通じて案内・書類提出 |
| 福井県内の国立高校 | 別途案内予定 |
| 福井県外の高校 | 申請書を郵送し、電話で連絡が必要 |
| 私立高校 | 福井県大学私学課（電話0776-20-0248）に問い合わせ |

通常の給付は、在学する高校を通じて例年9月頃に案内があり、申請書類を高校に提出したうえで、指定の金融機関口座に振り込まれる流れです。具体的な申請締切日は公式ページに明記されていないため、早めに学校からの案内を確認してください。

<Checklist items={["学校からの案内に従い、必要な申請書類を準備する", "保護者等全員の所得（課税）状況を確認できる書類を用意する", "住民票のある市町・在学先に応じた申請方法を確認する", "私立高校在学の場合は大学私学課に問い合わせる"]} />

なお、(3)の国籍・在留資格要件に該当しなくても、(2)の(ア)(イ)区分に該当する場合は給付対象になることがあります。また(2)の所得区分に該当しなくても、家計急変により収入が急減した場合は給付対象になる可能性があります。詳細は福井県教育委員会教職員課にお問い合わせください。
