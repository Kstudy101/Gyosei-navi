福岡県高校生等奨学給付金（国公立高等学校向け）とは、すべての高校生等が安心して教育を受けられるよう、授業料以外の教育費（教科書費・教材費・学用品費・修学旅行費など）を支援する返還不要の給付金です。令和8年度は住民税非課税世帯の全日制・定時制在籍者に年額143,700円が最大で支給されます。

<SubsidyInfoCard />

## この記事の結論

- **返還不要の給付型**。授業料以外の教育費をカバーする
- 所得区分は最大5段階で、**住民税非課税世帯（全日制・定時制）が年額143,700円と最高額**
- 年収目安600万円相当の**多子世帯（専攻科のみ）**も対象に含まれる
- 通常給付の申請期限は**令和9年2月26日（金）**（県外校在籍者向け）
- 令和8年度の前倒し給付（7月24日締切）は**申請期限が終了**している

## 1. 対象者・支給条件

令和8年7月1日現在で、以下のすべての要件を満たす世帯が対象です。

<Checklist items={["生徒が高等学校等就学支援金（高校生等・新修学支援、学び直し支援金または専攻科支援金を含む）の受給資格を有していること", "下記の世帯区分（ア〜ウ）のいずれかに該当すること（ウは専攻科のみ）", "保護者等が福岡県内に住所を有していること"]} />

### 世帯区分（ア〜ウ）

| 区分 | 内容 |
|---|---|
| ア | 生活保護（生業扶助）受給世帯 |
| イ | 保護者全員の道府県民税所得割額および市町村民税所得割額の合算額が**182,500円未満**の世帯 |
| ウ（専攻科のみ） | 生計維持者全員の合算額が105,500円未満の世帯、または**105,500円以上264,500円未満の多子世帯** |

※多子世帯とは、市町村民税に係る生計維持者の扶養親族や特定扶養親族が3人以上であり、かつ生徒が生計維持者に扶養されている世帯をいいます。

※高校生等奨学給付金は、生活保護における収入認定から除外されます。

### 判定基準日

令和8年7月1日現在の世帯の状況で判定します。前倒し給付（新入生向け）は入学日時点の状況で判定します。

### 国籍要件

給付を受けるには、次のいずれかに該当することが必要です（専攻科の一部区分に適用）。日本国籍・特別永住者・永住者・日本人の配偶者等・永住者の配偶者等・定住者（将来永住意思あり）・家族滞在（小中卒業後、専攻科修了後に日本就労・在留継続意思あり）。国籍要件に該当しない場合でも、専攻科の一部区分では給付額が低い金額（10,100円等）で支給されます。

## 2. 支給額・計算方法

### 通常給付（令和8年度・1人あたり年額）

**全日制・定時制**

| 世帯区分 | 所得割額基準 | 給付年額 |
|---|---|---|
| 生活保護（生業扶助）受給世帯 | — | 32,300円 |
| 住民税非課税世帯 | 0円 | 143,700円 |
| 年収270〜380万円相当の世帯 | 105,500円未満 | 47,900円 |
| 年収380〜490万円相当の世帯 | 105,500円以上182,500円未満 | 35,930円 |

**通信制・専攻科**

| 世帯区分 | 所得割額基準 | 給付年額 |
|---|---|---|
| 生活保護（生業扶助）受給世帯 | — | 32,300円 |
| 住民税非課税世帯 | 0円 | 50,500円 |
| 年収270〜380万円相当の世帯 | 105,500円未満 | 16,830円（国籍要件非該当: 10,100円） |
| 年収380〜490万円相当の世帯（通信制のみ） | 105,500円以上182,500円未満 | 12,630円 |
| **年収380〜600万円相当の多子世帯（専攻科のみ）** | **105,500円以上264,500円未満** | **12,630円**（国籍要件非該当: 10,100円） |

※年収目安は「両親のうちどちらか一方が働き、高校生1人（16歳以上）・中学生1人の4人世帯」の目安です。所得は保護者（生計維持者）全員の道府県民税・市町村民税所得割額の合計で判定します。

### 前倒し給付（令和8年度・新入生向け）

> **注意: 令和8年度の前倒し給付申請期限（令和8年7月24日）は終了しています。** 以下は参考情報として掲載します。

入学時の負担軽減のため、新入生の希望者に対し給付金の一部（4〜6月分相当額）を早期に給付する制度です。

| 世帯区分 | 生徒区分 | 前倒し給付額 |
|---|---|---|
| 生活保護（生業扶助）受給世帯 | 全日制・定時制・通信制 | 8,075円 |
| 住民税非課税世帯 | 全日制・定時制 | 35,925円 |
| 住民税非課税世帯 | 通信制・専攻科 | 12,625円 |
| 所得割105,500円未満の世帯 | 全日制・定時制 | 11,975円 |
| 所得割105,500円未満の世帯 | 通信制・専攻科 | 4,207円（国籍要件非該当: 2,525円） |
| 所得割105,500円以上182,500円未満の世帯 | 全日制・定時制 | 8,982円 |
| 所得割105,500円以上182,500円未満の世帯（通信制） | 通信制 | 3,157円 |
| 所得割105,500円以上264,500円未満の多子世帯（専攻科） | 専攻科 | 3,157円（国籍要件非該当: 2,525円） |

### 支給回数の上限

| 在学形態 | 通算支給回数 |
|---|---|
| 全日制・定時制 | 年1回・通算3回 |
| 通信制 | 年1回・通算4回 |
| 専攻科 | 年1回・通算2回（修業年限1年の場合は1回） |

※高等学校等学び直し支援金の対象者は、上記に加えて1回（定時制・通信制は最大2回まで）給付されます。

### 家計急変世帯への給付

保護者等の収入が急変し、急変後1年間の年収見込額が対象世帯に相当すると認められる場合は給付対象になります（生活保護（生業扶助）受給世帯は除く）。令和8年7月2日以降に家計が急変した場合は、急変翌月以降の月数に応じた按分額となります。家計急変分の申請期限は令和9年2月26日です。

## 3. 申請方法・必要書類

申請方法は在学する高校の所在地によって異なります。

| 在学先 | 申請方法 |
|---|---|
| 福岡県内の公立高等学校等・国立高等専門学校等 | 学校から申請書類が配布されます。在学する学校へお問い合わせください |
| 福岡県外の公立・国立高等学校等 | 福岡県教育庁 財務課学校予算係に直接申請書類を郵送 |

### 私立高等学校に通われている方

私立高等学校等の奨学給付金は、**福岡県庁の私学振興・青少年育成局私学振興課修学支援係**が別途担当しています。本記事の制度とは異なりますので、私立高校に通われている方は各自ご確認ください。

### 保護者等が福岡県外に在住の方

奨学給付金は保護者等が在住している都道府県に申請する必要があります。保護者等が福岡県外に在住の場合は、在住する都道府県に問い合わせてください。
