文京区は、小・中学校でかかる費用の支払いに困る世帯へ**就学援助**を実施しています。生活保護受給世帯（要保護）に加え、これに準ずると教育委員会が認める世帯（準要保護）も対象です。高校生以上の費用は本制度の対象外です。

<SubsidyInfoCard />

## この記事の結論

- 所得目安は2人世帯で**約351万円**、3人で**約437万円**、4人で**約477万円〜約508万円**、5人で**約571万円**（前年所得）
- 新入学用品費は小学校**91,600円**、中学校**101,000円**
- 通常受付は**4月6日〜4月30日**。以降も随時だが、受付月分からの認定

## 1. 対象者・所得の目安

次のすべてに当てはまる必要があります。

1. **文京区内に住んでいる**こと
2. 子どもが**小・中学校**に在籍していること（高校生以上は対象外）
3. 次のいずれかに該当すること
   - 現在、生活保護を受けている（要保護）
   - 生活保護は受けていないが、これに準ずると教育委員会が認める（準要保護）

要保護の方・前年度受給者も、毎年度の申請が必要です。

### 所得基準額の目安（前年所得）

| 世帯人員 | 家族構成の例 | 目安額 |
|---|---|---|
| 2人 | 父44歳・子中2 | 約351万円 |
| 3人 | 父43歳・母46歳・子中2 | 約437万円 |
| 4人 | 父43歳・母43歳・子中2・子3歳 | 約477万円 |
| 4人 | 父47歳・母41歳・子中2・子小3 | 約508万円 |
| 5人 | 父48歳・母48歳・子中2・子小6・子小4 | 約571万円 |

<Callout type="warning">
上記は公式が示す目安です。家族構成の基準日は令和8年4月1日、年齢は令和8年1月1日時点です。住民登録上の同一世帯（兄弟・祖父母等）の所得も合算されます。事前問い合わせでも認定基準所得額の計算はできません。
</Callout>

所得は原則として前年分です（令和7年度申請なら2024年1月〜12月）。給与所得は「給与所得控除後の金額（調整控除後）」、事業所得は必要経費控除後の所得金額を用います。特別な事情で前年所得以外での審査を希望する場合は、申請時にその旨を回答し、後日区の確認を受けます。

## 2. 支給される費用

支給は**7月末・12月末・3月末**です。国・都立および文京区外の公立校在籍者は、学習支援費以外の費用がすべて3月末支給となります。実費項目は後払いです。

| 費目 | 対象 | 金額 |
|---|---|---|
| 学校給食費 | 全学年（※国立のみ） | 実費 |
| 学習支援費 | 小1／小2〜6／中1／中2・3 | 37,866円〜1,305円／41,056円〜1,570円／64,626円〜2,535円／68,586円〜2,865円 |
| 新入学用品費 | 小学校就学前・小1／小6・中1 | 91,600円／101,000円 |
| 修学旅行費 | 中2（中3） | 65,000円 |
| 夏季施設参加費 | 小6 | 実費 |
| 移動教室参加費 | 小5・6 | 実費 |
| 遠足費・校外授業費 | 全学年 | 実費 |
| 卒業アルバム補助 | 小6／中3 | 11,000円／8,800円 |
| 通学費 | 条件該当者 | 実費 |
| PTA会費（加入者のみ） | 小／中 | 3,450円／4,260円 |
| 体育実技用具費 | 中1・2 | 実費（上限7,860円） |

<Callout type="info">
給食費無償化に伴い、就学援助の給食費対象は**国立学校在籍者のみ**です。生活保護（要保護）の方は、表中◎印の費用を福祉部生活福祉課から支給します。私立小・中学校は学習支援費（クラブ活動費相当・通信費相当額を除く）と新入学用品費のみです。
</Callout>

学習支援費の内訳は学用品費・通信費・通学用品費・クラブ活動費（中学の部活動加入者のみ）で、**申請月により金額が変わります**。新入学用品費は入学前支給が原則ですが、未受給かつ4月からの認定の場合に限り入学後も支給されます。入学前に区外転出予定の方は対象外です。

### 小学校新入学用品費の入学前支給（別案内）

令和8年4月小学校入学向けの入学前支給（91,600円）は、公式ページ上**申請受付終了**です。入学後の学用品費等は本記事の就学援助申請で対応します。

## 3. 申請方法・スケジュール

<Checklist items={["LoGoフォーム（オンライン）で申請する（学校への提出は不可）", "通常受付は4月6日〜4月30日。以降は随時だが受付月分から認定", "通帳・キャッシュカードなど口座情報が分かるものを用意する", "令和8年1月2日以降の転入者は住民税課税通知または課税（非課税）証明書を提出", "税申告未済だと審査保留になるため、無収入でも原則申告する", "4月中申請の認定結果は6月末までに通知（4・5月申請分は令和8年6月30日発送済み）"]} />

申請後のLoGoフォーム上での修正・削除・再申請はできません。内容変更や取り下げは受付期間内に学校運営課学事係へ連絡します。メンテナンスや通信障害を理由とした期限超過の個別対応はありません。

### 通学費の対象（実費）

- 指定校変更・区域外就学で、小学生は片道4km以上、中学生は6km以上
- 特別支援学級・学校在籍で交通機関を利用している方（距離不問）

## まとめ

文京区の就学援助は、区在住の小・中学生世帯を対象に学用品・入学準備・修学旅行などを援助する制度です。所得目安は世帯構成で約351万円〜約571万円、申請はLoGoフォームのみです。最新の要件・金額は文京区公式ページで確認してください。

お問い合わせ：教育推進部学校運営課学事係（文京シビックセンター20階南側）電話 03-5803-1295
