就学援助制度とは、経済的にお困りの小・中学生の保護者を対象に、学校給食費・学用品費・修学旅行費など学校で必要なお金の一部を奈良市が援助する制度です。支給には審査があります。

<SubsidyInfoCard />

## この記事の結論

- 所得めやすは2人世帯（母子・父子）で約211万円、4人世帯（父・母・子）で約303万円など。児童扶養手当受給世帯も対象
- **新入学学用品費は小学1年生64,300円・中学1年生81,000円**（4月認定の1年生）
- **奈良市立中学校は給食費無償化**のため、就学援助からの給食費支給なし（小学校給食費は実費援助）
- 令和8年度の当初受付は令和8年6月3日〜7月3日。その後も**最終受付は令和9年3月15日**まで随時受付

## 1. 対象者・認定基準

対象は、経済的にお困りの小・中学生の保護者です。次のいずれかに該当する場合に審査・認定されます。

### (1) 所得が認定基準額（めやす）以下

同一生計のご家族全員の令和7年中（1月〜12月）の所得合計が下表以下であることがめやすです。

| 世帯人数 | 基準額（令和7年1月〜12月の世帯全員の所得合計） |
|---|---|
| 2人世帯（母子・父子） | 211万円程度 |
| 3人世帯（父・母・子） | 262万円程度 |
| 3人世帯（母子・父子） | 266万円程度 |
| 4人世帯（父・母・子） | 303万円程度 |
| 5人世帯（父・母・子） | 330万円程度 |
| 6人世帯（父・母・子） | 400万円程度 |

- 給与所得および公的年金等所得の合計が10万円以上ある場合、合計所得金額から10万円を差し引いた額を判定所得として用います
- 自営業の場合は、売り上げから必要経費を除外した額を判定所得とします
- 世帯の年齢等により認定基準が上下します。該当するか分からない場合でも申請可能です

### (2) 児童扶養手当を受給している方

一部支給を含む児童扶養手当の受給者も対象です。所得制限限度額の詳細は奈良市の児童扶養手当ページおよび就学援助案内を参照してください。

<Callout type="info">
生活保護（教育扶助）を受給中の方は、必要な費用が保護費から支給されているため就学援助の申請は原則不要です。修学旅行費のみ支給対象で、実施後に学校から必要書類が配布されます。生活保護が停止・廃止された場合に就学援助を希望するときは申請が必要です。
</Callout>

## 2. 援助の内容（令和8年度・4月認定の場合）

| 費目 | 内容 |
|---|---|
| 学用品費 | 小1: 1学期4,400円・2学期5,500円・3学期3,330円／小2〜6: 5,160円・6,450円・3,890円／中1: 8,320円・10,400円・6,320円／中2〜3: 9,080円・11,350円・6,880円 |
| 新入学学用品費 | 小1: 64,300円、中1: 81,000円（4月を認定月に含む1年生。入学前に新入学準備金を受給した場合は差額のみ） |
| 学校給食費 | 実費。**奈良市立中学校在籍は給食費無償化のため保護者への支給なし** |
| 校外活動費（宿泊あり） | 小: 上限3,690円、中: 上限6,210円（年2回以上ある場合は高額な1回分のみ） |
| 修学旅行費 | 実費（上限20万円以下・対象経費に限る。小・中それぞれ1回限り） |
| 新入学準備金 | 小学6年生: 81,000円（2月1日現在奈良市在住で3月を認定月に含む方。受給すると翌年度の新入学学用品費は対象外） |
| 医療費 | 学校保健安全法施行令第8条の対象疾病の自己負担額（他の医療費助成で未支給の場合） |

支給時期の目安は、学用品費が1学期分8月末・2学期分1月末・3学期分4月下旬、新入学学用品費が8月末、新入学準備金が3月上旬です（予定であり変更の場合があります）。学年途中からの認定では費目・金額が変わります。

<Callout type="warning">
小学校の給食費は、認定確定までの4〜6月分が引き落とされたうえで返還される仕組みです。令和8年7月3日までに申請した市立小学校在籍者は、申し出により6月分の徴収猶予が可能です（「学校給食費支払猶予申請書」を教育総務課へ提出）。令和7年度受給者は自動的に支払猶予され、別途申請は不要です。
</Callout>

## 3. 申請方法・必要書類

| 項目 | 内容 |
|---|---|
| 当初受付 | 令和8年6月3日（水）〜7月3日（金）※この期間の申請は4月認定 |
| 随時受付・最終期限 | 7月4日以降も受付。**最終受付期限は令和9年3月15日（月）** |
| 受付窓口 | オンライン・奈良市教育総務課（市役所北棟3階）・通学する奈良市立小・中学校。出張所・行政センター・連絡所では不可。教育総務課への郵送可 |
| オンライン申請 | [ロゴフォーム](https://logoform.jp/form/p6et/1528087)（公開期間: 令和8年6月3日〜令和9年3月15日） |

### 申請に必要なもの

1. 保護者名義の普通預金通帳またはキャッシュカード（振込先口座が確認できるもの）
2. 申請書（教育総務課窓口で配布、またはHPからダウンロード可）
3. 令和8年1月1日現在に奈良市外在住・単身赴任中などだった場合: 令和8年度課税証明書（市在住なら添付不要。後日提出可）
4. 児童扶養手当受給者: 児童扶養手当証書の写し

令和7年度に就学援助または新入学準備金（入学前支給）を受給していた方は原則再申請不要です。小学校6年生のときに奈良市の就学援助を受給していた中学1年生も申請不要です。一方、兄姉が受給していても新小学校1年生については別途申請が必要です。
