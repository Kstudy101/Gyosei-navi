杉並区は、経済的な理由で義務教育の就学が難しい子どもの保護者へ、学用品費や入学準備金などの**就学援助**を支給しています。生活保護（教育扶助）の受給世帯に加え、所得が認定基準額以下の世帯や、災害・失業などで収入が急に減った世帯も対象になります。

<SubsidyInfoCard />

## この記事の結論

- 所得目安（認定基準額）は2人世帯で**約332万円**、3人**約370万円**、4人**約435万円**、5人**約459万円**（前年の総所得）
- 入学準備金は小学校**53,870円**、中学校**59,040円**（4月認定）
- 申請は**随時**。支給は申請月分から。認定結果は**7月以降**に郵送

## 1. 対象者・所得の目安

次のいずれにも当てはまる必要があります。

1. **杉並区に住んでいる**こと
2. 子どもが**国公立**の小・中学校に通学していること
3. 子どもと**同居**している保護者であること
4. 次のいずれかに該当すること
   - 現在、生活保護（生活保護法による教育扶助）を受けている
   - 前年4月1日以降に、生活保護が停止・廃止になった
   - 前年（1月から12月）の世帯員全員の総所得金額の合計が、教育委員会の認定基準額以下
   - 災害・失業などの事情で収入が著しく減少し、学費等の負担が困難であることが明らか

### 認定基準額の目安（前年の総所得）

| 世帯人数 | 認定基準額（目安） | 【参考】給与収入額 |
|---|---|---|
| 2人 | 約332万円 | 約483万円以下 |
| 3人 | 約370万円 | 約530万円以下 |
| 4人 | 約435万円 | 約611万円以下 |
| 5人 | 約459万円 | 約641万円以下 |

<Callout type="warning">
金額は家族構成や世帯員の年齢等により各世帯で変わります。あくまでモデルケースの目安です。総所得金額は年収そのものではありません。給与所得のみの場合は、令和7年分源泉徴収票の「給与所得控除後の金額」から10万円を控除した額で審査します。
</Callout>

審査の対象となる所得は、令和7年（2025年）1月〜12月の世帯全員の総所得金額です。該当するか分からない場合でも、希望すれば申請できます。

## 2. 支給される費用

令和8年度の費目別支給額表（区立校向けの定額）の主な内容は次のとおりです。

| 費目 | 対象 | 支給内容 |
|---|---|---|
| 学用品費 | 小学・全学年 | 年額9,860円（7・9・11・1・3月末頃に分割） |
| 学用品費 | 中学・全学年 | 年額34,410円（同上） |
| 入学準備金 | 小1（4月認定） | 53,870円 |
| 入学準備金 | 中1（4月認定） | 59,040円 |
| 入学準備金 | 小6（中学進学予定） | 59,040円を翌年3月に支給（国公立中） |
| 学校行事費 | 中学・全学年 | 年額7,370円 |
| 移動教室費 | 小5・6／中1・2など | 保護者負担相当額90,000円以内 |
| 修学旅行費 | 中3 | 保護者負担相当額90,000円以内 |
| 卒業アルバム費 | 小6・中3 | 実費 |
| 体育実技用具費 | 中学（柔道・剣道） | 柔道7,650円／剣道52,900円以内の実費（在学中1回） |
| 学校生活管理指導表作成費 | 小・中 | 定額3,000円 |
| 給食費 | 小・中 | 実費（無償化の場合は支給なし） |
| 医療費 | 学校病 | 実費（受診前に学校病医療券が必要） |

支給時期の目安は**7月末・9月末・11月末・1月末・3月末**頃です。兄弟姉妹で申請者が同じ場合は、その回の合計額を一括振込します。

<Callout type="info">
生活保護を受けている場合、学用品費・学校行事費・体育実技用具費・学校生活管理指導表作成費・入学準備金・給食費などは福祉事務所から支給され、就学援助からは下線対象の費目のみとなる旨が費目表に注記されています。入学準備金（1年生）は4月認定者のみです。
</Callout>

区外校や国立・都立に通う場合は、学用品費の金額差を3月に調整支給する、学校行事費の扱いが異なるなどの違いがあります。詳細は区外校向け案内PDFと費目表の注意書きを確認してください。

## 3. 申請方法・期限

- **申請は随時可能**です。支給は**申請月分から**です（例：5月申請→5月分から）。
- 認定の可否は**7月以降**、保護者宛てに郵送で通知されます（在籍校にも通知）。
- **区立学校**在籍者：就学援助の希望調査票で希望するにチェックし、申請書・委任状を記入して**学務課または学校**へ提出。
- **区外校**在籍者：申請書・委任状を記入し、**学務課へ郵送または持参**。
- 前年度に受給していても、毎年度の申請が必要です。
- 郵送申請の場合、学務課に届いた月が申請月になります。

転出・婚姻・離婚・死亡などによる保護者変更、転居・転校、振込口座の変更、受給辞退があったときは届出が必要です。杉並区外へ転出した場合、杉並区からの支給は転出月分までです。転出先でも受給を希望するときは、転出先の区市町村で改めて申請してください。

## 4. 入学前の入学準備金

- **小学校就学予定**：入学準備金を国公立小学校入学前（3月）に支給。案内と申請書は12月中旬に保護者へ送付。希望者のみ学務課就学奨励担当へ申請。生活保護世帯は福祉事務所から支給。
- **中学校就学予定（小学6年生）**：令和8年度就学援助の認定を受け、国公立中学校へ進学予定の場合、中学校入学前（3月）に支給。
