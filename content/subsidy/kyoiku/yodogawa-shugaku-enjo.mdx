大阪市就学援助制度とは、経済的な理由により就学が困難な**大阪市立の小・中・義務教育学校に通学する児童生徒の保護者**を対象に、学校教材費・給食費・修学旅行費などをはじめとした就学にかかる費用を補助する制度です。淀川区は大阪市の行政区であるため、独自の制度ではなく大阪市全域共通の制度として同じ条件で申請できます。

## この記事の結論

- 淀川区内の大阪市立学校に通う児童生徒の保護者が対象（大阪市全域共通制度）
- 給食費・教材費・修学旅行費・入学準備補助金など**複数の費目を補助**
- 対象は市民税非課税・児童扶養手当受給など**12種類の申請理由**のいずれかに該当する世帯
- **6月末までに申請すれば4月1日認定**（7月以降は申請日以降の認定）
- 申請は在籍する学校（または入学予定の学校）に提出

## 1. 制度の位置づけ——なぜ「淀川区の制度」でも申請できるのか

淀川区は大阪市の行政区であり、独立した基礎自治体ではありません。就学援助制度は大阪市教育委員会が所管する**大阪市全域共通の制度**です。淀川区内の大阪市立学校（小学校・中学校・義務教育学校）に通学する児童生徒の保護者は、他の23区の住民と同じ条件・同じ手続きでこの制度を利用できます。

## 2. 援助の内容

大阪市の就学援助では、次の費目が補助対象となっています（大阪市公式ページ記載）。

| 援助費目 | 内容 |
|---|---|
| 学校教材費 | 学校で使うドリルや実験の材料など |
| 校外活動費 | 林間学習・一泊移住など |
| 修学旅行費 | 修学旅行にかかる費用 |
| 入学準備補助金 | ランドセル・体操服など入学時の準備費用 |
| 学校給食費 | 給食にかかる費用 |
| 日本スポーツ振興センター共済掛金（保護者負担額） | 学校災害共済の保護者負担分 |

<Callout type="info">
各費目の具体的な支給単価は、大阪市教育委員会が毎年度発行する「就学援助制度のお知らせ（PDF）」に記載されています。金額は毎年度改定されることがあるため、必ず公式PDFで最新版をご確認ください。
</Callout>

## 3. 対象世帯・申請理由

次の①〜⑫のいずれかに該当する世帯が対象です（大阪市公式ページ記載）。

| 申請理由 | 内容 |
|---|---|
| ① | 市民税が非課税の方（所得割額・均等割額がともに0円） |
| ② | 固定資産税を減免された方（火災・地震等の災害による減免） |
| ③ | 個人事業税を減免された方 |
| ④ | 国民年金保険料を減免された方（保護者全員が減免対象） |
| ⑤ | 国民健康保険料を減免または徴収猶予された方（保護者全員） |
| ⑥ | 児童扶養手当の支給を受けている方（児童生徒が支給対象の場合） |
| ⑦ | 生活福祉資金の貸付決定を受けた方（令和7年4月1日以降の決定） |
| ⑧ | 雇用保険被保険者手帳をお持ちの日雇労働者の方 |
| ⑨ | 火災・風水害・震災その他の災害にあった方 |
| ⑩ | 生活保護を停止または廃止された方 |
| ⑪ | 生活保護を受けている方 |
| ⑫ | 上記①〜⑪に該当しないが、経済的に困窮し所得基準額以下の方（所得審査あり） |

<Callout type="warning">
申請理由⑫は世帯人数・住宅の所有状況に応じた所得基準額以下であることが条件です。具体的な所得基準額は毎年度の「就学援助制度のお知らせ（PDF）」に掲載されており、今回確認した公式ページ（HTML）には金額の記載がありませんでした。申請の際は必ず最新の案内PDFをご確認ください。
</Callout>

## 4. 申請方法

<Checklist items={["在籍する学校（または入学予定の学校）で配付される「就学援助制度のお知らせ」を受け取る", "申請書（就学援助申請書兼世帯状況票）に必要事項を記入し、必要な証明書類を添付する", "在籍する（または入学予定の）大阪市立の小・中・義務教育学校に直接持参または送付で提出する", "6月末までに申請すると、認定日は4月1日になる（7月以降は申請日以降の認定）"]} />

申請書はPDFで大阪市公式ページからもダウンロードできます。きょうだいが異なる学校に通っている場合は、**通学する学校ごとに1枚ずつ**申請書が必要です。

### 申請期限と認定日

| 申請区分 | 申請期限 | 認定日 |
|---|---|---|
| 一般（早期含む） | 令和8年6月30日まで | 令和8年4月1日 |
| 随時申請 | 7月1日以降も受付 | 申請日以降（4月にさかのぼれない） |

<Callout type="info">
申請は毎年度必要です。前年度に認定を受けていても、自動的に継続されるわけではありません。
</Callout>
