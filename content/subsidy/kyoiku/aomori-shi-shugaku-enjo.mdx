就学援助とは、経済的な理由で学用品費などの支払いに困るなど、就学が困難と認められる児童生徒の保護者に対して、青森市が就学に必要な経費の一部を援助する制度です。令和8年度の支給額には、学用品費・新入学学用品費に加え、スキー用具購入向けの体育実技用具費（3年に1回）が含まれます。

<SubsidyInfoCard />

## この記事の結論

- 学用品費等は**小学校1年生13,230円／2〜6年生15,500円**、**中学校1年生25,040円／2・3年生27,310円**（定額）
- 新入学学用品費は**小学校64,300円・中学校81,000円**（定額）
- **体育実技用具費**としてスキー用具購入費を**小学校26,500円・中学校38,030円**（3年に1回・定額）
- 申請は**年度ごと**。新規は随時、在籍する小・中学校へ提出

## 1. 対象者・支給条件

対象は、次のいずれかに該当するかたです。

- 青森市に住所を有し、小・中学校に在籍する児童生徒の保護者
- 青森市外に住所を有し、青森市立の小・中学校に在籍する児童生徒の保護者

さらに、次の**1または2**のどちらかに該当する必要があります。

1. **生活保護を受給中である**
2. **認定要件（ア〜サのいずれか）に該当する**

| 区分 | 認定要件（概要） |
|---|---|
| ア | 前年度または当該年度中に生活保護が停止または廃止になった |
| イ | 市民税が非課税である |
| ウ | 市民税が減免されている |
| エ | 個人の事業税が減免されている |
| オ | 固定資産税が減免・免除されている |
| カ | 国民年金の掛金が減免されている |
| キ | 国民健康保険の保険税が減免または猶予されている |
| ク | 児童扶養手当の支給を受けている |
| ケ | 生活福祉資金の貸付を受けている |
| コ | 世帯の総収入額が少なく経済的に困っている |
| サ | 事故・災害・長期入院・失職の影響による減収など、その他の理由で経済的に困っている |

### 収入基準額の目安（令和8年度・コ／サの場合）

申請理由が「コ」または「サ」の場合は収入審査があり、同一世帯全員分の**令和6年中**（2024年1月1日〜12月31日）の年間総収入額が収入基準額以下のかたが認定となります。下表は申請のための目安であり、世帯の人数や年齢によって実際の基準額は異なります。

| 世帯員数 | 世帯構成例（年齢は令和8年4月1日時点） | 収入基準額（目安） |
|---|---|---|
| 2人 | 父または母(40歳)、子(6歳) | 約254万円以下 |
| 3人 | 父または母(40歳)、子(6歳)、子(3歳) | 約309万円以下 |
| 3人 | 父(40歳)、母(40歳)、子(6歳) | 約312万円以下 |
| 4人 | 父(40歳)、母(40歳)、子(6歳)、子(3歳) | 約354万円以下 |
| 4人 | 父(40歳)、母(40歳)、子(12歳)、子(6歳) | 約371万円以下 |
| 5人 | 父(40歳)、母(40歳)、子(12歳)、子(6歳)、子(3歳) | 約406万円以下 |
| 5人 | 父(40歳)、母(40歳)、子(15歳)、子(12歳)、子(6歳) | 約433万円以下 |
| 6人 | 父(40歳)、母(40歳)、子(15歳)、子(12歳)、子(6歳)、祖父母(75歳) | 約489万円以下 |

年間総収入額には給与収入や事業所得のほか、年金・失業保険・退職金などの収入をすべて含みます。単身赴任などで別世帯となっている保護者の収入も含みます。申請前の収入基準額の試算は行われていません。

<Callout type="warning">
「児童扶養手当」は「児童手当」や「特別児童扶養手当」とは別の制度です。申請理由「ク」では児童扶養手当証書（有効期限内）の写しが必要です。
</Callout>

## 2. 支給額・計算方法

令和8年度の主な支給内容は次のとおりです。

| 費目 | 小学校 | 中学校 | 対象費用 |
|---|---|---|---|
| 学用品費等 | 1年生 13,230円／2〜6年生 15,500円 | 1年生 25,040円／2・3年生 27,310円 | 学用品・通学用品の購入費用及び校外活動（宿泊なし）の参加費用（定額） |
| 新入学学用品費 | 1年生 64,300円 | 1年生 81,000円 | 新入学にかかる学用品・通学用品の購入費用（定額） |
| 体育実技用具費 | 26,500円 | 38,030円 | スキー用具の購入費用として3年に1回支給（定額） |
| 修学旅行費 | 実費額 | 実費額 | 交通費・宿泊費・見学料等の一部 |
| 校外活動費（宿泊あり） | 実費額（上限3,690円） | 実費額（上限6,210円） | 交通費・見学料の一部 |
| 通学費 | 定期券購入実費額 | 定期券購入実費額 | 公共交通機関の定期代 |
| 医療費 | 免除（医療券交付） | 免除（医療券交付） | 学校より指示のあった特定疾病（結膜炎・中耳炎・う歯等）の治療費 |
| 日本スポーツ振興センター共済掛金 | 免除 | 免除 | 共済掛金の保護者負担額 |

体育実技用具費・修学旅行費・校外活動費・通学費には支給要件があります。医療費は交付された医療券を医療機関に提示することで無料受診できます。翌年度の支給額は変更となる場合があります。

### 世帯・在籍区分による支給費目の違い

| 区分 | 支給される費目 |
|---|---|
| 生活保護を受給している世帯 | 修学旅行費、医療費、日本スポーツ振興センター共済掛金 |
| 私立中学校在籍の生徒 | 学用品費、新入学学用品費、体育実技用具費 |
| 区域外就学（市外住所・市内公立小中在籍） | 医療費、日本スポーツ振興センター共済掛金 |
| 区域外就学（市内住所・市外公立小中在籍） | 学用品費、新入学学用品費、体育実技用具費、修学旅行費、校外活動費 |

<Callout type="info">
就学援助で修学旅行費が支給されない児童生徒向けに、別制度として「青森市修学旅行費補助金」（令和8年度は小学生上限3万5千円・中学生上限6万6千円）があります。就学援助または他制度で修学旅行費の補助・免除を受ける場合は対象外です。
</Callout>

## 3. 申請方法・必要書類

申請は『就学援助費申請書』に必要事項を記入し、『申請理由を証明する書類』と『振込通帳の写し』を添付のうえ、**就学している小・中学校**へ提出します。認定の可否は教育委員会で決定後、学校から知らせがあります。

申請書類は公式ページの添付ファイル（令和8年度就学援助申請書類PDF）からダウンロードできます。

### 申請時期

| 区分 | 時期 |
|---|---|
| 新入学児童生徒 | 4月上旬 |
| 在校児童生徒（年度更新） | 11月中旬〜1月下旬 |
| 新規申請 | 随時 |

年度ごとに申請が必要です。小学生と中学生がいる場合は、それぞれの学校で申請します。新1年生は入学後の申請となります。

<Checklist items={[
  "就学援助費申請書（公式ページ添付の令和8年度様式）",
  "申請理由を証明する書類（非課税・減免通知・児童扶養手当証書の写しなど。理由により異なる）",
  "振込通帳の写し",
  "生活保護受給中の場合は同意書（担当課へ。申請自体は不要）"

年度途中に市外へ転校する場合、就学援助を辞退する場合、生活保護開始となった場合などには、事前に支給している費目の一部（学用品費の月割り分等）が返納となります。
