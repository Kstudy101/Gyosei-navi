目黒区は、ご家庭の事情に応じて、小・中学校の就学に必要な経費の一部を**就学援助費**として支給しています。学用品費・給食費・修学旅行費などが対象です。特別支援学級・通級向けの**就学奨励費**は別制度です。

<SubsidyInfoCard />

## この記事の結論

- 所得限度額（目安）は2人世帯**290万円**、3人**350万円**、4人**410万円**、5人**480万円**、6人**530万円**（令和7年中の世帯合計所得）
- 令和8年度より**家賃書類は不要**。限度額に家賃相当額を加算し対象を拡充
- 通常申請期限は**令和8年5月29日**。最終受付は**令和9年2月26日**（申請月分から・金額減）

## 1. 対象者・所得の目安

次の申請要件の**すべて**に該当するかたが申請できます。

1. **目黒区在住**であること
2. 子どもが**国公立**の小・中学校（義務教育学校の前期・後期課程、中等教育学校の前期課程を含む）に通っていること
3. 次の申請理由（受給要件）のいずれかに該当すること

**私立学校・インターナショナルスクール・特別支援学校は対象外**です。

### 申請理由（受給要件）

| 区分 | 内容 |
|---|---|
| 1 | 生活保護を受けており、小学6年生から中学3年生を扶養している（中学1・2年生は、独自宿泊事業に参加予定の生徒のみ対象） |
| 2 | 令和7年度または8年度に、生活保護の廃止・停止を受けた |
| 3 | 国民年金保険料を減額または免除されている（法定免除を除く） |
| 4 | 児童扶養手当の支給を受けている |
| 5 | 災害等を受けた（申請日から遡って半年以内） |
| 6 | 経済的にお困りで、令和7年中の世帯合計所得が下表の限度額以下 |

申請理由1〜6のいずれにも該当しない場合でも、失業・疾病などで収入が著しく減り、直近3カ月の収入から算出した1年間の所得見込額が限度額以下なら、証明書類により申請できる場合があります。学校運営課へ相談してください。

### 世帯の所得限度額（目安・令和7年中）

| 世帯構成 | 所得限度額 |
|---|---|
| 2人世帯 | 290万円 |
| 3人世帯 | 350万円 |
| 4人世帯 | 410万円 |
| 5人世帯 | 480万円 |
| 6人世帯 | 530万円 |

<Callout type="warning">
限度額はあくまで目安です。世帯構成員の年齢や学年によって認定・却下が変わることがあります。少し超えていても、迷う場合は申請してください（公式Q&A）。
</Callout>

令和8年度より、家賃（地代）の支払い有無による所得限度額の変動はありません。全世帯の限度額に昨年度までの家賃相当額を加算する形で、支給対象を拡充しています。賃貸契約書などの提出も不要です。

- **世帯**とは、昨年12月31日時点で生計を同じくする家族
- **所得額**とは、源泉徴収票の「給与所得控除後の金額」、または確定申告書の「12所得金額合計」欄の金額

## 2. 支給される費用

お子様にかかる次の費用の**一部**を援助します。振込時期や支給金額は、認定通知書に同封する「支給予定表」で確認してください。

| 費目 |
|---|
| 学用品費・通学用品費 |
| 学校給食費 |
| 校外行事費 |
| 入学支度金（小学1年生・中学1年生） |
| 修学旅行・自然宿泊体験教室などの経費 |
| 卒業記念アルバム費 |

<Callout type="info">
学校に支払う額やかかった費用の全額を援助することはできません。不足額は自己負担です。生活保護を受けている場合、生活保護費から支給される費目は就学援助の対象外です。保護者負担がない場合も支給はありません。
</Callout>

各費目の個別円額は、公式ページ・申請案内PDFには掲載されていません。認定後の支給予定表を参照してください。

## 3. 申請方法・期限

### 申請方法

次のいずれかで申請します。

1. **オンライン電子申請** — 公式ページの申請フォーム（または二次元コード）から。必要書類は画像添付可
2. **郵送または持参** — 申請書に必要事項を記入し、必要書類を添付

郵送・持参先：〒153-8573 目黒区上目黒二丁目19番15号 目黒区教育委員会事務局学校運営課学事係（総合庁舎5階）

### 必要な書類

- 令和8年度就学援助費受給申請書
- 保護者名義の通帳またはキャッシュカードのコピー
- 申請理由を証明する書類（下表。理由6「経済的に困っている」は原則不要）

| 申請理由 | 書類 |
|---|---|
| 国民年金保険料の減免 | 国民年金保険料免除・納付猶予申請承認通知書のコピー（申請時点で有効） |
| 児童扶養手当の受給 | 児童扶養手当証書のコピー（申請時点で有効） |
| 災害等 | 罹災証明書または被災証明書のコピー（申請日から遡って半年以内） |
| 経済的に困っている | 原則不要 |

令和8年1月2日以降に目黒区へ転入したかた、またはご家族が目黒区外に住んでいるかたは、令和8年度住民税課税（非課税）証明書（平成19年4月1日生まれ以前の世帯員分・合計所得金額の記載あり）が必要です。通常6月ごろ発行のため、取得後**令和8年6月30日（金）まで**に申請してください（この期限内なら支給金額には影響しません）。

### 申請期限（令和8年度）

| 区分 | 期限 | 取り扱い |
|---|---|---|
| 通常 | 令和8年5月29日（金） | — |
| 期限後 | 令和8年7月17日（金）まで | 支給金額は変わらないが支給時期が遅れる |
| 最終受付 | 令和9年2月26日（金）まで | 申請した月分から支給・支給金額が減る |

期限までに郵送・来庁で必着、またはオンラインで送信完了してください。年度途中に目黒区へ転入したかたは、**転入日から1か月以内**に申請してください。

審査結果は、申請された月の翌月下旬ごろに郵送されます。

## 4. 就学奨励費との違い

特別支援学級に在学・通級しているお子さんの家庭向けに、給食費・学用品費・通学費などを援助する**就学奨励費**もあります。就学援助とは別制度です。詳細は目黒区の就学奨励費ページを確認してください（ページ更新日が古い場合があるため、最新の扱いは学校運営課へ問い合わせるのが確実です）。
