千代田区は、生活保護受給世帯や、それに準ずると教育委員会が認める世帯（準要保護）を対象に、小中学生の学用品費・給食費などを補助する就学援助制度を実施しています。

<SubsidyInfoCard />

## この記事の結論

- 対象は生活保護受給世帯、または区教育委員会が認める準要保護世帯
- 支給項目は学用品費・修学旅行費など**9項目**
- 令和8年度の申請期限は**令和8年6月5日**（期限後も随時申請可能）

## 1. 対象者・所得の目安

千代田区に居住し、小中学校（義務教育学校・中等教育学校前期課程を含む）に通う子どもの保護者が対象です。次のいずれかに該当する必要があります。

- 生活保護受給世帯
- 生活保護受給世帯に準ずると教育委員会が認める世帯（準要保護）

インターナショナルスクール・フリースクールなど学校教育法第1条に該当しない学校の在籍者は対象外です。

### 所得基準額の目安（令和7年中所得、モデルケース）

| 世帯構成 | 目安額 |
|---|---|
| 2人世帯（母35歳・子6歳） | 約234万円 |
| 3人世帯（父34歳・母32歳・子7歳） | 約263万円 |
| 4人世帯（父35歳・母33歳・子9歳・子7歳） | 約318万円 |

<Callout type="warning">
上記はあくまで「目安」です。賃貸住宅に居住している場合は加算があり（上限あり）、実際の判定は世帯構成・年齢等に応じて個別に行われます。5人以上の世帯のモデルケースは公式資料に記載がないため、対象になるか不明な場合は窓口に直接確認してください。
</Callout>

## 2. 支給項目

| 項目 |
|---|
| 学用品・通学用品購入費 |
| 新入学児童生徒学用品・通学用品購入費（入学準備金） |
| 校外活動費 |
| 移動教室参加費 |
| 夏季施設参加費 |
| 修学旅行費（中学生のみ） |
| 学校給食費 |
| 卒業記念アルバム費 |
| 医療費 |

千代田区立学校の在籍者は給食費無償化の対象となっており、就学援助費からの給食費支給は予定されていません（別途、給食費補助制度で対応）。

## 3. 申請方法・スケジュール

<Checklist items={["千代田区ポータルサイトでオンライン申請する（口座登録後に「就学援助費申請」手続き）", "令和8年度分は令和8年6月5日（金）までに申請する", "審査結果は例年7月中旬以降に郵送で通知される", "支給は年2回（例年7月下旬頃・翌年4月中旬頃）、保護者口座に振り込まれる"]} />

期限を過ぎても、申請月分からの援助を受けられる場合があるため随時申請を受け付けています。
