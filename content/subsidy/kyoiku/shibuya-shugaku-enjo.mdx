渋谷区は、国公立小中学校に通う子どもの保護者を対象に、家庭の経済的状況に応じて学校でかかる費用の一部を補助する就学援助制度を実施しています。

<SubsidyInfoCard />

## この記事の結論

- 対象は国公立小中学校に通う子どもの保護者（経済的に困難な世帯）
- 支給項目は学用品費・給食費・修学旅行費・校外活動費・新入学学用品費等
- 所得基準の目安は**世帯人数・年齢構成により異なる**（公式お知らせPDF参照）
- 申請はオンラインまたは申請書（郵送・窓口）で受付

## 1. 対象者・所得の目安

渋谷区に居住し、国公立小中学校に在籍している児童・生徒の保護者が対象です。家庭の経済的事情に応じて補助を受けることができます。

所得基準の目安は世帯人数や家族の年齢構成などにより異なります。具体的な金額は、各学校を通じて配布される「令和8年度就学援助のお知らせ」、または区のホームページからダウンロードできるPDFをご確認ください。

<Callout type="info">
渋谷区の就学援助では、所得の審査に**総所得金額**を使用します（特別控除後の金額ではありません）。給与所得者は源泉徴収票の「給与所得控除後の金額」、事業所得者は収入から必要経費を差し引いた金額が目安となります。基準に該当するかどうか迷う場合は、まず申請することをおすすめします。
</Callout>

### 令和8年1月1日以前に転入した場合

令和8年1月1日時点に渋谷区に住民登録がなかった場合は、次の書類を準備して申請してください。

- 個人番号確認書類（全員分）：マイナンバーカード裏面、個人番号が記載された住民票の写しなど
- 本人確認書類（申請者のみ）：マイナンバーカード表面、運転免許証、旅券など

## 2. 支給項目

渋谷区の就学援助では、学校でかかる以下のような費目が補助されます。具体的な支給費目と金額は、区ホームページ掲載の「就学援助・特別支援教育就学奨励費補助金額表（PDF）」でご確認ください。

| 支給費目（主なもの） |
|---|
| 学用品費 |
| 給食費 |
| 修学旅行費 |
| 校外活動費 |
| 新入学学用品費 |
| 卒業アルバム費 |
| 通学費 |

<Callout type="info">
詳細な費目・金額・支給時期は、渋谷区公式ページ掲載の「就学援助・特別支援教育就学奨励費補助金額表（PDF）」をご確認ください。各学校を通じて配布されるお知らせにも記載があります。
</Callout>

## 3. 申請方法・スケジュール

### 特別支援教育就学奨励費との違い

就学援助（一般向け）のほかに、特別支援学級・特別支援教室・通級に在籍している児童・生徒の保護者を対象とした「特別支援教育就学奨励費」もあります。就学援助の対象とならなかった場合でも、特別支援教育就学奨励費の補助を受けられる場合があります。
