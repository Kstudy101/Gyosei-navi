品川区は、生活保護受給世帯や経済的に困難な世帯を対象に、小中学生の学用品費・給食費などを補助する就学援助制度を実施しています。12項目と幅広い補助内容が特徴です。

<SubsidyInfoCard />

## この記事の結論

- 対象は生活保護受給世帯、または所得基準以下の世帯（失業・倒産等による家計急変も可）
- 支給項目は**12項目**（学用品費・給食費・医療費など）
- 令和8年度の当初申請期限は**令和8年4月30日**（期限後も翌年2月1日まで随時受付）
- 申請は**毎年度必要**

## 1. 対象者・所得の目安

品川区に居住し、公立小・中学校または義務教育学校に通う子どもの保護者が対象です。次のいずれかに該当する必要があります。

- 生活保護を受けている方
- 前年（令和7年）の所得が下記の目安以下の方
- 失業・倒産・疾病などで現在の所得が大幅に減少した方

### 所得上限のめやす（世帯人数別）

| 世帯人数 | 所得上限のめやす |
|---|---|
| 2人世帯 | 約259〜314万円 |
| 3人世帯 | 約295〜417万円 |
| 4人世帯 | 約332〜508万円 |
| 5人世帯 | 約390〜579万円 |
| 6人世帯 | 約439〜685万円 |

<Callout type="warning">
同じ世帯人数でも、世帯構成員の年齢により基準額に幅があります。「めやす」の範囲内でも認定されない場合があります。単身赴任や遠隔地扶養の場合は、別居していても世帯員に含まれます。迷う場合はまず申請することをおすすめします。
</Callout>

## 2. 支給項目

品川区の就学援助は**12項目**にわたります。小学校・中学校・義務教育学校で対象年次が異なる項目があります。

| 項目 | 対象 |
|---|---|
| 1. 学用品費 | 全学年 |
| 2. 給食費（実費） | 全学年（保護者が納付した実費に限る） |
| 3. 新入学学用品費 | 入学前または1年生・6年生等 |
| 4. 夏季施設参加費 | 小5・義務教育学校5年生のみ |
| 5. 体育実技用具費 | 中学生・義務教育学校7〜9年生のみ（支給要件あり） |
| 6. 通学費 | 全学年（支給要件あり） |
| 7. 義務教育学校標準服費 | 義務教育学校1年生・前期課程転入生のみ |
| 8. 校外教授費 | 全学年 |
| 9. 移動教室費 | 小6・義務教育学校6・7年生のみ |
| 10. 修学旅行費 | 中学9年生・義務教育学校9年生のみ（※区立学校以外で保護者負担額がある場合） |
| 11. 卒業アルバム費 | 小6・中9・義務教育学校6・9年生のみ |
| 12. 医療費 | 全学年（支給要件あり） |

<Callout type="info">
生活保護受給世帯の場合、項目1〜7については就学援助費ではなく生活保護（教育扶助）から支給されます。
</Callout>
