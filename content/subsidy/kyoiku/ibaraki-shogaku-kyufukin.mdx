茨城県の奨学のための給付金制度は、すべての意志ある生徒が安心して教育を受けられるよう、授業料以外の教育費負担を軽減するために、低所得世帯の高校生に対して**返還不要の給付金**を支給する制度です。令和8年度は世帯区分・学校種別に応じて年額**32,300円〜143,700円**が支給されます。

<SubsidyInfoCard />

## この記事の結論

- **返還不要**の給付型支援（奨学金の貸付ではない）
- 授業料ではなく**授業料以外の教育費**の支援
- 令和8年度の最高給付額は所得割額非課税世帯（全日制・定時制）で**年額143,700円**
- 通常の申請期限は**令和8年9月25日（金）必着**（在学校経由の場合は学校の指定期日）
- 私立高校は別制度・別窓口（このページは公立高校向け）

## 1. 支給対象者

支給の主な要件は以下のとおりです。

- 基準日（申請年度の7月1日）に保護者等が茨城県内に住所を有していること
- 国籍に係る要件を満たすこと（外国籍の場合は在留資格等によって給付額が異なる場合あり）
- 生徒が公立高等学校等に在学していること

さらに、世帯の所得が以下のいずれかに該当する必要があります（保護者のうち一方が働き、高校生1人・中学生1人の4人世帯の場合の年収目安）。

| 要件 | 年収目安（モデルケース） |
|---|---|
| 生活保護（生業扶助）受給世帯 | — |
| 道府県民税所得割額および市町村民税所得割額が非課税（0円） | 270万円未満 |
| 上記所得割額の合計が100円以上105,500円未満 | 270〜380万円 |
| 上記所得割額の合計が105,500円以上182,500円未満 | 380〜490万円 |

※専攻科は対象要件が一部異なります（詳細は原文参照）。

## 2. 令和8年度の給付額（年額）

| 世帯区分 | 全日制・定時制 | 通信制・専攻科 |
|---|---|---|
| 生活保護（生業扶助）受給世帯 | 32,300円 | 32,300円 |
| 所得割額が非課税（0円）の世帯 | **143,700円** | 50,500円 |
| 所得割額が100円以上105,500円未満の世帯 | 47,900円 | 16,830円 |
| 所得割額が105,500円以上182,500円未満の世帯 | 35,930円 | 12,630円 |
| 所得割額105,500円以上264,500円未満で扶養子3人以上（専攻科のみ） | — | 12,630円 |

## 3. 申請手続き

申請の手続きは、保護者等の在住都道府県と生徒の在学校の組み合わせによって異なります。

| ケース | 手続き方法 |
|---|---|
| 保護者が茨城県内在住、生徒が茨城県内公立高校に在学 | 在学する学校から案内。学校に書類を提出 |
| 保護者が茨城県内在住、生徒が茨城県外の公立高校に在学（栃木・千葉・埼玉・茨城工業高専） | 在学する学校に書類を提出 |
| 保護者が茨城県内在住、生徒がその他の県外公立高校に在学 | 茨城県教育委員会財務課宛に書留等で送付（令和8年9月25日必着） |
| 保護者が茨城県外在住、生徒が茨城県内公立高校に在学 | 保護者在住の都道府県の担当窓口に提出 |

**申請期限**：令和8年9月25日（金）必着（学校経由の場合は学校の指定する期日）

**支給時期の目安**：概ね11月下旬〜12月上旬頃（予定）

## 5. 家計急変世帯向け給付

災害等による保護者の失職等で家計が急変し、収入が激減した世帯に対しても給付があります。

- 令和8年7月1日までに家計急変の事実が発生した場合：令和8年9月25日まで申請
- 令和8年7月2日以降の場合：事実発生後速やかに申請（令和9年3月3日必着が最終締切の場合あり）

詳細は在学する学校、または茨城県教育庁財務課修学支援担当（029-301-5169）にご連絡ください。
