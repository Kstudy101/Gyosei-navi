富山県国公立高等学校奨学のための給付金とは、国公立高等学校等に通う低・中所得世帯の生徒に対し、授業料以外の教育費（教科書費・教材費など）の負担を軽減するために富山県教育委員会が支給する、返還不要の給付金です。住民税非課税世帯の場合、全日制で年額14万3,700円が支給されます。

## この記事の結論

- 対象は**国公立**高等学校等に通う生徒のいる低・中所得世帯（私立は別制度）
- 世帯区分（生活保護／住民税非課税／所得割額の合算額）に応じて**年額3万2,300円〜14万3,700円**が支給される
- 通常給付の申請期限は**令和8年10月30日（金曜日）**、家計急変給付は区分により異なる
- 県内在学校は在学校経由、県外在学校は県立高校課へ直接提出

## 1. 対象者・支給条件

令和8年7月1日現在において、次の要件をすべて満たす世帯が対象です。

- 保護者等が富山県内に居住していること（県外在住の場合は居住する都道府県の教育委員会に問い合わせる）
- 生徒が高等学校等就学支援金、高校生等・新修学支援金、学び直し支援金または専攻科修学支援金の対象となる者であること
- 生活保護（生業扶助）受給世帯、または保護者等全員の令和8年度道府県民税所得割額と市町村民税所得割額の合算額が下記の区分に該当する世帯であること

なお、保護者等が海外に居住しており住民税の所得割額が確認できない場合は対象外です。生活保護（生業扶助）受給世帯については、生徒等の生業扶助（高等学校等修学費）の措置状況により判定されます。

**このページで扱うのは国公立高等学校等の場合です。** 私立高等学校等に通う場合は「富山県私立高等学校等奨学給付金」という別制度が用意されており、対象要件の構造（生活保護世帯・住民税非課税世帯・所得割額の区分）はおおむね同様ですが、申請期限や具体的な給付額の明記状況が異なるため、本記事では国公立向けのみを扱います。

## 2. 支給額・計算方法

生徒一人当たりの給付額（令和8年度、国公立の場合）は次のとおりです。

| 区分 | 全日制 | 定時制 | 通信制 | 専攻科 |
|---|---|---|---|---|
| ①生活保護（生業扶助）受給世帯 | 年額3万2,300円 | - | - | - |
| ②住民税非課税世帯 | 年額14万3,700円 | 年額5万500円 | 年額5万500円 | - |
| ③所得割額の合算額が100円以上10万5,500円未満 | 年額4万7,900円 | 年額1万6,830円 | 年額1万6,830円 | - |
| ④所得割額の合算額が10万5,500円以上18万2,500円未満 | 年額3万5,930円 | 年額1万2,630円 | - | - |
| ⑤所得割額の合算額が10万5,500円以上26万4,500円未満かつ扶養する子が3人以上 | - | - | - | 年額1万2,630円 |

※③・④は、高等学校等就学支援金（新制度）、学び直し支援金（新制度）または専攻科修学支援金の対象者が対象です。
※専攻科の③・⑤について、専攻科支援金（旧制度）の対象者の場合は年額1万100円となります。

さらに、②〜⑤の非課税世帯に該当し、災害等により制服の再購入が必要となった場合は、当該災害等につき1回限り、次の加算があります。

- ②への加算額: 6万4,800円
- ③への加算額: 2万1,600円
- ④・⑤への加算額: 1万6,200円

**家計急変給付**: 家計の急変により収入が減少した世帯は、上記とは別の「家計急変給付」の対象になります。詳細は富山県公式ページに掲載されているリーフレットで確認できます。

**提出期限**

| 区分 | 提出期限 |
|---|---|
| 通常給付 | 令和8年10月30日（金曜日） |
| 家計急変給付（7月1日以前の急変） | 令和8年10月30日（金曜日） |
| 家計急変給付（7月2日以降の急変） | 令和9年2月末まで随時受付 |

**提出先**: 富山県内の学校に在学する場合は在学校経由。富山県外の学校に在学する場合は県立高校課に直接提出。

**問い合わせ先**: 富山県教育委員会教育みらい室県立高校課学事担当（〒930-8501 富山県富山市新総曲輪1-7 県庁南別館4階、TEL 076-444-3448）
