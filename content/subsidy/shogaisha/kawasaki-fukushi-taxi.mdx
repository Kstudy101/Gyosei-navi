川崎市の福祉タクシー利用券は、重度障害者に対しタクシー料金の一部（運賃・迎車料）を助成するため、利用券を交付する制度です。現金を直接支給するのではなく、乗車時に乗務員へ提出する券を渡す「現物給付」型の仕組みです。

<SubsidyInfoCard />

## この記事の結論

- **1枚につき運賃・迎車料500円まで**助成。**1回の乗車で複数枚**使用可（お釣りなし）
- 交付枚数は**月7枚**。人工透析で**週3回以上通院**する腎臓機能障害者は**月14枚**
- 申請月から**年度末（3月31日）まで**を一括交付。5月以降申請では4月分へのさかのぼり不可
- **ふれあいフリーパス・高齢者フリーパス（福祉パス）**交付者は対象外
- 障害者割引（1割引）とは**併用可**。待機料・介助料等には使用不可
- 申請は**各区役所の高齢・障害課**。令和8年度分の受付開始は**令和8年3月18日**

## 1. 対象者

本市（川崎市）に住所地を有する方で、次のいずれかに該当する方が対象です。ただし、ふれあいフリーパス、高齢者フリーパス（福祉パス）などの交付を受けている方は対象になりません。

| 区分 | 要件 |
|---|---|
| 身体障害者手帳 | 障害程度が1級または2級（下肢・体幹・視覚及び内部障害のいずれかを含む方に限る） |
| 療育手帳 | 障害程度がA1またはA2と判定された方 |
| 身体＋療育の併用 | 身体障害者手帳3級（下肢・体幹・視覚及び内部障害を含む）かつ療育手帳B1 |
| 精神障害者保健福祉手帳 | 障害等級が1級 |

<Callout type="warning">
ふれあいフリーパス、高齢者フリーパス（福祉パス）などの交付を受けている方は、福祉タクシー利用券の交付を受けられません。
</Callout>

## 2. 助成内容・交付枚数

| 項目 | 内容 |
|---|---|
| 1枚あたり助成 | 運賃・迎車料について500円まで |
| 通常の交付枚数 | 1人あたり月7枚 |
| 人工透析（週3回以上通院）の腎臓機能障害者 | 1人あたり月14枚 |
| 交付の仕方 | 受け取りに来た月の分から年度末（3月31日）までの分を一括交付 |
| さかのぼり | 5月以降の更新（交付）申請では、4月にさかのぼった交付は不可 |
| 1回の乗車 | 複数枚の使用が可能 |
| お釣り | 複数枚使用を含め、500円に満たない場合は出ない |
| 自己負担 | 1枚の助成上限を超える金額は現金等で支払い |

<Callout type="info">
タクシーの料金改定があっても、助成上限額（1枚500円）の変更は行わないと原文に明記されています。待機料・介助料など、運賃・迎車料以外には使用できません。
</Callout>

### 乗車事例（原文）

障害者割引（1割引）適用後の乗車運賃が1,200円の場合:

1. 利用券を**2枚**使用 → 助成額1,000円。残り200円は現金等で支払い
2. 利用券を**3枚**使用 → 助成額1,200円。この場合もお釣りは出ない

## 3. 利用方法

1. 乗車の前に、福祉タクシー利用券が使えるか乗務員に確認する
2. 使用前に券面へ障害者手帳の番号を記入し、障害者手帳を乗務員に提示する（番号未記入の券は使用不可）
3. 障害者本人（表紙記名者）が乗車する場合のみ使用できる
4. 障害者割引（1割引）と併用できる場合があるため、乗車前に乗務員へ確認する

利用できるのは、主なタクシー事業者に加盟しているタクシー、または市が福祉タクシー利用券取扱協力機関として認めたタクシー事業者・福祉有償運送です。事業者の最新一覧は市公式ページのPDF・外部リンクを確認してください。

配車アプリを使う場合は、事前に利用券が使えるかタクシー会社へ問い合わせ、利用可能な会社を指定して配車する必要があります。「事前決済」ではなく「車内決済」を指定しているアプリもあるため、予約・支払方法もあわせて確認してください。

<Callout type="warning">
紛失しても再交付できません。不正使用が判明した場合は券を回収します。
</Callout>

令和8年4月1日から使用できる利用券の更新（交付）申請は、**令和8年3月18日（水）**から受付開始です。開始直後は窓口が混雑するため、分散来所への協力が求められています。

大師・田島支所で扱っていた窓口業務は、一部を除き令和7年1月6日に川崎区役所へ移管されています。臨時窓口などの詳細は川崎区役所へ確認してください。
