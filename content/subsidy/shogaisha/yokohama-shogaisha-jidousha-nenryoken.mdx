横浜市の障害者自動車燃料券とは、対象となる障害のある市内在住者に対し、事前登録した自家用車（二輪を除く）の燃料費を1枚1,000円を限度に助成する券を交付する制度です。現金を直接渡すのではなく、契約ガソリンスタンドでの給油時に使う「現物給付」型です。同市の[福祉タクシー利用券](/subsidy/shogaisha/yokohama-fukushi-taxi-riyouken)とは対象者の障害区分が近い一方、**どちらか一方しか選べない**外出支援メニューの関係にあります。

<SubsidyInfoCard />

## この記事の結論

- 助成は**1枚1,000円限度**の燃料券で、通常は**年間24枚**（人工透析で週3回以上通院する腎臓機能障害者は**年間48枚**）
- 福祉タクシー利用券・福祉特別乗車券・敬老特別乗車証・特別乗車券とは**5制度のうち1つのみ**利用可
- 使えるのは**市と契約した取扱給油所**で、**事前登録した車両1台**のみ
- 引き続き対象の方への次回分は郵送のため、原則として毎年の再申請は不要

## 1. 対象者・支給条件

対象は、横浜市内に住所があり、福祉タクシー利用券・福祉特別乗車券・敬老特別乗車証・特別乗車券のいずれの交付も受けていない人のうち、次の（1）〜（4）のいずれかに該当する人です。

1. 下肢・体幹・視覚・内部・移動機能障害のいずれかを含む1・2級の身体障害者手帳を持っている人
2. 愛の手帳（療育手帳）A1、A2を持っている人、または障害者更生相談所・児童相談所で知能指数35以下と判定された人
3. 下肢・体幹・視覚・内部・移動機能障害のいずれかを含む3級の身体障害者手帳を持っている人のうち、愛の手帳B1を持っている人、または知能指数50以下と判定された人
4. 精神障害者保健福祉手帳1級を持っている人

<Callout type="info">
身体障害者手帳1・2級でも、対象になるのは「下肢・体幹・視覚・内部・移動機能障害のいずれかを含む」場合に限られます。すべての種別の1・2級が無条件で対象になるわけではありません。
</Callout>

### 登録できる車両

障害のある方1人につき、要件を満たす車両を**1台**事前登録します。

| 区分 | 内容 |
|---|---|
| 所有者 | 本人、配偶者、直系血族とその配偶者、兄弟姉妹とその配偶者、同居の親族が所有。割賦・長期リースは車検証の使用者欄が上記であること。本人・親族等が所有していないときは、対象者を継続して日常的に介護している方の所有・使用も可 |
| 車両 | 普通・小型・軽自動車で乗車定員10人以下の乗用（または類似の構造・機能） |
| 対象外 | 事業用、法人所有（割賦等を除く）、有償移動サービス・営業用、レンタカー、タクシー、軽トラック、借用車、代車など |

## 2. 支給額・交付枚数

| 項目 | 内容 |
|---|---|
| 助成上限 | 1枚につき**1,000円**を限度 |
| 通常の交付枚数 | 年間**24枚**（有効期間: 10月1日〜翌年9月30日） |
| 人工透析（週3回以上通院）の腎臓機能障害者 | 年間**48枚**（透析先での送迎サービス利用時は割増対象外） |
| 使える燃料 | ハイオク・レギュラー・軽油のみ（オイル・洗車等は対象外） |

燃料券は金額（1,000円）単位での給油に利用します。利用時の給油単価が店頭表示と異なる場合があるため、給油前に単価を確認し了承のうえで使う必要があります。

## 3. 申請方法・必要書類

申請窓口は**お住まいの各区福祉保健センター**です。

<Checklist items={["身体障害者手帳、愛の手帳（療育手帳）等、または精神障害者保健福祉手帳", "登録する自動車の自動車検査証（車検証）の写し（令和5年1月以降発行分は「自動車検査証記録事項」の写しも必要）"]} />

引き続き対象となる方には、次回有効期間分が郵送されるため、改めての申請は不要です。案内本文には「9月下旬までに」と「9月中旬までに」の両方の表現があります。10月1日以降有効な手帳がない場合は交付されないため、更新が必要な方は早めに手続きしてください。

令和8年（2026年）分の継続交付については、専用ダイヤル（電話 045-628-9350、令和8年8月21日から12月11日まで）が案内されています。

車両変更時は、変更前の残券・手帳・新しい車検証写しを持参して区の福祉保健センターで手続きします。残りの燃料券と同じ枚数が交付され、後からの追加交換はできません。

## 4. 他制度との関係・切替え

次の5制度は**どれか1つだけ**です。

1. 障害者自動車燃料券
2. 福祉タクシー利用券（[別記事](/subsidy/shogaisha/yokohama-fukushi-taxi-riyouken)）
3. 福祉特別乗車券
4. 敬老特別乗車証
5. 特別乗車券

有効期間中に福祉タクシー利用券・福祉特別乗車券・敬老特別乗車証へ切替える場合、燃料券の残り枚数**2枚**（48枚交付の方は**4枚**）を1か月分と換算して利用開始月が決まります。残数が足りない月までは切替えできません。切替えは有効期間中**1回限り**で、燃料券は返還します。

福祉特別乗車券へ切替える場合は、年額**1,200円**（20歳未満は**600円**）の利用者負担金がかかります。福祉タクシー利用券・敬老特別乗車証への切替えでは利用者負担金はありません。

## 5. 利用上の注意

- 貸与・譲渡・転売・換金・担保は禁止。不正利用が判明した場合は回収・交付停止・返還請求の対象になり得ます
- **紛失しても再発行なし**
- 契約給油所のみ利用可。一覧は公式のExcel・PDF（令和8年8月6日時点）またはデータマップで確認
- 問い合わせ先（制度全般）: 健康福祉局障害福祉保健部障害自立支援課移動支援係（電話 045-671-2401）
