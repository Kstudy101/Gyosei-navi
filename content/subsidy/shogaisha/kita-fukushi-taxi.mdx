北区の福祉タクシー券とは、歩行が困難な在宅の心身障害者（児）の外出を支援するため、1か月あたり500円券7枚と100円券5枚（合計4,000円分）を交付する制度です。区と契約したタクシー会社を利用するときに使用できます。

<SubsidyInfoCard />

## この記事の結論

- 交付内容は**月500円券7枚＋100円券5枚（合計4,000円分）**。申請した月から当該年度3月分までの月数分をまとめて一括交付する
- ガソリン券（自動車燃料費の助成）の受給者、施設入所中・病院等に入院中の人は対象外
- 所得制限があり、毎年7月に所得の見直しを行う。超過していた人も翌7月以降に再申請すれば交付対象になる可能性がある

## 1. 対象者・支給条件

次のいずれかの手帳等級に該当する人が対象です。複数の障害がある場合は、個別の障害等級で該当すれば対象になります。

- 身体障害者手帳：下肢・体幹機能障害1〜3級
- 身体障害者手帳：視覚障害1・2級
- 身体障害者手帳：内部機能障害1〜3級
- 愛の手帳1・2度
- 精神障害者保健福祉手帳1級

次のいずれかに該当する場合は対象になりません。

- ガソリン券（自動車燃料費の助成）の交付を受けている
- 施設入所、病院等に入院中
- 障害者本人（20歳未満は扶養義務者等）の所得額が、所得制限限度額表の所得額を超える

<Callout type="warning">
「施設入所、病院等に入院中の方」は対象外とされていますが、原文には入院期間の長短についての条件はありません。短期入院であっても対象外になり得る書き方なので、該当しそうな場合は窓口に確認してください。
</Callout>

### 所得制限限度額表（扶養親族等の数別）

| 扶養親族等の数 | 収入額（目安） | 所得額 |
|---|---|---|
| 0人 | 5,372,000円 | 3,758,000円 |
| 1人 | 5,848,000円 | 4,138,000円 |
| 2人 | 6,324,000円 | 4,518,000円 |
| 3人 | 6,776,000円 | 4,898,000円 |
| 4人 | 7,198,000円 | 5,278,000円 |
| 5人 | 7,620,000円 | 5,658,000円 |

所得判定は、障害者本人が20歳以上なら本人の所得、20歳未満なら扶養義務者等の所得で行います。扶養義務者等が複数いる場合は、個別に判定し、一人でも所得超過に該当すると対象外です。

所得の見直しは毎年7月に行われ、1〜6月に申請した場合は一昨年の所得額、7〜12月に申請した場合は昨年の所得額で判定します。

## 2. 支給額・交付金額表

1か月につき500円券7枚、100円券5枚（合計4,000円分）を、申請があった月から当該年度3月分までの月数分をまとめて一括で交付します。申請する月によって、初回の交付金額は次のように変わります。

| 申請月 | 交付金額 |
|---|---|
| 4月 | 48,000円 |
| 5月 | 44,000円 |
| 6月 | 40,000円 |
| 7月 | 36,000円 |
| 8月 | 32,000円 |
| 9月 | 28,000円 |
| 10月 | 24,000円 |
| 11月 | 20,000円 |
| 12月 | 16,000円 |
| 1月 | 12,000円 |
| 2月 | 8,000円 |
| 3月 | 4,000円 |

滝野川地域障害者相談支援センターで申請した場合は、後日郵送で交付されます。
