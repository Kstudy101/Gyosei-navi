千葉市の福祉タクシー・自動車燃料費等助成事業は、対象要件を満たす重度の障害者等に対し、タクシー運賃の割引利用券を交付する制度と、自家用車の燃料費等を現金で助成する制度を用意しています。どちらか一方のみ選択できます。

<SubsidyInfoCard />

## この記事の結論

- **福祉タクシー**と**自動車燃料費等助成**は**二者択一**
- 一般タクシー（黄色券）は運賃**2,600円以内で半額**、超過時は**1,300円割引**
- リフト付タクシー（水色券）は運賃**11,000円以内で半額**、超過時は**5,500円割引**
- 利用券は**年間30枚**（年度途中の新規は減少。透析で週2回以上通院の方は追加交付可）
- 燃料費助成は通年資格で**年15,000円**（各期5,000円）
- **所得制限あり**（特別障害者手当の所得制限限度額を超える方は対象外）

## 1. 対象者

次のいずれかに該当し、所得制限以下の方が対象です。

| 区分 | 要件 |
|---|---|
| 身体障害者手帳 | 1・2級 |
| 療育手帳 | ○A（○Aの1・○Aの2）〜Aの2 |
| 精神障害者保健福祉手帳 | 1級 |
| 特別児童扶養手当 | 1級受給者 |
| 障害児福祉手当・特別障害者手当 | 受給者 |
| 福祉手当（経過措置） | 受給者 |
| 小児慢性特定疾病 | 重症患者 |

<Callout type="warning">
所得による制限があります。特別障害者手当の所得制限限度額を超える方は対象外です。限度額の詳細は各区の窓口で確認してください。
</Callout>

## 2. 福祉タクシー助成事業

協力機関のタクシーで使える利用券が交付されます。券種は2種類です。

| 券種 | 割引内容 |
|---|---|
| 一般タクシー（黄色券） | 運賃2,600円以内：半額（10円未満切り上げ）／2,600円超：1,300円割引 |
| リフト付タクシー（水色券） | 運賃11,000円以内：半額（10円未満切り上げ）／11,000円超：5,500円割引 |

| 項目 | 内容 |
|---|---|
| 交付枚数 | 年間30枚（年度途中の新規申請は時期に応じて減少） |
| 追加交付 | 人工透析で週2回以上通院している方は追加交付可 |
| 利用期間 | 8月1日〜翌7月31日 |
| 使い方 | 利用券を運転手に渡して割引を受ける。手帳所持者は利用時に手帳を提示 |

<Callout type="info">
7月に所得確認が行われ、対象者には当該年度分の利用券が送付されます。協力機関の一覧は千葉市公式サイトのPDF（令和8年8月28日現在）で確認できます。記載内容は変更される場合があるため、利用前に各事業者へ確認してください。平成30年4月1日以降、「検見川交通」は協力機関から取り消されています。
</Callout>

## 3. 自動車燃料費等助成事業

福祉タクシーを選ばない場合の選択肢です。対象期間に受給資格があった期について、登録口座へ振り込まれます。

| 対象期間 | 金額 | 支給月 |
|---|---|---|
| 第1期（8〜11月） | 5,000円 | 2月（第2期と合算） |
| 第2期（12〜3月） | 5,000円 | 2月 |
| 第3期（4〜7月） | 5,000円 | 8月 |

通年で受給資格がある場合の合計は**15,000円**です。振り込み前（2月・翌年8月）に振込通知書が送付されます。助成対象自動車は1台につき原則として1人（営業用自動車を除く）です。
