長野市の障害者タクシー利用券交付事業は、対象となる身体障害者手帳をお持ちの市内居住者に、タクシー運賃の支払いに使える利用券を交付する制度です。現金を振り込むのではなく、乗車時に提出する券を渡す仕組みです。

<SubsidyInfoCard />

## この記事の結論

- **1枚600円**の利用券を**年間36枚**交付（寝台・リフト・スロープ付きの**時間制運賃**タクシー利用時は**1枚700円**）
- 対象は**身体障害者手帳**所持者のうち、視覚・下肢・体幹・上肢・内部障害など**等級・種別が限定**された方
- **1回の乗車あたり原則2枚まで**（上記の時間制運賃タクシーは**4枚まで**）
- 手帳提示による**運賃1割引との併用可**（1割引は別制度）
- 使えるのは市が示す一覧の事業者で、**緑ナンバー車両のみ**
- 所得制限の有無は公式案内に**明示なし**（「なし」とは断定しない）

## 1. 対象者

長野市に居住し、身体障害者手帳を所持している方のうち、次のいずれかに該当する方が対象です。

| 区分 | 等級・条件 |
|---|---|
| 視覚障害 | 1・2級 |
| 下肢障害 | 1・2級 |
| 体幹障害 | 1・2級 |
| 上肢障害 | 1級 |
| 内部障害（心臓・じん臓・呼吸器・ぼうこう・直腸・小腸・肝臓・ヒト免疫不全） | 1・2級 |
| 複合 | 上肢障害2級かつ下肢障害3級／上肢障害2級かつ体幹障害3級 |

<Callout type="warning">
案内ページの対象は身体障害者手帳所持者に限られます。療育手帳や精神障害者保健福祉手帳のみでの交付可否は、当該ページに記載がありません。申請書様式には「市長が特に認めるもの」欄もありますが、個別該当可否は窓口確認が必要です。
</Callout>

## 2. 交付内容・使い方

| 項目 | 内容 |
|---|---|
| 通常の利用券 | **1枚600円** |
| 寝台・リフト・スロープ付き時間制運賃タクシー | **1枚700円** |
| 年間交付枚数 | **36枚** |
| 1回の乗車で使える枚数 | 原則**2枚まで**（上記時間制運賃タクシーは**4枚まで**） |
| 1割引との併用 | **可**（手帳提示による料金1割引） |

<Callout type="info">
手帳提示によるタクシー運賃の割引（おおむね10％）は別制度です。身体障害者手帳・療育手帳所持者が対象で、精神障害者保健福祉手帳所持者は一部事業者のみと案内されています。詳細はタクシー会社への確認が必要です。
</Callout>

### 利用できるタクシー

長野市が公開する「障害者タクシー利用券　タクシー会社一覧」（令和8年9月現在）に掲載された事業者で利用できます。注意書きでは次が示されています。

- **緑ナンバーの車両のみ**利用可
- タクシー会社は追加になる場合あり
- 福祉タクシーの種類表示：●大型／◆普通・小型・軽

## 3. 申請方法・窓口

届出窓口は次のとおりです。

- 障害福祉課
- 福祉政策課篠ノ井分室
- 豊野支所・戸隠支所・鬼無里支所・大岡支所・信州新町支所・中条支所

必要書類は、**身体障害者手帳**と**障害者タクシー利用券支給申請書**です。申請書は市公式サイトからPDFで入手できます。

問い合わせ先：保健福祉部 障害福祉課（長野市大字鶴賀緑町1613番地 第二庁舎1階／電話 026-224-5030／ファックス 026-224-5093）
