京都市の重度障害者タクシー料金助成事業は、重度障害者に対してタクシー料金の一部を助成し、日常生活の利便と社会参加の促進を図る京都市独自の制度です。京都市に登録するタクシー事業者で使える利用券を交付する仕組みで、現金の定額給付ではありません。

<SubsidyInfoCard />

## この記事の結論

- **1枚500円**のタクシー利用券を、**月4枚（年間最大48枚）**交付
- 対象は**身体障害者手帳1・2級**、**療育手帳A判定**、**精神障害者保健福祉手帳1級**
- **福祉乗車証・敬老乗車証とは重複不可**（いずれか一つを選択）
- 利用券の有効期限は**交付を受けた年度中のみ**
- 令和8年度からの継続申請は**郵送・オンライン**、交付は**郵送**

## 1. 対象者

次のいずれかに該当する方が対象です。

| 区分 | 要件 |
|---|---|
| 身体障害者手帳 | 1級・2級 |
| 療育手帳 | A判定 |
| 精神障害者保健福祉手帳 | 1級 |

<Callout type="warning">
重度障害者タクシー利用券、福祉乗車証、敬老乗車証は重複して交付を受けられません。いずれか一つを選ぶ必要があります。
</Callout>

## 2. 助成内容（利用券）

| 項目 | 内容 |
|---|---|
| 券面額 | 1枚500円 |
| 交付枚数 | 1か月につき4枚、年間最大48枚 |
| 途中申請 | 申請月により交付枚数が4枚ずつ減少 |
| 有効期限 | 交付を受けた年度中のみ |
| 利用先 | 京都市に登録するタクシー事業者 |

タクシー利用券で支払った分の運賃には、領収書は発行されません。

### 1回の乗車で使える枚数（令和5年度以降の使用例）

| 乗車料金 | 使用可能枚数 |
|---|---|
| 500円未満 | 使用不可 |
| 500円以上1,000円未満 | 1枚まで（2枚以上は使用不可） |
| 1,000円以上1,500円未満 | 2枚まで（3枚以上は使用不可） |
| 1,500円以上2,000円未満 | 3枚まで（4枚以上は使用不可） |
| 2,000円以上 | 4枚まで（5枚以上は使用不可） |

<Callout type="info">
利用可能なタクシー事業者の具体的な一覧は、本ページ（京都市重度障害者タクシー料金助成事業について）には掲載されていません。「京都市に登録するタクシー事業者」とのみ案内されています。利用前に市または事業者へ確認してください。
</Callout>

## 3. 申請・窓口

### 新規申請

お住まいの地域の**区役所・支所の障害保健福祉課**および**京北出張所**（保健福祉第一・第二担当）が窓口です。

<Checklist items={["身体障害者手帳、療育手帳または精神障害者保健福祉手帳（お持ちの全ての手帳を提示）", "代理申請の場合は本人確認書類（委任状等が必要な場合あり）", "区役所・支所の障害保健福祉課または京北出張所で申請する"]} />

窓口での交付期間は、タクシー利用券交付年度の**4月1日から年度末の3月31日まで**です。

### 継続申請（令和8年度〜）

令和8年度から、継続利用の申請方法は**郵送・オンライン申請**に、交付方法は**郵送**に変更されています。区役所への来所は不要です。詳細は京都市の「重度障害者タクシー利用券の郵送交付について」の案内を確認してください。
