坂井市障害福祉タクシー料金助成とは、在宅で生活し自身で自動車の運転ができない重度障がい者がタクシーを利用する際に、料金の一部として使えるタクシー乗車券を年間最大18,000円分交付する福井県坂井市の制度です。

<SubsidyInfoCard />

## この記事の結論

- 在宅の重度障がい者（身体障害者手帳1〜3級・療育手帳A1/A2/B1・精神障害者保健福祉手帳1〜2級のいずれか）が対象で、施設入所者・入院者は原則対象外
- 交付額は年度当初の申請なら18,000円分だが、申請月が遅くなるほど月割で減額される（3月申請なら1,500円分）
- 申請は坂井市役所社会福祉課の窓口で年度内1回限り。乗車券は紛失しても再発行不可

## 1. 対象者・支給条件

この制度の対象となるのは、次の4つの要件をすべて満たす人です。

1. 坂井市に住民票があること
2. 実際に坂井市内に住んでいること（在宅であること）
3. 自身で自動車の運転ができないこと
4. 次のいずれかの障害者手帳を所持していること
   - 身体障害者手帳1〜3級
   - 療育手帳A1・A2・B1
   - 精神障害者保健福祉手帳1・2級

一方、次に該当する場合は対象外となります。

- 施設に入所している場合（ただし一部、在宅扱いとなる施設もあり、交付対象施設一覧で確認できるとされています）
- 病院・診療所に入院している場合（退院日が確定している場合は個別相談が可能とされています）
- 坂井市高齢福祉課が発行する「坂井市在宅介護外出支援事業タクシー乗車券」をすでに交付されている場合

なお、坂井市の案内ページには所得制限に関する記載が見当たりませんでした。所得要件の有無については断定できないため、申請前に社会福祉課へ確認することをおすすめします。

## 2. 支給額・計算方法

年間の交付額は18,000円分（ひと月あたり1,500円分の利用を想定）です。ただし、申請した月によって交付額が月割で逓減する仕組みになっており、年度途中で申請するほど交付額は少なくなります。

| 申請月 | 交付額 |
|---|---|
| 4月 | 18,000円分 |
| 5月 | 16,500円分 |
| 6月 | 15,000円分 |
| 7月 | 13,500円分 |
| 8月 | 12,000円分 |
| 9月 | 10,500円分 |
| 10月 | 9,000円分 |
| 11月 | 7,500円分 |
| 12月 | 6,000円分 |
| 1月 | 4,500円分 |
| 2月 | 3,000円分 |
| 3月 | 1,500円分 |

乗車券の有効期限は各年度4月1日から翌年3月31日までで、年度をまたいで繰り越すことはできません。令和7年度は500円券と300円券の2種類で交付されています。

タクシー乗車券は現物給付（金券方式）です。坂井市が指定するタクシー事業者を利用する際、障害者手帳を提示して障害者割引を適用したうえで、氏名・乗車年月日を記入した乗車券を運転者に渡して使用します。おつりは受け取れません。

なお、身体障害者手帳または療育手帳の所持者は、手帳を提示するだけで距離制・時間制運賃および待ち料金が10%引きになる別枠の割引制度も利用できます。これはタクシー乗車券とは別の制度で、あわせて利用することができます。

## 3. 申請方法・必要書類

申請は坂井市役所社会福祉課の窓口で行います。年度内の申請は1回限りで、乗車券を紛失しても再発行はされないため、あらかじめ理解したうえで申請してください。

<Checklist items={["障害者手帳（身体障害者手帳・療育手帳・精神障害者保健福祉手帳のいずれか）", "坂井市障害福祉タクシー乗車券交付申請書兼受領書（社会福祉課窓口または様式PDFで入手）"]} />

審査のうえ交付が決定すると、その場または後日タクシー乗車券が交付されます。

死亡や坂井市外への転出など利用資格がなくなった場合は、残りのタクシー乗車券を返納届とともに社会福祉課へ提出する必要があります。
