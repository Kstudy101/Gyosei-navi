岐阜市の重度障害者（児）タクシー利用料金助成とは、外出が困難な重度障がいのある方に、タクシーまたは福祉有償運送の料金の一部を助成する制度です。1回の乗車につき560円分の乗車券を、1年度あたり最大48枚交付します（年間最大26,880円相当）。1回の乗車で使える乗車券は1枚のみです。

<SubsidyInfoCard />

## この記事の結論

- **1枚560円の乗車券を年度あたり最大48枚**交付（年間最大**26,880円**相当）
- **1回の乗車につき乗車券は1枚のみ**使用可
- 対象は**在宅**の重度障がい者（児）。視覚1・2級、下肢・体幹・移動機能1・2級、内部障害1級、療育手帳でIQおおむね20以下（A1）
- **自動車税等の減免**や自動車改造・介助用自動車購入等の助成を受けている人、**施設入所者**は対象外
- 利用できるのは市と協定を結んだ**タクシー**および本市区域の**福祉有償運送**
- 新規は**オンライン申請可**。更新は窓口または郵送。乗車券の**再交付なし**

## 1. 対象者・除外条件

対象になるのは、岐阜市に住所を有する**在宅**の重度障害者（児）で、次のいずれかに該当する方です（公式ページ・要綱第2条）。

| 区分 | 要件 |
|---|---|
| 身体障害者手帳（視覚） | 1級又は2級 |
| 身体障害者手帳（下肢・体幹・移動機能） | 下肢、体幹機能障害、または乳幼児期以前非進行性の脳病変による移動機能障害で1級又は2級 |
| 身体障害者手帳（内部障害） | 心臓、じん臓、呼吸器、ぼうこう、直腸、小腸、免疫、肝臓機能障害で1級 |
| 療育手帳 | 知能指数がおおむね20以下（公式ページ表記: IQ20以下（A1）） |

次のいずれかに該当する場合は助成の対象外です。

## 2. 助成内容

| 項目 | 内容 |
|---|---|
| 1回あたりの助成 | 560円（乗車券1枚） |
| 年度あたりの上限 | 48回（48枚） |
| 年間最大相当額 | 26,880円（560円×48枚） |
| 1回の乗車で使える枚数 | **1枚のみ** |
| 対象となる移動 | 協定タクシー、本市区域の福祉有償運送 |

利用時は、協力機関のタクシーまたは福祉有償運送を利用したあと、乗車券1枚を提出し、料金から560円を差し引いた額を支払います（要綱第8条）。

介護保険のケアプランや障害福祉サービスのサービス等利用計画に位置づけられた通院等乗降介助の利用者負担分、福祉有償運送料金のうち運送の対価以外の料金は助成対象外です（要綱第4条）。

年度の途中で受給資格者となった場合の交付枚数は、認定した日の属する月を含め月割した回数分が限度になります（要綱第6条）。

## 3. 申請方法・必要書類

### 新規申請

身体障害者手帳または療育手帳を添えて認定申請を行います。公式ページでは**オンライン申請フォーム**も案内されています。

### 更新（毎年度の乗車券交付）

更新はオンラインフォームからはできません。窓口申請のほか、郵送でも手続きできます。郵送の場合は次を同封し、新年度の4月1日以降に手帳記載の住所へ送付されます。

送付先は「〒500-8701 岐阜市司町40番地1 障がい福祉課 給付係」です。

### 届出窓口

障がい福祉課のほか、柳津地域事務所福祉事務所柳津分室、南部東事務所、西部事務所、東部事務所、北部事務所、日光事務所、南部西事務所でも受け付けています。

<Callout type="warning">
乗車券はいかなる場合も再交付されません。紛失・破損に注意してください。
</Callout>
