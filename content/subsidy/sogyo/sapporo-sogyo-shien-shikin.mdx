札幌市の創業支援とは、特定創業支援等事業を修了して法人登記した人に定額補助を行う「さっぽろ新規創業促進補助金」と、市内での創業者・創業後5年未満の事業者などに低利融資をあっせんする「創業・雇用創出支援資金」の2制度です。いずれも札幌市経済観光局が所管しています。

## この記事の結論

- さっぽろ新規創業促進補助金は**株式会社設立75,000円・合同会社設立30,000円**の定額補助（登録免許税相当額）
- 補助金の申請期限は**会社設立日から90日以内、または令和9年3月31日のいずれか早い日**まで（先着順・予算到達次第終了）
- 創業・雇用創出支援資金は**融資限度額5,000万円**（創業3ヶ月以内は必要額の9割以内）、**利率年1.70%以内**で融資をあっせん

## 1. さっぽろ新規創業促進補助金

### 対象者・支給条件

さっぽろ新規創業促進補助金は、単独では申請できません。まず札幌市の**特定創業支援等事業**を修了して証明を受け、その証明により登録免許税の軽減措置（概ね半額）を受けたうえで法人登記した人が対象です。特定創業支援等事業を受けずに既に法人登記を終えている場合は対象外になります。

主な要件は次のとおりです。

- 事業を営んでいない個人、または開業届の提出から5年を経過していない個人事業主で、新たに会社を設立した者であること
- 札幌市より特定創業支援等事業の証明を受けたのち、登録免許税を支払っていること
- 札幌市内に登記上の本店所在地を置いていること
- 新たに設立した会社以外に代表権を持つ会社がない、または他の事業を営んでいないこと（個人事業は廃業届提出済みが必要）
- 反社会的勢力及び関係者でないこと
- 市税を滞納していないこと、または徴収猶予の特例制度等の対象であること

**申請期限に特に注意が必要です。** 会社の設立日（履歴事項全部証明書に記載の会社成立の年月日）から起算して**90日以内**、または**令和9年3月31日**のいずれか早い日までに、申請書類が到着している必要があります。90日を超えての申請は受け付けられません。

受付期間は**令和8年4月1日〜令和9年3月31日**（必着）ですが、予算に限りがあるため申請状況によっては募集期間内でも終了する場合があります（先着順）。

### 補助額

| 設立形態 | 補助額 |
|---|---|
| 株式会社設立 | 一律75,000円（登録免許税75,000円相当） |
| 合同会社設立 | 一律30,000円（登録免許税30,000円相当） |

補助金の交付時期は、申請書類を提出した月の翌月下旬が予定されています。毎月末までに到着した申請を翌月初頭にまとめて審査するため、申請タイミングによっては1か月以上待つこともあります。

### 申請方法

申請は**郵送のみ**受け付けています。窓口持参や電子申請はできません。

## 2. 創業・雇用創出支援資金

### 対象者・融資条件

創業・雇用創出支援資金は、札幌市中小企業融資制度の特別資金の一つで、次のいずれかに該当する人が対象です。

- 市内で創業する者、及び創業後5年未満の者
- 融資申請日前6か月以内に、新たに常用従業員を1名以上雇用した者
- 国の全国統一制度である「スタートアップ創出促進保証制度」を利用する者

### 融資条件

| 項目 | 内容 |
|---|---|
| 融資限度額 | 5,000万円（創業者・創業3ヶ月以内は必要額の9割以内。スタートアップ保証利用者のみ3,500万円） |
| 資金使途 | 運転資金、設備資金（市内の設備投資に限る） |
| 融資期間 | 10年以内（据置2年以内。スタートアップ保証利用者は据置1年以内、条件により3年以内も可） |
| 返済方法 | 割賦返済（スタートアップ保証利用者は原則均等分割返済） |
| 融資利率 | 年1.70%以内 |
| 信用保証 | 必要により信用保証協会の保証付（スタートアップ保証利用者は保証付） |
| 保証人 | 法人は必要に応じて要、個人は不要 |
| 担保 | 必要により徴する（スタートアップ保証利用者は物的担保不要） |
| 保証料補給 | 市が信用保証料の4分の1以内を補給 |

融資のあっせんを受けるには、札幌市中小企業融資制度の取扱金融機関を通じた申込みが必要です（取扱金融機関は別ページで案内されています）。

問い合わせ先は札幌市経済観光局経営雇用支援部商業・経営支援課（電話：011-211-2372）です。
