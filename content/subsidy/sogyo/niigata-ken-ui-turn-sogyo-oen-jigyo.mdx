新潟県のU・Iターン創業応援事業とは、県外から新潟県内へ移住して創業する人などに対し、創業に必要な経費の1/2以内（上限200万円・下限50万円）を補助する制度です。実施するのは県ではなく、公益財団法人にいがた産業創造機構（NICO）です。

<SubsidyInfoCard />

## この記事の結論

- 実施主体は新潟県の直営ではなく、NICO（公益財団法人にいがた産業創造機構）です。
- 令和8年度の一次募集（2026年5月12日〜6月18日）は終了しました。
- 二次募集は、2026年9月25日時点の公式ページ確認で告知が見当たりません。
- 補助率は1/2以内、上限200万円・下限50万円で、経費を支払った後に受け取る精算払いです。
- デジタル技術を使って地域課題・社会課題の解決につながる創業が対象です。

## 1. 現在の募集状況（2026年9月25日確認）

令和8年度の状況は次のとおりです。この記事は、今申請できることを案内するものではありません。

| 項目 | 内容 |
|---|---|
| 一次募集 | 2026年5月12日（火）〜6月18日（木）17時必着。終了済み |
| 一次募集の審査 | 書面審査のあと、2026年8月5日にプレゼンテーション審査（対面） |
| 二次募集 | 募集案内に「令和8年8月以降、二次募集を実施する予定」との記載あり。ただし2026年9月25日時点の公式ページ確認で、二次募集の告知は見当たらない |
| 参考（令和7年度） | 令和7年度は8月1日〜9月19日に二次募集を実施した前例あり。今年度も同様に行われるとは限らない |

公式ページ（2026年8月7日更新）は、今後の予定についてNICOの起業・創業支援チームへ問い合わせるよう案内しています。予算総額と採択倍率は、確認した資料に記載がなく未確認です。

## 2. 対象者・条件

県内に事業所を設置し、2026年5月12日から2027年2月28日までに起業する見込みの人が対象でした（令和8年度一次募集の条件）。「起業の種類」と「起業の形態」の両方に当てはまる必要があります。

### 起業の種類

| 種類 | 内容 |
|---|---|
| U・Iターン起業 | 新潟県外の居住者が県内へ転居して起業する。起業準備で転居済みの人は、2026年5月12日時点で転居後1年以内に限り対象 |
| じもと定着起業（ア） | 進学を機に県内に住む県外出身の大学院生等。卒業後1年以内の人も対象 |
| じもと定着起業（イ） | 有期雇用契約等で県内へ転居して働く県外出身者（例：地域おこし協力隊員）。契約終了後1年以内の人も対象 |

### 起業の形態

- 個人開業：開業届を提出し、営業を開始する人。
- 法人設立：株式会社・合同会社・合名会社・合資会社・特定非営利活動法人・一般社団法人のいずれかを登記し、営業を開始する人。

### 対象外・注意点

- 個人事業主の「法人成り」は対象外です。
- 申請開始日以前に法人設立・個人開業を済ませている人は対象外です。
- 会社などに所属している人は、交付決定から2か月以内に退職する必要があります。副業での起業は対象外です。
- フランチャイジーは対象外です。
- NICOが今年度実施する他の補助金との併願・併用はできません。
- 第2世代交付金（新しい地方経済・生活環境創生交付金）を財源とする他の補助金・助成金との併願・併用もできません。
- 事業承継による開業は、Society5.0関連業種など付加価値の高い分野に限られます。

## 3. 対象事業

次のすべてを満たす事業が対象です。

- デジタル技術を活用し、新潟県内の地域課題・社会課題の解決に資する事業
- 補助事業期間内に起業に至る事業
- 1年以上の事業継続が見込まれる事業
- 3年以上の事業計画を策定する事業

デジタル技術の例は、キャッシュレス決済の導入、Web予約システム、ECサイトでの販売、SNSやWebサイトでの情報発信などです。課題分野は、地域活性化、まちづくり、過疎地域等の活性化、買い物弱者支援、地域交通支援、社会教育、子育て支援、環境、社会福祉、地域資源の活用です。地域課題の解決を主目的としない単なる飲食業・美容業などは対象外とされています。

## 4. 補助額・対象経費

| 項目 | 内容 |
|---|---|
| 補助率 | 対象経費の1/2以内 |
| 補助限度額 | 200万円（下限50万円） |
| 対象期間 | 交付決定日〜2027年2月28日 |
| 受け取り方 | 精算払い（経費を支払ったあとに交付） |

交付決定額は、採択者数・申請合計額・審査結果などを踏まえて決まります。申請額より減額されることがあります。

対象経費は次の2区分です。期間内に契約・取得・支払が終わるものが対象です。

- 事業拠点開設費：設備・備品費、事業所の増改築費（新築・解体を除く）、法人登記費用（印紙代・登録免許税を除く）、消耗品費など
- 事業促進費：人件費（本人と3親等以内の親族を除く）、賃借料、光熱水費、通信運搬費、広告宣伝費など

住居兼店舗は対象外です。支払いは銀行振込・口座振替・クレジットカード（申請者または法人名義）のいずれかで、現金払いは認められません。

## 7. 新潟市の中小企業開業資金との違い

同じ新潟県内の創業支援でも、性格が異なります。市の融資制度を知りたい方は、[【新潟市】中小企業開業資金](/subsidy/sogyo/niigata-shi-chusho-kaigyo-shikin)も参照してください。

| 項目 | U・Iターン創業応援事業 | 新潟市 中小企業開業資金 |
|---|---|---|
| 実施主体 | NICO（公益財団法人） | 新潟市 |
| 性格 | 経費の一部を補助する補助金 | 制度融資（利子補給などを含む） |
| 主な対象 | 県外からのU・Iターン起業、じもと定着起業 | 市内で創業する人・開業間もない人。特定創業支援枠は、市発行の特定創業支援等事業の証明書が条件（詳細は同記事） |
