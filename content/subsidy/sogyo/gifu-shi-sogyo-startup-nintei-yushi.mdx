岐阜市の創業者支援資金【スタートアップ認定枠】とは、岐阜市スタートアップ認定制度でG-STA（岐阜市認定スタートアップ企業）として認定された事業者向けの融資制度です。融資限度額は3,500万円、利率は年1.50%以内で、信用保証料は市が全額を補てんするため事業者負担は0%になります。さらに、利用日から3年間に支払った利子は、年度ごとの申請により全額補給されます。

<SubsidyInfoCard />

## この記事の結論

- 対象は**G-STA（岐阜市認定スタートアップ企業）**で、設立または開業後**5年以内**の法人・個人
- 融資限度額は**3,500万円**、利率は**年1.50%以内**、信用保証料の事業者負担は**0%**（市が全額補てん）
- 利用日から**3年間**の支払利子は全額補給の対象（毎年4月1日〜6月30日に申請が必要）

## 1. 対象者・前提条件

スタートアップ認定枠を利用するには、まず岐阜市スタートアップ認定制度でG-STAとして認定を受ける必要があります。概要PDFに記載された対象者の要件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 認定 | 岐阜市スタートアップ認定制度の認定を受けた者 |
| 経過年数 | 設立又は開業後5年以内の法人又は個人 |
| 事業所 | 市内に事業所を有すること |
| 市税 | 完納していること |
| 返済 | 資金の返済が確実と認められること |

資金使途は運転資金・設備資金です。令和8年度のG-STA認定申請期間は**令和8年9月1日（火曜）〜9月30日（水曜）17時**までで、提出はLoGoフォームから行います。認定要件（市内居住の従業員割合、独自性・成長性・地域貢献性など）の詳細は募集要項で確認してください。

<Callout type="info">
認定制度の経済的支援特典として、市は「保証料の全額補填及び3年間の利子補給」を明示しています。融資枠そのものと利子補給はセットで設計されていますが、利子補給は別途申請が必要です。
</Callout>

## 2. 融資条件・保証料

スタートアップ認定枠の主な条件は次のとおりです（出典: 創業者支援資金【スタートアップ認定枠】の概要PDF、令和8年4月1日改正）。

| 項目 | 内容 |
|---|---|
| 融資限度額 | 3,500万円 |
| 融資利率 | 年1.50%以内 |
| 保証料率（市補てん前） | 年0.45%〜1.90% |
| 市の保証料補てん | 全額（事業者負担0%） |
| 返済期間 | 運転資金10年以内（据置2年以内）／設備資金15年以内（据置2年以内） |
| 返済方法 | 元金均等月賦 |
| 担保 | 不要 |
| 保証人 | 原則不要（法人は代表者を連帯保証人とする場合あり） |

取扱開始は令和7年4月1日で、令和8年4月1日に改正されています。申込みには資格要件申告書、創業計画書（様式第6号）、認定通知書の写しなどが必要です。融資の相談先は岐阜市信用保証協会（058-265-3131）、認定・制度の問合せは商工課スタートアップ推進室（058-214-2771）です。

## 3. 利子補給（G-STA特典）

G-STAの特典として、スタートアップ認定枠を利用した場合、その返済に係る利子の一部（実際には期間中の支払利子の全額）を市が補給します。

| 項目 | 内容 |
|---|---|
| 対象資金 | 創業者支援資金【スタートアップ認定枠】 |
| 交付対象者 | 岐阜市認定スタートアップ企業（G-STA） |
| 利子補給期間 | 対象資金の利用日から3年間 |
| 利子補給額 | 期間中に支払った対象資金の利子額（全額）。申請年度の前年度に支払った利子を補給 |
| 申請時期 | 毎年4月1日〜6月30日 |

<Callout type="warning">
利子補給を受けるには申請が必要です。申請しない場合は補給を受けられません。補給期間中であっても、年度ごとに申請する必要があります。
</Callout>

申請時の提出書類の例は、利子補給金交付申請書（様式第1号）、同意書、誓約書、法人税確定申告書（別表1）の写し、保証書の写し、返済予定表の写し、利子支払を確認できる書類（通帳の写しなど）です。初めて申請する場合は相手方申請書も必要です。

## 4. 申請の流れ

おおよその流れは次のとおりです。

1. 岐阜市スタートアップ認定制度に申請し、G-STAとして認定を受ける
2. 取扱金融機関・岐阜市信用保証協会を通じて創業者支援資金【スタートアップ認定枠】を申し込む
3. 融資実行後、毎年4月1日〜6月30日に利子補給を申請する（利用日から3年間）
