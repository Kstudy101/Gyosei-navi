やまぐち創業補助金とは、山口県内で社会的事業を新たに始める創業者に対し、対象経費の1/2（上限200万円）を補助する山口県の制度です。所管は県の産業労働部経営金融課で、公募の運営は公益財団法人やまぐち産業振興財団が担っています。

**令和8年度の公募は終了しています。** 県ページ冒頭に「令和8年度の公募は終了いたしました。」とあり、公募期間は令和8年4月30日から6月18日（当日消印有効）でした。令和9年度以降の公募の有無・時期は、取得した原文には記載がありません。本記事は令和8年度の公募内容を記録し、制度の骨格を整理したものです。

## この記事の結論

- 令和8年度の公募（令和8年4月30日〜6月18日）は終了済み。令和9年度以降の公募予定は原文に記載なし。
- 補助率は1/2（交付要綱は「1/2以内」）、上限は200万円、採択は11件程度。
- 補助事業期間は交付決定日から令和9年2月末まで。採択後に別途交付申請が必要で、採択通知は交付決定通知ではない。
- 申請前に、電話またはメールでの事前連絡が必要とされていた。

## 1. 対象者・対象事業

### 対象者

令和8年度の公募要領では、次のような方が対象でした（主な条件のみ。全項目は公募要領を確認してください）。

- 事業を営んでいない個人で新たに事業を開始する方、または新会社を設立してその代表者となる方
- 県内に居住していること（補助事業完了日までに県内居住となる場合を含む）
- 山口県内で開業届の提出または法人登記を行うこと（交付決定日以降から事業期間の完了日までの間に行う）
- 県税の滞納がないこと
- みなし大企業でないこと、性風俗関連営業等でないこと

### 対象事業

「やまぐち未来維新プラン」に関連する指定分野の社会的事業の創業が対象です。社会性・事業性・必要性・デジタルの活用を、いずれも満たす必要があるとされていました。制度の趣旨は、人口減少の克服に向け、社会的事業の創業を支援して県内中小企業数の減少を食い止めることです。

## 2. 補助額・対象経費

| 項目 | 内容（令和8年度） |
|---|---|
| 補助率 | 1/2（交付要綱は1/2以内） |
| 補助上限額 | 200万円 |
| 補助事業期間 | 交付決定日から令和9年2月末まで |
| 採択件数 | 11件程度（うち4件程度は三大都市圏の在住者等が対象。申請状況で変更あり） |

### 対象経費（13費目）

人件費、店舗等借料、設備費、原材料費、借料、知的財産権等関連経費、謝金、旅費、マーケティング調査費、広報費、外注費、委託費、その他

### 対象外となる主な経費

- 交付決定日前に発生した経費
- 通信運搬費・光熱水費、消費税
- 汎用PC・タブレット
- 土地・建物の購入、新築・増築
- 中古品、車両購入（艤装した移動販売車等を除く）、事務所の敷金・保証金

### 人件費の留意点

従業員は県内在住であることが必要で、正規の従業員は月額35万円、パート・アルバイトは日額8,000円が上限です。代表者・役員、個人事業主本人と三親等以内の親族の人件費は対象外とされていました。

## 3. 申請方法・審査・スケジュール

令和8年度は原則郵送での申請で、申請前に電話またはメールで財団へ事前連絡を行う必要がありました。審査は書面審査（応募多数の場合は事前審査）とプレゼンテーション審査（山口市内で開催予定）で、審査項目は社会的事業、独創性、計画の明確性、実施体制、雇用創出・地域貢献でした。

### 令和8年度の予定スケジュール

| 時期 | 内容 |
|---|---|
| 令和8年4月30日〜6月18日 | 公募期間 |
| 7月上旬 | 審査委員会・プレゼンテーション審査 |
| 7月中旬 | 採択者決定 |
| 7月中旬〜8月上旬 | 事務処理説明会 |
| 7月下旬〜8月上旬 | 交付申請・交付決定・補助事業開始 |
| 令和9年3月10日まで | 実績報告 |
| 3月上旬〜中旬 | 完了検査 |
| 3月中旬 | 精算払請求 |
| 3月下旬 | 補助金支払 |

事業期間中はヒアリング・現地視察・中間検査が行われます。実績報告書は、事業完了日から10日を経過した日または3月10日のいずれか早い日までに提出することとされています。完了後5年間は毎会計年度終了後の事業化状況報告、書類の5年間保存、単価50万円以上の財産の処分承認などの義務があります。

## 4. 移住支援金について

県ページと公募要領には、東京圏・中京圏（愛知）・近畿圏（京都・大阪・兵庫）・広島県・福岡県の在住者等が交付決定を受けた場合、別途移住支援金を申請できる場合がある旨の記載があります。金額や要件（在住年数等）は本記事では確認できていません。移住予定の市町へ確認してください。

## 5. 本記事で確認できていない事項

- 令和9年度以降の公募予定・時期（原文に記載なし）
- 令和8年度の採択結果
- 三大都市圏の在住者等の枠（4件程度）の具体的な要件
- 移住支援金の金額・要件
- 事業化状況報告の期限日数（公募要領と交付要綱で記載に差があるため、財団への確認が必要）
