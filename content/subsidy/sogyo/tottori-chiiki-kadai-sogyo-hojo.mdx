鳥取県地域課題解決型起業支援補助金とは、地域資源活用や中山間地域振興等の分野で地域課題の解決に取り組む社会的事業を新規起業する方を対象に、鳥取県が事業費の2分の1（最大200万円）を助成する補助金制度です。

<SubsidyInfoCard />

## この記事の結論

- 補助限度額は**200万円**、補助率は**補助対象経費の2分の1**
- 対象は当該年度**4月1日以降に新規起業する方**（同年度4月1日以前の既存開業者は原則対象外）
- 商工会議所・商工会・鳥取県産業振興機構等、**創業支援機関の伴走支援を受けることが必須要件**

## 1. 対象者・支給条件

### 対象となる事業

以下の要件をすべて満たす事業が対象です。

1. **地域資源活用または中山間地振興等の分野**において、地域課題の解決に資する社会的事業であること
   - 地域資源の活用とは、未利用または有効活用されていない県内資源の活用等を指します
   - 中山間地振興とは、「鳥取県みんなで取り組む中山間地域振興条例」で定める中山間地域の区域の振興を指します
2. **鳥取県内で実施**する事業であること
3. 当該年度の**4月1日から補助事業完了日までに新たに起業**する事業であること
4. 公序良俗に反せず、社会通念上適切と判断される事業であること

### 対象者の要件

次の要件をすべて満たす方が対象です。

| 要件 | 内容 |
|---|---|
| 起業の時期 | 当該年度4月1日〜補助事業完了日までに、個人事業の開業届または株式会社・合同会社・NPO法人等の設立を行い、その代表者となる方 |
| 居住要件 | 鳥取県内に居住していること。または事業完了日までに県内へ移住し、完了後も継続して居住する予定であること |
| 登記・開業地 | 個人事業主の開業届提出または法人設立登記を鳥取県内で行う方 |
| 伴走支援 | 商工会議所・商工会・公益財団法人鳥取県産業振興機構・鳥取県信用保証協会等の創業支援機関による支援を受けており、今後も継続的な伴走支援を受ける見込みがある方 |
| その他 | 法令順守上の問題がないこと。風俗営業・反社会的勢力等に該当しないこと |

### 注意事項

採択後も次の場合は補助金を交付できないことがあります。

- 地域おこし協力隊としての活動地である市町村内で起業し、当該市町村からも経費補助を受ける場合
- 鳥取県スタートアップ創出加速化補助金等、他の鳥取県補助金の交付を受ける場合

当該年度4月1日以前に開業届を提出済みの個人事業主や、既に設立登記された法人は**原則対象外**です。ただし、既存事業とは異なる事業で新たに起業する場合は対象となる可能性があるため、事前に窓口へご相談ください。

## 2. 補助限度額・補助率

| 項目 | 内容 |
|---|---|
| 補助限度額 | **200万円** |
| 補助率 | **補助対象経費の2分の1（1/2）** |
| 事業期間 | 交付決定日〜令和9年3月1日（月）まで |
| 採択予定件数 | 予算の範囲内で採択 |

### 補助対象となる主な経費

人件費、店舗等借料、設備費、原材料費（試作品製造用）、借料、知的財産権等関連経費、謝金、旅費、マーケティング調査費、広告費、外注費、委託費 等

**主な対象外経費:**

- 試作品製造以外の目的で使用する原材料費（商品製造に直接係る仕入れ等）
- 一般的な生活家電・生活雑貨・パソコン・タブレット等、汎用性の高いもの

## 3. 申請方法・必要書類

### 令和8年度の募集状況

| 区分 | 期間 |
|---|---|
| 1次募集 | 令和8年6月19日（金）〜令和8年7月31日（金）午後5時必着（終了） |
| 2次募集 | 現在受付中（締切日は公式サイトに未記載）|

2次募集の締切日は鳥取県商工労働部産業未来創造課（電話：0857-26-7246）に直接お問い合わせください。

### 提出方法

募集期間内に以下のいずれかの方法で、鳥取県産業未来創造課産業支援担当へ提出してください。

- 持参または郵送
- とっとり電子申請サービスからのオンライン提出

### 審査の流れ

1. **事前審査（書類審査）:** 提出書類をもとに書類審査を実施
2. **プレゼンテーション審査:** 事前審査通過者が審査会（令和8年度1次は8月下旬予定）でプレゼンテーションを実施
3. **採択通知・公表:** 採否は書面で全員に通知。採択者名・採択テーマは産業未来創造課ホームページで公表

**審査の主な観点:**

| 観点 | 内容 |
|---|---|
| 社会性 | 鳥取県の地域が抱える課題の解決に資する事業か |
| 必要性 | 当該地域でサービスの供給が十分でなく、ニーズが見込まれるか |
| 事業性 | 収益によって自律的な事業継続が可能か |
| 実現性 | 必要な知識・技術・販路・協力先・人材確保等の体制が整っているか |
| デジタル活用 | 情報発信・顧客の利便性向上等にデジタル技術を活用しているか |
