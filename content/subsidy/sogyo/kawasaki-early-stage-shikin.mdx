アーリーステージ対応資金とは、川崎市内に事業所を置く中小企業者等（NPO法人を除く）のうち、これから開業する方または開業後5年未満の方を対象に、川崎市が信用保証料の助成と利率優遇を組み合わせて融資をあっせんする制度です。融資限度額は最大3,500万円、要件を満たせば信用保証料は実質年0.000%になります。

## この記事の結論

- 融資限度額は申込資格1〜3（創業関連保証）で**3,500万円**、資格4（一般保証）で**1,000万円**
- 資格1〜3を利用すれば、信用保証料は市と川崎市信用保証協会の助成で実質**年0.000%**
- 代表者が「女性」「若者（30歳未満）」「シニア（50歳以上）」のいずれかなら、年**0.1%**利率優遇の「女性・若者・シニア起業家支援資金」が使える
- 融資のあっせん・保証料助成・利率優遇の組み合わせで、市が金利を後払いする「利子補給」ではない
- 申込みは川崎市役所ではなく、取扱金融機関の窓口のみ

## 1. 対象者・資格区分

対象は川崎市内に事業所を置く中小企業者等（NPO法人を除く）で、次の4つの申込資格のいずれかに該当する方です。

| 資格 | 対象となる方 | 保証区分 |
|---|---|---|
| 1（創業前・開業後5年未満） | 事業を営んでいない個人で、1か月以内に個人事業を開始する具体的計画がある方／2か月以内に会社を設立し事業を開始する具体的計画がある方（認定特定創業支援等事業の支援を受ける場合はいずれも6か月以内）／個人が新たに事業を開始し、その日以後5年を経過していない方／新たに設立された会社で、設立の日以後5年を経過していない方 | 創業関連保証 |
| 2（分社化） | 自らの事業の全部または一部を継続しながら新たに会社を設立し、その会社が事業を開始する具体的計画を有する方、または設立の日以後5年を経過していない方 | 創業関連保証 |
| 3（法人成り） | 資格1のウに該当する創業者が新たに会社を設立し、事業の譲渡により事業を承継させる場合で、創業者が事業を開始した日から5年を経過していない方 | 創業関連保証 |
| 4（一般保証） | 資格1〜3に該当せず、個人で新たに事業を開始した日以後1年を経過していない方、または新たに設立された会社で設立の日以後1年を経過していない方 | 一般保証・責任共有制度対象 |

資金使途は運転資金と設備資金です（設備資金は市内に設置する設備に限られます）。

アーリーステージ対応資金の申込資格1〜4のいずれかを満たし、代表者が「女性」「若者（30歳未満）」「シニア（50歳以上）」のいずれかに該当する場合は、「女性・若者・シニア起業家支援資金」の対象となり、年0.1%の利率優遇があります。ただし女性・若者・シニア起業家支援資金の公式案内ページには資格1〜3のみが記載されており、資格4（一般保証）との組み合わせについては本記事の取材時点で明記が確認できていません。該当しそうな場合は金融課に直接ご確認ください。

## 2. 融資限度額・利率・信用保証料

### アーリーステージ対応資金（一般）

| 項目 | 内容 |
|---|---|
| 融資限度額 | 資格1・2・3：3,500万円／資格4：1,000万円 |
| 融資利率（年） | 2.2%以内／自己資金が借入額の1/3以上なら2.1%以内／1/2以上なら2.0%以内。または制度所定変動金利（短期プライムレート＋0.7%以内） |
| 融資期間 | 運転資金：7年以内（据置1年以内）／設備資金：10年以内（据置1年以内） |
| 返済方法 | 割賦返済または一括返済（融資期間1年以内に限る） |
| 信用保証料 | 資格1・2・3：年0.000%（所定0.800%－市助成0.500%－川崎市信用保証協会の引下げ0.300%）／資格4：年0.450%から1.900%（協会所定） |
| 責任共有制度 | 資格1・2・3：対象外／資格4：対象 |
| 連帯保証人 | 法人は原則代表者による連帯保証、個人事業主は不要 |
| 担保 | 場合により必要 |

### 女性・若者・シニア起業家支援資金（資格1・2・3のみ）

代表者が「女性」「若者（30歳未満）」「シニア（50歳以上）」のいずれかで、資格1・2・3（創業関連保証）に該当する方が対象です。

| 項目 | 内容 |
|---|---|
| 融資限度額 | 3,500万円 |
| 融資利率（年） | 2.1%以内／自己資金1/3以上で2.0%以内／自己資金1/2以上で1.9%以内（一般より年0.1%優遇） |
| 信用保証料 | 年0.000%（一般と同じ助成の仕組み） |
| 責任共有制度 | 対象外 |

信用保証料の助成は、利用者側での追加の申請手続きは不要です。川崎市が利用者に代わって助成分を川崎市信用保証協会へ支払うため、借受者は保証料を負担しません。

なお、この制度は融資のあっせんと信用保証料の助成、利率優遇を組み合わせたものであり、市が借入利息そのものを補助する「利子補給」ではありません。現金を直接受け取れる補助金でもない点に注意してください。

## 3. 申請方法・必要書類

融資の申込窓口は取扱金融機関のみです。川崎市役所（金融課の窓口）では申込みできません。申込み後は金融上の審査があり、実行までの目安は概ね1か月程度です（審査状況によって前後します）。
