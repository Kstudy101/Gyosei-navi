目黒区の中小企業創業支援資金融資とは、区内で新たに事業を始める人・創業して間もない人を対象に、区が取扱金融機関への融資あっせんと利子補給を行う制度です。現金を直接支給する補助金ではなく、金利の大部分を区が負担することで実質的な低利融資を実現します。

## この記事の結論

- 融資限度額は**1,000万円以内**（特定創業は**1,500万円以内**）
- 金利**1.8%以内**のうち区が**1.6%**を利子補給し、**本人負担は0.2%以内**
- 返済期間は運転・併用が**7年以内**、設備が**9年以内**（いずれも据置1年を含む）
- 申し込みは商工相談所の**予約制**（相談と申し込みで原則2回来所）

## 1. 対象者・支給条件

対象は、区内に主たる事業所（法人の場合は登記上の本店所在地を含む）を置いて中小企業を創業しようとする事業者（創業後1年未満を含む）です。次の（1）〜（3）をすべて満たし、さらにAまたはBのいずれかに該当する必要があります。

1. 本融資に係る事業以外には事業（不動産賃貸業を含む）を営んでいないこと
2. 住民税を滞納していないこと
3. 原則として事業に必要な許認可を受けていること

| 区分 | 内容 |
|---|---|
| 対象A（これから創業） | 融資申込時に事業を営んでおらず、融資希望額と同額以上の自己資金と具体的な計画を持ち、個人は2か月以内・法人は3か月以内・特定創業は6か月以内に創業できること（設立登記後1年未満で事業を開始していない法人を含む） |
| 対象B（創業後1年未満） | 区内に主たる事業所を有し、事業開始（売上発生など客観的に確認できる日）から1年未満であること。法人は会社設立登記日から1年未満 |

「特定創業」に該当する場合は、産業競争力強化法に基づき市区町村長が発行する証明書（有効期限内）の提出が必要です。証明書があると融資限度額が1,500万円以内まで上がります。

信用保証協会の保証対象業種であることも前提です。生活資金・納税資金・住宅資金など事業以外の資金、借入金返済目的の資金（借換・一本化融資を除く）などは申し込めません。

## 2. 融資条件・支給額

令和8年度パンフレット（令和8年4月1日現在）で確認できる条件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 融資限度額 | 1企業1,000万円以内（特定創業は1,500万円以内） |
| 設備資金（対象A） | 上記上限を限度に自己資金の範囲内 |
| 資金使途 | 運転資金 / 運転・設備併用 / 設備資金 |
| 利率 | 1.8%以内（区補助1.6%、本人負担0.2%以内） |
| 返済期間（運転・併用） | 7年以内（据置1年を含む） |
| 返済期間（設備） | 9年以内（据置1年を含む） |

利子補給の受け取り方は、金融機関との約定により異なります。あっせん書の名目利率で借りた場合は年2回程度の補給、本人負担利率で借りた場合はあらかじめ金利に反映されるため年2回の補給はありません。区外へ転出すると利子補給は終了します。

東京都の中小企業制度融資「創業」の要件も満たす場合は、都の信用保証料補助と区の利子補給を併用できることがあります。補助額の詳細はパンフレットに金額が示されていないため、窓口で確認してください。

## 3. 申込み方法・必要書類

窓口は商工相談所（目黒区総合庁舎1階）です。相談・申し込みとも**事前予約制**で、原則2回来所します。

<Checklist items={["オンライン予約専用フォームまたは経済・融資係（03-5722-9880／03-5722-9879）で相談を予約する", "1回目：創業計画書（区所定）などを持参して相談し、申込書の配布と必要書類の説明を受ける", "2回目：申込書と必要書類を持参して申し込む（事前予約）", "後日あっせん書が届いたら、取扱金融機関へ提出して融資を申し込む"]} />

電話の予約受付は月曜日から金曜日、午前8時30分から午後5時です。あっせん書の発行は即融資決定ではなく、金融機関（必要に応じて信用保証協会）の審査を経て実行されます。あっせんから融資実行まで通常1か月程度、許認可が必要な創業支援資金では2か月程度かかると案内されています。

創業支援資金の主な必要書類は、創業計画書（所定用紙）2部、あっせん申込書、許認可の写し（必要な業種）、設備資金の見積書・カタログ等、申込人の確定申告控えまたは源泉徴収票・課税証明書等、住民票（個人番号省略）などです。特定創業の場合は市区町村長発行の証明書も追加で必要です。

創業前の相談だけしたい場合は、中小企業センター内の創業相談室（区民センター2階、電話03-3711-1185）も利用できます。相談日は火曜から金曜で、午後1時または午後2時30分からの枠があり、オンラインフォームで申し込みます。

## 4. 近隣区の同種制度との違い

同じ「融資あっせん＋利子補給」型でも、区によって限度額と本人負担が異なります。

- 目黒区：限度1,000万円（特定創業1,500万円）、本人負担**0.2%以内**
- 新宿区：限度最大2,000万円、本人負担0.2%以下
- 大田区：開業資金限度2,000万円、本人負担0.4%以下（商店街空き店舗・ものづくりは実質0%）
- 文京区：限度1,500万円（区民代表者は2,000万円）、本人負担0%

金額だけで選ぶのではなく、自己資金要件・創業後の経過年数・特定創業証明の要否など、自分の状況に合うかを公式パンフレットと窓口で確認してください。

## まとめ

目黒区の中小企業創業支援資金融資は、区内創業・創業1年未満の事業者向けに、融資あっせんと利子補給で本人負担を0.2%以内に抑える制度です。限度額は原則1,000万円、特定創業なら1,500万円まで広がります。申し込みは商工相談所の予約制で、創業計画書の準備が必要です。最新の利率・取扱金融機関・必要書類は、区の融資あっせん制度一覧と令和8年度パンフレットで必ず再確認してください。本記事は申請代行を行うものではありません。
