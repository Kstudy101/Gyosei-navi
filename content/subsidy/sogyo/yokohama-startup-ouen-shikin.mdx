スタートアップおうえん資金とは、横浜市が取扱金融機関を通じてあっせんする中小企業融資制度のひとつで、**会社のみ**を対象にした創業・スタートアップ向けメニューです。全国統一保証制度の「スタートアップ創出促進保証制度」を利用し、融資限度額は3,500万円以内、固定金利は1.9％以内です。担保と連帯保証人は不要で、市が定める支援プログラム修了などの条件を満たせば信用保証料は市が全額助成し、事業者負担はゼロになります。

## この記事の結論

- 対象は**会社のみ**（NPO法人は利用不可）。個人事業のみでは使えない
- 融資限度額**3,500万円以内**、固定金利**1.9％以内**
- **担保不要・連帯保証人不要**
- 条件該当時、信用保証料は助成前0.6％から**事業者負担ゼロ**（横浜市が全額助成）
- 既存の「創業おうえん資金」（金利2.3％以内・保証料0.1％助成）とは別メニュー

## 1. 対象者

公式ページでは、融資申込要件の全てを満たす中小企業者のうち、次のいずれかに該当する場合が追加要件です。

| 区分 | 内容 |
|---|---|
| これから創業 | 現在事業を営んでいない個人に限り、**2か月以内**に横浜市内で会社を設立し事業を開始する（特定創業支援等事業の支援修了証明がある個人は**6か月以内**） |
| 既に創業 | 会社設立から**5年未満**（当該事業開始時に他の事業を営んでいない場合に限る） |
| 個人→会社承継 | 個人事業開始後に新たに会社を設立し、事業の全部または一部を承継させる場合で、個人事業開始から5年未満 |
| 分社化 | 事業を継続している会社が新たに設立（分社化）した会社で、設立日から5年未満（横浜市内での分社化を含む） |

いずれも全国統一保証制度「スタートアップ創出促進保証制度」の対象であることが前提です。NPO法人は利用できません。

## 2. 融資条件

| 項目 | 内容 |
|---|---|
| 資金使途 | 運転資金および設備資金 |
| 融資額 | 3,500万円以内 |
| 利率（年利） | 固定金利：**1.9％以内** |
| 融資期間 | 運転・設備とも10年以内（据置12か月以内。プロパー融資との同時実行等の場合は36か月以内を含む） |
| 担保 | 不要 |
| 連帯保証人 | 不要 |
| 保証料率 | 助成前：0.6％ → 助成後：**事業者負担ゼロ**（横浜市が全額助成）※協会による保証料率割引（0.4％）適用後の全額助成 |

### 保証料全額助成の対象

全額助成は、次のいずれかに該当する会社が対象です（公式ページ記載）。

1. 特定創業支援等事業のセミナー等を受講し修了
2. 横浜市が指定する支援プログラムのいずれかを修了（YOXO関連・トライアル助成金・TECH HUB YOKOHAMA成長加速化伴走支援プログラムなど。年度により事業名が異なる）
3. Science Tokyo 横浜ベンチャープラザに入居中
4. 「横浜市スタートアップビザ」における確認証明書の発行を受けた
5. 日本政策金融公庫の挑戦支援資本強化特別貸付（資本性ローン）を利用している、または本資金と当該貸付で協調融資を受ける

創業おうえん資金が保証料の**0.1％助成**であるのに対し、本資金は条件を満たせば**全額助成**になる点が大きな違いです。

## 3. 創業おうえん資金との違い

| 比較軸 | 創業おうえん資金 | スタートアップおうえん資金 |
|---|---|---|
| 対象 | 個人・会社（型により異なる） | **会社のみ** |
| 利率 | 固定金利2.3％以内 | 固定金利**1.9％以内** |
| 担保・保証人 | 型により異なる（保証不要特別型は両方不要） | **両方不要** |
| 保証料の市助成 | 0.1％助成 | 条件該当時**全額助成（負担ゼロ）** |

どちらが合うかは、個人か会社か、保証料ゼロ条件を満たせるかで変わります。いずれも市が現金を直接支給する補助金ではなく、金融機関の融資あっせん型です。

## 4. 申請の流れ・必要書類

必要書類の細部は対象区分（特定創業支援修了、市指定プログラム、公庫協調など）で異なります。認定申請書兼認定書は、あらかじめ横浜市経済局イノベーション推進課（TEL 045-671-3487）へ提出し認定を受ける必要があります（認定の有効期間は認定日から3か月以内）。計画策定の相談は（公財）横浜企業経営支援財団でも受け付けています。
