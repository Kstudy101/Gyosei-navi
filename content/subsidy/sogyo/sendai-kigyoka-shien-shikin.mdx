仙台市の「新事業創出支援融資（起業家支援資金）」とは、新たに創業する方や創業後5年を経過していない方を対象に、融資限度額3,500万円・利率年1.2%で運転資金または設備資金をあっせんする市の中小企業融資制度です。現金の直接補助ではなく、取扱金融機関を通じた融資あっせん型です。

<SubsidyInfoCard />

## この記事の結論

- 融資限度額は**3,500万円**、融資利率は**年1.2%**（運転資金・設備資金）
- 融資期間は**10年以内**（据置期間1年以内）。スタートアップ創出促進保証では条件により据置**3年以内**も可
- **担保は不要**。保証人は保証の種類により異なり、スタートアップ創出促進保証なら保証人不要
- 申込みは市役所ではなく**取扱金融機関へ直接**

## 1. 対象者・申込条件

対象は、新たに創業する方や創業後5年を経過していない方です。基本的要件に加え、次の条件を満たす必要があります。

- 事業を行うに当たって、詳細かつ実効性のある事業計画が策定され、これを実施する経営能力を有すること
- 原則として、事業に着手していることが客観的に明らかであること
- 許認可等を必要とする事業については、その取得状況が客観的に明らかであること
- 次の**イまたはロ**のいずれか一に該当すること

### イ. 創業・再挑戦関連保証の対象となる者

創業を行おうとする者、または創業後5年を経過していない方が含まれます。創業予定の個人は、原則として1か月以内（認定特定創業支援等事業の支援を受け市町村長の証明がある場合は6か月以内）に新たに事業を開始する計画などが求められます。会社設立の場合は原則2か月以内（同証明がある場合は6か月以内）です。

### ロ. スタートアップ創出促進保証の対象となる者

創業を行おうとする者、または創業後5年を経過していない方が対象です。保証申込受付時点で税務申告1期未終了の創業者は、**創業資金総額の10分の1以上の自己資金**を有していることが条件になります。

## 2. 融資条件

| 項目 | 内容 |
|---|---|
| 資金使途 | 運転資金または設備資金 |
| 融資限度額 | 3,500万円 |
| 融資利率 | 年1.2% |
| 融資期間 | 10年以内（据置期間1年以内） |
| 保証人 | 創業・再挑戦関連保証: 必要に応じて（法人代表者以外の連帯保証人は原則徴求せず）／スタートアップ創出促進保証: 不要 |
| 担保 | 不要 |
| 信用保証 | 信用保証協会の信用保証が必要。保証料は創業・再挑戦関連保証 年0.7%、スタートアップ創出促進保証 年0.9% |
| 返済方法 | 原則として元金均等返済 |

スタートアップ創出促進保証の場合、申込金融機関において本保証付融資と原則同時にプロパー融資を実行する、または保証申込み時にプロパー融資の残高があるときは、据置期間を3年以内まで設けることが可能です。

## 3. 申請方法・必要書類

融資の審査・決定は金融機関および信用保証協会が行います。仙台市の窓口ではなく、公式ページ「申込先及び取扱金融機関」に記載の金融機関へ直接申し込んでください。
