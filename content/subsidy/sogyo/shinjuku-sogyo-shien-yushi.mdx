新宿区の創業資金融資とは、区の中小企業向け制度融資の一つで、区が利子の大半と信用保証料の一部を補助する形で、区内での創業予定者・創業5年未満の人に低利融資をあっせんする制度です。「創業等支援融資制度」として実施されています。

<SubsidyInfoCard />

## この記事の結論

- 融資限度額は**2,000万円**（創業予定者は1,000万円、分社化は1,500万円）
- 金利2.1%以下のうち区が1.9%以下を負担し、**本人負担は0.2%以下**
- 信用保証料も支払額の**2分の1（上限26万円）**が補助される

## 1. 対象者・支給条件

対象となるのは、次のいずれかに該当する人です。

- 現在事業主でなく、法人または個人で創業しようとする人
- 分社化しようとする人
- 法人または個人で創業し、5年未満の人
- 分社化により創業し、5年未満の人

いずれも東京信用保証協会の保証対象業種を営み、住民税・事業税を滞納していないことが必要です。法人は本店（営業の本拠）と本店登記を区内の同一所在地に置くこと、個人は事業所（営業の本拠）を区内に置くことが求められます（区内在住1年以上の場合は東京都内での創業も可）。

「登記のみ」「郵便受取のみ」のバーチャルオフィスや、都度払いで座席を利用する契約の事務所は対象外です（個人事業主で区内在住1年以上の場合を除く）。

## 2. 支給額・計算方法

| 区分 | 内容 |
|---|---|
| 貸付限度額 | 2,000万円（創業予定者は1,000万円、分社化は1,500万円） |
| 貸付期間 | 7年以内（据置期間12か月以内） |
| 金利 | 2.1%以下 |
| 本人負担 | 0.2%以下 |
| 区負担 | 1.9%以下 |
| 信用保証料補助 | 支払った信用保証料の1/2を補助（上限26万円） |

## 3. 申請方法

創業資金は通常の融資と異なり、1回2時間の面談を複数回受ける必要があります。

## 4. あわせて知っておきたい特例

区が認める商店会・商店街振興組合の区域内にある空き店舗（1か月以上営業していない店舗）を借りて創業する場合、「商店街空き店舗活用支援資金（空借）」を利用できます。創業資金の要件に加えて商店会等への加入などが必要ですが、**利子と信用保証料が全額補助**される、より有利な制度です。
