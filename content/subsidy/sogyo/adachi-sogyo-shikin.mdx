足立区中小企業融資「創業資金」とは、区が中小企業者に金融機関からの融資をあっせんし、区民が支払う利息の一部（利子補給）と信用保証料の一部を区が補助する制度です。融資限度額は1,000万円（特定創業支援等事業の認定事業者は2,000万円）で、①創業前から初回確定申告前までの人向けと、②確定申告済みで開業後5年未満の人向けの2区分があります。

## この記事の結論

- 融資限度額は**1,000万円**（特定創業支援等事業の認定事業者は**2,000万円**）
- 利子補給率は①申告前**2.9%**、②申告後は貸付利率の3分の2（上限**1.9%**）。信用保証料補助は3分の2（**限度額50万円**）
- 案内資料に記載の「運転資金3年・設備資金5年・併用資金4年」は**利子補給を受けられる期間**であり、実際の返済期間・貸付利率そのものは取扱金融機関との相談で決まります

## 1. 対象者・支給条件

創業資金には、確定申告の実施状況で分かれる2つの区分があります。

**①申告前**

- 過去に創業資金①・②を利用したことがなく、事業を営んでいない個人で、足立区内で新たに個人事業を始める、または法人を設立して開業する人
- または、区内で開業してから初回の確定申告時期が到来していない人

**②申告後**

- ①の要件を満たして開業し、確定申告を済ませている人で、開業後5年未満の人（区外で開業した後、営業実態のある事業所とともに区内へ転入した場合を含む）

いずれの区分も、次の共通要件をすべて満たす必要があります。

- 足立区内に住所（法人は本店または支店登記）を有する、または融資あっせんを受けるまでに区内へ転入する
- 区内に営業実体がある（住所や登記が区内でも、実質的な事業活動が区外の場合は対象外）
- 区民税（法人は法人都民税）その他税金の未申告・滞納がない
- 東京信用保証協会の保証対象業種である
- 現在・将来にわたって暴力団員等に該当しない、暴力団員等が経営を支配していると認められる関係を有しない

許認可が必要な業種は、その許認可等の取得が条件になります。また融資決定の時点で事業に着手していることが必要です。

## 2. 融資限度額・利子補給・保証料補助の内容

創業資金は区が現金を直接交付する制度ではなく、区が契約する取扱金融機関からの借り入れに対して、利子補給と信用保証料補助の2種類の支援を組み合わせる「融資あっせん型」の制度です。令和8年4月1日現在の内容は次のとおりです。

| 項目 | 内容 |
|---|---|
| 資金使途 | 運転資金・設備資金・併用資金 |
| 融資限度額 | 1,000万円（特定創業支援等事業の認定事業者は2,000万円）。①は1回限りの利用、②は①の残高と合算して管理 |
| 利子補給期間 | 運転資金3年、設備資金5年、併用資金4年（①②共通） |
| 利子補給率 | ①申告前2.9%　②申告後は貸付利率の3分の2（上限1.9%、小数点以下第二位切捨） |
| 信用保証料補助 | 保証料の3分の2（限度額50万円） |
| 返済期間・貸付利率 | 金融機関にご相談ください（区が定めるのは利子補給率・保証料補助のみ） |
| 信用保証 | 東京信用保証協会の保証が必要（個人タクシー事業者は別途案内） |
| 連帯保証人・担保 | 個人は原則不要。法人は代表者以外の連帯保証人は原則不要 |

ここで注意したいのが、「利子補給期間」と「返済期間」は別物だという点です。案内資料の「利子補給率および期間」欄に書かれている運転資金3年・設備資金5年・併用資金4年は、あくまで区が利子補給（利息の一部を補助）してくれる期間を指します。融資そのものの返済期間や貸付利率は、資料に「金融機関にご相談ください」と明記されているとおり確定した数値がなく、実際に融資を取り扱う金融機関が個別に審査・設定します。

返済期間が利子補給期間より長くなる場合、超過分の利息は区の補助対象外になる可能性があります（※編集部の推測です。案内資料に明記はありません）。申込時に取扱金融機関へ確認することをおすすめします。

申込みから融資実行までは、次の流れで進みます。

融資あっせん申込み時に必要な主な書類は次のとおりです。

- 創業計画書（①申告前は中小企業相談員の確認印が必要。②申告後は不要）
- 納税証明書原本、区民税領収書、引落口座通帳原本のいずれか一つ（個人）／履歴事項全部証明書（法人）
- 住民票原本（個人、3か月以内発行、本籍・マイナンバー記載なし）
- 確定申告書の控（②申告後は必須。①申告前は不要）
- 見積書（設備資金を申し込む場合。有効期限内で発行日・宛名が記載されたもの）
- 自己資金を確認できる預金通帳・有価証券等（創業前のみ必要）

融資あっせん申込みから融資実行までは、おおむね3〜4週間かかります。書類作成や申請そのものの代行は行っていないため、実際の記入・提出は申込者自身で行う必要があります。
