熊本市の創業サポート資金（正式名称: 熊本市中小企業創業サポート資金融資制度）とは、創業予定者や創業後5年未満の事業者向けに、市が取扱金融機関へ資金を預託し、熊本県信用保証協会の保証付きで融資をあっせんする制度です。融資限度額は1事業者あたり2,000万円以内で、現金を交付する補助金ではなく、借入・返済が前提の制度融資です。

## この記事の結論

- 融資限度額は**2,000万円以内**、融資期間は**7年以内**（据置は最大1年・期間に含む）
- 金利（固定）は**3年以内 年1.30%以内**／**5年以内 年1.45%以内**／**7年以内 年1.60%以内**
- 保証料率はパンフレット上**年0.35%**（特例対象者は**年0.00%**）。県外移住者・事業承継者は保証料全額補給あり
- 事業承継者は当初**3年**の支払利子全額補給（1会計年度**10万円**・総額**30万円**以内）も利用できる場合がある
- **現金直接補助ではなく、市預託の制度融資**である点に注意

## 1. どんな制度か｜補助金との違い

創業サポート資金は、熊本市中小企業融資制度のメニューの一つです。市が直接お金を給付するのではなく、市の資金を金融機関に預託し、その原資をもとに取扱金融機関が融資します。融資には熊本県信用保証協会の信用保証が付きます。

一般の制度融資では「市内に1年以上住所があること」「同一事業を1年以上継続していること」が求められますが、創業サポート資金はこの要件の例外です。創業前後の事業者でも申し込めます。

<Callout type="info">
港区などの「現金を交付する創業助成」とは性格が異なります。借りたお金は返済が必要で、金利・保証料の優遇や条件付きの補給が支援の中身です。
</Callout>

## 2. 対象者・支給条件

運用規程では、新規に事業を起こす（起こした）者で、次のいずれかに該当し、かつ市内に住民票住所（法人は本店登記）があり、事業開始に係る具体的計画を持つことが必要です。

| 区分 | 条件 |
|---|---|
| これから個人事業を始める | 事業を営んでいない個人で、**融資実行日から1か月以内**に個人事業を開始する者 |
| これから会社を設立する | 事業を営んでいない個人で、**融資実行日から2か月以内**に会社を設立する者 |
| 認定特定創業支援等事業の証明がある場合 | 上記の個人開始・会社設立とも、証明を受けた者は**6か月以内** |
| すでに個人事業を始めた | 個人事業開始日以降**5年を経過していない**者 |
| すでに会社を設立した | 会社設立日（法人登記日）以降**5年を経過していない**者 |

資金使途は、熊本市内の事業所（店舗）における創業または事業経営に必要な運転資金・設備資金です。新会社設立のための資本金（株式取得資金）は対象外です。

## 3. 融資条件（金額・金利・保証料）

| 項目 | 内容 |
|---|---|
| 融資限度額 | 1事業者につき**2,000万円以内** |
| 融資期間 | **7年以内** |
| 据置期間 | 保証協会および取扱金融機関が認める場合に限り**1年以内**（融資期間に含む） |
| 金利（固定） | 3年以内 **年1.30%以内**／5年以内 **年1.45%以内**／7年以内 **年1.60%以内** |
| 保証料率（パンフ表示） | **年0.35%**（特例対象者は**年0.00%**）※市補助・補給後 |
| 返済方法 | 元金均等返済 |
| 連帯保証人 | 原則として法人代表者以外の連帯保証人は不要 |
| 担保 | 物的担保は徴求しない |

取扱金融機関は、肥後銀行、熊本銀行、熊本信用金庫、熊本第一信用金庫、熊本中央信用金庫、横浜幸銀信用組合、熊本県信用組合、商工組合中央金庫です。相談窓口として、XOSS POINT.、取扱金融機関、熊本商工会議所、市内各商工会も案内されています。

<Callout type="warning">
通常枠の保証料「年0.35%」は令和8年度パンフレットの表記です。この数値が協会基本料率そのものか、別の補助後の数値かの内訳分解は、今回確認した要綱からは特定できません。最新の料率は取扱金融機関または熊本県信用保証協会で確認してください。
</Callout>

## 4. 上乗せ支援｜県外移住者・事業承継者

### 県外移住者の保証料全額補給

次のすべてに当てはまる場合、創業サポート資金の借入時信用保証料が**全額**補給されます。

- 熊本県外に住民登録後**1年以上**経過している
- 定住を目的として、熊本市内に住民登録後**1年以内**である
- 対象融資は**創業サポート資金のみ**

融資申込時に、住民登録の異動を証明する書類の写しが必要です。

### 事業承継者の保証料全額＋当初3年利子補給

事業承継者向けには、保証料全額補給に加え、当初3年間の支払利子全額補給があります。対象融資は**創業サポート資金**または**経営向上小口資金**です。

| 項目 | 内容 |
|---|---|
| 保証料補給 | **全額** |
| 利子補給 | 当初**3年間**の支払利子の**全額**（延滞利息等は除く） |
| 上限 | 1会計年度につき**10万円**かつ総額**30万円**以内 |
| 事前申込期間（令和8年度） | **2026年4月1日〜2026年12月28日**（予算に達し次第受付終了） |

入口ページの要約では「承継予定または承継後**1年未満**」、利子補給要綱では「承継予定または承継後**1年以内**」と書かれています。文言が微妙に異なるため、申請前に最新の要綱と市の案内を確認してください。

<Callout type="warning">
事業承継の保証料・利子補給は、**融資申込の前**に支援機関での事業承継支援について市の認定を受ける必要があります。事前申込は先着順で、予算枠の都合によりお断りや抽選になる場合があります。商業金融課窓口またはオンラインで手続きできます。
</Callout>

入口ページで示されている主な対象要件は次のとおりです（すべて満たす必要あり）。

1. 支援機関（熊本県事業承継・引継ぎ支援センター、熊本商工会議所、熊本県商工会連合会、市内各商工会）で事業承継支援を受けたこと
2. 熊本市内の事業所（店舗）を有機的一体に事業承継する予定、または承継後1年未満（要綱文言では1年以内）であること
3. 融資申込時に取扱金融機関へ必要書類を提出すること
4. 融資実行日から補給金請求日まで、承継した事業を市内で継続していること
5. 熊本市に本店登記または住民登録があること

## 5. 申請の流れ・必要書類

融資本体の申込みは、取扱金融機関を通じて行います。金融機関および熊本県信用保証協会の審査があり、希望どおりの融資が受けられない場合もあります。市の預託額は予算の範囲内で定められます。

市の必要書類の例として、運用規程には熊本市中小企業制度融資借入申込書、信用保証委託申込書の写し、申込人（企業）概要の写しなどが挙げられています。様式は令和7年4月1日に変更されているため、最新版を公式ページで確認してください。

問い合わせの代表電話は096-328-2111です。商業金融課の直通電話は、今回取得した入口ページ本文からは確認できませんでした。
