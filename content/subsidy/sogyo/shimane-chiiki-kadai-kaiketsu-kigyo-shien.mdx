地域課題解決型しまね起業支援事業費補助金とは、島根県内で地域課題の解決を目的とした起業をする方に、経費の一部（補助対象経費の1/2以内、上限200万円）を補助する制度だ。島根県の委託を受けた島根県商工会連合会が執行団体を務める。令和8年度の公募は第1回・第2回とも受付を終了している。

<SubsidyInfoCard />

## この記事の結論

- 補助率は補助対象経費の1/2以内（千円未満切捨て）、上限200万円。下限額の定めはない
- 令和8年度は第1回（2026年4月10日〜5月13日）・第2回（2026年6月22日〜7月28日）とも受付終了。次回公募は未確認（県・商工会連合会の公式ページで確認）
- 社会性・事業性・必要性・デジタル技術の活用のすべてに該当する社会的事業であることが求められる
- 申請は起業予定地の商工会・商工会議所に提出する。事前に市町村窓口での地域課題の確認が必要

## 1. 対象者・対象事業の要件

### 対象者

公募要領では、次の要件をすべて満たす方が対象とされている。

- 当該年度の第1回公募開始日以降、事業期間完了日までに、島根県内で個人事業の開業届出、または法人等（大企業・みなし大企業を除く）の設立を行い、その代表者となる方。または、Society5.0関連業種等の付加価値の高い産業分野で事業承継・第二創業を行う方
- 島根県内に居住している、または補助事業期間完了日までに県内に居住する予定であること
- 島根県税の滞納がないこと
- 自己資金を用意すること
- 法令順守上の問題を抱えておらず、反社会的勢力またはその関係者でないこと

**注意**: 当該年度の第1回公募開始日より前に設立済みの法人、開業届出済みの個人事業主は対象外とされている。ただし、既存事業と異なる新たな事業を行う場合は対象となり得ると記載されている。

### 対象事業

次の4分野のいずれかで、デジタル技術を活用した地域課題の解決に資する社会的事業であることが必要とされる（公募要領基準）。

1. 中山間地域・離島の生活機能の確保に資するサービス
2. まちづくりや地域の活性化に資するサービス
3. 教育や子育て環境の充実に資するサービス
4. 高齢者等の暮らしや福祉向上に資するサービス

さらに、次の4要件のすべてに該当する必要がある。

| 要件 | 内容 |
|---|---|
| 社会性 | 地域課題の解決に資すること |
| 事業性 | サービスの対価として得られる収益により、自律的な事業の継続が可能であること |
| 必要性 | 当該地域で課題解決に資するサービスの供給が十分でないこと |
| デジタル技術の活用 | 生産性の向上、機会損失の解消、顧客の利便性向上につながるデジタル技術を活用していること |

なお、島根県の制度ページにはデジタル技術の活用要件の記載がないが、公募要領には明記されている。他の補助金等を活用する事業は対象外（島根県・市町村等の自主財源によるもので、対象経費の重複がない場合を除く）。

## 2. 補助額・対象経費

| 項目 | 内容 |
|---|---|
| 補助率 | 補助対象経費の1/2以内（千円未満切捨て） |
| 上限額 | 200万円（下限なし） |
| 補助事業期間 | 交付決定日から令和9年1月末日まで |

補助対象経費の精査により、希望額から減額して交付決定される場合がある。

### 対象経費の6区分

| 区分 | 主な対象 |
|---|---|
| 店舗等借入費 | 店舗・事務所・駐車場等の賃借料、共益費、仲介手数料 |
| リース・レンタル費 | 機器・設備等のリース・レンタル料（補助事業期間分のみ） |
| 機械装置等費 | 機械装置・工具・器具・備品・ソフトウェア等の購入費（単価5万円（税抜）以上） |
| 店舗等改修費 | 店舗等の内外装工事費、改築工事費など |
| 広報費 | パンフレット・チラシ・ウェブサイト作成、広告、看板など |
| 外注・委託費 | 自ら実行が困難な業務の一部を第三者に外注・委託する費用 |

対象外の例として、敷金・礼金・保証金、名刺作成費、求人広告、事務用品等の消耗品費、中古品、通信運搬費・水道光熱費などが挙げられている。単価50万円（税抜）以上の機械装置等・店舗等改修は「処分制限財産」に該当し、交付後も一定期間、処分が制限されることがある。

**注意**: 交付決定通知書の受領後でないと補助対象経費の支出はできない。交付決定日前の発注・購入・契約は対象外で、支払は銀行振込が大原則とされている。

## 3. 申請の流れ

1. 起業予定地の市町村窓口で、事業が地域課題の解決に資するものかを確認する（市町村意見書の交付を受ける）。手続きに一定の期間を要するため、余裕をもって相談する
2. 起業予定地にある商工会または商工会議所に申請書類一式を提出する。事業計画書等の作成方法は、支援機関に相談するよう案内されている
