葛飾区の創業支援融資とは、区の中小企業融資あっせん制度のうち、区内で創業する人・創業して間もない人向けの特別融資です。区が取扱金融機関に融資をあっせんし、融資実行後に信用保証料と利子を補助します。令和8年度パンフレットでは、創業支援融資の本人負担利率が「なし」と示されています。

## この記事の結論

- **創業支援融資**の融資限度額は**2,000万円**（最大1口）
- 本人負担利率は**なし**（区負担1.3%。融資利率との差額は金融機関が負担）
- 信用保証料は**30万円まで**補助（都と併用あり）。超過分は金融機関負担
- 申し込みには区の**創業塾（特定創業支援等事業）の証明**が必須
- 創業塾をまだ受けていない場合の受け皿として、**起業家支援融資**（本人負担0.3%以内・限度額2,000万円）もある

## 1. 対象者・支給条件

### 創業支援融資（⑦）・起業家支援融資（⑥）に共通する要件

令和8年度パンフレットでは、次が示されています。

- 区内に主たる事業所を置くこと（法人の場合は本店登記と主たる事業所の両方を区内に置くこと）
- すでに起業している場合は、起業後2年以内であること（起業後2年以内に区内へ移転してきた場合を含む）
- 融資実行後、中小企業診断士による経営状況の確認を受けること

区公式ページでも、個人の場合は主たる事業所が区内であれば住所は区外でもよい旨が、起業家・創業支援の文脈で案内されています。バーチャルオフィス（登記のみ・郵便受取のみ等）は、制度全体の説明上、主たる事業所として認められません。

### 創業支援融資だけの追加要件

- 区の創業塾（特定創業支援等事業による支援）を受けたことの証明を有していること
- この融資と同時、または既にあっせんを受けたこの融資の元金償還が開始するまでは、起業家支援融資（⑥）を申し込めない

### 起業家支援融資だけの留意点

- 創業支援融資（⑦）を受けた場合、起業家支援融資の利用は1口まで
- ⑥と⑦は、同時申込や、既に申し込んだ⑥・⑦の元金償還開始前の追加申込に制限がある

## 2. 融資条件・支給額

令和8年度「葛飾区中小企業融資あっせん制度のご案内」パンフレットの制度一覧に基づく条件は次のとおりです。

### 創業支援融資（⑦）

| 項目 | 内容 |
|---|---|
| 融資限度額 | 2,000万円 |
| 最大口数 | 1口 |
| 本人負担利率 | なし |
| 区負担利率 | 1.3% |
| 金利の補足 | 融資利率と区負担利率の差額は金融機関が負担 |
| 信用保証料補助 | 30万円まで（都と併用あり）。上記超過分は金融機関負担 |

返済期間・据置期間の年数は、同パンフレット一覧表の⑦列で読み取りづらい箇所があるため、最新のパンフレット原本または産業経済課で確認してください。

### 起業家支援融資（⑥）

| 項目 | 内容 |
|---|---|
| 融資限度額 | 2,000万円 |
| 最大口数 | 2口（⑦を受けた場合は1口まで） |
| 資金使途 | 運転／設備／併用 |
| 最大返済期間 | 運転 6年（72か月）／設備・併用 8年（96か月） |
| 据置 | 12か月以内 |
| 本人負担利率 | 0.3%以内 |
| 区負担利率 | 1.3% |
| 上限金利 | 1.6%以内 |
| 信用保証料補助 | 30万円まで（都と併用あり） |

区の融資あっせんは、融資実行・保証承諾を約束するものではありません。金融機関・東京信用保証協会の審査により、減額や否決となる場合があります。

## 3. 申込みから融資実行までの流れ

創業支援・起業家支援は、一般融資と異なり、起業計画書の作成と区の中小企業診断士による認定が必要です。認定・相談は事前予約制です。

必要書類の例（パンフレット「あっせんに必要な書類等」）には、中小企業融資申込書、起業計画書、認定（申請）書、創業支援の場合は創業塾の証明書、個人で起業済みの場合は開業届などが挙げられています。

## 4. 創業塾との関係

葛飾区は産業競争力強化法に基づく創業支援等事業計画の認定を受け、経営・財務・人材育成・販路開拓を学べる「創業塾（特定創業支援等事業）」を実施しています。受講は無料で、修了証明があると創業支援融資のあっせんなど優遇措置の対象になります。開催日程・申込方法は回ごとに変わるため、区の創業支援ページで最新情報を確認してください。
