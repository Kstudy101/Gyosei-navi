横浜市中小企業融資制度「創業おうえん資金」は、これから横浜市内で創業する人や創業間もない事業者を対象に、市が融資をあっせんし、信用保証料の一部を助成する制度です。融資そのものの利率を補助する「利子補給型」ではなく、信用保証料を助成する仕組みである点が特徴です。

<SubsidyInfoCard />

## この記事の結論

- 融資限度額**3,500万円以内**、固定金利**2.3%以内**
- 横浜市が助成するのは利率ではなく**信用保証料**（0.1%分）
- 「経営者保証有」型と「経営者保証不要特別」型の**2区分**があり、対象者要件が異なる
- 担保は原則不要、経営者保証不要特別型は連帯保証人も不要

## 1. 融資条件（経営者保証有型）

これから創業する人（現在事業を営んでいない人に限る）で、1か月以内に横浜市内で個人事業を開始する、または2か月以内に横浜市内で会社を設立し事業を開始する人が対象です（特定創業支援等事業の支援修了証明を受けた事業者は6か月以内）。すでに創業しており、個人事業開始または会社設立から5年未満の事業者も対象に含まれます。

| 項目 | 内容 |
|---|---|
| 資金使途 | 運転資金および設備資金 |
| 融資額 | 3,500万円以内 |
| 利率（年利） | 固定金利2.3%以内 |
| 融資期間 | 運転資金・設備資金とも10年以内（据置12か月以内を含む） |
| 担保 | 原則不要 |
| 保証料率 | 助成前0.4%→助成後0.3%（横浜市が0.1%助成） |

NPO法人はこの資金を利用できません。

## 2. 融資条件（経営者保証不要特別型）

2か月以内に横浜市内で会社を設立し事業を開始する人（現在事業を営んでいない個人に限る、特定創業支援等事業の支援修了証明がある場合は6か月以内）、または会社設立5年未満の事業者が対象です。申込時点で税務申告1期未終了の創業者は、創業資金総額の1/10以上の自己資金を有していることが追加要件になります。

| 項目 | 内容 |
|---|---|
| 融資額 | 3,500万円以内 |
| 利率（年利） | 固定金利2.3%以内 |
| 融資期間 | 運転資金・設備資金とも10年以内（据置12か月以内、同時にプロパー融資を受ける場合は36か月以内） |
| 担保 | 不要 |
| 連帯保証人 | 不要 |
| 保証料率 | 助成前0.6%→助成後0.5%（横浜市が0.1%助成） |

融資を受けた後、原則として会社設立3年目・5年目のタイミングで中小企業活性化協議会による「ガバナンス体制の整備に関するチェックシート」に基づく確認・助言を受ける必要があります。
