南アルプス市創業支援補助金とは、市内で新たに創業する方や第二創業・事業拡大を行う事業者を対象に、補助対象経費（税抜）の3分の2、上限50万円を交付する制度です。機械装置の購入費からウェブサイト・ECサイトの構築費まで、幅広い経費が対象になります。

<SubsidyInfoCard />

## この記事の結論

- 補助率は**補助対象経費（税抜）の3分の2**、上限は**50万円**（概算ではなく必要経費での申請が必須）
- 対象は市内で**創業後5年未満**の個人事業主・会社代表者のほか、第二創業者、事業拡大・新分野進出を行う既存事業者
- 令和8年度の申請期間は**令和8年5月1日（金）～7月24日（金）**。市の資源・魅力（フルーツや観光資源など）を生かした事業を優先的に採択

## 1. 対象者・支給条件

南アルプス市創業支援補助金の対象は、次のいずれかに該当する方です。

1. **市内で新たに創業した方** — 個人開業または会社の設立を行った日から5年未満の個人事業主・会社の代表者
2. **第二創業を行う方** — 個人事業主・会社の代表者で、日本標準産業分類の中分類を越えた業態転換・新事業進出・新分野進出を行う方のうち、事業承継後5年未満の方
3. **事業拡大する方** — 個人事業主・会社の代表者で、新商品・新役務の開発等により現在営む業種の事業拡大を行う方
4. **新分野進出をする方** — 個人事業主・会社の代表者で、現在の業種に加えて日本標準産業分類の中分類を越えた新分野進出を行う方

これらに加えて、次の要件をいずれも満たす必要があります。

- 既に納期の到来した市税等を完納していること
- 市内に事業所等（仮設または臨時の店舗を除く）を設置していること
- 「南アルプス市特定創業支援等事業計画」に基づく特定創業支援等事業に関する証明を、申請期限（令和8年7月24日）までに受けていること（令和9年2月28日時点で創業後5年未満の創業者に限る）、**または**、申請事業の内容を含む経営革新計画の承認（計画の始期が令和8年7月24日以前かつ終期が令和9年2月28日以降）を受けていること

<Callout type="info">
令和8年度は「南アルプス市の資源や魅力（フルーツや観光資源など）を生かした事業」を優先的に採択する方針が示されています。該当する事業計画がある場合は、その旨を申請書に明記することが求められます。
</Callout>

## 2. 支給額・対象経費

補助率は補助対象経費（税抜）の**3分の2**、上限額は**50万円**です。概算額ではなく、必ず必要経費に基づいて申請する必要があります。

対象経費は次のとおりです。

| 経費区分 | 内容 |
|---|---|
| 機械装置等購入費 | 事業の遂行に必要な機械装置等を購入する経費 |
| 広報費 | パンフレット・ポスター・チラシ等の作成や広報媒体活用の経費 |
| ウェブサイト関連費 | 事業に必要なウェブサイト・ECサイト等の構築、更新、改修、開発の経費 |
| 展示会等出展費 | 新商品等の展示会出展・商談会参加の経費 |
| 旅費 | 情報収集・各種調査・販路開拓等に要する旅費（単なる視察・セミナー参加は除く） |
| 開発費 | 新商品の試作品・包装パッケージの試作開発に伴う設計・デザイン・製造・改良・加工費、原材料費 |
| 資料購入費 | 事業遂行に必要不可欠な図書等の購入費 |
| 雑役務費 | 補助事業期間中に臨時的に雇い入れた者のアルバイト代、派遣労働者の派遣料・交通費 |
| 賃借料 | 事業遂行に直接必要な機器・設備等のリース料・レンタル料 |
| 専門家謝金・旅費 | 指導・助言を受けるために依頼した専門家等への謝礼・旅費 |
| 設備処分費 | 作業スペース拡大等を目的とした不要設備の廃棄・処分費、または借用設備の返却時の修理・原状回復費 |
| 委託費・外注費 | 上記に該当しない、事業遂行に必要な業務を第三者に委託・外注するための経費（自ら実行が困難な業務に限る） |

## 3. 申請方法・必要書類

令和8年度の申請期間は**令和8年5月1日（金）～7月24日（金）**です。申請から交付までは次の流れで進みます。

1. **事前準備** — 「特定創業支援等事業に関する証明書」の証明、または「経営革新計画」の承認を受ける
2. **交付申請** — 別添書類とともに期限内に申請書を提出
3. **書類審査**
4. **面接審査** — 書類審査通過者に日程を通知。事業について5分程度のプレゼンテーションと審査委員からの質疑応答
5. **交付決定**
6. **事業実施** — 採択後は市主催イベントへの出店やホームページ掲載用インタビューへの協力を依頼される場合がある。事業年度内の2月末日（令和9年2月末日）までに事業を完了
7. **実績報告書の提出**
8. **補助金交付**

申請先は南アルプス市役所商工振興課の窓口です。所定の申請書に必要事項を記載し、必要書類を添付のうえ直接提出します。
