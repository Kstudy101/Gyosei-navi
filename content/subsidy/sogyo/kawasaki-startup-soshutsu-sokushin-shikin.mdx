スタートアップ創出促進資金とは、これから開業する、または開業後5年未満の**会社**を対象に、川崎市が取扱金融機関を通じてあっせんする創業融資です。スタートアップ創出促進保証（SSS保証）を利用し、**経営者保証と物的担保が不要**です。融資限度額は3,500万円、信用保証料は年0.500%（市の保証料補助の対象外）です。個人事業主は対象になりません。

## この記事の結論

- 対象は**会社のみ**（医療法人・NPO法人を除く）。個人事業主は利用不可
- 融資限度額は**3,500万円**。利率は年2.2%以内（自己資金割合で優遇あり）
- **経営者保証不要・物的担保不要**。信用保証料は**年0.500%**（市補助なし）
- 同じ創業支援資金のアーリーステージ対応資金（保証料実質0.0%）とは別メニュー
- 申込みは**取扱金融機関のみ**。設立後3年目・5年目にガバナンス確認が必要

## 1. 対象者

市公式ページの申込資格は、市内に法人登記（支店を含む）した、または登記する予定の創業者および創業者である中小企業者（医療法人およびNPO法人を除く）で、産業競争力強化法上の創業者区分（設立予定・設立後5年未満・分社化等）のいずれかに該当する方です。

| 項目 | 内容 |
|---|---|
| 対象形態 | 会社（株式会社等）。個人事業主は対象外 |
| 除外 | 医療法人、NPO法人 |
| 自己資金 | 保証申込受付時点で税務申告1期未終了の創業者は、創業資金総額の**1/10以上**の自己資金が必要 |
| 資金使途 | 設備資金・運転資金（創業者が創業者である期間内に行う事業の実施に必要なもの） |

認定特定創業支援等事業の証明書を受けて創業する場合、会社設立の申込み可能時期が通常の2か月前から**6か月前**に緩和されます（市ページ注記）。

## 2. 融資条件

| 項目 | 内容 |
|---|---|
| 融資限度額 | 3,500万円 |
| 融資利率 | 年2.2%以内／借入額の1/3以上の自己資金で創業なら年2.1%以内／1/2以上なら年2.0%以内。または制度所定変動金利（短期プライムレート＋0.7%以内） |
| 融資期間 | 運転・設備とも10年以内（据置期間は1年以内） |
| 据置の例外 | 申込金融機関で本保証付融資と原則同時にプロパー融資を実行する、または保証申込み時にプロパー融資残高がある場合は据置**3年以内** |
| 返済方法 | 割賦返済、または一括返済（融資期間1年以内に限る） |
| 連帯保証人 | 保証人は不要 |
| 担保 | 物的担保は不要 |
| 信用保証 | 必要（スタートアップ創出促進保証） |
| 信用保証料 | 年0.500% |
| 責任共有制度 | 対象外 |

市の申込手続き案内PDFには、本資金は**信用保証料の補助対象外**と明記されています。アーリーステージ対応資金（創業関連保証）で市と信用保証協会の助成により保証料が実質年0.000%になる仕組みとは別です。

## 3. アーリーステージ対応資金との違い

川崎市の創業支援資金FAQ（Q2）は、両制度を次のように対比しています。

| 比較軸 | アーリーステージ対応資金 | スタートアップ創出促進資金 |
|---|---|---|
| 対象 | 個人・法人いずれも可 | **会社のみ** |
| 信用保証料 | 実質**0.0%**（市FAQの表現） | **年0.5%** |
| 経営者保証 | 法人は代表者保証が原則（市FAQ） | **不要** |

どちらが有利かは、個人か会社か、保証料負担と経営者保証の要否のどちらを優先するかで変わります。市が現金を直接支給する補助金ではなく、いずれも金融機関の融資あっせん型です。
