さいたま市の創業支援資金融資とは、市内でこれから創業する方や創業間もない方などに対し、事業に必要な運転・設備資金を取扱金融機関経由であっせん融資する制度です。融資限度額は3,500万円、返済期間は運転・設備とも10年以内（据置1年以内）です。

## この記事の結論

- 融資限度額は**3,500万円**（運転資金／設備資金）
- 返済期間は運転・設備とも**10年以内**（据置期間**1年以内**）、償還は元金均等月賦
- 利率は令和8年9月30日受付分まで**年1.0%**、令和8年10月1日受付分から**年1.20%**（特定創業支援等事業の証明書提出時は**年1.0%**）
- 市が直接貸すのではなく、金融機関からの**あっせん融資**。担保は不要

## 1. 対象者・申込条件

創業支援資金融資の対象は、NPO法人・組合を除き、次のいずれかに該当する方です（融資制度案内PDF）。

1. これから事業を始めようとする方
2. 事業をしながら分社化等を行おうとする方
3. 事業を始めて間もない方
4. 法人成りした者であって、法人成り前に行っていた事業の創業後5年未満の者

あわせて、さいたま市中小企業融資制度の共通要件として、おおむね次を満たす必要があります。

- 法人は市内に本店の登記、個人は市の住民基本台帳の記録の届出をしていること
- 市内に事務所・店舗又は工場があり、事業を営んでいる又は営む予定の中小企業者であること
- 市税を滞納していないこと
- 許認可が必要な業種は原則として許認可を取得していること
- 埼玉県信用保証協会の保証が得られること
- 手形交換所の取引停止処分を現に受けていないこと
- 反社会的勢力でないこと

融資実行後の資金使途にも制約があり、借入金の返済（一部制度を除く）、納税、売買目的の不動産購入、乗用車購入、土地および市外への設備購入資金、支払済・設置済の設備購入資金など、経営上必要な事業資金以外は対象外です。

## 2. 融資条件（限度額・利率・期間）

| 項目 | 内容 |
|---|---|
| 融資限度額 | 3,500万円 |
| 資金使途 | 運転資金／設備資金 |
| 返済期間 | 運転資金／設備資金：10年以内 |
| 据置期間 | 1年以内 |
| 償還方法 | 元金均等月賦償還 |
| 融資利率（〜令和8年9月30日受付） | 年1.0%（特定創業支援証明書添付時は年0.80%・PDF記載） |
| 融資利率（令和8年10月1日受付〜） | 年1.20%（特定創業支援証明書提出時は年1.0%） |
| 保証料率 | 年0.80%以内（スタートアップ創出促進保証制度利用時は年1.0%以内）。証明書取得者・SCAP採択者・さいたま商工会議所会員は規定保証料率から0.1%引下げ |
| 担保 | 不要 |
| 連帯保証人 | 原則として法人代表者を除いて徴求しない（スタートアップ創出促進保証制度利用時は不要） |
| 信用保証 | 埼玉県信用保証協会の保証を付する |

利率改定は市公式ページ（更新日2026年9月18日）のお知らせに基づきます。PDF「さいたま市融資制度のご案内」の記載内容は令和8年4月1日時点であり、最新条件は市ホームページで確認してください。

特定創業支援等事業の証明書があると、創業支援資金融資では信用保証料の0.1%割引に加え、通常利率より0.2%低い優遇金利が適用されます（令和6年10月1日融資受付分から）。証明書の申請は市企業成長推進課へ行います。

## 3. 申請の流れ・相談窓口

一般的な申込の流れは次のとおりです。

1. 取扱金融機関へ融資を申し込み、借入額などを決める
2. 金融機関が代理で受付を依頼する
3. 創業支援資金は原則として現地確認が実施される

受付・相談窓口は次のとおりです。

- **（公財）さいたま市産業創造財団** 支援第一課 金融担当  
  さいたま市中央区下落合5-4-3 さいたま市産業文化センター4階  
  TEL 048-851-6391／FAX 048-851-6392
- **さいたま市** 経済局商工観光部企業成長推進課 企業支援係  
  TEL 048-829-1362／FAX 048-829-1944

必要書類の例として、融資申込書、同意書・誓約書、創業支援資金計画書（様式第3号）、経歴書などが挙げられます。確定申告書または決算書がある場合は計画書が不要になることがあります。最新の様式とチェックリストは公式ページの関連ダウンロードから確認してください。
