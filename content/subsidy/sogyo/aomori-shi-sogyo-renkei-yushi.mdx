「青森県・青森市」連携融資制度とは、青森県が実施する特別保証融資制度の利用者のうち一定の条件に該当する方へ、青森市が信用保証料を補給する仕組みです。創業枠では県の「青森新時代」への架け橋資金を使い、信用保証料を県30パーセント・市70パーセントで全額補給します。現金の創業補助金ではなく、融資に伴う保証料負担を軽くする制度です。

## この記事の結論

- 創業枠の信用保証料は**全額補給**（県30パーセント・市70パーセント）
- 市の補給対象は**融資額1,000万円以内・期間10年以内（据置2年以内）**
- **市への申請は不要**で、取扱金融機関の窓口へ直接申し込む

## 1. 制度の仕組み

青森市単独で融資枠を設けるのではなく、県の特別保証融資を受けた方のうち市の条件を満たす場合に、市が信用保証料を追加で補給します。創業向けのベースになるのは青森県「青森新時代」への架け橋資金です。

市公式ページと令和8年度チラシでは、次の点が共通して示されています。

- 青森県信用保証協会の保証付き融資が前提
- 市への申請手続は不要（金融機関窓口で申し込み）
- 補給は予算の範囲内のため、年度途中で取扱いできなくなる場合がある

現金給付型の創業補助金を探している場合は対象外です。融資を受けて創業・開業資金を調達し、その際の保証料負担を抑えたい方向けの制度です。

## 2. 創業枠の対象者・条件

創業枠の対象は、【中小企業者として創業する（創業後5年未満含む。）事業】により架け橋資金の融資を受けた方のうち、次のすべてに該当する方です。

1. 個人は市内に住所があること、法人は市内に法人登記をした事業者であること（一定の要件を満たすNPO法人を含む）
2. 市税に未納の額がないこと
3. 融資額1,000万円以内かつ融資期間10年以内（うち据置期間2年以内）で融資を受けたこと

さらに、市内事業所の事業資金が対象です。**太陽光発電設備の導入に係る事業は対象外**と明記されています。

## 3. 融資条件と保証料補給

| 項目 | 内容（創業枠） |
|---|---|
| ベース制度 | 青森県「青森新時代」への架け橋資金 |
| 融資額（市補給対象） | 1,000万円以内 |
| 融資期間 | 10年以内（うち据置期間2年以内） |
| 金利 | 取扱金融機関所定利率 |
| 信用保証料 | 全額補給（県30パーセント・市70パーセント） |
| 申込先 | 取扱金融機関（市への申請不要） |

注意点として、**スタートアップ創出枠**を利用する場合は、信用保証料の上乗せ分（0.2パーセント）は補給対象外です。

県の架け橋資金側では、条件を満たす創業者向けの優遇金利も案内されています。

- 女性・UIJターンによる創業: 年1.5パーセント
- 市町村の創業相談窓口を利用して創業: 年1.6パーセント

市チラシ上の表記は「取扱金融機関所定利率」のため、実際の適用利率は申し込み時に金融機関へ確認してください。

## 4. 申し込みの流れ

1. 青森市内での創業計画を整理し、必要なら市や商工会議所などの創業相談窓口も利用する
2. 取扱金融機関（青森みちのく銀行、青い森信用金庫、青森県信用組合など市が掲げる窓口）に相談・申し込み
3. 金融機関と青森県信用保証協会の審査を受ける
4. 融資実行後、県・市の条件に沿って信用保証料が補給される（市への別申請は不要と案内）

取扱金融機関は市公式ページに一覧があります（青森みちのく銀行、岩手銀行、七十七銀行、秋田銀行、北日本銀行、青い森信用金庫、青森県信用組合、商工組合中央金庫、東日本信用漁業協同組合連合会、東北銀行、東奥信用金庫、みずほ銀行、あすか信用組合）。

## 注意事項

- 本制度は融資であり、返済義務があります。審査の結果、希望に添えない場合があります
- 保証料補給は予算の範囲内です。年度途中で取扱いが終了することがあります
- 金額・金利・条件は制度改正や年度更新で変わる可能性があるため、必ず一次情報で再確認してください
- 個別の申請可否や必要書類の最終判断は、取扱金融機関・青森県信用保証協会・青森市の案内に従ってください
