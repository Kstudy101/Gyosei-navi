神戸市独自資金「こうべ創業支援貸付」は、神戸市内で創業した（または創業しようとする）小規模企業者向けの制度融資です。融資限度額は500万円、金利は年1.85パーセントの固定、信用保証料は神戸市が全額負担します。国家のjGrants公募ではなく、兵庫県中小企業向け融資制度の枠組みにある神戸市独自メニューです。

<SubsidyInfoCard />

## この記事の結論

- 融資限度額は**500万円**、金利は**年1.85パーセント（固定）**
- **信用保証料は神戸市が全額負担**（保証付き融資が前提）
- 対象は**事業開始5年未満**の小規模企業者。融資期間は**7年以内**（据置1年以内）

## 1. 制度の位置づけ

神戸市は兵庫県・金融機関・兵庫県信用保証協会と連携した中小企業向け融資制度のなかで、神戸市内の事業者だけが使える「神戸市独自資金」を設けています。こうべ創業支援貸付はその一つで、創業初期の資金調達と保証料負担の軽減を目的とします。

現金を給付する創業補助金ではなく、**返済が必要な融資**です。希望額・条件どおりに借りられるとは限りません。

## 2. 対象者

案内チラシ（令和8年4月1日現在）では、次の要件をすべて満たす方が対象です。

1. 主たる事業所が神戸市内にあり、事業を営んでいること（市内に主たる事業所を置こうとする市外からの進出予定者も対象）
2. 市税を滞納していないこと
3. 常時使用する従業員が20人以下であること（商業＝卸売・小売、サービス業＝宿泊・娯楽・旅行を除く、は5人以下）
4. 事業を営んでいなかった方で、事業を開始して5年未満であること

神戸市独自資金では、申込時に納期到来分の直近の納税証明書（原本）などの提出が求められます。

## 3. 融資条件

| 項目 | 内容 |
|---|---|
| 融資限度額 | 500万円（2026年4月1日保証申込分より400万円から引上げ） |
| 融資利率 | 年1.85パーセント（固定利率） |
| 融資期間 | 7年以内（うち据置1年以内。設備資金のみの場合は据置1年6か月以内） |
| 資金使途 | 設備資金および運転資金（市外からの進出予定者は設備資金に限る） |
| 担保・保証人 | 保証協会または金融機関の定めによる（第三者保証人不要） |
| 信用保証 | 必須。信用保証料の全額を神戸市が負担 |

同じ神戸市独自資金でも、「こうべおうえん」「こうべ躍進」など別メニューがあります。創業支援貸付は**営業開始5年未満**がポイントです。

## 4. 申し込みの流れ

公式ページに示されている一般的な流れは次のとおりです。

1. 取扱金融機関へ融資を申し込む
2. 取扱金融機関が融資審査を行う
3. 取扱金融機関を介して兵庫県信用保証協会へ保証申込
4. 信用保証協会の保証審査・保証承諾
5. 取扱金融機関が融資を実行

こうべ創業支援貸付の案内では、**神戸市経済政策課（中小企業金融担当）でも申し込める**と記載されています。取扱金融機関の一覧は、2026年度兵庫県中小企業融資制度パンフレットで確認してください。

- 本制度は融資であり、返済義務があります。審査により希望に添えない場合があります
