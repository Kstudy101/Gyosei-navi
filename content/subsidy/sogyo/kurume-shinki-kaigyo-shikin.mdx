久留米市の新規開業資金とは、開業直前から開業直後の事業者の資金繰りを支えるため、久留米市が取扱金融機関への融資をあっせんし、金利と信用保証料を優遇する制度です。現金を交付する補助金ではなく、借りたお金は返済が必要な融資である点が前提です。あわせて、借入後1年間の支払利子全額を市が補給します。

## この記事の結論

- 融資限度額は**2,000万円**、借入期間は**10年以内**（据置1年以内）
- 金利は**1.26%**、低利率要件に該当する場合は**1.16%**（令和8年4月1日現在）
- 信用保証料率は市補填後**0%**（スタートアップ創出促進保証制度で経営者保証を免除する場合は**0.2%**）
- **返済開始から1年間の支払利子全額**が補給対象（延滞利子は除く）
- 申し込み前に**創業塾等の修了**（直近2年以内）が必要

## 1. どんな制度か｜補助金との違い

新規開業資金は、久留米市中小企業融資制度のメニューの一つです。市が直接お金を給付するのではなく、指定の金融機関が融資し、福岡県信用保証協会の保証と市の補填・補給で金利・保証料・初年度利子の負担を抑える「あっせん型」の支援です。

福岡市の新規創業促進補助金（登録免許税相当額の定額補助）や北九州市の開業支援資金（融資限度額3,500万円）とは設計が異なります。久留米市の新規開業資金は、限度額2,000万円・保証料0%に加えて**初年度の利子補給**が付く点が特徴です。

## 2. 対象者

令和8年4月1日現在の一覧では、創業塾等を直近2年以内に修了したうえで、次のいずれかに該当する方が対象です。

- 事業を営んでいない個人で、融資実行日から**1ヶ月以内**に市内で開業する具体的な計画がある方
- 事業を営んでいない個人で、融資実行日から**2ヶ月以内**に市内で会社を設立して事業を開始する具体的な計画がある方
- 市内で開業して**6ヶ月未満**の個人または法人
- 市内で開業後6ヶ月以内に法人成りし、その後**6ヶ月未満**の法人

個別ページでは、特定創業支援等事業の証明書がある場合に開業時期が6ヶ月以内まで延びる旨や、市税の完納、暴力団排除の要件も案内されています。自分が当てはまるかは、申込前に新産業創出支援課または受付機関で確認してください。

### 創業塾等の例

- 創業塾（久留米商工会議所・久留米東部商工会）
- くるめ南部個別創業塾（久留米南部商工会）
- 個別による相談支援（田主丸町商工会。東部商工会分は令和3年12月23日以降実施分）
- 女性の起業セミナー（久留米市男女平等推進センター）
- KURUMEビジネススクール（久留米ビジネスプラザ）※一覧PDFに記載

## 3. 融資条件（金額・金利・保証料）

| 項目 | 内容（令和8年4月1日現在） |
|---|---|
| 融資限度額 | 2,000万円以内 |
| 使途 | 設備・運転 |
| 金利 | 1.26%（低利率要件該当時 1.16%） |
| 期間（据置） | 10年以内（据置1年以内） |
| 保証料率（市補填後） | 0%（経営者保証免除適用時は0.2%） |
| 保証人 | 原則、法人は代表者のみ・個人は不要。免除適用時は法人も不要 |
| 利子補給 | 返済開始から1年間の支払利子全額（延滞利子除く） |

### 低利率（1.16%）の対象例

一覧PDFでは、上記の対象要件を満たしたうえで次のいずれかに該当する場合に1.16%となります。

- 女性
- 融資申込時点で30歳未満または55歳以上
- 創業塾等による支援を受けた証明書を持つ方
- 市外から移住して18ヶ月以内の方、または市外から移住予定の方

個別ページの低利率欄には「転入し1年以内」との古い表記が残っていますが、同ページの必要書類欄や最新の一覧PDFは18ヶ月以内の整理です。申請時は最新の一覧PDFまたは窓口の説明を優先してください。

## 4. 利子補給・保証料補給の手続き

利子補給は、新規開業資金と緊急経営支援資金が対象です。返済開始から1年分の支払利子全額について、利子支払い開始月に応じた申請期限（例: 4〜6月開始なら1年経過直後の8月末日）が設けられています。申請時期には市から案内が送付されます。

なお、中小企業融資制度一般の「信用保証料の補給」（350万円以内の融資で支払済み保証料の償還払い）とは別メニューです。新規開業資金自体の保証料率は市補填により原則0%のため、制度の主眼は金利優遇と初年度利子補給側にあります。

## まとめ

久留米市の新規開業資金は、創業塾等の修了を前提に、開業前後の運転・設備資金を最大2,000万円まであっせんする融資制度です。金利1.26%（条件により1.16%）、保証料0%、初年度利子補給という組み合わせは、現金補助型ではないものの開業初期の負担を抑える設計です。条件や利率は改定され得るため、申し込み前に[久留米市の新規開業資金ページ](https://www.city.kurume.fukuoka.jp/1090sangyou/2020shoukougyou/3010shienseido/sinki01.html)と最新の融資制度案内PDF、新産業創出支援課（0942-30-9136）で確認してください。

個別の融資可否や必要書類の記入代行については本サイトでは対応できません。受付機関・取扱金融機関の案内に従ってください。
