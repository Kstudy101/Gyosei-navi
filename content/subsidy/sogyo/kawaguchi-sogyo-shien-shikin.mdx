川口市の中小企業創業支援資金融資とは、市内で創業しようとする方、または事業開始後5年以内の方に対し、創業時に必要な資金を取扱金融機関経由であっせん融資する制度です。貸付限度額は1,000万円（自己資金額の10倍まで）、利率は固定金利・年1.3%です。

## この記事の結論

- 貸付限度額は**1,000万円**（自己資金額の**10倍まで**）
- 利率は固定金利**年1.3%**、信用保証料は**年0.8%以内**（埼玉県信用保証協会）
- 運転資金・設備資金とも返済期間は**10年以内**（うち据置期間1年以内）。市が直接貸すのではなく**あっせん融資**
- 公式ページの最終更新日は**2018年4月1日**のため、金利・保証料など最新条件は申込前に市へ確認が必要です

## 1. 対象者・支給条件

融資対象は、市内で事業に必要な許認可等を受けて、埼玉県信用保証協会の信用保証対象業種の事業を営む方または営んでいる方（個人事業主は申請日現在市内に住所を有する者）で、次のいずれかに該当する方です。

1. 事業を営んでいない個人で、1ヶ月以内に新たに個人で、または2ヶ月以内に新たに会社を設立しようとする具体的計画を有する個人
2. 中小企業である会社が新たに中小企業である会社を設立し、その会社が事業を開始しようとする具体的計画を有する会社
3. 事業を営んでいない個人が事業を開始し、開始後5年未満の中小企業者
4. 事業を営んでいない個人が設立した会社で、設立後5年未満の中小企業者（事業を営んでいる個人が設立した場合は、事業開始時から起算して5年未満であること）
5. 中小企業である会社が新たに設立した会社であって、設立後5年未満の中小企業者

設備資金を申し込む場合は、市内に設備を設置することが条件です。信用保証協会の保証が得られない場合は融資を受けられません。

## 2. 融資条件（貸付限度額・利率・期間）

川口市の制度融資は「あっせん融資」であり、金融機関を通じて融資が行われます。公式ページに記載の条件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 貸付限度額 | 1,000万円（自己資金額の10倍までの貸付） |
| 貸付期間（運転資金） | 10年以内（うち据置期間1年以内） |
| 貸付期間（設備資金） | 10年以内（うち据置期間1年以内） |
| 利率 | 固定金利：年1.3% |
| 連帯保証人 | 個人…原則不要、会社…原則代表者のみ |
| 担保 | 原則として無担保 |
| 信用保証 | 原則として埼玉県信用保証協会の保証を付する |
| 保証料 | 年0.8%以内 |

**注意**: 公式ページの最終更新日は2018年4月1日です。金利・保証料率などがその後変更されている可能性があるため、申し込みを検討する際は最新条件を川口市経営支援課に確認してください。
