荒川区の創業支援融資とは、区の中小企業融資制度の一つで、荒川区が金融機関・東京信用保証協会と連携し、区内で創業する人・創業後1年未満の人に低利融資をあっせんする制度です。区が利子の一部と信用保証料の全額を補助する「利子補給＋信用保証料補助」の仕組みで、実質的な借入負担を下げます。

## この記事の結論

- 融資限度額は**1,500万円以内**
- 表面金利1.9%のうち区が1.4%を利子補給し、**本人負担は年利0.5%**
- 信用保証料は**荒川区が全額補助**
- 融資あっせん申込みの前に、区の中小企業診断士による**創業相談（予約制・平均4回程度）**を受け、開業計画書の承認を得ることが必須

## 1. 対象者・支給条件

対象となるのは、次のいずれかに該当する人です。

- 事業を営んでいない個人が、荒川区内で新たに個人事業主として、または法人（NPO法人を除く）を設立して創業しようとする場合
- 上記の人が荒川区内で創業し、融資あっせん申込み時において創業した日から1年未満の場合

ここでいう「事業を営んでいない個人」とは、原則、給与所得以外の収入がない個人を指します。他の法人の代表権を有する役員である人、フリーランスで事業所得がある人、不動産賃貸業を営み不動産所得がある人は、既に事業を営んでいる個人とみなされ、原則対象外です。会社員等として働いている場合は、融資実行前までに退職する必要があります（副業としての創業は不可）。

「荒川区内で創業」とは、個人の場合は創業当初から継続して荒川区内に主たる事業所を置くことを指します（区外在住者でも可）。法人の場合は、創業当初から継続して荒川区内に主たる事業所を置き、かつ本社と本店登記地が設立当初から引き続き荒川区内にあることが必要です。荒川区外での創業は、その後荒川区内に移転する場合を含めて対象外です。住所利用や郵便受取のみのバーチャルオフィスも、主たる事業所として認められません。

このほか、以下の要件をすべて満たす必要があります。

- 創業する業種が東京信用保証協会の保証対象業種であること（不動産賃貸業での創業は不可、NPO法人は利用不可）
- 許認可・届出等を要する事業の場合、その許認可等を受けている、または融資実行前までに受けること
- 申込み日までに納付すべき各種税金（個人は区民税・所得税・事業税、法人は法人税・事業税）を完納等していること
- 外国籍の場合、日本で事業活動を行える在留資格を有していること
- 「開業計画書」（第22号様式）を作成し、区の創業相談において相談員の審査・承認を受けていること

## 2. 融資条件・支給額

令和8年4月1日現在（【令和8年4月改訂】創業支援融資のご案内）の条件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 融資限度額 | 1,500万円以内 |
| 資金使途 | 運転資金、設備資金、運転・設備併用資金 |
| 表面金利（区基準金利） | 年利1.9% |
| 区の利子補給 | 1.4% |
| 本人負担利率 | 年利0.5% |
| 信用保証料 | 荒川区が全額補助 |
| 返済期間 | 運転資金・運転設備併用資金：7年以内（据置期間1年以内を含む）／設備資金：10年以内（据置期間1年以内を含む） |
| 保証人 | 個人は原則不要／法人は原則代表者本人 |
| 担保 | 信用保証協会における保証額の合計が8,000万円以内の場合、原則不要 |

決算実績のない創業前の申込者については、開業計画書内の資金計画にもとづき、運転資金（4か月相当分が目安）の融資限度額を積算します。融資実行時に既に支払済みの経費は、原則として融資対象外です。

利子補給は返済期間中継続しますが、区外への転出、廃業、目的外使用、あっせんに基づかない条件変更などの事由があった場合は中止されます（何年間で打ち切りといった年数の上限は原文に明示されていません）。また、この融資の申込み・あっせんについては、金融機関担当者による代理申請の対象外とされており、原則として申込者本人による手続きが必要です。

## 3. 申込みから融資実行までの流れ

創業支援融資は、他の融資メニューと異なり、あっせん申込み前の「創業相談」と「開業計画書」の作成・承認が必須です。

区が案内している目安として、相談開始から融資実行まで平均約3か月程度かかります（内訳：創業相談が平均約1か月、あっせん申込みから融資実行までが平均約2か月）。融資実行前に支払う経費（賃貸店舗の仲介手数料や家賃等）は自己資金でまかなう必要があり、荒川区の融資あっせんは融資実行そのものを保証するものではない点にも注意してください。
