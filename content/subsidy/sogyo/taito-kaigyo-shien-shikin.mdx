台東区の開業支援資金（台開）とは、区内でこれから開業する人、または開業後1年未満の人向けに、区が利子と信用保証料を補助する形で低利融資をあっせんする制度です。区が直接資金を貸し付けるものではありません。

<SubsidyInfoCard />

## この記事の結論

- あっ旋限度額は**1,000万円**（自己資金額の3倍程度の範囲内）
- 貸付利率1.8%以内のうち区が全額補助し、**本人負担は0%**
- 信用保証料も区が**全額補助**
- 申し込み前に商工相談員との**予約制面談（原則3〜4回）**が必要

## 1. 対象者・支給条件

融資希望額の3分の1程度の自己資金を持ち、住民税等を完納しており、区内で開業する方で、次のいずれかに該当することが必要です。

- 事業を営んでいない個人で、個人または法人として創業しようとする方
- 分社化しようとする方（中小企業者である法人が出資して子会社を設立する場合など。代表者・役員の個人出資のみによる子会社設立は分社化とみなされない）
- 事業を営んでいない個人が個人または法人で創業し、創業後1年未満の方
- 分社化により創業し、創業後1年未満の方
- 特許・意匠登録・法律に基づく資格により創業する方、またはその創業後1年未満の方（詳細は問い合わせ）

案内パンフレットでは、信用保証協会の保証対象業種であること、法人は営業の本拠かつ本店登記地が台東区内であることなども条件として示されています。「事業を営んでいない個人」は、事業所得で確定申告していない方などが該当します。

## 2. 融資条件

| 区分 | 内容 |
|---|---|
| あっ旋限度額 | 1,000万円（自己資金額3倍程度の範囲内） |
| 資金使途 | 運転資金・設備資金 |
| 貸付期間 | 700万円以内：7年以内（据置12か月以内）／700万円超：9年以内（据置12か月以内） |
| 貸付利率 | 1.8%以内 |
| 区補助 | 1.8%以内 |
| 本人負担 | **0%** |
| 返済方法 | 毎月元金均等割賦返済 |
| 信用保証 | 原則として東京信用保証協会の信用保証が必要 |
| 保証料補助 | **全額** |

保証人および担保の要否は、信用保証協会・金融機関の要件によります。利率・補助の数値は区公式ページ（2026年7月21日更新）および案内パンフレット（令和7年4月1日現在）に基づきます。

## 3. 申請の流れ

開業支援資金は、通常の制度融資と異なり、申し込み前の商工相談員面談が必須です。

<Checklist items={["産業振興課融資担当（03-5829-4128）へ電話するか来所して面談を予約する", "事業主本人が商工相談員と面談する（原則3〜4回、すべて同じ相談員）", "開業計画書など必要書類を整える", "区から融資あっ旋書の交付を受ける", "希望する提携金融機関で融資申込み・審査を受ける"]} />

面談は平日（祝日除く）午前10時〜正午、午後1時〜午後4時の1時間単位です。面談開始から融資実行まで通常2〜3か月かかるため、余裕をもって申し込む必要があります。あっ旋取得後も金融機関と信用保証協会の審査があります。借入希望の金融機関には事前に相談しておくと手続きがスムーズです。

NPO法人での申し込みは事前問い合わせが必要です。
