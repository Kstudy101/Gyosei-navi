江戸川区の創業支援資金融資（略称：区創業）とは、区内で創業しようとする人、及び創業後間もない中小企業者に必要な資金を、区と融資取扱契約を結んだ金融機関があっせんする制度です。融資自体は区が直接お金を交付するのではなく、区が利子の一部（利子補給）と信用保証料の全額を事後的に補助することで、実質的な低利融資を実現します。

## この記事の結論

- 融資限度額は**2,000万円**（創業予定の個人は必要資金の3分の2以内）
- 年利率2.0%以内のうち区が1.5%以内を利子補給し、**本人の実質負担は0.5%**
- **信用保証料は全額補助**（東京信用保証協会の保証を利用）
- 対象は創業A（創業予定の個人）・創業B（創業後3年未満）・創業C（分社化後3年未満の子会社）の3区分
- 原文に募集期間の記載はなく、通年受付のあっせん融資とみられるが確定情報ではない

## 1. 対象者・支給条件

### 基本要件

以下をすべて満たす中小企業者が対象です。

- 法人は法人税・法人都民税又は法人市町村民税を、個人は所得税・特別区民税又は市町村民税を完納していること
- 信用保証協会の保証対象業種であること
- 法律に基づく資格・許認可等を要する業種は、その資格・許認可等を受けていること（受けることが確実と見込まれる場合を含む）
- 中小企業者であること

### 創業段階の要件（創業A・B・Cのいずれか）

**創業A（創業予定の個人）**

- 事業を営んでいない個人であること
- 新たに個人で、又は新たに法人を設立して江戸川区内で創業しようとする具体的な計画を有すること
- 基本要件のうち「中小企業者であること」を除く全てに該当すること

**創業B（創業後3年未満の個人・法人）**

- 事業を営んでいない個人が、個人又は法人で創業し、創業した日から3年未満であること
- 法人は江戸川区内に本店及び事業所を、個人は江戸川区内に事業所を有していること
- 創業した日から引き続き同一事業を営んでおり、創業時から代表者に変更がないこと

**創業C（分社化後3年未満の子会社）**

- 分社化により設立された法人であって、設立された日から3年未満であること
- 江戸川区内に本店及び事業所を有していること
- 設立された日から引き続き同一事業を営んでいること

## 2. 融資条件・支給額

原文で確認できる融資条件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 資金使途 | 運転資金・設備資金（設備資金は原則区内の設備に係るものに限る） |
| 融資限度額 | 2,000万円（創業予定の個人は必要資金の3分の2以内） |
| 償還期間 | 7年以内（据置1年以内） |
| 年利率 | 2.0%以内 |
| 利子補給 | 1.5%以内 |
| 本人実質負担 | 0.5% |
| 信用保証料 | 全額補助 |

信用保証は東京信用保証協会が担い、創業関連保証を利用すると原則として融資額の100%が保証されます。ただし、申込人がNPO法人である場合や、創業保証の保証限度額を超過する場合などは100%未満となります。連帯保証人は、法人は原則代表者、個人は原則不要です。物的担保も原則不要ですが、不動産関連の融資などでは求められる場合があります。

融資実行後6か月経過から1年経過までの間に、区による経営指導が行われます。経営指導を実施できない場合は利子補給が停止となる点に注意してください。

## 3. 資金使途と対象外となるケース

資金使途は直接の事業活動のために必要な資金に限られ、次のような資金・ケースは対象外です。

- 支払済の資金
- 法人の代表者が個人事業主として別事業を創業するための資金
- 法人が子会社を設立するための出資金など

申込みから融資実行までは、区の経営診断や信用保証協会の審査に時間を要するため、目安として3か月程度かかります。許認可等が必要な業種の場合は、許認可を受けた後に融資が実行されるため、余裕をもって相談してください。
