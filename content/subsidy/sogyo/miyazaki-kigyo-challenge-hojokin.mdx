宮崎県の「女性・若者応援！起業チャレンジ支援事業費補助金」は、女性や若者が社会課題の解決や地域づくりに資する事業を起業する際に補助金を交付する県の制度です。社会性・事業性・必要性・デジタル技術の活用という観点の「社会的事業」への起業支援を目的としており、2つのメニューがあります。**令和8年度は受付終了**です。

<SubsidyInfoCard />

## この記事の結論

- **ビジネスプランコンテスト事業**: 対象経費の1/2以内・上限**300万円**
- **地域魅力度アップ事業**: 対象経費の1/2以内・上限**100万円**
- **令和8年度（2026年度）は受付終了**（ビジネスプランコンテストは5/1〜6/15、地域魅力度アップは6/1〜6/29で終了）
- よろず支援拠点のビジネスプランブラッシュアップが申請の必須要件

## 1. 2つのメニュー

### （1）ビジネスプランコンテスト開催事業

女性や若者（35歳未満）の起業・事業承継・第二創業を対象に、審査を経て最大300万円を補助する事業です。

| 項目 | 内容 |
|------|------|
| 対象者 | 女性または35歳未満（令和8年4月1日時点）で起業・事業承継・第二創業する者 |
| 補助率 | 対象経費の**1/2以内** |
| 補助上限 | **300万円**（コンテストの審査によって決定） |
| 令和8年度公募期間 | 令和8年5月1日〜6月15日（終了） |

### （2）地域魅力度アップによる女性・若者の県内定着応援事業

性別・年齢制限なし（女性・若者にとって魅力的な地域づくりに資する事業が要件）の地域課題解決型の起業を支援するメニューです。

| 項目 | 内容 |
|------|------|
| 対象者 | 性別・年齢制限なし。新たに起業・事業承継・第二創業する者 |
| 補助率 | 対象経費の**1/2以内** |
| 補助上限 | **100万円** |
| 令和8年度公募期間 | 令和8年6月1日〜6月29日（終了） |

## 2. 対象となる事業

両メニーとも、交付要綱が定める「社会的事業」の全要件（社会性・事業性・必要性・デジタル技術の活用）を満たす事業が対象です。農商工連携・6次産業化・子育て支援・移住対策・地域おこし・買物弱者対策・地域交通・高齢者対策・防災・減災など、持続可能な社会づくりの分野が想定されています。

## 3. 対象経費

人件費、店舗等借入費、設備費、原材料費、知的財産権等関連経費、謝金、旅費、外注費、委託費、マーケティング調査費及び広報費

詳細な対象経費の条件は、公益財団法人宮崎県産業振興機構ホームページの募集要領（外部サイト）でご確認ください。

## 4. 申請の前に必須の相談

<Callout type="warning">
各事業への申請には、**宮崎県よろず支援拠点コーディネーターによるビジネスプランのブラッシュアップが必須**です。公募期間は短いため、早めに事前相談の予約を取ることを強くおすすめします。
</Callout>
