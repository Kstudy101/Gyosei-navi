北九州市の開業支援資金とは、開業時や開業後5年未満の事業者の資金繰りを支えるため、北九州市が取扱金融機関への融資をあっせんし、金利と信用保証料を優遇する制度です。現金を交付する補助金ではなく、借りたお金は返済が必要な融資である点が前提です。

## この記事の結論

- 融資限度額は**3,500万円**、融資期間は**10年以内**（据置は1年または2年以内）
- 金利は**一般枠1.50%**、**特別枠1.40%**
- 信用保証料率は**初回利用時に限り0.00%**（2回目以降は0.36〜1.38%）
- 担保は原則不要。個人事業主は保証人不要。法人は必要に応じて代表者が保証人（保証料0.2%上乗せで代表者保証を外せる場合あり）

## 1. どんな制度か｜補助金との違い

開業支援資金は、北九州市中小企業融資制度のメニューの一つです。市が直接お金を給付するのではなく、指定の金融機関が融資し、市と福岡県信用保証協会の枠組みで金利・保証料を抑える「あっせん型」の支援です。

令和5年度からは、要件を満たしたうえで保証料を0.2%上乗せすると、法人の代表者を保証人にしない選択肢も用意されています。創業直後の経営者保証負担を下げたい場合に検討できる仕組みです。

## 2. 対象者（一般枠・特別枠）

### 一般枠の主な対象

- 新たに事業を開始しようとする、これまで事業を営んでいなかった個人（業種経験2年以上、資格を生かした開業、または国・県・市等の開業支援講座修了など、所定の要件を満たす場合。ただし自己資金が事業資金の2分の1以上ある場合や、特定創業支援事業の証明を得た場合は、その一部要件が免除される）
- 事業を営んでいなかった個人が、個人または会社で創業して5年未満の方
- 県内の会社が現事業を続けつつ、新たに市内で会社を設立する方、または分社化した会社で設立5年未満の方
- 法人成企業で、個人創業から5年未満の方

### 特別枠の主な対象

特別枠は金利が1.40%と一般枠より低く、次のような追加条件があります。

- 新たに事業を開始しようとする女性、申込時点で35歳未満または55歳以上の男性、あるいは市外からの転入者（一般枠と同様の経験・資格・講座修了などの要件あり）
- 事業を営んでいなかった個人で、新たに雇用創出を伴う事業または市の認定等を受けた事業を開始する方
- 創業5年未満の方のうち、代表者が女性・35歳未満または55歳以上の男性・市外転入者・市内での雇用創出者、または市の認定等を受けた方
- 法人成で個人創業から5年未満の方で、上記と同様の属性・認定等がある方

対象事業の一部には、商店街空き店舗活用事業（新規開業）やスタートアップ関連事業など、市が指定する事業も含まれます。自分がどの枠に入るかは、申請前に中小企業振興課または取扱金融機関で確認してください。

## 3. 融資条件（金額・金利・保証料）

| 項目 | 内容 |
|---|---|
| 融資限度額 | 3,500万円 |
| 期間（据置） | 10年以内（据置1年または2年以内） |
| 金利（一般枠） | 1.50% |
| 金利（特別枠） | 1.40% |
| 保証料率 | 初回利用時0.00%。2回目以降は0.36〜1.38% |
| 保証人 | 法人は必要に応じて代表者。個人事業主は不要 |
| 担保 | 原則不要 |
| 返済方法 | 一括償還または分割償還 |

経営者保証を外す場合（保証料0.2%上乗せ）は、据置が1年以内に制限され、新規開業または税務申告1期未終了の方は開業資金総額の10分の1以上の自己資金が必要です。さらに、原則として法人設立3年目・5年目に中小企業活性化協議会のガバナンス体制チェックを受け、チェックシートを金融機関へ提出する必要があります。

## 4. 申請の流れ・必要書類

申込みは取扱金融機関（14行）または北九州商工会議所（本所・サービスセンター）で受け付けます。取扱金融機関は、原則として福岡県信用保証協会北九州支所の担当地区および北九州市に隣接する市町村の本店・支店です。

必要書類は、これから開業する方・創業5年未満の方・法人成の方で異なります。北九州市公式ページに様式PDF・Excelと「開業支援資金チェックリスト（令和8年4月～）」が掲載されているため、申込前に最新版を確認してください。

## 5. あわせて知っておきたい関連制度

北九州市では、商店街の空き店舗へ出店する場合の「商店街空き店舗活用補助金（シャッターヒラクプロジェクト）」など、開業時の改装費を対象とする現金補助もあります（令和8年度は賃借料補助の新規受付は終了し、改装費補助が中心）。融資と補助金は性質が異なるため、併用の可否や手続き順はサービス産業政策課（電話093-582-2050）へ確認してください。

また、産業競争力強化法に基づく特定創業支援等事業を受けると、株式会社設立時の登録免許税軽減などのメリットがあります。COMPASS小倉などの創業相談窓口もあわせて活用できます。
