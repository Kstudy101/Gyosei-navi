大津市創業促進事業費補助金は、市内における創業を促進し地域経済の活性化を図るため、新たに事業を開始する者に対して創業当初の経費の一部を補助する制度です。補助率は対象経費の2分の1で、一般は上限50万円、令和9年3月31日時点で35歳以下の若者は上限100万円となっています。

<SubsidyInfoCard />

## この記事の結論

- 補助率は対象経費の**1/2**（千円未満切り捨て）
- 一般上限**50万円**、35歳以下の若者は上限**100万円**
- **令和8年度2次募集は締切済み**（2026年8月31日）。次回は大津市公式サイトで確認
- プレゼンテーション審査（第1次審査通過者対象）がある
- 支援機関の継続的な支援を受けていることが要件

## 1. 対象者

次のすべてに該当する者が対象です。

## 2. 補助額

| 区分 | 補助率 | 上限額 |
|---|---|---|
| 一般 | 対象経費の1/2 | 50万円 |
| 若者（令和9年3月31日時点で35歳以下） | 対象経費の1/2 | 100万円 |

補助対象経費の合計額に1/2を乗じた額とし、1,000円未満の端数は切り捨てです。

## 3. 補助対象経費

| 経費の種類 |
|---|
| 店舗等借入費 |
| 店舗等改装費 |
| 設備費 |
| 広報費 |
| ウェブサイト関連費 |
| 報酬費 |
| その他（募集要項で確認） |

※消費税は補助対象外経費です。

## 4. 申請方法

- 提出先: 産業観光部商工労働政策課（大津市役所別館3階）
- 提出方法: メール、郵送または持参
- プレゼンテーション審査: 第1次審査通過者に日時を連絡
