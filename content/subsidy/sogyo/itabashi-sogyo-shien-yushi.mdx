板橋区の創業支援融資とは、区内でこれから創業する人・創業後1年未満の人を対象に、東京信用保証協会や金融機関の協力を得て融資をあっせんし、あわせて貸付利率の8割（42か月まで）を区が利子補給する制度です。融資そのものは金融機関が行うため、区の窓口は「あっせん」と「利子補給」を担う立場になります。

## この記事の結論

- あっせん限度額は、開業前は**自己資金と同額まで**が目安、開業後1年未満は**2,000万円以内**が上限
- 貸付利率（融資実行時の長期プライムレート以内・固定金利）の**8割を42か月まで区が利子補給**
- 直接融資を申し込む制度ではなく、**区の中小企業診断士との面談→創業計画書の作成→経営診断**を経て、計画が妥当と認められて初めて融資があっせんされる

## 1. 対象者・支給条件

原則として、次の要件をすべて満たす「中小企業者」が対象です。

- 法人の場合、本店登記および活動実態（本社機能）が区内にあること。個人の場合、主たる売上の事業所が区内にあること（代表者・事業主の住所地は区外でもかまいません）
- 申込みをする日までに納期が到来している住民税を完納していること
- 東京信用保証協会の保証対象業種を営んでいること
- これから開業する場合は、申込日現在、事業を営んでいない個人であること。すでに創業している場合は、事業開始日時点で事業を営んでいない個人であったこと
- 資金の使途が適切であり、かつ返済能力があること

許認可が必要な業種で申し込んだ場合、融資の実行は許認可取得後になります。また、開業後1年以内の追加融資は受けられません。

## 2. 融資条件（限度額・利率・返済期間）

| 項目 | 内容 |
|---|---|
| あっせん限度額 | 開業前：自己資金と同額まで（目安）／開業後1年未満：2,000万円以内（上限） |
| 資金使途 | 運転資金・設備資金（併用可） |
| 返済期間 | 7年（84か月）以内（据置1年以内を含む） |
| 貸付利率 | 融資実行時の長期プライムレート以内（固定金利） |
| 利子補給 | 上記貸付利率に対し、42か月まで区が8割を助成 |
| 保証関係 | 東京信用保証協会の保証を付ける |

貸付利率は融資を実行する時点の長期プライムレートに連動するため、本記事執筆時点で確定した数値（%）は公開されていません。実際の利率は融資実行時に金融機関から案内されます。

## 3. 申請方法・必要書類

この制度は、区役所の窓口で融資を直接申し込むものではありません。**区の中小企業診断士による経営診断を受け、計画が妥当と認められて初めて融資があっせんされる**しくみです。

<Checklist items={["産業振興課（03-3579-2172）に電話し「創業相談」を予約する", "区の中小企業診断士と面談し、「創業計画書」を作成する", "診断士による経営診断を受ける（開業地への訪問診断を含む）", "計画が妥当と認められたら融資のあっせんを受け、金融機関で手続きを進める"]} />

相談時間は午前9時から午後5時まで1時間ごと（正午から午後2時、土日祝日を除く）です。相談窓口は産業振興課（板橋区板橋2-65-6 情報処理センター5階）です。

## 4. 東京都の制度との併用

板橋区の産業融資制度と東京都の融資制度の双方の要件を満たす場合、板橋区の利子補給と東京都中小企業制度融資（信用保証料補助）を併用できることがあります。東京都は信用保証料の3分の2を補助します。併用する場合は信用保証協会への申込時に追加資料の提出が必要で、一部対象外の金融機関もあるため、事前に東京都のホームページで確認してください。
