京都市の創業支援資金とは、市内でこれから創業する人や創業間もない事業者の資金調達を支えるため、京都市が取扱金融機関への融資をあっせんし、京都信用保証協会の保証を付けて利率の上限を設ける制度です。現金を交付する補助金ではなく、借りたお金は返済が必要な融資である点が前提です。本記事ではチラシに並ぶ3類型のうち、創業予定・創業後5年未満向けの「創業型」を中心に解説します。

<SubsidyInfoCard />

## この記事の結論

- 創業型の融資限度額は通常**1,500万円以内**。認定特定創業支援等事業の修了などで**3,500万円以内**に拡充できる
- 融資利率は**年1.7%以内（固定金利・令和8年5月1日現在）**。金利情勢等により変更される場合あり
- 現金補助ではなく、京都信用保証協会保証付きの**返済が必要な制度融資**

## 1. 対象者・利用条件（創業型）

創業型の対象は次のとおりです。

- 京都市内で創業する方
- 創業後5年未満の方

資金使途は**運転資金・設備資金**です。申込みには京都信用保証協会の保証と、取扱金融機関の審査が必要です。保証料は別途かかります。

<Callout type="info">
同じ「創業支援資金」チラシには、事業転換・多角化型（限度額1億円以内）と第二創業型（限度額2,000万円以内、うち運転資金は1,000万円以内）も掲載されています。対象・限度額が創業型と異なるため、該当する場合はチラシ原本または取扱金融機関で確認してください。
</Callout>

## 2. 融資条件（金額・金利・期間）

令和8年5月1日現在の創業型の条件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 融資限度額 | 1,500万円以内（認定特定創業支援等事業による支援を受けた場合等は3,500万円以内） |
| 融資利率 | 年1.7%以内（固定金利）。金利情勢等により変更される場合あり |
| 融資期間 | 運転資金7年以内（うち据置1年以内）／設備資金10年以内（うち据置1年以内）。創業関連保証を利用する場合は運転・設備とも10年以内（うち据置1年以内） |
| 返済方法 | 元金均等月賦返済（据置期間中は利息のみ） |
| 信用保証 | 京都信用保証協会の保証が必要（別途保証料） |
| 保証人 | 原則として法人代表者以外の連帯保証人は不要 |
| 担保 | 必要に応じて徴求 |

<Callout type="warning">
保証料率の具体額は保証内容に応じて個別に算定されるため、公式チラシ・一覧ページには一律の料率が掲載されていません。実質負担を事前に把握したい場合は、取扱金融機関または京都信用保証協会に確認してください。
</Callout>

## 3. 認定特定創業支援等事業との関係

創業型で融資限度額を**3,500万円以内**へ拡充するには、京都市・京都府指定セミナーの修了、商工会・商工会議所等の経営支援、指定インキュベート施設への入居、認定特定創業支援等事業による支援など、所定の要件を満たす必要があります。

京都市の特定創業支援等事業を修了し証明書の交付を受けると、融資限度の拡充以外にも次のメリットがあります（【経営】【財務】【人材育成】【販路開拓】の全4分野の支援受講が必要）。

1. **登録免許税の軽減**（株式会社の最低税額は15万円→7.5万円、合同会社は6万円→3万円。資本金の0.7%が0.35%に）
2. **創業関連保証の早期利用**（通常より早い、事業開始6ヶ月前から）
3. **日本政策金融公庫**の新規開業・スタートアップ支援資金で特別利率の適用（別途公庫の審査が必要）
4. **小規模事業者持続化補助金**の創業型への申請（上限200万円。過去1年以内の支援受講かつ1年以内の開業が条件）

証明書の申請はオンラインフォームから行い、発行まで概ね10日程度と案内されています。特定創業支援の問い合わせ先は京都市スタートアップ・産学連携推進室（創業支援担当）です。

## 4. 申請の流れ・取扱金融機関

1. 制度融資取扱金融機関の窓口で京都市制度融資（創業支援資金）の利用を相談する
2. 必要書類をそろえ、金融機関を経て京都信用保証協会へ保証申込を行う
3. 金融機関と保証協会の審査を経て融資が実行される（実行時に保証料が必要）
4. 契約条件に従って金融機関へ返済する

取扱金融機関は次のとおりです（一覧ページ・チラシ共通。制度によって取扱金融機関が異なる場合があるため、申込前に確認してください）。

- 京都銀行
- 南都銀行
- 滋賀銀行
- 関西みらい銀行
- 池田泉州銀行
- 京都信用金庫
- 京都中央信用金庫
- 近畿産業信用組合
- 京滋信用組合
- 三菱UFJ銀行
- みずほ銀行
- 商工組合中央金庫
