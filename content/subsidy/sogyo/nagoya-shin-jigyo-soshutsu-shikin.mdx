名古屋市の新事業創出資金とは、創業や分社化に必要な資金を、名古屋市信用保証協会の保証付きで取扱金融機関から借り入れる制度融資です。現金を交付する補助金ではなく、借りたお金は返済が必要です。同市のスタートアップ企業支援補助金（経費補助・上限100万円）とは別の制度です。

<SubsidyInfoCard />

## この記事の結論

- 融資限度額は**3,500万円**（ページ更新日2026年4月1日時点）
- 設備・運転資金の利率は**年1.4%〜1.6%**、設備資金10年以内は**年1.7%**
- 現金補助ではなく、信用保証付きの**返済が必要な制度融資**

## 1. 対象者・利用条件

申込の対象は、市内で事業を行う会社または個人で、次の（1）〜（7）のいずれかに該当することです。

| 区分 | 内容 |
|---|---|
| （1） | 事業を営んでいない個人で、1か月以内に事業を開始すること |
| （2） | 事業を営んでいない個人で、2か月以内に新たに会社を設立すること |
| （3） | 会社が新たに会社を設立（分社化）し、事業を開始すること |
| （4） | 事業を営んでいない個人が事業を開始し、開始後5年未満であること |
| （5） | 事業を営んでいない個人が会社を設立し、設立後5年未満であること |
| （6） | 創業者である個人事業主が設立した会社で、創業（事業開始）から5年未満であること |
| （7） | 会社が新たに会社を設立（分社化）し、設立後5年未満であること |

公式ページの注記は次のとおりです。

- （1）（2）に該当する方は**名古屋市内に住所があること**が必要
- （1）（2）で特定創業支援等事業により支援を受けた方は**6か月以内**
- 経営者保証を不要とする場合は、市内で開業する会社で（2）（3）（5）（6）（7）のいずれかに該当すること

資金使途は**設備・運転資金**（および設備資金）です。責任共有制度は**対象外**と案内されています。

## 2. 融資条件（限度額・金利・期間）

| 項目 | 内容 |
|---|---|
| 限度額 | 3,500万円 |
| 設備・運転資金の利率 | 3年以内 年1.4%／5年以内 年1.5%／7年以内 年1.6% |
| 設備資金の利率 | 10年以内 年1.7% |
| 返済方法 | 分割返済（据置12か月以内） |
| 担保・保証人 | 名古屋市信用保証協会所定 |
| 信用保証料 | 名古屋市信用保証協会所定 |

経営者保証を不要とする場合かつ税務申告1期未終了者については、**創業資金総額の10分の1以上の自己資金**を有することが条件です。

日本政策金融公庫と協調した取り扱いができる**協調推進枠**もあります。詳細条件は原文では概要のみのため、取扱金融機関または信用保証協会で確認してください。

<Callout type="warning">
融資条件等は変更になる場合があります。信用保証料の具体額は「名古屋市信用保証協会所定」とだけ記載されており、本記事では一律の料率を確認できていません。申込前に取扱金融機関または信用保証協会へ確認してください。
</Callout>

## 3. 利率の優遇措置（補助金認定者）

名古屋市スタートアップ企業支援補助金の事業認定通知を受けた方は、新事業創出資金の融資利率を**所定利率から0.1％引き下げる**優遇を受けられる場合があります。

必要な資格要件確認書は、次のいずれかです。

- 「名古屋市スタートアップ企業支援補助事業認定通知書」の写し
- 「名古屋市スタートアップ企業支援補助金交付決定通知書」の写し

優遇期間は、資格要件確認書に記載の日付が属する年度を含め、**3年度以内**に名古屋市信用保証協会が保証承諾した分までです。

## 4. 申請の流れ・問い合わせ

1. 名古屋市融資制度の取扱金融機関に相談・申し込む
2. 必要に応じ、名古屋市信用保証協会へ直接申し込む
3. 金融機関と信用保証協会の審査を経て融資が実行される
4. 契約条件に従って返済する

取扱金融機関の個別一覧は本ページではリンク先案内のみのため、公式の「名古屋市融資制度の取扱金融機関」から確認してください。

問い合わせ先は次のとおりです。

- 名古屋市信用保証協会：052-212-3011
- 経済局 産業労働部 中小企業振興課 金融担当：052-735-2100（ファクス 052-735-2104）

## 5. スタートアップ企業支援補助金との違い

| 項目 | 新事業創出資金（本制度） | スタートアップ企業支援補助金 |
|---|---|---|
| 性格 | 信用保証付き制度融資（返済必要） | 経費の一部を補助（現金補助） |
| 上限の目安 | 融資限度額3,500万円 | 補助限度額100万円 |
| 令和8年度の募集 | 制度融資のため随時（条件変更の可能性あり） | 募集終了（令和8年5月1日〜6月1日） |

経費補助を先に検討する場合は、別記事のスタートアップ企業支援補助金もあわせて確認してください。
