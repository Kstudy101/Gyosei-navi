横浜市の産前産後ヘルパー派遣事業は、妊娠中の心身の不調や産後の家事・育児負担を軽減するため、市が委託した事業者からヘルパーを自宅へ派遣する制度です。現金給付ではなくサービス利用型で、利用料は1回（2時間以内）あたり1,500円、所得に応じて減免があります。

## この記事の結論

- **現金ではなくヘルパー派遣**（家事・育児の支援）
- 利用料は**1回1,500円**（生活保護・住民税非課税は無料、所得割77,100円以下は500円）
- 産前・産後**各20回以内**（多胎児は産後40回以内）、月〜金・1回2時間以内
- **令和7年4月1日から第1子妊娠も対象**
- 希望事業者へ事前確認のうえ、**区役所こども家庭支援課の窓口申請**（郵送不可）

## 1. 対象者・利用条件

横浜市内に住民登録をしている世帯で、次のいずれかに該当する場合が対象です。

1. **妊娠中**で、心身の不調等があり、かつ日中に家事または育児を行う者が他にいないため支援が必要な世帯
2. **出産後5か月未満**（多胎児の場合は出産後1年未満）で、日中に家事または育児を行う者が他にいないため支援が必要な世帯

令和7年4月1日から、第1子の妊娠でも利用できるようになりました。早産などでお子さんが入院中でも、区役所に相談のうえ利用できる場合があります。

育児支援は、保護者とお子さんが一緒にいる場所で行います。ヘルパーだけでの留守番はできません。

## 2. 利用料・回数・時間

| 区分 | 内容 |
|---|---|
| 基本利用料 | 1回（2時間以内）1,500円 |
| 生活保護世帯 | 無料（保護証明が必要） |
| 住民税非課税世帯 | 無料（市民税・県民税非課税証明書） |
| 市民税算出所得割額77,100円以下 | 500円（市民税・県民税課税証明書） |
| 利用時間 | 月曜〜金曜 9時〜17時（12/29〜1/3・祝日を除く） |
| 回数上限 | 産前・産後各20回以内（多胎児は産後40回以内）、1日2回まで |

転入などで横浜市で課税状況を確認できない場合は、世帯全員分の証明書が必要です。買い物や保育園送迎などで片道おおむね1km以上移動する場合の公共交通費は利用者負担です（自宅までのヘルパー往復交通費は事業者が負担）。

利用規定では、利用予定日の3日前（土日祝・年末年始を除く）17時以降に変更・中止を連絡するとキャンセル扱いとなり、連絡タイミングによりキャンセル料（前日17時以降800円、当日出発後1,500円など）が発生する場合があります。

## 3. 申請から利用開始まで

<Checklist items={["委託事業者一覧から希望事業者へ電話し、派遣可否を事前確認する", "「横浜市産前産後ヘルパー利用(登録)申請書」を記入し、区役所こども家庭支援課の窓口で申請する（郵送不可・面接あり）", "妊娠中の利用は診療情報提供書（または診断書）を添付する", "利用承認通知書の到着後、利用希望日の3日前17時までに事業者へ日程連絡する"]} />

サービス利用開始希望日の**7日前（閉庁日を除く）**までに申請してください。産前と産後を続けて使う場合も、それぞれ別の利用手続が必要です。出産後の利用を見据える場合は、**妊娠32週以降**であれば事前の利用登録ができます。

承認通知の到着時期について、公式案内ページは「数日後」、利用規定PDFは「1〜2週間程度」と記載しています。余裕をもって申請してください。
