江戸川区老朽住宅除却工事助成事業とは、昭和56年5月31日以前の旧耐震基準で建てられた木造住宅を解体（除却）する際の工事費用の一部を助成する制度です。助成額は解体除却工事費・整地費用の2分の1（限度額は通常50万円、指定された対象地域または空き家は100万円）で、令和8年度の申請期限は12月25日（金曜日）です。

<SubsidyInfoCard />

## この記事の結論

- 助成対象は「解体・除却」の工事費用であり、住宅をそのまま残す耐震改修（リフォーム）とは別の制度
- 助成額は助成対象経費の**2分の1**、限度額は通常**50万円**、指定地域・空き家は**100万円**（令和8年度から拡充）
- 助成対象経費には床面積あたり39,900円/㎡という単価の上限があり、超過分は助成対象にならない
- 令和8年度の申請期限は**12月25日（金曜日）**。予算の状況により期限前に受付が終了する可能性もある

## 1. 対象住宅・対象者

### 対象住宅の条件（すべて満たす必要があります）

- 江戸川区内に存すること
- 昭和56年5月31日以前の旧耐震基準で建築されていること
- 昭和56年6月1日以降に増改築した部分がある場合、その部分の床面積が現在の延床面積の2分の1未満であること
- 主要構造部（建築基準法上の定義。屋外階段・廊下・玄関ポーチ等を除く）が木造であること（非木造の住宅は対象外）
- 地階を含む階数が2以下であること
- 個人が所有する住宅であること（法人所有は対象外）
- 接道要件（建築基準法第43条各項）を満たしていること
- 建築基準法その他関係法令に係る重大な違反がないこと
- 耐震性が十分でないこと
- 住民税を滞納していないこと

「住宅」には一戸建て・長屋・共同住宅が含まれ、店舗等との併用住宅も、店舗部分の床面積が延べ面積の2分の1未満であれば対象になります。

### 対象区域

区内全域が対象ですが、不燃化特区・市街地再開発事業・土地区画整理事業・都市計画道路事業・木造住宅密集市街地整備促進事業等の施行中または施行予定区域内で、建替え・除却費用の助成（補償）を別途受けられる場合は対象外です。

### 申請できる人の条件

- 対象住宅を除却して助成金の交付を受けることについて、所有者・居住者・敷地所有者（共有を含む）全員の同意を得ていること
- 助成対象経費の全額を申請者が負担すること
- 区職員による審査・調査（対象住宅内部への立ち会いを含む）に全面的に協力できること

<Callout type="warning">
区が助成決定する前に解体工事を契約・着手すると、助成の対象外になります。工事の契約は必ず助成決定通知を受け取ってから行ってください。
</Callout>

## 2. 助成額・計算方法

助成対象経費は、対象住宅の**解体除却工事費**と**解体後の敷地整地費用**のみです。アスベスト調査・撤去費、塀・外構・植栽・カーポート・物置・室内残留物・地下埋設物などの撤去費は助成対象に含まれません。

| 項目 | 内容 |
|---|---|
| 助成対象経費の上限 | 対象住宅の床面積×39,900円/㎡を超えた分は助成対象経費に含まれない |
| 助成率 | 助成対象経費の2分の1（千円未満切り捨て） |
| 限度額（通常） | 50万円 |
| 限度額（一部対象地域・空き家） | 100万円（令和8年度から拡充。従来は一律50万円） |

限度額100万円は「指定された対象地域内にある住宅」または「空き家に該当する住宅」のいずれかを満たす場合に適用されます。他の建替え・除却関連の助成事業との併用はできません。

### 空き家として限度額100万円を受ける場合の証明方法

- 給水契約の中止日が申請日から1年以上前であること
- 従量料金が申請前月から12カ月以上連続して0円であったこと

ガス・電話等の契約状況の証明では代用できません。

## 3. 他の耐震化助成メニューとの違い（混同注意）

江戸川区は建築指導課耐震化促進係が所管する耐震化助成制度を複数用意しています。この記事で扱う「老朽住宅除却助成制度」は、そのうち住宅を**解体する**費用を助成するメニューです。住宅を残したまま耐震性を高める工事とは別物なので、申請前に必ず区別してください。

| 制度名 | 内容 | 令和8年度 申請期限 |
|---|---|---|
| 耐震コンサルタント派遣制度 | 専門家による耐震相談の派遣（旧耐震住宅向け） | 令和9年1月29日 |
| **老朽住宅除却助成制度（本記事）** | **旧耐震住宅の解体工事費を助成** | **令和8年12月25日** |
| 戸建住宅耐震改修設計等助成制度 | 耐震改修の設計費を助成（旧耐震・新耐震とも別枠あり） | 令和8年12月25日 |
| 戸建住宅耐震改修工事助成制度 | 住宅を残したまま行う耐震改修工事費を助成（旧耐震・新耐震とも別枠あり） | 令和8年12月25日 |

分譲マンションや緊急輸送道路沿道建築物向けの助成は、戸建住宅とは別の制度として事前相談制で運用されています。

## 4. 申請方法・スケジュール

申請前に必ず「江戸川区老朽住宅等除却工事助成の手引き」を確認してください。申請は書面申請・電子申請のどちらでも可能です。建物の相続登記が済んでいない場合や未登記の場合は、申請者が建物所有者であることが分かる書類（遺産分割協議書の写し等）が別途必要になります。

### 主な手続きの流れ

1. **助成申請**: 申請書（第3号様式）、対象住宅に一見して倒壊の危険性があることの報告書（第4号様式）、対象住宅の壁の割合の計算結果報告書（第5号様式）等を提出
2. **助成決定通知**: 書類審査・現場調査の上、可否を通知（申請から概ね1か月）
3. **工事着手**: 助成決定通知の連絡後に契約・着工（決定前の契約・着工は助成取り消しの対象）
4. **完了報告・助成金交付申請**: 工事完了後、速やかに完了実績報告書等を提出
5. **助成金交付決定通知**: 書類審査・現場調査の上、交付額を通知
6. **助成金請求**: 助成金交付請求書を提出
7. **助成金交付**: 原則、申請者本人の口座に振込（請求から概ね1か月）
