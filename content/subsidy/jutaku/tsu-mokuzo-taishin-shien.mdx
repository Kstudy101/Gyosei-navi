津市の木造住宅耐震関係支援制度とは、昭和56年5月31日以前の旧耐震基準で建てられた木造住宅に対し、無料の耐震診断や耐震補強工事・耐震シェルター設置・除却工事などへ津市が補助する一連の制度です。耐震補強工事は令和6〜8年度に限り最高157.5万円まで拡充されています。

<SubsidyInfoCard />

## この記事の結論

- **無料耐震診断**あり（原則4月〜翌年1月末。予算で早期終了の場合あり）
- **耐震補強工事**は補強工事費の**全額・最高157.5万円**（令和6〜8年度は期間限定で50万円増額）。準耐震は**3分の2・最高30万円**
- **除却**は費用の**23%・最高40万円**。令和8年度は4月8日から先着受付
- 対象は**昭和56年5月31日以前着工**の木造（3階以下など）。**交付決定前の契約・着手は補助対象外**

## 1. 対象者・対象住宅の条件

### 共通のイメージ

メニューごとに細条件は異なりますが、中心となる対象は次のとおりです。

- 津市内の対象住宅の**所有者**（シェルターは所有者の承認を得た者も可）
- **昭和56年5月31日以前**に建てられた（着工された）**木造住宅**
- **3階建て以下**
- 延べ床面積の**過半が住宅**の用に供されていること
- **在来軸組工法・伝統工法・枠組工法**
- **丸太組工法（ログハウス）・プレハブ工法・大臣等の特別な認定工法は対象外**

耐震補強工事の概要PDFでは、**賃貸住宅も含む**と明記されています。

### 耐震補強工事で追加される条件

- 耐震診断の結果が**評点0.7未満**（倒壊する危険性が高い）
- **1ヘクタール当たり10戸以上**の住宅が建て込んだ区域内であること
- 診断は津市の無料診断（合併前10市町村での診断を含む）、または三重県木造住宅耐震促進協議会の有料診断等に限る

### 除却で追加される条件

- 評点0.7未満、または**容易な簡易診断調査票（自己診断）**により倒壊の危険性があること
- 令和7年度から、容易な簡易診断調査票の要件を満たせば診断結果が不要（**混構造は対象外**のため評点0.7未満の診断結果が必要）
- 同一年度につき**1敷地1棟限り**。一部のみの除却や着手済みは対象外

## 2. 補助メニューと金額

| メニュー | 補助の考え方 | 上限など |
|---|---|---|
| 耐震診断 | 市が実施 | **無料**（1棟1回） |
| 耐震補強計画 | 計画作成などに係る費用の額 | **最高18万円**（精密診断法による設計は**最高34万円**） |
| 耐震補強工事 | 補強工事費の**全額** | **最高157.5万円**（R6〜R8は期間限定で+50万円） |
| 準耐震補強工事 | 補強工事費の**3分の2** | **最高30万円** |
| リフォーム工事（併用） | リフォーム工事費の**3分の1** | **最高20万円**（県内に拠点を持つ建設業者が施工） |
| 耐震シェルター設置 | 購入・設置費用の額 | **最高100万円**（1戸1箇所） |
| 木造住宅除却 | 除却工事費の**23%** | **最高40万円** |

耐震補強とリフォームを同時に行う場合は「耐震（または準耐震）＋リフォーム」の合算になります。補助金が工事費を超える場合は工事費額が上限となり、1,000円未満は切り捨てです。

## 3. 受付期間・手続き上の注意

### 耐震診断

- 受付は原則**4月から翌年1月末**まで
- 予算により早期終了あり
- 申し込みから結果報告まで**数か月**かかる場合あり

### 除却

- 令和8年度は**4月8日（水）午前9時**から津リージョンプラザ3階展示室で受付開始（先着順）
- **4月9日以降**は本庁舎5階建築指導課
- 総合支所・郵送も可だが、建築指導課到着日が受付日。書類不備は受付不可
- 原則として**翌年1月末まで**に除却完了、**2月末まで**に完了実績報告書を提出できることが条件

### 共通の注意

- **交付決定前**に契約・着手（計画作成やシェルター設置を含む）した場合は補助対象外
- 補助金の受け取りを事業者へ委任する「代理請求及び受領制度」あり（事前に事業者へ制度利用の可否を確認）

申し込み・問い合わせ先は、都市計画部建築指導課（電話059-229-3187）です。診断の申し込みは各総合支所地域振興課・出張所でも受け付けています。

## 4. 他都市の木造耐震支援との違い

- 津市は診断無料に加え、補強・シェルター・除却まで**市の単独メニュー**が揃う
- 耐震補強の上限**157.5万円（全額補助・期間限定拡充）**は、定率＋上限型の都市と比べて分かりやすい一方、**評点0.7未満**かつ**建て込み区域**という条件が付く
- 除却は費用の23%・最高40万円で、空き家対策ページからも誘導されている

最新の受付状況・必要書類は、必ず津市公式の「木造住宅耐震関係支援制度」ページと各概要PDFで確認してください。
