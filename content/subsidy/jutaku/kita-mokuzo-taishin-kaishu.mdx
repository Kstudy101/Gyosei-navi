東京都北区の木造民間住宅・耐震改修工事事業とは、区内の耐震性が低い木造住宅について、耐震改修工事にかかる経費の一部を区が助成する制度です。助成額は工事費（消費税分を除く）の3分の2で、1棟あたりの限度額は通常100万円、整備地域内は120万円、高齢者世帯等が行う場合は150万円です。

なお、本記事の対象は**東京都北区**（総務省コード13117）です。大阪府大阪市北区とは別の自治体で、制度も申請窓口も異なります。

## この記事の結論

- 対象は北区内の**平成12年5月31日以前に建築着手**した木造2階建て以下・地階なしの住宅
- 助成額は工事費（税抜）の**3分の2**。限度額は**100万円／整備地域120万円／高齢者世帯等150万円**
- 対象承認申請は**4月1日〜11月30日**。契約は対象承認通知のあと
- 同じ上位事業には耐震診断・耐震補強設計・耐震建替えのメニューもある（本記事は改修工事に絞る）

## 1. 対象になる住宅と申請できる人

北区は、大規模地震による倒壊などを防ぐため、木造民間住宅の耐震診断・補強設計・改修工事・建替え工事に対する助成をまとめて「木造民間住宅耐震化促進事業」として実施しています。そのうち改修工事メニューの対象建築物は、パンフレットと実施要綱で次のように整理されています。

| 項目 | 条件 |
|---|---|
| 所在地 | 北区内 |
| 建築時期 | 平成12年5月31日以前に建築に着手 |
| 構造・階数 | 主要構造部が木造、階数2以下、地階なし |
| 用途 | 一戸建て・長屋・共同住宅（店舗等併用は店舗部分が延べ面積の1/2未満） |
| 診断結果 | 耐震診断資格者による一般診断法または精密診断で Iw が 1.0 未満 |
| 改修計画 | 改修後の Iw を 1.0 以上に計画（建築基準法第20条適合で確認済証取得済み・検査済証の交付を受ける住宅の例外あり） |
| その他 | 建築基準法関係規定に著しい違反がないこと、同種助成を既に受けていないこと、区との事前相談を行っていること、耐震診断資格者が工事監理を行うこと など |

プレハブ工法の建築物や、一部の特殊な構造方法を用いた住宅は助成対象外です。増改築の結果、上記の階数・構造条件に当てはまらなくなる場合もあります。

**申請できる人**は、対象建築物の所有者（個人に限る）で、住民税を滞納していない方です。

## 2. 助成金額の決まり方

助成金の額は、耐震改修工事に要した費用（消費税分を除く）の3分の2です。1,000円未満の端数は切り捨てます。1棟あたりの限度額は次のとおりです。

| 区分 | 限度額 |
|---|---|
| 通常 | 100万円 |
| 整備地域内の対象建築物 | 120万円 |
| 高齢者世帯等が行う場合 | 150万円 |

**整備地域**は、東京都震災対策条例に基づく防災都市づくり推進計画で定める地域です。パンフレットでは西が丘1〜2丁目全域、赤羽西2〜3丁目全域、上十条1〜5丁目全域など、丁目単位の一覧が示されています。自分が該当するかは区の案内または窓口で確認してください。

**高齢者世帯等**は、満65歳以上の方を含む世帯、または身体障害者手帳・愛の手帳を所持する方を含む世帯です。限度額150万円の加算を使うには、工事の前後とも専用住宅または兼用住宅であること、対象住宅に1年以上居住し今後も住み続ける見込みであることなどが必要です。

耐震改修工事に関連しないリフォーム工事の費用は、助成額の算定対象外です。対象になる工事の例は、基礎の補強、耐力壁の設置、柱と梁などの緊結、屋根の改修、耐震性向上のための一部撤去、およびこれらに必要な撤去・復旧工事です。

## 3. 手続きの流れと受付期間

大まかな流れは次のとおりです。

1. **事前相談**（方針・注意事項の案内。承認を約束するものではない。回答まで2〜3週間程度）
2. **対象承認申請**（受付は4月1日〜11月30日。土日祝の場合は前日）
3. **対象承認決定**（通常2週間程度。全体設計を伴う場合は国・都の審査があり2か月程度）
4. **契約・着手**（承認通知日以降に契約。着手届を提出）
5. **中間検査・完了検査**（希望日の1週間前までに連絡）
6. **完了報告および助成金交付申請**（承認日の属する年度の1月31日まで）
7. **交付決定・請求・振込**

契約を対象承認通知より前に結ぶと助成対象外になります。やむを得ず事業が2か年度にまたがる場合は、全体設計承認が別途必要です。申請は窓口持参・郵送・電子申請に対応しています。

## 4. 関連メニューと問い合わせ先

同じ上位事業には、耐震診断事業（限度額13万円）、耐震補強設計事業（費用の3分の2・限度額20万円）、耐震建替え工事事業（改修と同様の限度額体系、対象は昭和56年5月31日以前建築着手の旧耐震木造など条件が異なる）もあります。分譲・賃貸マンションや緊急輸送道路沿道建築物向けの別制度も北区にはあります。
