福岡市木造戸建住宅耐震改修工事費補助事業とは、昭和56年5月31日以前に建てられた木造戸建住宅の耐震改修工事や、耐震シェルター等の設置にかかる費用の一部を福岡市が補助する制度です。空き家活用補助金とは別メニューで、建築物安全推進課が所管します。

<SubsidyInfoCard />

## この記事の結論

- 耐震改修は工事費の**80%、上限150万円**。シェルター等は**40%、上限25万円**
- 対象は**昭和56年5月31日以前**に建築確認を得て着工した**木造戸建・2階建て以下**（共同住宅は対象外）
- 令和8年度は**4月13日から受付**。**交付決定前の契約・着工は対象外**。完了報告は**申請年度の1月末まで**

## 1. 対象者・対象住宅

### 補助対象者（施行者）

要綱では、当該住宅の所有者（2親等以内の親族を含む）などで、次を満たす方が対象です。

- この要綱（および廃止前の旧要綱）に基づく同種補助金を過去に受けていないこと
- 福岡市の市税を滞納していないこと
- 暴力団排除条例の排除対象に該当しないこと

### 補助対象住宅

| 要件 | 内容 |
|---|---|
| 建築時期 | 昭和56年（1981年）5月31日以前に建築確認を得て着工（昭和56年6月1日以降の増築等を含む） |
| 構造・用途 | 木造戸建（在来軸組・伝統的構法・枠組み壁／店舗併用は店舗部分が床面積の1/2未満） |
| 階数 | 地階を除く2階建て以下（**共同住宅は対象外**） |
| 診断結果（改修） | 建防協「木造住宅の耐震診断と補強方法」の一般診断法または精密診断法で上部構造評点1.0未満 |
| 工事内容（改修） | 建物全体が1.0以上、または1階部分が1.0以上になる耐震改修工事（耐震設計・工事監理を含む） |
| シェルター等 | 高齢者・障がい者等（要綱で定義）が居住していること |

## 2. 補助額の計算

| 区分 | 補助率・内容 | 上限 |
|---|---|---|
| （A）耐震改修工事 | 耐震改修工事に要する経費の80%の範囲内 | **150万円** |
| （B）耐震改修工事（利子補給利用時） | （A）で算出した額から、工事経費の40%を減じた範囲内。減ずる額は57.5万円を上限 | （A）より減額 |
| （C）耐震シェルター等の購入・設置 | 購入・設置に要する経費の40%の範囲内 | **25万円** |

- 交付額は1,000円未満切り捨てです（要綱第8条）
- （B）は住宅金融支援機構の**リ・バース60**による耐震改修融資への利子補給制度を利用する場合の区分です
- 設置可能なシェルター等は市が示す別紙（一定の評価を受けたもの）を参照します

### 計算イメージ（改修・利子補給なし）

工事費が200万円の場合、200万円×80%=160万円ですが上限があるため**150万円**が上限額になります。実際の交付額は見積・審査結果によります。

## 3. 申請の流れ・期限

概要チラシおよび公式ページの案内は次のとおりです。

1. **事前相談**（建築物安全推進課）— 工程を決める前に必ず相談
2. **交付申請**（申請年度の**4月13日から**受付開始）
3. **交付決定**（書類審査等でおおよそ1か月）
4. **工事契約・着工**（**交付決定後**に契約。着手届を提出）
5. **完了実績報告**（申請年度の**1月末まで**）
6. 額の確定・請求・交付

- 補助戸数・予算に限りがあります
- 交付決定前に工事契約した場合や、工事を開始・完了した場合は対象外です
- **代理受領制度**があり、施工事業者が補助金を代理受領すると初期負担を抑えられます

## 4. 耐震診断・関連メニュー

### 診断の進め方

市の改修補助を使う場合、建防協基準の一般診断法または精密診断法が必要です。福岡県耐震診断アドバイザー派遣などは自己負担3,000円（診断のみ）／6,000円（補強計画・概算見積含む）などのコースがあり、**改修工事費補助の申請には6,000円コース（補強計画含む）が必要**と案内されています。建替費補助なら3,000円コースでも申請可能な場合があります。

市独自の**建築物耐震診断費補助**もあり、令和8年度からは昭和56年5月31日以前の**全ての建築物**へ対象が拡大されています。木造戸建の改修補助を受けるには詳細診断側の要件が必要、との注意が診断ページにあります。

### あわせて検討できる市のメニュー

| メニュー | 概要（公式案内） |
|---|---|
| 木造戸建住宅耐震建替費等補助 | 倒壊の可能性が高いと判定された木造戸建の建替・除却費用の一部を補助（定額20万円＋条件により除却加算など） |
| ブロック塀等除却費補助 | 道路に面する危険なブロック塀等の除却費の3分の2・上限30万円 |
| 空き家活用補助金 | 空き家の改修・地域貢献利用向け（本制度とは別。別記事参照） |

税制上の特例（固定資産税の減額・所得税の耐震改修特別控除）も公式ページで案内されていますが、適用可否は区役所課税課・税務署の要件確認が必要です。

## 5. 県内の同種制度との違い

同じ福岡県内でも金額設計は異なります。

| 自治体 | 中心メニューの目安 |
|---|---|
| 福岡市（本制度） | 改修費の**80%・上限150万円** |
| 北九州市 | 工事費等の**5分の4・上限115万円**（条件により診断費上乗せ） |
| 久留米市 | 改修**50%・上限50万円**など |

金額だけで選ぶのではなく、対象住宅・診断要件・完了期限・市内事業者要件の有無を各公式ページで確認してください。
