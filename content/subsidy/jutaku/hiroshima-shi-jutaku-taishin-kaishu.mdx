広島市住宅耐震改修等補助事業とは、昭和56年（1981年）5月31日以前に着工した木造住宅を対象に、耐震改修・現地建替え・非現地建替え・除却にかかる費用の一部を広島市が補助する制度です。都市整備局住宅部住宅政策課が所管します。

<SubsidyInfoCard />

## この記事の結論

- 対象は**昭和56年5月31日以前着工**の**木造在来軸組・伝統的構法**（地階除く**2階以下**）
- **耐震改修**・**現地建替え**は対象工事費の**80%・上限115万円**
- **非現地建替え**・**除却**は除却工事費の**23%・上限58万円**
- リ・バース60**利子補給併用**の耐震改修は工事費の**40%・上限57.5万円**
- 令和8年度の初期申込は**2026年4月15日〜4月28日**。未達時は**随時募集**（残枠は要確認）
- **交付決定前の契約・着工は不可**。完了・実績報告は**令和9年1月末まで**

## 1. 対象者・対象住宅

### 対象住宅

| 要件 | 内容 |
|---|---|
| 所在 | 広島市内 |
| 構造 | **木造在来軸組構法**または**伝統的構法**（ツーバイフォー・プレハブは対象外） |
| 着工時期 | **昭和56年5月31日以前**に着工した一戸建・併用住宅（延べ面積の1/2以上が居住用） |
| 階数 | 地階を除く**階数2以下** |
| 耐震性 | 耐震診断の**上部構造評点が0.7未満**（倒壊する可能性が高い）。簡易診断の評点合計**7以下**は現地建替え・非現地建替え・除却に限り可 |
| その他 | 販売目的でないこと。国・他団体から同一対象への同種補助を受けていないこと |

昭和56年6月1日以降に増築している場合、現地建替え・非現地建替え・除却では増築部分が既存の過半を超えると対象外になる可能性があるため、事前に住宅政策課へ確認してください。

### 対象者

- 補助対象住宅の**所有者、配偶者、または一親等の親族**
- 当該住宅に**居住している者**、または**居住予定者**（居住予定者は耐震改修・現地建替えに限る）
- 事業完了後も**広島県内に居住**する者
- 世帯の主たる生計維持者に**市税の滞納がない**
- 世帯の主たる生計維持者の**前年所得が1,200万円以下**

### 補助対象事業の区分

| 区分 | 概要 | 主な追加要件 |
|---|---|---|
| 耐震改修 | 上部構造評点を**1.0以上**にするための補強（建築士が設計・工事監理） | — |
| 現地建替え | 同一敷地で取り壊し・新築 | 新築は**省エネ基準適合**かつ**土砂災害特別警戒区域外**。道路面ブロック塀の危険改善 |
| 非現地建替え | 別敷地で取り壊し・新築 | 道路面ブロック塀の危険改善 |
| 除却 | 取り壊し後、耐震性のある住宅へ住み替え | 道路面ブロック塀の危険改善 |

災害危険区域（急傾斜地崩壊危険区域）等での現地建替えは対象外になる可能性があります。

## 2. 補助金額・募集件数（令和8年度）

公式ページおよび令和8年度募集案内で確認した補助率・上限・件数は次のとおりです。

| 区分 | 補助率 | 上限 | 募集件数 |
|---|---|---|---|
| 耐震改修 | 耐震改修工事費の**80%** | **115万円/戸** | **8戸** |
| 現地建替え | 現地建替え工事費の**80%** | **115万円/戸** | **3戸** |
| 耐震改修（利子補給制度） | 耐震改修工事費の**40%** | **※57.5万円** | **2戸** |
| 非現地建替え | 除却工事費の**23%** | **58万円/戸** | （件数表に明示なし） |
| 除却 | 除却工事費の**23%** | **58万円/戸** | （件数表に明示なし） |

※利子補給欄の57.5万円は、利子補給分を含まない耐震改修工事費の補助限度額です。別途、リ・バース60による無利子・低利子融資が利用可能と案内されています。

申込み多数の場合は抽選です。

## 3. 申請期間・完了期限

| 項目 | 内容 |
|---|---|
| 初期申込期間 | **2026年4月15日（水）〜4月28日（火）午後5時必着** |
| 随時募集 | 募集件数に達しない場合は随時（残枠は問合せ） |
| 完了・実績報告 | **令和9年（2027年）1月末日まで** |
| 持参受付 | 土日祝を除く9時〜17時（本庁舎5階・住宅政策課） |

**交付決定通知書を受理する前に契約・着工すると対象外**になります。耐震改修を行う場合は、申込み前までに耐震診断（上部構造評点0.7未満の確認）を終えておく必要があります。

## 4. 関連する市の制度（別メニュー）

本記事の主対象は「住宅耐震改修等補助」ですが、同じ住宅政策課の助成メニューとして次もあります。

| 制度 | 主な金額（原文） |
|---|---|
| 住宅耐震診断補助 | 戸建木造: 診断費の**2/3以内・上限4万円**／分譲マンション: **2/3以内・上限133万3千円** |
| 耐震シェルター等設置補助 | シェルター等: **1/2以内・上限12万5千円**／感震ブレーカー: **1/2以内・上限4万円** |

診断補助の令和8年度初期申込も4月15日〜28日、シェルターも同期間です。詳細は各公式ページを参照してください。
