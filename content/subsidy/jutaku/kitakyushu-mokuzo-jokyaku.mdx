北九州市の木造住宅（住替え・建替えを前提とした除却工事）補助金とは、昭和56年5月31日以前に建てられた木造住宅を、耐震性のある住宅への建替えや住替えを前提に除却する際、工事費の一部を市が補助する制度です。「北九州市住宅・建築物耐震改修工事費等補助事業」の木造メニューの一つで、耐震補強のみの補助金（最大115万6千円）とは別枠です。

## この記事の結論

- 旧耐震・評点1.0未満で**現に居住中**の木造戸建を、建替えまたは耐震性のある住宅への住替えを前提に除却する制度
- 補助額は除却費（税抜）と耐震改修相当経費の**低い方×23.0%**、上限**30万円**（所有者70歳以上は令和10年度まで上限**50万円**）
- 令和8年度の募集は**2026年4月13日**開始。先着順で、予算到達で終了
- 耐震診断は**福岡県耐震診断アドバイザー派遣制度のみ**（除却なら自己負担3,000円コース）

## 1. 対象者・対象住宅

### 補助対象者

- 建物所有者、または所有者の同意を得て事業を行う者
- 市税を滞納していないこと
- 暴力団・暴力団員およびこれらと密接な関係を有する者でないこと

### 対象建築物（すべて満たすこと）

| 条件 | 内容 |
|---|---|
| 所在 | 北九州市内 |
| 建築時期 | 昭和56年5月31日以前に建築または工事着手 |
| 階数 | 2階建て以下 |
| 耐震性 | 耐震診断の結果、上部構造評点が1.0未満 |
| 居住 | 現に3カ月以上居住していること |
| 除却後 | 耐震性のある住宅を新築・購入するか、耐震性のある中古戸建・共同住宅・賃貸等へ転居したうえで除却 |

「耐震性のある住宅」とは、昭和56年6月1日以降に建築確認済証を取得して建築されたもの、または耐震診断で上部構造評点が1.0以上のものです（新築・既存を問いません）。

### 対象外の例

- **長屋・共同住宅**（Q&Aで除却補助は対象外と明記）
- 申請時点で居住していない住宅
- 交付決定前にすでに着工している工事
- 過去に同一住宅で同内容の補助金を受けた場合

## 2. 支給額・計算方法

要領第4条第3項に基づく算定です。

1. 除却工事に要する経費（消費税・地方消費税相当額を除く）の相当額
2. その除却の代わりに耐震改修工事監理および耐震改修工事を行った場合の経費相当額

上記のいずれか**低い方**に**23.0%**を乗じ、**1,000円未満を切り捨て**た額が補助額です。上限は次のとおりです。

| 区分 | 上限 |
|---|---|
| 通常（所有者70歳未満） | **30万円**／1戸 |
| 申請時点で所有者70歳以上、かつ令和11年3月31日までに工事完了 | **50万円**／1戸 |

50万円への拡大は、公式案内では「令和8年度から令和10年度に限り」と説明されています（要領の読替期限＝令和11年3月31日＝令和10年度末と一致）。

公式ページでは床面積1㎡あたり34,100円を乗じた額との比較にも触れています。Q&Aでは、県アドバイザーの簡易診断を使う場合の**耐震改修経費の目安**として要領の「34,100／㎡」を用いるとあります。最終的な算定根拠は要領の条文です。

## 3. 申請の流れ・必要書類

### 事前に必要なこと

1. **事前協議**（建築指導課 093-582-2531、午前8時30分〜16時）
2. **耐震診断**（福岡県耐震診断アドバイザー派遣制度のみ。除却予定なら自己負担3,000円）
3. 除却後に住む耐震性のある住宅の確保方針を固める

### 書類提出は3回

1. **交付申請**（工事前）— 交付決定通知まで工事契約・着工不可
2. **完了実績報告**（工事完了後）— 目安は1月末まで
3. **請求**（確定通知後）— 支払い完了の目安は2月末まで

令和5年7月21日以降、交付申請の電子申請も利用できます。代理受領制度（施工業者が補助金を代理受領）もあります。

施工は原則**市内事業者**です。やむを得ない理由があれば市外事業者も認められます。

## 4. 耐震補強補助金との違い

| 項目 | 除却（本制度） | 耐震補強のみ |
|---|---|---|
| 目的 | 建替え・住替え前提の除却 | 住宅を残して評点1.0以上へ補強 |
| 上限の目安 | 30万円（70歳以上は最大50万円） | 115万円＋診断費上乗せ最大6千円 |
| 算定 | 低い方の経費×23.0% | 監理・工事費の5分の4 |
| 診断 | 県アドバイザーのみ（除却なら3,000円） | 工事補助では6,000円コース等が必要になる場合あり |
| 長屋・共同 | 除却は対象外 | 補強メニューでは1棟単位の扱いあり |

同じ市の「3つの補助金」案内では、耐震補強のみ・耐震補強＋省エネ・除却の3メニューが並んでいます。自分の計画がどれに当たるかは公式ページと要綱・要領で確認してください。
