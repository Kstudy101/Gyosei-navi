名古屋市の子どもあんしん住まいる補助金とは、子育て世帯が行う住まいの安全対策（転落防止の鍵・手すり、チャイルドゲートなど）に対し、対象費用の2分の1（1戸あたり最大20万円）を補助する市独自の制度です。要綱上の正式名称は「名古屋市住まいの安全性の向上に関する改修費等補助金」です。

## この記事の結論

- **補助率は対象費用の2分の1**、**1戸あたり上限20万円**（100円未満切り捨て）
- 対象は市内の**小学生以下の子ども（12歳に達する日以降の最初の3月31日まで）または妊婦**がいる世帯
- **令和8年度の受付は2026年4月1日〜2027年2月28日**（予算到達で終了、超過日は抽選）
- **2階以上の全開口部への転落防止対策**が必須（集合住宅1階は不要）
- 木造住宅耐震改修助成や一般リフォーム補助とは別。市には性能維持目的の一般リフォーム補助はない

## 1. 制度の概要

子どもの窓・ベランダからの転落事故を防ぐため、名古屋市が子育て世帯の費用負担を軽減する目的で実施しています。補助メニューは「対象商品の購入・設置」と「改修工事」の2系統で、片方だけでも両方でも申請できます（両方の場合は同日同時申請）。

既存の木造住宅耐震改修助成とは対象・目的が異なります。耐震改修を探す場合は関連記事を参照してください。

## 2. 対象世帯・住宅

### 世帯

- 名古屋市内に居住していること
- **子ども**（12歳に達する日以降の最初の3月31日までの間にある子）または**妊婦**（母子健康手帳交付済み）がいること
- **前年度以前に本補助金の交付を受けていない**こと（申請は原則1回限り。住み替え後の住宅では改めて申請可）

### 住宅・必須の転落防止対策

- 市内の住宅で、対象世帯が居住していること
- **戸建て**: 2階以上の全ての開口部（玄関ドアを除く）に転落防止対策を実施済み、または本補助で実施すること
- **集合住宅の2階以上**: 居住部分の開口部（玄関ドアを除く）が対象
- **集合住宅の1階**: 転落防止対策は必須ではない
- 過去に同じ工事等で国の補助金を受けていないこと（要綱上、同一住宅での重複申請制限あり）

転落防止対策の例は、鍵付き／ダイヤル式クレセント錠、子どもの手の届かない場所への補助錠・開口制限ストッパー、転落防止手すりなどです。

## 3. 補助額とメニュー上限

補助額は、対象商品の購入費用または改修工事費用の**2分の1**と、メニューごとの上限額を比較して低い方を合計し、**最大20万円**です。送料、ポイント・クーポン・商品券利用分は対象外です。

### 対象商品の購入・設置（令和8年3月1日以降の新品）

| メニュー | 上限額 |
|---|---|
| 鍵付き又はダイヤル式クレセント錠（工事なし） | 6,000円／箇所 |
| 補助錠・開口制限ストッパー | 3,000円／申請 |
| チャイルドゲート | 3,000円／箇所（1申請あたり2箇所まで） |
| チャイルドロック等付きコンロ | 10,000円／申請 |
| ドアの指挟み込み防止商品 | 3,000円／申請 |

新古品・中古品・個人間売買は対象外です。新築工事に伴う購入・施工費用も対象外です。

### 改修工事

| メニュー | 上限額 |
|---|---|
| 鍵付き又はダイヤル式クレセント錠の設置（工事あり） | 6,000円／箇所 |
| 開口部への転落防止手すり設置 | 上限なし（全体上限20万円の範囲内） |
| バルコニー室外機への柵設置（高さ1,100mm以上） | 上限なし（同上） |
| クッション床への改修 | 7,000円／㎡ |
| 床の段差解消工事 | 上限なし（同上） |

集合住宅でバルコニー室外機に柵を設置する場合は、手すりおよび隔壁から600mm以上離す必要があります。クッション床は区画全面の張り替えが条件です。

令和8年度当初予算は手引き上**6,621千円**です。予算到達後は受付終了となり、終了日の超過申請は抽選になります。

## 4. 申請の流れ

原則は電子申請フォームです。用紙申請も可能です。

### 対象商品の購入・設置

1. 商品を購入・設置する（設置後の写真と領収証を用意）
2. 交付申請兼完了届を提出する
3. 交付決定・金額確定の通知後、指定口座に振込

### 改修工事

1. **着工前**に交付申請（図面・数量計算書・工事前写真・見積書など）
2. 交付決定通知を受けてから着工（決定前着工は対象外）
3. 完了後に完了届兼請求（完了報告期限は**令和9年3月31日**）
4. 金額確定後に振込

問合せ・提出先は「子どもあんしん住まいる補助金事務局」（名古屋市中村区佐古前町22番13号 森ビル502、株式会社MTK内、電話052-485-7034）です。制度所管は住宅都市局住宅部住宅企画課（052-972-2942）です。
