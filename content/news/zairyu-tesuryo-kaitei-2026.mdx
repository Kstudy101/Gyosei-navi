在留資格の変更・更新・永住許可の手数料が、2026年10月1日から大幅に引き上げられます。もっとも大きいのが永住許可で、**10,000円から200,000円へ、20倍**になります。2026年8月28日、官報で正式に公布されました。

本記事では、官報に掲載された政令原文から、何がどう変わるのかを整理します。永住許可申請の手続き全体（審査基準・標準処理期間など）は[永住許可申請の手続き完全ガイド](/guide/nyukan/eiju-kyoka-shinsei-tetsuzuki)にまとめています。

## この記事の結論

- **永住許可の手数料が10,000円→200,000円（20倍）**に。
- **在留資格の変更・更新**は一律6,000円から、**在留期間に応じた段階制（10,000円〜75,000円）**に変わります。
- **施行日は2026年10月1日**。2026年8月25日の閣議決定を経て、**8月28日に官報で公布済み**——すでに確定した制度です。
- **就労資格証明書・在留カードの交付・再入国許可の手数料は今回の改正の対象外**で、金額は変わりません。
- ⚠️ 官報の附則を確認した限り、変更・更新・永住・再入国の手数料について「9月末までの申請は旧料金」という経過措置の条項は**見当たりませんでした**。

## 1. 何が根拠か

今回の値上げは2段階で決まっています。

| 段階 | 内容 |
| --- | --- |
| ① 法律 | **令和8年法律第32号**（2026年5月29日成立）が、手数料の**法律上の上限そのもの**を引き上げ |
| ② 政令 | **令和8年政令第268号**（2026年8月28日公布）が、その上限の範囲内で**実際の徴収額**を具体的に規定 |

政令案は2026年7月3日から8月2日までパブリックコメントにかけられ、2026年8月25日の閣議決定を経て、8月28日に官報で公布されました。**e-Govのパブリックコメント案件ページは本記事作成時点でアクセスできない状態でしたが**、確定した内容は官報の公布文で確認できます。施行日は同日公布の別の政令（令和8年政令第267号）が、令和8年10月1日と定めています。

## 2. 新旧対照 — 何がいくらになるか

政令が改正する入管法施行令第25条の内容です。

### 永住許可

| | 現行 | **2026年10月1日〜** |
| --- | --- | --- |
| 永住許可 | 10,000円 | **★200,000円** |

現行の10,000円自体、2025年3月末までの8,000円から引き上げられたばかりの金額です。今回はそれに続く2度目の、はるかに大きな引き上げになります。

### 在留資格の変更・在留期間の更新

現行は在留期間にかかわらず一律6,000円（オンライン申請5,500円）ですが、改正後は許可される**在留期間の区分**に応じた段階制になります。

| 在留期間の区分 | 窓口申請 | 電子申請 |
| --- | --- | --- |
| 3か月以下 | 10,000円 | （記載なし） |
| 3か月超6か月以下 | 18,000円 | 15,000円 |
| 6か月超1年未満 | 25,000円 | 21,000円 |
| 1年 | 33,000円 | 27,000円 |
| 1年超3年未満 | 48,000円 | 42,000円 |
| 3年以上5年未満 | 64,000円 | 56,000円 |
| 5年以上 | 75,000円 | 65,000円 |

在留期間が長く許可されるほど手数料も上がる設計です。この変更は[在留資格変更許可申請](/guide/nyukan/zairyu-shikaku-henko-ryugaku-shuro)・[在留期間更新許可申請](/guide/nyukan/zairyu-koshin-shorui-shori-kikan)の両方に影響します。

### 変更されないもの

以下は今回の改正の対象外で、**金額は変わりません**。

| 項目 | 金額 |
| --- | --- |
| [就労資格証明書](/guide/nyukan/shuro-shikaku-shomeisho)の交付 | 2,000円（オンライン1,600円） |
| 在留カードの交付 | 1,900円 |
| 再入国許可（1回限り） | 4,000円（オンライン3,500円） |
| 再入国許可（数次） | 7,000円（オンライン6,500円） |

新設される特定登録者カードの交付は4,000円（再交付2,000円）、難民旅行証明書の交付は4,800円と定められています。

## 3. ⚠️ 経過措置の有無 — 9月30日までは旧料金なのか

多くの解説記事が「2026年10月1日申請分から」という表現を使っていますが、当サイトが政令の附則を官報原文で確認した限り、**変更・更新・永住・再入国の手数料（施行令第25条）について、「9月30日までに受け付けた申請は旧料金」という趣旨の経過措置条項は見当たりませんでした。**

附則で明示的に経過措置が定められているのは、**特定在留カード・特定特別永住者証明書に関するものに限られます**。

手数料は通常、申請の受付時に納付する運用です。そのため実務上は、**施行日（10月1日）以降に受け付けられた申請から新料金が適用される**と考えるのが自然であり、他の専門家による解説の多くもこの理解と一致しています。ただし、これは条文の構造からの推測を含みます。**申請を予定している方は、直前に入管庁の案内で最新の金額を確認してください。**

## 4. 減額・免除の規定

改正後の施行令は、手数料の減額・免除についても定めています。

| 対象 | 取扱い |
| --- | --- |
| 生活保護法上の要保護者に準ずる程度に困窮する**難民認定者・補完的保護対象者**等 | **減額**（変更・更新は10,000円まで、永住許可は20,000円まで） |
| 外交・公用の在留資格への**変更** | **免除** |
| 公用の在留資格での**更新** | **免除** |

減額・免除の対象者の具体的な認定基準を示すガイドラインについても、別途パブリックコメントが実施されています。当サイトでは確定次第、続報します。
