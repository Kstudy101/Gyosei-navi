進学や転勤で引っ越し先を検討するとき、「子育て支援が手厚い街はどこか」は気になるポイントです。ただし子育て支援は「妊娠・出産時」と「小中学校に上がってから」でまったく別の制度が動いており、片方だけを見て「この市は手厚い」と判断すると、もう一方では平均的、というケースが少なくありません。

この記事では、政令指定都市のうちさいたま市を除く11市（千葉市・横浜市・川崎市・新潟市・静岡市・名古屋市・京都市・神戸市・岡山市・広島市・北九州市）について、すでに公開している各市の制度記事のデータをもとに、**A. 妊娠・出産時（妊婦支援給付・市独自の上乗せ）**と**B. 小中学校の就学時（就学援助・給食費）**の2軸で整理しました。金額の単純な順位ではなく、「どんな制度が、どんな家庭に効くか」という視点でまとめています。東京23区は別記事（出産・就学援助それぞれの23区比較）で扱っているため、この記事では対象外です。

## 比較の軸について

- **A. 妊娠・出産時**: 国の「妊婦のための支援給付」（妊娠時5万円＋出産後は胎児1人あたり5万円が標準形）を、各市がどう実施しているか。現金給付が基本ですが、横浜市のように国の出産育児一時金とは別枠の市独自助成を案内している市や、京都市のように対象を第三子以降・多胎児に絞ったヘルパー派遣（現金給付ではない）を実施している市もあります。
- **B. 小中学校の就学時**: 経済的に就学が困難な世帯向けの「就学援助」制度における、所得基準の目安（4人世帯）と、給食費が実際にどう扱われるか（保護者負担が残るか、実質無償になるか）。

世帯構成（子どもの年齢・人数）によって、どちらの軸が重要かは変わります。乳幼児期の家庭には妊娠・出産時の支援が、就学中の子がいる家庭には就学援助の使いやすさが直接影響します。

## A. 妊娠・出産時の支援を市別に見る

### 標準形（1回目5万円＋2回目：胎児1人あたり5万円、単胎で合計10万円）の市

千葉市・川崎市・新潟市・名古屋市（妊婦応援金＋子育て家庭応援金）・岡山市・広島市・北九州市（妊娠期＋出産期）・神戸市（寄り添い給付金）は、いずれも国の「妊婦のための支援給付」をベースに、単胎出産で合計10万円（多胎はその分加算）を現金で支給する制度です。所得制限を設けていない市が大半ですが、支給のタイミング（妊娠届出時・出産後の面談時・新生児訪問時など）や振込までの期間は市によって異なります。北九州市は令和7年度、現金のほかに「にこふくギフト」55,000ポイント（1ポイント＝1円相当）も選べる仕組みを用意しています。さいたま市も同じ標準形（1回目5万円＋2回目胎児1人あたり5万円）に加え、期限内のデジタル地域通貨申請で「たまポン」等の上乗せがありますが、就学時の一般的な就学援助記事が確認できなかったため、今回の比較対象からは除いています。

静岡市も合計10万円の経済的支援を案内していますが、公式ページには1回目・2回目それぞれの内訳額が明記されていません。

### 標準形とは別の枠組みの市

- **横浜市**: 妊婦支援給付金の記事ではなく、出産費用助成金（子ども1人につき最大9万円）という市独自の別制度を案内しています。加入する健康保険から出産育児一時金の付加給付がある場合は、その額が9万円から差し引かれます（付加給付が9万円以上ある場合は支給なし）。
- **京都市**: 現金給付ではなく、第三子以降・多胎児の産前産後に家事・育児ヘルパーを派遣する事業（第三子以降16回以内・多胎児32回以内）です。利用料は生活保護・市民税非課税世帯が0円、その他は1回400〜1,600円。第一子・第二子のみの世帯は対象になりません。

<Callout type="warning">
横浜市・京都市は、他の9市とは制度の性格（対象者・現金かサービスか）が異なります。金額だけを単純に比べず、自分の世帯が対象になる制度かどうかを先に確認してください。
</Callout>

## B. 小中学校の就学時の支援を市別に見る

就学援助の所得基準（4人世帯の目安）と、給食費の扱いを整理すると、次のようになります。

| 都市 | 所得基準（4人世帯の目安） | 給食費の扱い |
|---|---|---|
| 千葉市 | 総所得236万円 | 中学生の給食費のみ実費援助対象（小学生は援助内容表に記載なし） |
| 横浜市 | 349万円 | 小学校は令和8年度から実質無償化。中学校は認定後無償 |
| 川崎市 | 約330万円 | 認定後、小中とも市が実費負担 |
| 新潟市 | 所得階層制（支給率100・75・50・25%） | 学用品費等とあわせ、修学旅行費・給食費も実費支給の対象 |
| 静岡市 | 生活保護基準の約1.3倍以下（具体額は年度PDFで確認） | 学校給食費（保護者負担分）は援助対象に含まれる |
| 名古屋市 | 420万0千円 | 中学生（スクールランチ実施校）の給食費のみ対象。小学生は記載なし |
| 京都市 | 279万2,700円 | 小中とも給食の保護者負担なし |
| 神戸市 | 266万4千円 | 市立は給食費を現物支給（認定後の実質無償） |
| 岡山市 | 267万6千円 | 実費を給食費の集金へ直接振替（保護者への現金支給ではない） |
| 広島市 | 約313万円 | 認定者は給食費の納付が免除される |
| 北九州市 | 約299万円 | 小学校はもともと給食費無償化のため対象外。中学校の給食費は実費援助 |

※所得基準は世帯の年齢構成・世帯人数などにより変動します。上記はいずれも各市公式ページに掲載された4人世帯の目安であり、実際の該当可否は各市の窓口で確認してください。

## 引っ越し先を選ぶときのチェックの目安

- これから妊娠・出産を控えている → まずA軸（妊娠・出産時の支援）を確認。横浜市・京都市は他市と制度の性格が異なる点に注意
- すでに小中学生の子どもがいる、または就学を控えている → B軸（就学援助の所得基準・給食費の扱い）を確認。所得基準を超えていそうでも、まず窓口に相談することをおすすめします
- 複数の子どもがいて年齢差が大きい → 出産時・就学時の両方の制度を長期的に使う可能性があるため、両軸のバランスを見る
- 掲載されていない市に引っ越す予定がある → お住まい予定の自治体の子育て支援窓口・教育委員会に、妊婦支援給付金と就学援助の制度がないか個別に確認する

自治体の制度は年度ごとに見直されるため、実際の転居判断にあたっては、必ず各市の最新の公式ページで金額・期限・所得基準を確認してください。
