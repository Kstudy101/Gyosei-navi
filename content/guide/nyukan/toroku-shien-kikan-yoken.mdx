登録支援機関になるかどうかを決める前に確認すべきは、「どんな会社が登録できるか」ではなく「**どんな会社が登録を拒否されるか**」です。入管法は要件を積極的な形では書かず、**拒否事由**という形で定めています。

本記事では入管法第19条の26と入管庁の手続案内、そして支援計画そのものを規律する運用要領の原文から、登録の可否と支援内容の中身を整理します。監理支援機関との違いや選び方は[監理支援機関と登録支援機関の違い](/guide/nyukan/kanri-shien-toroku-shien-chigai)を参照してください。

## この記事の結論

- 根拠は**入管法第19条の26**。要件は「**登録拒否事由**」という形で**14項目**列挙され、1つでも該当すれば**登録を拒否しなければならない**という建て付けです。
- 審査には**おおむね2か月**かかります。支援業務の開始予定日から逆算して申請してください。
- 登録の有効期間は**5年間**。更新するには**登録更新申請**が必要です。
- 手数料は**28,400円**（収入印紙、申請時納付・返還不可）。
- 支援計画の**義務的支援は9項目**——全てを行わなければならず、支援計画にも全て記載する必要があります。
- 義務的支援に係る費用を、**直接・間接を問わず外国人に負担させることはできません。**

## 1. 登録拒否事由 — 「要件」ではなく「これに該当したら拒否」

入管法第19条の26第1項は、こう定めています。

> 出入国在留管理庁長官は、第十九条の二十三第一項の登録を受けようとする者が次の各号のいずれかに該当するとき、又は……申請書若しくはその添付書類のうちに重要な事項について虚偽の記載があり、若しくは重要な事実の記載が欠けているときは、**その登録を拒否しなければならない**。
>
> （出入国管理及び難民認定法 第十九条の二十六第一項。太字は当サイト）

14の号を、ジャンルごとに整理します。

| # | 拒否事由の内容 |
| --- | --- |
| 1号 | **拘禁刑以上**の刑に処せられ、執行終了・執行を受けなくなった日から**5年**を経過しない者 |
| 2号 | 入管法・技能実習法など出入国・労働関係法令（政令で定めるもの）による**罰金刑**から5年を経過しない者 |
| 3号 | **暴力団**関係法令や、傷害・傷害致死・現場助勢・凶器準備集合等・恐喝罪などによる罰金刑から5年を経過しない者 |
| 4号 | 健康保険法・船員保険法・労災保険法・厚生年金保険法・労働保険料徴収法・**雇用保険法**の罰則規定による罰金刑から5年を経過しない者 |
| 5号 | 心身の故障により支援業務を適正に行えない者として**法務省令で定めるもの** |
| 6号 | **破産手続開始の決定**を受けて復権を得ない者 |
| 7号 | 登録を**取り消され**、その日から5年を経過しない者 |
| 8号 | 取消しを受けた法人の、取消し原因発生時の**役員**であった者（取消しの日から5年経過しないもの） |
| 9号 | 登録申請日前**5年以内**に出入国・労働に関する法令に関し不正・著しく不当な行為をした者 |
| 10号 | **暴力団員**、または暴力団員でなくなった日から5年を経過しない者 |
| 11号 | 未成年者で、その**法定代理人**が前各号等に該当する者 |
| 12号 | **法人**で、役員のうちに前各号のいずれかに該当する者がいる者 |
| 13号 | 暴力団員等が**事業活動を支配**する者 |
| 14号 | 支援業務を的確に遂行する**体制が整備されていない**者として法務省令で定めるもの |

見落とされやすいのは8号・11号・12号・13号です。**申請する会社自身が問題なくても、役員や法定代理人、あるいは支配関係にある暴力団員等がこれらに該当すれば、登録は拒否されます。**個人の欠格事由だけでなく、法人の役員構成全体を確認する必要があるということです。

第2項は、登録を拒否したときは遅滞なく理由を示して申請者に通知しなければならないと定めています。

## 2. 申請の実務 — 費用・期間・提出先

入管庁の手続案内が示す実務条件です。

| 項目 | 内容 |
| --- | --- |
| 根拠 | 入管法**第19条の24第1項**（平成31年4月1日施行） |
| 申請できる人 | 特定技能所属機関から契約により委託を受けて、適合1号特定技能外国人支援計画の**全部**の実施の業務を行う者 |
| **審査期間** | **おおむね2か月**。支援業務開始予定日の**おおむね2か月前**までに申請 |
| **手数料** | **28,400円**（収入印紙）。**申請後の印紙の返還は不可** |
| 提出書類 | 登録支援機関登録（更新）申請書（別記第29号の15様式）＋立証資料＋手数料納付書＋返信用封筒（角形2号・簡易書留490円分） |
| 審査基準 | **登録拒否事由**（第19条の26第1項各号）への該当の有無 |
| 提出先 | 申請者の本店または主たる事務所の所在地を管轄する地方出入国在留管理局・支局（空港支局・出張所を除く） |
| 申請方法 | **郵送可**。**オンライン申請には非対応** |
| 受付時間 | 平日 9:00〜12:00、13:00〜16:00 |

登記事項証明書は法務局のオンライン交付請求サービスで取得できると案内されています。

## 3. 審査結果 — 登録の有効期間は5年

入管庁の案内はこう説明しています。

> 登録拒否事由に該当しないと認められた場合、登録支援機関登録簿に登載し、登録支援機関登録通知書を交付します。**登録の有効期間は５年間**です。有効期間の更新を希望する方は登録支援機関の登録更新申請をしてください。
>
> （登録支援機関の登録申請 手続案内。太字は当サイト）

拒否事由に該当すると認められた場合は、**登録拒否通知書**が交付されます。

**5年ごとの更新が必要**という点は見落とされがちです。登録から5年が近づいたら、更新申請も同じく約2か月の審査期間を要する前提でスケジュールを組んでください。

## 4. 支援計画の義務的支援 — 9項目

登録支援機関が実施を担う「1号特定技能外国人支援」の中身は、運用要領が**9つの義務的支援**として定めています。

> 1号特定技能外国人に対する支援は、**必ず行わなければならない「義務的支援」**のほか、これに加えて行うことが望ましい「任意的支援」に分けられます。義務的支援は**その全てを行う必要**があり、支援計画には**全ての義務的支援を記載**しなければなりません。義務的支援の全てを行わなければ、支援計画を**適正に実施していないこととなります**（在留資格変更等で客観的に明らかに不要な支援は除く）。
>
> （１号特定技能外国人支援に関する運用要領。太字は当サイト）

| # | 義務的支援の内容 |
| --- | --- |
| (1) | **事前ガイダンス**の提供 |
| (2) | **出入国する際の送迎** |
| (3) | 適切な**住居の確保**に係る支援・**生活に必要な契約**に係る支援 |
| (4) | **生活オリエンテーション**の実施 |
| (5) | **日本語学習**の機会の提供 |
| (6) | **相談又は苦情**への対応 |
| (7) | **日本人との交流促進**に係る支援 |
| (8) | 外国人の責めに帰すべき事由によらないで特定技能雇用契約を解除する場合の**転職支援** |
| (9) | **定期的な面談**の実施・**行政機関への通報** |

⚠️ **9項目であり、10項目ではありません。**(9)には「定期的な面談」と「行政機関への通報」の2つが1項目としてまとめられている点も、しばしば見落とされます。

また運用要領は、(1)事前ガイダンス（第3条第1項第1号イ）は**対面またはテレビ電話装置その他の方法**により、(1)・(4)生活オリエンテーション・(7)日本人との交流促進・(9)定期的な面談は、外国人が**十分に理解できる言語**により実施することとされている、と定めています。

任意的支援についても、支援計画に記載した場合には**支援義務が生じる**とされているため、書く内容には注意が必要です。

## 5. 全部委託のインセンティブ — みなし規定

登録支援機関を使う実務上の理由がここにあります。運用要領はこう説明しています。

> 契約により登録支援機関に1号特定技能外国人支援計画の**全部の実施を委託**する場合には、特定技能所属機関は、**支援計画の適正な実施の確保の基準に適合するものとみなされます**。この場合以外は、特定技能所属機関が自ら適正な実施の確保の基準を満たす必要があります。
>
> （同運用要領。太字は当サイト）

つまり支援を**全部**委託すれば、企業側は適正実施の基準を自ら証明しなくてよくなります。**一部委託**にとどめる場合は、委託した部分以外について企業自身が基準を満たす必要があり、委託の範囲を支援計画に**明示**しなければなりません。

支援計画の作成・実施にあたっては、事業所所在地と外国人の住居地が属する地方公共団体が実施する**共生施策**を確認し、これを踏まえて計画を作成することも求められています。事業所と住居地の地方公共団体が異なる場合は、両方の共生施策を確認し、確認した市区町村名・確認日・確認方法を支援計画に記入します。

## 6. 費用を外国人に負担させることはできない

義務的支援のコストについて、運用要領は明確な歯止めを置いています。

> 義務的支援に係る費用について、**直接又は間接に当該外国人に負担させることはできません。**
>
> （同運用要領。太字は当サイト）

住居支援でも同じ考え方が適用されます。社宅等を貸与することで**経済的利益を得てはならない**とされ、費用を徴収する場合の上限が具体的に定められています。

| 物件の形態 | 徴収できる上限 |
| --- | --- |
| 借上物件 | 借上げに要する費用（**管理費・共益費を含む**。**敷金・礼金・保証金・仲介手数料・更新手数料・途中解約金等は含まない**）を、入居する特定技能外国人の人数で除した額以内 |
| 自己所有物件 | 建設・改築等に要した実費を基準とする額以内 |

「家賃を上乗せして利益を取る」「初期費用を丸ごと転嫁する」といった運用は認められていません。登録支援機関への委託料と、外国人本人への費用負担は**別の話**として管理する必要があります。

## 編集長の一言

登録支援機関の制度は「登録すれば終わり」に見えて、実際には**拒否事由という消極的な網**と、**義務的支援という積極的な網**の両方をくぐる必要があります。特に法人の役員構成にまで及ぶ拒否事由（第19条の26第8号・第12号・第13号）は、事業承継やM&Aの場面で見落とされがちです。支援計画についても、9項目という正確な数と「全部委託でみなし適合」という設計を知っているかどうかで、体制構築のコストが大きく変わります。
