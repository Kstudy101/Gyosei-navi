海外にいる人を日本に呼び寄せるとき、最初に立ちはだかるのが**在留資格認定証明書**（Certificate of Eligibility、以下COE）です。査証（ビザ）そのものではなく、**入国前に「上陸の条件を満たしている」ことを日本側で証明してもらう書面**で、これがあるかないかで在外公館での査証申請の重さが変わります。

本記事では入管法第7条の2・施行規則第6条の2の条文と、出入国在留管理庁の手続案内の原文から、COEの位置づけ・申請できる人・審査の考え方・処理期間・電子交付までを整理します。個別の必要書類は在留資格ごとに分かれるため、各在留資格の記事に譲ります。

## この記事の結論

- COEは**入管法第7条の2**に基づく制度。日本で行う活動が在留資格に該当し、上陸の条件に適合していることを**入国前に**証明する書面です。**短期滞在**を目的とする人は対象外。
- 審査で**立証する責任は申請した側**にあります。施行規則第6条の2第5項が「**立証した場合に限り**」交付すると定めています。
- **標準処理期間は1か月〜3か月／手数料は無料**。郵送申請はできません。
- **2023年3月17日から電子メールでの交付**が可能。海外の本人に転送でき、スマートフォンで提示して査証申請・上陸申請ができます。
- **不服申立ての方法は用意されていません**（手続案内の記載）。不交付なら再申請が実務的な選択肢です。

## 1. COEは何のための書面か

入管法第7条の2第1項は、COEを次のように定めています。

> 法務大臣は、法務省令で定めるところにより、本邦に上陸しようとする外国人（本邦において別表第一の三の表の短期滞在の項の下欄に掲げる活動を行おうとする者を除く。）から、あらかじめ申請があつたときは、当該外国人が前条第一項第二号に掲げる条件に適合している旨の証明書（以下「在留資格認定証明書」という。）を交付することができる。
>
> （出入国管理及び難民認定法 第七条の二第一項）

ポイントは「**前条第一項第二号に掲げる条件**」、つまり上陸のための条件のうち**在留資格該当性と上陸許可基準への適合**の部分だけを、入国前に切り出して審査するという構造です。

入管庁の手続案内は、交付されたCOEを在外公館の査証申請や上陸申請の際に提出・提示すれば、**速やかに査証発給や上陸許可を受けられる**と説明しています。COEは査証ではなく、査証審査と上陸審査を軽くするための「先に済ませておく証明」だと理解すると位置づけがはっきりします。

| よくある混同 | 実際 |
| --- | --- |
| COE＝ビザ（査証） | 別物。COEを持って**在外公館で査証を申請**する |
| COEがあれば必ず入国できる | 上陸審査は空港で別途行われる。COEは第7条第1項**第2号**の条件についての証明 |
| 短期滞在でも取れる | 条文が短期滞在の活動を**明文で除外** |

なお、手続案内の手続概要は対象となる在留資格を「『短期滞在』及び『永住者』を除く」と説明しています。条文が明文で除いているのは短期滞在で、永住者は入国前に取得する在留資格ではないという制度上の性質によるものです。

## 2. 誰が申請できるのか

施行規則第6条の2第1項は、申請は**別記第6号の3様式**の申請書1通を、**地方出入国在留管理局に出頭して**提出すると定めています。そのうえで第4項が、局長が相当と認める場合には出頭を要しないとして、代わりに提出できる者を列挙しています。

| 区分 | 誰か | 根拠 |
| --- | --- | --- |
| 本人 | 日本への入国を希望する外国人本人 | 手続案内 |
| 代理人 | 受け入れようとする機関の職員その他法務省令で定める者 | 法第7条の2第2項／規則第6条の2第3項（別表第4） |
| 取次者① | 外国人の円滑な受入れを図る**公益社団法人・公益財団法人の職員**で局長が適当と認めるもの | 規則第6条の2第4項第1号 |
| 取次者② | **登録支援機関の職員**（支援計画の全部の実施を委託されたもの） | 規則第6条の2第4項第1号 |
| 取次者③ | 所属会を経由して届け出た**弁護士・行政書士** | 規則第6条の2第4項第2号 |
| 取次者④ | 申請人本人の**法定代理人** | 規則第6条の2第4項第3号 |

手続案内は、取次者が提出できるのは「上記1又は2の方が、日本に滞在している場合に限られます」としています。呼び寄せる側（日本の受入れ機関や配偶者など）が動く前提の制度だ、ということです。

どの在留資格で申請すべきかが定まっていない段階なら、まず[在留資格判定ナビ](/tools/visa-navi)で候補を絞ってから、該当する在留資格の記事に進むのが早道です。

## 3. 審査で「証明する」のは申請した側

COEの実務で最も効いてくるのが、施行規則第6条の2第5項です。

> 第一項の申請があつた場合には、地方出入国在留管理局長は、当該申請を行つた者が、当該外国人が法第七条第一項第二号に掲げる上陸のための条件に適合していることを**立証した場合に限り**、在留資格認定証明書を交付するものとする。ただし、当該外国人が法第七条第一項第一号、第三号又は第四号に掲げる条件に適合しないことが明らかであるときは交付しないことができる。
>
> （出入国管理及び難民認定法施行規則 第六条の二第五項。太字は当サイト）

条文が「立証した場合に**限り**」と書いている以上、**資料が足りなければ通らない**のが原則です。入管が不足分を調べて補ってくれる制度ではありません。同じ発想は在留期間更新の審査にも通じていて、[更新でよくある不許可理由](/guide/nyukan/zairyu-koshin-fukyoka-10sen)で扱った「疎明資料の不足」はここに根があります。

提出資料については、施行規則第6条の2第2項が、**申請日前6か月以内**に撮影した写真1葉と、行おうとする活動に応じて**別表第3**の下欄に掲げる資料を提出すると定めています。ただし局長が「省略しても支障がない」と認めるときは一部・全部を省略できるという柔軟性も条文上は用意されています。

なお、入管庁の手続案内は審査基準として、活動が虚偽でないこと、入管法別表第一・第二の該当性、そして別表第一の二の表・四の表の活動については**基準省令**（平成2年法務省令第16号）に適合することを挙げています。

## 4. 申請先・期間・費用

手続案内が示す実務条件をまとめます。

| 項目 | 内容 |
| --- | --- |
| 提出先 | 本人申請なら**居住予定地**、代理人・取次者の申請なら**受入機関の所在地**を管轄する地方出入国在留管理官署 |
| 郵送 | **受け付けていません**（手続案内が明示） |
| 受付時間 | 平日 9:00〜12:00、13:00〜16:00（手続により曜日・時間が設定される場合あり） |
| オンライン | **申請可能**（在留申請オンラインシステム） |
| 手数料 | **かかりません** |
| 標準処理期間 | **1か月〜3か月** |
| 不服申立方法 | **なし** |

標準処理期間の1〜3か月は、**資料が整っている前提の目安**です。追加資料の求めが入ればその分延びます。入社日や入学日が決まっている呼び寄せでは、逆算して3か月以上の余裕を見ておくのが安全です。

オンライン申請の使い方そのものは[入管オンライン申請システムの実務マニュアル](/practice/dx/nyukan-online-shinsei-manual)にまとめています。

## 5. 電子交付 — 2023年3月17日から

紙のCOEを海外に国際郵便で送る運用は、時間も費用もかかり、紛失リスクもありました。入管庁の「在留資格認定証明書の電子化について」は、**令和5年（2023年）3月17日から電子メールでの受領が可能**になったと説明しています。

**対象になる人**

1. **オンラインで**COE交付申請を行う人
2. 事前にオンラインで**利用者登録**をしたうえで、地方出入国在留管理局の**窓口で**申請を行う人

窓口申請で電子交付を希望する場合は、「（窓口申請）在留資格認定証明書電子交付希望申出書」を提出書類と一緒に出します。すでに在留申請オンラインシステムの利用者情報登録をしている、または利用申出の承認を受けている場合は、現に持っている利用者IDを使えます。

**電子COEの実務メリットと注意点**

| | 内容 |
| --- | --- |
| メリット | 受領した電子メールを**海外の本人に転送できる**。郵送の手間・費用・時間が不要 |
| メリット | 本人は**スマートフォン等で提示**して査証申請・上陸申請ができる |
| 注意 | メール受領を希望すると、**審査完了メールは送信されない** |
| 注意 | 受領後は、メールに記載されたURLから**「受領登録」**を行う |

紙で交付を受けた後に入国を取りやめた場合や、上陸申請時に写しを提出した場合は、原本を交付元の官署へ返納するよう協力が求められています（返納理由書は任意様式、参考様式あり）。

## 6. 有効期間について — 当サイトが確認できた範囲

COEの有効期間について、**本記事の作成時点（2026年8月29日）に当サイトが確認した一次情報には、期間を明示した記載がありませんでした。**確認した範囲は次のとおりです。

- 入管法第7条の2（全5項）
- 施行規則第6条の2（全6項）
- 入管庁「在留資格認定証明書交付申請」手続案内ページ
- 入管庁「出入国審査・在留審査Q&A」

施行規則第6条の2第6項は、COEの様式を**別記第6号の4様式**（局長が相当と認める場合は第6号の4の2様式、または第6号の5様式および第6号の6様式）と定めており、期間に関する記載は**様式の側**にあるものと考えられます。交付を受けたCOEに記載された内容を必ず確認し、査証申請までのスケジュールはその記載を基準に組んでください。

他サイトで見かける期間の記載を鵜呑みにせず、**手元の証明書の記載と在外公館の案内**で確認する、というのがここでの安全な進め方です。

## 7. あまり知られていない「交付の一時停止」

入管法第7条の2には、第3項から第5項に**COEの交付を一時的に止める仕組み**が置かれています。特定技能に関わる制度で、条文はこう定めています。

> 特定産業分野……を所管する関係行政機関の長は、当該特定産業分野に係る分野別運用方針に基づき、当該特定産業分野において必要とされる人材が確保されたと認めるときは、法務大臣に対し、一時的に在留資格認定証明書の交付の停止の措置をとることを求めるものとする。
>
> （同条第三項）

第4項は、その求めがあったとき法務大臣は分野別運用方針に基づき**停止の措置をとるものとする**と定め、第5項は交付の**再開**についてこれらを準用しています（「確保された」を「不足する」と読み替え）。

つまり特定技能では、**分野ごとの受入れ状況によってCOEの入口が閉じることが制度上ありうる**ということです。特定技能での呼び寄せを予定している企業は、分野別運用方針の動きを追う必要があります。制度全体は[特定技能1号・2号の全体像](/guide/nyukan/tokutei-gino-1go-2go-zentaizo)にまとめています。

## 8. 入国前結核スクリーニングの記載について

手続案内には「入国前結核スクリーニング」の項があり、東京オリンピック・パラリンピックまでに開始予定だったものが新型コロナウイルス感染症の水際対策により見送られ、その後の入国者増加を受けて**「令和7年中の制度開始を予定していますので、お知らせします」**と書かれています（対象国としてフィリピン、ネパール、ベトナムに言及）。

⚠️ 本記事の作成時点は令和8年（2026年）8月であり、**この記載が現在の状況を反映しているかは当サイトでは確認できていません。**ページが更新されていない可能性があります。該当国からの呼び寄せを予定している場合は、厚生労働省の特設サイトと入管庁の最新の案内で開始状況を確認してください。

## 編集長の一言

COEの解説は「必要書類の一覧」で終わっているものが多いのですが、条文を開くと制度の骨格は別のところにあります。**立証責任が申請側にあること**（規則第6条の2第5項）と、**分野の受入れ状況で交付が止まりうること**（法第7条の2第3〜5項）。この2つを知っているかどうかで、準備の厚みとスケジュールの立て方が変わります。有効期間について当サイトが「確認できなかった」と書いたのも同じ姿勢で、一次情報にない数字を確からしく書くことはしません。
