留学生が日本で就職するとき、内定の次に来るのが**在留資格変更許可申請**です。「留学」のままでは正社員として働けないため、就労できる在留資格へ切り替える必要があります。ここでつまずくと入社日に間に合いません。

本記事では入管法第20条の条文と入管庁の手続案内の原文から、申請できる時期・費用・期間、そして4月入社から逆算したスケジュールを整理します。変更後の在留資格として最も多い「技術・人文知識・国際業務」の要件そのものは[技人国の完全ガイド](/guide/nyukan/gijinkoku-visa-guide)を参照してください。

## この記事の結論

- 根拠は**入管法第20条**。許可されるのは「変更を適当と認めるに足りる**相当の理由**」があるときに限られます。
- 申請は「**変更の事由が生じたときから在留期間満了日以前**」。内定が固まった時点から出せます。
- **手数料は許可時6,000円／オンライン申請なら5,500円**（収入印紙）。不許可なら不要。⚠️ **2026年10月1日から在留期間別の段階制（10,000円〜75,000円）に改定予定**（[詳細](/news/zairyu-tesuryo-kaitei-2026)）。
- **標準処理期間は1か月〜2か月**。更新（2週間〜1か月）より長いので、4月入社なら年内提出が安全です。
- 満了日までに処分が出なくても**特例期間（最長2か月）**で在留は続きます。ただし新しい活動はまだできません。
- **短期滞在からの変更は原則不可**（第20条第3項ただし書）。

## 1. 何が「変更」にあたるのか

入管法第20条第1項は、変更の範囲をこう定めています。

> 在留資格を有する外国人は、その者の有する在留資格……の変更（高度専門職の在留資格（別表第一の二の表の高度専門職の項の下欄第一号イからハまでに係るものに限る。）を有する者については、法務大臣が指定する本邦の公私の機関の変更を含み、特定技能の在留資格を有する者については、法務大臣が指定する本邦の公私の機関又は特定産業分野の変更を含み、特定活動の在留資格を有する者については、法務大臣が個々の外国人について特に指定する活動の変更を含む。）を受けることができる。
>
> （出入国管理及び難民認定法 第二十条第一項）

見落としやすいのはカッコの中です。**在留資格の名前が変わらなくても「変更」になる類型**があります。

| 在留資格 | 変更許可が必要になる場面 |
| --- | --- |
| 高度専門職（1号イ〜ハ） | **指定された機関**が変わるとき |
| 特定技能 | **指定された機関または特定産業分野**が変わるとき |
| 特定活動 | **個々に指定された活動**が変わるとき |
| 技術・人文知識・国際業務 など | 機関の指定がないため、同じ在留資格の範囲内の転職は変更ではなく**届出**の対象 |

[特定活動46号](/guide/nyukan/tokutei-katsudo-46go-guide)で就職した人が転職する場合も、指定活動の内容次第でこの論点に触れます。

また第20条第2項ただし書は、**永住者の在留資格への変更を希望する場合は第22条第1項による**と定めています。永住は本条ではなく別手続です。

## 2. 留学から就労へ — 申請時期と4月入社の逆算

入管庁の手続案内は、申請期間を「**在留資格の変更の事由が生じたときから在留期間満了日以前**」としています。留学生の就職なら、内定が出て職務内容・雇用条件が固まった時点が「事由が生じたとき」にあたります。

標準処理期間は**1か月〜2か月**。ここから逆算すると、4月入社のスケジュールはこうなります。

| 時期 | やること |
| --- | --- |
| 内定〜年内 | 雇用契約書・職務内容説明・会社資料をそろえる |
| **12月ごろ** | **変更許可申請を提出**（標準処理期間1〜2か月を見込む） |
| 1〜3月 | 審査。追加資料の求めがあれば速やかに対応 |
| 許可後 | 在留カードの交付を受けて効力発生（第20条第5項） |
| 4月 | 入社 |

手続案内には、申請期間の注記として「**本来の在留資格に基づく活動を行っていない場合には、在留資格を取り消される場合があります**」とあります。卒業後に留学の活動実体がない状態が続くのは、変更審査でも取消しの観点でもリスクになります。卒業から入社までの空白をどう説明できるかは、早く出すほど有利です。

## 3. 審査で見られること

第20条第3項は、許可の条件をこう定めます。

> 前項の申請があつた場合には、法務大臣は、当該外国人が**提出した文書により**在留資格の変更を適当と認めるに足りる**相当の理由**があるときに限り、これを許可することができる。ただし、短期滞在の在留資格をもつて在留する者の申請については、やむを得ない特別の事情に基づくものでなければ許可しないものとする。
>
> （同条第三項。太字は当サイト）

2点が重要です。

**① 判断材料は「提出した文書」** — [COEの記事](/guide/nyukan/zairyu-shikaku-nintei-shomeisho)で触れた立証責任の話と同じ構造で、出さなければ通りません。

**② 短期滞在からの変更は原則不可** — 「やむを得ない特別の事情」が要件です。海外から人を呼ぶときは短期滞在で入国させてから切り替えるのではなく、COEを取って査証を得る流れが原則になります。

実際の審査でどこを見られるかは、入管庁の「在留資格の変更、在留期間の更新許可のガイドライン」（平成20年3月策定、最終改正 令和8年6月）が8項目を示しています。在留資格該当性・上陸許可基準への適合を軸に、素行、独立生計、雇用・労働条件の適正性、納税義務の履行、入管法上の届出義務の履行などが並びます。項目ごとの中身と落とし穴は[更新でよくある不許可理由10選](/guide/nyukan/zairyu-koshin-fukyoka-10sen)で詳しく扱っています。変更と更新は**同じガイドラインが基準**なので、そのまま読み替えられます。

## 4. 手数料 — 6,000円／オンライン5,500円（2026年10月1日から段階制へ）

入管庁の手続案内が示す**現行（2026年8月29日時点）**の手数料は次のとおりです。

| 申請方法 | 手数料（許可されるとき） |
| --- | --- |
| 窓口 | **6,000円**（収入印紙で納付） |
| **オンライン** | **5,500円**（収入印紙で納付） |
| 経過措置 | 2025年3月31日までに受付した申請は、許可が4月1日以降でも**改定前の4,000円** |

**不許可の場合は手数料はかかりません**（「許可されるときは」と規定されているため）。オンライン申請が500円安く設定されている点は、件数をまとめて扱う企業ほど効いてきます。オンライン申請の実務は[入管オンライン申請システムの実務マニュアル](/practice/dx/nyukan-online-shinsei-manual)にまとめました。

### ⚠️ 2026年10月1日から在留期間別の段階制に改定

2026年8月28日、官報で正式に公布された政令（令和8年政令第268号）により、この一律料金は**在留期間の区分に応じた段階制**に置き換わります。

| 在留期間の区分 | 窓口 | 電子申請 |
| --- | --- | --- |
| 3か月以下 | 10,000円 | （記載なし） |
| 3か月超6か月以下 | 18,000円 | 15,000円 |
| 6か月超1年未満 | 25,000円 | 21,000円 |
| 1年 | 33,000円 | 27,000円 |
| 1年超3年未満 | 48,000円 | 42,000円 |
| 3年以上5年未満 | 64,000円 | 56,000円 |
| 5年以上 | 75,000円 | 65,000円 |

許可される在留期間が長いほど手数料も上がります。経過措置の有無を含めた詳細は[在留手続手数料の改定記事](/news/zairyu-tesuryo-kaitei-2026)にまとめました。

## 5. 誰が出せるか — 取次者と在留カード受領者の制限

手続案内は、提出できる人を本人・法定代理人・取次者に限っています。取次者は次のとおりです。

1. 地方出入国在留管理局長から**申請等取次者としての承認**を受けている者（申請人が経営・雇用されている機関の職員、研修・教育を受けている機関の職員、監理団体、公益法人の職員）で、申請人から依頼を受けたもの
2. 地方出入国在留管理局長に**届け出た弁護士・行政書士**で、申請人から依頼を受けたもの
3. 申請人が**16歳未満**の場合、または**疾病その他の事由により自ら出頭できない**場合の親族・同居者等で局長が適当と認めるもの

ここで実務上よく問題になる点を、手続案内の原文から拾います。

| 論点 | 原文の扱い |
| --- | --- |
| 「仕事が忙しい」「通勤・通学がある」 | 「その他の事由により自ら出頭することができない場合」に**該当しない** |
| 取次者が出す場合の本人の所在 | 出頭は不要だが、**日本に滞在していることが必要** |
| 18歳以上の人 | 成年年齢引下げ（令和4年4月1日）により、**取次者による場合を除き本人が申請** |
| 在留カードの受領 | 提出者と同じ制限。**所属企業・学校の職員、配偶者、子、兄弟姉妹は、取次者等に該当しない限り受領できない** |

最後の行は見落とされがちです。「会社の人が代わりに受け取りに行く」は、その人が承認を受けた取次者でなければできません。

## 6. 満了日を過ぎたら — 特例期間（第20条第6項）

申請したのに満了日までに結果が出ない、というのは珍しくありません。第20条第6項が受け皿を用意しています。

> 第二項の規定による申請があつた場合（三十日以下の在留期間を決定されている者から申請があつた場合を除く。）において、その申請の時に当該外国人が有する在留資格に伴う在留期間の満了の日までにその申請に対する処分がされないときは、当該外国人は、その在留期間の満了後も、**当該処分がされる時**又は**従前の在留期間の満了の日から二月を経過する日が終了する時**の**いずれか早い時**までの間は、引き続き当該在留資格をもつて本邦に在留することができる。
>
> （同条第六項。太字は当サイト）

| 項目 | 内容 |
| --- | --- |
| 効果 | 満了後も**従前の在留資格で**在留を継続できる |
| 上限 | 処分の時、または満了日から**2か月**経過時の、**早いほう** |
| 対象外 | 在留期間が**30日以下**と決定されている人からの申請 |
| 注意 | 続くのは**従前の在留資格**。新しい在留資格の活動が先にできるようになるわけではない |

つまり「特例期間中に新しい会社で働き始める」ことはできません。入社日と許可のタイミングがずれるときは、この点を会社側と共有しておく必要があります。

なお第20条第5項は、許可の効力は在留カードの交付などの措置があった時に生ずると定めています。**許可の連絡＝効力発生ではありません。**

## 7. 変更と更新の違い

同じガイドラインで審査される2つの手続ですが、実務条件は違います。

| | 在留資格変更（第20条） | 在留期間更新（第21条） |
| --- | --- | --- |
| 何をする | 別の在留資格に**切り替える** | 同じ在留資格で**期間を延ばす** |
| 申請期間 | 変更の事由が生じたとき〜満了日以前 | 満了日以前（6か月以上の在留期間なら**満了3か月前**から） |
| **標準処理期間** | **1か月〜2か月** | **2週間〜1か月** |
| 手数料 | 6,000円／オンライン5,500円（**2026年10月1日〜段階制**） | 同じ |
| 提出先 | 住居地を管轄する地方出入国在留管理官署 | 同じ |
| 不服申立て | なし | なし |

変更のほうが**1か月ほど長く見ておく**必要がある、というのがスケジュール上の要点です。

## まとめ

| 項目 | 内容 |
| --- | --- |
| 根拠 | 入管法**第20条** |
| 対象外 | **永住者**への変更（第22条第1項による別手続） |
| 申請期間 | 変更の事由が生じたとき〜在留期間満了日以前 |
| 審査 | 「提出した文書により」**相当の理由**があるとき。短期滞在からは**原則不可** |
| 手数料 | 許可時**6,000円**／オンライン**5,500円**（不許可なら不要）。**2026年10月1日から段階制10,000〜75,000円へ改定** |
| 標準処理期間 | **1か月〜2か月** |
| 特例期間 | 処分時か満了日＋**2か月**の早いほうまで（30日以下の在留期間は対象外） |
| 効力発生 | 在留カード交付等の**措置があった時**（第20条第5項） |
| 不服申立て | **なし** |

## 編集長の一言

留学から就労への切り替えは「必要書類を集める作業」だと思われがちですが、条文を読むと勝負どころは**時間**にあります。標準処理期間1〜2か月、特例期間は最長2か月、そして許可の効力は在留カードが出た時。この3つを並べると、内定から入社までのどこに余白を作るべきかが見えてきます。逆に、卒業後に留学の活動実体がないまま時間が過ぎることは、取消しの観点からも審査の観点からも重い意味を持ちます。早く出すことが、いちばん確実な対策です。
