一時帰国や海外出張のたびに気にすることになるのが**再入国許可**です。多くの人は空港で「みなし再入国」を使いますが、**みなしと通常の許可には、条文レベルで決定的な違いが1つ**あります。それを知らずに出国すると、帰国が延びたときに打つ手がなくなります。

本記事では入管法第26条・第26条の2と入管庁の解説の原文から、2つの制度の使い分けと出国時の手順を整理します。

## この記事の結論

- **みなし再入国許可**（第26条の2）は、出国時に**再入国の意図を表明**すれば通常の許可を受けたものと**みなされる**制度。申請も手数料も不要です。
- 有効期間は**出国の日から1年**。ただし**在留期限が先に来るならそこまで**。特別永住者は2年。
- ★**みなし再入国許可は延長できません**（第26条の2第3項が第26条第5項の適用を除外）。通常の再入国許可なら**在外公館で延長**できます。
- 「3月」以下の在留期間の人と「短期滞在」の人は**みなしの対象外**。ほかに**5類型**が対象外です。
- 通常の再入国許可は**当日交付**、手数料は1回限り**4,000円**／数次**7,000円**（オンラインは3,500円／6,500円）。

## 1. 2つの制度の関係

まず通常の再入国許可から。入管庁の手続案内はこう説明しています。

> 再入国許可とは、我が国に在留する外国人が一時的に出国し再び我が国に入国しようとする場合に、入国・上陸手続を簡略化するために法務大臣が出国に先立って与える許可です。再入国許可には、１回限り有効のものと有効期間内であれば何回も使用できる数次有効のものの２種類があり、その有効期間は、現に有する在留期間の範囲内で、**５年間（特別永住者の方は６年間）を最長**として決定されます。
>
> （出入国在留管理庁「再入国許可申請」。太字は当サイト）

そのうえで、多くのケースを申請不要にするのが**みなし再入国許可**です。

> 本邦に在留資格をもつて在留する外国人……で有効な旅券……を所持するもの（中長期在留者にあつては、**在留カードを所持するものに限る**。）が、法務省令で定めるところにより、入国審査官に対し、**再び入国する意図を表明して出国するとき**は、前条第一項の規定にかかわらず、同項の再入国の許可を受けたものと**みなす**。
>
> （出入国管理及び難民認定法 第二十六条の二第一項。太字は当サイト）

| | みなし再入国許可 | 通常の再入国許可 |
| --- | --- | --- |
| 根拠 | 第26条の2 | 第26条 |
| 申請 | **不要**（出国時の意思表明） | **必要**（出国前） |
| 手数料 | **不要** | 4,000円／数次7,000円 |
| 有効期間 | 出国の日から**1年**（在留期限が先ならそこまで）／特別永住者は**2年** | 在留期間の範囲内で最長**5年**（特別永住者は6年） |
| **延長** | **できない** | **できる**（在外公館で手続） |

## 2. 決定的な違い — みなしは延長できない

ここが本記事でいちばん伝えたい点です。入管法第26条第5項は、通常の再入国許可について延長制度を用意しています。

> 出入国在留管理庁長官は、再入国の許可を受けて出国した者について、当該許可の有効期間内に再入国することができない**相当の理由**があると認めるときは、その者の申請に基づき、**一年を超えず、かつ、当該許可が効力を生じた日から六年を超えない範囲内**で、当該許可の有効期間の延長の許可をすることができる。
>
> （同法 第二十六条第五項。太字は当サイト）

第6項は、この延長の事務を**日本国領事官等に委任する**と定めています。つまり**すでに海外にいる状態から、在外公館で延長を申請できる**わけです。

ところが第26条の2第3項は、こう書いています。

> 第一項の規定により外国人が受けたものとみなされる再入国の許可については、**前条第五項の規定は、適用しない**。
>
> （同法 第二十六条の二第三項。太字は当サイト）

みなし再入国許可には、この延長制度が働きません。

**結果として何が起きるか。**みなしで出国した人が、病気・家族の事情・勤務先の都合などで1年以内に戻れなくなった場合、海外から期間を延ばす手段がありません。期限を過ぎれば在留資格は失われ、日本で積み上げた在留歴もそこで切れます。[永住許可](/guide/nyukan/eiju-guideline-kaitei-2026)を目指して在留年数を積んでいる人にとっては、取り返しのつかない損失になり得ます。

| 出国の見通し | 選ぶべきもの |
| --- | --- |
| 1年以内に**確実に**戻る（旅行・短期出張・一時帰国） | **みなし**で足りる |
| 長期の海外赴任・留学・家族の看護など、**帰国時期が読めない** | **通常の再入国許可**（延長の余地を残す） |
| 在留期限が近い | みなしの期間は**在留期限まで**に縮む。要注意 |

「1年以内かどうか」ではなく「**予定が延びたときに打つ手があるか**」で選ぶ、というのが正しい判断軸です。

## 3. 有効期間の数え方

第26条の2第2項は、みなしの有効期間をこう定めます。

> 前項の規定により外国人が受けたものとみなされる再入国の許可の有効期間は、前条第三項の規定にかかわらず、**出国の日から一年**（**在留期間の満了の日が出国の日から一年を経過する日前に到来する場合には、在留期間の満了までの期間**）とする。
>
> （同法 第二十六条の二第二項。太字は当サイト）

つまり「みなし＝1年」ではありません。**在留期限が先に来るなら、そこで終わり**です。

例えば在留期限まで残り4か月の状態で出国したなら、みなしの有効期間も4か月です。この状態で長期の出国をすると、日本にいないうちに在留期限が来ます。[在留期間更新](/guide/nyukan/zairyu-koshin-shorui-shori-kikan)は日本国内で行う手続なので、海外にいる間に期限を迎えるのは避けなければなりません。

**在留期限が近いときは、出国前に更新を済ませておく**のが基本になります。更新は満了の3か月前から申請できます。

なお、更新や変更の申請中に再入国許可を持っている場合について、第26条第4項は、相当と認めるときは**第20条第6項の特例期間の終了時まで再入国許可の有効期間を延長できる**と定めています。申請中に出国する必要があるケースでは、この規定の存在を知っておくと相談の糸口になります。

## 4. みなしの対象外 — 5類型

入管庁の解説は、みなし再入国許可の対象とならず**通常の再入国許可が必要**になる場合として、次を挙げています。

| # | 対象外となる者 |
| --- | --- |
| 1 | **在留資格取消手続中**の者 |
| 2 | **出国確認の留保**対象者 |
| 3 | **収容令書の発付**を受けている者 |
| 4 | **難民認定申請中**の「特定活動」の在留資格をもって在留する者 |
| 5 | 日本国の利益または公安を害する行為を行うおそれがあることその他の相当の理由があるとして**法務大臣が認定**する者 |

加えて、条文・解説の前提として次の人も対象外です。

- **「3月」以下**の在留期間を決定された人
- **「短期滞在」**の在留資格で在留する人
- 有効な旅券を所持していない人（難民旅行証明書は除かれます）
- 中長期在留者で**在留カードを所持していない**人

## 5. 出国時にすること — EDカードの意思表明

みなし再入国許可は「黙っていても適用される」ものではありません。入管庁の解説はこう書いています。

> みなし再入国許可により出国しようとする場合は、有効な旅券（中長期在留者の方は旅券及び在留カード）を所持し、出国時に入国審査官に対して、**みなし再入国許可による出国を希望する旨の意図を表明する必要があります**。具体的には、**再入国出国記録（再入国ＥＤカード）**に一時的な出国であり、再入国する予定である旨のチェック欄が設けられているので、**同欄にチェック**していただき、入国審査官に提示するとともに、みなし再入国許可による出国を希望する旨を伝えてください。
>
> （出入国在留管理庁「みなし再入国許可」。太字は当サイト）

**チェック欄への記入を忘れると、みなし再入国許可による出国として扱われません。**空港で急いでいるときほど落としやすい手順です。

新様式の在留カードでは券面の記載事項が変わっています。出国時に在留カードを提示する場面もあるため、[新様式の在留カードと特定在留カード](/guide/nyukan/shin-yoshiki-zairyu-card-tokutei)もあわせて確認しておいてください。

## 6. 通常の再入国許可を取る場合

| 項目 | 内容 |
| --- | --- |
| 根拠 | 入管法**第26条** |
| 申請期間 | **出国する前** |
| 手数料 | 1回限り**4,000円**／数次**7,000円**（収入印紙）。**オンラインは3,500円／6,500円** |
| 経過措置 | 2025年3月31日までに受付した申請は、許可が4月1日以降でも**改定前の3,000円／6,000円** |
| **標準処理期間** | **当日** |
| 申請先 | **住居地**を管轄する地方出入国在留管理官署 |
| オンライン申請 | 可能。ただし**変更・更新・在留資格取得の許可申請と同時に行う場合に限る** |
| 審査基準 | ①現に**収容令書の発付**を受けている者でないこと ②その他再入国を許可することが適当でないと認められる者でないこと |
| 不服申立方法 | **なし** |

提出するのは再入国許可申請書、在留カードまたは特別永住者証明書の提示、旅券の提示（提示できないときは理由書）です。取次者が申請する場合は身分を証する文書の提示も必要です。

この手続の取次者には、他の在留手続にはない**旅行業者**が含まれています（局長から申請取次の承認を受け、申請人から依頼を受けたものに限る）。出国に直結する手続だからこその設計です。

**旅券を持っていない場合**——国籍を有していないなど旅券を取得できない事情があるときは、**再入国許可書**が交付されます。第26条第8項は、この再入国許可書を「当該再入国の許可に基づき本邦に入国する場合に限り、**旅券とみなす**」と定めています。

## 7. 出国中に旅券・在留カードをなくしたら

再入国許可（みなしを含む）で出国している間に旅券や在留カードを紛失した場合、あるいは新旅券の発給に伴い旧旅券を回収された場合、日本への再入国が可能であることを示す資料が手元にない状態になります。

入管庁は、この場合に**代理人等を通じて「再入国許可期限証明願」により再入国許可期限の証明を受けられる**と案内しています。ここでいう代理人等とは、本人と同居する親族、または本人から委任を受けたことを証する書面（委任状）を所持する人です。委任状はFAX等で受任者に送付したものの提出で差し支えないとされています。

日本側に頼れる人がいるかどうかで対応の速さが変わるため、長期の出国前に段取りを決めておくと安心です。

## 編集長の一言

みなし再入国許可は「手続が要らない便利な制度」として紹介されがちですが、条文が本当に語っているのは**引き換えに何を手放しているか**です。第26条の2第3項のたった一文——延長規定を適用しない——が、帰国が延びたときの選択肢をゼロにします。1年以内に戻る予定かどうかではなく、予定が崩れたときに打てる手が残っているかどうか。長期の出国を控えている方は、そこで判断してください。
