在留期間の更新は、日本で暮らす外国人が最も回数多く経験する手続です。それでも「いつから出せるのか」「間に合わなかったらどうなるのか」で毎回迷いが生じます。

本記事は、更新の**手続条件**——申請できる時期、費用、処理期間、満了日を過ぎたときの扱い——を入管法第21条と入管庁の手続案内の原文から整理します。**何を見られて落ちるのか**という審査の中身は[更新でよくある不許可理由10選](/guide/nyukan/zairyu-koshin-fukyoka-10sen)で扱っているので、あわせてお読みください。

## この記事の結論

- 根拠は**入管法第21条**。許可は「提出した文書により……**相当の理由**があるとき」に限られます。
- **6か月以上の在留期間がある人は、満了の3か月前から**申請できます。
- 3か月より前でも、**8つの特別な事情**にあたれば受け付けてもらえることがあります。
- **手数料6,000円／オンライン5,500円**、**標準処理期間2週間〜1か月**（変更より短い）。
- 満了日までに処分が出なくても**特例期間（最長2か月）**があり、オーバーステイにはなりません。
- **不服申立ての方法はありません**。

## 1. 更新とは何か

入管法第21条は次のように定めています。

> 本邦に在留する外国人は、現に有する在留資格を変更することなく、在留期間の更新を受けることができる。
>
> ２　前項の規定により在留期間の更新を受けようとする外国人は、法務省令で定める手続により、法務大臣に対し在留期間の更新を申請しなければならない。
>
> ３　前項の規定による申請があつた場合には、法務大臣は、当該外国人が**提出した文書により**在留期間の更新を適当と認めるに足りる**相当の理由**があるときに限り、これを許可することができる。
>
> （出入国管理及び難民認定法 第二十一条第一項〜第三項。太字は当サイト）

「在留資格を変更することなく」がポイントで、**同じ在留資格のまま期間だけを延ばす**手続です。仕事の内容が変わって別の在留資格に該当することになったのなら、更新ではなく[変更許可申請](/guide/nyukan/zairyu-shikaku-henko-ryugaku-shuro)になります。

第3項の「提出した文書により」は変更（第20条第3項）と同じ表現で、**資料をそろえるのは申請する側**という建て付けを示しています。

## 2. 申請できる時期 — 原則は「満了の3か月前から」

入管庁の手続案内は、申請期間をこう定めています。

> 在留期間の満了する日以前（**六か月以上の在留期間を有する者にあっては在留期間の満了する三か月前から**。）
>
> （在留期間更新許可申請 手続案内。太字は当サイト）

在留期間が1年・3年・5年といった6か月以上の人は、**満了の3か月前**が申請開始のタイミングです。標準処理期間が2週間〜1か月であることを踏まえると、3か月前に近いところで出しておけば、追加資料の求めが入っても満了日までに片づきます。

| 在留期間 | 申請開始 |
| --- | --- |
| 6か月以上（1年・3年・5年など） | 満了日の**3か月前**から |
| 6か月未満 | 満了する日以前 |

## 3. 3か月より前に出したいとき — 認められる8つの事情

ここが実務でよく効く部分です。手続案内は、「真にやむを得ない特別な事情が認められる場合は、3か月以上前から申請を受け付けることもあります」として、例を8つ挙げています。

| # | 特別な事情（原文） |
| --- | --- |
| 1 | 海外に留学する場合 |
| 2 | 業務命令により長期間にわたり海外出張や海外赴任をする場合 |
| 3 | 妊娠中であり、出産時期が申請時期と重なる場合 |
| 4 | 本国に里帰り出産する場合 |
| 5 | 病気治療により入院する場合 |
| 6 | 本国で病気治療による入院を予定している場合 |
| 7 | 家族が同時申請する場合 |
| 8 | 外国の査証取得の際、本邦での残りの在留期間が6か月以上必要である場合 |

手続案内は、これらに該当する場合は**事前に必要な資料を添えて、申請先の地方出入国在留管理官署に問い合わせる**よう案内しています。「受け付けることもあります」という書き方のとおり、当然に認められるものではありません。

8番目は特に見落とされます。海外出張のために第三国の査証を取るとき、残存在留期間が6か月以上必要とされることがあり、それを理由に前倒しできる、という趣旨です。

## 4. 手数料と処理期間

| 項目 | 内容 |
| --- | --- |
| 手数料（窓口） | 許可されるとき**6,000円**（収入印紙で納付） |
| 手数料（**オンライン**） | **5,500円**（収入印紙で納付） |
| 経過措置 | 2025年3月31日までに受付した申請は、許可が4月1日以降でも**改定前の4,000円** |
| **標準処理期間** | **2週間〜1か月** |
| 提出先 | **住居地**を管轄する地方出入国在留管理官署 |
| 受付時間 | 平日 9:00〜12:00、13:00〜16:00 |
| オンライン申請 | **可能** |
| 不服申立方法 | **なし** |

不許可の場合に手数料はかかりません。オンライン申請なら500円安くなります——毎年の更新を社員分まとめて扱う企業では、この差と窓口往復の時間が積み上がります。オンライン化の進め方は[入管オンライン申請システムの実務マニュアル](/practice/dx/nyukan-online-shinsei-manual)にまとめました。

在留資格変更（1か月〜2か月）と比べると**更新のほうが短い**のが公式の目安です。ただし目安は目安で、資料の追加提出を求められれば延びます。

## 5. 満了日を過ぎても大丈夫な理由 — 特例期間

更新を出したのに満了日までに結果が来ない。このとき在留が違法になるわけではありません。入管法第21条第4項は第20条第6項を準用しており、特例期間が働きます。

> 第二項の規定による申請があつた場合（三十日以下の在留期間を決定されている者から申請があつた場合を除く。）において、その申請の時に当該外国人が有する在留資格に伴う在留期間の満了の日までにその申請に対する処分がされないときは、当該外国人は、その在留期間の満了後も、**当該処分がされる時**又は**従前の在留期間の満了の日から二月を経過する日が終了する時**の**いずれか早い時**までの間は、引き続き当該在留資格をもつて本邦に在留することができる。
>
> （出入国管理及び難民認定法 第二十条第六項。太字は当サイト）

| 項目 | 内容 |
| --- | --- |
| 効果 | 満了後も**従前の在留資格で**在留を継続できる |
| 終わり | 処分の時、または満了日から**2か月**経過時の、**早いほう** |
| 対象外 | 在留期間が**30日以下**と決定されている人からの申請 |
| 前提 | **満了日までに申請していること**。出し忘れには効かない |

最後の行が肝心です。特例期間は**申請済みであること**が前提で、満了日を過ぎてから出しても救われません。逆に言えば、資料が完璧にそろっていなくても**期限内に申請しておく**ことに大きな意味があります。

## 6. 審査で見られること

更新の審査基準について、入管庁の手続案内はこう書いています。

> 出入国管理及び難民認定法別表第一の下欄に掲げる活動（**外交及び公用の項の下欄に掲げる活動を除く。**）又は別表第二の下欄に掲げる身分若しくは地位（永住者の項の下欄に掲げる地位を除く。）を有する者としての活動のいずれかに該当し、かつ、在留期間の更新を適当と認めるに足りる相当の理由があること。
>
> （在留期間更新許可申請 手続案内。太字は当サイト）

具体的な考慮要素は「**在留資格の変更、在留期間の更新許可のガイドライン**」（平成20年3月策定、最終改正 令和8年6月）が示しています。在留資格該当性・上陸許可基準への適合を軸に、素行、独立生計、雇用・労働条件の適正性、納税義務の履行、入管法上の届出義務の履行などが並びます。

ここで押さえておきたいのは、**全部を満たしたから必ず許可される、という制度ではない**ことです。ガイドライン自体が代表的な考慮要素を示すものであり、判断は裁量的です。項目ごとに何が減点になるのか——たとえば納税や社会保険料の未納がどう扱われるか——は[更新でよくある不許可理由10選](/guide/nyukan/zairyu-koshin-fukyoka-10sen)で具体的に整理しています。

なお、必要書類は在留資格ごとに分かれており、入管庁のページでも在留資格を選んでから一覧に進む構造になっています。自分の在留資格が定まっていない場合は[在留資格判定ナビ](/tools/visa-navi)で確認してください。

## 編集長の一言

更新でいちばん多い失敗は、書類の中身ではなく**出す時期**です。3か月前から出せることを知らずに満了間際に駆け込み、追加資料を求められて特例期間に突入する——というパターンを避けるだけで、体感の負荷はかなり下がります。そして特例期間は「申請済み」に対してのみ働きます。完璧な書類を待つより、期限内に出すことのほうが強い。ここは制度の設計思想がはっきり出ている部分です。
