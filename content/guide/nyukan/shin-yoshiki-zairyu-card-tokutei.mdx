2026年6月14日、在留カードの様式が変わりました。同時に、マイナンバーカードの機能を付加した**特定在留カード**が導入されています。

見た目の変更にとどまりません。**券面から「在留期間」の記載がなくなった**ため、外国人を雇用している企業の確認実務が影響を受けます。さらに2026年8月19日には、読取アプリの表示項目が改修されました。本記事では入管法第19条の15の2と入管庁の案内の原文から、いま押さえるべき点を整理します。

## この記事の結論

- 2026年6月14日から、在留カード・特別永住者証明書が**新様式**になり、**特定在留カード**（マイナンバーカード機能付き）が導入されました。
- 顔写真の表示対象が**1歳以上**に広がりました（従来は16歳以上）。
- 新様式では券面に**「在留期間」「許可の種類」「許可年月日」「交付年月日」が記載されません**。ただし**「在留期間の満了日」は記載されます**。
- **2026年8月19日**リリースの読取アプリから、「在留期間」「許可の種類」「許可年月日」が表示されるようになりました。
- 特定在留カードは**単独では申請できず**、他の手続と**同時申請**します。申請先は手続によって**入管**と**市区町村**に分かれます。
- 手数料は**入管庁**と**J-LIS**の2系統。2026年6月14日以降の**初回は原則不要**です。

## 1. 在留カードとは — 「証明書」であり「許可証」

前提を確認します。入管庁の説明はこうです。

> 在留カードは、新規の上陸許可、在留資格の変更許可や在留期間の更新許可など在留資格に係る許可の結果として我が国に中長期間在留する者（中長期在留者）に対して交付されます。したがって、……適法に在留する者であることを証明する「**証明書**」としての性格を有するとともに、上陸許可以外の在留資格に係る許可時に交付される在留カードは、従来の旅券になされる各種許可の証印等に代わって許可の要式行為となるため「**許可証**」としての性格を有しています。
>
> （出入国在留管理庁「在留カードとは？」。太字は当サイト）

「許可証」としての性格があるという点は、[在留資格変更](/guide/nyukan/zairyu-shikaku-henko-ryugaku-shuro)で触れた「許可の効力は在留カードの交付等の措置があった時に生ずる」（入管法第20条第5項）と対応しています。カードは記録ではなく、許可そのものの形式です。

## 2. 2026年6月14日の変更点

| 変更 | 内容 |
| --- | --- |
| 新様式化 | 在留カード・特別永住者証明書が新様式に。**券面記載事項が変わる** |
| 特定在留カードの導入 | マイナンバーカードの機能を付加する措置が講じられた在留カード。特別永住者証明書には**特定特別永住者証明書** |
| 顔写真 | **1歳以上**に表示（2026年6月13日以前の発行分は**16歳以上**） |

## 3. 券面から「在留期間」が消えた — 確認実務への影響

ここが実務上いちばん大きい変更です。入管庁は、読取アプリに関する周知（令和8年8月19日時点）の中で、券面記載事項をこう説明しています。

新様式の在留カードおよび特定在留カードで**券面に記載される**もの：

- 氏名／生年月日／性別／国籍・地域／住居地
- 在留資格
- **在留期間の満了日**
- 在留カードの番号／在留カードの有効期限満了日
- 就労制限の有無
- 資格外活動許可を受けているときはその旨

一方、**券面に記載されない**もの：

- **在留期間**
- 許可の種類
- 許可年月日
- 交付年月日

「在留期間」（1年・3年・5年といった長さ）は券面から読み取れなくなりました。ただし**「在留期間の満了日」は記載されています**。ここを混同すると話がずれるので注意してください。

| 確認したいこと | 新様式の券面で分かるか |
| --- | --- |
| いつまで在留できるか（満了日） | **分かる** |
| 在留期間の長さ（1年か3年か） | **分からない**（読取アプリで確認） |
| 就労できるか | **分かる**（就労制限の有無） |
| 資格外活動の許可があるか | **分かる** |

雇用管理では満了日が分かれば足りる場面が多い一方、在留期間の長さは[永住許可](/guide/nyukan/eiju-guideline-kaitei-2026)の「最長の在留期間」要件などで意味を持ちます。券面だけで判断する運用を組んでいる場合は、見直しが必要です。

在留カードによる就労可否の確認手順そのものは[外国人雇用の在留資格 早見表](/guide/nyukan/gaikokujin-koyo-zairyu-shikaku-hayamihyo)にまとめています。

## 4. 2026年8月19日 — 読取アプリの改修

券面に載らない項目は、当初は読取アプリでも見られませんでした。入管庁の周知はこう説明しています。

> ……令和８年６月１４日以降に交付される新様式の在留カード及び特定在留カードを読み取った場合、券面に記載されている……項目が表示されますが、新様式の在留カード及び特定在留カードでは券面に記載されない「在留期間」、「許可の種類」、「許可年月日」及び「交付年月日」が表示されませんでした。
>
> 今般、在留カード等読取アプリケーションの改修作業を終え、**令和８年８月１９日にリリースされるバージョンからは、「在留期間」、「許可の種類」及び「許可年月日」が表示されるようになりました**ので、周知いたします。
>
> （出入国在留管理庁「在留カードとは？」内の周知（令和8年8月19日時点）。太字は当サイト）

| 項目 | 券面 | 読取アプリ（2026年8月19日以降） |
| --- | --- | --- |
| 在留期間 | 記載なし | **表示される** |
| 許可の種類 | 記載なし | **表示される** |
| 許可年月日 | 記載なし | **表示される** |
| 交付年月日 | 記載なし | 周知文では、表示されるようになった項目として**挙げられていません** |

「交付年月日」については、入管庁の周知が改修後の表示項目に含めていません。必要な場面では、アプリの実際の表示で確認してください。

なお特定在留カードはマイナンバーカードの機能を持つため、デジタル庁が配布する**「対面確認アプリ」**でも在留期間等を読み取れると案内されています。ただし案内の時点では**iOS版のみ**です。

**古いバージョンのアプリを使い続けている場合は更新してください。**表示されないことと、記載がないことは別問題です。

## 5. 特定在留カードの申請 — 単独ではできない

入管法第19条の15の2第1項は、特定在留カードの申請を、他の届出・申請に**併せて**行うものとして設計しています。単独申請の制度ではありません。

入管庁の案内が示す「同時に行う手続」と申請先の対応は次のとおりです。

| 同時に行う手続 | 申請先 |
| --- | --- |
| 住居地以外の在留カード記載事項の変更届出 | **地方出入国在留管理官署** |
| 在留カードの有効期間の更新申請 | 同上 |
| 汚損等による在留カードの再交付申請 | 同上 |
| 交換希望による在留カードの再交付申請 | 同上 |
| 在留期間更新許可申請 | 同上 |
| 在留資格変更許可申請（引き続き中長期在留者に該当する場合に限る） | 同上 |
| 永住許可申請 | 同上 |
| 新規上陸後の住居地届出 | **住居地の市区町村の担当窓口** |
| 在留資格変更等に伴う住居地の届出 | 同上 |
| 住居地の変更届出 | 同上 |

対象は「**住民基本台帳に記録されている中長期在留者**」です。

提出書類は、同時に行う手続の書類に加えて次のものです。

| 書類 | 注意点 |
| --- | --- |
| 特定在留カード等交付申請書 | **地方入管用と市区町村用で様式が別** |
| 暗証番号設定依頼書 | 代理人・取次者が申請する場合は、**暗証番号を見られないよう封緘等の措置**をした状態で提出。署名用電子証明書は**15歳未満には原則発行されない** |
| 写真1葉 | 申請日前6か月以内。交付時点で**1歳未満と見込まれる場合は不要**。同時手続で写真を出すなら重ねて提出は不要 |

このほか旅券（提示できない場合は理由書）と在留カードの提示が必要です。

## 6. 手数料 — 入管庁とJ-LISの2系統

特定在留カードは2つの制度をまたぐため、手数料も2系統になります。

| 納付先 | 金額 | 納付方法 |
| --- | --- | --- |
| **出入国在留管理庁**（在留カードの機能） | **1,900円**（直送の場合は**2,600円**） | 収入印紙を貼付した手数料納付書 |
| **J-LIS**（マイナンバーカードの機能／入管で申請） | **600円**（電子証明書の発行を受ける場合は**800円**） | 指定口座への振込み |
| **J-LIS**（市区町村で申請） | 同額 | **現金** |

**原則として手数料が不要になるのは次の場合**です。

- 2026年6月14日以降、同年6月13日までに交付された在留カードを持っている人が、上記の申請時期に特定在留カードの交付を受ける場合（＝**6月14日以降に各手続を初めて行うとき**）
- 特定在留カードの交付を受けた後、次の各手続で引き続き特定在留カードを持ち続けようとする場合（一部例外あり）

⚠️ ただし実際の要否は、**同時に行う手続**と**いま所持しているカードの種別**（6月13日までの在留カード／6月14日以降の在留カード／特定在留カード）の組合せで細かく分かれます。入管庁の案内は一覧表と6つの注記でこれを示しており、本記事では骨格のみを扱います。**具体の要否は必ず入管庁の一覧表で確認してください。**

日付が動く項目もあるため、押さえておきたい点を挙げます。

| 日付 | 内容 |
| --- | --- |
| **2026年8月7日** | 永住許可申請と併せて申請し、交付時点で6月13日までの在留カードを所持する場合、**J-LIS手数料も不要**に |
| **2026年10月1日以降** | 永住許可申請と併せる場合は**入管・J-LISのいずれも必要**に／住居地の変更届出と併せる場合は**いずれも不要**に |

10月1日で扱いが変わる項目があるため、申請時期の選び方が費用に響きます。

## 7. 直送（郵送交付）という選択肢

市区町村で申請する場合に限り、特定在留カードを住居地への郵送で受け取る「**直送**」を申し出られる場合があります。**地方出入国在留管理官署で申請する場合は直送を利用できません。**

案内が挙げる対象者は次のとおりです。

- 申請日に**1歳未満**の中長期在留者で、特定在留カード・マイナンバーカードの交付を受けたことがない人
- 住民基本台帳法第30条の46または第30条の47の届出をした人で、その届出後に交付を受けたことがない人
- 特定在留カードの**追記欄の余白がなくなった**人、およびこれに準じるものとして長官が適当と認める人
- 刑の執行のため刑事施設等に収容されていた人等で、釈放後に交付を受けたことがない人

直送を申し出る場合、入管庁への手数料は1,900円ではなく**2,600円**です。また直送の申出を行うときは、申請時に本人も手続に来る必要があるとされています。

## 編集長の一言

この改正でいちばん実務を動かすのは、券面から「在留期間」が消えたことだと考えています。**満了日は残っているのに期間は消えた**——この非対称は、カードを目視で確認する運用にじわじわ効いてきます。そして読取アプリ側の対応が追いついたのが2026年8月19日。制度開始から2か月あまり、表示されない項目があった期間が存在したという事実は、記録しておく価値があります。手数料についても10月1日で扱いが変わる項目があるため、申請時期の判断材料として押さえておいてください。
