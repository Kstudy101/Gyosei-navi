転職した外国人社員の業務内容が、いまの在留資格の範囲に収まっているか——これは次の[在留期間更新](/guide/nyukan/zairyu-koshin-shorui-shori-kikan)まで待たないと結論が出ません。その待ち時間を先に潰す制度が**就労資格証明書**です。

一方で、この制度には「使い方を誤らせないための条文」も置かれています。本記事では入管法第19条の2と入管庁の手続案内の原文から、何ができて何ができないのかを整理します。

## この記事の結論

- 根拠は**入管法第19条の2**。「その人が**行うことができる**就労活動」を証明する文書です。
- **義務ではありません**。取らなくても違法ではない任意の制度です。
- 転職で業務内容が変わったときに、**次の更新を待たずに適合性を確認**できるのが実益です。
- **標準処理期間は「当日」。ただし勤務先を変えた場合などは1か月〜3か月**。
- **手数料2,000円／オンライン1,600円**。
- 第2項が、**提示しないことを理由とする不利益な取扱いを禁止**しています。

## 1. 何を証明する書面か

入管法第19条の2第1項はこう定めています。

> 出入国在留管理庁長官は、本邦に在留する外国人から申請があつたときは、法務省令で定めるところにより、その者が**行うことができる**収入を伴う事業を運営する活動又は報酬を受ける活動を証明する文書を交付することができる。
>
> （出入国管理及び難民認定法 第十九条の二第一項。太字は当サイト）

「行うことができる」——つまり**すでに与えられている在留資格の範囲を確認する**書面です。新しい資格を与えるものでも、業務内容を許可するものでもありません。入管庁の手続案内も「自らの在留資格で行うことができる……活動を証明する文書」と説明しています。

「交付することができる」という書き方のとおり、**申請するかどうかは本人の任意**です。取らないことが違法になる制度ではありません。

## 2. 転職時に取る意味 — 更新まで待たないという選択

就労資格証明書が実務で効くのは、**転職して業務内容が変わったとき**です。

たとえば「技術・人文知識・国際業務」で働いていた人が、別の会社の別の職種に移ったとします。その業務が[技人国の範囲](/guide/nyukan/gijinkoku-visa-guide)に収まっているかどうかは、次の在留期間更新の審査で初めて入管の判断が示されます。もし範囲外だったなら、更新の時点で不許可という重い結果になります。

就労資格証明書を申請すると、その判断を**前倒しで受けられます**。範囲内なら証明書が出ますし、疑義があれば審査の過程で見えてきます。転職後すぐに確認しておけば、まだ選択肢が残っている段階で手を打てます。

| 確認のタイミング | 起きること |
| --- | --- |
| 就労資格証明書で先に確認 | 早い段階で適否が分かる。必要なら[在留資格変更](/guide/nyukan/zairyu-shikaku-henko-ryugaku-shuro)などの手を打てる |
| 次の更新まで待つ | 不許可が判明したときには、その会社で働いた期間がすでに積み上がっている |

企業側から見れば、採用した外国人が問題なく働ける状態かを、更新期を待たずに確かめられる材料になります。

## 3. 標準処理期間が2つある理由

手続案内が示す標準処理期間は、少し変わった書き方をしています。

> 当日（**勤務先を変えた場合などは１か月～３か月**）
>
> （就労資格証明書交付申請 手続案内。太字は当サイト）

この差は、審査の中身の差です。

| ケース | 期間 | なぜ |
| --- | --- | --- |
| 勤務先・活動内容に**変更なし** | **当日** | すでに許可された内容の確認にとどまる |
| 転職等で勤務先・活動内容が**変わった** | **1か月〜3か月** | 新しい業務が在留資格の範囲に収まるかを**実質的に審査**する |

つまり、実務で使いたい場面（＝転職後の確認）ほど時間がかかります。「当日もらえる」というイメージで動くと予定が狂うので、転職時に取るなら**1〜3か月を見込んでおく**のが安全です。

提出書類も、この2つのケースで分かれています。手続案内は次の3類型を定めています。

| 類型 | 提出・提示するもの |
| --- | --- |
| 1. 勤務先・活動内容に変更がない人 | 申請書、資格外活動許可書（交付されている人）、在留カードまたは特別永住者証明書、旅券または在留資格証明書（提示できないときは理由書）、取次者なら身分を証する文書 |
| 2. 転職等で勤務先・活動内容が変わる（変わった）人 | 上記に加えて、**新たな勤務先や活動内容の詳細がわかる書類** |
| 3. 就労制限がない在留資格（永住者・定住者など）・特別永住者 | 類型1と同じ |

類型3には、資格外活動の許可を受けている人や、特定活動で就労が認められている人も同様の扱いだと注記されています。

## 4. 手数料・申請先

| 項目 | 内容 |
| --- | --- |
| 手数料（窓口） | 交付されるとき**2,000円**（収入印紙で納付） |
| 手数料（**オンライン**） | **1,600円** |
| 経過措置 | 2025年3月31日までに受付した申請は、交付が4月1日以降でも**改定前の1,200円** |
| 提出先 | **住居地**を管轄する地方出入国在留管理官署 |
| 受付時間 | 平日 9:00〜12:00、13:00〜16:00 |
| オンライン申請 | **可能** |
| 不服申立方法 | **なし** |

提出できるのは本人、法定代理人、そして取次者です。取次者は、地方出入国在留管理局長から申請等取次者としての承認を受けた者（申請人が経営・雇用されている機関の職員、研修・教育を受けている機関の職員、監理団体の職員、公益法人の職員）と、局長に届け出た弁護士・行政書士で、いずれも申請人から依頼を受けたものとされています。処分時の受領者も同じです。

## 5. 見落とされがちな第2項 — 提示を強いる制度ではない

入管法第19条の2には第2項があります。就労資格証明書を語るときに最も落ちやすい条文です。

> **何人も**、外国人を雇用する等に際し、その者が行うことができる収入を伴う事業を運営する活動又は報酬を受ける活動が**明らかな場合に**、当該外国人が前項の文書を提示し又は提出しないことを理由として、**不利益な取扱いをしてはならない**。
>
> （出入国管理及び難民認定法 第十九条の二第二項。太字は当サイト）

読み解くと、こうなります。

| 要素 | 内容 |
| --- | --- |
| 誰に対する規律か | **「何人も」** — 雇用主に限らない |
| どんな場面 | 外国人を**雇用する等に際し** |
| 条件 | 就労できる活動が**すでに明らかな場合** |
| 禁止されること | 証明書を**出さないことを理由**とする**不利益な取扱い** |

在留カードの「就労制限の有無」欄などで就労の可否が確認できるのであれば、そこで足ります。それにもかかわらず「就労資格証明書がないと採用しない」と扱うことは、この条項が想定していない対応です。

在留カードによる就労可否の確認方法は[外国人雇用の在留資格 早見表](/guide/nyukan/gaikokujin-koyo-zairyu-shikaku-hayamihyo)にまとめています。

つまり就労資格証明書は、**企業が外国人に突きつけるための書類ではなく、本人・企業がリスクを先に潰すために任意で使う道具**です。この位置づけを外すと、制度の使い方を誤ります。

## 編集長の一言

就労資格証明書は「転職したら取っておくと安心」と紹介されることが多い書面ですが、条文には**取らせる側への歯止め**（第19条の2第2項）がセットで書かれています。制度を紹介するなら、この非対称を落とさずに伝えるべきだと考えています。そのうえで、転職で業務内容が変わるケースでは、1〜3か月かかることを織り込んででも先に確認しておく価値がある——これが実務的な結論です。
