在留手続きは、COE・変更・更新・永住とそれぞれ別の記事で解説していますが、「結局どれが自分に必要で、いくらかかって、どれくらい待つのか」を横並びで見たいという声に応えて、4手続きの条件を1枚にまとめました。

**個別の必要書類は含みません。**在留資格ごとに大きく異なるため、各手続きの記事と入管庁の該当ページで確認してください。本シートは**手数料・期間・申請条件の比較**に特化しています。

## この記事の結論

- 4手続きの流れ：**COE**（海外から呼ぶ）→**変更**（国内で資格を切り替える）／**更新**（同じ資格で延長する）→**永住**（制限のない資格へ）。
- 標準処理期間は**COE 1〜3か月／変更 1〜2か月／更新 2週間〜1か月／永住 4〜6か月**の順に長くなります。
- ⚠️ **手数料は2026年10月1日から変わります**。永住は10,000円→200,000円、変更・更新は一律6,000円→在留期間別の段階制へ。
- **取次者・在留カードの受領制限は4手続きで共通の枠組み**——承認を受けていない人は代理提出・受領ができません。

## 2. どの手続きが必要か迷ったら

| 状況 | 必要な手続き |
| --- | --- |
| 海外にいる人を日本に呼ぶ | **COE**（交付後、在外公館で査証を取得） |
| 日本国内で転職・進学などで在留資格を切り替える | **在留資格変更許可** |
| 同じ在留資格のまま期間だけ延ばす | **在留期間更新許可** |
| 制限のない永住者の資格を得たい | **永住許可**（多くの場合、変更・更新を重ねた後の最終段階） |

在留資格そのものが分からない場合は、[在留資格判定ナビ](/tools/visa-navi)で候補を確認できます。

## 3. 4手続きに共通する確認事項

個別書類は手続きごとに大きく異なりますが、**申請の枠組みとして共通する点**が入管庁の各手続案内に繰り返し明記されています。

| 項目 | 内容 |
| --- | --- |
| 提出先 | **住居地**を管轄する地方出入国在留管理官署（COEのみ居住予定地・受入機関所在地の場合あり） |
| 取次者 | 承認を受けた機関の職員（受入れ機関・監理団体・公益法人等）、または届出済みの弁護士・行政書士に**限られる** |
| 在留カードの受領 | 取次者等に該当しない限り、**配偶者・子・兄弟姉妹・会社の同僚でも受領不可**（変更・更新・永住で明文確認。COEは電子交付制度あり） |
| 個別書類 | 在留資格・申請内容ごとに異なる。**本シートには含まれません** |

「会社の人事担当者が代わりに書類を出す」「配偶者がカードを受け取りに行く」といった対応は、承認を受けた取次者でなければできません。この制限は[在留資格変更許可申請の記事](/guide/nyukan/zairyu-shikaku-henko-ryugaku-shuro)で扱った内容が、4手続きに共通する構造として繰り返されています。

⚠️ オンライン申請については、COE・変更・更新は可能と明記されていますが、**永住許可申請のオンライン可否は、当サイトが確認した入管庁の手続案内に明確な記載がありませんでした。**申請前に最新の案内で確認してください。

## 編集長の一言

4つの手続きを並べてみると、「制限が緩くなる手続きほど、時間もお金もかかる」という一貫した設計が見えてきます。COEは無料で1〜3か月、永住は20万円で4〜6か月。この非対称を踏まえてスケジュールと予算を組んでおくと、土壇場で慌てずに済みます。個別書類まで含めた完全な準備には、必ず該当する在留資格のページを確認してください。
