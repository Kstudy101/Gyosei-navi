## 현재 상태

본 세션(2026-09-20)에서는 마스터플랜・IA・편집가이드・법적 포지셔닝의 **문서 재설계까지만 진행**했다. 코드(`taxonomy.ts` 등)와 실제 카테고리 확정은 다음 단계다.

콘텐츠 캘린더는 다음 두 가지가 확정된 **이후**에 수립한다.

1. `docs/01_IA_TAXONOMY.md` §3의 카테고리 후보(`shussan` `jutaku` `sogyo` 등) 중 실제로 착수할 초기 카테고리 확정
2. `src/config/taxonomy.ts`・`src/lib/content-schema.ts` v2 코드 작성 완료 (신규 기사를 실제로 만들 수 있는 상태)

## 캘린더 수립 시 반영할 원칙 (v1에서 계승할 것)

- **주 2건 최소 사수.** 완벽한 3건보다 꾸준한 2건이 이긴다(v1 원칙 그대로 유지).
- 카테고리 신설은 Pillar 1개 + Cluster 3개를 동시에 낼 수 있을 때만(`docs/01` §6).
- 一次情報(관공서 공식 발표) 확인 없이는 집필하지 않는다.
- 「신규 기사 3건 : 갱신 1건」 비율을 일정 시점 이후 유지(마감・조건 변경 추종용 — v1과 동일 발상이나, v2는 「법 개정」이 아니라 「모집 마감・조건 변경」을 추종).
