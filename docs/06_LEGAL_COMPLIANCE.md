# 법적 컴플라이언스 가이드 — 행정서사법 제19조 대응

> **이 문서는 프로젝트 전체에서 가장 중요하다.**
> 여기 적힌 선을 넘으면 1년 이하 징역 또는 100만엔 이하 벌금이며, 프로젝트 자체가 소멸한다.

---

## 1. 전제 — 2026년 1월 개정으로 무엇이 달라졌나

2026년 1월 1일 시행된 개정 행정서사법의 관련 포인트:

1. **업무 제한 규정의 명확화**
   「어떤 명목이든(いかなる名目であっても) 보수를 받고」 관공서에 제출하는 서류를 작성하는 행위는 행정서사의 독점업무임이 명시되었다.
   → **「컨설팅료」「정보제공료」「상담료」 등으로 이름을 바꿔도 빠져나갈 수 없다.**

2. **양벌규정 강화**
   무자격 업무뿐 아니라 **행정서사 명칭의 무단 사용**, 장부 미비치 등도 처벌 대상이며, 개인뿐 아니라 **소속 법인까지** 처벌된다.

3. **디지털사회 대응 노력의무 신설**
   → 이건 리스크가 아니라 기회. 우리 콘텐츠의 핵심 수요원이다.

## 2. 판정표 — 무엇이 되고 무엇이 안 되는가

### ✅ 자격 없이도 가능 (본 프로젝트의 활동 영역)

| 행위 | 조건 |
|---|---|
| 제도·법령·절차의 **일반적** 해설 기사 작성·공개 | 특정 개인의 사안에 대한 것이 아닐 것 |
| 통계·공표 자료의 정리 및 시각화 | 출처 명시 |
| 공개된 서식의 **기입례**를 일반 정보로 게재 | 「이렇게 쓰면 됩니다」가 아니라 「일반적으로 이런 항목이 있습니다」 |
| 셀프 진단 툴 제공 | **「참고 정보이며 법적 판단이 아님」 명시 필수** |
| 유자격 행정서사에게 상담을 권유 | 특정 사무소 소개로 대가를 받지 않을 것(유상 소개는 별도 검토 필요) |
| 광고·제휴 수익 (AdSense, 서적·강좌 어필리에이트) | 스테마 규제 준수 — 「PR」 표기 |
| **행정서사·사업 사무소의 광고 지면 판매 (2026-08-19 결정)** | **월액 고정 게재료만**. 소개 건수·성사 보수·클릭 과금은 취급 금지(유상 알선으로 평가될 구조를 배제). 슬롯에 「広告」 상시 표기, 등록번호·사무소 실재 확인, 편집권 독립. 상세: `/ads` 페이지·`src/config/ads.ts` |
| 정보 상품 판매 (제도 해설 e-book 등) | **개별 사안 대응이 아닌 일반 정보에 한정** |

### ❌ 절대 금지 (자격 취득 전)

| 행위 | 위험도 |
|---|---|
| 개별 사안에 대한 답변·조언 (「제 경우는 어떤가요?」에 답하기) | **치명적** |
| 관공서 제출서류의 작성·작성 보조 (유·무상 불문) | **치명적** |
| 신청 대리·동행 | **치명적** |
| 「컨설팅」 명목의 실질적 서류작성 지원 | **치명적** (2026 개정으로 명확히 차단) |
| 「行政書士」를 연상시키는 명칭·직함 사용 | **치명적** (양벌규정 대상) |
| 「許可を取れます」「必ず通ります」 등 결과 보증 표현 | 고위험 |
| 유상으로 특정 행정서사를 소개 | 요검토 (제휴 형태에 따라 다름) — **2026-08-19 부분 해소: 「월액 고정 게재료의 광고 게재」는 ✅ 표의 조건하에 가능. 소개·성사·클릭에 연동한 대가는 계속 금지** |

### ⚠️ 회색지대 — 반드시 보수적으로

- **LINE에서 오는 개별 질문**: 「〇〇のケースでは…」 하고 답하는 순간 아웃.
  → 자동응답 고정: 「個別のご事情に関するご相談にはお答えできません。関連記事はこちら → / 個別相談は行政書士にご依頼ください。」
- **셀프 진단 툴의 결과 표시**: 「あなたは永住申請できます」(❌) → 「一般的な要件との照合結果です。実際の可否は個別審査によります」(✅)
- **댓글·SNS 답글**: 동일 원칙. 일반 정보로만.

## 3. 사이트 전체에 박아 넣을 정형 문안

### 3.1 푸터 고정 (전 페이지)

```
本サイトは行政書士業務に関する一般的な情報提供を目的としており、
個別の法律相談・書類作成代行・申請代理は行っておりません。
個別のご相談は有資格の行政書士へご依頼ください。
掲載情報は執筆時点のものであり、最新の法令・運用と異なる場合があります。
```

### 3.2 기사 말미 `<Disclaimer />` 컴포넌트

```
【ご注意】
本記事は制度に関する一般的な情報提供であり、個別の事案に対する法的助言ではありません。
実際の申請にあたっては、最新の公式情報をご確認のうえ、
必要に応じて行政書士等の有資格者にご相談ください。
```

### 3.3 진단 툴 결과 화면

```
※ 本診断は公表されている一般的な要件との照合結果であり、
   許可の可否を判定するものではありません。
   実際の審査は個別事情を総合的に考慮して行われます。
```

### 3.4 運営者情報 페이지 (`/about`)

> **자격 상태를 숨기지 말고 명시할 것.** 숨기면 발각 시 신뢰가 붕괴하고, 명시하면 오히려 정직한 미디어로 평가받는다.

```
【運営者について】
本サイトは、行政書士試験の受験生であり、日本在住の外国人当事者でもある編集者が運営しています。
編集者は行政書士の有資格者ではないため、個別の相談業務・書類作成業務は一切行っておりません。
本サイトの役割は、官公庁の一次情報（法令・ガイドライン・パブリックコメント等）を
正確に読み解き、わかりやすく整理してお伝えすることに限定されます。
```

### 3.5 문의 폼

```
※ 個別のご相談（在留資格の可否、書類の書き方等）にはお答えできません。
   記事内容に関するご指摘・取材依頼・掲載依頼のみ承ります。
```

## 4. 발행 전 법적 체크리스트 (품질 게이트에 통합)

- [ ] 특정 개인·기업의 사안을 다루는 표현이 없는가
- [ ] 「あなたの場合は」「ご依頼ください」류의 수임 유도 표현이 없는가
- [ ] 「行政書士」를 자칭하거나 오인시키는 표현이 없는가
- [ ] 결과 보증 표현(「必ず」「確実に」「100%」)이 없는가
- [ ] `<Disclaimer />` 가 삽입되어 있는가
- [ ] 제휴 링크가 있다면 「PR」 표기가 있는가
- [ ] 인용이 인용 요건(주종관계·출처명시·개변 없음)을 만족하는가

## 5. 그 외 준수 법령

| 법령 | 대상 | 대응 |
|---|---|---|
| 個人情報保護法 | LINE·메일 취득 정보 | 프라이버시 폴리시 게재, 이용목적 명시 |
| 特定商取引法 | 유료 상품 판매 시 | 사업자 표기 페이지 필수 (개인정보 노출 주의 → 개업 후 사무소 주소로). **광고 지면 판매는 사업자 간(B2B) 계약으로 통신판매(소비자 거래)에 해당하지 않는다고 판단(2026-08-19) → 표기 페이지는 현 단계 미작성. 소비자 대상 유료 상품(e-book 등) 판매 시 재검토** |
| 景品表示法 / 스테마 규제 | 제휴·광고 | 「PR」「広告」 표기 |
| 著作権法 | 관공서 자료 인용 | 이용 규약 확인, 인용 요건 준수, 전재 금지 자료 주의 |
| 薬機法·医療法 | 해당 없음 | — |

## 6. Phase C (개업 후) 전환 시 변경점

자격 취득·등록 후에는 다음이 **한 번에** 해제된다:

- 개별 상담·수임 가능 → `ConsultCta` 컴포넌트 활성화
- 「行政書士」 명칭 사용 가능 → 사이트명·프로필 변경
- MEO(Google 비즈니스 프로필) 등록 가능
- `reviewedBy` 필드에 본인 등록번호 기재 → **전 기사의 E-E-A-T 일괄 상승**

> 이 전환을 코드 상 **1개 컴포넌트 + 1개 설정 파일**의 변경으로 끝낼 수 있도록 설계해 둘 것.
> 그것이 `src/config/site.ts`와 `src/components/cta/` 를 분리한 이유다.
