# 법적 포지셔닝 가이드 v2 — 완화판

> v1(행정서사법 제19조 대응)에서 리스크 성격이 크게 바뀌었다. 본 문서는 v1을 대체한다.
> **v1이 다뤘던 「행정서사법 제19조」 자체는 v2 사이트의 주제와 무관해졌다.** 보조금 정보 제공은 행정서사・사회보험노무사・중소기업진단사 등 특정 자격업의 독점업무가 아니기 때문이다.
> 단, 완전히 무제약은 아니다 — 이 문서는 v2에서 **여전히 지켜야 할 선**을 정리한다.

---

## 1. 전제 — 무엇이 달라졌고, 무엇이 안 달라졌는가

| 항목 | v1(행정서사 미디어) | v2(보조금 정보 사이트) |
|---|---|---|
| 핵심 리스크 | 무자격 업무(개별 상담・서류작성 대행) | **낮음** — 정보 제공 자체가 최종 서비스 |
| 자격업 독점 이슈 | 행정서사법 제19조 | **해당 없음** — 보조금 신청서류 작성을 「대행」하지 않는 한 문제되지 않음 |
| 여전히 지켜야 할 선 | — | **개별 신청 대행・서류작성 대행을 시사하는 표현은 여전히 금지**(아래 §2) |
| 새로 생긴 리스크 | — | **금전 정보(YMYL)의 정확성 책임**, 지자체 제도 변경 추종 실패 |

## 2. 판정표 — 무엇이 되고 무엇이 안 되는가

### ✅ 명확히 가능

| 행위 | 조건 |
|---|---|
| 보조금・조성금 제도의 일반적 해설・비교 기사 작성・공개 | 제한 없음 |
| 지역별 비교표・순위・시뮬레이션 콘텐츠 | 출처・기준일 명시 |
| 공개된 신청서식의 기입례를 일반 정보로 게재 | 「이렇게 쓰면 됩니다」가 아니라 「일반적으로 이런 항목이 있습니다」 |
| 자가진단 툴(받을 수 있는 보조금 찾기) | 「참고 정보이며 확정 심사 결과가 아님」 명시 권장(필수는 아니나 신뢰 제고) |
| 광고・제휴 수익(AdSense, 서적・서비스 어필리에이트) | 스테마 규제 준수 — 「PR」 표기 |
| 행정서사・중소기업진단사 등 전문가 사무소의 광고 지면 판매 | v1과 동일 원칙 유지: **월액 고정 게재료만.** 소개 건수・성사 보수・클릭 과금은 취급 금지 |
| 정보상품 판매(비교 PDF, 체크리스트 등) | 일반 정보에 한정 |

### ⚠️ 여전히 피해야 하는 것

| 행위 | 이유 |
|---|---|
| 「이 사업계획서로 신청하면 채택됩니다」류, 특정 신청자의 사업계획・서류를 대신 작성・첨삭해 주는 행위 | 보조금 신청지원(사업계획서 작성지원 등)은 중소기업진단사・행정서사・컨설턴트의 유상 업무 영역과 겹칠 수 있다. **유상・무상 불문 「대행」은 하지 않는다** |
| 개별 사안에 대한 「제 경우는 받을 수 있나요?」류 질문에 개별 판정으로 답하기 | 일반 정보 안내로만 응답(§3 정형문 참조) |
| 「반드시 받을 수 있습니다」「100% 채택됩니다」 등 결과 보증 표현 | 오인 유발, 신뢰 훼손 |
| 마감・조건이 바뀐 제도를 방치해 오래된 정보로 남기기 | 금전 손해로 직결되는 오정보 — YMYL 리스크 |

### 판단이 애매할 때의 원칙

> **「정보를 정리해서 보여준다」는 항상 안전하다. 「이 사람을 위해 무언가를 작성・대행한다」는 순간 위험해진다.**
> 자가진단 툴・비교표・체크리스트는 전자에 속하므로 자유롭게 설계할 수 있다.

## 3. 사이트 전체에 박아 넣을 정형 문안

### 3.1 푸터 고정 (전 페이지)

```
本サイトは補助金・助成金制度に関する情報提供を目的としています。
掲載情報は執筆時点のものであり、最新の制度内容と異なる場合があります。
申請の可否は各制度の実施主体による審査結果によります。
個別の申請書類の作成代行は行っておりません。
```

### 3.2 기사 말미 `<Disclaimer />` 컴포넌트

```
【ご注意】
本記事は制度に関する一般的な情報提供です。
実際の申請にあたっては、必ず各実施主体（国・都道府県・市区町村）の公式情報をご確認ください。
```

### 3.3 자가진단 툴 결과 화면

```
※ 本診断は公表されている一般的な条件との照合結果であり、
   支給の可否を確定するものではありません。
   詳細は各制度の実施主体にご確認ください。
```

### 3.4 運営者情報 페이지 (`/about`)

```
【運営者について】
本サイトは、全国の補助金・助成金制度の情報を、地域ごとに比較しやすい形で
整理・発信することを目的として運営しています。
個別の申請書類の作成代行・提出代行は行っておりません。
制度の詳細・最新情報は各実施主体の公式サイトをご確認ください。
```

### 3.5 문의 폼

```
※ 個別の申請可否判定・書類作成代行のご依頼にはお応えできません。
   記事内容に関するご指摘・情報提供・掲載依頼のみ承ります。
```

## 4. 발행 전 법적 체크리스트 (품질 게이트에 통합)

- [ ] 신청 대행・서류작성 대행을 시사하는 표현이 없는가
- [ ] 「あなたの場合は」식 개별 판정 표현이 없는가
- [ ] 결과 보증 표현(「必ず」「確実に」「100%」)이 없는가
- [ ] `<Disclaimer />`가 삽입되어 있는가
- [ ] 제휴 링크가 있다면 「PR」 표기가 있는가
- [ ] 모집 마감・조건 변경이 반영됐는가(오래된 정보 방치 여부)

## 5. 그 외 준수 법령 (v1 계승)

| 법령 | 대상 | 대응 |
|---|---|---|
| 個人情報保護法 | 메일・리드 수집 정보 | 프라이버시 폴리시 게재, 이용목적 명시 |
| 特定商取引法 | 유료 상품 판매 시 | 사업자 표기 페이지 필수 |
| 景品表示法 / 스테마 규제 | 제휴・광고 | 「PR」「広告」 표기 |
| 著作権法 | 관공서 자료 인용 | 이용 규약 확인, 인용 요건 준수, 전재 금지 자료 주의 |

### 5.1 공식 서류(통지서・신청서・리플릿) 해설과 이미지 게재 기준 (2026-09-26 신설)

「집에 도착한 통지서/시청 리플릿을 Google Lens로 찍어 검색하는」 유입(Search Console 「Web: multimodal」)을 받기 위한 서류 해설 콘텐츠의 선. **새 URL을 만들지 않고 기존 subsidy 기사의 한 섹션(「届いた書類の見方」「申請書の主な記入項目」)으로 넣는 것을 기본**으로 한다(얇은 신규 페이지 양산 방지).

| 구분 | 기준 |
|---|---|
| 게재 가능한 원본 | 실시주체가 **공개한** 백지 서식・記入例・리플릿만. 실제 개인에게 발송된 통지서, 독자가 보낸 서류 사진은 어떤 경우에도 게재하지 않는다(個人情報保護法). 독자에게 서류 사진 제공을 요청하지도 않는다 |
| 이용 규약 확인 | 게재 전 해당 사이트의 이용규약을 확인해 `data/sources/<slug>/README.md`에 기록. **政府標準利用規約・CC BY 계열이면** 출처 표기로 이미지 게재 가능. **転載禁止 표시가 있거나 규약이 없으면** 이미지는 넣지 않고 텍스트 해설 + 공식 PDF 링크만(인용 요건을 충족하는 최소 범위의 일부 발췌는 가능) |
| 인용 요건(著作権法32条) | 본문이 주, 이미지가 종(해설에 필요한 범위만) / 캡션으로 인용 부분을 명확히 구분 / `出典：〇〇市「(서식명)」` 표기 / 트리밍・가필로 내용을 바꾸지 않는다(同一性保持) |
| 오인 방지 | 공식 서식 이미지를 **OG・Discover 썸네일로 쓰지 않는다**(정부 사이트로 오인 유발). 서식명・서식 번호・안내 문구는 이미지와 별도로 **HTML 텍스트로도 기재**(검색・AI가 읽을 수 있게) |
| 해설 표현 | §2 원칙 그대로 — 「この欄にはこう書けば通る」가 아니라 「この書類には一般的にこういう項目があります」. 개별 기입 첨삭은 하지 않는다 |
| 최신성 | 서식은 연도마다 바뀌므로 `verifiedAt`과 서식의 연도판(令和〇年度版)을 함께 명기. 낡은 서식 이미지는 교체하거나 삭제 |
