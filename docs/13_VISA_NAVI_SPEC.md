# 13. 在留資格 判定ナビ — 설계서 (경우의 수 전수 도출)

> 작성일: 2026-08-19 / 상태: **설계 (구현 전)**
> 마스터플랜 §IA `/tools/visa-navi/` (在留資格 判定ナビ). 선행 툴: `/tools/eiju-shindan` (`src/components/tools/EijuShindan.tsx`).
> 이 문서의 목적: **구현 전에 입력 축·질문 흐름·도달 가능한 결과(리프)를 전부 열거**하고, 법적 제약 아래에서 무엇을 보여주고 무엇을 보여주지 않을지를 확정한다.

## 0. 법적 제약 → 제품 원칙 (docs/06 준수)

| 원칙 | 내용 |
|---|---|
| **「判定」하지 않는다** | 출력은 「該当し得る在留資格の候補」＋「主な要件」＋「根拠・関連記事」. 「あなたは〇〇ビザが取れます／取れません」 류 단정 표현 금지. 툴 명칭은 「ナビ」로 유지하되 결과 화면 제목은 「候補となる在留資格」 |
| 정형 문안 | 결과 화면 하단에 docs/06 §3.3 문안 고정: 「※ 本診断は公表されている一般的な要件との照合結果であり、許可の可否を判定するものではありません。実際の審査は個別事情を総合的に考慮して行われます。」 + `<Disclaimer />` |
| 비저장·비송신 | 永住診断과 동일하게 **브라우저 내 판정, 입력 미송신·미보존**. 개인 식별 정보(이름·생년월일·국적 자유입력 등)는 받지 않는다 — 국적은 「協定国か」 같은 **분류 선택지**로만 |
| 상담 유도 금지 | CTA는 「関連記事を読む」「一次情報を確認する」. 「無料相談」「お問い合わせ」 금지 (자격 취득 후 `src/components/cta/` 교체 지점만 남김) |
| 한 사람 = 한 자격 | 후보가 복수면 **全部 표시** (우선순위 표기). 최종 선택을 툴이 하지 않음 |

## 1. 판정 원리 (법 구조 → 질문 구조)

입관법 별표: **별표제2(身分系)** 가 있으면 그것이 우선(就労制限 없음), 없으면 **별표제1(活動系)** 에서 「일본에서 하는 활동」으로 정해진다. 따라서 질문은 **身分 → 活動 → 細分 → 背景属性** 순서.

```
Q0 立場 (本人/家族 or 受入れ企業)          … 문구 분기만, 판정 무관
Q1 身分関係 (別表第二 該当性)              … 6択 → 該当なら即 結果(S系)
Q2 日本で主にすること (活動の種類)          … 7택
Q3 活動の細分 (Q2별 2〜6択)
Q4 背景属性 (Q3별 필요한 것만: 学歴/経験/試験/日本語/資本金/ポイント/国籍分類/年齢)
Q5 現在地・現在の在留資格 (海外=認定 / 国内=変更·更新) … 「ルート」 출력용
Q6 希望条件 (家族帯同/長期在留/永住志向)   … 결과에 注記 추가 (後続 툴 링크)
```

최대 질문 수 6, 평균 4. 모든 리프는 §3 결정표의 ID로 수렴한다.

## 2. 입력 축 (선택지 정의)

### Q1 身分関係
| 값 | 라벨 |
|---|---|
| `jp-spouse` | 日本人と結婚している |
| `jp-child` | 日本人の実子・特別養子である（日系2世を含む） |
| `pr-spouse` | 永住者・特別永住者と結婚している |
| `pr-child` | 永住者の子として日本で生まれた／永住者の子である |
| `teiju` | 日系3世・4世、日本人等の配偶者の連れ子、定住者の配偶者、中国残留邦人等、難民・離婚死別など |
| `none` | 上記に当てはまらない（活動で決まる） |

### Q2 活動の種類
`work`（雇われて働く）/ `business`（会社を経営する・起業する）/ `study`（学ぶ・研修を受ける）/ `family`（家族に扶養される）/ `short`（90日以内の短期）/ `other`（外交・宗教・報道・芸術・医療滞在・ノマド等）/ `unknown`（まだ決まっていない）

### Q3 細分（Q2=work）
| 값 | 라벨 |
|---|---|
| `office` | エンジニア・事務・通訳・デザイン・マーケなどの専門職 |
| `transfer` | 海外の同じ会社（グループ）から日本拠点へ転勤 |
| `research-edu` | 大学・研究機関での研究／学校での教育 |
| `licensed` | 医師・看護師・弁護士・会計士・介護福祉士など日本の資格が必要な仕事 |
| `skilled` | 外国料理の調理師・パイロット・スポーツ指導者など熟練技能 |
| `field` | 介護・建設・外食・製造・農業など現場の仕事（人手不足19分野） |
| `entertain` | 俳優・歌手・ダンサー・プロスポーツ選手 |
| `graduate` | 日本の大学等を卒業（予定）して就職する／就職活動をする |
| `wh-epa` | ワーキングホリデー／EPA看護師・介護福祉士候補者／家事使用人 |
| `parttime` | 留学・家族滞在のままアルバイトをしたい |

### Q4 背景属性（필요한 분기에서만 묻는다）
- `edu`: 大学卒以上 / 日本の専門学校卒（専門士） / それ以外
- `exp`: 関連実務 10年以上 / 3年以上 / 3年未満
- `points`: 高度人材ポイント 80以上 / 70以上 / 70未満・不明
- `jlpt`: N1 / N2 / N4 / それ以下・未受験
- `ssw-test`: 特定技能評価試験(1号)合格 / 2号評価試験合格 / 技能実習2号良好修了 / いずれもなし
- `capital`: 事業用資金 3,000万円以上 / 未満
- `mgmt-bg`: 経営管理経験3年以上 or 関連修士以上 / なし
- `nationality-class`: ワーホリ協定国 / EPA対象国 / イラン / その他
- `age`: 18歳以上 / 未満
- `spouse-status`（Q2=family）: 扶養者の在留資格 분류（就労資格・留学 / 特定技能1号・技能実習 / 特定技能2号・高度専門職 / 特定活動 / 日本人・永住者 / 定住者）

### Q5 現在地
`abroad`（海外にいる→在留資格認定証明書交付申請）/ `japan`（日本にいる→在留資格変更／更新）+ 현재 자격(留学／家族滞在／技能実習／短期滞在／就労資格／その他)

### Q6 希望（任意, 注記用）
家族を呼びたい / 長く住みたい（5年・無期限）/ 将来永住したい
