原文で「不実施」「予算終了」「条件不充足」等の新規発見事項はなく、令和8年度（2026年度）版として
現行有効な制度であることを確認した。交付要綱・Q&A・公式ページ本文の3種が揃い、`articleType: subsidy`の
原文最低1件確保の要件を満たしているため、記事化を進めて問題ない。

執筆時の留意点:
- 本制度は令和3年度開始の継続事業であり、「新設」であるかのような書き方は避ける（記事では「令和8年度版の要件」として扱う）。
- 実費精算型（定額補助ではない）である点、モデルケース表（公式ページ記載3例）を使うと読者の誤解を防げる。
- 前年度受給世帯の差額追加申請制度（Q&A Q3-3）は、令和7年度に既に申請した読者向けの重要な補足情報。
