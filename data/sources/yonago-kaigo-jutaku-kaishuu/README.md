# 障がい者住宅改良費の助成（米子市）

- 原文URL: https://www.city.yonago.lg.jp/11638.htm
- 取得日: 2026-09-24
- アーカイブファイル: `01_main.txt`（1668字）

## 制度概要
- 制度名: 障がい者住宅改良費の助成（米子市障がい者住宅改良費助成事業）
- 所管: 米子市福祉保健部 障がい者支援課 相談給付係
- 制度種別: 現金補助型（工事費用の一部補助）

## 核心数値（原文根拠）

| 項目 | 内容 | 原文箇所 |
|------|------|---------|
| 補助率 | 改良経費の3分の2 | 01_main.txt 235行目 |
| 上限（通常） | 66万6千円 | 01_main.txt 235行目 |
| 上限（他事業と併用時） | 53万3千円（別事業の住宅改修助成を受けた場合） | 01_main.txt 235行目 |

## 対象者（原文根拠: 01_main.txt 227行目）
- 市県民税非課税世帯であること
- 65歳未満であること
- 身体障害者手帳1級または2級、もしくは療育手帳A判定を所持していること
- （身体障害者手帳3級でも一部認められる場合あり）

## 対象工事
- 既存住宅の居室、トイレ、浴室、玄関等の改良
- 新築・増築は対象外

## 重要注記
- 調査起点では「高齢者・障がい者向け」との二次情報があったが、原文では対象は**65歳未満の障がい者のみ**。高齢者（65歳以上）は本事業の対象外。
- 通常上限66.6万円だが、別の住宅改修助成と併用する場合は53.3万円に減額される。
