## 제도 유형

- 국가법 기반 시 실시의 **현금 직접지급형**（1회 5만 + 2회 5만、단태 합계 10만）
- 伴走型相談支援（임신신고 면접·가정방문·임신후기 앙케트）와 일체 실시
- 시 독자 가산（추가 현금）은 원문에서 **확인되지 않음**
