## 確認できた情報
- 金額: 「補助対象工事費の1／2以内の額で、30万円を限度」
- 金額（例外上限）: トイレ改修工事は上限10万円、ユニットバス設置工事は上限10万円
- 対象者（高齢者世帯）: 「65歳以上の高齢者がいる世帯で、かつ令和7年分の所得額が400万円を超える方がいない世帯」
- 対象者（介護認定世帯）: 「介護保険法による要介護又は要支援認定者がいる世帯で、かつ令和7年分の所得額が400万円を超える方がいない世帯」
- 対象者（障がい者世帯）: 「身体障害者手帳の交付を受けており、下肢・体幹又は脳原性運動機能障害の個別等級が1級～3級に認定されている方がいる世帯」
- 補助回数: 「1住宅につき1回限り」
- 対象工事: 「玄関、廊下、階段、居室、浴室、洗面所、台所、トイレ等のバリアフリー工事」
- 申請受付期間: 「令和8年6月1日（月曜）～令和8年6月19日（金曜）」
- 申請受付時間: 「8時30分～17時15分（12時00分～13時00分は除く）」
- 申請先: 「長寿支援課 市役所2階28番窓口」
- 実績報告提出期限: 「令和9年3月5日（金曜）」
- 交付決定通知: 「認定申請書等の受理から約8週間後を予定」
