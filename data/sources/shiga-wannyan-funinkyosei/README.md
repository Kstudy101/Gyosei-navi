## 確認された主な事実

- 実施主体: 一般財団法人滋賀県動物保護管理協会（行政機関の外郭団体、令和3年4月1日以降の手術が対象）
- 「わんにゃん倶楽部」賛助会員（個人）向け助成:
  - 犬不妊: 6,000円 / 犬去勢: 4,000円 / 猫不妊: 4,000円 / 猫去勢: 3,000円
  - 1会員につき犬または猫いずれか1頭
- 譲渡犬猫（滋賀県動物保護管理センター・大津市動物愛護センターから前年度内に譲渡）:
  - 同額の助成、1世帯つき1頭
- 手術施設条件: 公益社団法人滋賀県獣医師会所属の動物診療施設
- 犬の場合: 登録・狂犬病予防注射が条件
