# 原文根拠表: 京都市 住宅の自家消費型太陽光発電設備等設置補助金

## 制度概要
- 制度名: 令和8年度京都市住宅の自家消費型太陽光発電設備等設置補助金
- 実施主体: 京都市（環境政策局地球温暖化対策室）
- 対象: 京都市内の戸建て住宅に太陽光発電設備・蓄電池等を設置する者
