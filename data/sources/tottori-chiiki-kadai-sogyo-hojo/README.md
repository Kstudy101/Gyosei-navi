## 제도 유형 분류

**현금교부형(보조금)** — 新規起業者の事業費の一部を補助率1/2で助成。融資알선 아님.

**とっとり起業化促進事業助成金（toriton.or.jp）との比較:**
- 本制度: 地域資源活用・中山間地域振興分野の**新規起業者**向け、上限200万円、補助率1/2
- 起業化促進事業: 先端技術分野の起業化（既存企業も含む）、上限500万〜2,000万円、全額助成
