## ⚠️ 원문에서 확인되지 않은 것

- 「受付終了」확정 문구는 없음(募集枠100者程度+予算到達次第終了 조항만 존재) — `subsidy.status: "open"`으로 처리, periodEnd(신청기한)만 명시. 조기마감 가능성 있어 향후 재확인 우선순위로 표시.
