## 確認された事実（記事に使える）

- 対象要介護者: 65歳以上のねたきりまたは重度認知症、要介護4または5（重度認知症は要介護3でも可）
- 対象介護者: 金沢市に住所を有し在宅で3か月以上引き続き常時介護している配偶者または3親等以内の親族
- 介護者の就労要件: 無職または1週間で6時間を超えない範囲での内職等、自宅での自営業または農作業
- 支給額: 月額5,000円
- 支給回数: 年3回（4月・8月・12月）
- 基準日: 各支給月1日（4月1日・8月1日・12月1日）
- 対象外: 転出、施設・病院等への入所・入院
- 申請書類: 在宅ねたきり高齢者等介護手当金支給申請書、印鑑（代理人の場合）
- 所管: 金沢市福祉政策課（TEL: 076-220-2288、FAX: 076-260-7192）
