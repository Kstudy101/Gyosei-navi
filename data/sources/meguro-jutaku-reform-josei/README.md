## 採用理由

- カテゴリ `jutaku`（住宅リフォーム・窓・省エネ改修）。既存の `energy/meguro-saiene-shoene-hojo`（太陽光・蓄電池・エネファーム設備設置）とは別制度。
- 国の jGrants 単独制度ではない。目黒区独自の区民向け現金助成。

## 原文で確認した事実

### 助成金額（HTML「助成金額」節 / パンフ表紙）
| 種類 | 算定 | 上限 |
|---|---|---|
| A.一般リフォーム | 税抜工事費の10%（千円未満切捨て） | 10万円 |
| B.省エネリフォーム | 対象工事のみ税抜の20%（千円未満切捨て） | 20万円 |
| C.アスベスト除去 | 税抜の10%（千円未満切捨て） | 20万円 |
| D.空き家・空き室バリアフリー | 税抜の10%（千円未満切捨て） | 10万円 |

工事費用は「見積金額（税抜）」と「実際の工事金額（税抜）」の低い方。

### 省エネ対象工事（HTML + 省エネパンフ）
内窓の設置 / 複層ガラス・断熱窓・断熱ドアへの取替 / 壁・天井・床下の断熱材施工 / ビルトイン型食洗機 / 節水型トイレ。一般との併用不可。

### 期限・受付
- 令和9年3月31日までに工事及び支払完了が必要（HTML・両パンフ）
- 予算の範囲内で先着順（HTML・パンフ）
- 事前申請。審査結果通知後に着工

### 窓口
都市整備部 住宅課 居住支援係 電話 03-5722-9878
