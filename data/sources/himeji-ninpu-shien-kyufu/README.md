## 核心数値（原文対照）

出典は特記なき限り `01_main.txt`。

| 項目 | 原文の記載 |
|---|---|
| 事業開始日 | 令和7年4月1日（火曜日） |
| （妊娠時）対象 | 申請日時点で姫路市に住民票があり、医師が「胎児心拍」の確認をした妊婦 |
| （妊娠時）支給額 | 妊婦1人あたり **5万円**（多胎でも妊婦1人あたり5万円） |
| （産後）対象 | 出産した産婦 |
| （産後）支給額 | **胎児の数×5万円** |
| 支給方法 | 申請者本人名義口座へ現金振込。振込通知は送付しない |
| 振込者名 | 妊娠時「ニンシンキユウフキン」／産後「サンゴキユウフキン」（別々の振込） |
| 申請方法 | 原則 姫路市オンライン手続ポータルから電子申請 |
| （妊娠時）申請のきっかけ | 保健センターで妊娠届提出時にお知らせを渡す |
| （妊娠時）申請期限 | 産科医療機関等で妊娠が確定した日から二年間を経過した日の前日まで |
| （産後）申請のきっかけ | 「こんにちは赤ちゃん訪問」（おおむね産後4か月以内）時にお知らせを渡す |
| （産後）申請期限 | 出産予定日の8週間前の日から二年間を経過した日の前日まで（予定日前の死産・流産はその日起点） |
| 流産・死産等 | 医師が胎児心拍確認後であれば妊娠時・産後とも対象。心拍未確認は対象外。届出前の流産等は診断書が必要で電子申請不可→こども支援課へ |
| 出生後死亡 | （産後）申請可 |
| 外国籍 | 姫路市に住民票があれば対象 |
| 転入 | 転入前市町村で未申請なら姫路市で申請可（こども支援課へ問い合わせ） |
| 転出 | 申請前に転出した場合は転出先市町村で申請 |
| DV避難 | 住民票所在地の市町村が支給。住民票所在地へ申請 |
| 年齢 | 年齢要件なし。未成年でも妊婦本人に支給 |
| 申請者 | 妊婦（産婦）本人。養育者（父等）は申請不可 |
| 所得制限 | 当該ページに明示なし |
