## 制度の類型分類

- **なはし社会地域課題解決型起業支援事業**: **現金給付型（補助金）**。社会課題・地域課題解決型のビジネスプラン事業化に対する補助金。採択者へ専門家相談・広報支援も実施。
- **那覇市小口資金融資**: **融資あっせん型**。那覇市・金融機関・沖縄県信用保証協会の三者協力による小規模企業者向け融資。創業専用制度ではなく、既存小規模事業者も含む。
