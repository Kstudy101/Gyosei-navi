## 根拠表（一般枠・小規模枠、令和8年度）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 年度 | 令和8年度版（要綱 令和8年4月1日施行、同日以後に交付決定を受けた事業に適用） | 03 附則, 02 |
| 一般枠の対象者 | 中小企業者等（別表第1: 中小企業信用保険法上の中小企業者、協同組合等、医業を主とする社会福祉法人、農林漁業者等） | 03 別表第1・別表第3 |
| 小規模枠の対象者 | 小規模事業者（別表第2: 商業・サービス業(宿泊・娯楽除く)は常時使用従業員5人以下、宿泊業・娯楽業と製造業その他は20人以下 等） | 03 別表第2・別表第3 |
| 一般枠の事業 | ①事業承継計画策定委託（県指定様式=別紙1で策定）、②M&A仲介委託（3年間取り組むもの） | 03 別表第3, 05 |
| 小規模枠の事業 | ①M&A企業評価作成委託（M&A前段階の企業評価と企業概要書作成） | 03 別表第3, 05 |
| 補助率・上限（一般枠） | 補助対象経費の2分の1以内、上限100万円 | 03 別表第3, 05 |
| 補助率・上限（小規模枠） | 補助対象経費の3分の2以内、上限30万円 | 同上 |
| 上限の調整 | 小規模枠①の交付を既に受けた小規模事業者が一般枠を受ける場合、100万円から既交付額を控除した額が上限 | 03 別表第3 注2 |
| 端数 | 県補助額は1,000円未満切捨て | 03 注1, 05 |
| 対象経費 | 一般枠①: 初期診断委託料、コンサルティング委託料、事業承継計画作成委託料、企業価値算出委託料等。一般枠②: 仲介委託料、着手金等。小規模枠: 企業調査委託料、企業概要書作成委託料等 | 03 別表第3, 05 |
| 対象外経費 | 専門事業者への顧問料等／官公庁手続・書類作成・個別案件の訴訟・トラブル対応費用／M&A等成立時の成功報酬／他制度から同種補助を受けている経費／消費税及び地方消費税 | 03 別表第3 |
| 対象者の要件（全て） | ①県内で事業を営む中小企業者等で、県内に本社を置く法人または県内に住所を有する個人事業者 ②県内事業所で常時使用する従業員がいる ③M&Aの場合は譲渡側 ④県税・税外未収金の滞納なし | 03 別表第3, 05 |
| 補助要件 | 高知県事業承継・引継ぎ支援センターの相談・支援を受けていること。一般枠①は県指定様式の計画策定、②はM&Aに3年間取り組むこと（最終合意契約または活動中止で知事がやむを得ないと認めた場合は例外） | 03 別表第3 |
| 対象外となる者 | 同一大企業が発行済株式等の1/2以上所有、大企業が2/3以上所有、大企業の役職員が役員総数の1/2以上、風俗営業等、既に補助金交付を受けた者（小規模枠→一般枠は可）、知事が不適当と認める者 | 03 別表第3 |
| 複数事業の代表 | 複数事業で代表を務める者は1社分または1事業分まで | 03 別表第3 注3 |
| 申請期間 | 令和8年4月1日(水)～令和9年2月26日(金)（必着） | 05 |
| 申請時期の条件 | 申請年度の2月末日まで、かつ補助事業着手予定日の20日前まで。着手は交付決定通知に基づく（決定前着手不可） | 03 第5条・第7条 |
