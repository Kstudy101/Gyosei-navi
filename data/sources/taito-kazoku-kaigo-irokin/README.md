## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 家族介護慰労金 |
| 개요 | 본구에 주소를 두고, 개호서비스를 이용하지 않고 중도의 요개호 상태인 사람을 재택에서 개호하는 동거 가족에게 개호위로금 지급 |
| 지급금액 | 年間10万円（연1회, 10만엔） |
| 대상요건(과거1년간 전부 해당) | ①요개호4 또는 5 인정 ②재택생활자(기산일부터 1년간 통산 90일 이상 입원하지 않음) ③개호서비스 미이용 또는 기산일부터 1년간 개호서비스(복지용구대여・특정복지용구구입・주택개수 제외) 이용일수 합계 10일 이내 ④개호하는 자 세대와 개호받는 자 세대 모두 주민세 비과세세대 ⑤신청일 시점 개호하는 자(40세이상인 경우)・개호받는 자 모두 개호보험료 체납 없음 |
| 기산일 정의 | 신청일로부터 1년 전의 날 |
| 신청방법 | 담당(개호보험과 급부담당)에 문의 → 요건 확인 후 대상이면 신청서 발송 |
| 문의처 | 개호보험과 급부담당, 電話 03-5246-1249 / FAX 03-5246-1229 |

## 제도 유형 분류

현금지급형(연1회 정액 위로금, 개호서비스 미이용/저이용 재택개호자 대상)

## ⚠️ 원문에서 확인되지 않은 것

- 신청기간・마감일 명시 없음 — 수시접수로 추정되나 원문에 명시적 "受付中/終了" 문구 없음.
- 예산 상한이나 소진 시 접수중단 여부 언급 없음.
- 과거 지급 실적・신청건수 등 통계 정보 없음.
- 신청서 양식(PDF) 직접 링크는 본 페이지에 없음 — 문의 후 개별 발송 방식.
