## 確認できた事実（01の原文より）

- 制度名: 仙北市結婚新生活支援事業補助金【令和8年度】
- 対象世帯（すべて満たすこと）:
  - 令和8年1月1日〜令和9年3月31日の間に婚姻した夫婦
  - 夫婦の双方が指定の講座の受講等を行っていること
  - 婚姻時の年齢が夫婦ともに39歳以下
  - 申請時の直近所得証明書で確認できる夫婦合算所得が500万円未満（貸与型奨学金返済中は年間返済額を控除）
  - 市税に滞納がない
  - 他の公的制度による家賃補助等を受けていない
  - 過去に本制度（他自治体での受給を含む）の補助を受けたことがない
- 対象講座（いずれか1つを受講・相談）: ライフデザイン支援講座／プレコンセプションケアに関する講座／医療機関への妊娠・出産に関する相談／家事又は育児の分担に関する講座（1・2・4は秋田県作成のeラーニング予定）
- 前年度受給世帯: 前年度交付決定を受けた世帯のうち、前年度受給額が上限額に達しなかった世帯も対象（上限額から前年度受給済額を差し引いた額が上限）
- 対象経費（令和8年4月1日〜令和9年3月31日に支払った費用）: (1)新居の取得費用（新築・中古住宅購入費、建物のみ）(2)新居のリフォーム費用 (3)新居の賃借費用（家賃・敷金・礼金・共益費・仲介手数料）(4)新居への引越費用
- 補助上限額: 夫婦とも婚姻日年齢29歳以下→1世帯60万円／それ以外→1世帯30万円
- 申請期限: 令和9年3月31日まで
- 申請書類: 交付申請書（様式第1号）、講座等に関する申告書兼誓約書（様式第2号）、戸籍謄本または婚姻届受理証明書、夫婦の住民票、夫婦の所得証明書、市税滞納なし証明（納税証明書、省略可の場合あり）、本人確認書類の写し、費用区分ごとの契約書・領収書の写し等
- 窓口: 仙北市企画部まちづくり課（〒014-0398 秋田県仙北市角館町上野18、電話0187-43-3315、machi@city.semboku.akita.jp）
