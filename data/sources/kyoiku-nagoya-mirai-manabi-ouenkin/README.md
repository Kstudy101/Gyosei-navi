## 核心数値（原文根拠：03_shikyu-naiyoujiki.pdf「支給内容及び支給時期」表）

### 認定要件（原文：01_seido-honbun.txt「就学援助の認定要件」）

児童生徒が名古屋市在住で、以下1〜4のいずれかに該当すること：
1. 生活保護法に規定する要保護者
2. 生活保護が停止または廃止された（令和7年4月2日以降）
3. 児童扶養手当が支給された（令和7年11月以降）
4. 所得が基準額以下（各世帯員の令和7年中〈1〜12月〉の総所得から10万円差し引いた額の合算額が下表以下）

### 申請方法・受付状況（原文：01_seido-honbun.txt）

- 電子申請フォーム（外部リンク）での申請。月末23時59分までに不備なく申請受付された当月（申請月初日に対象校在籍がない場合は翌月）から認定。
- **3月は申請受付を行わない。**
- 令和8年9月より電子申請フォーム受付に移行。オンライン申請が難しい場合は在籍校へ相談。
- 特例申請（3種）：(1)海外所得（住民登録なし）、(2)生計維持者の傷病・解雇・倒産による家計急変、(3)天災等の被災。
- **受付状態：募集中（原文に「電子申請フォームでの受付としております」と明記、期限や予算到達による締切の記載なし）**
