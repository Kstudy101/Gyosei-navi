## 確定した事実
- 事業名: 令和8年度福島県住宅用太陽光発電設備等導入支援補助金
- 運営: 一般社団法人福島県再生可能エネルギー推進センター
- 申請期間: 令和8年5月20日～令和9年3月12日17時まで（予算達成次第終了）
- 太陽光: 公称最大出力1kWあたり40,000円、最大160,000円（4kWまで）
- 蓄電池: 蓄電容量1kWhあたり40,000円、最大200,000円（5kWhまで）
- V2H: 上限100,000円（定額）
- 予算規模: 太陽光約2,200件、蓄電池約800件、V2H約20件
- 対象: 福島県内の住居等に設置する10kW未満の太陽光・蓄電池・V2H
- 市町村補助金との併用可
- J-クレジットクラブへの入会要件あり（一部例外を除く）
- 初期投資0円モデル・リースは対象外
