## 核心数値（原文対照）

出典は特記なき限り `01_main.txt`。流産・死産手続は `02`。チラシは `03`。

| 項目 | 原文の記載 |
|---|---|
| 枠組み | 「妊婦等包括相談支援事業」と「妊婦支援給付金」（妊婦のための支援給付）を組み合わせた「新潟市出産・子育て応援事業」 |
| 妊婦給付認定の対象 | 医療機関により**胎児心拍を確認**された方で、**令和7年4月1日以降に妊娠している（いた）方**（妊産婦本人）。令和7年4月1日以降の妊娠期間に日本に住民票がある（あった）ことが必要 |
| 流産・死産等 | 令和7年4月1日以降に医療機関で確認された流産・死産・人工妊娠中絶も対象。令和7年3月31日までのは対象外（`01`/`02`） |
| 支給の前提 | 申請時点で新潟市に住所を有し、新潟市で妊婦給付認定を受けていること |
| 1回目 | **妊婦1人あたり5万円**。原則、妊娠届出時の面談後の申請案内から申請。胎児心拍確認日から**2年以内**。同一妊娠で令和6年度までに出産応援ギフト（5万円）を申請（受給）している方は受給不可 |
| 2回目 | **胎児の数（妊娠した子の数）×5万円**。原則、新生児訪問等の面談時の申請案内から申請。出産予定日の8週間前の日（それ以前に出産・流産等した場合はその日）から**2年以内** |
| 伴走型相談 | （1）妊娠届出時（2）妊娠8か月頃（希望者のみ。妊娠7か月頃にアンケート郵送）（3）出生届出後、新生児訪問やこんにちは訪問時 |
| 全国統一制度 | 「妊婦支援給付金」や国の出産・子育て応援交付金を活用した「出産・子育て応援ギフト」は全国統一。他市区町村で申請済み（受給済み）の場合は本市支給なし。二重受給判明時は全額返還 |
| 転入 | 他市区町村で1・2回目または2回目未受給で本市支給希望の場合、転入後に各区健康福祉課で「妊婦給付認定申請書」提出が必要 |
| 問い合わせ | 新潟市こども未来部こども家庭課 / 〒951-8550 新潟市中央区学校町通1番町602番地1（市役所本館1階） / 電話025-226-1205（平日8:30〜17:30） |
