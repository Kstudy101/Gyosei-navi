## 別制度メモ（本稿の主対象外）

令和8年度から「区立学校の教育に関する費用負担補助」が新設され、区立小中の全児童・生徒について教材費・校外活動費・移動教室費・修学旅行費を原則区が補助（保護者徴収なし）。所得制限なし。就学援助とは別制度（02）。
