## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **大津市 令和8年度 예산 소진 여부・마감일**: 「受付中」이라고만 명시되어 있고 구체적 접수 마감일이나 예산 잔액은 원문에 없음. 기사에서는 "受付中(2026年9月22日 시점)"으로만 표기하고 상시 최신 정보 확인을 유도해야 함.
- **国従来基幹メニュー(보조율23%/상한97.86만엔) 적용 시정촌이 실제로 있는지**: 大津市는 国総合支援メニュー(80%/115만엔) 방식을 채택하고 있음을 확인했으나, 다른 18개 시정촌이 어느 메뉴를 적용하는지는 개별 조사하지 않음.
- **다설구역(多雪区域) 할증 구체 금액**: 현 페이지에 "할증 있음"만 명시, 구체 금액은 시정촌별 요강 확인 필요 — 大津市 요강에는 다설구역 관련 조항이 없어 大津市는 다설구역 비대상으로 추정되나 명시적 확인은 못 함.
- **大津市 이외 시정촌(彦根市・長浜市・草津市 등)의 구체적 보조율/상한액**: 이번 조사는 大津市만 원문 확보. 타 시정촌은 미조사(unresearched) — 기사에서 타 시정촌 수치를 단정하지 말고 "시정촌마다 다르므로 거주지 창구 확인 필요"로 안내.
- **利子補給制度(リ・バース60)의 구체 이자율/조건**: 大津市 요강에서 언급만 되고(利子補給制度を利用する場合は補助対象経費の5分の2/57.5万円上限 등) 제도 자체의 상세(독립행정법인 주택금융지원기구 관련)는 이번 조사 범위 밖.
- **耐震シェルター等設置補助制度・既存民間建築物耐震診断補助制度의 구체 금액**: 大津市에서 別建て로 존재함은 확인했으나(02), 요강 PDF는 미취득 — 필요 시 별도 조사.
- **東近江市 보강사례(PDF)의 세부 내용**: 01 페이지에 링크된 PDF(補強事例1 東近江市)는 미다운로드.
