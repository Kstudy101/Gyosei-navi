## 制度タイプ分類

- **現金給付型**（指定口座振込）。2回分割（1回目=妊婦1人定額5万円、2回目=胎児数×5万円）。
- 妊婦等包括相談支援（妊娠届出時面談・妊娠8か月頃アンケート）と一体。
