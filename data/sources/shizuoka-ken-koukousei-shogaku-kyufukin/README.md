共通: 返還不要／授業料以外の教育費が対象／保護者が申請、指定口座へ振込／就学支援金等と併用可（01）。令和8年度から対象世帯が拡充（01）。

## 対象者（令和8年度、基準日7月1日）
- 保護者等が静岡県内に住所、生徒が就学支援金等の受給資格あり（01, 02）。
- 対象外（01）: 措置費（見学旅行費・特別育成費）対象者、特別支援学校高等部、別科・聴講生・科目履修生。
- 世帯区分（公立, 01）: ア生活保護(生業扶助) / イ住民税非課税 / ウ所得割額合計100円以上105,500円未満（年収270～380万円） / エ 105,500円以上182,500円未満（年収380～490万円） / オ 専攻科のみ 105,500円以上264,500円未満かつ多子世帯。国籍・在留資格が要件2の場合は区分が限定される（01の表）。
- 私立（02）: 専攻科を除く全日制等・通信制＝生業扶助 or 所得割合計0円～182,500円未満（国籍・在留資格要件あり）。専攻科＝所得割合計が「105,000円未満」（原文ママ。同ページ給付額表は105,500円未満、原文内の不一致）または扶養する子3人以上かつ264,500円未満。
- 「同居する祖父母等は保護者等に含まない」（02）。

## 申請方法・期限（令和8年度）
| 区分 | 内容 |
|---|---|
| 国公立 | 提出期限 **8月21日（金）**（01）。間に合わない場合、県内校は在籍校、県外校は高校教育課へ問合せ。**2026-09-25時点で既に過ぎている**。書類は在学校配布。県外校は様式PDF（01内リンク）をDL可、提出先は高校教育課学校支援班 |
| 私立 | 県外校直接郵送分の期限 **令和8年9月30日（水）**（県庁必着、郵送は消印有効）。期限後は理由を問わず不受理。県内校は学校の指示に従う（02） |
| 支給時期 | 国公立: 認定決定日から2か月以内（10月末頃予定）（01）／私立: 概ね年末までに審査完了予定、数か月かかる場合あり（02） |
| 必要書類（国公立・県外校） | 受給申請書（公立用）、保護者全員分の令和8年度課税/非課税証明書等、住民票、在学証明書、国籍・在留資格確認書類、(該当時)生業扶助受給証明書・扶養誓約書・扶養親族申告書（01）。私立の様式はPDF一覧を02参照（様式第1号その1～3、第2・5・7・8号等） |
| 家計急変 | 両ページに「家計急変」の実施の言及あり。要件・期限・金額は未取得 |
