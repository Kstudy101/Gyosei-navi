# 鹿児島県 国公立高等学校等奨学のための給付金（令和8年度） — 原文アーカイブ

## 対象自治体・制度

- 実施主体: 鹿児島県教育委員会 教育庁高校教育課
- 制度名: 令和8年度鹿児島県国公立高等学校等奨学のための給付金
- カテゴリ: kyoiku（教育）
- 根拠法: 高等学校等就学支援金の支給に関する法律（国制度）
- 制度種別: 現金給付（返還不要の給付金）型。授業料以外の教育費（教科書費・学用品費等）を支援。
