## 제도 유형

**융자알선형（利子補給＋信用保証料補助）**. 구가 취급 금융기관에 융자를 あっせん하고, 실행 후 신용보증료와 이자를 보조한다. 현금 직접보조형 아님.

핵심 메뉴는 特別融資の **⑥起業家支援融資** と **⑦創業支援融資**.

## 차별화

他区の創業融資あっせん（例: 新宿区本人負担0.2%以下、荒川区0.5%）に対し、葛飾区⑦創業支援は **本人負担なし**（区1.3%＋金融機関が差額負担）が公式パンフで明示されている点が強い. 創業塾（特定創業支援等事業）修了証明が⑦の必須条件.
