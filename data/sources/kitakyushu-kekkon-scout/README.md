## 確定した事実
- 県のふく♥こい一覧は「交付金活用の有無に関わらず結婚新生活支援事業を行っている市町村を掲載」と明記 → 一覧非掲載は、同事業（現金補助型）を市が実施していない強い根拠
- 北九州市にある結婚関連の公的取組は出会いサポート（JUNOALL）であり、`kekkon` カテゴリ（新婚世帯の住居費・引っ越し費用補助）の対象外
- 既存 `content/subsidy/kekkon/` に北九州記事はなし（重複調査対象なし）
