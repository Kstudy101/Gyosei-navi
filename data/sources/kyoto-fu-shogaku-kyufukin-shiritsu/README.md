## 確認できた事実（原文どおり）
- 対象: 基準日 令和8年7月1日現在、親権者全員の道府県民税所得割+市町村民税所得割の合算額182,500円未満、または生活保護「生業扶助」受給世帯。親権者全員が京都府内在住（一方が他県在住でも生活の本拠が府内で他県に同様の申請をしない場合可、海外在住は対象外）。就学支援金等の受給資格あり。通算3回まで（定時制・通信制は4回）。専攻科で合算額105,500円以上は264,500円未満の多子(扶養3人以上)世帯のみ。
- 支給額（通常申請/早期2回目）: 生業扶助 52,600円/39,450円。非課税 全日制・定時制 152,000円/114,000円、通信制・専攻科 52,100円/39,075円。課税・105,500円未満 全日・定時 50,670円、通信・専攻科 17,370円（通常のみ）。105,500円以上182,500円未満 全日・定時 38,000円、通信 13,030円。専攻科・多子(105,500以上264,500未満) 13,030円。
- 申請先: 府内認可私立校 → 在学校へ提出（期限は学校の指示）。府外私立校 → 〒602-8570 京都市上京区下立売通新町西入薮ノ内町 京都府文化生活部文教課 奨学のための給付金担当へ郵送/持参、期限 令和8年10月30日(金)（学校取りまとめの場合は学校指示）。保護者が府外在住 → 居住都道府県。市区町村役所には申請書なし。
- 新入生一部早期給付1回目: 令和8年度は受付終了。1回目申請者は残額のため2回目申請が必要。
- 家計急変: 別ページ。府外校向け期限は 7/1までの急変: 令和8年10月30日、それ以降: 令和9年2月19日（原文は「7月2日までに発生」と記載、7月2日以降の誤記の可能性。要問合せ）。
- 問い合わせ: 京都府文化生活部文教課 075-414-4516 / FAX 075-414-4523 / bunkyo@pref.kyoto.lg.jp
- 国公立分: 京都府教育庁指導部高校教育課修学支援係 075-414-5043、https://www.kyoto-be.ne.jp/koukyou/cms/?p=445
