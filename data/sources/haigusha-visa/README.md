## 원문 대조로 정정한 사항 (2026-08-20)

초안 단계에서 WebFetch 요약본에 의존해 부정확했던 부분을 원문 취득 후 정정했다. 기사 #29·#37에 반영 완료.

| 항목 | 초안(부정확) | 원문 |
|---|---|---|
| **과세·납세증명서 명의자** | 「配偶者の」 | **「申請人の滞在費用を支弁する方の」** — 배우자에 한정되지 않음. 가장 중요한 정정 |
| 戸籍謄本 | 「婚姻の記載があるもの」 | 「戸籍謄本（**全部事項証明書**）」1通。婚姻事実の記載がない場合は**婚姻届出受理証明書**도 추가 |
| 과세증명서 대체 | 「預貯金残高が分かる資料（補助書類）」 | (1)로 증명 불가 시 **預貯金通帳の写し／雇用予定証明書／採用内定通知書** |
| 住民票 | (기재 없음) | 「世帯全員の記載のあるもの」1通・**マイナンバーは省略**하고 다른 사항은 생략하지 않을 것 |
| スナップ写真 | 「写真2〜3葉」 | 2〜3葉・2인이 함께 찍혀 용모가 명확할 것・**アプリ加工したものは不可** |
| 返信用封筒 | (기재 없음) | 정형봉투에 수신처 명기 + **簡易書留用**의 우표 첨부 |
| 신원보증인 | 「配偶者が保証人」 | 「**日本に居住する**配偶者(日本人)になっていただきます」 |
| 증명서 유효기간 | (기재 없음) | 일본 발행 증명서는 전부 **발행일로부터 3개월 이내** |
