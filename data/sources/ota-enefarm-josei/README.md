## 制度類型の位置づけ（energy）

- 港区・品川区・渋谷区のエネファーム助成と同系統（家庭用燃料電池）。
- 大田区は**申請書提出型ではなく LINE クーポンによる購入時値引き**という手続上の差がある。
- 大田区の環境関連助成一覧（03）に太陽光・蓄電池の区単独メニューは見当たらない。太陽光・蓄電池は住宅リフォーム助成（建築調整課・jutaku 系）で触れる旨が家庭向け案内（02）にあり、本記事（energy）とは別制度。
