## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 私立高校在籍の場合は別ページ（文書学事課ホームページ）案内のみで、私立의 급부금액은 원문에서 확인 불가.
- 소득 기준 판정 시점은 令和7年7月1日로 기재; 가계급변의 경우 기준이 다름. 
- 외국 국적 학생에 대한 대응은 별도 차트 제공 언급만 있고 세부 요건 원문에 미확인.
