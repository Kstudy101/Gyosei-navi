## 核心数値（原文対照）

出典は特記なき限り PDF `02` / 抽出テキスト `02txt` の「１-７-４ 家族介護慰労金支給事業」。

| 項目 | 原文の記載 |
|---|---|
| 正式名称（PDF） | 家族介護慰労金支給事業 |
| 案内ページ表記 | 家族介護慰労事業 |
| 目的 | 要介護４又は５と認定された高齢者を介護保険サービスを利用することなく自宅で介護された家族に慰労金を支給し、家族の経済的負担の軽減と高齢者の在宅生活の継続向上を支援 |
| 対象 | 市民税非課税世帯に属する要介護４又は５と認定された高齢者で過去１年間、介護保険のサービスを使わなかった人を介護した同居の家族（介護保険のサービスのうち、１週間以内のショートステイは除きます） |
| 対象外 | ３か月を超える入院があったときや、介護保険料が未納である場合 |
| 支給額 | 年間１００,０００円 |
| 問い合わせ | 高齢福祉課、各総合支所市民福祉課（福祉課）、各在宅介護支援センター及び各地域包括支援センター |

案内HTML（01）は「介護保険を利用せずに在宅の高齢者の介護を行っている家族に慰労金を支給する事業」との概要のみ。金額・要介護度・非課税・例外条件の詳細はPDFを正とする。
