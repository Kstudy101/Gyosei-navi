## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 建築物不燃化推進事業補助（エリア限定の解体・新築の補助金） |
| 소관 | 横浜市都市整備局 防災まちづくり推進課（045-671-3595） |
| 최종갱신 | 공식 페이지 최종갱신일 2026年8月19日。令和8年度 신청접수 개시 안내 게재 |
| 대상 지역 | 重点対策地域（不燃化推進地域）およびそれ以外の補助対象地区（町丁目一覧・i-マッピーで確認）。全市一律 아님 |
| 보조 메뉴 | ①老朽建物の除却（解体）②耐火性の高い建物（準耐火建築物以上等）の新築 |
| 보조율・상한 | 重点対策地域: 3/4、その他補助対象地区: 2/3。いずれも上限 **150万円** |
| 除却 산정 | ①最低見積額（本体除却・税込）×補助率、②延べ面積×2万円/㎡×補助率、③上限150万円 중 최저액 |
| 新築 산정 | ①延べ面積×2万円/㎡×補助率、②上限150万円 중 최저액 |
| 주요 요건（除却） | 昭和56年5月31日以前 건축 등（耐用年数経過含む）。R8改正で昭和56年6月1日〜平成12年5月31日 목조 제외도 일부 대상。市内事業者発注、個人・自治会町内会・中小企業者等、市税滞納なし、過去10年市内補助金未受給、契約は市の工事計画承認後 |
| 주요 요건（新築） | 準耐火建築物等＋感震ブレーカー設置（適用除外あり）。重点対策地域以外は市内事業者発注必須。建売（宅建業者の売買目的）は対象外 |
| 절차 | 事前相談→工事計画承認申請（契約約30日前）→承認後契約→工事→完了報告・交付申請→請求。予算内実施のため受付締切の可能性あり。承認日から1年以内に工事完了しない場合は進捗報告で完了予定日変更が必要 |

## ⚠️ 원문에서 확인되지 않은 것

- 연간 접수 마감의 **고정 일자**는 원문에 없음（「予算内で実施するため、申請受付を締め切る場合がある」만 명시）— `periodEnd`는 두지 않음
- 개별 필지가 보조대상지구에 들어가는지 여부는 필지마다 i-マッピー/창구 확인이 필요 — 기사에서 전필지 대상처럼 쓰지 않음
- 공동주택建替推進・木造建築物不燃化・耐震改修 등 관련 요강은 별제도로 링크만 확인 — 본 기사 범위 밖
