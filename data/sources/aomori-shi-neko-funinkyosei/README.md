## 制度の種別分類

現金給付型（後払い・実績報告方式の補助金）。事前申請・交付決定を受けた上で、申請者が動物病院に費用を全額立替払いし、実績報告書提出後に補助金が交付される方式。融資あっせん型・現物支給型ではない。
