## 核心数値（01原文より）

このページには結婚新生活支援に関する2つの補助金が掲載されている。

### ① なると結婚新生活スタート支援補助金

- 対象経費: 住宅費用（敷金・礼金・仲介手数料・共益費など）、引っ越し費用、リフォーム費用、家賃（上限60万円の対象者に限る）
- **対象者（婚姻要件）**: 令和8年1月1日〜令和9年3月31日に婚姻（またはパートナーシップ・ファミリーシップ宣誓書受領証の交付）した夫婦で、婚姻日における年齢がともに39歳以下の世帯
  - パートナーシップ・ファミリーシップ制度の対象世帯も含む点に注意
- 追加要件: 申請日から起算して2年以上市内居住の意思、生活保護等の公的給付との重複なし、市税滞納なし、暴力団関係者でないこと、過去受給歴なし、夫婦双方が令和8年度中にライフデザイン支援講座等の受講または医療機関への妊娠・出産relevantな受診・相談のいずれかを満たすこと
- **補助金額（所得・年齢要件で3段階）**:
  - 夫婦ともに29歳以下 かつ 世帯所得合計500万円未満 → **上限60万円**
  - それ以外の年齢 かつ 世帯所得合計500万円未満 → **上限30万円**
  - 世帯所得合計500万円以上 → **上限15万円**
  - 対象経費合計が上限額を下回る場合は実費支給（1,000円未満切り捨て）
  - 貸与型奨学金（本人名義）を返済中の場合、年間返済額を所得から控除可
- 対象期間: 令和8年4月1日〜令和9年3月31日に支払い完了した費用
- 交付申請受付期間: 令和8年4月1日（水）〜令和9年3月31日（水）
- 問い合わせ: 鳴門市子育て支援課 088-684-1563

### ② なると新婚世帯家賃補助金

- 対象: 鳴門市内の民間賃貸住宅に居住する対象世帯の家賃を一部補助
- 対象者（婚姻要件）: 令和7年4月1日以降に婚姻（またはパートナーシップ・ファミリーシップ宣誓書受領証の交付）した夫婦で、婚姻日における年齢がともに39歳以下の世帯
- 追加要件: 家賃3万円以上を負担、家賃滞納なし、市内2年以上居住意思、公的給付重複なし、市税滞納なし、暴力団関係者でないこと、過去受給歴なし（年度間継続申請を除く）、上記①同様の講座受講・相談要件
- 注意: ①の補助金で「上限60万円」対象となる世帯は、本補助金との併用不可
- **補助金額**: 最大24カ月分、月額上限は所得別
  - 夫婦所得合計500万円未満 → 月額上限1万円
  - 夫婦所得合計500万円以上 → 月額上限5千円
- 認定申請受付期間: 令和8年4月1日（水）〜令和9年3月15日（月）
- 交付申請受付期間: 令和8年4月1日（水）〜令和9年3月31日（水）
- 問い合わせ: 鳴門市子育て支援課 088-684-1563
