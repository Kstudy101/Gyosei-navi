## 제도 유형 분류

**현물지급型（金券・回数券方式）** — 현금 직접지급이 아니라 「タクシー乗車券」라는 금권을 연간 최대18,000円分 교부하고, 이용자는 지정 택시사업자 승차 시 금권으로 요금 일부를 결제하는 방식. 별도로 手帳呈示에 의한 운임 10%할인 제도가 병존（이것은 전국 공통적인 장애인수첩 할인이며 본 제도와는 별개）.
