# hiroshima-shi-neko-funinkyosei — 広島市 地域猫活動支援事業（不妊去勢手術）

## 制度概要

- 制度名: 広島市地域猫活動支援事業（実施要領上の名称）
- 所管: 広島市健康福祉局 動物愛護センター
- 類型: **現物支援**（現金の定額助成ではなく、地域猫の不妊去勢手術の実施・捕獲器貸出等）
- 対象: 広島市内で地域猫活動を行う町内会等の活動団体（飼い猫向け個人助成ではない）

## 原文から確認できた事実

- 支援内容（要領第4条）: 助言・啓発資料、現地調査・説明会、**地域猫の手術の実施・捕獲器貸出**、ボランティア紹介 等
- 申請書類（要領第5条・申請ページ）: 支援申請書・実施計画書・地図・不妊去勢手術支援承認申請書・対象猫一覧表
- 承認期間（要領第6条・案内）: 承認日から**当該年度の3月31日まで**（令和7年度からの変更。変更前は3年間）
- 手術実施場所（要領第8条）: 原則は市長指定の動物病院。年度途中追加猫は動物愛護センター。令和4年6月14日以前申請団体は従来どおりセンター
- 活動報告: 翌年度5月末まで（要領第9条・申請ページ）
- 窓口: 〒730-0043 広島市中区富士見町11-27 / 電話 082-243-6058 / FAX 082-243-6276
