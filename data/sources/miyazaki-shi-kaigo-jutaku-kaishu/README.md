## 確認できた核心情報

### 対象者
以下の全要件を満たす方:
- 宮崎市内に住所がある
- 介護保険法で要支援または要介護状態と認定された方
- 要介護者等と生計を一にする親族・同居人の前年分所得税額合計が **7万円以下**
- 介護保険給付対象工事の場合: 介護保険の支給限度基準額（20万円）を使い切った方

### 補助額・補助率
- **対象限度額**: 工事種目ごとに上限あり、最大 **20万円**（1住宅あたり上限20万円だが上限に達するまで何度でも申請可）
- 補助率は世帯の課税状況に応じて変動:

| 区分 | 補助率 |
|------|--------|
| A 生活保護世帯 | **10割** |
| B 市民税・所得税非課税 | **9割** |
| C 市民税課税・所得税非課税 | **8割** |
| D 所得税1円〜5,000円以下 | **7割** |
| E 所得税5,001円〜15,000円以下 | **6割** |
| F 所得税15,001円〜40,000円以下 | **5割** |
| G 所得税40,001円〜70,000円以下 | **4割** |

### 対象住宅設備（要介護度による制限あり）
**要支援1,2・要介護1〜5 共通**: 手すりの取付け、段差の解消、床材変更、引き戸等への扉の取替え、洋式便器への取替え（各20万円上限）
**要支援2・要介護1〜5のみ**: スペース確保、浴室改修（20万円）、浴槽取替え（20万円）、給湯設備（10万円）、配管（5万円）、シャワー水栓（5万円）、給水栓取替え（5万円）

### 申請方法
- 工事**着工前**に事前申請必須（ケアマネジャー等を通じて市に申請）
- 工事完成後30日以内に事後申請
- 介護保険の住宅改修と**併用可能**
