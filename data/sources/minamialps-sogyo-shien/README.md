# minamialps-sogyo-shien — 南アルプス市創業支援補助金（sogyo）

## 判定
**採用** — 創業者本人が直接申請・受給できる現金直接型の補助金。原文は令和8年度の募集要項ページで、申請期間・補助率・対象経費が具体的に確認できた。

比較対象として提示された「山梨県地域課題解決型起業支援事業費補助金」は、原文取得の結果、**起業者への直接補助ではなく、起業支援金の交付・伴走支援業務を担う「執行団体」を県が公募する制度**であり、しかも当該募集は「※募集は終了しました」と明記されていた（`data/sources/yamanashi-ken-startup-hojokin/01_yamanashi-ken-startup-hojokin.txt`）。創業者が直接申請できる制度ではなく、記事化する場合も「起業者向け二次募集」を執行団体が別途行う必要があり、現時点では申請可能な一次情報が確認できないため、sogyoカテゴリの採用候補からは除外した。

## 確定した事実
- 制度名：南アルプス市創業支援補助金
- 補助率：補助対象経費（税抜）の3分の2、上限50万円
- 対象者：市内で新たに創業した個人事業主・会社代表者（創業後5年未満）、第二創業者、事業拡大・新分野進出を行う既存事業者
- 要件：市税完納、市内に事業所等を設置、「特定創業支援等事業に関する証明」（申請期限＝令和8年7月24日まで、証明日時点で創業後5年未満）または「経営革新計画」の承認（始期令和8年7月24日以前・終期令和9年2月28日以降）
- 対象経費：機械装置等購入費、広報費、ウェブサイト関連費、展示会出展費、旅費、開発費、資料購入費、雑役務費、賃借料、専門家謝金・旅費、設備処分費、委託費、外注費
- 申請期間：令和8年5月1日（金）～令和8年7月24日（金）
- 流れ：交付申請→書類審査→面接審査（5分程度のプレゼン）→交付決定→事業実施（令和9年2月末日までに完了）→実績報告→補助金交付
- 令和8年度は「南アルプス市の資源や魅力（フルーツや観光資源など）を生かした事業」を優先採択
- 申請窓口：南アルプス市役所商工振興課
