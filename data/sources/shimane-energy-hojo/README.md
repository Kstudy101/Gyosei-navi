# 原文根拠表: shimane-energy-hojo

**所管**: 島根県環境生活部環境政策課 エコライフ推進係
**取得日**: 2026-09-25

## 重要な注意(依頼文との差異)
- 依頼URL(.../infra/energy/energy/saisei/hojo/hojo.html)は本制度のページではない。「島根県再生可能エネルギー設備等導入支援事業(市町村への間接補助)」と「しまね脱炭素加速化事業再エネ設備導入補助金(中小企業者向け)」の一覧ページ。本制度の正規ページは `.../infra/kankyo/kankyo/datsutanso/zeh_hojyo_r8.html`。
- 「窓改修と同時施工の蓄電システム・EV充電設備・熱交換型換気設備」は本制度の内容ではない。国の「既存住宅の断熱リフォーム支援事業(トータル断熱・居間だけ断熱)」(実施:公益財団法人北海道環境財団)の説明であり、県ページ 03_katei_syouen.txt に紹介があるのみ。本制度は新築ZEH/ZEH+が対象。
- 蓄電池の「4,800Ah・セル相当のkWh未満」は原文のまま(公募要領・交付要綱・県ページ共通)。
