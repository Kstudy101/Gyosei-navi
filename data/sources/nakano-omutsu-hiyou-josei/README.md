# 中野区 おむつサービス（おむつ費用の助成）

## 制度概要（現金助成型）
医療機関に入院中の方を対象に、入院期間中のおむつ費用を月単位で助成する制度（紙おむつの現物支給とは別枠）。

## 対象者（01_omutsu-hiyou-josei.txt L37-48）
中野区内に住所がある方で、以下(1)(2)いずれかに該当。介護保険施設・障害者支援施設等入所中の方、生活保護・中国残留邦人等支援給付受給者は除外。

- (1) 65歳以上／要介護認定は不要／世帯全員の前年（1～6月申請は前々年）合計所得金額が350万円未満／医療機関に入院中で常時おむつ必要
- (2) 3歳以上／身体障害者手帳1～2級・精神障害者保健福祉手帳1～2級・愛の手帳1～2度のいずれか／医療機関に入院中で常時おむつ必要

## 助成額（L50-52）
実費相当額のうち**月額上限6,000円**まで助成

## 助成方法（L23-26）
おむつ代等の必要事項が明記された領収書を添えて3か月ごとに請求。口座振替により後日支給。

## 開始時期・注意点（L30-35）
- 申請締切：月末（土日祝の場合は直前平日）
- 翌月から開始。遡及助成不可
- 同月内で「紙おむつ支給」と「おむつ費用助成」の重複受給は不可

## 申請方法（L54-65）
- 高齢者：担当区域の地域包括支援センター
- 障害者：障害福祉課（区役所3階5番窓口、電話03-3228-8956）
- インターネット申請：電子申請サービス（LoGoフォーム）
- 郵送：在宅サービス係へ問い合わせ

## 問い合わせ先
地域包括ケア推進課 在宅サービス係（区役所3階3番窓口、電話03-3228-5632）

## 制度分類
現金助成型（実費償還・月額上限6,000円、入院者限定）
