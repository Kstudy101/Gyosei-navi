## 制度類型

**現物給付型（タクシー利用券）／選択的現金助成型（自動車燃料費）**。千代田区・新宿区など他区の福祉タクシー券と同型だが、申請月により年額12,000〜48,000円と変動する点が中央区の特徴。精神障害者保健福祉手帳1級も対象に含む。
