- 節水トイレ・宅配ボックス・省エネ冷蔵庫は令和8年度をもって終了予定（`01`・`02`）
- 東京ゼロエミポイントとの併用は可（ただしポイント分は対象経費から控除）— `06_qa.txt` Q9
