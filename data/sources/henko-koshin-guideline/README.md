## 주요 사실 (기사 검수용 메모)

- 변경·갱신 허가는 **법무대신의 자유재량** — 「相当の理由」 종합 판단
- 8항목 중 **1(자격해당성)은 필요조건**, **2(상륙기준)는 원칙 적합 요구**, 3~8은 대표적 고려요소 (전부 충족해도 불허 가능)
- 3: 現に자격에 응한 활동 수행 (실종 기능실습생·제적 후 재류 유학생·**장기 재입국 출국**은 소극 요소)
- 4: 素行 (퇴거강제 사유에 준하는 형사처분·불법취로 알선은 **초범도 불량 판정**)
- 5: 독립 생계 (세대 단위 가능, 공공부담이어도 인도상 이유 감안)
- 6: 고용·노동조건 적정 (아르바이트 포함. 법규 위반 勧告 시 외국인 본인 무책 감안)
- 7: 납세의무 이행 (고액·장기 미납, **国民健康保険料** 포함. **令和8年6月 개정: 관계기관 제공 정보로 허부 판단 가능 注記 추가**)
- 8: 입관법상 신고의무 이행 (재류카드 기재사항·소속기관 신고 등, 중장기재류자 범위 명기)
- 건강보험증 폐지 (令和6年12月2日) 이후 마이나포털 자격정보 화면·자격확인서 제시 요구. 단 미제시로 불허는 하지 않음

- 申請期間 (6月以上の在留期間は おおむね3か月前から)·手数料 6,000円/온라인 5,500円·標準処理期間 2週間〜1か月: ISA 16-3.html (2026-08-19 실측)
