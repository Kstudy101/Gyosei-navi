## 제도 유형 분류

**融資あっせん型**（利子補給＋信用保証料補助の併用）。현금 직접교부가 아니라, 取扱金融機関의 융자에 대해 中野区가 이자의 일부(利子補給)를 보조하고, 별도로 東京都・中野区가 信用保証料를 보조하는 이중 우대 구조.

## 확인되지 않은 것

- **募集期限・予算上限の有無**: 원문 어디에도 연간 접수 건수/예산 상한이나 「予算到達次第終了」와 같은 문구는 없음. 상시접수형 제도로 추정되나, "募集期限 없음"을 원문이 명시적으로 밝히지는 않음 — **미확인**으로 처리.
- **令和8年度(2026年度)와 그 이전 연도의 이자율/한도액 변경 이력**: 04번 PDF는 「2026年度」판이며 과거 연도와 비교한 변경사항은 원문에 기재 없음.
- **東京都「創業融資」（都制度融資）의 구체적 병용 조건**: 01/04 모두 "요건을 만족하면 병용 가능한 경우가 있다"고만 언급, 구체적 병용 요건표는 04번 PDF에는 없고 별도 도쿄도 페이지 확인 필요(미조사).
- **PDF 전체 페이지(3, 10페이지 등) 미독**: 1~2, 4~9페이지만 확인. 3페이지(2. 資金用途について 이하 부분은 확인), 10페이지(商店街連合会 연락처 등)는 미확인이나 창업지원자금 핵심 수치와는 무관.
- **接수 현황(募集中/終了)**: 홈페이지 갱신일이 2026年6月10日(01)/2026年5月27日(02)/2026年7月14日(03)로 최신이며 "受付終了" 등의 공지는 없음 — **募集中으로 추정**되나 명시적 "受付中" 표기는 원문에 없음.
