## 確認された事実（記事に使える）

- 対象: 令和7年4月1日以降に妊娠（医師による胎児心拍の確認）した方
- 妊婦支援給付金（1回目）: 妊娠時に5万円
- 妊婦支援給付金（2回目）: 出産後に胎児1人につき5万円
- 流産・死産の場合: 妊娠が確定した後に流産等で出産に至らない場合も1回目・2回目ともに給付対象
- 1回目受取方法: 妊娠届出時の面談で申請書受取→審査後→指定口座に振込
- 2回目受取方法: 出産後の面談（元気に育て!赤ちゃん訪問事業など）で胎児数届出書を受取→届出に基づき振込
- 事業の柱: 「伴走型相談支援」（妊娠届出時・妊娠8か月頃・出産後に面談）と「経済的支援」を一体的に実施
