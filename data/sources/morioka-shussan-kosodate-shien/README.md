## 制度1: 産後ケア事業（利用料無料化）

### 制度分類
現物給付型（サービス利用料の公費補助＝自己負担額を0円にする形）。令和8年度は「国、岩手県、盛岡市の補助」により課税世帯を含め自己負担が発生しない。現金給付ではない。

### 確定した中核情報と原文根拠

**対象者**
- 盛岡市に住民票がある、産後1年以内のお母さんとお子さん（デイサービス型・宿泊型は各医療機関により対象月齢が異なる）
- 医療行為が必要な方・感染症状がある方は除外
- 根拠: `01_sango-care-gaiyo.txt` 30行目、`03_sango-care-leaflet.pdf` 1ページ目

**産後ケアの種類（3種）**
- 訪問型（助産師が自宅訪問）／デイサービス型（施設で日帰り）／宿泊型（施設で宿泊）
- 根拠: `01_sango-care-gaiyo.txt` 18・42-48行目

**利用料金表（補助前の本来額、原文完全一致）**
根拠: `01_sango-care-gaiyo.txt` 58-94行目、`03_sango-care-leaflet.pdf` 2ページ目の表

| 区分 | 課税世帯 | 市民税非課税世帯・生活保護世帯 |
|------|----------|-------------------------------|
| 訪問型（1日につき） | 1,620円 | 無料 |
| デイサービス型 3時間コース | 1,620円 | 無料（食事代・オプション代は別途自己負担） |
| デイサービス型 5時間コース | 2,700円 | 無料 |
| デイサービス型 6時間コース | 3,240円 | 無料 |
| 宿泊型（1泊2日） | 14,310円 | 無料 |

- 依頼プロンプトで想定されていた「デイサービス型1,620~3,240円/日」は正確には3時間/5時間/6時間コースでそれぞれ1,620円/2,700円/3,240円と3段階に分かれる（原文で確認）。

**令和8年度の無料化**
- 「令和8年度は、国、岩手県、盛岡市の助成により、利用料が無料となります」（`01_sango-care-gaiyo.txt` 20行目）
- 「令和8年度は、課税世帯の方も下記の利用料金が『無料』となります（国、岩手県、盛岡市の補助による）。ただし、食事代やオプション代は別途自己負担となります。」（同60行目）
- リーフレット（`03_sango-care-leaflet.pdf`）にも同旨「令和８年度は、利用料金が『無料※』となります！食事代は別途自己負担となります。※国・岩手県・盛岡市の補助により無料となります。補助がない場合の利用料金は下記の表とおりです。」と明記 — **「補助がない場合の料金表」を明示している = 通常は自己負担が発生する制度であり、令和8年度に限り無料化されていることが原文上も明確**。
- **令和8年度限定か恒久かは原文からは断定できない**。ページ本文・PDFいずれも「令和8年度は」という年度限定の表現を繰り返しており、令和7年度以前の料金体系がどうだったかを直接記載したページは見つからなかった（後述「確認されなかった事項」参照）。少なくとも「令和8年度に限り無料化された」という文言autoは一次資料で確認済み。

**利用回数**
- 通算7日まで（デイサービス型・宿泊型は合わせて4日まで。宿泊型は1泊2日を上限とし2日カウント）
- 根拠: `01_sango-care-gaiyo.txt` 56行目、`03_sango-care-leaflet.pdf` 2ページ目

**申請方法・期限**
- 母子健康課（019-603-8303）へまず電話 → 申請書提出（電子申請／窓口／郵送）
- 原則、出産後から利用希望日の10日前（土日祝日除く）までに申請書類提出が必要
- 出産予定日の2か月前から仮申請可能（出産後に必ず電話で正式申請）
- 必要書類: 産後ケア事業利用申請書、（非課税・生活保護世帯のみ）証明書類（省略可の場合あり）
- 根拠: `01_sango-care-gaiyo.txt` 96-118行目、`03_sango-care-leaflet.pdf` 2ページ目フロー図

**問い合わせ先**
盛岡市子ども未来部母子健康課　〒020-0884盛岡市神明町3-29盛岡市保健所庁舎2階
電話 019-603-8303（本文中の問い合わせ先。ページ下部の「このページに関するお問い合わせ」欄には019-603-8304の記載もあり — 前者が事業窓口用、後者がページ管理用と推測されるが原文からは明確な使い分けの説明はない）

### 個人が直接申請可能な市独自予算が絡む制度であることの裏付け
- 原文に「国、岩手県、盛岡市の補助により、上記利用料が無料となります」（`01_sango-care-gaiyo.txt` 94行目）と明記 — 国・県だけでなく**盛岡市自身の補助（市独自財源の投入）が明記**されている。
- 申請は個人（産後の母親）が母子健康課に直接電話・申請する方式であり、市が窓口・申請受理・利用承認通知書発行を行う個人向け制度であることが申請フローから確認できる。

## 制度2: 盛岡市子育て応援在宅育児支援金

### 制度分類
現金直接給付型。市が指定口座へ直接振込む個人向け現金給付。年3回（8月・12月・4月）に分けて振込。

### 確定した中核情報と原文根拠

**支給対象児童の要件（すべて満たす必要あり）**
- 保育所等（保育所、認定こども園、地域型保育施設、認可外保育施設、常態的な一時預かり保育事業（週4日以上）、幼稚園のプレスクール（週4日以上）等）を利用していないこと
- 高校卒業までの児童のうち**第2子以降**で、生後8週間を超え、3歳未満であること
- 盛岡市に住民登録していること
- 根拠: `02_zaitaku-ikuji-shienkin.txt` 26-46行目、`05_zaitaku-chirashi.pdf` 1ページ目

**支給対象者（保護者・申請者）の要件**
- 令和8年度中に育児休業給付金（手当金）を受給（予定含む）していないこと（配偶者を含む）
- 児童と同じ住所であり、生計中心者（主に家計を支える保護者）であること（児童と同居していない場合は同居する養育者が対象）
  - ※`05_zaitaku-chirashi.pdf`（チラシ版）では「児童手当の受給者であること（児童手当を受給していない場合は生計中心者であること）」とやや詳しい表現。本文ページ（`02_zaitaku-ikuji-shienkin.txt`）は「生計中心者であること」のみのシンプルな表現。両者に文言の粒度差はあるが矛盾はない。
- 生活保護法による保護を受けていないこと
- 暴力団関係者や公序良俗に反する者ではないこと（配偶者を含む）
- 根拠: `02_zaitaku-ikuji-shienkin.txt` 34-42行目、`05_zaitaku-chirashi.pdf` 1ページ目

**支給額・支給期間**
- 対象児童1人当たり**月額10,000円**
- 支給期間: 令和8年4月〜令和9年3月までの12か月間
- 基準日: 各月1日時点の状況でその月の支給要件を判定
- 支給要件に該当しなくなった月以降は打ち切り（例: 9月1日生まれの児童が満3歳到達→8月分までの支給、と原文に明記）
- 根拠: `02_zaitaku-ikuji-shienkin.txt` 50-64行目、`05_zaitaku-chirashi.pdf` 2ページ目

**支給月・申請期限（原文の表をそのまま転記）**
| 支給月 | 対象月分 | 申請期限 |
|--------|----------|----------|
| 令和8年8月支給 | 4月〜7月分 | 7月31日 |
| 令和8年12月支給 | 8月〜11月分 | 11月30日 |
| 令和9年4月支給 | 12月〜3月分 | 3月5日 |

- 各支給月を過ぎて申請した場合も遡及支給可能。ただし**最終申請期限は令和9年3月5日（必着）**
- **令和7年度以前の支援金については遡及して支給しない**（`05_zaitaku-chirashi.pdf` 2ページ目に明記）— この一文から、**令和7年度以前にも同種の支援金制度が存在していたことが原文上示唆される**（後述）
- 根拠: `02_zaitaku-ikuji-shienkin.txt` 66-102行目、`05_zaitaku-chirashi.pdf` 2ページ目

**申請方法・必要書類**
- 子ども青少年課窓口へ持参、または郵送
- 必要書類: ①支給認定申請書（様式1）②育児休業給付金受給申請状況証明書（様式2、育休給付金を受給していない場合も提出必要、配偶者分も必要な場合あり）③審査・支払等にかかる同意書（様式3）④申請者名義の受取口座を確認できるものの写し
- 住民基本台帳で親子関係・第2子以降であることが確認できない場合は戸籍謄本等の追加提出を求められる場合あり
- 根拠: `02_zaitaku-ikuji-shienkin.txt` 104-132行目、`05_zaitaku-chirashi.pdf` 1-2ページ目

**問い合わせ先**
盛岡市子ども未来部子ども青少年課（給付係）　電話019-613-8354
受付時間: 平日8:30〜17:30
住所: 〒020-0884盛岡市神明町3番29号盛岡市保健所4階

  — この文言は、令和7年度以前にも同種の「支援金」が存在し、年度をまたいだ遡及請求を防ぐための注記であることを強く示唆する。少なくとも**単年度限定の一過性事業ではなく、年度更新を重ねている継続事業である可能性が高い**。ただし「令和7年度以前の支援金」が全く同じ制度（同一要綱）を指すのか、名称・要件が変わった前身制度を指すのかは、令和7年度以前の要綱・広報を直接確認していないため**断定不可（unresearched）**。

### 個人が直接申請可能な市独自予算が絡む制度であることの裏付け
- 制度名自体が「**盛岡市**子育て応援在宅育児支援金」であり、国の児童手当等とは別建ての市独自の給付金であることが名称・様式（盛岡市様式1〜5）から明確。

## 記事化の判断材料（まとめ）

| 観点 | 制度1: 産後ケア事業無料化 | 制度2: 子育て応援在宅育児支援金 |

| 記事としての訴求力 | 「本来1,620円〜14,310円かかるサービスが無料に」という分かりやすいビフォーアフターがあり具体的な金額比較がしやすい | 「月1万円×12か月＝最大12万円」という総額訴求がしやすい。第2子以降・在宅育児という対象が明確でニーズが強い層に刺さる |
| 制度の継続性の確証 | 「令和8年度は」という年度限定表現のみで、過去年度の状況を裏付ける一次資料は未確認。**単年度施策である可能性が高いことを明記する必要あり** | チラシの「令和7年度以前の支援金は遡及対象外」という一文から、**複数年度にわたる継続事業であることが一次資料から示唆される**。ただし令和7年度版要綱は未取得 |
| 市独自財源の明確さ | 国・県・市の3者補助と明記（市単独ではない） | 国・県の言及一切なし＝市単独事業と読める。市独自性を訴求する記事に向く |
| 情報の充実度 | 対象・料金表・利用回数・申請フローともに非常に充実。原文で完全に裏付け可能 | 支給要件・支給額・申請期限（3段階の表）・必要書類ともに充実。原文で完全に裏付け可能 |
| リスク・注意点 | 「令和8年度限定」であることを必ず明記しないと、恒久制度であるかのような誤解を招く | 「第2子以降」「育休給付金受給世帯は除外」等の除外要件が複雑なため、記事内で正確に要件を書く必要あり |

**結論**: どちらも公式原文（HTML本文＋PDF）で数値・条件を完全に裏付けられており、記事化に適している。特に制度2（在宅育児支援金）は現金給付で金額・期間が明確、かつ市独自事業である点を強調しやすく、writerが書きやすい。制度1（産後ケア事業無料化）も訴求力は高いが、「令和8年度限定」という時限性を必ず本文に明記する必要がある（恒久的な制度であるかのような誤った印象を与えないため）。両方とも記事化可能だが、時限性の注記が必須な点で差がある。
