## (참고, 채택 안 됨) 조사한 다른 2개 후보

- **高齢者紙おむつ等支給事業**: 요개호2이상, 40〜70点(1点100円환산=4,000〜7,000円상당), 입원자용월7,000円한도. 이미千代田区・新宿区가같은現物支給型(紙おむつ)다뤄유형중복이라비채택.
- **緊急通報システム**: 65세이상独居/고령자만세대, 월액이용료(고정전화형과세600円・비과세0円/무선형과세900円・비과세450円). 이미品川区가같은見守り支援型다뤄비채택. 이후보는WebFetch만확인, npm run source/PDF재대조는안함 — 향후채택시원문재확인필요.
