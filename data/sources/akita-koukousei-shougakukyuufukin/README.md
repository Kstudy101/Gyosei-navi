## 確認事項（基準日 令和8年7月1日、申請期限 令和8年9月30日(水)必着）
共通要件: 保護者等が秋田県内に住所／就学支援金等の受給資格／国籍・在留資格要件(R8から確認)。令和8年度改正で対象世帯拡充（所得割合算182,500円未満まで）。

### 給付額（生徒1人・年額）
私立(01,02):
- 生活保護(生業扶助): 52,600円（通信制の記載なし。02のPDFでは通信制欄は空欄）
- 所得割非課税: 全日制等152,000円 / 通信制52,100円
- 所得割合計100円以上105,500円未満: 50,670円 / 17,370円
- 105,500円以上182,500円未満: 38,000円 / 13,030円
- 制服加算(災害等で喪失・き損, 1回限り): 非課税81,000円 / 区分③27,000円 / 区分④20,250円

国公立(03,04):
- 生活保護(生業扶助): 32,300円（全日制・通信制とも）
- 非課税: 143,700円 / 50,500円
- 105,500円未満: 47,900円 / 16,830円
- 182,500円未満: 35,930円 / 12,630円
- 制服加算: 非課税64,800円 / 105,500円未満21,600円 / 182,500円未満16,200円
- 区分3,4は就学支援金【新制度】等の受給資格者のみ

### 申請先・方法
- 私立・県内: 在籍校(学校指定期限)。私立・県外: 教育庁総務課(簡易書留等)、期限9/30。
- 国公立・県内: 在籍校が窓口(学校指定期限)。国公立・県外校: 〒010-8580 秋田市山王三丁目1-1 教育庁高校教育課 調整・企画チーム 奨学給付金担当、9/30必着。
- 期限後の家計急変申請: 最終期限 令和8年12月25日(金)必着（国公立, 03）。
- 給付: 私立は県が保護者口座へ直接振込(11～12月頃予定)。国公立は県立校在籍なら学校経由、その他国公立は県から直接。
- 問合せ: 私立高校=教育庁総務課 018-860-5111／専修・各種学校=高等教育振興課 018-860-1223／国公立=高校教育課 018-860-5161。
