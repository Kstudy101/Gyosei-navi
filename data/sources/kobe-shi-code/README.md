# 神戸市 — 全国地方公共団体コード 一次情報

## 目的

兵庫県神戸市を `src/config/regions.ts` の MUNICIPALITIES に登録するための、総務省公式の団体コード一次情報アーカイブ。
「住みかえーる」（こうべぐらし応援補助金）記事調査（`data/sources/kobe-sumikaeru/`）に伴い取得。

## 確認した事実

- PDF 21ページ目、兵庫県セクション: `281000 | 兵庫県 | 神戸市 | ヒョウゴケン | コウベシ`
- `src/config/regions.ts` の他エントリ（横浜市14100、名古屋市23100 等）の慣行に合わせ、検査数字を除いた5桁「28100」で登録した。
