## 원문에서 확정한 사실 (기사 근거)

| 항목 | 원문 |
|---|---|
| 제도명 | 沼田市結婚新生活支援補助金（国の地域少子化対策重点推進交付金を活用） |
| **보조상한액** | 夫婦双方が**29歳以下**の世帯：**60万円**上限／夫婦双方が**39歳以下**の世帯（30歳以上39歳以下を含む）：**30万円**上限（L229「夫婦双方が29歳以下の世帯には60万円、夫婦双方が39歳以下の世帯には30万円を上限に補助します。」） |
| 経過措置（令和7年度からの繰越） | 令和7年度に申請し受給額が限度額に達しなかった世帯は、令和8年度に限り「令和7年度限度額−令和7年度給付額」を令和8年度の上限額として申請可（例示：29歳以下世帯が令和7年度35万円申請済なら、令和8年度上限は60万円−35万円=25万円） |
| 対象世帯（9要件） | (1)令和8年1月1日〜令和9年3月31日の間に婚姻届提出・受理 (2)交付申請時に夫婦の双方または一方が市内対象住居に居住・住民登録 (3)婚姻時の年齢が夫婦ともに39歳以下 (4)夫婦の令和7年分（令和8年4〜5月申請の場合は令和6年分）所得合計500万円未満（貸与型奨学金返済中は返済額を所得控除可） (5)市税等の滞納なし (6)他の公的家賃補助等の不受給 (7)過去に同要綱の補助未受給 (8)暴力団排除条例に規定する暴力団員でない (9)市が定める講座を夫婦共に受講 |
| 対象費用・支払時期 | 令和8年4月1日〜令和9年3月31日に支払った費用のみ。住居費（新築・購入・建替え／賃借の家賃・礼金・敷金・共益費・仲介手数料／リフォーム費用、ただし住宅手当支給分は除く）＋引越し費用（引越し業者・運送業者への支払いのみ、レンタカー自力引越しは対象外） |
| 申請期間 | 令和8年4月1日〜令和9年3月31日 |
