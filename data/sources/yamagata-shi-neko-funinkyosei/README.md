## 確認できた情報
- 金額（不妊手術・メス）: 「1件につき上限10,000円」
- 金額（去勢手術・オス）: 「1件につき上限5,000円」
- 対象となる猫: 多頭飼育崩壊・日常的屋外飼養により近隣から苦情のある飼い猫、または市内に生息する飼い主のいない猫
- 対象者: 「市内に住所を有する者又は市内に事務所若しくは住所を有する団体」
- 手続き: 事前に山形市動物愛護センター（わんにゃんポート）へ相談、交付申請書（様式第1号）等を提出
- 申請先: 山形市動物愛護センター（わんにゃんポート）〒990-0894 山形市大字船町1030-1、電話023-681-1210
- 飼い主のいない猫の場合: 術後に片耳V字カットが必要
