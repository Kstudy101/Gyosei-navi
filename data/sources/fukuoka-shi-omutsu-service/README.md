## 確認できた最終数値・条件

### 対象者（01）
- 福岡市の介護保険被保険者（福岡市に介護保険料を納めている人）
- 要介護3〜5と認定された、おむつが必要な**在宅**の人
- 入院中・ショートステイ中は利用不可

### サービス内容（01）
- 登録事業者から希望業者を選び申込み、業者がおむつを毎月宅配
- 現金給付ではなく用品配送＋費用の一部助成

### 月あたり助成率・助成限度額（01）

| 介護保険料所得段階 | 階層区分（要約） | 助成率 | 助成限度額（月） |
|---|---|---|---|
| 第1段階【A】 | 生活保護・支援給付／市民税世帯非課税の老齢福祉年金受給者など | 100％ | 6,000円 |
| 第1段階【B】 | 市民税世帯非課税で本人の課税年金収入＋その他合計所得が80.9万円以下 | 90％ | 5,400円 |
| 第2・3段階 | 市民税世帯非課税で上記合計が80.9万円超 | 90％ | 5,400円 |
| 第4・5段階 | 市民税世帯課税で本人が市民税非課税 | 60％ | 3,600円 |
| 第6・7段階 | 本人が市民税課税で合計所得200万円未満 | 35％ | 2,100円 |
| 第8段階 | 本人が市民税課税で合計所得200万円以上300万円未満 | 10％ | 600円 |
| 第9〜15段階 | 本人が市民税課税で合計所得300万円以上 | 0％ | 0円 |

- 申込金額×助成率で算出。ただし助成額には上記限度額があり、超過分は利用者負担。
- 第1段階の【A】【B】は当該事業独自区分。
- 世帯に市民税全額減免者がいる場合、負担が下がる場合あり（同意書・世帯員全員の本人確認書類が必要）。
- 住所地特例（市外在住）で郵送配達の場合、配達実費が請求される場合あり。

### 申請（01）
- 窓口・郵送: 各区保健福祉センター福祉・介護保険課
- オンライン: マイナポータル（区別に新規・変更・辞退）
- 必要書類: 地域支援事業サービス利用申込書／利用内訳書／介護保険被保険者証（番号記入済なら不要）／未申告所得状況申立書（第2号被保険者で課税状況確認不可の場合）
- 申請窓口: 住民票所在地を所管する区役所の福祉・介護保険課

### 受付状態（01）
- 募集期限・予算到達による受付停止の記載なし。常設案内。
