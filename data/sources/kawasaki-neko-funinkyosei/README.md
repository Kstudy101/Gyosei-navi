## 確認できた事実（原文根拠あり）
- 申請対象（一般）: 市内在住で、市内飼い猫の飼い主、または所有者不明猫を責任をもって世話している方（`01_main.txt`）
- 補助対象施術: 協力動物病院指定獣医師による不妊去勢手術および手術不要猫への処置（令和8年4月1日以降。飼い猫は「手術不要猫」に含まない）（`01_main.txt`）
- 補助額（一般・令和8年4月1日以降）: 1頭あたり上限5,000円（実費が下回れば実費）（`01_main.txt`。原文表記は「上額5,000円」）
- 補助額（一般・令和8年3月1日〜31日）: メス4,000円／オス3,000円（`03_march.txt`）
- 補助額（地域猫活動サポーター・令和8年4月1日以降）: 1頭あたり上限10,000円（`02_supporter.txt`）
- 補助額（サポーター・令和8年3月）: メス上限8,000円／オス上限6,000円（`02_supporter.txt`）
- 申請期間: 令和8年4月1日〜令和9年3月31日（`01_main.txt`／`02_supporter.txt`）
- 手術・処置日の案内区分（一般・現行ページ）: 令和8年4月1日〜令和9年2月28日（`01_main.txt`）
- 1世帯上限（一般）: 年度内最大8頭（`01_main.txt`）
- サポーター: 年度内頭数制限なし。代表者のみ申請可（`02_supporter.txt`）
- 予算上限到達で申請期間内でも締切（`01_main.txt`）
- リリースする場合は耳先カット必須（`01_main.txt`）
- 申請: e-KAWASAKI または区役所衛生課窓口（`01_main.txt`）
- 振込: 原則、提出月の翌々月末日頃（`01_main.txt`）
