## 確定した事実
- 制度名：甲府市重度心身障害者等タクシー利用料金助成制度（重度心身障害者等タクシー利用券の交付）
- 内容：山梨県内のタクシー料金を助成。1枚740円以内の利用券を月2枚（年間最大24枚）交付
- 年度中に使い切った場合、申請により10月以降に月2枚（最大12枚）追加交付
- 1回の乗車につき1枚のみ利用可能。運賃と利用券（740円以内）との差額は自己負担
- 対象者：市内居住・住民登録があり、身体障害者手帳1級または2級、視覚障害3〜6級、療育手帳A、精神障害者保健福祉手帳1級のいずれかを所持する重度心身障がい者
  - 令和7年度から視覚障がい3〜6級が新たに対象に拡充
  - 自動車税・軽自動車税の減免を受けている方、リース車による自動車燃料費助成を受ける方は対象外
- 令和8年度申請受付開始：令和8年3月26日（木曜日）午前8時30分〜午後5時15分、障がい福祉課5番窓口（本庁舎2階）。中道地区・上九一色地区は中道支所・上九一色出張所でも手続き可能
- 令和7年度分の有効期限は令和8年3月31日まで（追加交付分含む）
- 利用可能業者：山梨県タクシー協会加盟のタクシー会社、県内一部の介護タクシー（福祉有償運送は対象外）
- 紛失時の再交付なし
- 問い合わせ：福祉支援室障がい福祉課医療支援係 055-237-5642
