## 確認されていないこと / 注意

- 新入学学用品費について、HTML本文は「入学前に新入学準備金を受給された方は**差額のみ**対象」、PDF案内は「**対象外**」と表記が異なる。記事では更新日付きのHTMLページ（01_main.txt）の「差額のみ」を採用し、PDF表記差はここに記録。
- 国私立学校の給食費単価（小350円・中450円）は完全給食実施校向けの支給上限根拠として原文にあるが、市立中学校無償化とは別枠。
- 特別支援教育就学奨励費は別制度（02）。本記事の主対象外。
- 所得基準は「めやす」。世帯の年齢等で上下する旨が原文に明記。
