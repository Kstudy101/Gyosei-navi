| 항목 | 원문 |
|---|---|
| 제도명 | 北九州市住宅・建築物耐震改修工事費等補助事業（木造住宅の耐震補強工事） |
| 소관 | 都市戦略局指導部建築指導課（093-582-2531） |
| 令和8年度募集開始 | 2026年4月13日（先着順・予算到達で終了） |
| 대상건물 | 市内・昭和56年5月31日以前建築（または工事着手）・2階建て以下・上部構造評点1.0未満→1.0以上に補強 |
| 보조대상자 | 建物所有者または所有者の同意を得た者。市税滞納なし。暴力団関係者でないこと |
| 工事費補助 | 耐震改修工事監理及び工事費の5分の4、上限115万円（長屋・共同住宅は1棟あたり同額） |
| 진단費上乗せ | 令和7年度以降に耐震診断を実施し、令和7年10月7日以降に初めて申請する場合、診断費用を上限6千円まで上乗せ（合計最大115万6千円） |
| 消費税 | 補助対象外 |
| 시공자 | 원칙市内事業者（やむを得ない理由があれば市外可） |
| 착공조건 | 交付決定前の着工は対象外。事前協議必須 |
| 完了期限 | 1月末までに完了実績報告書を提出し、市の確定通知まで完了するもの |
| 신청서류 | 交付申請（工事前）→実績報告（完了後）→請求（確定通知後）の3回 |
| 관련메뉴 | 耐震＋省エネ併用で最大140万6千円／除却工事は所有者年齢により最大50万円（70歳以上）または30万円（70歳未満、令和8〜10年度） |
