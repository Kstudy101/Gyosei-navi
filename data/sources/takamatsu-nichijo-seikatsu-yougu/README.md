- 制度名: 日常生活用具の給付（身・知・難）／高松市重度障害者日常生活用具給付事業
- 所管: 高松市 障がい福祉課（〒760-8571 高松市番町一丁目8番15号本庁舎2階／TEL 087-839-2333／FAX 087-821-0086／syoufuku@city.takamatsu.lg.jp）

### 自己負担額・所得区分別月額負担上限額（`02`）
- 原則**1割負担**。各用具の限度額を超えた分は全額自己負担。
- 月額負担上限額（所得区分別）:

| 所得区分 | 対象となる世帯 | 月額負担上限額 |
|---|---|---|
| 生活保護 | 生活保護受給世帯 | 0円 |
| 低所得 | 市町村民税非課税世帯 | 0円 |
| 一般（18歳未満） | 世帯員合計で市町村民税所得割28万円未満の世帯 | 4,600円 |
| 一般（18歳未満） | 世帯員合計で市町村民税所得割28万円以上の世帯 | 37,200円 |
| 一般（18歳以上） | 世帯員合計で市町村民税所得割16万円未満の世帯 | 9,300円 |
| 一般（18歳以上） | 世帯員合計で市町村民税所得割16万円以上の世帯 | 37,200円 |

- 月額負担上限額の算定基準: 18歳以上は本人と配偶者のみの所得、18歳未満は住民票の世帯の所得で判断（`02`）
- **所得制限（対象外の壁）**: 世帯の中で市町村民税所得割が最も多い方の税額が**46万円以上**の場合、日常生活用具の給付の**対象外**（`01`・`02`一致確認）
- 限度額超過時の自己負担額計算の具体例（ネブライザー限度額36,000円、見積額40,000円の場合）: ①限度額超過分4,000円＋②限度額内1割負担3,600円＝計7,600円。ただし②が月額負担上限額を超える場合は「①＋月額負担上限額」（`02`）

### 申請手続（`01`）
- **事前申請必須**。用具購入後の申請は受付不可
- 原則、各用具の耐用年数経過後でなければ再給付申請不可（修理不能等の場合は要相談・修理不能証明書提出で耐用年数内再給付も可、`02`）
- 必要書類: 申請書、身体障害者手帳/療育手帳または難病患者は医師の診断書、見積書、カタログ（品名・写真入り）、本人のマイナンバー（18歳未満は保護者・同一世帯員、18歳以上は配偶者・同一世帯員のマイナンバーも記載要）、窓口来所者の身分証明書、代理申請時は委任状等
- 品目により医師の意見書が必要（表中○印は必須、△印は場合により必要）
- 用具を購入する業者は市の受託業者一覧から選定（希望業者が未登録の場合は業者登録が必要）
- **申請窓口**: 障がい福祉課（市役所本庁舎2階23番窓口）のほか、牟礼・山田・仏生山・香川・勝賀・国分寺の各総合センター、庵治・塩江・香南の各支所

## 制度の性格分類
- **給付形態**: 現物給付（品目別限度額の実費助成、上限額の範囲内で1割負担）。現金の一律給付や融資あっせんではない
- **所得制限あり**（市民税所得割46万円以上で対象外）。加えて所得区分別の月額負担上限額（0円〜37,200円）で低所得世帯ほど自己負担が軽減される二段構えの仕組み
- 国の障害者総合支援法に基づく日常生活用具給付等事業の枠組みに沿った、他自治体（世田谷区・渋谷区等）と同種の制度設計だが、**品目別限度額・対象要件・所得区分の刻み方は高松市独自**（金額は自治体ごとに異なるため他市と単純比較不可）
