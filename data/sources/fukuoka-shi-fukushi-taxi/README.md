# 福岡市 福祉タクシー料金助成事業（令和８年度）— 原文アーカイブ

## 対象制度
- 制度名: 令和８年度福祉タクシー料金助成事業（福岡市福祉タクシー利用券）
- 所管: 福岡市 福祉局 障がい者部 障がい在宅福祉課（TEL 092-711-4985 / FAX 092-711-4818 / s-zaitakufukushi.PWB@city.fukuoka.lg.jp）※取扱事業者ページの問い合わせ先。窓口申請は各区福祉・介護保険課（身体・療育）／各区健康課（精神）
- 制度類型: **現物給付型（利用券方式）** — 現金の直接支給ではなく、一般車は1枚500円の利用券、ワゴン型は時間制運賃（30分）相当の利用券を交付する方式。横浜市・東京23区の同種「福祉タクシー券」系列。政令指定都市として区役所（福祉・介護保険課／健康課）が窓口になる点が特徴。一般車とワゴン型の2系統がある。

## 確認できた核心情報

### 対象者（`01_taxi_r8.txt`）
- **福岡市内に居住**（住民票上の住所ではなく、実際に福岡市内にお住いの方）し、在宅の方
- **所得条件**
  - 対象者が18歳以上: 対象者及び配偶者がともに市民税非課税
  - 対象者が18歳未満: 保護者の属する住民基本台帳上の世帯員すべてが市民税非課税
  - 申請書（`05_sinseisyo.pdf`）注記: 18歳未満の「世帯」範囲は同一住民票上の世帯員全員**及び別世帯で生計同一の方**も含む。市外居住の生計同一者がいる場合は非課税証明書添付
- **障がい区分（いずれか）**
  1. 視覚障がい1級または2級
  2. 下肢、体幹機能障がい、または乳幼児期以前の非進行性の脳病変による運動機能障がい（移動機能障がいに限る）1級または2級
  3. 内部障がい1級または2級
  4. 視覚障がい、肢体不自由（上肢，下肢，体幹機能障がい）、内部障がいが重複して総合2級以上で、かつ下肢または体幹機能障がい3級
  5. 療育手帳A
  6. 精神障害者保健福祉手帳1級
- **対象外**: 施設に入所している方及び入院中の方（`01`本文・`05`申請書の確認事項と一致）
- **ワゴン型券の追加要件**: 電動車いす常時使用者（体幹保持部品等を付属した姿勢保持装置等を含む）にワゴン型タクシー券を交付（`01`）

### 交付内容・金額
#### 一般車タクシー（`01` / `03`）
- 1枚あたり**500円**の利用券を、年間最大**55枚**交付
- 支払い順序（`03`）: 障がい者割引（1割）適用後 → 助成額（1枚500円）差引 → 残額は自己負担
- 1回の乗車で利用できる枚数（お支払い料金＝障がい者割引適用後）※令和6年10月1日以降の現行ルール:
  | お支払い料金 | 利用枚数 |
  |---|---|
  | 500円未満 | 利用不可 |
  | 500円以上1,000円未満 | 1枚のみ |
  | 1,000円以上 | 最大2枚まで |

#### ワゴン型タクシー（`01` / `04`）
- **30分までの時間制運賃額**（九州運輸局から認可された金額を上限）相当の利用券を、年間最大**48枚**交付
- 1回の乗車につき**1枚まで**
- 参考上限額（`04`）: 特定大型車最大**3,720円**（令和7年12月25日時点）— 認可額の参考値であり、常にこの額が助成されるわけではない
- 一般型タクシーを利用した場合は初乗り運賃額の範囲内までの助成（`04`）

### 有効期間
- **令和8年4月1日〜令和9年3月31日**（`01` / `03` / `04`）
- 有効期間外の券は使用不可

### 申請・窓口（`01`）
- **窓口受取**: お住まいの区の福祉・介護保険課（身体障害者手帳・療育手帳）または健康課（精神障害者保健福祉手帳1級）
- **郵送受取**: 申請書を福岡市行政事務センター（〒812-8591・住所不要）へ郵送 → 課税状況確認後、対象なら簡易書留で送付／非対象なら別途通知
- **必要書類**: 障害者手帳。代理人申請・受領時は委任状＋代理人身分証（郵送時は写し同封）
- 申請書PDF・Word、記入例PDF、委任状Wordが本体ページからダウンロード可能

### 他制度との排他・重複制限（`01`）
- 福岡市が発行する**その他のタクシー券と同時利用不可**
- 福祉タクシー利用券の交付を受けた方は、**福祉乗車券・高齢者乗車券・障がい者移送サービスにおいてタクシー助成券を選択不可**
- 利用は本人に限る（`03` / `04`）。市外居住者が利用した場合は不正利用（`03` / `04`）
- 取扱事業者として登録されたタクシーのみ利用可。登録会社でも福岡交通圏外では使用できない場合あり（`03` / `04`）
- ミライロIDによる手帳提示も可（`03`一般車・`04`ワゴン型）

## 制度の性格分類
- **給付形態**: 現物給付（利用券・チケット方式）。現金給付でも融資あっせんでもない
- **一般車の実質年間上限（参考算出）**: 500円 × 55枚 ＝ 27,500円相当（原文に総額表記はなく、単価×枚数から算出した参考値。記事化時は「1枚500円・年間最大55枚」と原文どおり表記し、掛け算総額を断定する場合は算出である旨を明記）
- **ワゴン型**: 時間制運賃（30分）相当 × 最大48枚。1枚あたり金額は事業者の認可運賃により変動（参考: 特定大型車最大3,720円・R7.12.25時点）
- **所得制限あり**（市民税非課税）— 横浜市福祉タクシー利用券（所得制限なし）と対照的
- **2系統**: 一般車券／ワゴン型券（電動車いす常時使用者向け）
