## 核心数値（原文対照）

出典は特記なき限り `01_kamiomutsu.txt`。

| 項目 | 原文の記載 |
|---|---|
| 枠組み | 要介護認定を受け対象と認められる方に、市から**紙おむつ券**を交付。指定業者に連絡し希望の型の紙おむつと引き換え。尿とりパッドと引き換えも可 |
| 対象者 | 常時おむつを必要とする**40歳以上**の在宅の要介護認定者（第1号・第2号被保険者）で、身体要件・所得要件を満たす方 |
| 身体要件 | 要介護1〜5で、介護保険認定調査における障がい高齢者の日常生活自立度が**B以上**（B1・B2・C1・C2）**または**認知症高齢者の日常生活自立度が**3以上**（3a・3b・4・M） |
| 所得要件 | **市民税本人非課税**の方（介護保険料段階が1から5の方） |
| 非課税世帯（段階1〜3）×要介護1〜3 | パンツ型**60枚**または平型**200枚**相当券を**毎月**支給 |
| 非課税世帯（段階1〜3）×要介護4〜5 | パンツ型**90枚**または平型**300枚**相当券を**毎月**支給 |
| 本人非課税（段階4・5）×要介護1〜5 | パンツ型**30枚**または平型**100枚**相当券を**毎月**支給 |
| 備考 | 希望のタイプ・サイズにより枚数が少なくなる場合あり |
| 問い合わせ | 各区役所健康福祉課高齢介護担当（`02`に8区の電話）。作成担当: 福祉部高齢者支援課 025-226-1295 |
