## 制度の分類

**現物給付・現金補助型（費用の一部を助成金として交付する補助金制度）**。融資あっせん型ではない。以下4種類の助成が段階的に連動する構成:

1. 耐震診断助成
2. 補強設計助成（木造住宅のみ）
3. 耐震改修工事助成
4. 段階耐震改修工事助成（木造住宅のみ、①②を2段階に分けて実施する場合）

いずれも**事前申請・事前承認が必須**（診断・設計・工事の実施後に申請しても助成対象外）。

## 確定した核心数値（原文根拠: 01_taishinkoji.txt および 02_anshinanzengoannai.pdf で相互確認済み）

### 対象建築物
- 昭和56年5月31日以前（旧耐震基準）に建築されたもの、または
- 昭和56年6月1日〜平成12年5月31日に建築された新耐震基準の**木造**住宅（2階建て以下・在来軸組構法）
- 台東区内にあるもの。延床面積の2分の1以上が住宅であること等（01_taishinkoji.txt 65-72行、PDF p.2）

### 〔1〕耐震診断助成
- 木造の住宅: 診断費用の10/10（ただし20万円以内）
- 木造以外の住宅: 診断費用の1/2（ただし50万円以内）
- 住宅以外の建築物・煙突等の工作物: 診断費用の8/10（ただし20万円以内）
（01_taishinkoji.txt 56-59行、PDF p.2表と完全一致）

### 〔2〕補強設計助成（木造住宅のみ、新耐震基準木造住宅含む）
- 補強設計費用の1/2（ただし10万円以内）
（01_taishinkoji.txt 109行、PDF p.3表と完全一致）
- 前提: 区の助成を受けた耐震診断で評点1.0未満と判定された木造住宅のみ対象

### 〔3〕耐震改修工事助成
- 昭和56年5月31日以前の建物・重点地域内の住宅: 工事費用の**2/3（ただし200万円以内）**
- 昭和56年5月31日以前の建物・その他地域の住宅: 工事費用の**1/2（ただし150万円以内）**
- 平成12年5月31日以前（新耐震木造）・全区域の住宅: 工事費用の**1/2（ただし100万円以内）**
（01_taishinkoji.txt 165-167行）

**注意（topic-scout仮説との相違）**: 事前情報にあった「重点整備地域 最大20万円(補助率67%)／その他地域 最大15万円(補助率50%)」という金額は原文と一致しない。原文の上限額は**200万円・150万円・100万円**であり、桁が異なる（WebSearch要約の誤りとみられる）。本記事作成時はこの原文の数値（200万/150万/100万円）を採用すること。

### 〔4〕段階耐震改修工事助成（木造住宅のみ）
- 一段階目: 工事費用の1/2（ただし50万円以内）
- 二段階目: 昭和56年5月31日以前・重点地域内は工事費用の2/3（200万円から一段階目助成額を差し引いた額以内）、その他地域は1/2（150万円から差し引いた額以内）、平成12年5月31日以前（新耐震木造）は全区域1/2（100万円から差し引いた額以内）
（01_taishinkoji.txt 216-255行）

### 申請方法
- 区の窓口での**事前相談 → 現地調査 → 助成承認申請 → 助成承認通知 → 診断・設計・工事実施 → 完了報告・助成金交付申請 → 請求 → 助成金交付**という流れ（01_taishinkoji.txt 293-309行、PDFフローチャートp.2と一致）
- 事後申請は一切不可
