## 不採用の理由

本制度は個人の住宅用太陽光発電・蓄電池を対象とした制度ではなく、**中小企業者・農林漁業者・福祉施設等の事業者向け**制度である。topics-db記載のnote「太陽光発電設備・蓄電池の設備購入費が対象」という説明とは対象者の点で異なる（個人住宅向けではない）。
また記事執筆時点（2026-09-22）で申請受付期間が終了しており、次回募集時期も原文からは不明のため、時宜性の観点からも記事化を見送った。
energyカテゴリの記事は `data/sources/kofu-clean-energy-hojo/`（甲府市クリーンエネルギー機器普及助成金制度）を採用。
