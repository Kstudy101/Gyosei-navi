# 大阪市補装具費支給制度（淀川区住民が利用する大阪市統一制度）

対象自治体: 大阪府大阪市淀川区（総務省全国地方公共団体コード **27123**、大阪市の行政区。淀川区は大阪市の一部であり単独の地方公共団体コードは持たない — 既存記事 `content/subsidy/kaigo/yodogawa-kaigoyohin-kyufu.mdx` と同じ扱い）。

制度名: 補装具の購入・借受け・修理にかかる費用の支給（通称: 補装具費支給制度）
所管: 大阪市福祉局障がい者施策部障がい支援課 自立支援事業グループ（TEL 06-6208-7986／FAX 06-6202-6962）
制度の性格: **淀川区独自の制度ではなく、大阪市24区共通で運営される制度**。申請窓口のみ各区（淀川区の場合は淀川区保健福祉課）。

## 制度分類

- **現物給付・費用償還型（法定給付）**: 障害者総合支援法に基づく自立支援給付の一種。対象品目（補装具）の購入・借受け・修理費用について、原則1割の利用者負担を除いた額を市が支給する仕組み。現金を直接手渡す給付ではなく、代理受領（業者が市から直接受領）が原則。
- 融資ではない。宝くじ的な抽選・先着順の要素はなし（予算上限による受付終了の記載も原文では確認できなかった＝随時申請制と見られるが、明示的な「予算に達し次第終了」等の記載は無い）。

## 確認できた主要事実（原文根拠つき）

- **対象者**: 身体障がい者手帳の交付を受けた方、または障害者総合支援法の対象疾病（難病等）のある方（01_gaiyo.txt 118-149行）。
- **対象品目**: 視覚障がい（安全つえ・義眼・眼鏡）、聴覚障がい（補聴器・人工内耳〔修理のみ〕）、肢体不自由（義手・義足・装具・姿勢保持装置・車載用姿勢保持装置・車椅子・電動車椅子・歩行器・歩行補助つえ）、肢体不自由18歳未満のみ（起立保持具・排便補助具）、呼吸器/心臓機能障がい（車椅子・電動車椅子）、肢体不自由+言語機能障がい等（重度障がい者用意思伝達装置）（01_gaiyo.txt 129-137行）。
- **借受け（レンタル）の対象は限定的**: 義肢・装具・姿勢保持装置の完成用部品／重度障がい者用意思伝達装置／歩行器／車載用姿勢保持装置の4種のみ（01_gaiyo.txt 139-143行、02要綱PDF第2条にも同旨）。
- **自己負担割合**: 定率1割負担（01_gaiyo.txt 153行）。「所得等に応じた月額負担上限額が設定されています」との記載はあるが、**補装具費専用の上限額表そのものは大阪市公式ページ上に見当たらなかった**（下記「確認できなかったこと」参照）。
- **申請窓口**: お住まいの各区保健福祉センター（01_gaiyo.txt 155-157行）。淀川区の場合は淀川区保健福祉センター＝淀川区役所内（〒532-8501 大阪市淀川区十三東2-3-3、04_kuyakusho-madoguchi.txt 299-305行）。
- **淀川区での担当窓口・郵送申請**: 補装具費支給の手続きは淀川区役所 保健福祉課（保健福祉）が担当し、郵送でも申請可能な手続きの一つとして明記されている（電話06-6308-9857、FAX06-6885-0537）（05_yodogawa-yusou-tetsuzuki.txt 184-199行）。
- **申請書類**: 補装具費支給申請書（様式第1号）、同意書（様式第3号）、18歳未満は補装具費支給意見書（様式第2号）＋補装具処方箋、18歳以上は医師の意見書等（不要な場合あり）、難病等は受給者証等、見積書（01_gaiyo.txt 161-168行）。
- **要綱の位置づけ**: 「大阪市補装具費支給事業事務取扱実施要綱」（02のPDF）は自治体内の事務処理・実施機関の判定手続き等を定めたもので、令和7年9月3日施行が最新（附則、02要綱PDF 6ページ目参照）。
