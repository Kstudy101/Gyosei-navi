## 制度の種別分類

現金給付型（後払い）。事前申込み・承認後に申請者が協力病院へ費用を立替え、交付申請後に補助金が振込まれる方式。融資あっせん型・現物支給型ではない。飼い猫ではなく飼い主不明猫（TNR的）向け。
