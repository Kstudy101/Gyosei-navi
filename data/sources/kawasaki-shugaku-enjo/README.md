## 確認できた事実（原文根拠あり）
- 対象: 市立小・中学校等へ通学させるのに経済的な理由でお困りの方。（1）生活保護受給（2）今年度又は前年度の生活保護停止・廃止（3）児童扶養手当受給（4）令和7年世帯合計所得が基準額以下（5）別紙理由で基準超過でも援助を要すると認められる場合
- 所得目安（合計所得）: 2人約230万・3人約286万・4人約330万・5人約379万・6人約430万・7人約482万・8人約516万（世帯年齢構成等で基準額は変動）
- 年度当初申請: 令和8年4月1日〜6月1日。冒頭注記はオンライン・郵送・持参とも必着、申請区分表は郵送消印有効と記載。6月1日まで提出で認定日は原則令和8年4月1日
- 援助費目例（表中金額は令和7年度実績。令和8年度額は認定結果のお知らせで案内予定）: 学用品費・通学用品費（小1年11,630円、小2〜6年13,900円、中1年22,730円、中2〜3年25,000円）、新入学児童生徒学用品費（小1年57,060円・中1年63,000円等）、学校給食費は認定後に市が実費負担、ほか修学旅行費・医療費等
- 要保護（生活保護）は★費目のみ対象
- 申請方法: e-KAWASAKI または紙申請（持参・郵送）。提出先は川崎市教育委員会学事課
- 支給: 原則年3回（8月又は10月・12月・3月）
- 令和8年3月31日時点認定者は原則再申請不要（世帯変更・1月1日時点市外・理由(5)等は例外）
