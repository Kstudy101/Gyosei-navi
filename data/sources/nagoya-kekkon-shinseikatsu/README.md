## 原文から確定した数値・条件（記事に使用）

- 助成上限額: 夫婦等ともに29歳以下 → 上限60万円／それ以外の世帯 → 上限30万円（01・PDF一致）
- 対象婚姻期間: 令和8年1月1日〜令和9年3月31日（ファミリーシップ宣誓を含む）
- 所得要件: 令和7年中の夫婦等の合計所得金額500万円未満（貸与型奨学金返済額は控除可）
- 居住要件: 夫婦等の双方又は一方が市内の申請に係る住宅に居住
- 居住意思: 1年以上市内に居住する意思
- 動画視聴: 夫婦ともに市作成の結婚新生活支援動画（YouTube「まるはっちゅーぶ」）を視聴完了必須
- 対象費用支払期間: 令和8年4月1日〜令和9年3月31日
- 住宅賃借費: 賃料・敷金・礼金・共益費・仲介手数料（賃料・共益費は3か月上限）。住宅手当は差し引き
- 住宅取得費: 戸建・マンション等建物の購入費（土地取得費は対象外）
- リフォーム費: 修繕・増築・改築・設備更新等工事費
- 引越費用: 引越業者・運送業者への支払実費
- 申請期間: 令和8年8月8日〜令和9年3月31日（予算上限到達で早期終了あり）
- 申請方法: オンライン申請（名古屋市電子申請システム）
- 問い合わせ: TEL 052-485-7035、E-mail kekkonshinseikatsu@758nagoya.jp（平日9:00〜17:30）
- 担当課: 子ども青少年局 企画経理課 子ども未来応援担当（TEL 052-972-4654）

## 制度タイプ
現金直接補助型（新婚世帯の住居費・引越費等）。国の交付基準額（29歳以下60万／それ以外30万）をそのまま採用。久留米市と異なり、指定講座の受講ではなく市作成の**動画視聴**が要件（オンラインで完結）。申請方法も**完全オンライン**で、窓口持参は不要。
