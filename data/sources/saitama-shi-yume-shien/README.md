## 既存記事との差別化

- `saitama-shi-shingaku-shienkin`（低所得の子育て家庭児童進学支援金）は学習支援教室登録が前提の低所得世帯向け助成。
- 本制度は学力評定・作文審査で最大30人を選抜する給付型奨学金で、学習支援教室登録は要件にない。
