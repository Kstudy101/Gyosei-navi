## 確認できた事実（01・04で一致）
- 実施機関・申請先: (公財)にいがた産業創造機構(NICO) 産業創造グループ 起業・創業支援チーム、新潟市中央区万代島5-1 万代島ビル11F、TEL 025-246-0051、FAX 025-246-0030
- 目的: 県外から県内へU・Iターンし、デジタル技術を活用して地域課題・社会課題の解決に資する創業を促進
- 対象者: 県内に事業所を設置し、2026-05-12〜2027-02-28に起業見込みの者で、(1)起業の種類 ①U・Iターン起業（U・Iターン=新潟県外居住者が県内に転居すること。起業準備のため既に転居済みの者は2026-05-12時点で転居後1年以内に限り対象）②じもと定着起業（ア: 進学を契機に県内在住の県外出身大学院生等、卒業後1年以内も可 / イ: 有期雇用契約等で転居就業している県外出身者、例: 地域おこし協力隊、契約終了後1年以内も可）、かつ(2)起業の形態 ①個人開業（開業届提出、営業開始）②法人設立（株式会社・合同会社・合名会社・合資会社・特定非営利活動法人・一般社団法人）。個人事業主の法人成りは対象外
- 対象外・注意: 申請開始日以前に法人設立・個人開業済みは対象外／NICOの他補助金及び第2世代交付金財源の他補助金と併願・併用不可／会社等に所属する者は交付決定2か月以内に退職が必要（副業起業は対象外）／事業承継はSociety5.0関連等付加価値の高い分野に限る／過去申請者の同内容再申請不可／フランチャイジー対象外(04)
- 対象事業: デジタル技術活用(例: キャッシュレス決済、Web予約、EC、SNS/Web発信)＋県内の地域・社会課題解決(分野: 地域活性化、まちづくり、過疎地域等活性化、買い物弱者支援、地域交通支援、社会教育、子育て支援、環境、社会福祉、地域資源の活用)。1年以上の事業継続見込み、3年以上の事業計画。単なる飲食業・美容業等は対象外(01)
- 補助率・上限: 経費の1/2以内、上限200万円、下限50万円。交付決定額は減額される場合あり。精算払（経費支払後）(04)
- 補助対象期間: 交付決定日〜2027-02-28。この間に契約・取得・支払が完了する経費（人件費・賃借料・設備リース料は交付決定前契約でも期間内支払なら可）
- 対象経費: 事業拠点開設費（設備・備品費、事業所の増改築費[新築・解体除く]、法人登記費用[印紙・登録免許税除く]、消耗品費）、事業促進費（人件費[本人・3親等以内親族除く、基本給のみ]、賃借料、光熱水費、通信運搬費、広告宣伝費）。住居兼店舗は対象外。支払は銀行振込・口座振替・クレカ(申請者/法人名義)のみ、現金不可
- 申請手順: 事前にNICOへ事業内容の対象可否を問い合わせ（問い合わせなしは受付不可）→申請書作成→事前確認団体（創業予定地の商工会・商工会議所または金融機関）で「確認書」発行→NICOへ簡易書留郵送または持参
- 一次募集期間: 2026-05-12(火)〜2026-06-18(木)17:00必着。事前確認団体への提出締切2026-06-08(月)
- 審査: 書面審査→プレゼン審査（2026-08-05、対面）。採択時に申請者名・市区町村・業種を公表
- 事後義務: 実績報告、補助事業終了後5年間の事業化状況報告
