## 制度유형 분류

現金給付型（補助金・助成金）。地域猫活動を担う個人向けに、不妊去勢手術費の一部（オス8,000円・メス10,000円）を助成する方式。手術は協力動物病院での実施が前提で、事前申請（押印済み申請書の持参）が必須、事後申請は不可。
