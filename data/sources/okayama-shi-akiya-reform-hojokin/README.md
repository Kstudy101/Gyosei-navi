## 制度概要（分類）

- **制度種別**: **現金助成型**（空き家の再生改修＝リフォーム経費の一部を市が補助。融資あっせんではない）
- **正式名称（要綱）**: 岡山市空家等適正管理支援事業費（リフォーム）補助金
- **ページ表記**: 空家等適正管理支援事業（リフォーム）
- **対象年度**: 令和8年度（要綱附則: 令和8年4月1日施行／パンフレット表題: 令和8年度版）
- **代理受領**: あり（平成30年度より。補助金を施工業者へ直接支払可）

## 確認できた最終数値・条件

### 受付状態（重要・01）

- **一般世帯向け（上限60万円）**: 申請受付期間内。原文「予算がなくなり次第終了」「予算に達し次第受付を終了」。**取得時点で一般枠の受付停止告知はなし** → 事実上 **募集中（予算到達次第終了）**。
- **子育て世帯向け上乗せ（上限70万円）**: **「令和８年度の子育て世帯への補助金（上限70万円）は、予算がなくなったため終了しました。」**（01冒頭・補助金額欄）。ただし「子育て世帯であっても、一般世帯向けの補助金（上限60万）は、ご利用できます。」
- **申請受付期間（01・02）**:
  - 通常: **令和8年5月1日（金）〜令和8年12月18日（金）**
  - 昭和56年5月31日以前着工建物: **〜令和8年11月30日（月）**
- **実績報告書提出期限（01・02）**: **令和9年2月12日（金）**までに提出見込みがあるもの
- 事前相談必須（01・02）

### 補助金額（01・02・03 第8条）

| 区分 | 内容 | 根拠 |
|------|------|------|
| 補助率 | 補助対象経費の合計額の **3分の1** | 01／02／03第8条 |
| 端数 | **1,000円未満切り捨て** | 01／03第8条第2項 |
| 上限（一般） | **60万円** | 01／02／03第8条 |
| 上限（子育て世帯） | **70万円**（※令和8年度分は予算終了） | 01／02／03第8条ただし書 |
| 対象工事費の下限 | リフォーム工事経費 **60万円以上** | 01／02／03第3条 |

### 子育て世帯の定義（03 第2条第2項第9号）

- 「出生の日から **18歳に達した日以後の最初の3月31日**までの間にある者を含む世帯」
- 子育て世帯の場合、申請日から **10年以上継続して居住する意思**が必要（03 第5条第4号／01）

### 補助対象者（01・03 第5条）

- 空き家の所有者（個人）、または所有者の承諾を受けた賃借人等（個人）、その他市長が認めた者
- 市税滞納なし
- 暴力団員（離脱後5年未経過含む）でないこと

### 補助対象住宅（01・03 第4条）

- 岡山市内の一戸建て（併用住宅は延べ面積の1/2以上が居住用）
- ア: 空家法第2条第1項の空家等（住宅）／イ: 岡山市空き家情報バンク登録物件（補助事業者による再入居なし）
- **空家法第22条第2項に基づく勧告を受けた特定空家等は除外**
- 耐震: 着工が昭和56年6月1日以降、またはそれ以前でも補助事業完了後の実績報告時に耐震診断結果を提出できるもの
- リフォーム後に居室・台所・水洗便所・浴室があること

### 補助事業・施工者（01・03 第3条）

- **市内施工業者**による居住用部分の工事（申請時未契約のもの）
- 「市内施工業者」定義（03 第2条第2項第8号）: 本市内に本社・本店・支店・営業所等の活動拠点を置き建築関連業務等を営む者。**見積書等を本市内の所在地で発行できる者に限る**
- 必須: 「耐震改修工事等」「バリアフリー改修工事」「省エネルギー改修工事」の **いずれかを含む** リフォーム
- 附帯工事（家財道具等の搬出処分、屋内外の清掃）も可

### 補助対象経費・附帯工事の扱い（要綱とパンフで一致）

| 出典 | 附帯工事の算定 |
|------|----------------|
| **要綱 第7条**（03） | 附帯工事の実支出額。ただし **リフォーム工事経費の5分の1を上限** |
| **パンフレット**（02） | 「附帯工事の補助対象経費は、リフォーム工事の補助対象経費の **1/5** を上限」 |

→ 要綱・パンフレットとも **リフォーム工事経費の1/5上限**で一致。

- 他の市・県・国補助制度の対象工事経費は補助対象外（03 第7条ただし書／01「他の補助制度の対象となる工事を除く」）

### 交付条件・活用義務（01・03 第10条）

- 改修後に活用すること（賃貸・売却、または自己／親族等の居住）
- 賃貸・売却の場合: 空き家バンク登録申請、または不動産業者との媒介契約等

### 同一住宅の回数制限（03 第6条）

- 同一の補助対象住宅について **1回限り**
- 同一申請者が確定通知書交付まで重複申請不可

### バリアフリー・省エネの基準（03 別表）

- BF（別表第1）: 手すり3箇所以上／段差解消1室以上／廊下幅拡張／昇降機／和式→洋式トイレ／開き戸→引き戸等
- 省エネ（別表第2）: 先進的窓リノベ該当の窓断熱／みらいエコ住宅該当の外壁・屋根天井・床断熱／太陽熱利用／節水Ⅱ型トイレ／高断熱浴槽／エコキュート・エコジョーズ・エコフィール等／SII指定の家庭用定置型蓄電池

### 申請方法（01・02）

1. 事前相談（建築指導課 空家対策推進室）
2. 交付申請（着手前・未契約）
3. 交付決定 → 契約・着工
4. 完了後に実績報告 → 確定 → 請求（または代理受領）

様式: 補助金交付申請書（.doc）、様式集（.doc）がページに添付（今回は金額確定に不要のため未取得）
