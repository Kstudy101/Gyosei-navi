## 確認できた事実（原文根拠あり）
- 対象: 要介護1〜5、常時失禁、千葉市内住所・市内居宅で介護、生活保護等非受給、本人および同一住所地親族全員が市民税非課税、在宅重度心身障害者おむつ給付事業を受けていないこと（すべて満たす必要）
- 給付基準額: 要介護1・2・3＝月額4,000円（市9割3,600円＋利用者1割400円）／要介護4・5＝月額8,000円（市9割7,200円＋利用者1割800円）
- 実費が基準額未満の場合は実費の9割（1円未満切捨て）を市が給付
- 配達: 登録業者による月1回（布おむつは週1回以上）。単価表掲載品のみ
- 申請窓口: 各区保健福祉センター高齢障害支援課高齢支援班
- 給付期間: 開始月の初日から介護保険被保険者証の有効期間満了月まで
- 施設入所・1か月以上入院・1か月以上ショートステイは利用廃止対象
- 本編ページ更新日: 2025年10月14日／業者価格一覧更新日: 2026年9月1日
- 案内PDF（令和7年4月）にも同額・同条件を確認
