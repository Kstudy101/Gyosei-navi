## 上位ハブページに存在する「他の耐震化助成メニュー」との区別（混同注意）

`02_taishin_josei_hub.txt`（住宅・建築物の耐震化助成制度）には、本記事が対象とする**「老朽住宅除却助成制度」（除却＝解体型）以外に、以下の別制度が並記されている**。記事では除却型のみを扱うため、これらとは明確に区別すること。

- **旧耐震基準住宅向け**（昭和56年5月31日以前）
  - 耐震コンサルタント派遣制度（申請期限は令和9年1月29日で、除却型の12月25日と**期限が異なる**）
  - **老朽住宅除却助成制度**（＝本記事の対象、除却工事費補助）
  - 戸建住宅耐震改修設計等助成制度（設計費補助、除却とは別制度）
  - 戸建住宅耐震改修工事助成制度（改修工事費補助、除却とは別制度）
- **新耐震基準住宅向け**（昭和56年6月1日〜平成12年5月31日、木造）
  - 戸建住宅耐震改修設計等助成制度
  - 戸建住宅耐震改修工事助成制度
- **建築物（分譲マンション・緊急輸送道路沿道建築物等）向け**の別助成制度群（事前相談制）

いずれも所管は同じ建築指導課耐震化促進係だが、対象要件・助成額・申請期限が個別に設定されている。特に「戸建住宅耐震改修工事助成制度」（改修型）と「老朽住宅除却助成制度」（除却型）は名称が紛らわしいが原文で明確に別メニューとして併記されている。
