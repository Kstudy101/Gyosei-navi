## 제도 유형 분류

**현금교부형(給付金)** — 返済不要の給付型奨学金（返還義務なし）。授業料以外の教育費負担を軽減。

## 원문에서 확정한 사실（02_kyufukin_detail.txt 대조）

| 항목 | 원문 |
|---|---|
| 제도명 | 教材費等給付金（鳥取県高校生等奨学給付金） |
| 目的 | 全ての意思ある高校生等が安心して教育を受けられるよう、授業料以外の教育費負担を軽減 |
| 返還義務 | **返済不要（給付型）** |
| 受付開始 | **令和8年7月1日（水）** |
| 申請期限（延長後） | **令和8年9月30日（水）** |
| 最終期限 | 令和8年11月30日（月）（期限後も受付するが給付が遅延） |
| 申請方法 | 令和8年度より原則**電子申請** |
| コールセンター | 0120-50-7148（平日・日曜12:00〜20:00） |

### 対象世帯（令和8年7月1日基準）

| 区分 | 条件 |
|---|---|
| 区分1 | 生活保護（生業扶助(高等学校等就学費)）受給世帯 |
| 区分2 | 非課税世帯（年収目安270万円未満） |
| 区分3 | 道府県民税・市町村民税所得割合算額105,500円未満（年収目安380万円未満） |
| 区分4 | 道府県民税・市町村民税所得割合算額182,500円未満（年収目安490万円未満） |
| 区分5 | 所得割合算額264,500円未満の**多子世帯**（年収目安600万円未満） |

共通要件: (4) 保護者が鳥取県内在住、(5) 就学支援金支給対象校に在学
