# miyagi-monodukuri-venture-hojokin

対象記事候補（未執筆・government-researcher調査段階）: 宮城県「宮城県ものづくり産業振興起業家等育成支援事業費補助金（ベンチャー企業支援型）」

## 制度概要（結論）

宮城県（経済商工観光部新産業振興課スタートアップ支援班）が実施する県単独事業。県内で研究開発型ベンチャーを興そうとする中小企業者・個人に対し、オフィス・ラボ等の**賃料の1/2（月額上限5万円）を最長3年間補助**する。**個人（創業前）でも直接申請可能**であり、原文（交付要綱第3条(1)、Q&A 1-3・1-7・1-10）で明確に確認できた。

## 個人直接申請可否についての結論

**可能。** 交付要綱第3条(1)が「起業又は第二創業の日から10年以内の中小企業者**又は**入居後3年以内に事業化に係る法人を設立する計画のある個人」と明記し、Q&A1-3で現役の個人事業主の応募が明示的に肯定されている。ただし個人の場合は入居後3年以内の法人化が条件（Q&A1-10）。よって「創業予定の個人」も「創業済みの個人事業主」も申請主体になり得る、法人限定ではない制度である。
