## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 19市町それぞれの持参書類の詳細差異（マイナンバーカード等以外に市町独自で必要なもの）は「市町により異なる」とのみ記載され、各市町の個別要件までは今回確認していない。記事では福井市・坂井市の窓口情報のみを具体的に扱い、他市町は「各市町のホームページを確認」と案内する。
- 02_ryuzan.pdf（流産・死産等の場合の給付金と相談窓口のご案内）は取得済みだが、本README作成時点で内容を全文精査していない（流産・死産時の追加手続き詳細は要事前確認）。今回の記事が通常の妊娠・出産ケースを主眼とするなら支障なし。
- 令和7年度以前の「出産・子育て応援交付金」との金額差異（同額か否か）は原文で明記されておらず、旧制度の詳細は未調査（今回のfoundAtでは新制度=妊婦支援給付金のみを対象とする）。
