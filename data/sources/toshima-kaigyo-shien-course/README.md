## 제도 유형 분류

**현금지급형（보조금 직접교부）**。融資あっせんではなく、補助対象経費(事業PR経費・デジタル環境整備経費・専門家活用経費)の3分の2以内・上限20万円を区が直接補助する仕組み。事前に「特定創業支援プログラム」受講＋としまビジネスサポートセンターの専門相談員による助言・指導を経る必要がある点が特徴（単なる要件確認ではなく、教育プログラム受講＋コーディネーター面談を交付の前提条件とする「伴走型」補助金）。
