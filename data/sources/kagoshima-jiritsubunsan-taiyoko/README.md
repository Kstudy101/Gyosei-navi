## T2 調査判断: 個人向けか事業者向けか

**事業者向け（中小事業者等）** と判断。

原文L97に「県内中小事業者等（県内に事業所を置く法人格その他の団体及び個人事業主）」と明記されており、一般住宅の個人向け制度ではない。蓄電池の補助単価も業務用スケール（20kWh以上も対象）であることと整合する。

個人向けの太陽光・蓄電池補助金を探すなら鹿児島市や各市区町村の制度（T3: 鹿屋市など）を参照すること。
