## 제도 요약

- **제도명**: 介護用品の給付
- **운영 주체**: **大阪市**（福祉局高齢者施策部地域包括ケア推進課）— 24区共通。北区は行政区であり、独自の上乗せ給付は区公式の高齢者福祉ページを確認した範囲では見当たらない。

- **유형**: 給付券（現物交換）型。紙おむつ等と交換できる給付券を交付。
- **provider 表記**: `municipality`（基礎自治体＝大阪市。北区単独の制度ではない）

## 北区 독자 상조 여부

`06_kita-koreisha-kaigo-hoken.txt`（北区 高齢者福祉・介護保険）を確認した範囲では、紙おむつ・介護用品の区独自上乗せ給付は見当たらない。認知症予防・地域包括・介護保険申請様式などの案内が中心。よって本記事は**大阪市統一制度＋北区申請窓口**として扱う。

## 확인되지 않은 것

- 北区保健福祉センター内の「高齢者福祉」専用内線が代表番号と別途あるか（一覧PDFの福祉業務担当課番号以外）→ 06-6313-9857を福祉業務担当課として記載。フロア・窓口番号の細部は未確認。
- 行政オンラインシステムで介護用品給付のどの手続きまで電子申請可能か → 01本文は「一部の申請」とのみ。
- 東京都北区の紙おむつ支給とは別制度（混同注意）。本記事の regionCode は 27127（大阪市北区）。

## 전국공통 제도 배제

介護保険の住宅改修（居宅介護住宅改修）は全国共通のため本記事の単独テーマにしない（배치指示どおり）。
