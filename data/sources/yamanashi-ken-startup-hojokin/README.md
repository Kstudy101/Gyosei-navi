## 確定した事実
- 制度スキーム：山梨県 → （補助率：定額）→ 執行団体（補助事業者）→ （補助率1/2＋伴走支援）→ 起業者（間接補助事業者）
- ページの主目的：令和8年度の「執行団体」公募要領（応募資格・審査基準・応募書類等）
- 執行団体向け募集は「※募集は終了しました」と明記（受付期間は令和8年4月10日まで）
- 起業者（実際に創業する個人・法人）向けの募集は、今後執行団体側が別途行う想定だが、その募集ページ・詳細条件は本ページに記載なし
- 補助金交付規模：起業支援金分2,600万円＋伴走支援等事務費1,040万円（執行団体への交付総額の内訳）

## 確認されていないこと / 今後の再調査トリガー
- 令和8年度の執行団体がどこに決定したか、また起業者向けの二次募集要項・申請期間・支給額の上限等は本ページに記載がなく未確認
- 執行団体決定後、当該団体の公式サイトで起業者向け募集が別途行われる可能性がある。その場合は執行団体名・募集ページを新たに特定・原文取得する必要がある
- 記事化する場合は「起業者が直接申請できる制度」としてではなく、「県のスキームを理解した上で執行団体経由での間接補助」として正確に説明する必要がある（現時点では一次情報が不足し記事化不可）
