### 原文で確認できた事実（03、令和8年度＝2026年度）
- 執行団体（事務局）: 一般社団法人まちのtoolbox（山梨県から指定）
- 制度名: やまなし地域課題解決型起業支援金
- 補助率: 1/2以内、補助限度額: 2,000千円（最大200万円）
- 対象者: 山梨県内で新しく起業（個人事業開業または法人設立）する方、またはSociety5.0関連事業等の付加価値の高い産業分野で事業承継・第二創業を経て新事業を行う方。居住要件: 事業完了日までに山梨県に住民票があること
- 補助対象期間: 2026年4月1日〜2026年12月31日（事業完了日）
- 対象経費: 人件費、店舗・事務所等賃借料、設備費、原材料費、賃借料、知的財産権等関連経費、謝金、旅費、外注費、委託費、マーケティング調査費、広報費 など
- 優先採択: 先進的・革新的技術活用事業、観光関連分野の地域課題解決事業、ランドオペレーター、「リニアやまなしビジョン」分野など
- 採択予定: 13件程度。精算払（概算払なし）。メンタリング（伴走支援）付き
- 併給制限: 国・山梨県・(公財)やまなし産業支援機構の補助金等の対象事業は対象外
- 一次募集: エントリー6月11日17時まで（終了）
- 二次募集: エントリー6月27日〜7月12日17時必着（終了）。審査7/17書類・7/27プレゼン、8/8キックオフ、12/31事業完了、実績報告は翌1月8日まで、精算払は1月中旬〜2月中旬
- 注意: 03は民間法人ドメインだが県指定の事務局の公式募集ページ。募集要領PDFの原本は未取得のため、詳細要件（上記以外）は未確認
