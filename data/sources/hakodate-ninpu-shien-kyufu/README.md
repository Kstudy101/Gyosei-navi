## 確認できた主要事実（一次確認）

### 制度名
- **函館市妊婦支援給付金給付事業（出産応援給付金・子育て応援給付金）**（原文01）
- 令和7年4月から従前の「函館市出産・子育て応援給付金給付事業」が改正子ども・子育て支援法に基づく「妊婦のための支援給付」へ移行（原文01）

### 金額（原文01）
- 出産応援給付金: **妊婦1人あたり5万円**
- 子育て応援給付金: **お子さん1人につき5万円**

### 対象・手続（原文01）
- 出産応援: 妊娠届出または妊婦給付認定申請＋助産師・保健師等の面談
- 子育て応援: 出生届出後のこんにちは赤ちゃん訪問＋胎児の数の届出
- 申請: 市公式LINEまたは郵送、指定口座振込
- 給付対象者は妊産婦に限る
- 所得制限なし（FAQ）
- 胎児心拍確認後の流産・死産・人工妊娠中絶も対象

### 問い合わせ（原文01・03）
- 子ども未来部 母子保健課 TEL 0138-32-1533
