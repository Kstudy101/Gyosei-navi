# kitakyushu-untenmenkyo-josei

対象自治体: 福岡県北九州市（団体コード 40100／検査数字込み6桁 401005）
対象制度: 北九州市障害者自動車運転免許取得助成事業
所管: 北九州市保健福祉局障害福祉部障害者支援課

## 制度類型

**現金助成型（教習費用の一部助成）** — 教習開始前に申請→交付決定→教習・免許取得→請求。融資あっせん・現物支給ではない。

## 原文で確定した事実（01_gaiyo.txt + 02_chirashi.pdf）

| 項目 | 原文 |
|---|---|
| 制度名 | 障害者自動車運転免許取得助成事業 |
| HTML更新日 | 2026年4月1日 |
| ページ番号 | 000175086 |
| 対象免許 | 第一種普通自動車免許 |
| 助成額 | 実費の範囲内で上限5万円（チラシ・HTMLとも「5万円」） |
| 対象者① | 身体障害者手帳1〜4級、療育手帳、精神障害者保健福祉手帳のいずれかを所持する満18歳以上 |
| 対象者② | 助成申請時に市内居住、かつ助成確定時まで引き続き市内居住 |
| 対象者③ | 助成申請時までに自動車教習を開始していないこと |
| 対象者④ | 免許取得により就労等社会参加が見込まれること |
| 対象者⑤ | 他の制度から同種の助成を受けていないこと（チラシ） |
| 対象者⑥ | 市税を滞納していないこと（チラシ） |
| 対象者⑦ | 過去に本助成を受けたことがないこと（チラシ） |
| 対象者⑧ | 申請年度内に免許取得が見込まれること（チラシ） |
| 申請時期 | 自動車教習開始前（教習開始後・免許取得後は申請不可） |
| 申請窓口 | 各区役所 保健福祉課 高齢者・障害者相談係／電子申請可 |
| 申請時提出 | 見積書又はパンフレット等（費用額が分かるもの）、手帳の写し、住民票住所確認書類 |
| 請求時期 | 免許取得後1か月以内、または当該年度の3月31日のいずれか早い日まで（チラシ） |
| 請求時提出 | 請求書、請求内訳書、領収書、免許証の写し（チラシ） |
| 問合せ | 障害者支援課 TEL 093-582-2424／FAX 093-582-2425 |
