## 제도 유형 분류

- **현물지급형(이용권/타이켓 방식)** — 택시요금 할인이 아니라 1매당 정액 조성되는 회수권(이용권) 12매철을 연 1책 지급. 도쿄 시나가와구의 500円券/100円券 조합형과 달리, 히로사키시는 **매수(12매)만 확인되고 1매당 금액은 원문에 없음**.
- 예산제약형 요소: 추가교부(1회 한정)에는 "予算の範囲内において" 문구가 있어 예산 소진 시 추가교부가 제한될 가능성 있음. 다만 이는 최초 교부가 아닌 추가교부에 한정된 조건.

## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **이용권 1매당 금액**(할인/조성 단가) — 원문에 전혀 언급 없음. 다른 시정촌 사례(시나가와 500円/100円)를 유추 적용하지 말 것.
- **소득제한의 구체적 기준액**(본인/부양의무자 소득 등) — "소득제한이 있다"고만 명시, 금액 기준 없음.
- **정신장애자보건복지수첩 소지자의 대상 여부** — 원문에 언급 없음. 愛護手帳A 또는 身体障害者手帳1・2級만 명시되어 있어, 정신장애자수첩은 대상에서 제외되는 것으로 보이나 원문에 "제외"라는 명시적 문구는 없어 단정 표현은 피할 것("정신장애자수첩 소지자에 대한 언급이 원문에 없음"으로 서술 권장).
- **愛護手帳 B 판정자, 身体障害者手帳 3級 이하 소지자의 대상 여부** — 원문상 A판정・1〜2급만 대상으로 읽히나, "제외"라는 명시적 부정문은 없음.
- **원문 갱신일자** — 페이지 내 표시 확인 안 됨.
- **접수기간/募集期限** — 페이지에 상시제도로 보이는 서술만 있고 募集期限·予算到達 종료 공지는 확인 안 됨（단, 추가교부는 예산 범위 내로 제한되는 문구 있음 — 위 참조）.
- **신청서식 다운로드 페이지, 별도 안내 PDF** — 이 페이지에서 링크 확인 안 됨（"上記リンク"는 행정사무 표준문자 안내에 관한 것으로 본 제도와 무관）.
- **이용 가능 택시회사 명단** — "이용권 뒷면에 기재"라고만 되어 있고 목록 페이지 확인 안 됨.
