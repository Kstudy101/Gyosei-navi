## topic-scout事前調査との差異チェック

topic-scout事前調査note：「徳島市公式サイトに専用ページあり。既存published記事との重複なし（徳島県初）」という記載のみで、金額・期間等の具体的数値の事前調査はなし。原文で新たに確認した内容は以下の通り：

- 補助率・上限額は申込み区分（A/B/C）で異なり、区分Cが最も手厚い（30％・上限30万円、移住・中心市街地定住者向け）。
- **重要**：取得日（2026-09-22）時点で、ページ冒頭に「追加募集は予算の上限に達しましたので受付を終了します」と明記されている。また「今年度の事前申込み受付は終了しました」（L232）とも記載。つまり事前申込み（新規の応募窓口）は既に終了しており、現在進行中なのは、既に事前申込み・抽選を経た当選者向けの「本申請（LoGoフォーム、6/8～9/30）」と「実績報告（7/1～翌3/1）」の手続きのみ。
- 記事化する場合、「現在は新規募集を行っていない（既に予算上限に達し受付終了）」旨を明確に記載する必要がある。次年度以降の募集再開見込みは原文に記載なし。
