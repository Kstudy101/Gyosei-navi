## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 소득할액 기준에 대응하는 정확한 연수 목안은 모델케이스(保護者のうち一方が働き、高校生1人・中学生1人の4人世帯)에 기반한 참고값이며 실제 판정은 개별 과세증명서로 결정
- 사립고등학교의 급부금 제도는 별도 제도·별도 창구(본 원문에 미기재)
- R8년도 조기급부(새 입학생 대상)의 수부는 이미 종료 확인됨（「令和8年度分の受付は終了しました」）
