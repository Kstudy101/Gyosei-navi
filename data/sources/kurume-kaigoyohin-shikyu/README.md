## 제도 유형 분류

**給付券型（定額）** — 紙おむつ購入費の一部を月額3,000円の介護用品給付券で助成。北九州市のおむつ給付（要介護度別限度額＋原則10％自己負担の現物配達）とは設計が異なる。

## 調査中に確認した別制度（本記事対象外）

- **家族介護慰労金の支給**（`03_iroukin-ref.txt`）: 要介護4・5を家族がほぼ介護保険サービスを使わず1年以上在宅介護した場合、上限年12万円。別記事候補。
