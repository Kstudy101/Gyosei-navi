## 確認済み事項（原文より）

### 創業支援資金（融資・利子補給）— 01_main.txt
- 対象: 事業を営んでいない個人が市内で創業する、又は創業して5年を経過しない中小企業者（分社・廃業後5年未満含む）。個人は市内居住・市内事務所（見込み含む）・市民税完納
- 資金使途: 運転資金・設備資金（運転資金でのみ借換可）
- 融資額: 500万円以内（特定創業支援等事業修了者は1,000万円以内）
- 融資期間: 5年以内（特定創業支援等事業修了者は10年以内、1年以内据置可能）。元金均等月賦返済
- 利率: 年1.4%（基準金利年2.37%のうち市利子補給率0.97%）
- 保証料率: 0.23%または0.68%（創業関連保証・再挑戦支援保証）／0.28%または0.83%（スタートアップ創出促進保証）
- 申請: 産業振興課へ必要書類持参。経済局商工部産業振興課経営支援係 054-354-2232（清水庁舎5階）
- ページ更新日: 2026年9月1日

### 保証料補助 — 02_hoshorryo-hojo.txt
- 原則: 保証料の25%軽減（平成28年4月1日以降に市で受け付けた融資が対象）
- 75%補助: 特定創業支援等事業の修了者（支援証明書発行対象者・創業後5年未満）ほか被表彰者・認定企業等
- 問い合わせ: 産業振興課経営支援係 054-354-2058
- ページ更新日: 2026年4月16日

### 特定創業支援等事業 — 03_tokutei-sogyo-shien.txt
- 定義: 「経営・財務・人材育成・販路開拓」の知識習得が見込まれる継続支援（原則4回以上かつ1ヶ月以上）
- 特典（証明書発行時）: 登録免許税軽減／創業関連保証の特例／保証料75%補助／創業支援資金の融資額・期間拡充（5年以内・500万円以内→10年以内・1,000万円以内）／日本政策金融公庫の利率引下げ対象
- 問い合わせ: 産業政策課企画係 054-354-2185
- ページ更新日: 2025年5月23日
