## 確認事項

### A. 基本枠「秋田県奨学金返還助成制度」(01,02,03,04,06)
- 目的: 県指定の奨学金の貸与を受けた者に、県内就職後の返還額を助成し若年層の県内定着・人材確保を図る(01,06第1条)。
- 対象者(02,06): 令和7年4月1日以降に民間企業に就職した、ほぼ全員。募集人数の制限なし。正規雇用に限らず契約社員・アルバイトも対象。新卒に限らず中途退学者・一定要件の既卒者も可。公務員(国・地方、会計年度任用職員含む)、独立行政法人・国公立大学法人等の正規雇用者は対象外(06第3条2項。正職員給与表適用外の非常勤等は除外対象から除く旨の但書あり)。定住の意思を持って県内に住所を有すること。
- 県内就職の定義(06第2条): 県内に本社機能のある企業等に雇用／県外企業で主たる勤務地が県内／県外企業に雇用され県内居住でリモート勤務／県内で起業・農林漁業等従事。
- 対象奨学金(02,08別表): 日本学生支援機構、秋田県育英会、母子父子寡婦福祉資金貸付金(修学資金)、生活福祉資金貸付金(教育支援費に限る)、市町村奨学金等(08別表に県内市町村・育英会等の一覧、県外は宇都宮市・角田市・青森県育英奨学会・岩手育英奨学会・東京理科大学等が記載。他県の市町村・育英会等は個別相談と注記)。貸与期間の制限なし(令和6年度から2年未満も対象に拡充と08に記載)。
- 助成額(06): 一般分 助成率2/3、1年分の上限13万3千円(千円未満切捨て)。特定業種認定企業等に雇用され、別に定める学科(理学・工学・農学・保健系の大学・大学院卒等)・外国語資格・高専工業学科等の要件に該当する者は未来創生分 助成率10/10、上限20万円/年(06第6条, 04, 05)。
- 助成期間(06第4条): 奨学金貸与期間が2年未満なら12か月、2年以上3年以内なら24か月、3年超は36か月(12か月単位)。01・02の見出しにある「最大3年間60万円」は、3年×上限20万円の未来創生分の最大値(60万円)に対応。一般分の上限は13万3千円×3年=39万9千円(計算値。原文に総額の明記は未確認)。約定利息含む・延滞金含まず。複数の奨学金がある場合は1つのみ対象。
- 手続(02,03,06): 認定申請(様式第1号ほか)を移住・定住促進課 県内就職者奨学金返還助成担当へ郵送 → 認定通知 → 認定通知書裏面の期間内に交付申請(在職証明書、住民票(3か月以内・マイナンバー記載なし)、返還額証明書等)。JASSは返還額証明書の入金期間を指定して申請。
- 認定申請の受付期間(02): **令和8年4月1日〜令和9年2月20日(消印有効)**。提出先 〒010-8570 秋田市山王四丁目1番1号 秋田県 移住・定住促進課 奨学金返還助成担当。
- 年度: 令和8年度版(02)、要綱は令和8年4月1日改正(01,06)。
- 特定業種5分野(04,05): 航空機・自動車・医療福祉機器・情報・新エネルギー。該当企業一覧は令和8年9月4日更新(05)。
- 問合せ先(17): 人口戦略部 移住・定住促進課 TEL 018-860-1248 / FAX 018-860-3871(02のページ末尾。topics-db記載と一致)。特定業種の確認申請は iju@pref.akita.lg.jp(04)。

### B. あきた企業連携型奨学金返還助成制度(07,10,11,13,14)
- 位置づけ: 令和6年度開始。大学卒相当以上(大卒者等)対象(01,13)。
- 対象者(13,10): 県内就職日以降に別表1の奨学金を返還予定/中の者で、(ア)令和7年度以降に大学等を卒業・修了し令和8年4月1日以降に県内居住、(イ)令和6年度以前卒業で通算1年以上県外居住し令和8年4月1日以降に県外から県内転入、のいずれかに該当し定住の意思を持つこと(10にはウとしてAターン希望登録済みで令和6年4月1日以降に県内居住、も記載。13本文には無く、10と13で記載差あり)。令和8年4月1日以降に登録企業(別表2)に正規雇用され、6年以上継続就業の意思があること。公務員等は対象外。他の返還支援制度との併用予定がないこと(県内市町村の連動支援は除く)。正規雇用=期間の定めのない契約・通常労働者と同一の所定労働時間・長期雇用前提の待遇(13)。
- 助成額(13): 最大120万円(上限20万円/年×最大6年)、年返還額の10/10、千円未満切捨て、約定利息含む・延滞金含まず。返還期間が3年なら3回、12年なら6回(最大6回)。年払い。
- 企業の負担(14 取扱要領第5): 登録企業等が助成対象者の年間返還額(10/10、上限20万円)に対し負担。中小企業1/3(最大40万円)、大企業1/2(最大60万円)、特定企業3/4(最大90万円)、助成は最大6年。企業は寄附申出書で申込み、県発行の納付書で単年度ごとに納入。「特定企業」の定義は14の抜粋範囲では未確認。
- 登録企業の登録: 年度ごとに県へ登録申請(11)。締切は該当者の就職年度の2月20日(14第2、6条4項該当の場合)。登録企業は令和8年度採用分で令和7年8月1日時点123社(16)。kocchake上では令和10(2028)年度就職者向け登録企業一覧が2026-09-01に更新(07)。
- 募集期間(13,10): **令和8年4月1日(水)〜令和9年2月20日(土)消印有効**、募集人員上限なし。
- 手続(13): 申請者は所属する登録企業経由で県に提出(認定申請: 様式第7号・第8号、奨学金証明書、卒業証明書、住民票)。翌年度以降、毎年10〜11月頃に交付申請(最大6回)。助成金は県から本人口座へ直接振込。
- 年度: 令和8(2026)年度採用者向け募集要項(13)。2027・2028年度就職者向けページも別途あり(07。内容は未取得)。
- 問合せ先(13): 人口戦略部 移住・定住促進課 調整・県内定着促進チーム TEL 018-860-3751 / iju@pref.akita.lg.jp。基本枠(018-860-1248)と番号が異なる点に注意。
