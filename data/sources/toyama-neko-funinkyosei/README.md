## ⚠️ 원문에서 확인되지 않은 것

- **富山市를 제외한 이유**（富山市가 별도 자체 제도를 운영하는지 여부）는 이 페이지에서 언급 없음 — 富山市 자체 고양이 불임거세 보조사업 유무는 이번 조사 범위(県페이지 1건)에서 확인되지 않음(불명, 별도 municipality 조사 필요).
- 연간 예산 총액, 두수 상한(1인당/町内会당 신청 가능 두수 제한)은 원문에 명시되지 않음 — 관련 PDF(교부요강)를 다운로드하면 확인 가능할 수 있으나 이번 조사에서는 미취득.
- 개(犬)에 대한 유사 조성 제도는 이 페이지에 없음 — 별도 페이지 존재 여부는 미확인.
- topics-db 메모의 "예산의 범위 내에서 선착순 종료 가능성"은 원문과 일치("予算の範囲内での補助…申請状況によっては補助終了となることがあります")하여 확인됨.
