## 제도 유형 분류

現物給付／現金給付混在型（費用助成型）。個々の用具ごとに市が定めた「基準額」を上限として、購入費の実費（原則1割自己負担）を助成する仕組み。事前相談・申請が前提で、予算消化型の先着受付とは明記されていない（要件判定型に近い）。ストマ装具・紙おむつは月額上限方式（継続的な消耗品扱い）、特殊寝台・住宅改修等の耐久品は個別購入時の一括助成方式という2つのサブタイプが同一制度内に混在している点に注意。
