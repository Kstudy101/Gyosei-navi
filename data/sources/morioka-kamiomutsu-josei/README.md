# 盛岡市「在宅要介護高齢者紙おむつ助成事業」（紙おむつ助成券交付）

## 制度概要（分類）
- **制度種別**: 助成券交付型（現金給付ではなく、月1枚・額面3,000円の助成券を交付し、市登録の取扱事業者で紙おむつ等と引換える方式）
- **所管**: 盛岡市 保健福祉部 長寿社会課（〒020-8530 盛岡市内丸12-2 盛岡市役所本館5階、電話019-603-8003）
- **申請窓口**: 長寿社会課へ郵送または窓口申請（締切日必着）

## 確認できた最終数値・条件（01・02で一致確認）

### 対象者の要件（すべて満たす必要あり、01本文）
1. 盛岡市の介護保険被保険者で、市内に住所を有する65歳以上の方
2. 次の施設のいずれにも入所していない: 地域密着型介護老人福祉施設／介護老人福祉施設／介護老人保健施設／介護医療院／特別養護老人ホーム
3. 申請日において医療機関に入院していない方
4. 次のいずれかに該当:
   - (1) 1日中ほとんど床に伏している状態が6月以上継続、または今後6月以上継続見込み
   - (2) 心身の障害または疾病等により失禁の状態が6月以上継続、または今後6月以上継続見込み
5. 申請者本人及び同居者の前年分（1〜5月の申請は前々年分）所得に係る市県民税が非課税
6. 生活保護法による保護を受けていない
7. 中国残留邦人等支援給付を受けていない
8. **要介護状態区分が要介護3、要介護4または要介護5**（依頼文にあった「要介護3以上」と一致）
   - **要介護3の方のみ、認定調査票の「排尿」または「排便」の項目が「介助」または「見守り等」に該当する場合に限る**（要介護4・5にはこの追加条件の記載なし＝要介護4・5は排尿排便要件を問わず対象と読める。依頼文の「要介護3以上・排尿排便介助を要する場合に限定」という要約は不正確で、正確には「排尿排便条件が付くのは要介護3のみ」）
9. 介護保険料を滞納していない
10. 他の制度等により紙おむつに係る給付を受けていない

### 助成対象品目（01本文）
フラット型紙おむつ／テープ止め型紙おむつ／パンツ型紙おむつ（リハビリパンツ含む）／尿とりパッド

### 助成券の内容（01本文）
- 交付枚数: 1人につき**月1枚**
- 助成券の額: **3,000円**（消費税・地方消費税込み）
- 3,000円未満の額で使用する場合は使用額が助成額（差額は返還されず、次回への充当も不可）
- 額面を超えた分は自己負担
- 市登録の取扱事業者に提出し、有効期間内に額面金額を限度として引換え
- 譲渡・換金・転売・貸付・担保提供は禁止

### 申請方法・必要書類（01本文）
- 申請者: 対象者本人または家族
- 年度ごとに交付申請が必要（毎年度の更新申請）
- 必要書類: 「盛岡市在宅要介護高齢者紙おむつ助成事業利用申請書及び同意書」（様式第1号）
- 申請締切: **毎月15日**（15日が閉庁日の場合は次の開庁日）。郵送可（締切日必着）
- 必要書類の不足・記入漏れがある場合は受付不可、締切までに整わない場合は翌月扱いになることがある
- 審査後、承認・不承認を通知

### 資格喪失の届出が必要なケース（01本文）
1. 受給者が死亡したとき
2. 受給者が引き続き1月を超えて医療機関に入院したとき
3. 上記「対象者の要件」を満たさなくなったとき
