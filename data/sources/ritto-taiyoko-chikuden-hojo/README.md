# ritto-taiyoko-chikuden-hojo

対象記事候補: 栗東市「住宅用太陽光発電システム等の設置補助について」（滋賀県）

## 制度の性質に関する重要な注記

栗東市の本制度は独立した市単独補助ではなく、**滋賀県が公益財団法人淡海環境保全財団（滋賀県地球温暖化防止活動推進センター）に委託実施している「スマート・ライフスタイル普及促進事業補助金」の「基本対策推進事業」（太陽光発電システム・蓄電池分）に対する上乗せ補助**である。
栗東市原文に「本補助金は、滋賀県が実施している淡海環境保全財団スマート・ライフスタイル普及促進事業補助金（以下、「財団補助金」）「基本対策推進事業」のうち、太陽光発電システム・蓄電池について上乗せ補助をするものです。」と明記されている（01_ritto-taiyoko-chikuden-hojo.txt L31）。
申請順序も「県（財団）補助金の交付決定通知を受け取った後に、市の補助金を申請」という順で、県制度への申請が前提条件になっている（同 L33, L97）。
記事化する際は「栗東市が県のスマート・ライフスタイル普及促進事業補助金に独自で上乗せする制度」であることを明確にし、県の基本対策推進事業（太陽光=定額4万円、蓄電池=定額5万円）と栗東市上乗せ分（太陽光=1kWあたり1.5万円・上限4万円、蓄電池=一律5万円）を合算した実質補助額を示すと正確な記事になる。

## 制度の関係整理（合算した場合の実質補助額の目安）

栗東市在住者が太陽光発電システムを新設し、栗東市の要件（施工令和8年4月1日〜令和9年1月31日、市内施工業者）を満たして県・市両方の交付を受けた場合の原文ベースの積み上げ：

- 太陽光: 県・基本対策推進事業（定額4万円、HEMS等の併設条件あり）＋栗東市上乗せ（1kWあたり1.5万円・上限4万円）
- 蓄電池: 県・基本対策推進事業（定額5万円）＋栗東市上乗せ（定額5万円）

ただし基本対策推進事業の太陽光4万円は「HEMS購入または他の対象設備設置」が条件になっており、太陽光単体設置のみでは県側の基本対策推進事業の対象外になり得る点に注意（02_ohmi-r8smart-life.txt L291）。記事化時はこの条件を明記する必要がある。
