## 確定した制度内容（原文根拠あり）

### 対象者
ページ本文（`01_taxi.txt`）と要綱条文（`02_yoko.txt` 第2条）で表現に差があるため両方併記する。

**ページ本文（簡略表記）**:
- 身体障害者手帳の肢体不自由及び視覚障害者の1級又は2級を所持している方
- 療育手帳の程度区分「A」を所持している方
- 要介護老人（非課税世帯で介護慰労金の支給を受けている方に介護されている方）
- 施設入所者、自動車税・軽自動車税の減免を受けている方は対象外

**要綱第2条（詳細条文）**:
- 身体障害者手帳交付者で、肢体不自由・視覚障害の1級/2級、または腎臓機能障害1級かつ人工透析を通院で行っている自立支援医療受給者証所持者
- 療育手帳交付者でAに該当する者
- 要介護老人（非課税世帯で介護慰労金の支給を受けている者に介護されている者）
- 除外: 各種福祉法に基づく施設入所措置者（通所除く）、自動車税・軽自動車税減免者、山梨県心身障害者自動車燃料費助成事業の助成を受けた者

→ ページ本文は要綱の「腎臓機能障害1級＋人工透析」要件を省略した簡略版。記事化時は要綱の詳細条文を優先すべき。

### 助成内容
- 助成券1枚650円分（要綱第5条：1回の利用につき650円）
- 月3枚、年36枚を上限に交付（ページ本文）
- 要綱第5条第2項：交付枚数＝交付決定日の属する月から年度末3月までの月数×3
- 助成券の有効期限は交付の日の属する年度（要綱第5条第3項）
- 運賃との差額は利用者負担（要綱第6条から読み取り）

### 申請方法
- 重度心身障害者（児）等タクシー利用料金助成券交付申請書で毎年市長に申請（要綱第3条）
- 用紙は本庁福祉課窓口・各支所地域市民課窓口、またはホームページ「障害福祉関連」からダウンロード可
- 申請には手帳と印鑑を持参

### 制度の現行性
要綱の沿革を確認したところ、最新改正は**令和6年3月27日告示第23号（令和6年4月1日施行）**であり、2026年9月現在も廃止・改正の記録なく現行制度と判断できる。一方、案内ページ自体の更新日は「2011年6月24日」のままで、令和6年改正の内容（何が変わったか）がページ本文に反映されているかは本文からは判別できない。

## 記事化可能性の判断

**条件付きで可能**。要綱原文で制度の骨格（対象・助成額・上限枚数・申請方法）は確認できるが、次の点に注意が必要:
- 案内ページの更新日が2011年であり、令和6年改正の具体的な変更点（対象拡充か、様式変更か等）が本文から読み取れない。記事では「現行の要綱に基づく制度」として要綱の条文を根拠に書き、ページの古い更新日はそのまま使わない方が安全。
- 甲府市（740円/枚・月2枚+追加交付・視覚障害3〜6級まで対象拡充）と比べて、北杜市は650円/枚・月3枚・視覚障害は1〜2級のみと対象範囲が狭い。この違いは比較記事の切り口になる。
