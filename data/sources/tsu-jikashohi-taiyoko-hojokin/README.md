## 核心数値（原文対照）

出典は特記なき限り `01_main.txt` および `02_r8youkou.txt` 第6条・`03_r8tebiki.txt`。

| 項目 | 原文の記載 |
|---|---|
| 正式名称 | 津市自家消費型家庭用太陽光発電設備等設置費補助金 |
| 対象者 | 津市内で自ら所有し居住する住宅の屋根等に太陽光発電設備等を設置する者 |
| 回数制限 | 住宅1戸に1回、かつ1者に1回（要綱第6条第3項） |
| 太陽光補助額 | 最大出力値（モジュール公称最大出力合計とパワコン定格出力合計の低い方、小数点以下切捨、10kW限度）×（70,000円/kW と 1kW当たり価格（工事費込・税抜）の低い方）。千円未満切捨 |
| 蓄電池補助額 | (1)1kWh当たり価格<=155,000円: 価格×1/3（定格>10kWh時は×10/定格）。(2)>155,000円: 定格（10kWh限度）×155,000×1/3。千円未満切捨 |
| 蓄電池条件 | 導入する太陽光の附帯設備として同時導入必須。定格容量20kWh以下。SII登録のZEH化等支援事業対象機器＋市の蓄電池仕様 |
| 受付開始 | 令和8年6月1日（月）から先着順。予算無くなり次第終了 |
| 事業完了・実績報告 | 令和9年1月29日（金）までに事業完了かつ実績報告書提出 |
| 事前申請 | 交付決定前の工事請負契約は対象外。契約締結日の10日前までに申請（要綱第7条） |
| 自家消費 | 発電量の30%以上を申請住宅の敷地内で自家消費 |
| FIT/FIP | 認定を受けての売電は不可（相対契約による余剰売電は可・Q2） |
| 他補助金併用 | 対象設備について国・他地方公共団体の補助金等との併用不可（経費区分が明確な別設備は例外・Q3） |
| 問い合わせ | 環境部 環境政策課 地域脱炭素推進担当 / 059-229-3212 |
