### 利用上限
根拠: `02_sango-care-ryokin.txt` 79-103行目、`03_sango-care-gaiyo-pamphlet.pdf` 1ページ目
- 1回の出産につき「宿泊型」「日帰り型」「訪問型」を通算して**7回（7日）まで**
- 宿泊型の連泊は**3泊4日まで**
- 訪問型は上限**3回まで**（早期型は1回。※「早期型」の定義は原文からは詳細不明。「早期型」という語は02ファイルの一覧表81-83行目にのみ登場し、詳細説明は見当たらない → **未確認**）
- ケアの種類に関係なく、通算5回まで1回最大2,500円分の減免あり（6・7回目は減免なし）
- 多胎児の場合も利用料金は変わらない（`03_sango-care-gaiyo-pamphlet.pdf` 1ページ目）
- 産婦のみの利用可（赤ちゃんのみの利用は不可）

### 申請方法
根拠: `01_sango-care-gaiyo.txt` 51-65行目、`03_sango-care-gaiyo-pamphlet.pdf` 2ページ目のフロー図
- 利用前に申請が必要（サービス利用は出産後のみ申請可能）
- 電子申請フォーム（利用申請フォーム）または二次元コードから申請。1回ごとに申請必要（2回目以降は住所等省略可）
- 利用開始希望日は申請日の**2週間先以降**の日付を指定（お急ぎの場合は質問欄に記載、直近日は希望に添えないこともある）
- 妊娠中の事前相談は**妊娠32週以降**から、相談フォームまたは二次元コードで申込可能（ただし申請自体は出産後のみ）
- 電子申請が難しい場合は地域保健センターに電話相談可
- 承認までの流れ: 相談・申請 → 保健師から連絡 → 地域保健センターが希望施設の日程調整 → 「川口市産後ケア事業利用承認通知書」交付（申請から約1週間程度、急ぎ希望は別途対応）→ 利用時に承認通知書・事業アンケート・利用料金（自己負担分）を施設へ提出
