## 確認できた情報

- 正式名称: 「結婚・妊娠・共育ての相談機会提供・支援プログラム」（旧称：結婚新生活支援事業）
- 根拠制度: こども家庭庁「地域少子化対策重点推進交付金」を活用
- 対象世帯（5要件すべて満たすこと）:
  1. 令和8年1月1日から令和9年3月31日までに入籍
  2. 夫婦の所得合計500万円未満（奨学金返還額は控除可）
  3. 夫婦ともに婚姻日時点で39歳以下
  4. ライフデザイン支援講座・プレコンセプションケア講座・医療機関への妊娠出産相談・共家事共育て講座のいずれか1つを交付決定年度内に夫婦ともに実施
  5. その他お住まいの市町村が定める要件
- 対象費用: 新居の住宅費（購入費・家賃・敷金礼金・共益費・仲介手数料）、新居のリフォーム費用、引越費用
- 補助金額:
  - 夫婦ともに29歳以下: 1世帯あたり上限60万円
  - 夫婦ともに39歳以下: 1世帯あたり上限30万円
- 令和8年度実施市町村（35市町村）: 山形市・米沢市・鶴岡市・酒田市・新庄市・寒河江市・上山市・村山市・長井市・天童市・東根市・尾花沢市・南陽市・山辺町・中山町・河北町・西川町・朝日町・大江町・大石田町・金山町・最上町・舟形町・真室川町・大蔵村・鮭川村・戸沢村・高畠町・川西町・小国町・白鷹町・飯豊町・三川町・庄内町・遊佐町
- 申請先: 各実施市町村
- 問い合わせ: しあわせ子育て応援部多様性・女性若者活躍課（TEL: 023-630-2727）
