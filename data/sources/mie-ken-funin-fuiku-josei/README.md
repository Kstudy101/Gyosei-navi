## 要点（02より）
1. 先進医療助成: 先進医療費の70%、上限5万円。妻43歳未満（治療開始日）。県内29市町 + 四日市市・伊賀市は独自事業内で助成
2. 回数追加（保険適用回数終了後）: 治療A,B,D,E 上限30万円/回、C,F 上限17.5万円/回、保険適用・PGT-A助成と合算して1子あたり8回まで。29市町
3. PGT-A含む治療（R7.4〜）: 妻35歳以上43歳未満、体外受精等2回以上不成功または流産2回以上（染色体構造異常を除く）、上限は2と同額、1子6回まで、保険+2の合算8回以上は対象外。23市町
4. 不育症治療費助成: 実施は各市町規定、県から市町へ補助率1/2（上限5万円）。29市町（R8.1現在）
5. 窓口・金額詳細は市町ごとに異なる（原文明記）。県担当: 子どもの育ち支援課母子保健班 059-224-2248

## 要点（05より：県直接実施）
- 対象: 申請時三重県在住、2回以上の流産・死産既往（年齢・所得要件なし）
- 対象検査: 流死産検体遺伝子検査1、抗ネオセルフβ2GPI複合体抗体検査、流死産検体遺伝子検査2。実施日: 各 R4.12.1 / R7.5.31 / R8.4.30 以降のもの
- 助成額: 検査費用の7割（千円未満切捨、上限6万円）。市町助成を受けた分は控除
- 申請期限: 検査終了日の属する年度内（3/1〜3/31終了分は翌年度4月末日まで）
- 窓口: 県子どもの育ち支援課母子保健班へ郵送または持参（市町・保健所は受付不可）
- 必要書類: 第1号様式、第2号様式（医療機関証明）、領収書写し、住民票（マイナ番号なし・3か月以内）
