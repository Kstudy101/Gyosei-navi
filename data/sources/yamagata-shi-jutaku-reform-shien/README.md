## 確認できた情報
- 金額（市補助タイプ）: 「工事に要する経費(消費税抜き)の50％（20万円限度：千円未満切捨て）」
- 金額（県市補助タイプ・一般世帯）: 「工事に要する経費(消費税抜き)の20％（24万円限度：千円未満切捨て）」
- 金額（県市補助タイプ・移住/新婚/子育て世帯）: 「工事に要する経費（消費税抜き）の33％（30万円限度：千円未満切捨て）」
- 加算: 別表1「1-1」該当工事は補助限度額に20万円加算、「1-3」で基準点10点以上は10万円加算
- 所得制限（市補助）: 「世帯（同居親族）の中で最も収入の多い方の所得額が400万円以下であること」
- 対象者: 山形市民でリフォーム工事を行う住宅または空き家バンク登録空き家の所有者（二親等までの親族を含む）、市税等を滞納していない方
- 対象工事費下限: 「5万円以上の工事」
- 申請受付（市補助第1回）: 「令和8年4月20日（月曜）～4月24日（金曜）」
- 申請受付（市補助第2回）: 「令和8年6月15日（月曜）～6月19日（金曜）」
- 申請受付（県市補助第1回）: 「令和8年5月25日（月曜）～5月29日（金曜）」
- 申請受付（県市補助第2回）: 「令和8年7月13日（月曜）～7月17日（金曜）」
- 実績報告期限: 県市補助タイプ令和9年1月29日、市補助タイプ令和9年2月19日
- 申請先: 「市役所9階 901会議室」（郵送不可）
- 接受状況: 令和8年7月22日更新時点「県市補助第2回は補助予定額を下回る申込件数であったため抽選なし、申込者を補助予定者と決定」
- 施工業者要件: 「山形県内に本店を有し、山形市内に事業所、支店又は営業所を有する法人又は個人」
