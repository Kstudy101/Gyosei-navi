## 原文根拠表（原文で確定した事実）

| 項目 | 原文値 | 根拠 |
|---|---|---|
| 制度名 | 岡山市創業促進助成金 | 01 / 04 p.1 |
| 目的 | 創業機運の醸成・創業促進による産業活性化 | 01 |
| **対象者条件①** | 岡山市より特定創業支援等事業の支援を受けたことについての証明を受けた方 | 01 / 04 |
| **対象者条件②** | 新たに株式会社または合同・合名・合資会社を設立し、登記上の本店所在地を市内に置き、その代表となる方 | 01 / 04 |
| **対象者条件③** | 設立日が証明の発行日以降であること | 01 / 04 |
| **設立時期** | 令和8年4月1日〜令和9年3月31日の間に岡山市内で会社を設立 | 04 p.1 |
| **助成額（株式会社）** | 10万円（1社） | 01 / 04 |
| **助成額（合同・合名・合資会社）** | 5万円（1社） | 01 / 04 |
| **複数設立時** | 最初に立ち上げた1社のみ対象 | 04 p.4 |
| **募集期間** | 令和8年4月1日〜令和9年3月31日（郵送は3月31日必着） | 04 p.1 |
| **予算到達** | 予算の上限に達した場合は年度途中でも受付終了 | 04 p.1 |
| 提出先 | 創業支援・雇用推進課（startup@city.okayama.jp）、e-mail・郵送・持参可 | 01 / 04 |
| **創業促進特別資金融資 限度額** | 500万円 | 02 |
| **創業促進特別資金融資 金利（当初1年）** | 年0％（変動型） | 02 |
| **創業促進特別資金融資 金利（2年目以降）** | 年1.19％ | 02 |
| **創業促進特別資金融資 保証料率** | 年0.7％ | 02 |
| **創業促進特別資金融資 融資期間** | 10年以内（据え置き1年以内を含む） | 02 |
| **創業促進特別資金融資 制度開始** | 令和7年6月1日 | 02 |
| **創業促進特別資金融資 対象者** | 特定創業支援等事業の支援を受け、6か月以内に開業予定または開業後1年以内 等 | 02 |
| **同時申込** | 創業資金融資との同時申込は不可 | 02 |
| 旧制度 | 令和5年度をもって「岡山市創業者支援事業補助金」は終了 | 01 |
