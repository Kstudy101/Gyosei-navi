### 申請期限（令和8年度）
- 定期給付: **令和8年12月15日（火）**
- 一部早期給付: **令和8年9月15日（火）**
- 家計急変（7月1日以前）: 令和8年9月30日（水）
- 家計急変（7月2日以降）: 令和9年1月29日（金）

### 申請方法
- 原則オンライン申請（スマートフォン・パソコンから手続き可）
- 家計急変の場合のみ書類申請

### 対象者（主な要件）
- 宮崎県内に住所がある保護者等の子が私立高等学校等（就学支援金対象校）に在学
- 上記所得区分に該当する世帯
