## 核心数値（原文対照）

出典は特記なき限り `01_zaitaku-fukushi.txt` の「津市障害者等交通サービス支援事業」節。

| 項目 | 原文の記載 |
|---|---|
| 正式名称 | 津市障害者等交通サービス支援事業 |
| 目的・内容 | 在宅で通院、通学のため、タクシー、自家用車、公共交通機関等を月1回以上利用している対象者に対し助成 |
| 助成額 | 1回につき1,000円（月4回4,000円を限度） |
| 対象者 | 身体障害者手帳1級および2級（単体の等級で）／療育手帳A1（最重度）、A2（重度）／精神障害者保健福祉手帳1級および2級 |
| 所得等条件 | 所得税非課税の人で、視覚障害者タクシー料金助成を受けていない人に限る。障がいのある児童については、保護者が所得税非課税の人に限る |
| 回数の除外 | 特別支援教育就学奨励制度の通学に要する交通費の支給を受けているときは、当該通学費にかかる通学は回数に参入できない |
| 申請 | 事前の申請が必要。医療機関の領収書〔本人の氏名が記載されたもの〕（ないときは医療機関の証明書）または学校などに通学していることがわかる書類（学生証等）を持参 |
| 申請時期注記 | 手帳の等級が確定した月以降の申請。申請月の翌月からが対象 |
| 問い合わせ | 健康福祉部 障がい福祉課 障がい福祉担当（電話：059-229-3157／ファクス：059-229-3334） |
