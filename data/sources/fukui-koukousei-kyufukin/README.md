## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 원문의 "令和8年度給付額" 표는 판정연도(令和8年7月1日 현재)를 기준으로 한 것으로 보이나, **실제 신청・지급이 이루어지는 시점(정확한 월/일)에 대한 구체적 스케줄표는 원문에 "9月頃 안내"라고만 명시**되어 있고 정확한 접수 마감일은 원문에 없음 — 기사에서 "○月○日까지"로 단정하지 말 것.
- 사립고 재학자에 대한 구체적 급부액・절차 차이는 원문에 명시되어 있지 않고 "大学私学課에 문의"로만 안내됨 — unresearched.
- 정시제/통신제의 4회 상한이 적용되는 구체적 학년 구성(유급 등 예외 케이스 처리)은 원문에 언급 없음 — unresearched.
- 가계급변 인정 시의 구체적 소득 산정방법・필요서류는 원문에 없음 — unresearched.
- 이 페이지의 "최終更新日 2024年3月15日"과 본문 속 "令和8年度" 수치 사이에 갱신 시차가 있을 수 있으므로, 기사 게재 전 재확인 권장(단 npm run source로 취득한 2026-09-22 시점 원문 자체는 令和8年度 수치를 명기하고 있음).
