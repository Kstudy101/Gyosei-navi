## 核心数値（原文対照）

出典は特記なき限り `01_ninpu-shien-kyufu.txt`。

| 項目 | 原文の記載 |
|---|---|
| 枠組み | 妊婦等包括相談支援（届出時／妊娠8か月頃／出産2か月頃の面談・情報発信）＋妊婦のための支援給付 |
| 1回目 | **5万円**。対象: 申請時点で津市に住民票がある妊娠届出をされた人。妊娠届出時（または届出後）の保健師等面談で案内。原則として面談後に支給 |
| 1回目必要書類 | 妊娠届出書あるいは妊婦給付認定申請書／振込先口座のわかるもの／母子健康手帳（表紙・出産予定日ページ。添付省略できる場合あり） |
| 1回目申請期限 | 医療機関で胎児心拍が確認された日から2年 |
| 2回目 | **胎児一人当たり5万円**。対象: 津市の妊婦給付認定者で、届出時点で津市に住民票がある人。赤ちゃん訪問の際に手続方法を案内 |
| 2回目届出期限 | 出産予定日の8週間前から2年（予定日の8週間前以前に出産等した場合はその日から2年） |
| 転出 | 妊婦給付認定後に津市を転出した場合、津市の認定は取消。転入先で再認定が必要 |
| 流産・死産等 | 妊娠届出前の流産・死産・人工妊娠中絶でも1回目・2回目を申請可。医師発行の妊婦給付認定用診断書で妊娠の事実を確認 |
| 問い合わせ（給付） | 健康福祉部 こども政策課 給付支援担当 / 電話 059-229-3155 / 〒514-8611 三重県津市西丸之内23番1号 |

`02_ryuzan-shizan.txt`: 流産・死産等のグリーフケア相談、産後ケア事業（妊娠が継続しなくなった日から1年以内も対象）への案内。給付本体の金額は01を正とする。
