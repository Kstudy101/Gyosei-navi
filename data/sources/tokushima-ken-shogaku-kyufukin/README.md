## 核心数値（01原文より、令和8年度支給額・年額）

制度は高校生等が在学する世帯の課税状況に応じて4区分。全日制・定時制と通信制、国公立・私立で金額が異なる。

- 生活保護（生業扶助）受給世帯: 国公立32,300円／私立52,600円（全日制・定時制・通信制共通の記載）
- 道府県民税・市町村民税所得割額が非課税の世帯:
  - 全日制・定時制: 国公立143,700円／私立152,000円
  - 通信制: 国公立50,500円／私立52,100円
- 上記非課税世帯に該当せず、道府県民税・市町村民税所得割額合計が105,500円未満の世帯:
  - 全日制・定時制: 国公立47,900円／私立50,670円
  - 通信制: 国公立16,830円／私立17,370円
- 道府県民税・市町村民税所得割額合計が182,500円未満の世帯:
  - 全日制・定時制: 国公立35,930円／私立38,000円
  - 通信制: 国公立12,630円／私立13,030円
- 家計急変世帯も上記非課税世帯・105,500円未満世帯・182,500円未満世帯と同額の年額表を適用し、家計急変発生日・申請時期に応じた月割り計算（12分の12など）で支給額を算定。

### 対象者・要件
- 保護者等が徳島県内に在住していること（徳島県外の高校等在学でも対象になりうる。逆に徳島県内高校在学でも保護者が県外在住なら対象外）。
- 平成26年4月1日以降に高等学校等就学支援金の対象である高等学校等に入学し、基準日（原則7月1日）に在学していること。
- 生活保護（生業扶助）受給世帯、または保護者等全員の道府県民税・市町村民税所得割額合計が182,500円未満の世帯。
- 卒業・修了済み、特別支援学校高等部在籍、令和8年4月1日以降入学の留学生等は対象外。

### 申請・提出期限（令和8年度）
- 生活保護世帯・非課税世帯等の通常申請: 令和8年7月6日(月)〜令和8年9月30日(水)必着。新入生早期申請は令和8年7月31日(金)必着。最終申請は令和8年12月18日(金)必着（12月支給予定以降にずれ込む）。
- 家計急変世帯: 令和8年12月18日(金)必着。
- 提出先: 県内在学者は在学校経由、県外在学者は保護者等在住地の徳島県教育委員会生涯学習課（国公立）またはこども未来政策課（私立）。

原文の支給額表には **84,000円・129,700円という数値は一切登場しない**。原文で確認できる非課税世帯の年額は

第一子と第二子以降で異なる金額設定など）由来の数値である可能性があるが、本ページ内では確認できなかった。
**記事化にあたっては topics-dbのnote数値を使わず、本READMEの原文数値表（143,700円/152,000円/50,500円/52,100円等）
を正としてverifierに提出すること。**
