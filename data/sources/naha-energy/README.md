# 那覇市省エネ診断支援事業補助金

## 制度の種類

**現金給付型（受診費用の自己負担分を補助）**。那覇市が独自に実施する中小企業等向け補助金。住宅設備（太陽光・蓄電池等）の個人向け設置補助金ではない。

## 確認されていないこと

- 令和8年度の予算総額・残り枠の現時点残高（公開ページに記載なし）
- 各診断メニューの標準自己負担額の具体金額（チラシは「事業者の自己負担分を補助」とだけ記載。診断機関側の料金表は未取得）
- 他自治体・国の同種助成との詳細な併用可否の境界（要綱第12条に「他の機関から同種の助成を受けていたとき」取消事由あり。個別案件は窓口確認が必要）
- 個人世帯向けの太陽光・蓄電池・エネファーム等の設置補助金（那覇市独自の住宅向けエネルギー補助金）の有無 — 本ディレクトリでは未確認のため「なし」と断定しない
