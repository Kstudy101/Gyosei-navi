## 원문에서 확정한 사실 (기사 근거)

### 제도 개요

申請主体は**訓練事業者**（身体障害者本人への直接補助ではない）。身体障害者補助犬法第3条に基づき、佐賀県内の身体障害者に補助犬を育成・貸与する訓練事業者に対し「予算の範囲内において補助金を交付」。

### 対象補助犬と利用対象者

| 補助犬の種類 | 利用者の障害程度 |
|---|---|
| 盲導犬 | 視覚障害1級 |
| 介助犬 | 肢体不自由1級または2級 |
| 聴導犬 | 聴覚障害2級 |

利用者要件：佐賀県内に1年以上居住する満18歳以上、身体障害者手帳交付を受けていること。

### 応募条件（訓練事業者）

- 今年度中に佐賀県内の身体障害者に対し育成・貸与する補助犬が見込まれること
- 今年度中に補助犬としての使用が開始されること
