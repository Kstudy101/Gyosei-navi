## 制度類型

**自己負担上限型（現物給付＋償還払い）** — 「重度障害者医療証」提示で窓口負担を上限額までに抑える。北九州市の重度障害者医療（保険診療自己負担の全額助成）とは異なり、通院・入院ごとに自己負担上限がある。ページ上で「所得制限はありません」と明記。

## 原文で確定した事実（主に01_seido.txt）

| 項目 | 原文 |
|---|---|
| 制度名 | 重度障害者医療制度 |
| 目的 | 一定の障害のある市民の通院・入院医療費の一部を市が助成し、窓口自己負担を軽減 |
| 所得制限 | **なし**（原文「所得制限はありません」） |
| 対象年齢の起点 | 小学生以上（6歳就学前は子ども医療を適用） |
| 障害要件① | 身体障害者手帳の1級または2級 |
| 障害要件② | 療育手帳のＡ判定 |
| 障害要件③ | 身体障害者手帳の3級かつ療育手帳のＢ1判定 |
| 障害要件④ | 精神障害者保健福祉手帳1級 |
| 共通要件 | 久留米市住民基本台帳記載／国保・後期高齢者医療（65歳以上）または社会保険等加入／生活保護を受けていない／医療費助成がある施設に入所していない |
| 通院上限（小中学生） | 月500円（1医療機関ごと） |
| 入院・薬局（小中学生） | 自己負担なし |
| 通院上限（上記以外） | 月500円 |
| 入院上限（上記以外） | 1日500円・月5,000円（低所得は1日300円・月3,000円） |
| 低所得の定義 | 限度額適用認定証（低所得）または限度額適用・標準負担額減額認定証（低所得）交付者 |
| 対象外 | 健保非適用診療、入院時食事代・部屋代、精神手帳1級の精神病床入院（中3まで除く）、後発がある先発希望時の「特別の料金」（価格差の4分の1、R6.10診療分〜） |
| 資格取得（新規） | 申請月の初日（65歳以上で後期高齢新規加入は申請月初日または後期高齢該当日の遅い方） |
| 転入 | 転入翌日〜14日以内なら転入日から。それ以外は申請月初日（同月申請なら転入日） |
| 有効期間 | 精神1級は手帳有効期限まで／15歳到達後最初の3/31まで（該当者）／15歳到達後最初の4/1以降は3年ごと更新（次回更新は令和8年10月1日） |
| 窓口（県内） | 重度障害者医療証提示で上限額まで |
| 県外・証未提示等 | 償還払い（支払翌日〜5年以内）。窓口: 医療・年金課／各総合支所市民福祉課／各市民センター |
| 担当 | 健康福祉部医療・年金課 電話0942-30-9034 |
