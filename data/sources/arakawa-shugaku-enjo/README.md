## 原文から確定した数値・事実

- 対象: 荒川区に住所があり、国公立小・中学校に在学する児童・生徒及び保護者で、昨年の世帯全員の総所得額が教育委員会基準額以下の方（公式案内）。
- 区立小・中で生活保護受給中の方は、就学援助対象費目がすべて生活保護費から支給されるため申請不要（公式案内）。
- 所得目安（総所得・モデルケース）: 2人約280万円 / 3人約365万円 / 4人約420万円 / 5人約470万円。
- 所得の定義（公式案内注釈3）: 給与は源泉の給与所得控除後から10万円引いた額、事業者は収入−必要経費。審査対象は令和7年1年間の所得。
- 認定: 原則として申請された月の初日から支給対象。
- 区立校の援助内容: 入学準備金・学用品費・クラブ活動費・通学費（特別支援学級）。給食費・修学旅行費等は保護者負担軽減事業対象のため就学援助からは支給なし。
- 区外国公立校: 上記に加え給食費（保護者負担がある場合）・夏期施設費・修学旅行費・遠足費・移動教室費・卒業記念アルバム費。
- 問い合わせ: 教育委員会事務局学務課学事第二係 TEL 03-3802-3111（内線3336〜3338）／FAX 03-3802-3194。

- 入学準備金・学用品費などの**円建て定額**は公式案内・申請書PDF・要綱本文のいずれにも掲載なし（要綱第3条第3項「支給額及び支給時期については、教育委員会が別に定める」）。別表1（認定基準額の計算表）・別表2（費目範囲）の全文も再キサイトのテキスト抽出では取得できず。
- 当初申請期間の具体的な締切日（「毎年度申請」はあるが、公式ページに4月末等の日付は未掲載）。
- 要綱上は不登校支援目的と教育委員会が認める私立校も対象に含み得るが、公式案内ページは「国公立」と案内。記事の対象校記述は公式案内に合わせ、要綱の例外は注記に留める。
