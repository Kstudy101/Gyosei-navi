# 弘前市奨学金制度（弘前市育英資金貸与条例に基づく貸与型奨学金）

## 制度概要
弘前市教育委員会（教育総務課）が実施する、無利子・貸与型の奨学金制度。給付ではなく貸与であり、卒業後に返還義務がある（一定要件を満たせば大学等奨学生は返還の一部免除あり）。令和8年度は「追加募集」中。
