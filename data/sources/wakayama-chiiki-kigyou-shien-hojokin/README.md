## 対象自治体・制度

- 自治体: 和歌山県（県レベル制度）
- 制度名: わかやま地域課題解決型起業支援補助金（令和8年度）
- 所管: 和歌山県 商工労働部 企業政策局 企業振興課 ／ 公益財団法人わかやま産業振興財団（実施主体）
- カテゴリ: sogyo（創業支援）
- 制度種別: **現金補助型**（補助対象経費の一部を直接補助金として交付する。融資あっせんではない）
