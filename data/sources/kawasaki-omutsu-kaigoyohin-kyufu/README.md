## 제도 유형 분류

**현물급부형（物品支給・カタログ選択方式）**。現金給付でも商品券配布でもなく、市が委託した複数事業者のカタログから利用者が介護用品を選択し、月1回自宅配達される方式。利用者は限度額を超えない範囲で選択し、所得階層に応じた利用者負担率分のみを事業者に直接支払う（現金は給付されない）。
