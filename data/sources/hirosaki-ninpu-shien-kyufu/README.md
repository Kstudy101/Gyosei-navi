## 核心数値（原文対照）

出典は特記なき限り `01_ninpu-shien-kyufu.txt`。

| 項目 | 原文の記載 |
|---|---|
| 制度開始 | 令和7年4月より、子ども・子育て支援法に「妊婦のための支援給付」が創設。認定を受けたかたに「妊婦支援給付金」を支給。妊婦等包括相談支援事業（伴走型相談支援）と一体実施 |
| 1回目 | 妊婦一人あたり **5万円**（妊娠届出時・母子健康手帳交付及び面談後に窓口で申請書交付） |
| 2回目 | 妊娠している子どもの人数×**5万円**／妊娠している子ども一人あたり5万円（流産・死産を含む）。「こんにちは赤ちゃん訪問事業」面談時に申請書類を手渡し、郵送でこども家庭センターへ提出 |
| 対象 | 申請時点で弘前市に住民票があり、妊婦給付認定を受けたかた。他市町村で認定済みで転入した場合は弘前市で再認定が必要。1回目を他市町村で受給済みなら2回目のみ可 |
| 流産・死産等 | 令和7年4月1日以降に流産・死産・人工妊娠中絶等を経験したかたも申請できる場合あり。妊娠届出前でも申請可（医師の胎児心拍確認の診断書等で妊娠事実を確認） |
| 1回目申請期限 | 胎児の心拍が医療機関で確認され妊娠が確定した日より2年間。心拍確認日が令和7年3月31日以前なら令和7年4月1日から2年間 |
| 2回目申請期限 | 出産予定日の8週間前の日（死産・流産した時はその日）より2年間。期限超過は受付できない場合あり |
| 支給時期 | 申請からおおよそ1か月後（審査後、決定通知を送付） |
| 注意 | 申請者は妊婦さん及び妊婦給付認定を受けた胎児の母に限る。振込口座名義は申請者と同一。海外で妊娠・出産されたかたは対象外となる場合あり |
| 窓口 | 弘前市こども家庭センター（健康こども部 こども家庭課 子育て包括支援係）／弘前市大字駅前町9番地20 ヒロロ3階／0172-37-1323／平日 8:30〜18:00 |
