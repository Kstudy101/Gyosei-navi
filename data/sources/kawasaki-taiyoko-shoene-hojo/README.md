## 確認できた事実（原文根拠あり）
- 対象: 川崎市内の住宅に居住（予定）の個人、共同住宅の管理組合・所有者等
- 太陽光発電設備（非FIT）: 7万円/kW（設置費用の1/2）、上限28万円/件、2kW以上50kW未満
- 太陽光発電設備（FIT）: 定額4万円/件、2kW以上
- 蓄電池（非FIT連系・新設）: 10万円/kWh（設置費用の1/2）、上限70万円/件
- 蓄電池（FIT連系・既設連系）: 10万円/kWh（設置費用の1/2）、上限30万円/件
- ZEH: 25万円/戸（定額）
- ZEH+: 40万円/戸（定額）
- 申請期間: 令和8年4月24日〜令和8年12月28日
- 事業完了期限: 令和9年1月31日
- 申請方法: オンライン（e-KAWASAKI）のみ、紙提出不可
- 問い合わせ: 川崎市環境局脱炭素戦略推進室 044-200-2178
