## 原文から確定した事実

| 項目 | 原文 |
|---|---|
| 制度名 | 高齢者見守り・安否確認機器補助事業 |
| 所管 | 健康福祉局高齢健康福祉部高齢在宅支援課（ページ記載電話 045-671-2405 / リーフレット記載 045-671-2406） |
| 対象 | 本市在住で65歳以上のひとり暮らしの方／横浜市の他の見守りサービスを利用していない方 |
| 「他の見守り」例示 | センサー付き高齢者用市営住宅居住者、セーフティネット住宅見守りサービス補助事業利用者、本事業の既存申込者 |
| 補助額 | 利用者1人当たり月額1,000円（上限）。月額費用が1,000円未満ならその額（交付要綱第7条） |
| 補助対象費用 | 利用料のうち月額費用のみ。初期費用・その他費用は対象外。消費税は対象外（交付要綱第6・7条） |
| 交付開始 | 契約開始日の属する月の翌月から（交付要綱第7条2項） |
| 申込 | 区役所等でサービス選択 → 利用者が事業者へ直接連絡・契約。市窓口への補助金申請は事業者が委任を受けて行う |
| 最終更新（HTML） | 2026年8月3日 |
