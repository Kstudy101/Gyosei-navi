# 荒川区 高齢者紙おむつ購入費助成事業（kaigo）

## 制度名
荒川区高齢者紙おむつ購入費助成事業（実施要綱：平成12年4月1日制定、令和6年4月1日最終改正施行）

## 制度分類
**現物給付型（紙おむつ購入券の支給）＋ 現金給付型（施設・入院時のおむつ代助成、選択制）**
- 原則は「紙おむつ購入券」を3か月ごとに自宅・入所先に送付し、指定店舗で紙おむつと引き換える方式（自己負担10%）。
- 病院入院・施設入所等で購入券の引き換えが困難な場合は「おむつ代（現金）助成」に切り替え可能（同一月内での併用は不可）。

## 対象者（`01_reiki_kamiomutsu.txt` 第2条 / `02_hokenfukushi.txt` 対象者欄）
荒川区内に住所を有する40歳以上（下記(4)(5)に該当する場合は65歳以上）で、次のいずれかに該当する者：
1. 要介護4または5の認定を受けた者
2. 要介護1～3の認定を受け、かつ認知症である者
3. 入院中で1・2に準ずる状態にある者（区による聴き取り調査あり）
4. 身体障害者手帳1級または2級の者
5. 愛の手帳1度または2度の者

※第2号被保険者（40～64歳）は上記1～3のいずれかに該当する場合のみ対象（`02_hokenfukushi.txt`注釈）。
※要介護認定は必須要件ではない（`03_faq.txt`で明記）。
除外：介護保険施設入所者（一時入院含む）、生活保護受給者でおむつに関し一時扶助を受けている者、荒川区重度心身障害者（児）紙おむつ購入費助成事業の助成を受けている者。

## 助成金額（`01_reiki_kamiomutsu.txt` 第3条・第4条、`02_hokenfukushi.txt` 支給内容欄）

### 紙おむつ購入券方式（原則）
- 非課税世帯：月額7,800円分（2,600円券×3枚）
- 課税世帯：月額3,900円分（1,300円券×3枚）
- 利用者負担：購入券額面の10%（店舗で自己負担金を支払い引き換え）
- 発送は3か月ごと（4-6月分→3月末発送、7-9月分→6月末、10-12月分→9月末、1-3月分→12月末）

### おむつ代（現金）助成方式（入院・施設入所等で購入券利用困難な場合の代替）
- 課税世帯：利用限度額（月額）3,900円 → 助成額3,510円／自己負担額390円
- 非課税世帯：利用限度額（月額）7,800円 → 助成額7,020円／自己負担額780円
- 自己負担は費用の10%（実支払額が限度額未満の場合は実支払額の1割）
- 請求は年3回（4か月ごと）：8月請求（4-7月分）、12月請求（8-11月分）、4月請求（12-3月分）
- 領収書は入院・入所先の病院・施設発行のもののみ対象（ドラッグストア等外部購入は対象外）

## 申請方法
- 「高齢者在宅保健福祉サービス利用申請書・同意書」を高齢者福祉課（区役所2階5番）に提出
- 受付：区役所開庁時間内、随時（募集期限・予算上限の記載は原文になし＝通年制度と見られる）
- おむつ代助成を希望する場合は別途「おむつ代口座振替依頼書（登録申請書）」の提出が必要
- 助成は原則申請月から開始し、課税状況の確認ができるまで一時保留される場合がある
