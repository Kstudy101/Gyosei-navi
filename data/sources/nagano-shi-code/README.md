## 확인한 사실

PDF 15페이지 목(15ページ目)의 長野県 섹션에서 다음을 확인:

| 항목 | 원문 | 출처 |
|---|---|---|
| 都道府県コード | 200000（長野県） | PDF 15ページ目 |
| 長野市 団体コード | **202011**（検査数字込み6桁） | PDF 15ページ目、長野県セクション1行目「202011 / 長野県 / 長野市 / ナガノケン / ナガノシ」 |

`regions.ts`의 다른 엔트리와 동일하게, 검사숫자(마지막 1자리)를 제외한 **5자리「20201」**을 団体コードとして登録した（例: 231002→23100、401307→40130と同じ変換パターン）。

## 확인되지 않은 것

- 이 PDF가 최신판(令和8年 시점)인지 여부는 총무성 사이트 자체의 갱신일 표기로 확인 필요 — 다른 세션(kobe-shi-code 등)에서 이미 같은 파일을 기준으로 여러 시정촌을 등록한 선례를 그대로 따름.
