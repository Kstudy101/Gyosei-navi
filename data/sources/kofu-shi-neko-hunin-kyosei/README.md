## 確定した事実
- 制度名：甲府市猫の不妊・去勢手術費補助金交付制度
- 目的：望まれない猫の繁殖抑制、殺処分・住環境被害の減少
- 令和8年度の申請期間：令和8年7月1日〜令和9年3月31日（消印有効）
- 補助金額（上限。手術費がこれに満たない場合はその実費額）
  - 飼い猫（申請年度で1人につき1頭まで）：オス3,000円、メス5,000円
  - 飼い主のいない猫（頭数制限なし）：オス10,000円、メス15,000円
  - 期間限定加算：令和8年7月1日〜令和9年3月12日に申請の飼い主のいない猫は1,000円加算（3月13日以降の申請は手術日に関わらず加算なし）
- 対象者：甲府市に住所を有する個人・団体で、市内の飼い主のいない猫の繁殖抑制を希望する、または市内で猫を飼養する者
- 申請方法：動物病院で不妊・去勢手術を受けた後、必要書類を揃え衛生薬務課窓口または郵送で申請
- 申請は先着順、年度途中でも予算額に達した時点で受付終了
- 年度をまたいでの申請不可。ワクチン等は対象外
- 虚偽申請の場合は補助金の返還を求められる
- 問い合わせ：生活衛生室衛生薬務課衛生薬務係 055-237-2550
