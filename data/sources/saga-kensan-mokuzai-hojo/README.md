## 원문에서 확정한 사실 (기사 근거)

### 제도 개요

令和8年度の募集は3区分。受付窓口は佐賀県庁ではなく佐賀県木材協会。

### ① 木造住宅の新築

| 항목 | 원문 값 |
|---|---|
| 補助金額 | 30万円/棟 |
| 募集戸数 | 30棟 |
| 募集期間 | 令和8年6月1日（月）〜令和8年7月31日（金） |
| 必須条件 | 構造材に県産木材を体積比60%以上 かつ 外装または内装に10㎡以上使用 |
| 施工・設計 | 佐賀県産木材地産地消の応援団登録業者が施工または設計 |
| 工事完了期限 | 令和8年12月31日 |

### ② 住宅・施設のリフォーム

| 항목 | 원문 값 |
|---|---|
| 補助金額 | 20万円/棟 |
| 募集戸数 | 10棟 |
| 募集期間 | 令和8年6月1日（月）〜令和8年7月31日（金） |
| 必須条件 | 事業費50万円以上 かつ 県産木材を現しとして20㎡以上使用 |
| 対象 | 自宅（賃貸除く）・非住宅（店舗・事務所等） |

### ③ 展示効果の高い施設の木質化

| 항목 | 원문 값 |
|---|---|
| 補助金額 | 事業費の1/2以内（上限250万円/施設） |
| 募集施設数 | 3施設 |
| 募集期間 | 令和8年6月1日（月）〜令和8年7月31日（金） |
| 必須条件 | 事業費100万円以上 かつ 県産木材を体積比70%以上使用 |
| 制限 | 内外装木質化に係る他補助制度との重複不可 |

### 他補助金との併用

「国、他の地方公共団体及び全国団体等の補助を利用する場合は、その補助制度に併用制限がないこと」が要件。
