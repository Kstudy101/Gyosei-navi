# 出産・子育て応援給付金（米子市）

## 原文情報
- 原文URL: https://www.city.yonago.lg.jp/39192.htm
- 取得日: 2026-09-24
- アーカイブファイル: `01_main.txt`（5779字）

## 制度概要
- 制度名: 出産・子育て応援給付金
- 所管: 米子市こども総本部こども支援課
- 制度種別: 現金給付型（またはJ-Coin Payポイント選択可）

## 核心数値（原文根拠）

| 項目 | 内容 | 原文箇所 |
|------|------|---------|
| 出産応援給付金 | 妊娠1回につき5万円 | 01_main.txt 297行目 |
| 子育て応援給付金 | 出生児童1人につき5万円（双子は10万円） | 01_main.txt 299行目 |
| 合計 | 最大10万円（単胎の場合） | 01_main.txt 243行目 |
| J-Coin Pay選択時 | 現金5万円に代えて5千円または1万円分プラスのポイント給付 | 01_main.txt 303行目 |
| 所得制限 | なし | 01_main.txt 267行目 |

## 対象者
- **出産応援給付金**: 令和4年4月1日以降に妊娠届出をした妊婦、かつ米子市の面談を受けた方、かつ他自治体で支給を受けていない方
- **子育て応援給付金**: 令和4年4月1日以降に出生した子の養育者（原則子と居住する母か父）、かつ赤ちゃん訪問で面談を受けた方

## 申請方法
- 出産応援給付金: 妊娠届出の翌月下旬に申請案内を郵送
- 子育て応援給付金: 出産からおおむね2か月後の赤ちゃん訪問時に申請案内を手渡し

## 接受状態（重要）
- **このページの対象は令和7年3月31日以前に出産した方のみ**
- 令和7年4月1日以降に出産した方は「妊婦のための支援給付」（別制度）として実施中
- 既存の出生者への申請は引き続き受け付けている可能性があるが、新規妊婦は対象外（2026-09-24時点）
