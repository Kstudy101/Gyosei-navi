## トピックスカウト要約との差異

- 出産育児支援金・妊婦支援給付金ともに**topic-scoutの要約と原文の金額・条件は一致**していた（9万円／子、5万円＋5万円の構造）。
- ただし原文でのみ判明した重要な補足：
  - 妊婦支援給付金1回目の5万円は「妊婦1人につき」であり、**多胎妊娠でも増額されない**（2回目のみ胎児数に応じて増額、双子で10万円）。
  - 出産育児支援金と妊婦支援給付金（2回目）は**同時申請・合算振込**が原則（赤ちゃん訪問時の電子申請案内で一体的に案内される）。
  - 出産育児支援金は「出産育児一時金の対象となっている方」が条件のため、健康保険未加入者は対象外（国の出産育児一時金の適用要件に連動）。
  - 妊婦支援給付金1回目と2回目で申請期限の起算点が異なる（1回目＝胎児心拍確認日、2回目＝出産予定日の8週間前の日）。
