# 特別障害者手当（国の制度） — 原文アーカイブ

## 対象制度
- 制度名: 特別障害者手当
- 根拠法: 特別児童扶養手当等の支給に関する法律（国の制度）
- 実施主体: 全国共通の制度。認定・支給事務は市区町村の障害福祉担当窓口が行うが、支給要件・手当額は国が全国一律に定める。
- 既存記事 `shogaisha-hojokin-kanzen-guide`（補装具費支給制度が中心）とは対象制度が異なる — 本制度は現金給付（手当）であり重複しない。

## ⚠️ 本セッションの制約（重要）

本セッションのネットワーク egress は組織ポリシーにより全面的にブロックされており（`curl` で `www.google.com` 等の一般サイトへの接続すら `connect_rejected` で拒否される。エージェントプロキシの `recentRelayFailures` で `www.mhlw.go.jp:443` への CONNECT が組織ポリシーにより拒否されたことを確認済み）、`npm run source` で厚生労働省公式ページ（mhlw.go.jp）を新規に取得することができなかった（実行ログ: `HTTP 403`）。

そのため本アーカイブは、**厚生労働省の一次ページそのものではなく**、既存バッチ（他トピック調査、`npm run source`で正規に取得済み）で偶然アーカイブされていた、**国の制度を説明する2つの独立した公式自治体サイトのページ**を根拠として採用した。両者が同一の金額（令和8年度: 月額30,450円）を独立に記載しており、全国一律の制度であることと整合する。

**次にネットワーク制約が解消された session では、厚生労働省公式ページ（例: `https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/hukushi_kaigo/shougaishahukushi/teate/teate.html`、本セッションで403確認済みのURL）を `npm run source` で正式取得し、本README・sourceLinksを厚労省一次情報に差し替えることを強く推奨する。**

## 確認できた核心情報（01・02の一致箇所）

### 対象者
- 身体又は精神に重度の障がいを有し、日常生活において常時特別の介護を必要とする**在宅の20歳以上の方**（01・02とも一致）
- 施設入所中、継続して3か月以上入院している場合、本人・扶養義務者等の所得が限度額以上の場合などは支給されない（01明記）
- 所得が一定以上の場合は支給されない（02でも「所得が一定以上の人には支給されません」と一致するが、具体的な限度額は01・02とも金額の記載なし）

### 支給額（01・02で独立に一致 — 全国一律額と判断する根拠）
- 令和7年度: 月額29,590円（01のみ記載。02に令和7年度の記載なし）
- **令和8年度: 月額30,450円（01・02の双方が独立に記載、完全一致）**

### 申請書類（01のみ）
認定請求書、認定診断書、所得状況届、承諾書、公的年金調書、受給資格者の戸籍・住民票、身体障害者手帳（所持している場合）、療育手帳（所持している場合）

### 届出が必要な場合（01のみ）
現況届（毎年夏頃）、住所変更、氏名変更、振込先金融機関変更、受給資格喪失（3か月以上の入院・施設入所）、再認定月到来、扶養義務者変更、受給資格者死亡

### 申請窓口
お住まいの市区町村の障害福祉担当窓口（01は福岡市の区別窓口一覧、02は弘前市障がい福祉課を例示。全国共通で「市区町村の障害福祉担当窓口」が窓口になる制度）
