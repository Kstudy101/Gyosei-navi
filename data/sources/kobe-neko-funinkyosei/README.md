# 神戸市 地域猫活動 不妊去勢手術費用支援 — 原文アーカイブ

## 制度概要
神戸市人と猫との共生推進協議会が実施。地域猫活動団体が協議会の計画に基づいて野良猫の捕獲・搬入等を行う場合、協議会が不妊去勢手術費用を全額負担するTNR支援。
