## 核心数値（01原文より）

- 制度名: 令和8年度徳島市住宅用太陽光発電システム・蓄エネルギー機器等導入支援事業
- **重要**: 2026年9月22日時点で本ページには「（受付終了）予算額に達したため、今年度の受付を終了しました」の告知あり。記事執筆時は必ずこの受付終了状態を明記すること。
- 申請受付期間（本来の予定）: 令和8年4月1日〜令和9年2月26日（予算超過時は早期終了）
- 補助対象設備・金額（定額）:
  - 住宅用太陽光発電システム（出力2kW以上10kW未満）: 5万円
  - 家庭用蓄電システム（ZEH支援事業の登録済一覧に記載のもの）: 5万円
  - 電気自動車等充給電設備（V2H）: 5万円
  - 各設備1回限り交付、補助対象経費が補助額より少ない場合はその金額を交付
- 対象要件: 市内の既築・新築住宅に自ら設置、市内販売店からの購入、居住予定者、環境家計簿記入協力、市税滞納なし等
- 実績報告期限: 工事完了日から30日以内、または令和9年3月31日のいずれか早い日
- 問い合わせ: 徳島市環境保全課 電話088-621-5213
