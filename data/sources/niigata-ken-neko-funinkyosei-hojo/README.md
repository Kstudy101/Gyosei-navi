# 新潟県 飼い主(所有者)のいない猫の不妊去勢手術費用補助(新潟市を除く)

取得日: 2026-09-25 / 取得方法: 01,02は npm run source、03-05はPDFを直接ダウンロード(User-Agent明示、間隔2秒)
注意: 新潟市の制度(data/sources/niigata-shi-neko-funinkyosei/)とは別制度。県制度は新潟市在住・生息の猫を対象外とする。
