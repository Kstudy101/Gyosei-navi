# 東京都北区「要介護高齢者等紙おむつ支給」

## 制度種別
現物支給型（区が紙おむつをカタログから選択させて直接支給する。現金給付ではない）

## 対象（原文 L19-33）
北区在住で常時おむつが必要な方のうち、いずれかに該当:
- 要介護4・5認定の40歳以上
- 要介護3認定の75歳以上

除外対象:
- 介護保険施設（特養・老健・介護医療院）入所者
- 生活保護受給者
- 心身障害者紙おむつ支給の受給者

## 支給内容（原文 L35-39）
- カタログから紙おむつを選択できる方式
- 具体的な金額・数量・上限は原文に明記なし（各高齢者あんしんセンターで配布の「高齢者紙おむつ等支給事業のご案内」冊子に詳細ありと案内されているが、その冊子自体はWeb上未確認）
