## 制度類型メモ

- 新潟市「企業参加型奨学金返済支援」は**企業（事業所）が申請主体**。下関市本制度は**個人（交付候補者→交付対象者）が申請主体**で、登録企業への就職・市内居住が条件。比較時に混同しないこと。
