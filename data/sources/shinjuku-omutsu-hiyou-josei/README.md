## ⚠️ 원문에서 확인되지 않은 것

- 「受付終了」류 문구는 없음 — `subsidy.status: "ongoing"`으로 처리(수시신청, 신청전소급불가).
- (참고, 이 기사와 무관) 원문에 「紙おむつあっせん制度」라는 별개제도도 언급됨 — おむつ費用助成 대상외자용, 기저귀대는 전액자기부담이라 "조성금"은 아님. 기사 본문에서 참고정보로만 언급.

## ⚠️ 서브에이전트 보고 대조

조사 에이전트가 PDF(`content/000394609.pdf`) 원문에는 정식명칭 「新宿区高齢者等おむつ費用助成」이 있다고 보고했고, 개정이력 문구는 PDF에는 없고 개요HTML에만 있다는 점을 원문대조로 스스로 밝혔다. 이번 재검증은 HTML 페이지(`npm run source`)만 재취득해 대조했으며(30〜37줄에서 개정이력 확인, 에이전트 보고와 일치), PDF는 추가로 다운로드하지 않음 — 기사 본문에 필요한 모든 수치(대상・금액・부담률・방식・문의처)가 HTML 원문에 전부 있어 PDF 추가확인 없이도 검증 완결.
