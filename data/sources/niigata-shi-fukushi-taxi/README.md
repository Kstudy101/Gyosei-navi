## 原文から確定した事実（記事根拠）

出典は特記なき限り `04_taxi1.txt`。

| 項目 | 原文の値 |
|---|---|
| 制度名 | 福祉タクシー利用助成 |
| 目的 | 障がい者が社会活動等に参加するためのタクシー等の料金の一部を助成 |
| 対象者（助成券） | 身体障がい者手帳1・2級／身体障がい者手帳3級の一部（下肢・体幹・脳原性運動〔移動〕・内部障がい）／療育手帳A／精神障がい者保健福祉手帳1級 |
| 1回あたり使用枚数 | 精算額500円以上1,000円未満→1枚（500円）／1,000円以上1,500円未満→2枚（1,000円）／1,500円以上→3枚（1,500円）まで。支払額が500円を下回る場合は使用不可 |
| 年間枚数 | 年間（毎年4月から翌年3月末日）52枚。10月から翌年3月までの交付申請の場合は26枚 |
| 申請必要書類 | 障がい手帳（身体・療育・精神） |
| 併用不可 | 自動車燃料費助成を受けている場合、この制度を受給できない（`04`注意事項／`05`注意事項／`02`でも（1）と（2）の両方申請不可） |
| 毎年度申請 | 助成を受けるには毎年度申請が必要 |
| リフト付タクシー利用券対象 | 身体障がい者手帳所持者で車いす等使用者 |
| リフト付助成内容 | リフト付タクシー料金（大型料金）と小型料金との差額。枚数制限なし |
| 申請窓口 | 各区役所健康福祉課障がい福祉係／各出張所（身体・療育）／各地域保健福祉センター（精神） |
| 契約事業者一覧 | 「新潟市福祉タクシー利用助成事業　契約事業者一覧（令和7年6月1日現在）」PDF |
| 燃料費助成額（関連） | 年間上限10,000円（10月以降資格取得は5,000円）— `05` |
| 人工透析タクシー券（関連） | 500円券を年間40枚（10月以降申請は20枚）。バス／燃料費は年額20,000円上限（10月以降資格は10,000円）— `06` |
| 令和8年度券受付 | 令和8年3月24日から窓口受付。券の使用は令和8年4月1日から — `02` |
| 所管 | 福祉部 障がい福祉課 在宅福祉係（電話：025-226-1239） |
