## ⚠️ 원문에서 확인되지 않은 것

- **예산 소진시 조기마감 여부**: 요강 제6조2項에 "전항의 교부액은 해당연도 예산의 범위내로 한다"는 문구는 있으나(=예산상한 존재), "예산 소진시 접수를 조기종료한다"는 명시적 접수마감 문구는 원문 어디에도 없음. 접수기간 자체(연중 상시접수인지, 특정기간 한정인지)도 원문에서 명시된 문구를 찾지 못함(리플릿·요강 모두 "매년도 2월말까지 공사완료"라는 공사완료기한만 명시, 신청접수 개시월은 불명확). 기사에는 "예산범위내에서 교부"까지만 확정사실로 적고, 접수개시월・조기마감여부는 unresearched로 남길 것.
- **令和8年4月 대상확충 전(昭和56年5月31日 이전만 해당하던 시절)의 助成金額이 현행과 동일했는지**: 확충은 "대상건물 범위(연식)"만 넓힌 것으로 보이며, 부칙에도 금액표 자체의 개정이력은 별도로 명시되어 있지 않음. 단, 개정연혁상 助成金額(3분의2/100만, 6분의1/50만, 1분의1가산/100만)이 언제부터 이 수치였는지 별표 신구대조까지는 하지 않음.
- **재해시요원호자 명부(災害時要援護者名簿)의 구체적 등재요건(연령・장애등급 등)**: 요강 제2조8号는 "豊島区가 작성하는 「災害時要援護者名簿(全件名簿)」에 게재가 있는 자"로만 정의하고 있고, 명부 자체의 등재기준(연령・요양보호등급 등)은 이번 조사 범위(耐震改修助成 요강)에 포함되어 있지 않아 미확인. 별도 페이지(재해시요원호자명부 소관과)를 확인해야 함.
- **온라인신청 가능여부**: 원문에서 워드・엑셀 서식(다운로드용)만 확인되며, 전자신청(LoGoフォーム 등) 시스템 존재여부는 확인하지 못함. 창구제출(정・부 각1부 등)이 기본으로 보임.
- **耐震診断技術者의 강습회・등록명부 페이지**: 관련정보에 "耐震改修事業者講習会를 受講한 施工業者의 リスト"링크가 있으나 해당 리스트 페이지 자체는 다운로드하지 않음(업체명 나열은 기사에 불필요하다고 판단).
- **助成対象経費에서 제외되는 "공사감리비용"의 구체적 범위**: 요강 제5조 단서에 "공사감리비용을 제외한다"고만 되어 있고, 공사감리비용의 산정기준・비율 등은 원문에서 별도 규정을 찾지 못함.
