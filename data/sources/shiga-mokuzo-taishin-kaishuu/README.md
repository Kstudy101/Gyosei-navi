## 確認された主な事実

- 昭和56年5月31日以前着工の木造住宅が耐震診断無料の対象
- 耐震診断・補強案作成: 滋賀県登録の耐震診断員が実施（無料）
- 耐震改修工事補助: 国総合支援メニュー 80%・上限115万円 / 国従来基幹メニュー 23%・上限97.86万円
- 割増補助例: 高齢者世帯5万円、子育て世帯5万円、主要道路沿い5万円、県産材（びわ湖材）0.7立方メートル超で20万円
- 令和8年9月9日更新（最新情報を反映）
- 申請先は各市町担当窓口（19市町の連絡先を原文で確認）
