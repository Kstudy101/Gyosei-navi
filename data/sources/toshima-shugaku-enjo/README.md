# toshima-shugaku-enjo — 豊島区 就学援助費・奨励費

取得日: 2026-09-22

## 制度概要

- 制度名: 就学援助費（関連: 特別支援教育就学奨励費・奨学金は別制度）
- 実施主体: 東京都豊島区（教育委員会事務局 学務課学事グループ）
- 類型: 準要保護・要保護世帯向けの義務教育費援助（現金支給中心）
- 対象: 国公立小・中学校へ通学し、豊島区内在住の保護者。生活保護受給、または支給要綱の認定基準を満たす世帯
- 申請期限（通常）: 令和8年4月30日（木）郵送は当日消印有効。5月以降も随時だが認定は申請月から
- 電子申請: https://logoform.jp/form/gXWR/824732
- 公式ページ: https://www.city.toshima.lg.jp/353/kosodate/gakko/teate/005900.html （更新日 2026年8月3日）

## 根拠にした主な数値（原文対照）

### 所得目安（令和9年度新入学の手引き p12）

| 世帯人数 | 家族構成例 | 合計所得金額 |
|---|---|---|
| 2人 | 35歳・7歳 | 約335万円以下 |
| 3人 | 45歳・45歳・9歳 | 約380万円以下 |
| 4人 | 40歳・12歳・7歳 | 約445万円以下 |
| 5人 | 45歳・45歳・14歳・9歳 | 約470万円以下 |
| 6人 | 70歳・45歳・45歳・12歳・7歳 | 約505万円以下 |

※ 令和8年度お知らせ本文には円建ての所得表はなく「支給要綱の認定基準」と記載。所得目安は手引き掲載のモデルケースを用いる。

### 入学支度金・学用品費など（費目表 / お知らせ）

- 入学支度金: 小学校 91,600円 / 中学校 101,000円（4月認定者。入学前支給あり）
- 学用品費（例）: 小学1年 年27,600円 / 中学1年 年39,200円
- 学習応援費（R8新設）: 小学 年14,000円 / 中学 年13,000円
- 区立給食費無償化のため、区立在籍者への就学援助からの給食費支給なし（区立以外は実費相当）
