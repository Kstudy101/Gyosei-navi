## 確認された事実（記事に使える）

- 令和8年度交付開始: 令和8年3月23日（月）から予定
- 対象障害: 下肢障害1〜2級、体幹障害1〜3級、視覚障害1〜3級、内部障害1級の身体障害者手帳所持者、療育手帳A所持者、精神障害者保健福祉手帳1・2級所持者
- 除外: 自動車運転者、市民税所得割額16万円以上（1〜6月申請は前々年基準、7〜12月は前年基準）、施設入所者
- 助成内容: 身体・知的障害＝年36枚綴り1冊、精神障害＝年24枚綴り1冊を年度に1冊交付
- 助成額: 1乗車700円まで（料金700円未満の場合はその額、お釣りなし）
- 新規申請: 月割で交付
- 申請窓口: 市役所1階81〜86番窓口（継続は福祉健康センター・市民センターも可）
- 電子申請・郵送申請対応
- 所管: 障害福祉課（TEL: 076-220-2289、FAX: 076-232-0294）
