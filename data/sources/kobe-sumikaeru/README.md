## kekkon（結婚）vs jutaku（住宅）カテゴリ判定への意見

**jutaku寄りが適切と考える。ただしkekkonカテゴリ読者向けの副次コンテンツとしての活用は妨げない。**

根拠:
1. 神戸市自身が公式FAQで「神戸市では結婚新生活支援事業を行っていない」と明言し、「住みかえーる」を国の結婚新生活支援事業の"代替"としてではなく別立ての「子育て応援」「近居・同居」事業と位置づけている（事業名自体に「結婚」の語を一切含まない）。
2. 交付要件は婚姻そのものではなく「夫婦年齢合計90歳以下」「未就学児のいる世帯」「ひとり親世帯」のいずれかであり、何年も前に結婚した夫婦や、婚姻を伴わない事実婚・同性パートナーシップ、さらにはひとり親（未婚・離婚を問わない）も対象になる。「新婚」であることは要件にもFAQにも登場しない。
3. 「親・子世帯の近居・同居」プログラムは平成25年（2013年）制定と、国の結婚新生活支援事業（開始は平成28年度前後）より古く、そもそも結婚支援策として設計されたものではない。
4. 一方で、URLパス `shinkonportal`（新婚ポータル）という命名は神戸市側のマーケティング上の位置づけであり、「新婚世帯が住み替えを検討する際に読むポータル」という訴求軸自体は否定できない。kekkonカテゴリの記事内で「神戸市在住・転入予定の新婚夫婦が使える住み替え支援」という切り口で紹介し、jutakuカテゴリでも「エレベーターなし団地・近居同居の住み替え補助」という切り口で紹介する、という両カテゴリ展開も選択肢としてありうる。

最終判断はorchestrator/writerに委ねるが、記事本文で「結婚新生活支援事業」という言葉を使う場合は、神戸市が明確にそれを実施していないと否定している事実（上記FAQ原文）を必ず明記し、読者に誤認させないようにする必要がある。
