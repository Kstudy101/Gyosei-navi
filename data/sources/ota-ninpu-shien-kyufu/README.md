## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 妊婦のための支援給付（妊婦支援給付金）。子ども・子育て支援法 기반, 令和7年4月1日〜 |
| 임신시(1회) | 5만엔. 妊婦面接 안내의 2차원코드로 신청 |
| 출산시(2회) | 태아 수 × 5만엔. すこやか赤ちゃん訪問 안내의 2차원코드로 신청 |
| 대상 | 令和7年4月1日以降에 妊婦給付認定 신청한 임산부. 신청일 시점 大田区 주민표 필요. 태아심박 확인자. 유산・사산・인공임신중절도 대상(조건・증명 있음) |
| 병급 제한 | 동일 임신으로 出産・子育て応援ギフト(구제도) 미신청・미수령 / 타 지자체 동사업 미수급 |
| 지급방법 | 임산부 본인 명의 금융기관 계좌만(배우자 등 불가) |
| 지급시기 | 신청일로부터 약 2개월 후 월말경 |
| 문의 | 健康づくり課 管理担当 03-5744-1661 / 각 지역건강과 |
| 구 독자 부가 | 妊婦面接 수진자에게「大田区子育て応援ギフト1万円相当」(面接 페이지・妊娠届 페이지). 유산・사산 등으로 面接 전인 경우 ギフト는 대상외, 지원급부는 대상될 수 있음 |
