## 確認できた事実（原文根拠あり）
- 対象（主): 65歳以上の在宅高齢者で要介護3〜5かつ紙おむつが必要な方
- 対象（若年性認知症）: 40〜64歳で要介護3〜5かつ「初老期における認知症」に該当する方（令和2年10月から対象拡大）
- 施設入所・1か月以上入院中は対象外
- 給付利用限度額: 月6,000円（令和8年4月から増額。3月分まで5,000円）
- 生活保護等: 月3,000円（紙おむつ類・おむつカバーは対象外）
- 対象品目: 紙おむつ類・おむつカバー・防水シーツ・使い捨て手袋・消臭剤・清拭剤・ドライシャンプー
- 利用者負担率: 0%（生活保護等）〜20%（市民税本人課税）
- 申請窓口: 各区役所高齢・障害課
- 最終更新日: 2026年7月13日（川崎市HP）
