## 制度タイプ分類

- **現金給付型**（妊婦本人名義口座振込）
- 国の「妊婦のための支援給付」を高松市が実施主体として支給
- 1回目＝妊婦1人定額、2回目＝胎児数連動の**2回分割支給**
- 妊婦等包括相談支援（妊娠届出時面談・妊娠8か月頃アンケート／希望者面談・こんにちは赤ちゃん訪問）と一体
