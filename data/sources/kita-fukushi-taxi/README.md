## topic-scout 사전개요와의 차이점 / 보완사항

- 대상 수첩등급・지급액(월500円券7枚+100円券5枚, 연4,000円分을 신청월부터 3月분까지 일괄지급)・소득제한(부양가족0인 기준 3,758,000円)・대상외(ガソリン券수급자, 시설입소・입원중)는 **모두 원문과 일치** 확인.
- 단, 대상외 "입원중"에 대해 원문은 **"施設入所、病院等に入院中の方"**로만 표기되어 있고 세타가야구처럼 "장기입원"이라는 기간 조건 문구가 없음. 北区는 입원 기간과 무관하게 입원 중이면 전부 대상 제외로 해석될 여지가 있음 — 기사에서 "장기입원"이라 단정하지 말고 원문 표현 그대로 "입원중"으로 쓸 것.
- topic-scout 개요에 없던 추가 확인사항(기사에 반영 권장):
  - 20세 미만은 부양의무자(부모 중 소득 높은 쪽) 소득으로 판정, 20세 이상은 본인 소득으로 판정.
  - 소득 재심사가 매년 7月에 있고, 신청월에 따라 판정 대상 연도(재작년/작년 소득)가 다름.
  - 신청 시 지참물(장애자수첩, 마이넘버카드/통지카드+본인확인서류, 대리인 시 신분증) 구체적으로 명시됨.
  - 매월 교부액이 아니라 "신청월부터 3月분까지 개월수 × 월4,000円"을 일괄 교부하는 방식이며, 월별 교부금액표가 원문에 그대로 존재(4月신청 48,000円 〜 3月신청 4,000円).
  - 갱신은 2月상순 안내발송 → 기한 내 회신 시 3月하순 우편교부, 미회신 시 익년도 4月 이후 창구신청.
  - 신청창구가 오지(王子)/아카바네(赤羽) 2곳으로 나뉘어 있으며, 滝野川地域障害者相談支援センター에서 신청 시 우편교부.

## ⚠️ 원문에서 확인되지 않은 것 / 재확인 필요 (기사에서 단정 금지)

- **"※今年度（令和5年度）に限り、すでに一部を交付済みの方については、追加交付にて対応させていただいております。"** 라는 문구가 본문에 남아 있음. 이 페이지의 표시 최종갱신일은 2026年8月1日이지만 이 문구는 令和5年度(2023年度)를 지칭하고 있어 갱신 시 삭제되지 않은 잔재 문구일 가능성이 높음. **기사에서 이 문구를 근거로 "추가교부" 같은 현재 진행 시책을 단정하지 말 것** — 필요시 verifier가 재확인.
- 신청 기한(募集기간)이 상시인지 여부: 원문에는 특정 마감일 표기가 없고 "신청 있었던 달부터" 계산하는 구조라 상시접수로 보이나, 접수 중단 조건(예산 소진 등)에 대한 명시는 없음 — "상시접수로 보임(원문에 마감일 명시 없음)"으로만 기재하고 확정 표현은 피할 것.
- 온라인 신청 가능 여부: 원문은 지참물만 안내하고 있고 "지참하세요"라는 문구로 보아 창구 방문(또는 대리인 방문)이 기본으로 보이나, 온라인/우편 신청이 별도로 가능한지는 이 페이지에서 명시적으로 부정도 긍정도 하지 않음 — 미확인으로 남길 것.
- 500円券/100円券의 사용처가 "구와 계약한 택시 회사"로 한정된다는 것 외에, 공통권/전용권 구분이나 유효기간(연도 내 사용 제한 등)은 원문에 기재 없음 — 미확인.
- ガソリン券（自動車燃料費の助成）의 상세 조건 페이지는 이번 조사에서 원문 취득하지 않음(링크만 확인). 상호배타 관계의 세부(併給 불가 여부의 정확한 문구)는 이 페이지 텍스트("ガソリン券の交付を受けている方は対象外")로만 확인했고, 반대 방향(福祉タクシー券 수급자가 ガソリン券 대상외가 되는지)은 이 페이지에 명시 없음 — 필요시 별도 원문 확인 권장.
- 「福祉タクシー券」의 신체장애자수첩 발급주체・재발급 절차 등은 조사 범위 밖으로 다루지 않음.
