# 大阪市新婚・子育て世帯向け分譲住宅購入融資利子補給制度 — 一次情報 원문

> 취득일: 2026-09-20 / 용도: `kekkon`(結婚) 카테고리 대阪府大阪市淀川区(slug: yodogawa, 총무성코드27123) 기사 집필용 기초조사
> 소관: 大阪市 都市整備局 住宅支援受付窓口（企画部 住宅政策課 民間住宅助成グループ）
> ※ この制度は大阪市**全域**（24区共通）を対象とする市独自の融資利子補給制度であり、淀川区だけの独自制度ではない。
>   淀川区民も対象になる、という文脈で淀川区の kekkon 記事に使う（既存の `yodogawa-kaigyo-startup-shikin.mdx` 等と同じ「市域制度を区記事で解説する」パターンに合わせ、slug は `yodogawa-` 接頭辞を採用）。
> ※ 大阪市は国の「結婚新生活支援事業」（内閣府/こども家庭庁の補助制度）を採用していない。本制度はそれとは別の、大阪市が独自に設けた**住宅ローン利子補給型**の制度である（現金直接交付ではない）。
