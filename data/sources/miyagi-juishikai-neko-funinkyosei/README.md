## 確認された事実

- 実施主体: （公社）宮城県獣医師会の独自事業に、宮城県（食と暮らしの安全推進課）が補助金を交付する官民スキーム。県公式ページに「この制度に対して、宮城県は一部補助しています」と明記。県要綱(平成26年施行、平成31.4.1改正)の補助対象は獣医師会。市民は県ではなく動物病院に申請。
- 令和8年度: 実施あり。受付(手術)期間 令和8年4月1日〜令和9年2月11日。予算上限到達で早期終了あり(実施頭数制限により期間変更あり)。
- 対象: 仙台市を除く宮城県内に生息する飼い主のいない猫。飼い猫は対象外。
- 助成額: オス(去勢)6,000円/頭、メス(不妊)12,000円/頭（県ページ・要領・要綱一致。予算内）。
- 申請方法: 事前に協力動物病院または獣医師会へ相談し、動物病院で「施術依頼助成金申請書」を受け取り提出。申請者以外に、同一世帯でなく猫の生息地付近に居住/勤務する1名の連署が必要。手術後の申請不可。
- 対象者(要領): 生息地付近に居住/勤務し保護した者、県登録の譲渡団体等、その団体から移管を受けた者。
- 対象外: 虚偽申請、マイクロチップ装着済み猫、購入・譲渡で新たに飼養する猫、申請前に手術済みの猫。
- 頭数上限(要領): 原則、団体は年度概ね20頭、個人は概ね10頭まで（県登録団体等は除外）。1動物病院あたり年間概ね40頭上限、2月1日以降は獣医師会へ電話確認・承諾が必要。
- 手術要件: マイクロチップ確認後に手術、オス右耳・メス左耳のV字カット(自ら屋内飼育する場合のみ免除可)。手術後は元の場所に戻す(地域猫)か里親探し・自ら飼養。
- 助成金の受取: 獣医師会が審査し、手術月の翌月末に申請者口座へ振込。手術費用自体は申請者がまず病院に支払い、後に助成金を受け取る（要領⑥⑨）。実際の自己負担額は病院ごとで未確認。
- 問合せ: 宮城県獣医師会事務局 TEL 022-297-1735（平日9:00-17:00）。
- 市町村独自の行政補助: 今回確認できた範囲では、仙台市以外の県内市町村の独自補助は見つからず（美里町ページも獣医師会制度の案内のみ）。網羅調査ではない。
