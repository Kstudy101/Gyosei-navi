## 飼い主向け（飼い猫・犬のMC等）調査結果

動物愛護一覧（`02`）を確認したところ、次は**情報案内のみ**で費用助成ではなかった。

- 「マイクロチップを装着している犬猫の飼い主の皆さまへ」→ 環境省データベース登録の案内（義務化・努力義務の説明）。装着費用の補助なし。
- 犬の登録・狂犬病予防注射、フン放置防止、引取り、譲渡会などは本記事の給付制度対象外。

よって本記事の主対象は「飼い主のいない猫」向け手術料金軽減とする（豊島区・津市など既存 `pet` 記事と同型）。
