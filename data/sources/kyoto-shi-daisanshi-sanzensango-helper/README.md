# 京都市 第三子以降等産前産後ヘルパー派遣事業

## 制度分類
**現物給付型（ヘルパー派遣＝サービス利用型）**。現金給付ではない。市が委託事業者に支援員（ヘルパー）を派遣させ、利用者は世帯区分に応じた自己負担利用料を市に納付する仕組み。市が「特に必要と認めた」場合にのみ利用決定される審査制。

案内ページ上では制度を次の2区分で呼ぶこともある（同一要綱・同一事業の下位区分）:
- 第三子以降産前産後ヘルパー派遣事業
- 多胎児産前産後ヘルパー派遣事業

正式要綱名: **京都市第三子以降等産前産後ヘルパー派遣事業実施要綱**

## 確定した中核情報と原文根拠

### 対象者
- 京都市内に住所（住民票）を有する母親／母子で、次のいずれかに該当し、家事等が困難であり、かつ適切に家事等を行う者が他にいない者のうち、**市（市長）が本事業の支援が特に必要と認めた者**
  - ア: 小学生以下の子が3人以上（産前にあっては2人）いる世帯において、第三子以降の子の妊娠中又は出産後
  - イ: 多胎児の妊娠中又は出産後
  - 根拠: `01_gaiyo.txt` L113-116／`02_jisshi-yoko.txt` L121-124／`03` 2頁
- あらましは「京都市内に住民票を有し、京都市内に居住している母子」と明記（`03` 2頁）。案内HTMLは「京都市内に住所を有する母親」（`01` L114）、要綱は「本市に住民票を有する母子」（`02` L122）— 表現差あり。記事化時はあらましの「住民票＋居住」を優先してよいが、差異は注記推奨。

### 派遣期間
| 区分 | 期間 |
|------|------|
| 第三子以降 | 出産予定日の2か月前から、出産（予定）日の2か月後まで |
| 多胎児 | 出産予定日の2か月前から、出産（予定）日の1年後まで |

- 根拠: `01` L118-122／`03` 2頁

### 利用日・時間・回数
- 利用日: 月曜日〜日曜日（年末年始を除く）、原則 午前8時〜午後6時（`01` L125-126／`03` 2頁）

- 時間: 1日1回、30分単位、最大2時間以内（`01` L127-128／`02` L152／`03` 2頁）
- 回数:
  - 第三子以降: **16回以内**
  - 多胎児: **32回以内**
  - 根拠: `01` L129-131／`02` L153／`03` 2頁

### 援助内容
家事（食事準備・洗濯・掃除・買い物等）および保育・育児（授乳・おむつ交換・沐浴・兄弟の世話等）。詳細の可／不可は `03` 6頁「支援内容の詳細」に□／■で明示（例: ペットの世話・銀行振込・庭掃除は不可、兄弟の保育園送迎は徒歩・公共交通に限り例外可 等）。

### 申請方法
- 申込先: 住所地の区役所・支所子どもはぐくみ室子育て相談担当（京北は京北出張所保健福祉第一担当）（`01` L157）
- 申請受付: **派遣を希望する月の2か月前から**（それより前は受理不可）（`01` L157／`03` 3頁）
- 必要書類: 利用（変更）申請書兼情報提供等同意書（第1号様式）＋住民票等。調査同意で一部省略可（生活保護世帯を除く — 要綱 `02` L139）（`01` L159-165／`02` L138-140／`03` 3頁）
- 令和7年4月1日からオンライン申請開始。区ごとの二次元コードは各区版「利用のあらまし」に記載（`01` L168-169／`03` 3頁・5頁）
- 伏見区・西京区は支所管轄で申請先が分かれる（`03` 3頁）
- ヘルパー調整がつかず希望に沿えない場合あり（`01` L166-167／`03` 3頁）
- キャンセル: 派遣日前日の午後5時までに事業者へ連絡。連絡なき中止は1回利用扱い（`02` L156-157／`03` 4頁）
