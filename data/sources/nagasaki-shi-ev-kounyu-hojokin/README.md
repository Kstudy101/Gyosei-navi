## 원문 간 불일치 (사실 기록)

- **実績報告の外側期限**: 個別ページ(02)は「令和9年2月末日」、総括ページ(01)は「実績報告期限 令和9年2月26日」、交付要綱(03b第10条)は「完了から30日または翌年度の4月10日の早い日」。記事では運用案内として最新の個別ページ・チラシの「2月末(事業完了/報告)」を主に伝え、要綱の4/10は一般規定として併記可能。申請期限自体は三者とも **令和9年1月31日(=補助対象年度の1月末日)** で一致。
