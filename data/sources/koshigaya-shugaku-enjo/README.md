# 越谷市就学援助制度

| 新入学児童生徒学用品費等 | 小学1年：57,060円／中学1年：63,000円（7月。入学前支給の場合あり） | R8tebiki p.2 / 03_shinnyugaku-junbihi.txt |

| 校外活動費（宿泊あり）・通学費・修学旅行費・給食費・医療費 | 実費（修学旅行は小学6年・中学3年） | R8tebiki p.2 |
| 受付期間（令和8年度） | 令和8年4月10日〜令和9年1月29日（土日祝除く。4/19・5/17のみ日曜も市役所で受付） | 01_shugaku-enjo.txt |
| 認定開始月 | 5月29日までに申請し認定→4月1日から。6月1日以降申請し認定→申請月の翌月から | 01_shugaku-enjo.txt |
| 受付場所 | 4/10〜5/29：市役所エントランス棟2階2-1／6/1以降：学務課（第二庁舎3階）。市内小・中学校でも受付 | 01_shugaku-enjo.txt |
| 対象外の主な例 | 生活保護受給中（停止・廃止は対象）、市外への区域外就学、私立・特別支援・中等教育・義務教育学校、他市区町村からの区域外就学、所得が基準以上、所得申告不適正、市県民税滞納 | R8tebiki p.1-2 |
