## ⚠️ 원문에서 확인되지 않은 것

- 受付終了・予算上限到達の記載なし → `subsidy.status: "ongoing"`（通年のあっ旋制度）。
- PDFは「令和7年4月1日現在」。利率・限度額はHTML（2026-07-21更新）と一致するため記事数値に採用。将来改定の可能性あり。
- 港区式の現金直接補助型の創業助成金は台東区公式ページでは確認できず。本制度（融資あっ旋・本人負担0%）を主記事とする。

## 차별화（他区 sogyo との関係）

- 新宿区・世田谷区等と同型の融資あっ旋だが、**本人負担0％＋保証料全額補助**が台東区の特徴。
- あっ旋限度は1,000万円で新宿（最大2,000万円）より低い一方、金利負担はより軽い。
