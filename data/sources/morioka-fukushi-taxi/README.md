### "개인 직접신청 / 시 자체 예산" 여부 확인
원문에서 "手続きに必要なもの"（절차에 필요한 것）로 수첩・인감・차검증을 나열하고 "手続き先"（절차처）로 시청 각 창구를 명시하고 있어, **본인(또는 법정대리인)이 직접 시청 담당 창구에 신청서를 제출하는 개인 신청형 제도**임이 원문에서 확인된다. 민간단체가 대행하거나 단체를 통해서만 신청 가능하다는 문구는 없음. 다만 "盛岡市 자체 예산"이라는 재원 근거(조례・요강명, 예산과목)는 이 페이지 자체에는 명시되어 있지 않다(시가 직접 운영하는 사업임은 소관부서 표기로 유추 가능하나, 재원 문구 자체는 원문에 없음).

## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **조성 금액・매수・상한액**: 원문은 "料金の一部を助成します"（요금의 일부를 조성합니다）라고만 기술되어 있고, 구체적인 금액(예: 월액 몇 엔, 몇 매, 연간 상한)이 전혀 명시되어 있지 않다. 검색 스니펫 상에는 "600엔권을 월수에 따라 교부"라는 취지의 문구가 잡혔으나, 이는 WebSearch 요약(AI 생성 요약)이며 원문(01번 파일)에는 해당 문구가 없다. **이 수치는 원문 미확인이므로 기사에 절대 쓰지 말 것.** 별도의 요강・안내책자(PDF)에 금액이 있을 가능성이 높으나, 이번 조사에서는 유효한 PDF 링크를 찾지 못했다(위 "시도했으나 확보 실패한 자료" 참조).
- **신청 기한 / 유효기간**: 원문에 언급 없음. 연도 갱신 여부, 유효기간(회계연도 단위인지 등) 불명.
- **택시권과 가솔린권의 병용/선택 여부**: 원문 제목이 "福祉タクシー**及び**ガソリン等助成券"으로 "및"으로 표기되어 있어 별개 항목처럼 보이지만, 신청자가 택시권과 가솔린권을 동시에 받을 수 있는지, 아니면 양자택일인지는 원문에 명시되어 있지 않다. "手続きに必要なもの"에 차검증이 "ガソリン等助成券を申請する場合"라는 조건부로만 붙어 있어 가솔린권은 별도 신청 절차로 보이지만, 택시권과의 중복 수급 가부는 확정할 수 없다.
- **실시요강(実施要綱) 등 세부 규정**: 미확보. 대상 장애 정도의 판정 기준 세부사항, 지급 방법(사전교부/사후정산), 계약 택시회사 목록 등은 미확인.
