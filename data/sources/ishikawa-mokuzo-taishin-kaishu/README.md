## 確認された事実（記事に使える）

- 補助対象: 昭和56年5月31日以前に工事が着手された住宅
- 能登半島地震被災住宅: 令和6年6月から対象に追加
- 補助額の変遷: 令和6年10月から180万円、令和7年7月から210万円（補強計画含む）
- 令和7年7月以降: 耐震改修費（補強計画を含む）定額210万円
- 対象地域: 県内全19市町（各市町の担当課が窓口）
- 所管: 土木部建築住宅課（TEL: 076-225-1777）
- 市町によっては補助上限額がさらに高い場合あり
