## 確認できた情報

- 正式名称: 奨学のための給付金（国公立高等学校等）
- 対象者: 令和8年7月1日現在、以下すべてを満たす保護者等
  - 保護者等が山形県内に在住
  - 高校生等が就学支援金等の対象者
  - 基準日（令和8年7月1日）に国公立高等学校等在学
  - 世帯が(1)生活保護（生業扶助）受給世帯、(2)所得割合計非課税世帯、(3)所得割合計105,500円未満の世帯、(4)所得割合計182,500円未満の世帯のいずれかに該当
- 給付額（年額）:
  - 生活保護（生業扶助）受給世帯: 32,300円（全日制・定時制・通信制共通）
  - 非課税世帯: 143,700円（全日制・定時制）／50,500円（通信制）
  - 所得割100円以上105,500円未満: 47,900円（全日制・定時制）／16,830円（通信制）
  - 所得割105,500円以上182,500円未満: 35,930円（全日制・定時制）／12,630円（通信制）
- 申請方法:
  - 県内高校在学: 各学校が指定する日までに学校へ申請書類提出
  - 県外高校等在学: 令和8年11月30日（月）必着で山形県教育局高校教育課へ郵送
- 申請先: 在学校 or 山形県教育局高校教育課経理・奨学金担当（〒990-8570 山形市松波二丁目8番1号、TEL: 023-630-2513）
