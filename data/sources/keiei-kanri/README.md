## 주요 사실 (기사 검수용 메모)

- 시행일 **令和7年10月16日**. 施行日 前日까지 접수된 신청은 개정 전 기준 적용
- 5대 개정: ①資本金等 500万→**3,000万円** ②**常勤職員 1名 이상** (日本人·特別永住者·別表第二 재류자 한정, 別表第一 외국인 불가) ③申請者 or 常勤職員 중 1인 **日本語 B2 상당** (JLPT N2 / BJT 400 / 중장기 20년 재류 / 일본 대학등 졸업 / 의무교육+고교 졸업. 日本語能力 요건의 常勤職員에는 別表第一 외국인도 포함 — ②와 범위가 다름 주의) ④**博士·修士·専門職学位 or 経営管理 経験 3年** (特定活動 起業準備 기간 산입) ⑤事業計画書에 **中小企業診断士·公認会計士·税理士** 확인 의무 (上場企業相当 규모 등 제외)
- 自宅 兼用 事業所 원칙 불인정 / 業務委託 등으로 経営 실태 없으면 비해당
- 개정 기준 미충족 시 **永住許可 불가**, 高度専門職1号ハ→2号 변경 불가
- 在留中인 자: 施行後 3年 (**令和10年10月16日**) 까지의 更新은 경영상황·적합 전망 종합판단 (전문가 평가문서 제출 요구 가능). 3년 경과 후 更新은 원칙 적합 필수 (경영 양호+납세 이행+次回까지 충족 전망 시 종합판단)
- 更新 시 공租公課 (労働保険·社会保険·国税·地方税) 이행 확인 — 説明書 참고양식 (10)
- カテゴリー3・4: 令和8年4月15日 이후 신청부터 「所属機関の代表者に関する申告書」 (事業管理 종사자) 추가 (자격 페이지)
- 在留期間: 5年・3年・1年・6月・4月・3月
- 有償新株予約権 (J-KISS 등) 払込金: 반환의무 없음 + 장래 資本金 계상 誓約 시 3,000万円에 산입 가능 (05 §5)
