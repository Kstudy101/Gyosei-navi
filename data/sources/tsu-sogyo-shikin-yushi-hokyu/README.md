# tsu-sogyo-shikin-yushi-hokyu — 原文根拠

- 対象: 三重県津市（regionCode `24201` / slug `tsu`）
- 制度: 津市創業資金融資に係る補給金の交付（保証料補給金・利子補給金）
- カテゴリ: sogyo

## 核心数値（原文対照）

出典は特記なき限り `01_sogyo-shikin-yushi-hokyu.txt`。金額は `07_sougoyou_youkou_hyou.pdf` 別表と一致。

| 項目 | 原文の記載 |
|---|---|
| 制度趣旨 | 津市区域内で創業する者の経営安定・事業発展のため、創業資金融資に係る補給金を交付 |
| 二制度 | 「津市創業資金融資保証料補給金」と「津市創業資金融資利子補給金」。どちらも対象でも**併用申請不可** |
| 保証料補給・対象 | 三重県「創業・再挑戦アシスト資金融資要綱」に基づき三重県信用保証協会の保証を得て融資を受けた者で、津市内に主たる事務所・事業所を有し創業後5年未満、または新たな事務所・事業所を設置し創業しようとする者 |
| 保証料補給・額 | 三重県信用保証協会の信用保証料のうち**10万円を限度**（予算の範囲内） |
| 保証料補給・申請期限 | **融資実行日から3カ月以内** |
| 保証料補給・返還 | 繰上げ償還等で保証協会から保証料返還を受けた場合、支給した補給金の一部を返還 |
| 利子補給・対象 | 日本政策金融公庫の新企業育成貸付・新企業育成・事業安定等貸付・企業活力強化貸付・食品貸付に基づく融資を受けた者で、津市内に主たる事務所・事業所を有し創業後5年未満、または新たな事務所・事業所を設置し創業しようとする者 |
| 利子補給・額 | 公庫に支払われた利子のうち、融資の最初の返済日の属する月から**36月を限度**、補給金の額は**合計10万円を限度**（予算の範囲内） |
| 利子補給・申請期限 | **毎年2月末** |
| 申請場所 | 経営支援課（あのつ台四丁目6-1 あのつピア1階） |
| 問い合わせ | 商工観光部 経営支援課 経営支援担当 / 電話 059-236-3355 / ファクス 059-236-3356 / 〒514-0131 |
