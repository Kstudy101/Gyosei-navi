## 제도 유형 분류

**融資あっせん型**（既存記事群＝千代田区・世田谷区・渋谷区・品川区・新宿区と同一構造）。
現金給付型ではなく、区が金融機関・東京信用保証協会と連携して低利融資をあっせんし、
- 表面金利1.9%のうち区が1.4%を利子補給（本人負担0.5%まで圧縮）
- 信用保証料は区が全額補助
という「利子補給＋信用保証料補助」の組み合わせで実質負担を下げる制度。現物給付や補助金の直接交付ではない。

## ⚠️ 원문에서 확인되지 않은 것

- 利子補給の適用**期間の年数上限**（例:「〇年間」といった明示的な補給継続年数の記載）は今回取得した3点の原文には見当たらなかった。返済期間中は継続し、区外転出・廃業等の事由でのみ「中止」される旨のみ確認できている。他区記事（世田谷等）との比較記述をする際は、この点を「明示的な補給年数の記載なし」として扱うこと。
- 「受付中／受付終了／予算到達」等、時期的な受付状況を明示する文言は見当たらない。募集要領上の予算上限（今年度分の予算枠に達したら停止、等）の記載も確認できず。ページ更新日（2026年4月1日）時点では通常運用中とみられるが、断定はしない。
- 融資あっせん1回あたりの運転資金限度額は「直近決算書の運転資金相当額の4か月分以内」（既存事業者向けの一般規定）とあるが、創業支援融資（創業前で決算書がない場合）については「開業計画書内の資金計画で積算」（03 p2）とのみ記載があり、具体的な計算式・上限金額の別枠数値は確認できず。
