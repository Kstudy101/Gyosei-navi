## 原文で確定した事実（記事根拠）

### A. 寄り添い給付金（経済的支援）— 01

| 項目 | 原文根拠 | 内容 |
|---|---|---|
| 制度名 | 01 表題 | 国の「妊婦のための支援給付」を活用した『妊娠・出産・子育て寄り添い支援事業』 |
| 趣旨 | 01 冒頭 | 妊娠期から出産・子育てまでの切れ目ない「相談支援」と、出産・育児関連用品の購入や子育てサービス等の負担軽減を図る「経済的支援」を一体的に実施 |
| 給付の種類 | 01「給付金の概要」 | 「妊娠時」と「出産時」の2種類 |
| 妊娠時 対象 | 01 | 申請・支給対象者：妊婦／支給額：5万円 |
| 出産時 対象 | 01 | 申請・支給対象者：産婦／支給額：妊娠されたお子さま1人あたり5万円（双子の場合10万円＝5万円×2人分） |
| 所得制限 | 01「注意事項」 | 所得制限はありません |
| 流産・死産 | 01「注意事項」および Q7 | 出産後にお子さまを亡くされた方も妊娠時・出産時とも受取可。2025年4月1日以降に流産・死産（人工妊娠中絶含む）でお子さまを亡くされた方も対象。心拍確認後が条件（Q7） |
| 申請（妊娠時） | 01「給付金の申請方法」・Q1 | 妊娠届出時に申請方法を案内。案内受取後オンライン申請 |
| 申請（出産時） | 01・Q1・Q5 | 新生児訪問時に申請方法を案内。案内受取後オンライン申請。里帰り等で神戸市の新生児訪問を受けない場合は事前に区役所・支所保健福祉課へ連絡 |
| 申請者 | Q2・Q3 | 妊娠時は妊婦本人、出産時は産婦本人が申請 |
| 海外妊娠・帰国 | Q4 | 出産前に帰国し神戸市で妊娠届出→両方対象。出産後帰国は原則対象外（海外転出前に妊娠していた場合は例外で相談） |
| 里帰り | Q5 | 里帰り先で新生児訪問を受けても支給は神戸市から。事前連絡が必要。確認に時間がかかることがある |
| DV避難 | Q8 | 住民票がなくても一定要件で受給可。各区保健福祉課（寄り添い支援事業担当）へ相談 |
| 問い合わせ | 01 | 各区役所・支所保健福祉課／こども家庭局家庭支援課 |

## 制度タイプ分類

- **現金給付型**（寄り添い給付金／妊娠時5万円＋出産時・胎児1人あたり5万円）
- 国の「妊婦のための支援給付」を市が実施する枠組み（他市の妊婦支援給付と同系統）
- 伴走型相談支援と一体実施
