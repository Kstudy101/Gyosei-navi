# 鹿屋市 太陽光発電設備・蓄電池の設置費用補助

## 制度概要
- **制度名**: 太陽光発電設備・蓄電池の設置費用補助
- **実施主体**: 鹿屋市（市民生活部環境政策課環境政策係）
- **根拠**: 環境省「地域脱炭素移行・再エネ推進交付金（重点対策加速化事業）」活用

## 核心数値

### 補助対象設備
1. **太陽光発電設備**: 個人住宅屋根設置・自家消費型・10kW未満・FIT/FIP非認定
2. **蓄電池設備**: 太陽光発電設備の付帯設備・20kWh以下・1kWhあたり価格155,000円以下（税抜）

### 補助金額
| 設備 | 補助額 |
|------|--------|
| 太陽光発電設備 | 出力(kW) × 70,000円（設備価格が上限） |
| 蓄電池設備 | 価格（工事費込・税抜） × 1/3（10kWh上限） |

- 蓄電池：1kWhあたり価格が155,000円超の場合は補助対象外
- 千円未満切り捨て

### 対象者
1. 自ら所有・居住する市内住宅に補助対象設備を設置する者（新築・購入予定含む）
2. 実績報告提出時に補助設備設置住宅に住所を有する者
3. 市税を滞納していない者
4. 本事業の補助金を受けたことがない者
5. 国・鹿児島県・鹿屋市から同様の補助金等を受けていない、または受ける見込みのない者
6. 暴力団員等でない者

### 対象住宅条件
- 個人が自ら所有・居住する戸建て
- 専用住宅（居住用床面積50㎡以上）または併用住宅（居住用床面積50㎡以上かつ居住用割合5割以上）
- 集合住宅・保養所・寄宿舎等は対象外
- 自家消費率30%以上（発電電力量の30%以上を自家消費）

### 申請期間
- **交付申請期限**: 令和8年11月16日（月）
- **実績報告期限**: 事業完了日から3か月以内または令和9年2月15日（月）のいずれか早い方

### 申請窓口
- 持参のみ（郵送・メール・FAX不可）
- 鹿屋市役所本庁5階 環境政策課

## 注意事項
- FIT/FIP制度認定設備は対象外（自家消費型のみ）
- 既存設備の置換・増設は対象外（ただし全量売電設備の置換は対象）
- 蓄電池のみの導入は対象外
- 補助金交付決定後に着手した事業が対象（契約締結は着手とみなす）
- 国・鹿児島県・鹿屋市からの二重補助禁止
