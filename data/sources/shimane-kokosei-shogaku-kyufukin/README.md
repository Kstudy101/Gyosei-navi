## 根拠表

| 項目 | 内容（原文どおり） | 出典 |
|---|---|---|
| 制度概要 | 国公立高校等に通う生徒の授業料以外の教育費負担を軽減。給付金は返済不要 | 01 |
| 基準日 | 申請は7月1日を基準日とする | 01 |
| 対象（通常申請）| 令和8年7月1日現在、1〜5の全てを満たす。1) 生徒が高等学校等就学支援金(新制度)・高校生等新修学支援金・学び直し支援金の受給資格を有する 2) 保護者等が島根県内に住所を有する 3) 生活保護受給世帯、または保護者等全員の令和8年度の県民税・市町村民税の所得割額の合計が182,500円未満 4) 令和8年7月に国公立の高等学校等・高等学校専攻科・高等専門学校に在学（高専は1〜3年生のみ）5) 児童福祉法による児童入所施設措置費（見学旅行費又は特別育成費（母子生活支援施設の高校生等を除く））の支弁対象でない | 01, 02 |
| 注記 | 給付回数が上限に達している場合は不可。保護者に海外在住等で課税額が確認できない者がいる場合は対象外。就学支援金新制度対象外の外国籍等の生徒は生活保護世帯・非課税世帯のみ対象 | 01 |
| 給付額の範囲 | 12,630円〜143,700円（生徒一人当たり、年額）。給付額は申請者の状況により変わる | 02 |
| 目安 | 案内PDFに「生活保護世帯ではない場合(年収約490万円未満)」の記載。表の目安は下記 | 02, 04 |
