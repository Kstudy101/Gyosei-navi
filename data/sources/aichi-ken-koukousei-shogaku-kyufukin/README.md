## 対象要件（令和8年度・7月1日時点）

- 生徒: 平成26年度以降に高校等(県外校含む)1年生に入学し、7月1日時点で就学支援金（新制度／経過措置＝旧制度）等の受給資格あり。
- 保護者等（全員）の区分: (1)生活保護「生業扶助」受給、(2)令和8年度県民税所得割・市町村民税所得割が非課税、(3)合算所得割105,500円未満、(4)専攻科以外は105,500円以上182,500円未満（公立ページは「エ」）、(5)[私立・専攻科のみ]264,500円未満かつ扶養する子3人以上、家計急変世帯（7月2日以降の急変も可）。
- 対象外: 7月1日時点で未在学／休学（公立）／特別支援学校高等部（公立）／措置費（見学旅行費・特別育成費）受給者／他都道府県の奨学給付金受給者（公立）／保護者等の所得証明が出せない者（私立）／支給回数超過（私立: 全日制3回・定時制通信制4回）。
- 外国人学校在籍生は旧制度のみ申請可（私立）。国籍・在留資格等申告書が必要（県内校で就学支援金申請済みなら私立は不要）。
