## PDF（02・03）について

同一ページの「1回目／2回目の支給用のチラシ」リンク先だが、中身は旧制度の**出産応援ギフト／子育て応援ギフト**（電子ギフト・電子マネー等、令和7年3月13日付チラシ）である。新制度の現金5万円表の根拠としては使わない。旧ギフトの要点のみ参考記録:

- 出産応援ギフト: 妊娠届出・面談後に5万円相当（02）
- 子育て応援ギフト: 出生届出・面談後に子ども1人あたり5万円相当。多胎児は人数分（03）
- 03には「令和7年3月末までに出生した子ども」向け案内あり（01の経過措置と整合）
