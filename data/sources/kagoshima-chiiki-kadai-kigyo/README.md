# かごしま地域課題解決型起業支援金（令和8年度） — 原文アーカイブ

## 対象自治体・制度

- 実施主体: 鹿児島県 商工労働水産部 産業人材確保・移住促進課
- 制度名: 令和8年度かごしま地域課題解決型起業支援金
- カテゴリ: sogyo（創業支援）
- 制度種別: 現金給付（補助金）型。デジタル技術を活用して地域課題を解決する起業者に起業支援金を交付し、伴走支援も提供。
