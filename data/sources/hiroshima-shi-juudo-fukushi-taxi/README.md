## 制度タイプ分類

- **利用券（タクシー乗車券）交付型** — 現金定額給付ではなく、1枚500円限度の乗車券を年次交付
- 市の独自事業（要綱に基づく）
- 既存記事 `hiroshima-shi-juudo-shinshin-shogaisha-iryohi`（医療費補助）とは対象・給付形態が異なる
- 「障害者公共交通機関利用助成（いきいき乗車券）」とは相互排他（公共交通助成を受けた方は本制度対象外）
