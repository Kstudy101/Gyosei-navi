## 確認された事実（記事に使える）

- 受付開始: 令和8年6月22日（月）
- 補助対象者: 自ら居住する住居に補助対象設備を導入する個人、PPA事業者、リース事業者
- 太陽光発電設備: 1kWあたり7万円（上限5kW・35万円、千円未満切り捨て）、瓦屋根・カーポートは10万円加算
- 蓄電池: 15万円または対象経費の1/3のいずれか低い方（5kWh以上の定置用、太陽光と同時設置または設置済み）
- V2H充放電設備: 15万円（国の充電・充てんインフラ等導入促進補助金の補助対象設備、太陽光と同時または設置済み）
- 太陽光の要件: 発電電力量の30%以上自家消費、FIT/FIP制度認定を取得しない、北陸電力「かんたん固定単価プラン」加入
- 交付申請締切: 太陽光・同時蓄電池は令和8年12月28日、蓄電池（設置済み）・V2Hは令和9年1月29日
- 実績報告締切: 太陽光・同時蓄電池は令和9年1月29日、蓄電池（設置済み）・V2Hは令和9年3月31日
- 津幡町の住宅は太陽光・同時蓄電池は津幡町の「津幡町カーボンニュートラル加速化事業補助金」へ
- 令和8年度よりメール受付廃止（電子申請・郵送・持参のみ）
- 所管: 生活環境部カーボンニュートラル推進課（TEL: 076-225-1527、cn3@pref.ishikawa.lg.jp）
