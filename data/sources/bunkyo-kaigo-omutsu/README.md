## 制度1: 高齢者紙おむつ現物支給事業（現物支給型）

- **対象者**: 文京区内在住で、(1)要介護3以上に認定され常時おむつ使用の方、または(2)紙おむつの持込ができる病院に医療保険で入院し常時おむつ使用の満65歳以上の方。
  - 2025年4月1日（令和7年4月1日）より、(1)(2)以外で40歳以上の方も所定の「医師の意見書」提出で対象化。
  - 対象外: 特別養護老人ホーム等の施設入所者／文京区心身障害者紙おむつ支給事業の受給者／64歳以下で身体障害者手帳・愛の手帳保有者。
- **支給内容**: 31種類の紙おむつから最大45点まで組み合わせ選択（下限20点）。月1回、指定場所へ配送。
- **費用負担**:
  - 月額500円（生活保護世帯は免除）
  - 45点超過分は1点につき100円の自己負担
  - 配送料: 区内・都内（島しょ除く）病院は無料／23区内500円／23区外900円（着払いまたは振込用紙で支払い）
- **申請方法**: 高齢福祉課窓口または最寄りの高齢者あんしん相談センター（地域包括支援センター）窓口、または郵送。
  - 必要書類: 支給対象者の介護保険被保険者証（またはマイナンバーカード等の本人確認書類）、認印。
  - 要介護2以下の場合は「医師の意見書」の追加提出が必要（既に要介護3以上で受給中の方が要介護2以下になった場合は不要）。
- **問い合わせ**: 福祉部高齢福祉課高齢福祉推進係 03-5803-1213（〒112-8555 文京区春日1-16-21 文京シビックセンター9階南側）

原文根拠: `01_genbutsu-shikyu.txt` 47〜139行目。

## 制度2: 高齢者おむつ代費用助成事業（現金助成型）

- **対象者**: 文京区内在住で、紙おむつの持込ができない病院・有料老人ホーム・グループホーム等に入院・入所中でおむつを使用中の方のうち、制度1と同じ要介護3以上／満65歳以上医療保険入院の要件（2025年4月1日より40歳以上＋医師意見書のルートも追加）。対象外要件も制度1と同一。
- **助成金額**: 上限1月あたり4,000円。申請書を受理した月からが対象（遡及不可）。
- **申請から受給までの流れ**:
  1. 高齢福祉課へ申請書提出（窓口または郵送、必要書類は制度1と同様）。要介護2以下は医師の意見書が必要。
  2. 申請受付月の翌月初旬に助成決定通知書＋請求書類が送付される。
  3. 病院等が発行する領収書（コピー可）を添えて区に請求（毎月でも数か月分まとめてでも可）。
  4. 請求書類到着から概ね1か月後に指定口座へ振込。
- **注意点**: 同一月に現物支給とこの費用助成の**併用不可**。助成申請は年度ごとで、次年度も継続入院・入所の場合は再申請が必要。
- **問い合わせ**: 福祉部高齢福祉課高齢福祉推進係 03-5803-1213（同上）

原文根拠: `02_omutsudai-josei.txt` 47〜121行目。

## 制度分類

- 制度1（現物支給事業）＝ **現物支給型**（実物の紙おむつ現物を配送）
- 制度2（費用助成事業）＝ **現金助成型（償還払い）**（領収書に基づき上限4,000円/月を助成）

両制度は同じ対象要件（要介護3以上等）を共有しつつ、「紙おむつを現物で受け取れる施設か否か」で使い分ける設計。他区（例: 千代田区omutsu-shikyu、練馬・大田・目黒等のkamiomutsu系記事）と比較する際は、この「現物 or 現金」の分岐構造が文京区特有の切り口になる。
