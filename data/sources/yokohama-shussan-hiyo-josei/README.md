## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 出産費用助成金（市独自制度、FAQ페이지 제목에 「（市独自）」로 명시） |
| 소관 | 出産費用助成金 専用コールセンター（0120-547-059、kd-syussan@city.yokohama.lg.jp） |
| 대상 | 令和8年4月1日以降に出産（妊娠85日以上의 사산・유산 포함）, 출산일~신청시점까지 요코하마시 주민등록, 건강보험 가입. 令和7年4月1日以降 출산자도 출산 후 1년간 신청가능 |
| 助成額 | 자녀1인당 최대9만엔. 가입 건강보험조합의 出産育児一時金 부가급여가 있으면 그 액수를 차감(부가급여9만엔 이상이면 지급없음) |
| 申請期限 | 출산일 익일부터 기산 1년간 |
| 申請方法 | 子育て応援サイト・アプリ「パマトコ」（외부사이트）경유, 미이용시 콜센터에 연락해 우편신청. **구청 창구는 접수하지 않음** |
| 申請者 | 출산한 본인만(배우자・가족 대리신청 원칙불가) |

## ⚠️ 원문에서 확인되지 않은 것

- 出産費用助成金과 별개로 妊婦健康診査費用助成金(임부1인당5만엔, 令和6年4月1日以降 검진자 대상)이 관련페이지 목록에 확인됨 — 이번 기사에서는 다루지 않음(별도 기사화 검토 가능).
- 産後母子ケア事業・産前産後ヘルパー派遣事業(둘 다 유료 현물서비스, 소득에 따라 감면)도 같은 소관부서(地域子育て支援課)에서 확인됨 — 별도 성격의 제도라 이번 기사에는 포함하지 않음.
