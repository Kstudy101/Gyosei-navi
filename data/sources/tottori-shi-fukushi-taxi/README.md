# 鳥取市 重度障がい者（児）タクシー料金助成（障がいのある方への各種助成事業）— 原文アーカイブ

## 対象制度

- 制度名: 重度障がい者（児）タクシー料金助成（鳥取市タクシー利用券）
- 所管: 鳥取市 福祉部 障がい福祉課 障がい者福祉係（Tel: 0857-30-8217 / Fax: 0857-20-3907 / 市役所本庁舎1階）
- 制度類型: **現物給付型（利用券方式）** — 現金の直接支給ではなく、初乗り運賃分を助成するタクシー利用券を交付する方式。あわせてタクシー乗車時の手帳提示により10％割引も受けられる。
- 同ページ掲載の関連制度: 自動車改造費等助成（車両改造・福祉車両購入助成）も同ページに掲載。

## 制度の性格分類

- **給付形態**: 現物給付（利用券・チケット方式）。現金給付でも融資あっせんでもない

- **登録事業所制**: 利用可能なタクシー事業者が限定されている
