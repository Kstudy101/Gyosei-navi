## 要旨

熊本市「令和8年度省エネルギー機器等導入推進事業補助金」の公式ページが2026年9月25日付けで更新され、（1）前期分の受付状況（令和8年9月25日12時時点）と（2）後期分の補助件数・受付開始日が公表されている。

### 前期分の受付状況（令和8年9月25日12時時点）
- 蓄電池（固定価格買取制度満了世帯対象）：補助件数35件のうち申請26件（残り9件）。前期分メニューの中で唯一、受付終了になっていない個別件数枠
- 集合住宅用宅配ボックス：200万円分のうち申請9件（金額未確定・受付終了の記載なし）
- 他7メニュー（エアコン、宅配ボックス、EV等、ZEH、太陽光＋蓄電池、エネファーム、エコキュート）はいずれも受付終了済み

### 後期分の補助件数・受付開始日（令和8年9月1日8時30分時点公表分、9月25日時点でも同内容）
- 10月1日〜：エアコン（2万円・125件）、戸建て宅配ボックス（5千円・100件）
- 10月19日〜：EV・PHV・FCV（10万円・70件）※後期本来の65件に前期不交付分5件を繰越
- 11月2日〜：ZEH（15万円・50件）、太陽光＋蓄電池（8万円・80件）、蓄電池・FIT満了世帯対象（8万円・10件）※前期未消化分は後期へ繰越の可能性、エネファーム（8万円・10件）、集合住宅宅配ボックス（上限10万円・200万円分）※前期未消化分繰越の可能性、エコキュート（4万円・60件）

### ニュース性の根拠
- 蓄電池（FIT満了世帯対象）の前期枠が35件中26件申請済みで残り9件と僅少
- 後期受付が10月19日・11月2日から開始し、メニューごとの件数・繰越条件（※1・※2）が新たに確定・公表されている
- 前期メニューの大半（7/9）が既に受付終了しており、次の申請機会は後期受付開始日であることが読者にとって行動喚起になる
