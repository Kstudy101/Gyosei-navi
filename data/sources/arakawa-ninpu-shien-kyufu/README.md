- 국가법 기반 현금/카탈로그 선택형 급부（妊婦支援給付金）＋ 구 독자 현물성 기프트（ゆりかごギフト1万円相当）
- 大田区 `ota-ninpu-shien-kyufu` 와 동형（국제도＋구 독자 1만엔 상당 기프트）. 荒川는 지급이 **현금 or 카탈로그 선택**인 점이 차별화.
