## 원문에서 확정한 사실

**① 新生児誕生祝金（목黒区 独自制度, 01）**

| 항목 | 원문 |
|---|---|
| 대상 | 「令和5年4月1日以降に出産し、かつ、出生日において出生した子どもを含む住民登録が目黒区にある世帯」かつ「出生通知票を提出し、かつ、目黒区が受理した日において出生した子どもを含む住民票が目黒区にある世帯」の両方に該当する가정 |
| 지급액 | **新生児1人につき2万円**（원문 그대로） |
| 지급방법 | 指定の金融機関に口座振替により支給（현금・계좌송금） |
| 신청기한 | **お子さんの出生日から3か月以内**（원문 그대로） |
| 소득제한 | 원문에 **소득제한에 관한 문구 자체가 없음**（본문・문의처・신청조건 어디에도 "소득" "課税" 등의 단어 미등장） |
| 주의사항(원문 인용) | 「（注記）お子さまが生まれた後に、目黒区へ転入された世帯は目黒区新生児誕生祝金の対象外です。」→ 출생 후 전입 세대는 대상 외（topic-scout 사전조사와 일치） |
| 갱신일 | 2025年4月1日（원문 페이지 표시） |
| 문의처 | 地域保健課 地域保健サービス係 03-5722-9503 |

**② 妊婦のための支援給付（국가제도, 02）**

| 항목 | 원문 |
|---|---|
| 시행일 | 令和7年4月1日（2025年4月1日）부터, 子ども・子育て支援法에 창설된 신제도 |
| 1회째 | 임신시 5만円分（給付金） — 妊娠届出・妊婦給付認定申請・면담 완료한 목黒区 주민등록 임산부 대상 |
| 2회째 | 출산후 아이 1인당 5만円分 — 신생아방문 완료・태아수 신고한 목黒区 주민등록 산모 대상 |
| 지급방법 | 令和8年4月1日부터 현금급부(계좌송금) 또는 기프트카드(전자쿠폰) 중 선택 가능（원문: 「令和8年4月1日より現金給付（口座振替）に加え、ギフトカード（電子クーポン）交付をご選択いただけるようになりました。」） |
| 신청기한 | 1회째: 태아심박확인일(수진일)로부터 2년간 / 2회째: 출산예정일 8주 전부터 2년간 |
| 유산・사산 대응 | 유산・사산・인공임신중절 경험자도 1-2회 신청 가능（단, 이소성임신・생화학적임신・포상기태임신은 대상외） |
| 소득제한 | 원문에 소득제한 문구 없음 |

**정리**: 목黒区는 千代田区・港区형（출산비 실비보조형）이 아니라, **①妊婦のための支援給付（국가제도, 임신시5만+출산후1인당5万=최대10万엔, 현금 또는 기프트카드 선택）＋②区独自新生児誕生祝金（정액2万엔, 현금)**의 **2단 구성**이다. 이는 世田谷区 패턴(국가 妊婦支援給付＋区独自定額給付)과 구조적으로 유사하나, 세타가야구는 区独自금액이 5万엔인 반면 목黒区는 2万엔으로 금액이 다르다.

세대 합산 시 최대 12万円（妊婦支援給付10万 + 区独自2万, 자녀 1인 기준）규모.

## ⚠️ 확인되지 않은 것 (unresearched)

- **소득제한 유무의 명시적 확인**: 신생아탄생축하금(01)과 妊婦のための支援給付(02) 두 페이지 모두 소득제한을 언급하는 문구가 원문에 전혀 없다. 이는 "소득제한 없음"을 강하게 시사하지만(같은 목록 페이지 05에서 初回産科受診費用助成・入院助産費用 등 다른 제도는 명시적으로 소득 조건을 기재하고 있어 대비됨), **목黒区가 명시적으로 "소득制限なし"라고 선언한 문구는 확인하지 못했다**. 기사에서는 "원문에 소득제한 규정이 없음(확인 가능한 범위에서 소득제한 없음)"으로 표현하고, "소득제한 없음"을 단정적 원문 인용처럼 쓰지 않도록 주의 필요.
