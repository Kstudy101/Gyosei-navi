## 核心数値（原文対照）

### チャレンジ資金（出典: `01`/`02`）

| 項目 | 原文の記載 | 根拠 |
|---|---|---|
| 対象者 | これから市内で新たに事業を開始しようとする中小企業者、又は創業後5年未満の者 | `01` 資金メニュー表 / `02` |
| 融資限度額 | 3,500万円（設備資金の場合は設備投資額の80%が融資限度額） | `02` メニュー表・注意事項2 |
| 融資期間 | 運転: 5年以内（据置6か月）／設備: 7年以内（据置1年） | `02` |
| 融資利率（期間別・上限） | 1年以内 年1.7%以内／3年以内 年1.9%以内／5年以内 年2.1%以内／7年以内 年2.4%以内 | `02`。HTMLの令和8年度利率表（融資期間5年）もチャレンジ資金 2.1%で一致（`01`） |
| 利子補給率 | 1.4%（ただし上限は融資利率） | `01` 利子補給率表 / `02` |
| 返済方法 | 元金均等・元利均等・期日一括 | `02` |
| 信用保証 | 創業関連保証／スタートアップ創出促進保証制度 | `02` |

| 申込 | 取扱金融機関へ。事業計画書の作成支援は（公財）千葉市産業振興財団 | `01` 流れ / `02` 注意事項5 |
| 記載時点 | 令和8年4月1日時点。今後変更の可能性あり | `02` 注意事項10 |

### 利子補給の優遇（出典: `01`/`02`）

| 項目 | 原文の記載 |
|---|---|
| 指定創業支援施設入居中 | 融資金額2,500万円を上限に利子補給率 2.0% |
| 指定施設退去後1年以内／ベンチャー・カップCHIBA入賞後1年以内 | 融資金額5,000万円を上限に利子補給率 2.0% |
| 指定創業支援施設 | CHIBA-LABO、千葉大亥鼻イノベーションプラザ、千葉県外資系企業スタートアップセンター、千葉大学サイエンスパークセンター、千葉大学知識集約型共同研究拠点 |
| 入金時期 | HTML: 毎年5月下旬と11月下旬／PDF: 毎年3月末と9月末に金融機関が集計し概ね2か月後入金（一致） |
| 申請 | 申込時の同意書により金融機関が代行。利用者の特別手続き不要 |

### SDGs推進支援（出典: `01`/`03`）

チャレンジ資金利用時、対象認証等を取得していれば利子補給率＋0.5%上乗せ（上限は融資利率−0.2%）および融資利率上限−0.1%引き下げ。令和8年4月から「ちばSDGsパートナー登録制度」は優遇対象外。
