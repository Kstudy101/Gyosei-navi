## 制度類型

**耐震対策費補助型（費用全額・上限あり／診断・改修・簡易改修・シェルターの4メニュー）** — 仙台・横浜・久留米等の木造耐震改修助成と同類型。高松市は令和8年度に上限を拡充し、診断・改修とも「費用の全額（上限付き）」表記。賃貸住宅も対象と明記。
