# 杉並区 創業スタートアップ助成事業（sogyo）

## 制度概要
杉並区内に主たる事業所を有し、創業後6か月以内の中小企業者を対象に、創業当初の経費（事業所家賃／ホームページ等作成費）の一部を助成する制度。年2回公募。所管：杉並区産業振興センター 就労・経営支援係。

## 制度タイプ分類
**現金給付型（助成金）**。融資あっせん型ではない。事業所家賃助成とホームページ等作成助成の2メニューがあり、申請者はいずれか一方のみ選択可（併願不可）。
