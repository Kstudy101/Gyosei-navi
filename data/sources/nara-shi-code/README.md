## 確認結果

- PDF 21ページ目（奈良県セクション、兵庫県の次）に以下の記載を確認:
  `292010　奈良県　奈良市　ナラケン　ナラシ`
- 直前の見出し行「290009　奈良県」（県コード）を確認した上で、その直下の最初の市区町村行が奈良市であることを確認。
- 検査数字込み6桁の団体コードは **292010**。
- このファイルの既存登録慣行（横浜市 141003→14100、名古屋市 231002→23100 等と同様、末尾の検査数字1桁を除いた5桁を採用）に従い、奈良市は **`29201`** として登録する。
- slug は県スラッグ「nara」との混同を避けるため、さいたま市（saitama-shi）・京都市（kyoto-shi）等と同じパターンで **`nara-shi`** とする。
- 奈良市は政令指定都市ではないため、区単位ではなく市全体を1エントリとして登録する（青森市・岡山市・静岡市と同じ扱い）。
- 奈良県として初の市区町村登録。
