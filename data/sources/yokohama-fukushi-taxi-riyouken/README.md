## 対象制度
- 制度名: 福祉タクシー利用券の交付（身体・知的・精神）
- 所管: 横浜市 健康福祉局障害福祉保健部障害自立支援課 移動支援係（TEL 045-671-2401 / FAX 045-671-3566 / kf-syojiritsu@city.yokohama.lg.jp）
- 制度類型: **現物給付型（利用券方式）** — 現金の直接支給ではなく、1枚500円上限の福祉タクシー利用券を交付する方式。東京23区の同種制度（千代田・港・新宿・品川・世田谷・渋谷・北区など）と同じ「福祉タクシー券」系列だが、横浜市は政令指定都市として区（行政区）単位の福祉保健センターが窓口になる点が特徴。

## 確認できた核心情報（すべて `01_riyoken.txt` 原文より）

### 対象者（市内在住、かつ福祉特別乗車券・敬老特別乗車証・特別乗車券・障害者自動車燃料券のいずれの交付も受けていない方）
1. 下肢・体幹・視覚・内部・移動機能障害のいずれかを含む1・2級の身体障害者手帳を持っている方
2. 愛の手帳（療育手帳）A1、A2を持っている方、又は障害者更生相談所・児童相談所で知能指数35以下と判定された方
3. 下肢・体幹・視覚・内部・移動機能障害のいずれかを含む3級の身体障害者手帳を持っている方のうち、愛の手帳（療育手帳）B1を持っている方、又は障害者更生相談所・児童相談所で知能指数50以下と判定された方
4. 精神障害者保健福祉手帳1級を持っている方

（背景資料で言及されていた「愛の手帳A1/A2、精神障害者保健福祉手帳1級」は原文で確認一致。ただし「身体障害者手帳1・2級」の対象は「下肢・体幹・視覚・内部・移動機能障害のいずれかを含む」場合に限定されており、全種別の1・2級ではない点に注意。また3級でも愛の手帳B1等の重複要件を満たせば対象になる区分がある＝背景情報より詳細）

### 交付内容・金額
- 1枚につき500円を上限に助成する福祉タクシー利用券を交付
- 福祉タクシー利用券を使用しても、タクシー事業者独自の「タクシー料金の割引」（メーター料金×0.9、10円未満切捨、迎車料金除く）は別途受けられる（併用可）
- 利用は交付者本人に限る（同乗者がいても利用は可、ただし本人以外の使用は不可）

### 交付枚数と有効期間
- 有効期間: 10月1日～翌年9月30日（年度単位）
- 通常: 年間84枚
- 腎臓機能障害で人工透析のためタクシーを週3回以上利用して通院している方: 年間168枚

### 1回乗車あたりの利用制限（2026年10月の制度変更 — 背景情報と一致・原文で確定）
- **令和8年（2026年）9月30日まで**: 1回の乗車につき7枚まで利用可能
- **令和8年（2026年）10月1日から**: 1回の乗車につき7枚までの制限が撤廃される
- 原文は上記2行のみで、変更理由や代替の上限設定（例: 金額上限に変更するのか等）についての言及なし → **撤廃後に別の制限（例:金額ベースの上限）が新設されるか否かは原文からは確認できず、不明**

### 利用方法
- 乗車の際、身体障害者手帳・愛の手帳・精神障害者保健福祉手帳のいずれかを乗務員に提示
- 手帳番号を明記した福祉タクシー利用券を乗務員に提出
- 利用前に必ず利用券表面に手帳番号を記入（点字も可）
- 本人確認のため、手帳の顔写真・手帳番号を乗務員が確認できるよう協力が必要
- 本券は貸与・譲渡・複写・換金禁止（不正発覚時は券の回収、以後1年間の交付停止、不正利用額の返還請求もあり得る）
- 神奈川県下で運行するタクシー会社が対象（ユニバーサルデザイン（UD）タクシーでも利用可）
- 福祉車両を利用できる事業者は別途PDF一覧あり（02ファイル、内容未読解）

### 他制度との排他性・切替ルール
- 福祉タクシー利用券、障害者自動車燃料券、福祉特別乗車券、敬老特別乗車証、特別乗車券の5制度のうち利用できるのは1つのみ（福祉タクシー利用券を申込むと他4つの交付は不可）
- 有効期間中に「福祉特別乗車券」または「敬老特別乗車証」へ切替可能（切替は有効期間中1回限り）。残り枚数（7枚＝1か月分、腎臓機能障害168枚交付者は14枚＝1か月分）から換算した切替可能月の一覧表あり（原文に表形式で記載、02の要約参照不要・01原文に直接記載済み）
- 福祉特別乗車券への切替時は年額1,200円（20歳未満600円）の利用者負担金が発生。敬老特別乗車証への切替は利用者負担金なし
- 敬老パス（敬老特別乗車証）はIC化されており、交換希望者は交換まで1か月程度要し、その間福祉タクシー利用券も利用不可 → 交換希望者は早めの区役所申請を推奨
