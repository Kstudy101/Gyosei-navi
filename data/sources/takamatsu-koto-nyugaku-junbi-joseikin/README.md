## 制度概要・類型

- **類型**: 現金給付型（返済不要の助成金）。市の「就学等支援基金」（令和5年度寄附金原資）による事業。
- 「高松市高等学校入学準備金貸付制度」という別の**貸付型**制度が存在し、本助成金との**併用不可**（両方認定された場合はどちらかを選択）。本README・記事化ではこの2制度を混同しないこと。

## 核心数値（原文根拠：01_kurashi.txt）

- **支給金額**: 35,000円（対象生徒1人あたり）、返済不要 — 01_kurashi.txt L51、02_chirashi2025.pdf p.1
- **支給時期**: 令和8年3月6日（金曜日） — L52、PDF p.1
- **申請期限**: 令和7年12月15日（月曜日） — L109、PDF p.1（電子申請は12月16日午前0時以降受付不可、とPDFに追記あり）
- **審査結果通知**: 令和8年2月13日（金曜日）頃発送予定（実際に2026年2月13日付で発送済みと本文冒頭に記載） — L37-41, L166
- **対象者要件（①〜④すべて満たす者）**:
  1. 住所要件: 令和7年11月1日時点で高松市に住所を有する生徒の保護者
  2. 受験（進学）要件: 令和8年度に高等学校等（高校・中等教育学校後期課程・高専・特別支援学校高等部）への入学を予定し出願を行うこと
  3. 成績要件: 中学校3年生（4月〜12月）の評定平均が3.0以上
  4. 経済要件: ア生活保護停止/廃止、イ市民税非課税世帯、ウ児童扶養手当受給、エ国民年金掛金減免、オ世帯所得が生活保護基準の1.3倍以下、カ令和7年1月以降の家計急変（離職・休職等）のいずれか
  — L56-100、PDF p.2
- **申請方法**: 電子申請（フォーム、外部サイト）または学校教育課窓口（高松市役所10階、平日8:30-17:00、祝日除く）での紙申請 — L111-129
- **必要書類**: 共通＝通帳等口座情報がわかる書類の写し・本人確認書類。ケース別（市外居住・年金減免・転入・家計急変）に追加書類あり — L131-162、PDF p.2
- **窓口**: 高松市教育委員会学校教育課 TEL 087-839-2616（〒760-8571 高松市番町一丁目8番15号本庁舎10階） — L210-218
