## 制度類型

**耐震改修費補助型（定率23%＋上限117.2万円）＋低料金診断派遣型** — 仙台市・横浜市等の木造耐震改修助成と同類型。青森市は補助率が**23%**・上限**1,172,000円**、改修の令和8年度募集が**1戸程度**と極めて少ない点が差別化になる。
