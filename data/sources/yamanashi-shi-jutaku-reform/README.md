## 確定した事実
- 制度名：市内の施工業者による住宅リフォーム工事費用を補助します（山梨市住宅リフォーム補助金）
- 補助額：工事金額の10％、上限15万円（令和8年度から15万円に増額。千円未満切り捨て）
- 対象工事：10万円以上（消費税込）の増築・改築・改修・修繕・模様替え・設備工事等
- 施工業者要件：市内に本社のある会社又は市内に住所を有する個人事業主で、市税の滞納がないこと
- 対象住宅：自己所有・自己居住の住宅（店舗等併用は自己居住部分のみ）、または市の空き家バンク登録住宅（空き家バンク経由の売買契約者も対象者に含む）
- 建築後5年経過した住宅が対象
- 補助は同一住宅・同一所有者につき1回限り
- 実施期間：令和9年3月31日まで。ただし年間予算の上限到達時点で受付終了
- 他の国・県・市の補助事業対象工事は対象外。交付決定前着手工事も対象外
- 問い合わせ：山梨市役所西館3階 商工労政課商工労政担当（内線2362,2363）
