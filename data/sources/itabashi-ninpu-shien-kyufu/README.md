## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 妊婦のための支援給付（ページ番号1056054、更新日2026年7月2日） |
| 1回目 | 妊婦支援給付認定後、妊婦1人あたり5万円。妊婦面接後の案内に沿って申請 |
| 2回目 | 出産予定日の8週間前の日以降の胎児の数の届出後、お子さん1人につき5万円。妊娠8か月アンケートと併せて送る案内に沿って届出 |
| 1回目対象 | 令和7年4月1日時点に妊娠中、もしくは同日以降に妊娠／医療機関で胎児心拍確認／申請日時点で板橋区に住民登録 |
| 2回目対象 | 令和7年4月1日以降に出産予定または出産／胎児の数の届出時点で板橋区住民登録かつ板橋区の妊婦支援給付認定済み |
| 신청期限 | 1回目: 胎児心拍確認日から2年間／2回目: 出産予定日の8週間前の日から2年間 |
| 지급 | 妊婦本人名義口座へ振込。受付から約2〜3カ月目安 |
| 대상外 | 同一妊娠で「出産・子育て応援給付金(旧事業)」受給済み、または他自治体で同事業を受給済み（二重受給不可）。他自治体で1回目のみ受給し2回目のみ板橋区で受ける場合は改めて妊婦給付認定申請等が必要 |
| 転入 | 妊娠中: 妊婦転入届→妊婦面接時に案内。出産後: コールセンターへ電話 |
| 転出 | 認定(届出受付)時点で板橋区住民登録があれば転出後も板橋区から振込 |
| 流産・死産 | 妊娠届出後は上記と同じ流れ。届出前の流産等も対象になる場合あり→健康推進課母子保健係またはコールセンターへ |
