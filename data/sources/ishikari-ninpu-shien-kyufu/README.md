## 根拠表（主制度＝01）

| 項目 | 原文の内容 | 根拠 |
|---|---|---|
| 制度名 | いしかりっ子の未来応援ギフト（妊婦のための支援給付） | 01 タイトル |
| 趣旨 | 伴走型支援と一体的に実施する給付金。妊娠にかかる経済的負担軽減のため、妊娠した方に2回に分けて支給 | 01 |
| 1回目 対象 | 胎児の心音が医療機関にて確認された妊婦 | 01 |
| 1回目 案内時期 | 原則、妊娠届を提出する際の面談時 | 01 |
| 1回目 金額 | 5万円（口座振込または金額相当の電子ギフト） | 01 |
| 2回目 対象 | 出産された方、または出産予定日まで8週間以内となった方 | 01 |
| 2回目 案内時期 | 原則、出産後1か月前後に実施する赤ちゃん訪問の面談時 | 01 |
| 2回目 金額 | 児一人当たり5万円（口座振込または金額相当の電子ギフト） | 01 |
| 多胎児 | 1回目は5万円、2回目は5万円×子の人数分 | 01 FAQ |
| 流産・死産 | 医師が確認した日から申請可能 | 01 |
| 人工流産 | 医師により胎児心拍が確認されたことが証明できる場合は給付可。手続は事前に担当課へ | 01 |
| 妊娠届なし | 「妊婦給付認定用診断書」が必要。発行手数料は自己負担 | 01・04 |
| 受取方法 | 二次元コード付きカード→ウェブ回答後、(1)口座振込（申請から約1〜2か月）または(2)電子ギフト（申請後すぐ） | 01 |
| 本人限定 | カード手渡し・振込口座とも妊婦本人 | 01 |
| 転出入 | 申請時点の居住市町村に相談。転入前・転出後の両方から支給は不可 | 01 FAQ |
| 養育者（父） | 令和7年度からの本事業では妊婦への交付金のため父は受け取れない（令和6年度までの出産・子育て応援事業では養育者として父が受け取れた旨の記載あり） | 01 FAQ |
| 問い合わせ | 子育て推進部 こども家庭センター 母子保健担当（石狩市役所1階）電話0133-72-3116 | 01 |
