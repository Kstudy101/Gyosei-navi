## 確定した中核情報と原文根拠

### 対象者（産後ケア事業）
- 越谷市に住所があり、産後ケアを必要とするお母さんと1歳未満のお子さんで、次のいずれかに該当
  - （1）家族等から十分な家事や育児の援助が受けられない方
  - （2）出産後、心身の不調や育児不安のある方
  - （3）流産や死産等を経験された方
  - ただし母子ともに入院加療が必要と診断されていない方、感染性疾患に罹患していない方
  - 根拠: `01_sango-care.txt`

### 自己負担額
| 区分 | 利用時間 | 利用料 |
|------|----------|--------|
| 訪問型 | 1回2時間まで | 1回500円 |
| 通所型 | 1回8時間 | 1回2,000円 |
| 宿泊型 | 1泊2日 | 1泊2日7,500円 |

- 宿泊型は通常1泊2日10,000円だがクーポン券により2,500円減免。1日増すごとに2,500円追加
- 市町村民税非課税世帯・生活保護受給世帯は利用料無料
- 根拠: `01_sango-care.txt`。PDF `03` も宿泊7,500円／通所2,000円／訪問500円で一致（事業名表記は「産後ケア事業「はぐ」」）

### 利用上限
- 訪問型・通所型・宿泊型合わせて7回（7日）まで
- ただし宿泊型については最大5泊6日まで
- 双子でも利用回数・利用料は変わらない
- 根拠: `01_sango-care.txt`

### 申請・利用の流れ
- 利用希望日のおおむね1か月前までにこども家庭センター（048-963-9179）へ相談。出産予定日の2か月前から相談可能
- 窓口で申請書兼同意書記入 → 郵送で利用承認通知書兼利用管理簿 → 本人が事業者へ連絡・調整 → 利用 → 事業者へ支払い
- 根拠: `01_sango-care.txt`

### 別制度：産後支援事業
- 産後4か月未満・1人1回・市が利用料のうち1,000円を負担。利用票は母子健康手帳別冊
- 根拠: `02_sango-shien.txt`。産後ケア実施施設一覧の★付き助産所等で併施
- 本記事の主対象ではないが関連として言及
