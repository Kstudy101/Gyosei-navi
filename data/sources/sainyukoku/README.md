## ⚠️ 미확인

- 특별영주자의 **6년 / みなし 2년**은 手続案内·해설의 기재로 확인했으나, 근거법(입관특례법)의 조문까지는 미취득.
  기사에서는 조문 인용 없이 입관청 기재로만 서술했다.
