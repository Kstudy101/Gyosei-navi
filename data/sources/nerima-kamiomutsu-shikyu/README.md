## 制度概要・類型
- 制度名: 高齢者等紙おむつ等支給事業
- 類型: **現物給付型（紙おむつ配達）＋実費償還型（入院時のおむつ代支給）の併用制度**
  - 紙おむつ配達: 区指定製品を月1回配達する現物給付。利用者は一部自己負担
  - 入院時のおむつ代支給: 病院で紙おむつ持込不可の場合に月額上限内で実費相当を支給（現金給付・年3回振込）

## 核心数値（原文根拠: `01_kamiomutsu.txt` L39-L72）
- **対象者**（すべて満たす必要あり）
  - 練馬区の介護保険被保険者（住所地特例で練馬区被保険者となっている転出者含む）
  - 要介護1以上（40〜64歳の要介護認定者含む）で常時紙おむつ等を必要とする方
    - 要介護1〜3は「排尿」または「排便」項目で「全介助、一部介助」または「見守り等」該当者に限定
  - 介護保険料所得段階「第8段階」以下（本人の前年合計所得320万円以下）
  - 除外: 生活保護受給者、所得段階「第9段階」以上、介護保険施設サービス入所者、他自治体等で紙おむつ支給を受けている方
- **紙おむつ配達の利用者負担**
  - 6,000円まで：購入金額の1割が利用者負担
  - 6,001円以上：注文金額から5,400円を差し引いた金額が利用者負担
  - 23区内および練馬区隣接市以外への配達希望の場合、別途配達料が利用者負担
- **入院時のおむつ代支給**
  - 月額上限5,400円（実費がこれ未満の場合は実費額）
  - 年3回（4月・8月・12月）各支給月25日前後に登録口座へ振込
  - 同一月に「紙おむつ配達」と「おむつ代支給」の重複受給は不可
  - 受給登録月より前に使用した紙おむつ等は助成対象外
- **申請方法**
  - 窓口申込み: 練馬・石神井・大泉・光が丘の各総合福祉事務所 高齢者支援係（電話番号は原文L87-90参照）
  - 電子申請: 「練馬区高齢者紙おむつ等支給事業電子申請フォーム」（外部リンク、原文にURL本体は記載なし）
  - 必要書類: 介護保険の保険証。施設退所者は退所証明書等、転入者は住民税課税（非課税）証明書
  - 問い合わせ: 高齢者支援課 高齢給付係 03-5984-2774
