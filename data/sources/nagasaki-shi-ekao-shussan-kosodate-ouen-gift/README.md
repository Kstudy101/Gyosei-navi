## 制度類型

現金振込型（妊娠時5万円＋出産後・胎児数×5万円）。国の「妊婦のための支援給付」を長崎市が「イーカオ出産・子育て応援ギフト」として実施。市独自ブランド名・伴走型相談（3回面談）付き。国家制度の出産育児一時金単独ではない。
