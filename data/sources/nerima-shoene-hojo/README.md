出典: `01_hojo.txt`

- 令和8年9月16日以降に提出された申請書は返送
- 令和8年第三回練馬区議会定例会に予算増額の補正予算案を提案予定。成立時は**10月中旬頃に受付再開見込み**（再開は本ページで告知）
- 設置完了日: **令和8年4月1日〜令和9年3月31日**

- 申請方法: 設置完了後に郵送または持参。個人・個人事業主は本人のみ電子申請可（委任時は不可）
- 問合せ: 環境部 環境課 地球温暖化対策係 補助金担当 TEL 03-5984-4706、本庁舎18階

### 補助金額（令和8年度パンフレット表）
出典: `05_panfuretto.txt` 1ページ目

| 対象設備 | 対象者 | 補助額 |
|---|---|---|
| 太陽光発電設備 | 個人・事業者・管理組合 | **定額8万円** |
| エネファーム | 個人・事業者 | **定額5万円** |
| エコキュート | 個人・事業者 | **定額3万円** |
| 高断熱窓・ドア | 個人・事業者・管理組合 | 経費の**1/6**（区内業者上限**20万円**／区外**12万円**、千円未満切捨て） |
| LED照明（マンション共用部分） | 管理組合のみ | 経費の**1/2**（49戸以下上限25万／50〜99戸50万／100戸以上75万） |

- 補助対象経費 = 機器費+工事費（税抜）。仮設費・事務手数料・諸経費は対象外（`01`・`05`）
- 区内業者 = 練馬区内に事業所等を有し、設置完了証明書・見積書・領収書いずれかに区内住所記載（`05`）

### 個人向け主な要件
出典: `05_panfuretto.txt` P.2〜
- **既存住宅のみ**（新築は対象外）。設置完了日が新築年月日から**1年以上**経過
- 区内居住かつ練馬区に住民登録、費用自己負担、住民税非滞納
- 令和3年度以降に同一種類設備で本補助金の交付決定を受けていないこと
- 太陽光: JETまたはIECEE-PV-FCS加盟海外認証、中古・リース不可、自己取付不可
- エネファーム: FCA登録製品
- エコキュート: 日本冷凍空調工業会の性能検定合格登録品
- 国・都補助との併用案内あり（`01`「併用可能な国・東京都の補助事業」）
