## 제도 유형: 현금직접형(返還不要の給付型)。国公立のみ県教委、私立は私学課。

## 원문 확정 사실
| 항목 | 원문 |
|---|---|
| 대상 기준일 | 令和8年7月1日現在で要件を満たす世帯 |
| 소득요건 | 生業扶助（高等学校等就学費）受給世帯、または保護者等全員の令和8年度道府県民税+市町村民税所得割額合計が182,500円未満 |
| 専攻科 | 生計維持者全員の所得割合計105,500円未満、または264,500円未満かつ扶養する子等3人以上 |
| 그 외 요건 | 高校等就学支援金の受給資格あり／保護者等が三重県内在住／7/1時点で休学中は対象外／特別支援学校高等部・児童入所施設・里親養育は除く／国籍・在留資格①〜⑦、該当しない場合は生保・非課税世帯のみ（留学の新入生除く） |
| 給付額(令和8年度・国公立・年額) | 生業扶助世帯 32,300円(全日・定時・通信・高専) ／ 非課税 全日・定時・高専143,700円、通信制50,500円 ／ 所得割105,500円未満 全日等47,900円、通信16,830円 ／ 105,500円以上182,500円未満 全日等35,930円、通信12,630円 ／ 専攻科 非課税50,500円、105,500円未満16,830円、264,500円未満かつ3人以上12,630円 |
| 国籍等①〜⑦非該当 | 専攻科の105,500円未満は10,100円、3人以上世帯も10,100円（表の※） |
| 지급 | 年1回、指定口座へ振込（学校に受領委任した場合は学校へ）。通算3回上限（定時制・通信制4回、専攻科2回）。返還不要。他の奨学金との併給制限なし（ただし受給で他制度が受けられなくなる場合あり） |
| 신청시기 | 令和8年7月（各学校ごとに締切あり。学校担当者へ申出、申請書類を受け取る） |
| 신청방법 | 在籍校の担当者経由。県外校在籍者の保護者は県教委へ直接問合せ |
| 필요서류 | 申請書(様式1／専攻科は1-2)、チェックシート、振込別紙2、国籍・在留資格別紙3、住民票（7/1以降取得、原則両親と生徒分）、通帳写し（学校委任以外）、生業扶助受給証明書（生保世帯）または所得課税証明書（それ以外）、県外校は在学証明書（様式5）、専攻科多子世帯は扶養親族申告書（様式9）、口座が申請者以外なら委任状（様式3） |
| 私立 | 私立高校等在籍者は 三重県環境生活部私学課 TEL 059-224-2161 |
| 家計急変世帯 | 令和8年7月2日以降の急変は別案内（月別給付額は手引に記載、本アーカイブ未取得） |
| 문의 | 教育財務課 修学支援班 TEL 059-224-2827／FAX 059-224-2319／kyozaimu@pref.mie.lg.jp |
