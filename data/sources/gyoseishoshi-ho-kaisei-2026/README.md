## 주요 사실 (기사 검수용 메모)

- 令和7年6月13日 公布 (法律第65号, 議員立法) / **令和8年1月1日 施行**
- ① 1条 「目的」→「行政書士の使命」 (국민의 권리이익 실현) ② 1条の2 新設 「職責」: 品位保持·法令実務精通·公正誠実 + **ICT 활용 努力義務** (2項) ③ 1条の4 1項2号: 特定行政書士 不服申立て 대리 범위 「作成した」→「**作成することができる**」 (본인신청·타 행정서사 작성 안건도 대리 가능) ④ 19条1項: 「他人の依頼を受けいかなる名目によるかを問わず報酬を得て」 문언 추가 ⑤ 21条の2 新設 (19条1項 위반: 1年以下拘禁刑/100万円) + 22条の4 (名称使用制限 위반 100万円) + **23条の3 両罰規定** (법인에도 罰金刑)
- 10条: 「誠実に業務」 문언 삭제 → 1条の2로 이동 (信用失墜行為の禁止 로 제목 변경) / 13条の17: 行政書士法人에 1条·1条の2 準用
- 19条 ただし書 (総務省令 정형 절차의 電磁的記録 작성 예외) 는 개정 전부터 존재 (新旧 대조 확인)
- 入管庁 経営・管理 改正GL (data/sources/keiei-kanri/02) 도 「弁護士及び行政書士以外の方が…報酬を得て業として行うことは行政書士法違反に当たるおそれ」 명시 → 교차 인용 가능
