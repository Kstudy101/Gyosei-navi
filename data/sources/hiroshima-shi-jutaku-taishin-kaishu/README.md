# 原文根拠表: 広島市 住宅耐震改修等補助事業

## 制度概要
- 制度名: 広島市住宅耐震改修等補助事業（耐震改修・現地建替え・非現地建替え・除却）
- 実施主体: 広島市（都市整備局住宅部 住宅政策課計画係）
- 対象: 昭和56年5月31日以前着工の木造在来軸組構法・伝統的構法の一戸建／併用住宅（地階除く2階以下）
