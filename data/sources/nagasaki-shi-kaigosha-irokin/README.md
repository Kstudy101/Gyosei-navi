## ⚠️ 원문에서 확인되지 않은 것（unresearched）

- **신청서 서식・필요서류・접수기간/기한**: 웹페이지・가이드북 모두 「総合事務所へ相談/くわしくは各総合事務所地域福祉課へ」만 안내. 신청기한・연간 접수 일정・필요서류 목록 없음 → unresearched.
- **개호자(가족) 측 市民税非課税 요건 여부**: 3요건의 (3)은 피개호자(고령자) 쪽 비과세로 읽히는 표현. 개호자 세대 비과세 별도 요건은 원문에 명시 없음 → unresearched.
- **家族介護用品支給과의 併給(동시 수급) 가부**: 원문 언급 없음 → unresearched.
- **예산도달・접수중단 여부**: 「受付終了」「予算到達」류 문구 없음. 개인 요건 판정형으로 보이나 원문 명시 없음 → `subsidy.status`는 잠정 `ongoing`.
- **조례・요강 정식 명칭**: 원문에 조례명 없음 → unresearched.

## writer용 차별화 포인트

- 那覇市・世田谷区・足立区의 家族介護慰労金과 **연액 10만엔・要介護4/5・비과세・개호보험 서비스 미이용**이라는 골격이 유사.
- 長崎市만의 차이: 미이용 판정 기간이 **「申請前6ヶ月」**（타 자치체는 대개 「1年間」）, 쇼트스테이 예외가 **「1ヶ月程度」**（那覇市는 1週間以内 등）.
- 가이드북(R7.10)이 웹페이지(2024-11-11更新)보다 최신이므로, 요개호도 요건의 「申請前6ヵ月に認定」 서술은 가이드북을 우선한다.
