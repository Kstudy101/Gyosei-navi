## 熊本市事業との関係（重複有無）

- 重複しない。県事業は「熊本市を除く」が原文で明記（01 L189, 02 第1条）。熊本市内の猫は市の事業（`data/sources/kumamoto-shi-neko-funinkyosei/`、熊本市動物愛護センター）が対象。
- 相違点: 県=2人以上の活動組織・グループ限定・原則10頭まで・県内他市町村エリア・県センター（宇城市）で実施・捕獲器貸出なし。市=（別アーカイブ参照）予約制で1人4頭まで・捕獲器貸出あり。
