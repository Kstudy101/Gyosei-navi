## ⚠️ 중요: 이 제도는 県→市町 경유 집행 구조

HTML本文・PDF裏面とも「※募集開始時期の異なる市町や未実施の市町もあるため、詳細等についてはお住いの市町にお問い合わせください」と明記。PDF裏面のフロー図でも「申請」「審査・交付決定」「実績報告」「審査・額の確定」の各ステップに「市町業務」と注記あり。

→ **県が予算・補助基準（補助率・上限）を定め、実際の申請受付・交付決定・実績確認は市町が行う**制度。市町によって募集開始時期が異なり、未実施（不参加）の市町も存在しうる。記事化する場合、「福井県内で一律に申請できる」という誤解を招かない書き方が必須（各市町の実施有無・受付時期は本調査の範囲外＝unresearched）。
