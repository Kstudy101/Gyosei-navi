## 確認できた数値・事実（原文一致）

- 太陽光: **8万円/kW（上限45万円）**（要綱第5条・案内・本文）
- 蓄電: **補助対象経費の1/3 または 20万円の低い方**（上限 **14.1万円/kWh の1/3**、千円未満切捨て）
- 対象: 既存住宅のみ。太陽光単独、または太陽光＋蓄電。蓄電のみ・新築は対象外
- 法人対象外。PPA・リース設置は対象外
- FIT/FIP認定不可。自家消費30%以上
- 予約申請期間（案内）: 令和8年5月25日〜令和8年11月30日／交付申請: 〜令和9年1月29日
- **本文冒頭（2026-08-03更新）**: 予算上限到達により**予約申請受付終了**。本年度追加募集予定なし → 記事 `subsidy.status: closed`
