## 原文根拠表（数値・条件）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 制度名 | 地域猫の不妊・去勢手術費用の助成 | 01 |
| 対象となる猫 | 地域猫（地域の有志が地域住民の理解と協力を得た上で不妊去勢し、エサ場・ふん尿等を一定ルールで管理する一代限りの猫）。飼い犬・飼い猫の不妊去勢は助成対象外 | 05, 03 |
| 助成対象者 | あらかじめ開始届出書を保健所に提出し届出済証の交付を受けた方（地域猫活動推進グループとして認定）。活動グループは成人3人以上 | 01, 05 |
| 届出時の主な要件 | 地域住民の合意／地区責任者（町内会長など）の承諾書／活動グループ（3名以上）／エサ場・トイレの特定／管理する猫の情報（頭数・性別・毛色など） | 01 |
| 助成金額（1頭あたり） | オス 5,000円／メス 10,000円 | 05, 07 |
| グループ自己負担の目安 | 市内のほとんどの動物病院で、オス・メスとも1頭あたり3,000円程度のグループ負担で手術できる（別途ノミ・ダニ駆除代などが必要な場合あり） | 05 |
| 手続きの流れ | ①届出・届出済証 → ②猫一頭ごとに補助金交付申請（届出済証添付）→ ③交付決定通知 → ④捕獲・不妊去勢手術（耳カット含む）→ ⑤交付請求（獣医委任または自己請求） | 01 |
| 飼い猫への助成 | 行っていない（FAQ明記）。野良猫については地域猫に対する不妊去勢手術費の助成等を実施 | 03 |
| 関連・別枠 | 公益財団法人どうぶつ基金の「さくらねこ無料不妊手術事業」に市が参加。当面は多頭飼養の崩壊現象を生じている施設の猫に活用 | 02 |
| 活動状況（参考） | 令和6年1月末現在、186グループが地域猫活動等を実施 | 06 |
| 問い合わせ | 生活衛生課 動物愛護管理係 電話099-803-6905／FAX099-803-7026 | 01, 05, 03 |

## 制度の種別分類

現金給付型（手術費用の一部助成・後払い請求方式）。地域猫活動推進グループ登録が前提。飼い猫向け一般助成ではない。融資あっせん型・現物支給型ではない。
