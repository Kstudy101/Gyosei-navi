# 板橋区立小・中学校給食費補助金制度（給食費無償化）

## 基本情報
- 市区町村: 東京都板橋区（prefSlug: tokyo / citySlug: itabashi / 総務省団体コード 13119）
- カテゴリ: kyoiku（教育・奨学金）
- 制度分類: **現金給付型（実質は保護者委任による現物給付相当）** — 保護者が学校長に給付金交付の申請・受領権限を委任し、区が学校長に補助金を交付、学校給食費相当額と相殺する仕組み。保護者に直接現金が振り込まれる制度ではない。
- 調査日: 2026-09-20

## 重要な訂正（topic-scoutのWebFetch要約との相違）

topic-scoutの要約は「低学年 月7,400円／中学年 月5,510円／高学年 月5,890円／中学生 月6,460円」としていたが、これは**学年と金額の対応が誤り**である。原因は、当該ページのHTML表が
```html
<thead><tr>
  <th colspan="3">小学生</th><th colspan="1">中学生</th>
</tr></thead>
<tbody>
  <tr><td>低学年</td><td>中学年</td><td>高学年</td><td rowspan="2">7,400円</td></tr>
  <tr><td>5,510円</td><td>5,890円</td><td>6,460円</td></tr>
</tbody>
```
という2行構成（1行目に学年ラベル＋中学生列の値、2行目に小学生3学年分の値）になっており、単純なテキスト抽出（`npm run source`のcheerioタグ除去や要約AI）では「ラベルの並び→値の並び」がそのまま1対1に対応していると誤読しやすい構造だったため。

生のHTML（`<table>`のcolspan/rowspan属性）を直接確認し、かつ`02_youkou.pdf`（板橋区立小・中学校給食費補助金交付要綱 別表・第4条）の表（こちらは行内にラベルと金額が同居する明確な3列表）と突き合わせた結果、**正しい対応は以下の通り**であることを確認済み:

- 小学生 第1・2学年（低学年）：月額 **5,510円**
- 小学生 第3・4学年（中学年）：月額 **5,890円**
- 小学生 第5・6学年（高学年）：月額 **6,460円**
- 中学生：月額 **7,400円**

（学年が上がるほど金額が上がる、直感的にも整合的な構造。topic-scout版は低学年が最高額になっており不自然だった。）

記事作成時はこの訂正後の数値を必ず使用すること。

## 制度の分類
- 給付形態: **保護者への現金振込ではなく、区→学校長への補助金交付による給食費相殺方式**（保護者の委任状に基づく代理受領スキーム）。実質的には給食費の無償化＝現物給付に近い性質だが、法的構成は「補助金交付」。
- 融資ではない。
- 所得制限なし（生活保護世帯の教育扶助受給者を除く）。
- 区外在住でも板橋区立校在学なら対象。逆に区内在住でも他自治体の学校在学なら対象外。
