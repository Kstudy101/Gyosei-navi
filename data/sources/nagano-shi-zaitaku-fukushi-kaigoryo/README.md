## 根拠表（記事に使う数値）

| 項目 | 値 | 根拠 |
|---|---|---|
| 制度名 | 在宅福祉介護料 | 01 タイトル・見出し |
| 目的 | 在宅で要介護高齢者を介護する方の労をねぎらい、家族の福祉増進 | 01「概要」 |
| 対象（介護者側） | 市内に1年以上居住する65歳以上の要介護高齢者を、基準日（7/1または1/1）以前1年間に居宅で通算180日以上介護している者 | 01「対象者」／02「1.対象者」 |
| 第1種 | 要介護4・5 → 年額35,000円 | 01「内容」／02「2.支給額」 |
| 第2種 | 要介護3 → 年額25,000円 | 01「内容」／02「2.支給額」 |
| 支給方法 | 口座振込 | 01「支給方法」 |
| 申請時期 | 7/1〜7/31 または 1/1〜1/31 | 01「申請時期」 |
| 支給時期 | 7月申請→9月、1月申請→3月（年1回。9月支給分は3月に重ねて給付しない） | 01「支給時期」／02「3.支給時期」 |
| 窓口 | 地域包括ケア推進課（第二庁舎1階）または各支所 | 01「窓口」 |
| 除外 | 基準日前日までに要介護高齢者が死亡・市外転出／基準日前日から福祉施設入所中（短期入所除く） | 01「注意事項」 |
| 問い合わせ | 地域包括ケア推進課高齢者福祉担当 TEL 026-224-8929 | 01・02 末尾 |

## 制度類型

家族介護慰労型（現金給付・年1回）。全国共通の介護保険住宅改修費とは別制度。
