## 核心数値（原文対照）

出典は特記なき限り `01_ninpu-shien-kyufu.txt`。

| 項目 | 原文の記載 |
|---|---|
| 制度名 | 妊婦のための支援給付／妊婦支援給付金（子ども・子育て支援法、令和7年4月1日施行） |
| 事業開始 | 令和7年4月1日 |
| 妊娠の定義 | 医療機関により胎児の心拍が確認できたこと |
| 1回目 金額 | 妊婦さん1人につき **5万円** |
| 1回目 対象 | ①令和7年4月1日以降に妊娠届出・妊婦給付認定の申請をし認定を受けた妊婦 ②令和7年3月31日までに妊娠届出をし、出産応援ギフト（又は類する支援）未申請（令和7年4月以降出産） |
| 1回目 申請 | ベビくる面談（旧：妊婦サポート面接）時の二次元コードからオンライン申請（マイナンバーカード・パスワード必要）。郵送希望者は面談時書類から申請書DL |
| 1回目 期限 | 胎児心拍確認日から2年間 |
| 2回目 金額 | **胎児の数×5万円** |
| 2回目 対象 | 出産予定日の8週間前を経過した妊産婦で、令和7年4月1日以降に出産し、**申請日時点で立川市に住民登録**のある妊産婦 |
| 2回目 申請 | 妊娠8か月アンケート（SMS）。回答完了画面・完了メールのURLから申請。郵送も可 |
| 2回目 SMS送付 | 予定日が月上旬(1–15日)→前々月15日以降の開庁日／下旬(16–31日)→前々月末以降の開庁日。SMS不可時は後日郵送 |
| 2回目 期限 | 出産予定日の8週間前から2年間 |
| 振込 | 申請指定口座。**妊婦本人以外の口座不可**。外国籍はカナ名義（アルファベットだと振込できない場合あり）。申請から給付まで**3か月程度**。ギフト選択者は簡易書留 |
| セブンペイメント | 令和8年4月申請分より選択可。申請時に「電子カタログギフト（現金受取可）」→ATM受取。メール到着後60日以内。商品交換申込期限は令和9年3月31日。コールセンター 0120-700-107 |
| 流産・死産 | 令和7年4月1日以降に流産・死産等で妊娠継続できなかった方も1回目・2回目とも申請可。期限は医療機関等確認日から2年間。方法は問い合わせ先へ |
| 旧制度（`02`） | 令和7年3月31日までに妊娠届・出生の方は旧・出産・子育て応援事業。出産応援ギフト5万円相当／子育て応援ギフト10万円相当（国5万・都5万）。登録期限は令和7年9月30日（経過） |
| 問合せ | 子ども家庭部 子ども家庭センター こんにちは赤ちゃん係（錦町3-3-6、042-523-2111 内線4722） |
