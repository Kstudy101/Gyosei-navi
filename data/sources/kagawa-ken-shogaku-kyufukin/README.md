## 원문에서 확정한 사실 (모두 `01` 근거)

| 항목 | 내용 |
|---|---|
| 制度名 | 令和8年度香川県奨学のための給付金（授業料以外の教育費支援、返済不要） |
| 基準日 | 令和8年7月1日（7月2日以降入学者は入学日） |
| 対象 | 基準日に保護者等（親権者）が香川県内在住、かつ 生活保護(生業扶助)世帯 / 道府県民税所得割+市町村民税所得割の合算額が 0円(非課税) / 105,500円未満 / 182,500円未満（本科生等）の世帯。専攻科生は264,500円未満かつ扶養する子3人以上も対象。就学支援金の対象者等が前提 |
| 対象外 | 保護者が賦課期日に海外在住で合算額不明/就学支援金対象校を既に卒業・修了/専攻科を既に修了/平成25年度から引き続き在学/児童福祉法の見学旅行費・特別育成費の支給あり |
| 県外在住の保護者 | 居住する都道府県へ問い合わせ(本ページは香川県在住者のみ) |
| 本校が県外にある場合 | 「県外の高等学校等」扱い(申請は県へ郵送/持参) |

外国籍・外国人学校の生徒(就学支援金新制度の対象外、R8新入生の留学生を除く)は生活保護世帯・非課税世帯のみ対象。

### 申請期限・方法・支給時期(令和8年度)

| 項目 | 内容 |
|---|---|
| 第1回締切 | 国公立・私立とも令和8年9月15日(火) |
| 第2回締切(最終) | 令和8年12月31日(木)消印有効。秋入学者・1回目に間に合わなかった人向け。期限後は受付なし |
| 県内校在学 | 在学校経由で提出(学校の指示に従う)。県へ直接提出も可(在学証明書または個人対象要件証明書が必要) |
| 県外校在学 | HP から書類DLまたは電話で郵送依頼。国公立/私立の別に問い合わせ先へ郵送または持参 |
| 審査結果通知 | 12月末頃(1回目締切後の申請者は令和9年3月末頃)に文書郵送 |
| 支給 | 年度内(3月末まで)に指定口座へ振込予定 |
| 主な書類 | 確認シート、受給申請書(第1号の1様式)、通帳写し貼付書、通帳コピー、在学証明書(県外校は必須)、生活保護受給証明書(生業扶助世帯)、課税証明書等(保護者全員)、国籍・在留資格確認書類、扶養誓約書(親権者が両親でない場合) |

### 家計急変世帯

- 原則、入学日(進級日)の属する年度の10月末日まで、または家計急変日から3か月以内に申請(様式は第1号の2)。
- 本科生等の金額は上表と同額。基準日が7月2日以降の場合は翌月以降の月数に応じた月割額。
- 県内校は令和9年3月1日までに在学校へ提出、県外校は令和9年3月1日消印有効。3月2日〜31日申請は令和8年度分の支給なし。

## 제도 유형 분류

返済不要の現金給付型・所得段階別(国の高校生等奨学給付金を都道府県が実施)。国公立と私立で金額が異なり、私立が高い。
