## トピックスカウト要約との差異・補足

- topic-scoutの「1回目5万円・2回目子ども1人あたり5万円（多胎児加算）」という要約は、金額の骨格は原文と一致する。ただし**原文には「双子なら10万円」という明示的な合算額の表記はなく**、「妊娠したこどもの数につき5万円」という単価表現のみである。記事では「子ども1人につき5万円（多胎の場合は人数分を支給、原文に合算額の明記なし）」と正確に書くべきで、topic-scout候補にあった「10万円」等の断定表現はそのまま使わない。
- **区役所窓口では一切受付できない**ことが1次資料（01・02とも）に明記されている。淀川区に限った特例や、淀川区役所独自の相談窓口は検索（WebSearch: `淀川区 妊婦支援給付金 site:city.osaka.lg.jp`）でも見つからず、大阪市の子育て支援マップ・淀川区トップページ等の一般案内ページのみがヒットした。よって**淀川区固有の独自ページ・独自運用は確認できなかった**（全市共通の中央集約型オンライン・郵送受付、外部委託事業者TETRAPOT株式会社が窓口業務を受託）。
- 旧制度「出産・子育て応援交付金事業」の終了日（令和8年3月30日）と新法定事業への移行時期（令和7年4月）は原文で確認済み。ただし出産・子育て応援交付金の**支給額や対象要件など詳細な旧制度内容そのもの**は今回未取得（終了案内ページのみ確認、旧制度の金額等は本アーカイブでは扱っていない）。記事では「旧制度は終了し、令和7年4月から法定事業に移行した」という事実のみ言及し、旧制度の金額比較はしない方針が安全。
