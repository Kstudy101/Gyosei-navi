## 重要な確認事項（Issue本文の断片抜粋との食い違い）

- Issue本文の断片には「（3万5千円）」という注記のみ引用されていたが、原文表を直接確認した結果、この「入学一時金」は**返還免除制度で使われる「入学一時金相当額」とは別物ではなく、同じ金額（大学等24万円/18万円/12万円、高校等10万8千円/7万2千円）を指す語だが、令和9年度から新たに「貸与時に前払いで受け取れる選択肢」として貸与額表に明示された**、という理解が正確である。
- 令和8年度（旧）の貸与額表には入学一時金の列が一切なく、単に月額×月数＝貸与総額という単純な構成だった。令和9年度で「入学一時金（希望者のみ）＋軽減後月額」という前払い選択肢が新設され、生涯貸与総額自体は変わらないことを合計計算で確認済み（例: 大学4年制 24万円＋3万5千円×48月＝192万円＝従来の月4万円×48月と同額）。
- 高校等の入学一時金（10万8千円・7万2千円）は、Issue本文の断片には数値が含まれていなかったため、原文HTMLで直接確認して補完した。
- 「入学一時金」は**追加でもらえる上乗せ給付ではない**。同じ生涯総額のうち、入学時にまとめて受け取るか、毎月均等に受け取るかを選べる制度である。この点を記事で誤解を招かないよう明記する。
