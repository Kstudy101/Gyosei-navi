# 福岡市 新規創業促進補助金（令和8年度）— 原文アーカイブ

## 対象自治体・制度

- 自治体: 福岡県福岡市（政令指定都市、市全体で1エントリ登録）
- 制度名: 令和８年度福岡市新規創業促進補助金
- 所管: 福岡市経済観光文化局創業推進部創業課
- カテゴリ: sogyo（創業支援）
- 制度種別: **現金給付（定額補助）型**。融資あっせんではなく、登録免許税相当額の定額補助金を直接交付する。国の「特定創業支援等事業」受講による登録免許税半額軽減とセットで、残り半額相当額を補助することで実質負担0円（最低税額の場合）にする制度。

## 接受状況（重要・時期依存）

取得日2026-09-20時点で、申請受付期間は令和８年４月１日～令和９年３月３１日（必着）であり、**取得日時点では受付期間中（募集中）** と読める。ただし以下の点に注意。

- 原文に「予算に限りがあるため、申請状況によっては、受付期間内でも受付を終了する場合があります（先着順）」と繰り返し明記されており（01: L312-314, L372 / 02: p1「先着順」、p2「募集期間内・予算内で先着順」）、実際の受付終了・予算消化状況はこのページの記載だけでは判断できない。
- ページ更新日は「2026年4月1日」（01: L284）であり、年度当初の案内がそのまま維持されている可能性がある。記事公開時点で福岡市公式ページを再確認し、受付中か終了かを都度確認する必要がある。
- 記事化する場合は「予算に限りがあるため、申請状況によっては早期に受付終了する可能性がある」旨を必ず明記すること。
