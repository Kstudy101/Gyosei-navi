## 주요 사실 (기사 검수용 메모)

- 在留資格 29종 (別表第一: 一の表 6·二の表 13(高度専門職·特定技能·技能実習 포함)·三の表 2·四の表 3·五の表 1 / 別表第二 4)
- 就労 구분: 一·二の表 = 정해진 범위 내 就労 / 三·四の表 = 就労不可 (資格外活動許可로 원칙 週28h) / 特定活動 = 指定書에 따름 / 別表第二 = 제한 없음
- 在留期間: 一覧表 원문 그대로 (特定技能1号 「3年を超えない範囲」, 留学 「4年3月」, 家族滞在 「5年」, 高度専門職2号·永住者 無期限)
- 技能実習 → 2027-04-01 育成就労 (ikusei-shuro-2027 기사 교차)
- 外国人雇用状況届出: 대상 = 外交·公用·特別永住者 제외 전원 / 雇用保険被保険者: 雇入れ 翌月10日·離職 翌日から10日以内 (資格取得·喪失届 備考欄) / 非被保険者: 雇入れ·離職 翌月末日 (様式第3号) / 罰則 30万円以下 (労働施策総合推進法40条) / 2020年3月〜 在留カード番号 기재 (厚労省 페이지 확인)
- 在留カード 新様式 2026-06-14: 1歳以上 顔写真, 券面에 「在留期間」「許可の種類」 미기재 → 読取アプリ로 확인 (R8.8.19 버전부터 표시)
- 不法就労助長罪 (73条の2): 3年以下拘禁刑/300万円, 「知らなかった」 항변은 過失 없을 때만
