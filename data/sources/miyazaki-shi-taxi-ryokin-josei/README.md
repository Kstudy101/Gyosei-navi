## 確認できた核心情報

### 交付内容
- **タクシー券**: 12,000円分（500円券×24枚）
- **ガソリン券**: 6,000円分（500円券×12枚）
- タクシー券とガソリン券の**選択制**
- 交付期間: 7月1日〜翌年6月30日（令和7年度分: 2025-07-01〜2026-06-30、令和8年度分: 2026-07-01〜2027-06-30）

### 交付要件
**手帳要件**（次のいずれか）
- 身体障がい者手帳 **1〜2級**
- 療育手帳 **A、B1、B2**
- 精神障がい者保健福祉手帳 **1級**

**所得要件**
- 障がい者が20歳以上: 市県民税の所得割非課税
- 障がい者が20歳未満: 市県民税の所得割非課税世帯

### 申請方法
- 必要書類（手帳、ガソリン券選択の場合は車検証）を持参し申請窓口で手続き（代理申請可）
