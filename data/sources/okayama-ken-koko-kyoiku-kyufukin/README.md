## 根拠表（01_page.txt より）

| 項目 | 原文の記載 | 
|---|---|
| 制度の性質 | 国の「高等学校等修学支援事業費補助金（奨学のための給付金）」を活用した、授業料以外の教育費負担を軽減する返還不要の給付金 |
| 支給回数 | 1人につき年1回、通算3回（定時制・通信制は4回、専攻科は2回） |
| 対象世帯 | 保護者が岡山県内に住所を有し、平成26年4月以降に高校等へ入学した高校生がいる世帯。基準日は令和8年7月1日 |
| 対象要件 | 就学支援金等の受給資格あり／保護者が県内在住／(1)生業扶助受給、(2)保護者等全員の令和8年度道府県民税・市町村民税所得割の合計が182,500円未満（専攻科除く）、(3)専攻科のみ別基準 |
| 家計急変 | 対象世帯になると認められる場合も対象 |
| 対象外 | 特別支援学校高等部／年度内全期間休学許可／県外在住保護者が他県で同種制度を申請／児童相談所・児童福祉施設入所や里親委託で見学旅行費等が別途措置されている場合 |
| 支給額（年額・国公立） | 生業扶助: 全日制・定時制 32,300円 ／ 非課税(0円): 全日制・定時制 143,700円、通信制 50,500円 ／ 所得割100円以上105,500円未満: 全日制・定時制 47,900円、通信制 16,830円（専攻科16,830円）／ 105,500円以上182,500円未満: 全日制・定時制 35,930円、通信制 12,630円 ／ 専攻科のみ 105,500円以上264,500円未満で扶養する子3人以上: 12,630円 |
| 注記 | 区分3・4は就学支援金【新制度】または学び直し支援金【新制度】の受給資格者のみ。制服が災害等で喪失・毀損した場合の加算分あり（金額は本文になし）。専攻科の上記以外は10,100円 |
| 申請先 | 県内の高校等在籍者は在籍校（学校から案内配布）。県立校生は学校事務室から順次案内 |
| 県外の高校等在籍者の窓口 | 国公立: 財務課 Tel(086)226-7572 ／ 私立: 総務学事課 Tel(086)226-7198 |
| 受付期限（県外の国公立高校等在籍者向け） | 通常申請（年額一括）: 令和8年10月30日（金）、最終期限 12月11日（金）／新入生一部早期給付（年額の4分の1）: 令和8年9月7日（月）／家計急変: 随時、最終期限 令和8年12月11日（金） |

## topics-db note との照合

- 全日制・定時制非課税143,700円、通信制50,500円、所得割182,500円未満: 原文と一致。
- 「県立高校・中等教育学校の生徒が対象」: 原文タイトルは県立・中等教育学校だが、本文の金額表は「（国公立）」表記で、要件は保護者の県内在住。県立校在籍者は在籍校経由。

## 国の制度との関係

- 国の補助金を活用した県の制度（原文）。国の制度名として「高校生等奨学給付金」という名称は原文に出ず、県の名称は「高校生等教育給付金」。
- 私立高校等の窓口は総務学事課（原文の連絡先欄）。私立分の制度詳細・金額は今回未精査。
