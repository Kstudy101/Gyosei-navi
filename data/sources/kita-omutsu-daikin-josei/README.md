# 東京都北区「要介護高齢者等おむつ代金助成」

- 原文URL: https://www.city.kita.lg.jp/socialcare-health/elderly/1008607/1008615.html
- 取得日: 2026-09-21
- 保存ファイル: `01_omutsu-daikin-josei.txt`（npm run source、HTML→テキスト化、原文まま）
- ページ更新日（原文記載）: 2025年6月10日

## 制度種別
現金助成型（入院・入所等で区支給の紙おむつを使用できない場合に、自費で購入したおむつ代の一部を現金で助成。上記「紙おむつ支給」の代替制度）

## 対象（原文 L20-36）
北区在住で次の全てに該当する方:
- 要介護3（ただし75歳以上のみ）、4または5の認定
- 常時失禁状態でおむつを必要とする
- おむつ指定の病院等に入院・入所している、または入院中の病院売店で購入し持ち込んでいる

除外対象:
- 介護保険施設（特養・老健・介護医療院）入所者
- 生活保護受給者
- 心身障害者紙おむつ支給の受給者

## 助成額（原文 L38-40、根拠明記）
- 月額6,000円を上限に助成
- 月のおむつ代が6,000円未満の場合は支払った実額を助成
- 申請月からのおむつ代金が助成対象（遡り不可が原則）

## 申請・請求方法（原文 L41-87）
- 最寄りの高齢者あんしんセンターで申請
- 「申請」（現金給付を受ける資格取得）と「請求」（実際に代金を受け取る手続き）の2段階が必要
- 請求は請求月ごとに毎回必要。ただし入院等やむを得ない事情の場合のみ1年間遡り請求可
- 請求月と支給月の対応表あり（例: 4-7月分→8月請求→9月支給、原文L75-85）
- 助成金は支給月末日までに受給者本人名義口座へ振込
- 必要書類: 介護保険証（要介護度記載）または認定結果通知、本人名義預金通帳（申請時）／おむつ代金領収書（請求時、品名・金額・病院名等の明記が必要）
