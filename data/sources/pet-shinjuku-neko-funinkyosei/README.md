## 원문에서 확정한 사실 (기사 근거)

新宿区는 조사한 4개 구(치요다・미나토・신주쿠・시부야) 중 **유일하게 「飼い猫」와 「飼い主のいない猫」 양쪽 모두를 별도 제도로 조성**하는 구.

| 항목 | 飼い猫（01） | 飼い主のいない猫（02） |
|---|---|---|
| 대상 | 신주쿠구민(재주・재근・재학)이 구내에서 사육하는 고양이 | 신주쿠구민(재주・재근・재학) + 구내에 서식하는 주인 없는 고양이 |
| 조성액(상한) | 오스 2,500円 / 메스 4,000円 | 오스 15,000円 / 메스 25,000円 |
| 신청 시기 | **수술 전**（수술 후 신청 불가） | **수술 전**（수술 후 신청 불가） |
| 承認書 유효기한 | 승인받은 달의 익월 말까지(3月 승인 시 3月末까지) | 좌동 |
| 신청방법 | 창구 또는 온라인 | 창구 또는 온라인（지정병원용/지정병원외용 양식 상이） |

| 지정동물병원 | 東京都獣医師会新宿支部가맹 17개 병원（원문에 병원명・주소・전화 전부 명시, 令和7年4月1日 현재） | 좌동 + 지정병원 이외(구내 한정)도 별도 정산방식으로 가능 |

## ⚠️ 원문에서 확인되지 않은 것

- **犬(개)의 불임거세 수술비 조성금 제도는 이 두 페이지 어디에도 없다.** 新宿区가 犬 대상 별도 제도를 운영하는지는 검색으로도 발견되지 않았음 — 「이 조사 범위에서는 확인되지 않음」으로 기록.
- 마이크로칩 장착비 조성 제도는 이 두 페이지에서 언급되지 않음(불명, 없다고 단정하지 않음).
- FAQ에 「보호한 주인 없는 고양이를 그대로 기르게 되면 飼い猫 제도를 쓴다」는 취급 기준이 원문에 명시돼 있어, 두 제도가 상호배타적이지 않고 신청자의 사육 의사에 따라 갈린다는 점은 확정 사실.
