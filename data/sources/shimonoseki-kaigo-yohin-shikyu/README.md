## 확인되지 않은 것

- 공식 페이지에는 「受付終了」「予算到達」문구 없음 → `subsidy.status: ongoing`으로 판단
- 배달 가능 지역・등록사업자 개별 목록의 상세는 PDF 표에 있으나 기사 본문에서는 「配達可能地域一覧表を確認」로 안내（수치 창작 방지）
- 신청 마감일・심사 소요일수는 요강・페이지에 구체 일자 없음
- 연간 합산 상한（6期×1万円）은 요강에 「1期当たり1万円」만 명시 — 연간 6만원으로 단정하지 않고 기 단위로만 기재
