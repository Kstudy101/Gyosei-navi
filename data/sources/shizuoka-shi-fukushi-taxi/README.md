## 確認済み事項（原文より）

### 重度心身障害者タクシー利用券
- 対象: 市内在住で身体障害者手帳1・2級（聴覚、音声・言語、そしゃく機能障害を除く）または療育手帳A
- 除外: 福祉施設入所・長期入院・自動車税や軽自動車税の減免を受けている方
- 助成額: 額面550円の利用券を年間24枚交付
- 使用: 1回の乗車につき1枚のみ。他タクシー券と併用不可
- 対象: 市と協定を結んだタクシー会社のみ

### 精神障害者タクシー利用券
- 対象: 精神障害者保健福祉手帳1級（施設入所・長期入院・自動車税減免除外）
- 助成額: 額面550円の利用券を年間24枚
- 重複不可: 重度心身障害者タクシー利用券と精神障害者タクシー利用券は重複不可
- 問い合わせ: 精神保健福祉課企画係 054-249-3179

### 車いす用タクシー利用券
- 対象: 重度心身障害者タクシー利用券の要件を満たし、かつ下肢・体幹障害3級以上、市から電動・リクライニング・ティルト式車椅子の給付または介護保険貸与を受けている方
- 助成額: 額面500円の利用券を年間48枚交付
- 使用: 1乗車につき複数枚使用可能

### 申請
- 初回: 電子申請可（葵・駿河・清水区別フォーム）
- 継続: 毎年3月頃に更新通知
- 窓口: 葵福祉事務所障害者支援課 054-221-1099 / 駿河 054-202-5818 / 清水 054-354-2106
