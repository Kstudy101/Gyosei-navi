## 確認できた事実（原文根拠あり）
- 対象①: 身体障害者手帳1・2級（下肢・体幹・視覚・内部障害のいずれかを含む方）
- 対象②: 療育手帳A1またはA2
- 対象③: 身体障害者手帳3級（下肢・体幹・視覚・内部障害含む）かつ療育手帳B1
- 対象④: 精神障害者保健福祉手帳1級
- ふれあいフリーパス・高齢者フリーパス（福祉パス）交付者は対象外
- 交付枚数: 月7枚（人工透析で週3回以上通院の腎臓機能障害者は月14枚）
- 助成額: 1枚につき運賃・迎車料500円まで（1回の乗車で複数枚使用可）
- 令和8年度分申請受付開始: 令和8年3月18日〜
- 申請窓口: 各区役所高齢・障害課
- 申請書類: 有効な各種手帳、旧福祉タクシー利用券（未使用）、印鑑（署名の場合は不要）
