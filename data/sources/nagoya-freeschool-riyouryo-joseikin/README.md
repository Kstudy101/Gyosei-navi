## 核心数値（原文根拠）

### 補助率・月額上限（01_seido / 02要綱第8条 / 03チラシ）

| 区分 | 補助率 | 月額上限（児童生徒1人） |
|---|---|---|
| 名古屋市の就学援助認定を受けている方等（特別支援学校在籍で同程度困窮と認められる場合を含む） | 2分の1（100円未満切捨て） | 22,000円 |
| 上記以外 | 4分の1（100円未満切捨て） | 11,000円 |

- 予算の範囲内で交付（要綱第8条第3項）
- 令和8年度に限り、要綱第9条第3項の提出期限「7月末日」は「9月末日」と読み替え（要綱第9条第5項）。公式案内・チラシは受付開始を9月1日と記載

### 対象外経費の例（01_seido / 03チラシ）

入学費・体験利用料・施設整備費・教材費・行事参加費・交通費・弁当代、土日祝・夜間・オンライン参加日、一度も通所していない月の利用料

## 確認されていないこと

- 個別施設が対象に該当するかの事前一覧（申請後の審査・ヒアリング・現地確認で決定とポータル記載）
- 令和9年度以降の補助率・上限・受付期間の継続条件
- 「就学援助と同程度に経済的に困窮」判定の具体的な所得基準額（要綱・ポータルに金額表なし。教育委員会認定）
