## 確定した制度内容（原文根拠あり）

### 対象者（`01_taxi.txt` 83〜91行目）
- 市内に居住し住民登録している重度心身障がい者で、次のいずれかを所持:
  - 身体障害者手帳1級又は2級
  - 視覚障害3〜6級（**令和7年度から拡充で新規追加**）
  - 療育手帳A
  - 精神障害者保健福祉手帳1級
- 除外: 自動車税・軽自動車税の減免を受けている方、リース車による自動車燃料費助成を受ける方

### 助成内容（`01_taxi.txt` 67〜79行目）
- 1枚740円以内の利用券を月2枚（年間最大24枚）交付
- 年度中に使い切った場合、申請により10月以降に月2枚（最大12枚）追加交付
- 1回の乗車につき1枚のみ利用可能
- 運賃と利用券（740円以内）との差額は自己負担

### 申請手続き（`01_taxi.txt` 103〜131行目）
- 令和8年度分の受付開始：令和8年3月26日（木）、午前8時30分〜午後5時15分、障がい福祉課5番窓口（本庁舎2階）。中道地区・上九一色地区は中道支所・上九一色出張所でも可
- 代理申請可
- 追加交付申請は10月以降、初回交付分を使い切ってから
- 申請書はPDF・エクセルでダウンロード可能
- 令和7年度分の有効期限は令和8年3月31日まで（追加交付分含む）
- 紛失時の再交付なし

### 利用できる業者
山梨県内のタクシー業者に限定（山梨県タクシー協会加盟会社、一部の介護タクシー／福祉タクシー含む。福祉有償運送は対象外）
