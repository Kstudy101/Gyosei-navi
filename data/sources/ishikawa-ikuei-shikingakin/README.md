## 確認された事実（記事に使える）

### 貸与型奨学金
- 石川県育英資金（高校）:
  - 対象: 高校生、高等専門学校生（1〜3年生）、専修学校生（高等課程）
  - 月額: 国公立自宅18,000円、国公立自宅外23,000円、私立自宅30,000円、私立自宅外35,000円
- 石川県育英資金（大学）:
  - 対象: 専修学校生（専門課程）、大学生
  - 月額: 44,000円（区分なし）

### 給付型奨学金
- 畠山育英資金: 高校生・月額8,000円（給付）
- 石川県立商業高等学校育英資金: 高校生・月額8,000円（給付）

### 申込資格
- 保護者等が現に石川県内に居住していること
- 勉学意欲があり、かつ、学資の支弁が困難な者であること
- 独立行政法人日本学生支援機構の奨学金の貸与を受けていない者であること

### 申込区分
- 在学採用（各学校に入学している方）: 4月10日〜5月15日（学校から県への申込み期間）
- 予約採用（高校入学予定の中学3年生）: 9月1日〜10月5日
- 緊急採用（家計急変による場合）: 随時

### 支給日
- 原則毎月10日（4月分は5月に4・5月分を合算支給）
- 在学採用初回は8月末（4〜8月分を合算）

## 確認されていないこと
