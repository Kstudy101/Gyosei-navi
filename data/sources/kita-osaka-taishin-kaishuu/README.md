## 核心数値（01原文より）

- 制度名: 民間戸建住宅等の耐震診断・改修等補助制度
- 令和8年度受付開始: 4月1日（お知らせ）
- 耐震診断: 補助率11/10、限度額 1戸5万円 / 1棟20万円、申請締切 12月28日
- 耐震改修設計: 補助率2/3、限度額 1戸10万円 / 1棟18万円、申請締切 12月28日
- 耐震改修工事: 補助率1/2、限度額 1戸115万円、申請締切 12月15日
- 解体工事（耐震除却）: 補助率1/3、限度額 1戸70万円 / 1棟140万円、申請締切 12月28日
- 対象住宅: 大阪市内民間住宅、平成12年5月31日以前建築
- 予算到達時: 受付停止・終了あり（注2）
- 申請窓口: 大阪市都市整備局 耐震・密集市街地整備 受付窓口（大阪市住宅供給公社内）電話06-6882-7053

- 耐震シェルター拡充の個別上限額は事前相談前提のため記事では詳細金額を書かない。
- 住まいカテゴリに掲載の空家利活用改修補助・新婚子育て利子補給は大阪市共通の別制度。本記事の主対象ではない。
