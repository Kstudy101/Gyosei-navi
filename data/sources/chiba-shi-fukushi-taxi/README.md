## 確認された主な事実

- 制度名: 福祉タクシー助成事業 / 自動車燃料費等助成事業（二者択一）
- 対象（共通）: 身体障害者手帳1・2級、療育手帳○A（○Aの1・○Aの2）〜Aの2、精神障害者保健福祉手帳1級、特別児童扶養手当1級受給者、障害児福祉手当・特別障害者手当受給者、福祉手当（経過措置）受給者、小児慢性特定疾病重症患者。所得制限あり（特別障害者手当の所得制限限度額を超える方は対象外）
- 福祉タクシー:
  - 一般タクシー（黄色券）: 運賃2,600円以内は半額（10円未満切上）、2,600円超は1,300円割引
  - リフト付タクシー（水色券）: 運賃11,000円以内は半額（10円未満切上）、11,000円超は5,500円割引
  - 交付枚数: 年間30枚（年度途中新規は減少）。人工透析で週2回以上通院の方は追加交付可
  - 利用期間: 8月1日〜翌7月31日
- 自動車燃料費等助成:
  - 第1期（8〜11月）5,000円・第2期（12〜3月）5,000円 → 2月に合計10,000円振込
  - 第3期（4〜7月）5,000円 → 8月に振込
  - 通年資格ありで年15,000円
  - 助成対象自動車は1台につき原則1人（営業用除く）
- 窓口: 身体・知的・手当系は各区高齢障害支援課、精神・小児慢性は各区健康課
- ページ更新日: 2026年8月28日（HTML）
- 受付状態: 通年制度（ongoing）。利用券は7月所得確認後、対象者へ当該年度分を送付
