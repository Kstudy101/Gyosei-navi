## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 北区妊婦のための支援給付（令和7年4月より実施。子ども・子育て支援法等の改正を踏まえ） |
| 1回目 | 妊婦一人につき現金5万円。はぴママたまご面接時の電子申請用二次元コードから申請 |
| 2回目 | 子ども（胎児）一人につき現金5万円。赤ちゃん訪問時の二次元コードから申請 |
| ギフトカード代替 | 現金の代わりに東京都のギフトカード5万ポイント（育児・家事支援用品等限定）を希望可。保健サービス課へ連絡。簡易書留郵送のため口座不要 |
| 대상 | 申請時点で北区住民登録／2025年4月1日以降に妊婦／医療機関で胎児心拍確認。2025年4月1日以降の流産・死産も対象 |
| 他自治体 | 北区以外で1回目を受けた方は2回目のみ受給可。転入者は前住所未受給なら北区で申請可（前市区町村へ支給状況確認あり） |
| 지급방법 | 妊婦（産婦）本人名義口座のみ（旧姓・パートナー口座不可）。申請から振込まで1か月〜1か月半程度 |
| 신청期限 | 1回目: 胎児心拍確認日から2年間／2回目: 出産予定日の8週間前の日から2年間（予定日前出産はその日から2年間） |
| 旧制度 | 2025年3月31日までに出産→出産応援ギフト・子育て応援ギフト対象。同日までに出産応援ギフト申請済みなら1回目は対象外 |
| 区独自の現物 | はぴママたまご面接後に「はぴママグッズ」送付（金額は原ページに未記載、PDF案内）。ひよこ面接後にカタログギフト |
| 문의 | 保健サービス課保健サービス係 03-3908-7050／各健康支援センター |
