## 確認されていないこと

- 市チラシに記載の「取扱金融機関所定利率」の具体的な通常金利（優遇以外の標準利率）の一覧値
- 令和8年度の市側保証料補給予算残額・受付終了の有無（随時要確認）
- スタートアップ創出枠の詳細要件（県制度側の定義）
- 地場産業振興資金は「1年以上同一事業を営んでいる事業者」対象のため、本記事の創業枠主題からは除外

## 制度類型

信用保証料補給型（県特別保証融資＋市保証料補給）。現金直接補助型ではない。
