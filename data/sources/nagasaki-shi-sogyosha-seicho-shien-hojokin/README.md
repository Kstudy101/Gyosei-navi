### 訪問客還元事業の定義（01 / 04）
長崎市外からの訪問客をターゲットとしたサービス向上又は高付加価値化に係る事業。

## 確認できていないこと / 注意

- 現時点の残余予算・採択件数は公式ページに未掲載（予算到達で途中終了しうる旨のみ明記）。
- ⑵「その他の事業」の補助率は PDF テキスト抽出では空欄に見えるが、公式 HTML 表で `2分の1` が rowspan=2 のため双方に適用と判断。記事でもその根拠を明示する。
- 国 jGrants 単独制度ではない（市独自）。県制度との併用可否は「同様の趣旨の他の補助金等の交付を受けていないこと（国または県によるものを含む）」とあるため、趣旨が同じ補助金との併用は不可。
