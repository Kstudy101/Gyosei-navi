## 選定方針（このセッションの担当範囲）

ユーザー指示（2026-09-20）: 「大阪市24区のうち人口上位から」着手。
上位6区 = 淀川区・平野区・東淀川区・城東区・住吉区・北区（表4-1原文で確認済み）。

## 確認されていないこと

- 各区の福祉・住宅・創業支援等、個別カテゴリの補助金制度内容はこのアーカイブの対象外。カテゴリごとの記事作成時に別途 `data/sources/<slug>/` で一次情報を取得すること。
- ローマ字スラッグ（yodogawa, hirano, higashiyodogawa, joto, sumiyoshi, kita）はヘボン式表記を採用したが、総務省の公式ローマ字表記文書までは確認していない。既存の東京23区registrations（chiyoda, minato等）との命名パターン踏襲。
