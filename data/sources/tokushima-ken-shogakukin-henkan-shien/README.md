## 核心事実（01/02/05/07/08より）

- 実施: 令和8年度も実施中。「助成候補者」募集期間 令和8年7月31日(金)〜令和9年1月22日(金)（当日消印有効、電子申請は同日23:59まで）。
- 枠は2つ:
  - 全国枠: 募集250名程度。区分1=大学等（大学3・4年生など）の在学生、令和8年度(令和9年3月卒)または令和9年度(令和10年3月以外も含む)に修業年限内で卒業予定。区分2=既卒者（県外在住・令和7年度以前卒・令和9年4月1日時点で30歳まで・返還残額あり・滞納なし）。
  - 県内枠: 募集50名（うち徳島大学「生物資源産業学部」及び「医光/医工融合プログラム」進学者枠10名）。県内の高校3年生等で令和9年度に大学(短大除く)へ進学(編入)予定、JASS第一種(無利子)貸与を希望する方。応募は在籍校経由。
- 共通要件（全国枠）: JASS等の無利子/有利子奨学金を貸与中または貸与済、県内事業所に正社員就業希望（公務員除く）、卒業後県内に住所を有する予定、修業年限内卒業。就業開始期限: 在学生は卒業翌年度の9月末まで（要項では卒業月翌月から6か月以内、3月以外卒業は12か月以内）、既卒者は令和8年7月31日〜令和10年9月末（令和8年7月30日以前から県内で就業中の者は対象外）。県内就業返還免除型の公的貸付(医師・看護師・介護福祉士・保育士修学資金等)や県内就業要件の公的給付(青年就農給付金等)の利用者は原則対象外（貸付期間が重複しない場合を除く）。
- 助成金額（全国枠、借受総額に対する割合と上限）:
  - 大学(短大除く)・大学院・高専(4・5年・専攻科): 無利子 1/2・上限125万円／有利子 1/3・上限85万円
  - 専修学校専門課程: 無利子 上限95万円／有利子 上限60万円
  - 短期大学: 無利子 上限60万円／有利子 上限40万円
  - 既卒者は上記と令和9年3月31日時点の返還残額の少ない方。千円未満切捨て。入学時特別増額貸与奨学金は対象外。無利子・有利子の両方の場合は無利子で算定し、有利子上限まで加算。
- 助成方法: 助成候補者に認定後、県内事業所で3年以上就業した場合に支援開始。就業4年目から8年目の5年間、毎年度、助成金額の1/5を返還費用として助成。
- 認定: 書類審査。結果は令和9年4月中を目途に郵送通知（要項/手引）。県内枠も令和9年4月中目途。
- 申請方法（全国枠）: 電子申請（https://apply.e-tumo.jp/pref-tokushima-u/offer/offerList_detail?tempSeq=16845）または簡易書留郵送。書類: 認定申請書(様式第1号)、奨学金貸与証明書等(既卒者は返還証明書)、学業成績証明書、住民票写し(既卒者のみ)、チェックリスト。
- 問い合わせ・書類提出先（R8・01ポータル）: 〒770-8055 徳島市山城町東浜傍示1-1 (株)テレコメディア内 令和8年度徳島県奨学金返還支援制度事務局 TEL 088-602-1422 / henkanshien@schol.jp（平日9:00〜17:00、6〜7月・1〜2月以外は月・水のみ対応）。県担当課: 徳島県こども未来部こども未来政策課（03記載 088-621-2787, henkan@pref.tokushima.lg.jp はR7時点情報）。
- 改正: 令和7年4月1日から上限100万円→125万円、自己都合離職後6月以内に県内企業へ転職なら認定取消なし。令和6年4月1日から県外転勤(通算36月以内)を県内就業期間とみなす等、在籍校推薦書不要化（06）。
- 別制度との区別: 04は企業向け「奨学金返還支援基金」寄附募集（サポート企業）。市町独自の奨学金返還支援も別に存在（01に「各市町にお問い合わせ」とのみ）。
