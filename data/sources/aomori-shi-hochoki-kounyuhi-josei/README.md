# 青森市 高齢者補聴器購入費助成事業 — 原文アーカイブ

## 対象自治体・制度
- 自治体: 青森県青森市（regionCode `02201` / slug `aomori-shi`）
- 制度名: 青森市高齢者補聴器購入費助成事業（通称: 高齢者補聴器購入費の助成）
- 所管: 青森市福祉部高齢者支援課（駅前庁舎）／浪岡地区は浪岡振興部健康福祉課 介護保険チーム
- カテゴリ: kaigo（高齢・介護）
- 制度種別: **現金助成（代理受領）型**。購入前申請→交付決定・助成券交付→認定店等で助成額を差し引いて購入し、販売店が市へ請求する仕組み。既存の `aomori-shi-hari-kyu-massage-josei`（受療券型）とは別制度。

## 既存記事との差別化

- `aomori-shi-hari-kyu-massage-josei`: はり・きゅう・マッサージ受療券。本制度は補聴器購入費助成で別制度。
- `kumamoto-shi-hochoki-kounyuhi-josei`: 同系統だが、熊本市は市民税非課税世帯（または生活保護）要件あり。青森市は市税滞納なし（分割納付可）で、市民税非課税は要件に含まれない。
