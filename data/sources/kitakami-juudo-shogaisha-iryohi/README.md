## 이 제도가 「개인 직접 신청형 시 자체 예산 보조금」임을 뒷받침하는 원문 근거

- 01번 원문 L110-112: "医療費助成を受けるには／国保年金課公費医療係に申請を行い、認定されると「福祉医療費給付受給者証」が交付されます。" — 신청 주체가 수급자 본인(미성년은 보호자)이며, 시청 창구(国保年金課)에 개인이 직접 신청하는 구조임을 명시.
- 01번 원문 L134-152: 필요서류가 개인 명의 서류(본인의 보험정보, 마이넘버, 예금통장 등)로 구성되어 있어 단체·법인 대행 신청 절차가 아님.
- 02번 원문 L31, L59-81: 대상 확대분도 동일하게 "受給者証の交付申請手続が必要"이며 제출처가 "福祉部国保年金課公費医療係（本庁舎1階9番窓口）"로 개인이 시청 창구에 직접 제출하는 구조.
- 단체전용 신청, 사업자 대행신청, 민간단체 경유 등의 문구는 두 원문 어디에도 등장하지 않음.
