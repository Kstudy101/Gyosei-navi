## topics-db note との差異
- 補助率1/2・上限100万円・4/2〜4/30・所管課・電話: 原文と一致。
- 差異/補足: (a) 令和8年度募集は**終了済み**（02、2026-05-01）。県ページ01は終了表示なしで更新されていない。(b) 制度名は「助成金」で、実際の窓口・申請先は県ではなく(公財)千葉県産業振興センター(043-299-1078)。県経営支援課は案内窓口。(c) 「創業予定者」も対象だが、特定創業支援等事業の証明書またはインキュベーション施設入居のいずれかが必須。
