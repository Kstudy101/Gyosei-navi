# 那覇市：省エネ改修工事に伴う固定資産税の減額（熱損失防止改修等住宅の減額）

## 制度の種類

**現金給付ではない。固定資産税の減額（税制優遇型）。** 那覇市が独自財源で交付する補助金ではなく、**地方税法附則第15条の9第9項・第10項**（国の税制）に基づき全国一律で適用される特例を、那覇市税条例附則第6条の3第8項により那覇市が受付・処理している制度。記事化する場合は「補助金」ではなく「固定資産税減額（税の特例）」として明確に区分すること。
