## 制度類型分類

**利用券型（年額上限・決定日連動）** — 現金ではなく紙おむつ利用券を交付し、指定事業者で紙おむつ・尿とりパッドを購入。他市の月額給付券型（例: 久留米市月3,000円）や現物配達＋自己負担型とは設計が異なる。
