## 制度の性質に関する重要な注記

**群馬県が個人に直接補助する制度ではない。** 市町村が実施している耐震改修補助制度に協調して、県が市町村に補助を行う「県費補助」の仕組みであり、事業は市町村を通じて実施される。耐震改修を希望する住民は住んでいる市町村窓口へ問い合わせる必要があり、県への直接手続きは不要（原文: 「県への手続きは不要です」）。
したがって記事化する場合、タイトル・本文で「群馬県が個人に直接給付する補助金」ではなく「市町村の耐震改修補助制度に県が上乗せ補助している制度で、住民は市町村窓口を通じて申請する」旨を明確にする必要がある。実際の申請窓口・補助率・上限額は35市町村中26市町（令和5年7月末時点、全県人口比率97%）でそれぞれ実施されており、市町村ごとに制度の有無・詳細が異なる可能性がある。
