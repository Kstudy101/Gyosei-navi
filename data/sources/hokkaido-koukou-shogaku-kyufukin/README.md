## 확정 사실

- 返還不要。就学支援金(授業料)とは別制度で、別途申請が必要。前年度受給者も再申請必要(01)。
- 基準日: 令和8年(2026)7月1日(01)。
- 対象要件(01・03): 平成26年4月1日以降入学、基準日に国公立の高等学校等(専攻科含む・中等教育学校後期課程・高専1~3年・専修学校高等課程・就学支援金対象校)に在籍／保護者等が北海道内に住所(単身赴任等で世帯の生活本拠が道内なら道に申請可)／生活保護(生業扶助)受給世帯、または保護者等全員の道府県民税所得割+市町村民税所得割が182,500円未満(専攻科は別区分)。③④区分は就学支援金【新制度】等の受給資格者のみ。
- 給付額(年額・生徒1人) (01・02・03):

| 区分 | 全日制・定時制 | 通信制 | 専攻科 |
|---|---|---|---|
| 生活保護(生業扶助措置) | 32,300円 | 32,300円 | - |
| 非課税世帯 | 143,700円 | 50,500円 | 50,500円 |
| 所得割合算105,500円未満(年収270~380万円相当) | 47,900円 | 16,830円 | 16,830円 |
| 105,500円以上182,500円未満(年収380~490万円相当) | 35,930円 | 12,630円 | - |
| 専攻科: 105,500円以上264,500円未満かつ扶養する子3人以上 | - | - | 12,630円 |

  - 上記2区分(105,500円未満/182,500円未満)は今年度からの拡充(02)。専攻科③⑤で専攻科支援金【新制度】非該当は10,100円(01)。
  - 制服の災害等による再購入: 最大64,800円加算(03。詳細は問合せ)。
- 支給方法: 支給決定後、指定口座に一括振込(01)。
- 申請窓口・期限(01・03):
  - 道内国公立: 在学校に提出。道立・市町村立は7~8月の学校指定日、国立(高専等)は8~9月の学校指定日。
  - 道外国公立: 北海道教育委員会(高校教育課学校制度係 011-204-5760)へ郵送または持参。新入生8月31日(月)、在学生9月30日(水)(令和8年)。
  - 学校以外の問合せ: 道立=各教育局、国立・市町村立=高校教育課学校制度係。
- 書類(01): 申請書、口座振込申出書、国籍確認書類(道内校は就学支援金認定通知等/道外は住民票原本・在留カード写し等)、在学証明書(道外のみ)、個人対象要件証明書(専攻科のみ)、世帯区分別書類(生業扶助受給証明書／令和8年度道民税・市町村民税課税(非課税)証明書等 保護者等全員分)。
- 対象外(03): 就学支援金対象外の生徒、児童福祉法措置費で見学旅行費・特別育成費支弁、海外赴任等で課税証明書提出不可、定時制教科書給与事業/アイヌ子弟進学奨励補助受給、年度全期間休学予定。
- 家計急変世帯(04): 対象。7/1以前の急変は基準日7/1、7/2以降は申請月の翌月1日。道内は学校、道外は高校教育課へ。額は申請日で変動(「支給額一覧」PDFは未取得)。
- 私立分(05): 別制度・別窓口。北海道総務部行政局学事課。道内私立校は在学校へ、道外校在籍は令和8年10月23日(金)必着で北海道へ郵送。家計急変は8/31までの分が9月18日、9/1以降は令和9年3月5日まで随時。特別支援学校高等部は対象外(就学奨励費)。私立の給付額表は本ページ内の画像/表で未確認。
- 国立: 道内国立(高専等)は公立扱いで在学校へ申請(01)。道外国公立は上記のとおり道教委に直接。保護者が道外在住の場合は居住都府県の制度(01)。
