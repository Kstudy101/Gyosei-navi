# 神戸市 就学援助 — 原文アーカイブ

## 制度概要
神戸市が実施する小学校・中学校（義務教育学校含む）の就学援助制度。学用品費・給食費・修学旅行費など多岐にわたる費用を援助する（所得制限あり）。
