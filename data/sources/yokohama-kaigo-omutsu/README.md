## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 高齢者紙おむつ給付事業（介護保険以外のサービス로 분류） |
| 소관 | 健康福祉局高齢健康福祉部高齢在宅支援課（045-671-2405） |
| 대상 | 재택 ねたきり 또는 인지증 요개호자, 요개호4・5 또는 요개호1~3에서 각구 福祉保健センター長이 필요인정, 세대가 생활보호수급세대등 또는 시민세비과세세대 |
| 이용기준액 | 2,000円=1단위. 요개호4・5는 월상한8,000円(4단위), 요개호1~3(요인정)은 월상한6,000円(3단위) |
| 자기부담 | 이용기준액의1割(1단위200円・2단위400円・3단위600円・4단위800円). 생활보호수급세대등은 무료 |
| 신청 | 구 福祉保健センター(高齢・障害支援課) 또는 지역포괄지원센터 창구, 또는 조건부 온라인신청 |
| 배송시기 | 창구신청: 매월1일~말일신청→익익월분을 익월중순~말일 배송. 전자신청은 더 늦음 |

## ⚠️ 원문에서 확인되지 않은 것

- 家族介護慰労金(가족개호위로금) 명칭의 제도는 이 페이지 및 사전 웹조사에서 확인되지 않음 — 요코하마시가 이 제도를 운영하는지는 이번 기사에서 다루지 않음(존재를 단정하지 않음).
- 緊急通報装置(긴급통보장치)는 관련페이지로 언급되나 이번 원문취득 범위에는 없음.
