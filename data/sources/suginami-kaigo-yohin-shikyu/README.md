## 制度概要
在宅で生活する要介護高齢者に対し、月額7,000円を上限として「介護用品（おむつ等）の現物支給」または「入院時おむつ代金の助成」のいずれかを行う制度。同月内での両方の重複利用は不可。

## 制度の類型
**現物支給型（カタログ配送）＋現金助成型（おむつ代金助成）のハイブリッド制度**
- 介護用品の支給：現物給付（カタログから商品を選び配送）
- おむつ代金の助成：現金給付（入院時、領収書に基づき助成金を振込）

## 対象者（原文 01_gaiyo.txt 78-88行）
杉並区内に住所を有し、以下いずれかに該当する方：
- 要介護3以上でおむつが必要な方
- 要介護1・2で常時おむつが必要な方（医師の「身体状況確認書」による証明が必要。年1回「現況届」「身体状況確認書」の再提出も必要）

除外：介護保険施設（老健・特養等）入所者は対象外。逝去後の申請は不可。
身体障害者手帳等をお持ちの場合は別制度（心身障害者おむつ支給制度）の対象となり、支給品目・助成有無が異なる旨の案内あり（01_gaiyo.txt 100-108行）。

## 支給額・利用料（原文 32-77行）
### 介護用品の支給（現物支給、月次配送）
- 月額7,000円を上限にカタログから商品を選び配送
- 利用料金：区民税課税世帯＝注文総額の1割（上限700円）／区民税非課税世帯・生活保護受給者＝無料

### おむつ代金の助成（入院時、現金助成）
- 区民税課税世帯：月額上限7,000円－1割負担分（例：上限6,300円）
- 区民税非課税世帯・生活保護受給者：支払額の全額（月額上限7,000円）
- 助成対象は「決定月以降」のおむつ代のみ（決定月より前の分は対象外）

## 申請方法（原文 110-222行）
- 電子申請フォーム、または郵送・窓口（高齢者在宅支援課管理係、各ケア24＝地域包括支援センター）
- 要介護1・2の方は事前に「身体状況確認書」を取得の上で申請
- 決定月の判定：申請日が1日～25日→当月決定、26日～月末→翌月決定（25日が土日祝の場合は前開庁日が締切）
- 決定通知到着後、専用カタログから商品を選び「おむつ相談窓口」（電話：0120-8910-78）へ注文

## 助成金の請求・振込（現金助成分、原文 242-345行）
- 請求方法：電子フォーム、または郵送・窓口
- 必要書類：領収書等、おむつ持込可否確認書（第8号様式）、振込先口座情報
- 請求可能期間：おむつ使用月（決定月以降）から2年以内
- 振込は年4回（4月・7月・10月・1月末日）。請求月により振込月が異なる（1-3月請求→4月末、4-6月請求→7月末、7-9月請求→10月末、10-12月請求→1月末）
