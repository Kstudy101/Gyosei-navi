## 원문에서 확정한 사실

**① 妊婦のための支援給付金（01）— 現行・本記事の主対象**

| 항목 | 원문 |
|---|---|
| 제도 개시 | 令和7年4月1日から（子ども・子育て支援法改定により創設） |
| 페이지 갱신 | 2026年8月13日 |
| 1回目（妊娠時）対象 | (1) 令和7年4月1日以降に妊娠届出・妊婦給付認定申請をし認定を受けた妊婦 / (2) 令和7年3月31日までに妊娠届出をしたかたで出産応援ギフト未申請のかた。いずれも**申請時点で豊島区に住民登録** |
| 1回目 필수조건 | **医師による胎児心拍の確認が必須**。未確認は対象外 |
| 1回目 給付 | **5万円（現金かギフトを選択可能）** |
| 1回目 申請 | 妊娠届出後、ゆりかご面接の際に案内する二次元コードから電子申請 |
| 2回目（出産後）対象 | 令和7年4月1日以降に出産し、胎児の数の届け出日時点で豊島区に住民票がある産婦。申請時点の区住民登録が要件 |
| 2回目 給付 | **こども（胎児）の人数×5万円（現金かギフト選択可）** |
| 2回目 申請 | こんにちは赤ちゃん訪問の際の二次元コードから電子申請 |
| 現金支給 | **妊産婦名義の銀行口座のみ**（本人以外の口座名義は指定不可） |
| ギフト | 出産育児関連用品や家電製品等に使える**東京都のギフトカード** |
| 流産・死産等 | 対象。母子健康手帳で妊娠の事実・胎児数を確認。届出・面接前の流産等も診断書等で申請可。**異所性妊娠（子宮外妊娠）は対象外** |
| 문의 | 健康推進課管理・事業グループ 03-3987-4173／長崎健康相談所管理・事業グループ 03-3957-1191 |
