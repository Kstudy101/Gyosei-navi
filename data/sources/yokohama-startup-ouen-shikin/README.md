## 기존 기사와의 차별화

- `yokohama-sogyo-ouen-shikin`（創業おうえん資金）: 固定金利2.3%以内・信用保証料0.1%助成・個人/法人・経営者保証有/不要の2型。
- 本制度: **会社のみ**・固定金利**1.9%以内**・保証料**全額助成(負担ゼロ)**・担保・連帯保証人不要・スタートアップ創出促進保証制度連動。

## ⚠️ 원문에서 확인되지 않은 것

- 保証料「全額助成」の適用可否はア〜オの該当が前提。該当しない場合の保証料負担額は本ページに「助成前0.6%」以外の別途金額は未記載。
- 「創業おうえん資金（再挑戦）」は別制度（venture-retry.html）。本記事では扱わない。
- 現金直接補助型の市独自創業助成金の有無は今回未調査。
- 取扱金融機関の個別支店・審査基準・実際の承認率は原文になし。
