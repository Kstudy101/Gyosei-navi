# 福岡市木造戸建住宅耐震改修工事費補助事業 — 一次情報 原文

## 制度概要（分類）
- **制度種別**: 現金助成型（耐震改修工事費の定率補助・上限あり）／耐震シェルター等設置補助併設
- **所管**: 福岡市 住宅都市みどり局 建築指導部 建築物安全推進課（TEL 092-711-4580）
- **姉妹メニュー**: 木造戸建住宅耐震建替費等補助／建築物耐震診断費補助（R8より全建築物へ対象拡大）／ブロック塀等除却費補助

## 確認できた最終数値・条件（主制度＝改修工事費補助）

| 項目 | 値 | 根拠 |
|---|---|---|
| 制度名 | 福岡市木造戸建住宅耐震改修工事費補助事業 | 05 P.1／06 標題 |
| 対象住宅 | 昭和56年5月31日以前に建築確認を得て着工した木造戸建・地階除く2階以下（共同住宅は対象外）。昭和56年6月1日以降の増築等を含む | 01／05／06第6条 |
| 診断要件（改修） | 建防協基準で上部構造評点1.0未満 → 建物全体または1階を1.0以上にする工事 | 01／05／06第2条 |
| 補助額（A） | 耐震改修工事に要する経費の80％の範囲内・**上限150万円** | 01／05／06別表第1 |
| 補助額（B・利子補給利用時） | （A）算出額から工事経費の40％を減じた範囲内。減ずる額の上限**57.5万円** | 01／06別表第1 |
| 補助額（C） | 耐震シェルター等の購入・設置経費の40％・**上限25万円**（高齢者等居住が条件） | 01／05／06 |
| 受付 | 申請年度の**4月13日から**受付開始。予算・補助戸数に限りあり | 05 P.2／01 |
| 完了報告 | 申請年度の**1月末まで** | 01／05 |
| 事前契約禁止 | 交付決定前の工事契約・着手・完了は対象外 | 01／05 |
| 要綱期間 | 令和8年4月1日施行附則。要綱は令和11年3月31日をもって廃止予定（継続は要検証） | 06 附則 |

- `fukuoka-chiiki-koken-akiya-katsuyo`（空き家活用・改修）とは別制度・別所管メニュー。
