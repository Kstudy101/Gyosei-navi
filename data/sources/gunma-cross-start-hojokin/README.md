# gunma-cross-start-hojokin

対象記事（未執筆・government-researcher調査段階）: ぐんまクロススタート補助金（群馬県起業支援金）

## 制度の性質に関する重要な注記

群馬県が実施する**給付型の補助金**（融資ではない）。県公式ページ（`www.pref.gunma.jp/page/638116.html`）は制度紹介・リンク集にとどまり、実際の公募要項・補助額等の詳細は運営を委託されている公益財団法人群馬県産業支援機構のサイト（`g-inf.or.jp`）および県の報道提供資料に掲載されている。
2026年9月22日時点で確認できる公募情報は「令和8年度」分（公募期間：令和8年4月15日～5月22日17:00必着）であり、**産業支援機構サイトには「今年度の公募は終了しました」と明記**されている（記事化時は令和9年度の公募開始時期を要確認）。令和7年度分の公募期間（令和7年5月7日～6月9日）は県の報道提供資料で確認済み。
