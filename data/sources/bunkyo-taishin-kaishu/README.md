## 제도 유형 분류

- **耐震改修型（工事費一部助成・現金給付）** — 신주쿠구 `shinjuku-taishin-kaishu`・시부야구 `shibuya-mokuzou-taishin`과 같은 축.
- 하위 메뉴로 **除却(해체)형**・**耐震シェルター等**・**분양맨션 개수/재건축**이 한 팸플릿에 병설.
- 목조 일반・고령자등 조성은 **준방화지역 한정**이라는 점이 신주쿠(도로돌출・무접도 감액)와 다른 지역조건.

## ⚠️ 원문에서 확인되지 않은 것

- **「助成対象設計費・工事費」의 산정 상한단가**(예: 연면적×단가와 실비 중 낮은 쪽 등)는 표4에 명시되지 않음 — 요강・별도 안내 여부 미확인.
- **접수 개시일**의 명시적 날짜는 「令和8年4月から…拡充」만 있고, 4/1 개시인지 여부는 웹에 단정 문구 없음(팸플릿 작성월은 令和8年4月).
- **현재 잔여예산・접수 중단 여부**의 실시간 표시는 페이지에 없음 — 예산 한도 단서만 있음. 기사화 직전 전화 재확인 권장.
- **소득제한** 유무는 원문에 명시 없음.
- 진단(`03`)・설계(`04`)・容易な診断(`05`)의 개별 한도액은 본 아카이브 목적상 개수(표4) 중심으로 확정했고, 진단・설계 표의 수치는 기사에 쓸 경우 06 P.3〜6을 추가 대조할 것.
