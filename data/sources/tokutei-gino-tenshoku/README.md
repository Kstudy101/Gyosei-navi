## ⚠️ 확인되지 않은 것

- 「정당한 이유」의 구체적 판단기준(예: 구직활동 중이면 자동으로 정당한 이유로 인정되는지, 몇 개월까지 유예되는지)은
  원문에 명문 기준이 없다. 「구직활동 중이라는 사실 자체가 정당한 이유가 될 수 있다」는 일반적 해석은 있으나
  **몇 개월까지 인정된다는 수치 기준은 원문에 없음** — 기사에서 단정하지 않음.
