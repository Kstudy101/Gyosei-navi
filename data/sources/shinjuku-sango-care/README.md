## 채택 안 된 이유

`shinjuku-sanzensango-shien`(産前産後支援事業)를 최종 채택했다. 이 産後ケア事業은:
- 쇼트스테이형(1泊2日〜6泊7日)・데이서비스형(2回)・아웃리치형(訪問型) 3종 중 **아웃리치형만 원문에 금액이 명시**(1回1,000円, 원문222줄)
- 쇼트스테이형・데이서비스형 요금은 원문 본문에 없고 별도 PDF(令和8年度ショートステイ型・デイサービス型利用案内)에만 있어, 이 조사에서는 PDF까지 다운로드해 확인하지 않음
- 産前産後支援事業 쪽이 원문(HTML) 하나에 모든 수치(단가・연령구간별 상한시간)가 완결돼 있어 원문 검증 신뢰도가 더 높아 이쪽을 채택

향후 産後ケア事業을 별도 기사로 다룰 경우, 반드시 PDF 2종(令和8年度ショートステイ型・デイサービス型利用案内, 令和8年度アウトリーチ型利用案内)을 직접 다운로드해 원문 확인할 것.
