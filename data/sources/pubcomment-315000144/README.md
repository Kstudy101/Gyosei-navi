## 요지 (원문 근거)
- 趣旨: **令和8年7月24日** 일본·브라질 정부 간 워킹홀리데이 사증 **書簡 교환** → 告示 第5号의 대상국에 ブラジル連邦共和国 추가
- 新旧対照: 파나마(口上書 그룹 말미 삽입)와 달리, **「又は日本国政府のブラジル連邦共和国政府に対するワーキング・ホリデーに関する書簡」 이라는 별개 그룹을 협력각서 그룹 뒤에 신설**한다
  (現行 第5号은 ①口上書 ②協定 ③協力覚書 의 3그룹 구성 → ④書簡 추가)
- 附則: **この告示は、令和八年十二月一日から施行する。**
- 今後の予定(概要): 公布日 **令和8年12月1日** / 施行日 **令和8年12月1日** (공포일과 시행일이 같음 — 파나마는 10/30 공포·11/1 시행으로 다름)
