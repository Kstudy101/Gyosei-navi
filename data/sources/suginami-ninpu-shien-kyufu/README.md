## 원문에서 확정한 사실

**① 妊婦のための支援給付（01, FAQ 05）— 現行**

| 항목 | 원문 |
|---|---|
| 대상 페이지 | 令和7年4月1日以降にゆりかご面接を受ける方 / 同日以降にお子さんが出生した方 |
| 대상자 | 申請日時点で区内に住所を有する妊産婦。医師等が胎児心拍を確認した方。流産・死産も対象 |
| 지급액 | 妊娠時: 妊娠に対して5万円 / 出産時: 子どもの数に応じて5万円（1人につき5万円。双子は5万+5万×2 — FAQ） |
| 지급방법 | 指定口座（妊婦・産婦本人名義）へ振込 |
| 신청 | ゆりかご面接案内の2次元コードから妊婦給付認定申請 / すこやか赤ちゃん訪問案内の2次元コードから子どもの数の届出 |
| 소득제한 | FAQ「所得制限はありません。」 |
| 이중수급 | 複数市区町村から二重受給不可。他自治体で妊娠時5万円受給済みの場合、杉並区では出産時分のみ |
| 구제도 | 「出産・子育て応援ギフト」は令和8年3月31日に申請受付終了（01・03） |
| 문의 | 地域子育て支援課子育て支援係 03-5307-0786 |
| 페이지 갱신 | 2026年4月1日 |

**② 無償の子育て応援券（02）— 区独自（令和8年度）**

| 항목 | 원문 |
|---|---|
| 出生0歳児券 | 令和8年4月2日〜令和9年4月1日生まれ・区内居住保護者。交付額 **30,000円分**（多子世帯=小学生以下の兄姉2名以上は **35,000円分**）。出生届提出後約1〜2週間でアプリ交付 |
| 0歳児転入・1・2歳児券 | 15,000円分（多子20,000円分） |
| ゆりかご券（妊婦） | ゆりかご面接を受けた妊婦本人。**10,000円分**。面接後約1〜2週間でアプリ交付。妊産婦タクシーにはそのまま使えず専用券への交換申請が必要 |
| 조건 | 対象の子と同一世帯の保護者で区内居住 |
| 페이지 갱신 | 2026年7月16日 |

**③ 旧 出産・子育て応援ギフト（03）**

- 申請受付は令和8年3月31日終了。令和7年3月31日以前のゆりかご面接・出生分向けの経過案内ページ。
