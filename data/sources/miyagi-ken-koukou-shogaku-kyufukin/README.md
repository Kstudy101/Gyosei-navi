## 원문에서 확정한 사실

### 국공립（01 + 03）令和8年度
| 항목 | 원문 |
|---|---|
| 목적 | 高校生等がいる低中所得世帯の授業料以外の教育費負担軽減、返済不要 |
| 공통 요건 | 就学支援金等の受給資格／保護者等が宮城県内に住所／児童福祉法の見学旅行費・特別育成費が措置されていない |
| 通常給付 기준일 | 令和8年7月1日。所得割額(道府県民税+市町村民税)合算が 非課税（専攻科以外は生業扶助含む）／100円以上105,500円未満(年収270〜380万円相当)／105,500円以上182,500円未満(年収380〜490万円相当・専攻科除く)／105,500円以上264,500円未満(年収380〜600万円相当)かつ多子世帯(専攻科のみ)。平成26年4月1日以降入学で基準日に在学 |
| 新入生前倒し給付 | 基準日 令和8年4月1日、令和8年度新入生。年額の4分の1(3か月分)を支給。通常給付で年額が一括支給される場合は申請不要 |
| 家計急変支援 | 7/1までの急変は年額、7/2以降は翌月以降の月数按分（1円未満切捨） |
| 年額(令和8年度) | 全日制・定時制／通信制／専攻科: 生業扶助(生活保護)世帯 32,300円(全日・通信 共通欄。専攻科は斜線)／非課税 143,700円／50,500円／50,500円／270〜380万円相当(所得割100円以上105,500円未満) 47,900円／16,830円／16,830円(旧制度10,100円)／380〜490万円相当(105,500円以上182,500円未満) 35,930円／12,630円／専攻科なし／380〜600万円多子(専攻科) 12,630円(旧制度10,100円) |
| 新旧制度 | 全日・定時・通信の270〜380万・380〜490万区分は就学支援金【新制度】等の受給資格者のみ。旧制度は対象外 |
| 申請先 | 県内学校: 在学校経由（校ごとの期限）。県外学校: 就学支援班へ郵送 |
| 室への提出期限 | **令和8年9月30日（水）**（本取得日2026-09-25時点で残り5日） |
| 支給時期 | 申請書到着後 約2か月見込み。振込 |
| 不正受給 | 全額返還＋年率10.95%の違約金 |

## 국공립 vs 사립 차이（기사화 시 주의）
- 창구・요강・지급액이 다르다（同じ非課税・全日制でも 143,700円 vs 152,000円）。
- 사립은 所得区分が3段階(生活保護/非課税/100円〜105,500円未満/105,500〜182,500円未満)、국공립도 동일 구간이나 금액이 다름.
- 국공립 마감 9/30 임박、사립 10/19（기사 공개 시점에 따라 마감 경과 주의）。
