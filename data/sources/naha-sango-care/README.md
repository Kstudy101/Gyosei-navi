> 那覇市に住民票があり、出産退院後、産後ケアを必要とする1年以内の産婦さんと赤ちゃん

チラシ表記: 「那覇市民（那覇市に住民票があること）で 本事業の利用を希望する出産後1年以内の産婦さんと赤ちゃん」

→ 産婦・赤ちゃんとも「出産後1年以内」が共通の上限。ただし各実施機関ごとに赤ちゃんの受入上限年齢がさらに細かく設定されている（後述「実施機関一覧」参照。1歳になる前日まで／4か月になる前日まで／8か月になる前日まで／2か月になる前日まで等、施設により異なる）。

> 利用回数：合計6回まで利用可。ただし宿泊型の利用は、3回までとなります。

### 産後ケアの種類（`03_chirashi.pdf` p.1下段）

- 訪問型：ご自宅でケアが受けられます。外出が難しい方に、おススメです。
- 通所型：施設でケアが受けられます。3時間・6時間コースがあります。※6時間コースは食事提供あり。
- 宿泊型：施設に宿泊し、助産師等によるケアを受けられます。※食事提供あり。

### ケアの内容（`03_chirashi.pdf` p.1表 / `02_1002737.txt` 74-80行目）

- 産婦さんの産後のからだやこころのケア、睡眠、栄養、休養の相談
- 授乳指導、乳房ケア
- 赤ちゃんの健康や発育、発達の観察、相談
- 育児の手技（抱っこの仕方、オムツ交換、沐浴、寝かしつけ等）のアドバイス、相談

### 利用の流れ（`03_chirashi.pdf` p.1「産後ケア利用の流れ」）

①利用申込（オンラインまたは紙で申請） → ②審査（那覇市が申請内容を審査、決定通知書を送付） → ③決定通知書確認 → ④施設予約（希望する施設に連絡し、利用日の予約） → ⑤産後ケア利用（決定通知書・親子健康手帳を施設に提示） → ⑥支払い（利用回数、自己負担区分に応じた利用料を施設に支払い）

### 申請方法（`02_1002737.txt` 27-59行目）

- オンライン申請：那覇市オンライン申請システムの「那覇市産後ケア事業利用申請フォーム」から。利用者登録が必要。決定通知書は5日程度で交付（登録メール宛に案内）。
- 紙申請：「那覇市産後ケア事業利用申請書兼同意書」を提出。決定通知書は1週間程度で郵送。

### 注意事項（`03_chirashi.pdf` p.1 / `02_1002737.txt` 88-104行目）

1. 事業を利用する際に、実施機関に「那覇市産後ケア事業利用決定通知書」「親子健康手帳」を提示して、必要事項の記載と押印をお願いする。
2. **途中で利用を中断した場合、利用当日または前日にキャンセルした場合、キャンセルの連絡がない場合は、利用したものとみなし自己負担額を「全額」お支払いいただきます。**
3. 訪問型では乳児だけの見守り・買物・掃除・洗濯等の家事は行わない。
4. 感染症にかかっている場合や治療が必要な場合は対象外。
5. 児を預けての外出や、対象乳児以外の兄弟児のお預かりは行わない。
6. 自己負担額は利用当日に直接施設へ支払う。
7. 那覇市で課税状況が確認できない場合は自己負担額免除の対象外（転入前市町村の非課税証明の提出で対応可）。
