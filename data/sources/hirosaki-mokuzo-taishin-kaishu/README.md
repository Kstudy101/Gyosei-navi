## 確認できた主要事実（原文02・03・要綱PDFで一次確認済み）

### 共通の対象住宅要件（両事業共通）
- **建築年基準**: **平成12年5月31日以前**に建築され、同日後に増改築等が施されていないもの（増改築部分が既存不適格建築物の緩和措置を受けている場合を除く）。
  - ※topic-scoutの事前情報にあった「令和8年度から対象拡充」との記述は、公式ページ内の注記「※令和８年度から、補助対象を平成12年5月31日以前に拡充しました。」で原文確認できた。すなわち令和7年度以前は別の基準日（旧耐震基準＝昭和56年5月31日以前）だった可能性が高いが、**旧年度要綱までは未取得のため、拡充前の基準日は原文で確認していない**（WebSearchの要約で「昭和56年5月31日」という記載が出ていたのは旧年度の情報とみられるが未確認）。
- 一戸建て住宅（併用住宅は住宅部分が延べ面積の1/2以上かつ非住宅部分の合計が50㎡以下）、地上階数2以下、在来軸組構法または伝統的構法。
- ツーバイフォー（枠組壁工法）は公式ページ・要綱の対象要件には明記されていない（WebSearch要約に「枠組壁工法」との記載があったが、原文の要件列挙〔要綱第3条(5)〕には「在来軸組構法又は伝統的構法」としか書かれておらず、枠組壁工法は含まれていない。要約情報は不正確だった可能性がある）。

### 【1】木造住宅耐震診断支援事業
- 診断費用総額186,000円のうち、自己負担14,000円（延べ200㎡以下）。200㎡超400㎡以下は自己負担が段階的に増額（表は原文01に記載: 200-250㎡→40,000円、250-300㎡→67,000円、300-350㎡→93,000円、350-400㎡→121,000円）。
- 令和8年度は診断費用増加により自己負担額が増額（原文に明記、旧年度額は未取得）。
- 募集戸数: **2件程度**（先着順、予算上限到達で終了）。
- 募集期間: **令和8年6月1日(月)〜11月30日(金)**。

### 【2】木造住宅耐震改修促進事業費補助金
- 上部構造評点: 耐震診断の結果、上部構造評点のうち最小値が**1.0未満**（建替え・除却の場合は簡易耐震診断で評点7以下、または倒壊の危険性ありと判断されたものも可）。
- 補助率・上限額（交付要綱第6条で原文確認）:
  - **耐震改修工事・建替え工事**: 補助対象経費の**23%（100分の23）**を乗じた額（1,000円未満切捨て）と**1,172,000円**のいずれか低い額
  - **除却工事**: 同じく23%を乗じた額と**200,000円**のいずれか低い額
  - 令和8年度から上限額が増額されたと公式ページに明記（旧年度の上限額は未取得のため比較不可）。
- 募集戸数: **1件〜6件程度**（先着順、予算上限到達で終了）。
- 募集期間: **令和8年6月1日(月)〜11月30日(金)**（交付要綱第8条第3項でも同一期間を確認）。
- 補助対象者要件: 弘前市内に補助対象住宅を所有する者（法人を除く）またはその親族、完了後居住予定（除却は除く）、令和7年度から交付申請時までの市税等（市県民税・固定資産税都市計画税・軽自動車税・国保料・介護保険料・後期高齢者医療保険料等）に滞納がないこと、暴力団関係者でないこと。
- 補助対象外: 交付決定前着手、他制度の補助を受けた（受ける予定の）工事、建替え後住宅が土砂災害特別警戒区域内になる工事、建替え後住宅が省エネ基準に不適合な工事。
- 施工業者要件: 市内に本店を有する法人または市内に住所を有する個人事業者であること（要綱第7条）。※公式ページの表現「市内に本店を有する施工業者」より要綱の方が詳細（個人事業者は「市内に住所を有する」ことが条件）。
- 問い合わせ先: 弘前市 建築指導課 指導・審査係、電話 0172-40-7053 または 0172-40-3736（両事業共通）。
