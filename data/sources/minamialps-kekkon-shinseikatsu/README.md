## 確定した事実
- 制度名：南アルプス市結婚新生活支援事業補助金
- 令和8年度申請受付開始（令和8年1月1日以降に婚姻届を提出し受理された夫婦が対象）
- 補助金の額：1世帯当たり最大30万円（夫婦ともに29歳以下の場合、最大60万円）
  - ※子育て世帯が中古物件を購入、またはリフォームを行った場合、補助額が加算される場合がある（加算の具体的な金額・条件は原文に記載なし）
- 対象となる費用：令和8年4月〜令和9年2月に支払った住居費（住宅の取得費、改修費、賃料、敷金、礼金〔保証金等含む〕、共益費、仲介手数料の合計）及び引越費用
  - ※勤務先から住居手当が支給されている場合は住居費から差し引き
- 対象になる条件（全て満たす必要あり）：
  - 令和8年1月1日以降に婚姻届を提出し受理された夫婦
  - 婚姻日において夫婦いずれも39歳以下
  - 夫婦の合計所得が500万円未満（貸与型奨学金の年間返済額は所得から控除可）
  - 夫婦いずれもライフデザイン支援講座・プレコンセプションケア講座・妊娠出産相談・共家事共育て講座のいずれかを受講等していること
  - 申請時に少なくとも夫婦の一方が入居する住居を住民票の住所としていること
  - 入居する住居が南アルプス市にあること
  - 公的制度による家賃補助を受けていないこと
  - 夫婦いずれも市町村税等を滞納していないこと
  - 夫婦いずれも暴力団員でないこと
  - 過去に地域少子化対策重点推進交付金による補助を受けていないこと
  - 交付を受けた日から5年以上市内に定住する意思があること
- 申請期限：令和9年2月26日まで
- 手続きの流れ：申請（ふるさと振興課へ提出）→審査→交付決定通知書送付→請求書類提出→指定口座へ振込
- 事前問い合わせ推奨：南アルプス市ふるさと振興課　055-282-6073
