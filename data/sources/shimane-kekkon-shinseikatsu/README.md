## 県ページと浜田市要綱の差異（記事化時の注意）
- 講座等: 県ページは4種（相談機会含む）、浜田市要綱は5種（「乳幼児とふれあう体験又は子育て世帯との意見交換」を追加）。いずれか1つで足りる文言（「いずれかに該当する講座等を受講し、又は実践」）は要綱で確認。県ページは「夫婦ともに受講」と記載。
- 浜田市は補助金のほか、別制度の結婚新生活応援金（一律10万円）があり、併給不可（要綱第2条第3項(1)）。
