### 新入生の一部前倒し給付（04）
通常申請は7月以降だが、希望する新入生には4〜6月分相当を前倒し給付。一部給付額/年額: 生活保護 8,075円/32,300円、非課税（通信制・専攻科以外）35,925円/143,700円、非課税（通信制・専攻科）12,625円/50,500円（他区分は04参照）。基準日は令和8年4月1日。前倒しを受けた人が残額を受給するには7月に再度申請が必要。前倒しを申請しなくても7月の申請で年額受給可（01）。

### 申請時期・方法・提出先（01）
- 県内の国公立高校等在籍: 申請期間は「各高等学校が定める期間」、提出先は各高校
- 県外の国公立高校等在籍: 令和8年7月1日（水）〜11月30日（月）。間に合わない場合は相談可。家計急変世帯は令和9年1月29日（金）まで。郵送または持参。〒902-8501 那覇市寄宮1-2-16 沖縄県教育庁教育支援課（旧県立図書館1階）
- 7月2日以降に生じた家計急変は申請日の翌月からの月割額。生活保護（生業扶助）世帯は家計急変の対象外
- 私立高校等在籍: 沖縄県総務部総務私学課（098-866-2074）へ
- 保護者が県外在住の場合は、保護者の住む都道府県から給付（制度・期間は都道府県で異なる）
- 主な提出書類: 受給申請書、課税証明書（令和8年度・全項目記載）または代替書類、生徒の国籍確認書類（戸籍抄本等／在留カード写し等）、債権・債務者登録申出書、振込先口座通帳写し等。生活保護世帯は生業扶助（高等学校等就学費）受給証明書。世帯状況別に異なる（詳細は01）
- 問い合わせ: 教育支援課 TEL 098-866-2711
