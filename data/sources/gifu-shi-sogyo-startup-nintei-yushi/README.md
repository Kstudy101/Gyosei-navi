| 項目 | 原文の記載 |
|---|---|
| 取扱開始 | 令和7年4月1日（令和8年4月1日改正） |
| 対象者 | 岐阜市スタートアップ認定制度の認定を受けた者で、設立又は開業後5年以内の法人又は個人、市内に事業所を有する、市税完納、返済確実 |
| 資金使途 | 運転資金・設備資金 |
| 融資限度額 | 3,500万円 |

| 市の保証料補てん | 全額（事業者負担 0%） |

| 返済方法 | 元金均等月賦 |
| 担保・保証人 | 担保不要。保証人は原則不要（法人は代表者を連帯保証人とする場合あり） |
| 必要書類（抜粋） | 資格要件申告書、創業計画書（様式第6号）、認定通知書の写し 等 |
| 問合せ | 商工課スタートアップ推進室 058-214-2771／岐阜市信用保証協会 058-265-3131 |

### 利子補給制度（G-STA特典）（出典: `04`/`06`）

| 項目 | 原文の記載 |
|---|---|
| 対象資金 | 創業者支援資金【スタートアップ認定枠】 |
| 交付対象者 | 岐阜市認定スタートアップ企業（G-STA） |
| 利子補給期間 | 対象資金の利用日から3年間（年度毎に申請が必要） |
| 利子補給額 | 利子補給期間中に支払った対象資金に係る利子額（全額）／申請した年度の前年度に支払った利子を補給 |
| 申請時期 | 毎年4月1日から6月30日まで |
| 注意 | 申請しないと利子補給を受けられない |
