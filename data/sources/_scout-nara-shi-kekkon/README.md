# 奈良市 × kekkon — topic scout / research SKIP 記録

- 調査日: 2026-09-22
- 対象: 奈良市 (`nara-shi`, 総務省コード 29201, prefCode 29) — `regions.ts` 登録済
- カテゴリ: kekkon（結婚新生活支援＝新婚世帯の住居費・引越費用補助が中核）

## 結論

**SKIP** — 奈良市・奈良県いずれにも、記事化に必要な「結婚新生活支援事業」型（家賃・住宅取得・リフォーム・引越の現金補助）の公式実施ページ／要綱／金額・申請期間の一次情報を確認できなかった。

マッチング・セミナー等の出会い支援はあるが、taxonomy 上の kekkon（住居費補助）記事の根拠としては不十分。金額を捏造して published にしない。
