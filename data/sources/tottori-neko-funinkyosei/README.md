## 제도 유형 분류

**현금교부형(助成金)** — 飼い猫・野良猫の不妊去勢手術費用の一部を助成。県獣医師会による県内全域対象助成と、各市町村独自助成の2層構造。

### 耳先カット（野良猫手術の場合）
飼い主のいない猫の手術時は耳先カット（TNR識別）を実施。メスは左耳、オスは右耳。
