# 北九州市 開業支援資金 — 原文アーカイブ

## 対象自治体・制度

- 自治体: 福岡県北九州市（政令指定都市、市全体で1エントリ登録。regions.ts code `40100` / slug `kitakyushu`）
- 制度名: 開業支援資金（北九州市中小企業融資制度の一種）
- 所管: 産業経済局地域経済振興部中小企業振興課
- カテゴリ: sogyo（創業支援）
- 制度種別: **融資あっせん型**。現金直接補助ではなく、取扱金融機関からの借入に対し金利・信用保証料を優遇する制度。初回利用時の保証料率0.00%、一般枠金利1.50%・特別枠金利1.40%。
