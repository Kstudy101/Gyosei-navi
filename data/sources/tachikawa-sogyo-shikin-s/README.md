## 制度分類
- **融資あっせん型（利子補給＋信用保証料補助）**。現金給付でも現物給付でもなく、金融機関融資に対する市の利子補助＋信用保証料補助の組み合わせ。
- 「創業資金A」「創業資金B」「創業資金S」の3メニューのうち、創業資金Sは「立川市創業支援事業計画」に基づく特定創業支援等事業を受講し証明書（認定創業者証明）を取得した者のみが使える最優遇メニュー。

## 確認された核心数値（原文根拠）

### 創業資金S 融資条件（出典: 02_sogyo-shikin-s.txt 68-88行、03_riritsu-ichiran.txt 133-141行で一致確認）
- 融資限度額：**2,000万円**
- 貸付期間：**7年以内（据置期間1年を含む）**
- 利率（年）：**0.200%**（表面金利1.750%のうち1.550%を立川市が補助）※令和8年6月1日改定後も「変更なし」と明記（03_riritsu-ichiran.txt 133-139行）
- 返済方法：据置期間経過後、元金均等返済
- 資金使途：運転・設備
- 利用対象：立川市創業支援事業計画に基づく特定創業支援等事業の証明（認定創業者証明書）を受けた者のみ（05_yushi-jyoken-hitsuyoshorui.txt 37行）

### 比較：創業資金A・B（令和8年6月1日改定後の現行値、03_riritsu-ichiran.txt 113-131行）
- 創業資金A：表面金利2.150%／市負担1.600%／利用者負担0.550%（融資限度額・期間はSと同一：2,000万円、7年以内）
- 創業資金B：表面金利2.150%／市負担1.700%／利用者負担0.450%（女性・若年者・シニア世代向け）

### 信用保証料補助
- 原則：融資実行後、**市が信用保証料の2分の1（1/2）を補助**（03_riritsu-ichiran.txt 29行）。
- ただし**創業資金S含む「東京都中小企業制度融資との連携に該当する資金（小規模事業者支援資金、創業A・B・S）」は、令和5年4月1日以降の申請分から信用保証料補助が東京都から交付され、市からの補助はない**（03_riritsu-ichiran.txt 33行、原文まま）。
- → トピックスカウトが示した「2/3を東京都が補助」という数値は、立川市の公式ページ（02, 03, 04, 05いずれも）には記載がなく、**確認できなかった**。東京都創業NET（tokyo-sogyo-net.metro.tokyo.lg.jp）の「東京都中小企業制度融資『創業』」ページもWebFetchで確認したが、都の補助率（1/2か2/3か）は明記されておらず、東京都産業労働局金融部金融課への問合せが必要と案内されているのみ（WebFetch確認のみ、未アーカイブ・未確定情報）。

### 特定創業支援等事業・認定創業者証明（出典: 04_ninteisogyosha-yoken.txt）
- 対象：事業を営んでいない個人、または事業開始後5年未満の個人・法人
- 要件：市が定める特定創業支援等事業（セミナー・創業塾・個別相談等）を原則4回以上、1か月以上継続して受講
- 令和8年度からの追加要件：受講した年の翌年度末（3月31日）までに申請すること（期限経過後は再受講が必要）
- 証明書取得の5つのメリット：①登録免許税軽減（資本金の0.7%→0.35%）、②信用保証協会「創業関連保証」の利用開始時期前倒し（事業開始2か月前→6か月前）、③日本政策金融公庫「新規開業・スタートアップ支援資金」の利率引き下げ、④市の融資あっせん「創業資金S」の利用、⑤小規模事業者持続化補助金「創業型」の申請資格
- 申請書類：申請書（2部）、個人情報提供同意書、各支援機関発行の修了証（原本）
- 提出先：立川市役所本庁2階48番窓口（産業観光課）、平日8:30-12:00, 13:00-17:00
- 手数料：無料。証明書発行まで約1週間

### 融資条件・必要書類（出典: 05_yushi-jyoken-hitsuyoshorui.txt）
- 創業資金S共通条件：申請時に事業主として事業を営んでいない、または創業後1年未満／立川市内で事業を営む予定（法人は本店所在地が市内）／市税を滞納していない／特定創業支援等事業の証明書交付を受けていること
- 必要書類（法人・個人共通の主なもの）：中小企業事業資金あっせん申請書、創業計画書、賃貸借契約書の写し、預金通帳の写し、創業前の源泉徴収票の写し、特定創業支援等事業による支援を受けたことの証明書の写し 等（詳細は法人／個人で異なる。原文参照）
