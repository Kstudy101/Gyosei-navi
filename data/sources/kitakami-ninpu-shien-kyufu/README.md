## 根拠表（主制度＝01）

| 対象者への案内 | 対象者には個別にお知らせ | 01 |

| 1回目 除外 | すでに「出産応援給付金」を申請した人は1回目の対象外 | 01 |
| 1回目 要件 | (1)申請時点で北上市に住所登録 (2)他市区町村で1回目相当を受けていない (3)産科等で胎児心拍を確認 | 01 |
| 1回目 申請期限 | 胎児心拍確認日から2年を経過する日まで | 01 |
| 2回目 金額 | 子どもの数×5万円（令和7年4月1日以降に出産） | 01 |
| 2回目 要件 | (1)申請時点で北上市に住所 (2)北上市の妊婦給付認定者 (3)他市区町村で2回目相当を受けていない | 01 |
| 2回目 申請期限 | 出産予定日の8週間前の日から2年を経過する日まで。流産・死産は処置日から2年 | 01 |
| 流産・死産 | 令和7年4月1日以降の流産・死産でも対象。妊娠届出後の流産・死産も2回目対象と案内 | 01 |
| 所得制限 | なし | 01 留意事項1 |
| 支給時期 | 不備のない申請受理後おおむね1〜2か月後に認定・可否通知とともに支給 | 01 |
| 転出 | 転出時点で北上市の妊婦支援給付認定は自動取消。胎児の数の届出前に転出した場合は転出先で再認定が必要 | 01 |
| 問合せ | こども家庭センター親子保健係 直通0197-72-8298（平日8:30-17:15、火曜のみ18:30まで）。問合せフォームあり | 01 |
