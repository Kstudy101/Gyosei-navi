## 참고: 私立高等学校等奨学給付金(선택하지 않음, 02_shiritsu.txt)의 요지

- 대상요건은 국공립과 거의 동일한 5구분(생업부조수급/비과세/소득할액105,500円미만/182,500円미만/264,500円미만+3인이상부양)이나, **구체적 지급액 표는 본문에 없음**(리플렛 PDF 참조 안내만).
- 소관은 富山県経営管理部学術振興課私学振興係（076-444-3159）로 국공립과 소관과가 다름.
- 신청기한: 신입생 전도급부 令和8年7月24日, 통상분 令和8年10月30日, 가계급변(7/2이후) 令和9年2月26日까지 수시접수.
