## 確定した事実
- 制度名：甲府市結婚新生活支援事業（国の地域少子化対策重点推進交付金を活用）
- 目的：結婚に伴う新生活のスタートアップ経費（住居費・引越費用等）を軽減
- 補助対象世帯要件（すべて満たす必要あり）：
  - 令和8年1月1日〜令和9年2月26日の間に婚姻届を提出・受理
  - 婚姻日において夫婦双方が39歳以下
  - 夫婦合算所得500万円未満（貸与型奨学金返済中は年間返済額を所得から控除可）
  - 申請日時点で夫婦双方の住所が申請住宅の所在地（甲府市の住民基本台帳に記録）
  - 申請日から5年以上継続して甲府市に居住する意思
  - 市税の滞納なし
  - 生活保護による住宅扶助等の公的家賃補助を受けていない
  - 過去に本交付金による結婚新生活支援事業の補助を受給していない（他自治体含む）
  - 暴力団員でない
  - 夫婦双方が令和8年4月1日以降に指定講座等（ライフデザイン支援講座、プレコンセプションケア講座、妊娠・出産相談、共家事・共育て講座のいずれか）を受講・実施していること
- 補助対象経費：住居費（購入費〈土地代除く〉、リフォーム費用、賃料〈共益費含み駐車場代除く〉、敷金・礼金、仲介手数料）、引越費用。令和8年4月1日〜令和9年2月26日の間に支払った分が対象
  - 「甲府市空き家バンク活用促進助成金」交付を受けているリフォーム費用は対象外
- 補助金額：一世帯あたり上限30万円。婚姻日に夫婦とも29歳以下の場合は上限60万円（1,000円未満切り捨て）
- 申請方法：申込フォームに事前入力→担当者から連絡後、書類を揃え連携共創課自治体連携係へ郵送または持参
- 申請期限：令和9年2月26日（金曜日）。予算の都合で期限前に受付終了の場合あり
- 問い合わせ：財政経営室連携共創課自治体連携係 055-237-5319
