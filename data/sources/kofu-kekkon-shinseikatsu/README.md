## 確定した事実
- 制度名：甲府市結婚新生活支援事業
- 国の地域少子化対策重点推進交付金（結婚新生活支援事業）を活用した市の制度
- 対象世帯（1〜10の要件を全て満たす世帯）：
  - 令和8年1月1日〜令和9年2月26日の間に婚姻届を提出し受理された夫婦
  - 婚姻日において夫婦双方の年齢が39歳以下
  - 新婚世帯の合算所得が500万円未満（貸与型奨学金の年間返済額は所得から控除可）
  - 申請日において夫婦双方の住所が甲府市の住民基本台帳上、申請に係る住宅の所在地であること
  - 申請日から5年以上継続して甲府市に居住する意思があること
  - 市税の滞納がないこと
  - 生活保護の住宅扶助等の公的家賃補助を受けていないこと
  - 過去に地域少子化対策重点推進交付金による結婚新生活支援事業の補助を受給していないこと（他自治体分含む）
  - 夫婦いずれも暴力団員でないこと
  - 夫婦双方が令和8年4月1日〜申請日までに、ライフデザイン支援講座・プレコンセプションケア講座・妊娠出産相談・共家事共育て講座のいずれかを受講/実施していること
  - 外国籍でも要件を満たせば対象
- 補助対象経費：住居費（購入費〔土地代除く〕、リフォーム費用、賃料〔共益費含み駐車場代除く〕、敷金・礼金、仲介手数料）、引越費用。令和8年4月1日〜令和9年2月26日に支払った費用が対象
  - ※「甲府市空き家バンク活用促進助成金」の交付を受けたリフォーム費用は対象外
  - ※勤務先の住宅手当がある場合は当該分を差し引いた額
- 補助金額（上限）：
  - 一世帯あたり：30万円
  - 婚姻日において夫婦ともに29歳以下の場合：60万円
  - （1,000円未満の端数は切り捨て）
- 申請方法：申込フォーム入力後、担当者から連絡→書類を揃え甲府市連携共創課自治体連携係へ郵送/持参
- 申請期限：令和9年2月26日（金）まで。※予算の都合で期限前に受付終了する可能性あり、申請1か月前までに申込フォーム入力が必要
- 問い合わせ：財政経営室連携共創課自治体連携係　055-237-5319

## 山梨県内の他市町村との比較メモ（writer向け）
- 南アルプス市（`data/sources/minamialps-kekkon-shinseikatsu/`）も上限30万円・夫婦とも29歳以下で60万円という**同一の加算構造**。topics-db（`data/topics-db/yamanashi.json`）のnoteには「南アルプス市の29歳以下60万円が甲府市版との差別化ポイント」と記載されていたが、原文対照の結果これは誤り。甲府市も全く同じ加算ルールを持つ。県内17市町村共通の国の枠組み（地域少子化対策重制推進交付金）をベースにしているため、両市の制度はほぼ同一。差別化するなら「受講必須講座の有無」（甲府市は明記して必須、南アルプス市も同様に必須）や、南アルプス市の「子育て世帯が中古物件購入・リフォームで補助額加算の場合あり」という追加要素（南アルプス市原文59行目参照、詳細条件は原文に記載なし・要再調査）で書き分けること
