## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **이용자부담・지급상한액・구체적 지급품목・소득제한은 「시정촌의 판단에 따름」이라고만 원문에 명시** — 전국 공통 금액이 존재하지 않는 제도이므로, 기사에서 구체적 금액을 전국 공통값처럼 쓰면 안 된다. 반드시 「거주 시정촌마다 다름」을 명확히 하고, 구체적 사례는 개별 시정촌 기사(千代田区・港区・新宿区 등)로 안내할 것.
- 종목 6종의 구체적 대상 품목 예시 목록(告示第529号 본문에 나온 것 외 세부 리스트)은 이번 조사에서 취득하지 않음 — 필요시 후생노동성이 공표하는 별도 참고자료(품목 예시집) 확인 필요.
- 이 사업은 필수사업(必須事業)이지만, 동시에 시정촌 재량 범위가 넓어 지자체별 운용에 차이가 크다는 점 — 원문(01)에는 이 재량 범위의 구체적 한계(예: 국가가 강제하는 최소 종목 수 등)는 명시되어 있지 않음.
