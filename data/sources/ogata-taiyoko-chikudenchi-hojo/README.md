## 確認できた事実（原文と数値100%対照済み）

- **正式名称**: 令和8年度　大潟村家庭用太陽光発電設備等導入費補助制度（要綱上の名称は「大潟村家庭用発電設備等導入費補助金」）
- **所管**: 大潟村役場 生活環境課 環境班（電話 0185-45-2115）
- **目的**: 大潟村が表明した2050年カーボンニュートラル実現「ゼロカーボンシティ」に向け、「脱炭素先行地域」として自然エネルギーの地産地消を推進するための助成（要綱第1条）
- **募集期間**: 令和8年4月1日～令和8年12月20日（01_hojo-page.txtに明記。予算上限到達時の早期終了に関する明示的記述は原文になし＝要綱第2条「予算の範囲内で本補助金を交付する」とのみ規定）
- **対象者**: 対象設備を自ら居住する住宅に設置する村民（要綱第2条）
- **補助率**:
  - 住宅用太陽光発電設備: 対象経費（税抜）の **3分の2**
  - 蓄電池: 対象経費（税抜）の **4分の3**
  （※01_hojo-page.txtは「2/3」「3/4」の表記、02_kofu-youkou_extracted.txtの要綱本文は「３分の２」「４分の３」の表記で完全に一致）
  - **補助上限額（円建て）の明記は原文に一切なし** — 要綱・案内ページとも比率のみの規定。これは「未確認」ではなく「原文に上限額の定めが存在しない」という事実として扱う。
- **対象設備の要件**（要綱第3条・03_shousai-youken.docx）: 国の「二酸化炭素排出抑制対策事業費交付金（地域脱炭素移行・再エネ推進交付金）交付要綱」に示される要件を満たす太陽光発電設備・蓄電池。中古設備は原則対象外。FIT/FIP認定を取得しないこと等の条件あり。
  - **EV充電設備・エネファームは対象設備として一切記載なし** → 対象外と判断（原文に太陽光・蓄電池以外の設備の記載がないため）。
- **申請方法**: 交付要綱・交付規則に基づき村長に交付申請書を提出する方式（要綱第4条・第5条）。添付書類は収支予算書・見積書・配置図・カタログ等（04_shinsei-tenpu-ichiran.docx）。**個人（村民）が直接申請する制度であり、事業者向け設備投資支援や販売代理店経由の制度ではない**。

## 個人直接申請の確認

要綱第2条「交付の対象及び補助金額」に「対象設備を自らの居住する住宅に設置する村民」と明記。販売店・施工業者ではなく村民個人が申請主体である。事業者向け設備投資補助ではなく、個人が直接申請できる村独自予算の補助金であることを確認した。
