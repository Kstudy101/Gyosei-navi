### 이전 요건（4つすべて充足が必要）

1. **移住元**: 住民票移転直前10年中通算5年以上かつ直前1年以上佐賀県外居住
2. **移住先**: 実施14市町のいずれかへ令和7年4月1日〜令和8年12月31日に転入し、転入後1年以内かつ令和9年1月31日までに申請
3. **就業等**: 子育て世帯要件（要件1〜4：18歳未満帯同で就職・起業・農林漁業・空き家取得のいずれか）または重点分野担い手要件（要件5〜6：59歳以下で伝統工芸等またはスポーツ振興）
4. **その他**: 反社不該当、在留資格要件、過去10年以内の移住支援金受給歴なし

### 실시 14시정촌（令和8年度）

佐賀市・唐津市・多久市・伊万里市・武雄市・鹿島市・小城市・嬉野市・神埼市・基山町・有田町・大町町・白石町・太良町

### 반환 규정

- 申請日から3年未満の転出 → 全額返還
- 3年以上5年以内の転出 → 半額返還
- 虚偽申請・就職後1年以内離職等 → 全額返還
