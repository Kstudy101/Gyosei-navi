## 確定した事実
- 制度名：甲府市妊婦等包括相談支援事業及び妊婦のための支援給付事業
- 経済的支援（妊婦支援給付金）は2回に分けて支給
  - 1回目（妊婦給付認定申請）：妊娠届出時に5万円（多胎妊娠の場合も5万円）
  - 2回目（胎児の数の届出）：出産予定日の8週前の日以降、妊娠している子ども1人につき5万円（多胎出産の場合は胎児の数×5万円）
- 対象者：甲府市内に住所を有し、産科医療機関で妊娠の事実（胎児心拍）を確認した妊婦。他自治体で国の制度による同給付金を受けていないことが条件
- 流産・死産・人工妊娠中絶等の場合も支給対象（診断書提出が必要な場合あり）
- 申請期間：妊娠の事実を確認した日から2年
- 申請窓口：甲府市子ども未来部母子保健課（郵送可）
- 振込時期：申請日から約1〜2か月後
- 旧制度「妊娠・子育て応援給付金」は令和8年3月30日をもって終了し、本制度に切り替わった
- 問い合わせ：子ども未来総室母子保健課母子保健係 055-237-8950
