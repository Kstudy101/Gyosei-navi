## 制度タイプ分類

- **現物給付型（サービス利用料補助）** — 現金給付ではない
- 宿泊型・通所型・訪問型の3メニュー（宿泊・通所は同一申請系統、訪問型は別申請）
- 課税状況に応じた自己負担の段階設定あり
