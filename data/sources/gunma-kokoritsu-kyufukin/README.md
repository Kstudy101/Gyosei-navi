# gunma-kokoritsu-kyufukin

対象候補記事（government-researcher調査段階）: 群馬県「国公立高等学校等奨学のための給付金制度」（令和8年度より対象世帯を年収490万円程度まで拡充）。比較のため私立版「群馬県私立高等学校等奨学のための給付金制度」も原文を取得済み。

## 制度の性質・ニュース性

国の「高校生等奨学給付金」制度の群馬県運用版で、低・中所得世帯の授業料以外の教育費（教材費等）を支援する**返済不要の給付金**。令和8年度より対象世帯を「年収490万円程度（保護者等全員の住民税所得割額の合計が182,500円未満）」まで拡充したと明記されており、ニュース性がある。

公立版と私立版は**別制度**（申請窓口・所管課も異なる：公立＝教育委員会管理課、私立＝生活こども部私学・青少年課）。対象世帯区分（ア～キ）の所得基準は同一の枠組みだが、**給付額は私立の方が高額**（例：住民税非課税世帯・通信制以外で公立143,700円に対し私立152,000円）。記事化の際はどちらの制度を対象にした記事か、または両方を比較する記事かを明確にする必要がある。

## 公立版と私立版の差異まとめ

| 比較項目 | 公立版 | 私立版 |
|---|---|---|
| 所管課 | 教育委員会管理課 | 私学・青少年課 |
| 対象校種 | 公立高等学校、公立中等教育学校後期課程、国立高等専門学校 | 私立高等学校等 |
| 所得区分の枠組み | 同一（ア～キ、年収目安270万～490万円） | 同一（ア～キ、年収目安270万～490万円） |
| 給付額（非課税世帯・通常制） | 143,700円 | 152,000円（私立の方が高額） |
| 給付額（非課税世帯・通信制） | 50,500円 | 52,100円 |
| 給付額（年収380-490万世帯・通常制） | 35,930円 | 38,000円 |
| 災害時制服再購入加算 | 記載なし（公立版原文には該当条項が見当たらない） | あり（非課税世帯81,000円等） |
| 令和8年度拡充の明記 | 「令和8年度より年収490万円程度まで拡充」と明記 | 給付額一覧に既に年収490万円世帯区分（カ・キ）が組み込まれている（拡充の経緯明記は本文になし） |
