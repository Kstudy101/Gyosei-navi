## 確認できた最終数値・条件（01で確認）

### 対象者
福井市内に住所を有し、常時（目安: 1日3枚以上）おむつを使用している人で、以下すべてに該当:
1. 福井市の介護保険被保険者であること
2. 給付額減額の措置を受けていないこと
3. 要介護3以下の新規利用者は、介護認定調査票の排泄項目に「介助」または「見守り等」に該当していること

**補足条件**:
- 40〜64歳の人（第2号被保険者）は市民税非課税世帯の人に限る
- 令和3年3月以前からの利用者は上記(3)の要件にかかわらず継続利用可
- **要介護度の下限規定はなし**（要支援1・2の人も対象。要介護3以下の「新規」利用者にのみ認定調査票の排泄項目要件が付く点に注意 — 依頼文にあった「要介護度○以上」という一律の下限は原文になく、要支援1から要介護5まで幅広く対象）

### 支給内容・自己負担額（月1回配達、商品受領時に自己負担額を支払い）
希望する1種類を月1回配達。品目ごとに支給枚数の上限と自己負担額（円）が課税世帯／非課税世帯で異なる。

**要支援1・2の場合**（抜粋、全額は01参照）:
- 尿取りパッド: 90枚／課税1,386円・非課税924円
- テープタイプ: 45枚／課税2,722円・非課税1,815円
- パンツタイプ: 45枚／課税2,598円・非課税1,732円
- 軽失禁用尿取りパッド: 90枚／課税2,376円・非課税1,584円
- 高吸収尿取りパッド: 30枚／課税957円・非課税638円

**要介護1〜5の場合**（抜粋、テープ・高吸収パッドは2段階の枚数設定あり）:
- 尿取りパッド: 120枚／課税1,848円・非課税739円
- テープタイプ: 50枚（課税3,025円・非課税1,210円）または90枚（課税5,445円・非課税2,178円）
- パンツタイプ: 50枚（課税2,887円・非課税1,155円）または90枚（課税5,197円・非課税2,079円）
- 軽失禁用尿取りパッド: 90枚／課税2,376円・非課税950円
- 高吸収尿取りパッド: 30枚（課税957円・非課税382円）または60枚（課税1,914円・非課税765円）
