## 制度유형 분류

現物支給型（介護用品の現物配達、購入費補助ではなく商品自体を月1回配達）。受領時に自己負担額を支払う方式で、所得（市民税課税・非課税）に応じた2段階の自己負担額設定。要支援・要介護度別に支給枚数上限が異なる。
