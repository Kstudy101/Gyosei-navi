## 確認できた核心情報（01・04対照）

### 対象者（01 / 条例第2・3条）
- 9月1日〜11月30日まで継続して要件を満たすこと
- （1）身体障害者手帳1級、または療育手帳A1・A2、もしくは判定機関で知的障がいが重度と判定された方
- （2）市内居住かつ住民基本台帳記載（市の介護給付費による施設入所等は例外あり）
- 対象外例（01）: 市外の高齢者関係施設入所、市外介護医療院入院、市外医療機関1年以上入院で退院見込みなし、他自治体措置・支給決定による入所、11/30までに市外転出・死亡等

### 支給額
- 在宅者: **20,000円**（01）＝条例第4条の年額15,000円＋在宅加算5,000円
- 施設入所者: **15,000円**（01）＝条例第4条の年額15,000円
- 支給時期: **12月中旬頃**（01）。条例第7条は12月1日〜15日

### 申請
- 各年度 **9月1日〜10月31日**（郵送は10月31日消印有効）。期限後は受付不可（01）
- 令和8年度受付開始: 令和8年9月1日（オンラインは9月1日10時〜）
- 方法: オンライン／行政事務センター郵送／区福祉・介護保険課（窓口・郵送）
- 必要書類: 受給申請書（対象者へ郵送）、施設入所証明書（施設のみ）、本人名義通帳写し（印字口座変更なしなら不要）、公金受取口座利用時はマイナンバー確認書類
