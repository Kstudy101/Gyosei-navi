## 制度類型

- **費目別援助型**（学用品費等・オンライン学習通信費・新入学学用品費は定額、給食費・修学旅行費・体育実技用具費・通学費は実費）。学校納付金の免除制度ではない（01/04）。
- 市が実施する就学援助（市立・県立・国立の小中）。国家制度の単独紹介ではない。
- 既存記事 `nagano-shi-freeschool-riyouryo-joseikin`（フリースクール利用料助成）とは別制度。フリースクール助成は就学援助受給が前提条件。

- 修学旅行費・校外活動費・通学費の具体的な上限額・距離条件。
