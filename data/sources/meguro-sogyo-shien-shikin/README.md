## 제도 유형 분류

**융자알선형（이자보급 병행）** — 구가 직접 현금을 교부하는 급부형이 아니라, 취급 금융기관에 대한 융자 알선과 금리 일부(1.6%)의 이자보급으로 본인부담을 0.2% 이내로 낮추는 제도. 신주쿠・오타・분쿄 등과 같은 유형.
