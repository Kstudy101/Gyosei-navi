## 根拠表（記事に使う数値）

| 項目 | 値 | 根拠 |
|---|---|---|
| 融資限度額 | 3,500万円 | 01_main |
| 融資利率 | 年2.2%以内／自己資金1/3以上で年2.1%以内／1/2以上で年2.0%以内。または制度所定変動金利（短期プライムレート＋0.7%以内） | 01_main |
| 融資期間 | 運転・設備とも10年以内（据置1年以内）。プロパー融資同時実行または残高がある場合は据置3年以内 | 01_main |
| 信用保証料 | 年0.500% | 01_main |

| 担保 | 物的担保は不要 | 01_main / 02 PDF |
| 対象 | 会社のみ（医療法人・NPO法人を除く）。個人事業主は対象外 | 01_main / 05_faq Q2 |
| 自己資金 | 税務申告1期未終了の創業者は創業資金総額の1/10以上 | 01_main |

| 申込窓口 | 取扱金融機関のみ（市役所では申込み不可） | 01_main |
| アーリーステージとの差 | アーリー＝個人・法人いずれも保証料実質0.0%。本資金＝会社のみ・保証料0.5%・経営者保証不要 | 05_faq Q2 |

## 確認されていないこと

- 中小企業庁「スタートアップ創出促進保証」公式ページは取得時 HTTP 403 で原文アーカイブできず。市ページが外部リンクとして案内する保証制度の詳細は、申し込み前に取扱金融機関または中小企業庁資料で確認が必要。
- 取扱金融機関ごとの実際の約定利率・審査基準は公開ページに記載なし。
- 令和8年度以降の利率改定の有無は、本稿作成時点（ページ更新日 2026-06-26）以降の再確認が必要。
