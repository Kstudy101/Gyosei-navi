## 核心数値（01原文より）

### 福祉タクシー利用券の交付
- 制度名: 福祉タクシー利用券の交付
- 目的: 障害者の社会参加の促進と生活圏の拡大
- 対象者（本市に住民登録があり、以下いずれか該当）:
  1. 下肢または体幹機能障害があり、総合等級が1・2級の身体障害者手帳を持つ人
  2. 視覚障害1級または視覚障害のみの総合等級が1級の身体障害者手帳を持つ人
  3. 心臓・腎臓・呼吸器・ぼうこう・直腸・小腸・免疫・肝臓のいずれか1級の身体障害者手帳を持つ人で、前年度の市町村民税所得割課税額が6万円以下の人
  4. 療育手帳Aを持つ人
- 申請に必要なもの: 申請書（PDF、障害福祉課窓口にも備え付け）、身体障害者手帳または療育手帳、所得課税証明書（転入等必要な場合のみ）
  - 注1: 令和8年度から申請書が新しくなる
  - 注2: 代理人申請の場合は代理人の身元確認書類も必要
- **令和8年度の交付スケジュール（原文で最新確認済み）**:
  - 令和8年3月23日（月曜日）から交付開始
  - 3月23日(月)〜4月10日(金)の期間: 市役所1階国際親善コーナー（総合案内前）で交付
  - 4月13日（月）以降: 市役所南館1階 障害福祉課（13・14番窓口）で交付
  - 注: 交付開始から1か月程度は窓口混雑の案内あり
- 利用可能タクシー会社: 徳島市と契約しているタクシー会社に限る（契約タクシー会社一覧PDF、令和8年3月15日現在）
- 問い合わせ先: 徳島市福祉事務所障害福祉課 電話 088-621-5177（FAX 088-621-5300）

### 同ページ内の関連制度（参考・比較用に原文で確認済み）
- タクシー運賃割引: 手帳提示で割引（問い合わせは各タクシー協会）
- 市バス無料乗車証の交付: 1〜4級の身体障害者手帳・療育手帳・精神障害者保健福祉手帳を持つ住民登録者に徳島市営バス無料乗車証を発行
- 障害者特定回数乗車券の交付: 市バス路線の無い地区居住者向け、徳島バス指定区間を無料利用できる回数乗車券
- バス運賃割引、有料道路通行料金割引（ETC対応）、自動車改造費助成（上限10万円、対象: 肢体不自由総合等級2級以上）、自動車運転免許取得費補助（上限2万円、対象: 身体障害者手帳1〜4級または療育手帳、申請期限は取得年度の3月31日まで）、JR・私鉄・旅客船・航空運賃割引、駐車禁止規制の適用除外、携帯電話料金割引
