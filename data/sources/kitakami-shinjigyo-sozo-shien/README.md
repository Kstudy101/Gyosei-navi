# 北上市新事業創出支援事業補助金（令和8年度公募）— 原文アーカイブ

## 対象自治体・制度

- 都道府県: 岩手県（03、slug: iwate）
- 自治体: 岩手県北上市（03206）
- 制度名: 北上市新事業創出支援事業補助金
- 所管: 北上市産業雇用支援課 産業連携係
- カテゴリ: sogyo（創業支援）
- 制度種別: **現金給付（補助率型）**。融資あっせんではなく、対象経費の1/2または2/3（上限100万円）を直接補助する。平成28年度から毎年度継続実施されている恒常的な制度で、令和8年度（2026年度）も公募が実施されている（後述の令和7年9月1日更新の実績一覧ページで確認）。

## 個人・個人事業主が直接市に申請可能か

**確認済み・可能。** 交付要綱第2条第1号に「中小企業基本法第2条に規定する中小企業者**又は事業年度内に起業を予定している個人**」と明記されており、法人限定ではない。令和8年度公募チラシにも「中小企業者（個人事業主含む）または個人（事業年度内に起業予定の方）」と明示されている。申請先は交付要綱第9条により「市長」（北上市）であり、代理店や金融機関を介した融資あっせん型ではなく、市への直接申請・直接交付の現金給付型である。事業一覧ページ（01）でも平成28年度から令和7年度まで毎年、個人名での採択事業者（法人格を持たない個人事業者を含む）が多数実績として掲載されており、実務上も個人事業主の採択実績が確認できる。
