## 原文で確定した事実

| 項目 | 原文 |
|---|---|
| 制度名 | 北九州市住宅・建築物耐震改修工事費等補助事業（木造住宅・建替え等に伴う除却工事） |
| 所管 | 都市戦略局指導部建築指導課（093-582-2531） |
| 令和8年度募集開始 | 2026年4月13日（先着順・予算到達で終了） |
| 対象建物 | 市内・昭和56年5月31日以前建築（または工事着手）・2階建て以下・上部構造評点1.0未満・現に3カ月以上居住 |
| 対象外（Q&A） | 長屋・共同住宅は除却補助の対象外。申請時点で居住していない住宅は対象外 |
| 補助対象者 | 建物所有者または同意を得た者。市税滞納なし。暴力団関係者でないこと |
| 補助額（要領第4条第3項） | 1戸あたり上限30万円。除却工事費（税抜）相当額と、仮に耐震改修工事監理・工事を行った場合の経費相当額のいずれか低い額×23.0%（千円未満切捨て）。申請時点で所有者が70歳以上かつ令和11年3月31日までに工事完了の場合は上限50万円 |
| HTMLの34,100円/㎡ | 要領本文の算定式には直接現れず、Q&A Q3-5で「要領第4条第3項の34,100／㎡を目安」と記載。耐震改修経費の見積り目安として用いる |
| 消費税 | 補助対象外 |
| 住替え・建替え条件 | 耐震性のある新築・購入・中古戸建・共同・賃貸等へ転居したうえで除却。昭和56年6月1日以降建築確認または評点1.0以上 |
| 耐震診断 | 本メニューは福岡県耐震診断アドバイザー派遣制度のみ。除却予定なら自己負担3,000円（診断のみ）コース |
| 施工者 | 原則市内事業者（やむを得ない理由があれば市外可） |
| 着工条件 | 交付決定前着工は対象外。事前協議必須 |
| 完了 | 交付決定を受けた年度中に完了実績報告→市の確定通知まで。流れ資料は1月末まで完了報告・2月末までに支払い完了を目安 |
| 申請回数 | 交付申請（工事前）→実績報告（完了後）→請求（確定通知後）の3回。電子申請可 |

## 原文対照

- HTML「上限30万円／70歳以上は50万円（令和8〜10年度）」＝ パンフレット「50万円／30万円」＝ 要領「300,000円／70歳以上かつ令和11年3月31日まで完了で500,000円」一致（令和10年度末＝令和11年3月31日）
- HTML「経費の相当額又は床面積×34,100円のいずれか低い額×23.0%」＝ 要領「除却経費相当額又は耐震改修監理・工事経費相当額のいずれか低い額×23.0%」＝ Q&Aの34,100／㎡目安と整合（算定の根拠は要領、単価目安はQ&A）
- HTML「現に3カ月以上居住」「評点1.0未満」＝ Q&A Q2-5・Q3-3 一致
- HTML「県アドバイザー派遣制度のみ」＝ 診断窓口ページ「除却予定なら3,000円コース」一致
