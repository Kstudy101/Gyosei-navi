## 제도 유형 분류

**間接助成型（現金直接交付ではなく、獣医師への手術費助成による実質割引・抽選制）**。かつ実施主体が市区町村ではなく岩手県獣医師会という民間の職能団体である点が、他の自治体窓口型制度と大きく異なる。

## 개인 관련성 판정

**개인(飼い主)이 이용 가능**한 구조: 飼育犬・ねこの飼い主が「1世帯1頭まで」申し込み、動物病院窓口経由で申込 → 抽選 → 当選すれば補助券で手術費が実質割引される。個人の飼い犬・飼い猫（地域猫に限らない）が対象に含まれる点は盛岡市の地域猫限定制度と明確に異なる。

ただし以下の点で「市区町村の補助金」として記事化するには注意が必要:
1. **実施主体が北上市ではなく岩手県獣医師会**（一般社団法人＝民間職能団体）。北上市の予算・条例に基づく補助金ではない。
2. **岩手県内全域が対象**であり、北上市民に限定された制度ではない（北上市サイトはこの県獣医師会事業を告知しているだけ）。
3. **抽選制**であり、申込めば必ず助成を受けられるわけではない。
4. **募集期間が令和8年9月30日で終了**しており、単年度事業として毎年度実施要領が更新される可能性が高い（原文に令和9年度以降の実施予定の記載なし）。
5. 助成金は獣医師に対して支出される仕組みであり、飼い主が直接現金を受け取る補助金ではない。
