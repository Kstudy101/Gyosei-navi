## ⚠️ 먼저 확인할 것 — 이 제도는 城東区 고유 제도가 아니다

「大阪市緊急通報システム事業」은 **大阪市(政令指定都市) 福祉局 高齢者施策部 地域包括ケア推進課**가 시행하는 **大阪市 24개 구 공통 제도**다. 城東区는 이 중 하나의 신청창구(城東区保健福祉センター 保健福祉課)일 뿐이며, 城東区만의 독자적 급부・요건・금액이 아니다. 기사 작성 시 "城東区 제도"로 단정하지 말고 "大阪市 제도, 城東区 주민 관점의 신청창구 안내"로 명확히 서술해야 한다(다른 23개 구도 요건・금액은 동일, 신청창구 전화번호만 구별로 다름 — `04_kaku-ku-madoguchi-ichiran.txt` 및 `03_jigyounaiyou.pdf` 참조).

## ⚠️ 원문에서 확인되지 않은 것 (unresearched)

- **城東区 독자적인 상한액・추가지원(구 단독 상승분)** — 원문 어디에도 城東区가 大阪市 공통제도에 추가로 급부하는 내용은 없음. "없다"고 단정하기보다, 城東区 홈페이지 전체를 샅샅이 훑은 것은 아니므로 `unresearched`로 남긴다.
- **연간 신청건수・예산규모(城東区 또는 大阪市 전체)** — 공식 페이지에 통계 수치 게재 없음. 확인 안 됨.
- **협력자 등록 관련 상세 서식(様式) 원문 내용** — PDF 첨부파일 목록만 확인했고, 각 첨부 PDF(신청서 등) 자체는 다운로드하지 않음(양식지이므로 기사 본문에 필수는 아니라 판단, 필요시 추가조사 가능).
- **행정온라인시스템(大阪市行政オンラインシステム)에서 정확히 어떤 절차까지 온라인 신청 가능한지** — 원문은 "일부 신청"이라고만 명시, 구체적 범위 불명.
- **城東区 보건복지과 창구의 실제 접수시간(9:00~17:30 외 금요일 연장시간 중 保健福祉課가 어디까지 대응하는지)** — `05`(やさしい日本語판)에 "金曜日は一部窓口のみ延長"이라고 나오나 保健福祉課가 그 "一部"에 포함되는지는 원문에 애매하게("窓口サービス課와 保健福祉課〈一部〉") 표기되어 있어, 緊急通報システム 신청업무가 금요일 연장시간에 가능한지는 확정 불가 — 추가 확인 필요시 城東区保健福祉課(06-6930-9857)에 직접 문의 권장.
- **신체장애 대상자 요건 문구의 미세한 차이**: 홈페이지 본문(`01`)은 "외출곤란한 신체장애 2급 이상 또는...(단신세대 또는 1일 8시간 이상 1인)"으로, PDF(`03`)는 "신체장애2급 이상 또는...(단신세대 또는 이에 준하는 세대)"로 표현이 미묘하게 다름. 두 원문 모두 확보했으나 완전히 동일 문구는 아니므로, 기사 작성시 대표 문구는 홈페이지 본문(`01`, 최신 갱신일 2026-08-20 기준)을 우선하고 PDF 표현 차이를 각주 처리할 것을 권장.
- 城東区 이외 다른 23개 구의 창구 접수시간(구별로 다를 수 있음)은 `04`(각구 소재지 일람)에서 일부만 확인했고 전수조사는 하지 않음 — 城東区 기사에는 불필요하므로 skip.
