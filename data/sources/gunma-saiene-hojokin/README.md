# gunma-saiene-hojokin

対象候補記事（government-researcher調査段階）: 群馬県「令和8年度太陽光発電設備等導入支援事業費補助金」及び「令和8年度住宅用蓄電池導入支援事業費補助金」（個人住宅・事業者向け再エネ導入支援補助制度）

## 制度の性質に関する重要な注記

`gunma-taiyoko-yushi`（住宅用太陽光発電設備等導入資金＝低利融資制度）とは別に、群馬県グリーンイノベーション推進課は**給付型（返済不要）の直接交付補助金**を実施している。環境省の「地域脱炭素移行・再エネ推進交付金」及び内閣府の「物価高騰対応重点支援地方創生臨時交付金」を活用した事業で、個人・中小企業者等が対象。

**重要**: 令和8年度分は2026年6月29日～7月20日で交付申請の受付を既に終了しており（本文取得時点＝2026-09-22で「【交付申請受付を終了しました】」の表題）、抽選済み・当選者確定済みの状態。記事化する場合は「現在募集中」ではなく「令和8年度は受付終了、次年度の実施有無・スケジュールは群馬県公式サイトで要確認」である旨を明記する必要がある。過去にも令和6・7年度と毎年度実施されている実績があり、令和9年度も同様の制度が実施される可能性が高いが、予算措置・スケジュールは未確定（unresearched）。

- 令和8年度の抽選で落選した場合の追加募集・二次募集の有無 → unresearched。
- 「【終了しました】令和7年度の個人住宅・事業者向け再エネ導入支援補助制度について」（https://www.pref.gunma.jp/page/697525.html）は検索結果に存在を確認したが、原文取得（アーカイブ）はしていない。前年度の補助単価比較が必要な場合は別途取得が必要。
