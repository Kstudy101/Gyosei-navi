## 確認された主な事実

- 対象: 市立小・中学校等に在籍する児童・生徒の保護者で、経済的理由・児童扶養手当受給・市民税非課税等のいずれかに該当する方
- 所得基準（目安）: 2人世帯約223万円、3人世帯約287万円、4人世帯約319万円、5人世帯約344万円
- 学用品費: 小1 11,630円、小2-6 13,900円、中1 22,730円、中2-3 25,000円
- 新入学学用品費（入学後）: 小1 64,300円、中1 81,000円
- 新入学学用品費（中学入学前）: 小6 81,000円（3月支給）
- 小学校給食費: 令和8年度から無償化
- 中学校給食費: 認定日以降分を教育委員会が負担
- 申請: 毎年4月から、電子申請（令和8年度から）または紙申請

- 所得基準の詳細（年齢構成別の詳細計算式）
- 令和9年度以降の小学校給食費無償化の継続
