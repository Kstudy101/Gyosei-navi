## 原文根拠表

| 項目 | 内容 | 根拠 |
|---|---|---|
| 対象治療 | 人工授精（医療保険適用）。第三者精子提供・代理母は対象外 | 01 §1／07 §1 |
| 対象者 | 県内に住所を有し人工授精治療を受けている法律上の夫婦（事実婚は対象と記載なし）。申請日前年（1～5月申請は前々年）の夫婦合算所得額が730万円未満 | 01 §2／07 §2 |
| 所得制限の現況 | 県分は730万円の所得基準の記載あり（01・07）。下関市は市独自分で令和8年度から所得制限撤廃・上限撤廃だが、県分（9,000円まで）は「730万円以内」の表を維持 | 04 |
| 助成額 | 1年度9,000円まで。通算5年間。3年目以降は医師が必要と判断したものに限る。記入例に「1回申請5,460円／2回以上9,000円」 | 01 §3／07 §3・記入例／05 |
| 申請先 | 住所地の市町、または市町を管轄する県健康福祉センター。市町提出分は県健康福祉センターへ送付され審査。郵送可 | 01 §4／07 §4 |
| 申請期限 | 治療を受けた日の属する年度内（消印有効）。3月治療分は翌年度4月15日まで。当年度に限度額まで助成済みの場合は対象外。期限後は受付不可 | 01 §4／07 §4 |
| 必要書類 | 申請書（別記第1号）、受診等証明書（別記第2号）、住所確認書類、婚姻証明（住民票続柄記載）、夫婦それぞれの所得証明、領収書（保険適用分） | 01 §5／07 §5 |
| 市町上乗せの例 | 下関市: 県の承認通知書日付から2か月以内に市へ申請、令和8年度は全額助成（県9,000円超過分）。所得730万円超の夫婦は市が直接受付 | 04 |
| 現行の別制度 | しあわせ運ぶ妊活応援事業: 保険適用の生殖補助医療1回6万円限度、先進医療1回20万円限度。令和8年3月31日までの治療分の受付は終了、令和9年3月31日までの治療分の期限は原則令和9年4月30日 | 03 |
| 同上 不育症検査費 | 先進医療の不育症検査の費用の7割、上限6万円 | 02（詳細ページは未取得） |
| 不妊専門相談 | 不妊専門相談センター（県立総合医療センター「女性のなやみ相談室」）、無料 | 02 |
