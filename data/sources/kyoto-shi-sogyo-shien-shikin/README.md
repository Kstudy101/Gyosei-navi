# 原文根拠表: 京都市 創業支援資金（中小企業融資制度）

## 制度概要
- 制度名: 京都市中小企業融資制度「創業支援資金」（京都信用保証協会保証付融資）
- 実施主体: 京都市（産業観光局）
- 問い合わせ: 京都市産業観光局産業企画室（TEL 075-222-3337）／制度融資取扱金融機関
- 特定創業支援の問い合わせ: 京都市スタートアップ・産学連携推進室（創業支援担当）

| 対象（創業型） | 市内で創業する方、創業後5年未満の方 | 03_sougyo.pdf |

| 保証人 | 原則として法人代表者以外の連帯保証人は不要 | 03_sougyo.pdf |
| 担保 | 必要に応じて徴求 | 03_sougyo.pdf |
| 取扱金融機関 | 京都銀行・南都銀行・滋賀銀行・関西みらい銀行・池田泉州銀行・京都信用金庫・京都中央信用金庫・近畿産業信用組合・京滋信用組合・三菱UFJ銀行・みずほ銀行・商工組合中央金庫 | 01_main.txt / 03_sougyo.pdf |
| 認定特定創業支援のメリット | 登録免許税軽減／創業関連保証の早期利用／融資限度拡充／公庫特別利率／持続化補助金創業型（上限200万円） | 02_startup.txt |

## 同チラシに記載があるが本記事の主対象外
- 事業転換・多角化型（限度額1億円以内）
- 第二創業型（限度額2,000万円以内、運転資金は1,000万円以内）
- スタートアップ創出促進保証制度（保証限度額3,500万円等）
