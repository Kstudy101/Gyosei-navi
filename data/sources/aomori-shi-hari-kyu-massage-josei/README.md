## 対象自治体・制度
- 自治体: 青森県青森市
- 制度名: はり・きゅう・マッサージ施術料の助成
- 所管: 青森市福祉部高齢者支援課（駅前庁舎）／浪岡地区は健康福祉課（浪岡庁舎）
- カテゴリ: kaigo（介護）
