## 確認された主な事実

- 制度名: 心身障害者医療費助成（仙台市独自）
- 内容: 保険診療の自己負担相当分の一部または全部を助成。償還払い（後日口座振込）
- 全額助成: 身障1・2級（総合等級）、身障3級（心臓・じん臓・呼吸器・ぼうこう・直腸・小腸・免疫・肝臓・部位等級）、特別児童扶養手当1級、療育A、精神1級
- 3分の2助成（65歳未満）: 身障3級（視覚・聴覚・平衡・音声言語そしゃく・上肢・下肢・体幹・運動機能・部位等級）、特別児童扶養手当2級、療育B+障害基礎年金等。65歳の誕生月（誕生日1日は前月）の保険診療分まで
- 所得制限あり。障害者本人20歳以上・扶養0人: 令和8年10月1日〜 3,758,000円 / 令和7年10月1日〜令和8年9月30日 3,661,000円。配偶者・扶養義務者 6,287,000円（扶養0）
- 受給者証有効期間: 10月1日〜翌年9月30日
- 生活保護受給中は対象外。入院食事代・差額ベッド・介護保険利用者負担は対象外
- 助成額100円未満は対象外
- 振込: 社保 約2か月後15日 / 仙台市国保・後期高齢 約3か月後28日
- 資格登録は手帳交付日・転入日から30日以内（超過時は申請月1日から）
- こども医療費助成対象年齢はこども医療を優先
