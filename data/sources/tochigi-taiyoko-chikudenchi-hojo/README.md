## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 취득 시점(2026-09-24)에서 예산 소진율 약85%로 조기 마감 가능성 있음. 실제 마감일 확인 필요.
- 이미 태양광 설치된 주택에 추가 축전지만 설치하는 경우는 보조 대상 외라고 명기.
- 보조 상한 28만엔(4kW)·25.8만엔(5kWh)은 최대값. 실제 설치 용량에 따라 보조액 달라짐.
- 기기별 자세한 요건(메이커 지정 등)은 交付要領PDF 및 Q&A PDF에 기재되나 미취득.
