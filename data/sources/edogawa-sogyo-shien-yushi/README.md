## 제도 유형 분류

**融資あっせん型**（金利優遇＝利子補給・信用保証料全額補助）。구가 현금을 직접 교부하는 것이 아니라, 구와 융자취급계약을 맺은 지정금융기관이 신용보증협회의 보증을 받아 융資를 실행하고, 구가 사후적으로 이자 일부와 신용보증료를 보조하는 방식.

## ⚠️ 원문에서 확인되지 않은 것 (unresearched)
