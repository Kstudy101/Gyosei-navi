## 核心数値（01原文より）

- 制度名: 介護用品の給付
- 運営: 大阪市福祉局高齢者施策部地域包括ケア推進課
- 給付: 給付券 1か月あたり6,500円分、申請月に応じて交付、1年間に最大12枚
- 給付期間: 7月〜翌年6月（受給中も毎年更新手続きが必要）
- 対象介護用品: 紙おむつ、尿取りパッド、清拭剤、ドライシャンプー、使い捨て手袋、介護用スプーン・フォーク、介護用箸、差し込み式便器・尿器、防水シーツ、口腔ケア用品、食事用エプロン、消臭剤、とろみ剤
- 支給事業者（令和7年7月1日〜令和9年3月31日）: 株式会社ゴトウ・アズ・プランニング、株式会社セレクト、ダイキチレントオール株式会社
- 対象: 市内在住の要介護高齢者を在宅介護する市内在住の家族。要介護4または5、または要介護3で認定調査票の「排尿」「排便」のいずれかが全介助。要介護高齢者・介護者とも市民税非課税世帯。申請は介護者1人のみ
- 自己負担: 原則なし。給付券1枚（6,500円分）超過分は自己負担
- 申請窓口: 要介護高齢者の住民登録がある区の保健福祉センター福祉業務担当（高齢者福祉）
- ページ最終更新表示: 2026年9月17日
