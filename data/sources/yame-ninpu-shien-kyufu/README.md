## 核心数値（原文対照）

出典は特記なき限り `01_main.txt`。

| 項目 | 原文の記載 |
|---|---|
| 枠組み | 子ども・子育て支援法の「妊婦のための支援給付」（令和7年4月1日施行）。市では「やめっこ未来応援金事業」として実施。並行して「妊婦等包括相談支援」 |
| 経過措置 | **令和7年3月31日以前に出産**された方は、**令和6年度やめっこ未来応援金事業**での給付 |
| 共通要件 | 申請日時点で**八女市に住民登録**があること |
| 1回目 | 妊娠届出時。**令和7年4月1日以降に妊娠届出**。医療機関で**胎児心拍の確認**が必要。妊婦給付認定後、**妊娠1回につき5万円** |
| 2回目 | 見出し上「出生から生後4か月頃まで」。1回目支給を受け、**令和7年4月1日以降に出産・胎児の数の届出**をした方。支給額欄では**出産予定日の8週間前の日以降**に、**胎児1人当たり5万円** |
| 支給方法 | **現金給付（5万円）**、もしくは**ポイント給付（にこふくギフト 55,000円相当）**を選択可。「にこふくギフト」は福岡県が運用する申請プラットフォーム |
| 申請 | 1回目: 妊娠届出窓口で案内。2回目: 出産後の面談終了後に申請書交付→八女市こども家庭センターへ提出 |
| 流産・死産等 | 令和7年4月1日以降、流産・死産・人工妊娠中絶も対象となる場合あり。医師が胎児心拍を確認した際の診断書等で妊娠の事実・胎児の数を確認 |
| 相談支援 | 妊娠届出時面談、妊娠8か月時アンケート、赤ちゃん訪問・出産後面談 |
