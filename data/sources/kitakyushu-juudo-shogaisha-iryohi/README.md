対象自治体: 福岡県北九州市（団体コード40100／検査数字込み6桁は401005）
対象制度: 北九州市重度障害者医療（ページ題「重度障害のある方へ医療費を助成します」）

## 制度類型

**現物給付型（医療費自己負担の全額助成）** — 「重度障害者医療証」と健康保険情報を県内医療機関窓口に提示して助成。現金の定額給付ではない。県外受診・医療証忘れ等は償還払い。

## 原文で確定した事実（01_iryohi.txt）

| 項目 | 原文 |
|---|---|
| 制度名（ページ題） | 重度障害のある方へ医療費を助成します |
| 制度の通称表現 | 重度障害者医療／重度障害者医療費支給制度 |
| 目的 | 重度障害者の健康の保持及び福祉の増進をはかるため、保険診療による医療費の自己負担額を助成する |
| 対象① | 市内に住所を有する |
| 対象② | 健康保険に加入している |
| 対象③手帳 | 身体障害者手帳（1級または2級）／療育手帳（A表示）／精神障害者保健福祉手帳（1級）のいずれか |
| 対象外① | 生活保護を受けている人 |
| 対象外② | 65歳以上の人で後期高齢者医療に加入していない人 |
| 対象外③ | 前年の所得（1〜9月申請は前前年）から一定の控除額を差し引いた額が所得制限限度額**以上**の人 |
| 所得制限（扶養0人） | 459万6千円 |
| 所得制限（扶養1〜5人） | 497万6千円／535万6千円／573万6千円／611万6千円／649万6千円 |
| 助成範囲 | 保険診療による自己負担額の**全額** |
| 助成対象外① | 精神障害者保健福祉手帳1級の人の精神病床への入院医療費（ただし18歳に達する日以後の最初の3月31日までは無料） |
| 助成対象外② | 入院時の食事代等（標準負担額） |
| 助成対象外③ | 保険診療以外（差額ベッド代、健康診断、予防接種、選定療養費、保険外歯科等） |
| 選定療養費注記 | 令和6年10月から、後発医薬品がある先発医薬品希望時は価格差の4分の1相当が自己負担・保険適用外 |
| 医療証提示 | 県内医療機関で健康保険情報＋重度障害者医療証を提示 |
| 償還払い対象 | 県外受診／医療証忘れ／治療用器具作製／他の公費後も自己負担が残る場合 |
| 償還時効 | 医療費支払いの翌日以降5年 |
| 更新 | 原則毎年10月に自動更新（所得超過・手帳確認不可・65歳到達・精神手帳有効期限等は例外） |
| 転入時の有効開始 | 転入翌日〜15日以内申請なら転入日から有効。15日経過後は申請月の初日から（ただし転入日と申請日が同月なら転入日から） |
| 窓口 | 住所地の区役所保健福祉課高齢者・障害者相談係（7区の電話・住所は原文表） |
| ページ更新日 | 2026年7月8日 |
