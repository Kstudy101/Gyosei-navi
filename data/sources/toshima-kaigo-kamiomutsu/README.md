## 制度概要（分類）

豊島区には在宅高齢者向けの介護用品支給に関して、**互いに排他的な2つの制度**が存在する（同月内の併給不可であることが両ページに明記）。

| 制度名 | 制度種別 | 対象 |
|---|---|---|
| 高齢者紙おむつ等支給 | **現物支給型**（カタログ選択・現物配布） | 在宅（有料老人ホーム・グループホーム含む）で常時紙おむつ等が必要な要介護1以上のかた |
| 高齢者おむつ購入費等助成 | **現金助成型**（購入費の助成） | 医療機関に入院中で常時紙おむつ等が必要な要介護1以上のかた |

所管はいずれも豊島区高齢者福祉課高齢者事業グループ（電話 03-4566-2432）。

## 確認できた最終数値・条件

### 高齢者紙おむつ等支給（01より）
- **支給内容**: 1か月80点（8,000円相当分）を上限に、常時紙おむつ等が必要な在宅の方へ月1回紙おむつ等を配布（カタログから商品選択）。
- **改定**: 令和7年9月分から支給上限が70点→80点（8,000円相当分）に引き上げ。
- **対象者**（すべて満たす必要あり）:
  1. 要介護認定「要介護1以上」（第2号被保険者含む）
  2. 介護保険料所得段階が第1〜5段階
  3. 常時紙おむつ等が必要
  4. 在宅（有料老人ホーム・グループホームは在宅扱いで対象。特別養護老人ホーム・介護老人保健施設・介護医療院入所者、医療機関入院中の方は対象外＝入院中は下記「おむつ購入費等助成」の対象になり得る）
  5. 生活保護制度の扶助を受けていない
  - 「高齢者おむつ購入費等助成」を同月内に受けている場合は併給不可。
- **申請の流れ**: 「高齢者紙おむつ等支給申請書」を高齢者総合相談センターへ提出（電子申請サービスも可）→ 区が要介護度・所得段階等を審査→ 決定通知または却下通知を郵送→ 決定通知に同封のカタログから商品を注文。
- **問合せ**: 高齢者福祉課高齢者事業グループ 03-4566-2432。

### 高齢者おむつ購入費等助成（02より）
- **助成内容**: 1か月8,000円を上限に、入院中のおむつ購入費等を申請月の分より助成（現金給付・口座振込）。
- **改定**: 令和7年9月分から助成上限が7,000円→8,000円に引き上げ。
- **対象者**（すべて該当する必要あり）:
  1. 要介護認定「要介護1」以上（第2号被保険者含む）
  2. 介護保険料所得段階が第1〜8段階
  3. 常時紙おむつ等が必要
  4. 医療機関に入院している（特別養護老人ホーム・介護老人保健施設・介護医療院入所者は除く）
  5. 生活保護制度の扶助を受けていない
  - 「高齢者紙おむつ等支給事業」を同月内に受けている場合は併給不可。
- **申請方法**: 「高齢者おむつ購入費等助成申請書」をお住まいの地域の高齢者総合相談センターへ提出（電子申請サービスも可）。申請日時点で入院していることが必要（入院中に申請）。
- **申請に必要なもの**: 本人の振込口座確認書類（通帳コピー等）／本人以外の口座希望時は委任状／成年後見人申請時は「本人確認証」＋発行6か月以内の「登記事項証明書」。
- **請求**: 決定通知受領後、高齢者総合相談センターで請求。**請求月は1月・4月・7月・10月の年4回**。必要書類の詳細は決定通知郵送時に案内。
- **問合せ**: 高齢者福祉課高齢者事業グループ 03-4566-2432（01と共通）。
