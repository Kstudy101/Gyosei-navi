## 確定した事実
- 制度名：住宅改修（介護予防含む）＝甲府市介護保険住宅改修費支給
- 対象者：要支援・要介護認定を受け、ケアマネジャー等の意見に基づき住宅改修（厚生労働大臣が定める種類）を行った方
- 支給額：住宅改修費用のうち20万円（支給限度基準額）を上限として、その9割（一定以上の所得者は8割または7割）相当額
- 転居時や要介護状態区分が一定以上悪化した場合は支給限度基準額が再度20万円に設定される
- 対象工事：手すりの取付け、段差の解消、床材の変更、扉の取替え、便器の取替え、これらに付帯する工事
- 家屋の老朽化を原因とする改修や身体状況に関係ないリフォームは対象外
- 申請方式：原則「事前申請」（工事着工前に長寿介護課へ申請書類提出、着工前申請がない場合は支給されない）＋工事後の事後報告
- 支払い方式：原則「償還払い」（利用者が全額支払後に9割等が支給）だが、甲府市では「受領委任払い」（利用者負担分のみ支払い、保険適用分は市から施工業者へ直接支払い）も選択可能
- 事後報告から支給までは約1か月
- 問い合わせ：福祉支援室長寿介護課保険給付係 055-237-5480
