## 核心数値（原文対照）

出典は特記なき限り `01_ninpu-no-tame-no-shien-kyufu.txt`。FAQは `02_faq.txt`。

| 項目 | 原文の記載 |
|---|---|
| 制度移行 | 子ども・子育て支援法改正に伴い、現行の「出産・子育て応援金」は令和7年4月から「妊婦支援給付金」に変更（01・03） |
| （1回目）対象 | 鹿児島市に住民票があり、令和7年4月1日以降、妊婦である方 |
| （1回目）支給額 | 妊婦1人当たり **5万円** |
| （1回目）支給時期 | 母子健康手帳交付時の面談で申請書を交付し、申請受付日の翌月末を目途に指定口座へ振込 |
| （2回目）対象 | 鹿児島市に住民票があり、令和7年4月1日以降、出産された方 |
| （2回目）支給額 | 妊娠された胎児1人当たり **5万円** |
| （2回目）支給時期 | 新生児訪問時の面談で申請書を交付し、申請受付日の翌月末を目途に指定口座へ振込 |
| 口座 | 妊婦本人名義以外の口座への振込は不可（01・02） |
| 通常の申請 | 面談で申請書交付後、郵送申請 |
| オンライン申請 | 公金受取口座登録済みのマイナンバーカード所持者はマイナポータルから申請可（本人確認・口座確認書類の添付と郵送が不要） |
| 流産・死産等 | 申請可。母子健康手帳で妊娠の事実・胎児数を確認。届出前の流産等は医師の胎児心拍確認の診断書等が必要。マイナポータル電子申請は不可。母子保健課窓口 |
| 流産・死産の支給額 | 妊婦1人あたり5万円、胎児1人当たり5万円（既に妊娠時5万円を受けた場合は胎児1人あたり5万円） |
| FAQ: 胎児心拍未確認の流産 | 産科医療機関を受診せず流産に至った場合は支給不可 |
| FAQ: 振込口座（夫名義） | 不可 |
| FAQ: DV避難 | 住民票のある市町村へ申請 |
| FAQ: 転出（1回目未申請） | 転出先市町村へ申請 |
| FAQ: 1回目受給後に転出 | 転出先で妊婦給付認定後、胎児の数の届出で2回目 |
| FAQ: 里帰り出産 | 住民票のある鹿児島市へ申請 |
| FAQ: 海外妊娠・出産後帰国 | 妊娠期間中に鹿児島市に住民票があれば対象 |
| 経過措置 | 令和7年3月31日までに出生したお子様のいる家庭への経過措置は終了（01） |
| FAQ: R7.3.31以前の流産・死産 | 2回目は対象外 |

## 制度類型

現金振込型（妊娠時5万円＋出産後・胎児数×5万円）。国の「妊婦のための支援給付」を市が実施する枠組み。市独自の出産祝い金加算は当該原文では確認していない。
