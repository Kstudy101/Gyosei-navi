### 対象機器の購入・確定期間（各期共通）
出典: `01`
- エアコン・冷蔵庫: 令和8年1月1日〜12月31日に購入した、東京都「東京ゼロエミポイント」対象機器
- 太陽光: 令和8年4月1日〜12月31日に都の太陽光発電補助の**助成額が確定**した機器（交付決定＋額確定が条件）

### 対象者
出典: `01`・`03`
- 区内に住所を有する個人で、その住宅に自ら使用する目的で設置した者
- 管理組合・事業者等は対象外。リース不可
- 各機器につき年度ごとに世帯で1台まで
- 蓄電池は対象外

### 申請・請求
出典: `01`・`02`・`03`
- 電子申請（LoGoフォーム）のみ。紙不可。申請フォームは「後日公開」（原文時点）
- 付与決定後にポイント請求が必要。請求期限: **令和9年3月10日**（各期共通）。請求しないと付与されない／辞退扱い
- 審査: 2〜4週間程度（混雑時はそれ以上）
