## 確認結果

- PDF 5ページ目（青森県セクション、北海道の次）に以下の記載を確認:
  `022012　青森県　青森市　アオモリケン　アオモリシ`
- 検査数字込み6桁の団体コードは **022012**。
- このファイルの既存登録慣行（横浜市 141003→14100、名古屋市 231002→23100 等と同様、末尾の検査数字1桁を除いた5桁を採用）に従い、青森市は **`02201`** として登録する。
- slug は県スラッグ「aomori」との混同を避けるため、さいたま市（saitama-shi）・京都市（kyoto-shi）等と同じパターンで **`aomori-shi`** とする。
- 青森市は政令指定都市ではないため、区単位ではなく市全体を1エントリとして登録する（岡山市・静岡市と同じ扱い）。
- 青森県として初の市区町村登録。
