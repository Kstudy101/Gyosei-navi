## 確認できた主要事実（一次確認）

### 制度名
- 案内ページ表記: **紙おむつ給付サービス**（原文01）
- 申請書様式名: **石狩市寝たきり高齢者等紙おむつ給付申請書**／事業名 **石狩市寝たきり高齢者等紙おむつ給付事業**（原文03・06）
- 進捗資料でも「寝たきり高齢者等紙おむつ給付サービス」と表記（原文07）

### 目的・給付形態（原文01）
- 保健衛生の向上及び家庭の経済的負担軽減を目的に、**自宅まで紙おむつを配達**する現物給付

### 対象（原文01）
自宅で日常生活を営む上で紙おむつを利用しており、次のいずれかに該当する方:
1. 65歳以上であって要介護認定に係る調査結果等における寝たきり度がB以上であり、排泄において一部介助もしくは全介助が必要であると認められた方
2. 40歳以上であって要介護認定に係る調査結果等における認知症高齢者の日常生活自立度が3a以上であり、排泄において一部介助もしくは全介助が必要であると認められた方
3. 身体障害者手帳の等級が1・2級である、3歳以上で寝たきり状態等の方
4. 療育手帳がA判定である、3歳以上で寝たきり状態等の方

※原文01末尾: 「記載の対象要件を満たさない場合でもサービスの利用が認められる場合があります。詳細は高齢者支援課までお問い合わせください。」

### 給付の仕組み（原文03）
- 「紙おむつは、**１月に必要とする枚数を隔月で給付**します。」（申請書注記）

### 品目（原文05・令和8年度メーカー希望用紙）
希望用紙上で選択可能な大分類:
- パンツタイプ（はくタイプ）
- パンツタイプ（テープタイプ）※用紙表記
- フラットタイプ（平おむつ）
- 尿とりパッド
- 濡れタオル（おむつ交換時用）も記載あり
メーカー例: 白十字・クレシア・ネピア・大王製紙・ユニチャーム・光洋・花王 等（用紙記載の商品から**1つだけ○**）

### 申請書類（原文02）
申請書ダウンロードページ「紙おむつ給付サービス」欄:
- 紙おむつ給付事業申請書
- 紙おむつ給付事業調査票（介護支援専門員・市保健師用）
- 紙おむつ給付事業メーカー希望用紙（令和8年度）
- 紙おむつ給付事業利用者異動届

### 窓口（原文01・02）
- 福祉部 高齢者支援課（石狩市総合保健福祉センター「りんくる」1階）
- 電話: 0133-72-6121（ページ下部共通）／在宅サービス関連の問い合わせ表記として 0133-72-7014 も原文02にあり
- ファクス: 0133-72-1165
- Eメール: koureisyas@city.ishikari.hokkaido.jp

### 制度の位置づけ（原文07）
- 「寝たきり高齢者等紙おむつ給付サービスは**令和３年度より市町村特別給付で実施**しています。」（令和6年度進捗確認資料）

### 制度類型
現物支給型（自宅配達）・隔月給付（1か月分）
