## 原文から確定した数値・条件（記事に使用可）

- 補助額: 工事費用（税抜き）の1/3（最大10万円）、2千円単位ごとに切り捨て
- 受付期間: 令和8年5月11日（月）〜令和8年12月28日（月）、先着順・予算到達で終了、窓口持参のみ（郵送不可）
- 完了報告期限: 令和9年2月26日（金）必着
- 対象住宅: 川口市内の既存集合住宅（新耐震、または旧耐震で耐震適合確認済）。新築・一戸建ては対象外
- 申請者: 賃貸既存集合住宅の所有者、または区分所有者団体の管理者（市税・県税滞納なし）
- 工事: 交付決定通知後に契約・着手。固定式・セキュリティ付き・3辺合計60cm以上のボックス1つ以上・新品（リース不可）等
- 1棟につき1箇所まで
- 業者の本社所在地は市内外問わず可。自己購入・自己設置は不可

## 確認されていないこと

- 令和8年度の予算残額・現時点の受付可否（先着順のため公式問い合わせが必要）
- 県補助の個別配分額・県側の最新通知文面（市ページ・要綱・パンフで市制度として確認済みのため記事化は市制度として扱う）
- ブロック塀等安全対策補助の金額（別制度。本アーカイブ対象外。HTMLに金額なし・PDF要追加調査）
