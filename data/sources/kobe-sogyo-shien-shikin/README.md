# 神戸市 こうべ創業支援貸付（中小企業向け融資制度） — 原文アーカイブ

## 制度概要
神戸市独自資金「こうべ創業支援貸付」。営業開始5年未満の小規模企業者が対象。信用保証料は神戸市が全額負担。融資上限500万円、金利年1.85%（固定）、融資期間7年以内（据置1年以内／設備のみ1年6か月以内）。
