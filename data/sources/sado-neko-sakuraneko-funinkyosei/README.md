## 地方公共団体コードの根拠

佐渡市公式ページのフッターに記載された法人番号「9000020152242」は、地方公共団体の法人番号が
「9000020」+ 6桁の地方公共団体コード（検査数字含む）で構成される総務省の付番ルールに基づく。
このため末尾6桁「152242」が佐渡市の地方公共団体コード（検査数字込み）であり、
`src/config/regions.ts` の5桁表記では検査数字を除いた「15224」を採用した（新潟県コード15 + 市区町村コード224）。
出典: 01_sakuraneko-funinkyosei.txt（フッター「法人番号9000020152242」の記載）。

## 制度の種別分類

現物支援・無料化仲介型（市が現金を交付する補助金ではなく、公益財団法人どうぶつ基金の
「さくらねこ無料不妊手術事業」行政枠への申請を市が取り次ぎ、手術自体を無料で受けられるようにする制度）。
個人単位の申請は不可で、集落・地域単位の申請に限られる点が新潟県内の他市町村（動物愛護協会による
定額現金助成型）と異なる。
