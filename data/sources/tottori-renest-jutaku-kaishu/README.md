| 항목 | 원문 |
|---|---|
| 제도명 | とっとり健康省エネ住宅改修支援事業補助金（Re NE-ST） |
| 목적 | 既存住宅の断熱改修施主に対し改修費の一部を補助 |
| 개수패턴1: 全面改修等『Re NE-ST』 | 보조율 1/3、**最大補助額 150万円/戸**、性能要件 UA値0.48以下 |
| 개수패턴2: ゾーン改修 | 보조율 1/3、**最大補助額 100万円/戸**、性能要件 UA値0.48以下（断熱区画内） |

| 기본 요건 | 省エネ性能向上改修を行う既存戸建て住宅が対象。設計及び施工は県に登録された事業者が行うこと |

| 국가 보조금 병용 | 先進的窓リノベ事業（1/2、最大100万円/戸）、長期優良住宅化リフォーム推進事業（1/3、最大210万円/戸）、既存住宅における断熱リフォーム支援事業（1/3、最大120万円/戸）との併用可（参考記載） |
| 전자 신청 | とっとり電子申請サービスで申請可 |
| 상담 창구 | じゅうmado米子（非営利相談窓口）〒683-0853 米子市両三柳2360-8、TEL: 0859-38-8010 |
