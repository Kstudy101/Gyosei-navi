## 制度の性質に関する重要な注記

**予算がなくなり次第、年度途中でも受付終了**する制度。原文に「例年、年度途中で予算額に達しており、申請受付が終了しております」と明記されている（01_gaiyo.txt L168）。記事化する場合は、通年募集ではなく先着・予算枠内である旨と、手術前の受付状況確認を推奨する旨を明記する必要がある。取得時点（2026-09-22、ページ更新日2026年4月1日）で「令和8年度の申請受付を開始しました」との記載があるが、本調査時点で受付終了の有無は未確認（unresearched）。
