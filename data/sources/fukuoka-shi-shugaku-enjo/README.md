## 確認できた最終数値・条件

### 対象（02）
市内の市立小・中学校に通学する子、または市内居住で国・県立小・中学校に通学する子をもつ世帯のうち、経済的理由で学習等費用の支払いに困る世帯。要件1〜6のいずれか:
1. 生活保護の廃止・停止を受けたが現在も経済的に困っている世帯
2. 市・県民税が非課税、または減免適用世帯
3. 国民年金または国民健康保険の保険料全額減免世帯（育児期間免除措置を除く）
4. 職安登録の日雇い労働者、または1か月以内に生活福祉資金貸付を受けた方
5. ひとり親家庭等で児童扶養手当を受けている方
6. 市県民税の課税所得金額が基準額以下の世帯

※生活保護受給中は保護費から就学援助相当額が支給されるため就学援助申請不要。
※父母が同じ要件に該当している必要（ひとり親家庭等を除く）。

### 主要支給額（02・認定月が4月の場合）
**学用品費等（小学校）**: 1年1学期7,070円／2〜6年1学期9,340円／全学年2学期3,850円・3学期2,310円
**学用品費等（中学校）**: 1年1学期14,160円／2〜3年1学期16,430円／全学年2学期6,800円・3学期4,080円
**入学準備金**: 小学校1年 64,300円／中学校1年 81,000円（認定月が4月の世帯のみ）
**修学旅行費**: 小6 実費上限26,180円／中2 実費上限62,300円
**オンライン学習通信費**: 年額15,000円（1世帯・市立のみ）

その他: 社会科見学費（小5実費）／校外活動費宿泊（小上限3,690円・中上限6,210円）／卒業アルバム（小6上限11,000円・中3上限10,000円）／柔道着（中実費上限7,650円・市立のみ）／通学費（距離条件・市立のみ）／災害給付金
