## 確認できた事実（県原文・令和8年4月版チラシ 06 / 画像 002-004 より）

- 位置づけ: 「昭和56年以前の住宅について、耐震診断等や耐震改修を行う際の費用について、県と市町が連携して補助制度を設けています」（01）
- 対象住宅: 昭和56年5月31日以前に建てられた戸建ての木造住宅（07。チラシ表紙は「昭和56年5月以前の木造住宅」）
- 耐震診断＋補強プラン作成: 自己負担最大1万円。「耐震診断と補強プラン作成は同時にお申込みが条件」。耐震診断士が住宅を調査し補強方法・費用を提案
- 耐震改修工事: 補助額「最大140万円まで」。加算は次のいずれか（チラシ上は「OR」）: 高齢者(65歳以上)のみの世帯は35万円加算／過去に作成した補強プランとは別の補強方針で耐震改修工事を実施した場合10万円加算
- 除去工事補助（新制度）: 対象は「過去に耐震診断および補強プランを作成したものの、補強工事に至らなかった世帯」、内容は除却工事費用の補助、補助額は「補助対象経費の23%以内、上限額30万円」
- 注意書き: 「補助額および加算の有無については、市町により異なるため市町担当課まで」「補助額および制度の有無については、市町により異なる」
- 申込先は市町: 「お住まいの市町担当課に耐震診断の補助の申し込みをすると、後日、耐震診断士がご自宅に派遣されます。お申込みについては、市町担当課へお問合せください」（04、06）。伝統的構法の解説PDFにも「申込み・問合せ窓口: 市町の建築担当課（補助の実施状況と内容は市町により異なります）」（08）
- 県の問合せ先: 福井県土木部建築住宅課 住まいづくりグループ 0776-20-0506
- 低コスト工法・部分改修・耐震シェルターなどの方法があると記載（金額の記載なし）。ブロック塀除却補助は別制度として案内のみ
- 旧版(令和7年4月版, 07): 耐震改修「175万円まで自己負担なし」（令和7年度まで）。令和8年4月版は「最大140万円＋加算35万円(高齢者のみ世帯)」に整理されており、合計175万円は福井市の既存READMEの数値と整合する
