# 川崎市 アーリーステージ対応資金 — 原文アーカイブ

## 対象自治体・制度

- 自治体: 神奈川県川崎市（政令指定都市。`regions.ts` 既登録: code `14130` / slug `kawasaki` — **本作業では再登録しない**）
- 制度名: アーリーステージ対応資金（川崎市中小企業融資制度・創業支援資金）
- 属性優遇枠: アーリーステージ対応資金（女性・若者・シニア起業家支援資金）— 同一ファミリーの利率優遇サブタイプ
- 所管: 川崎市経済労働局経営支援部 金融課（044-544-1846・1847）／中小企業溝口事務所（044-812-1112・1113）
- カテゴリ: `sogyo`
- 推奨記事 slug: `kawasaki-early-stage-shikin`
- **制度類型**: **融資あっせん** ＋ **信用保証料助成**（市0.500%助成＋協会0.300%引下げ）＋ **利率優遇**（自己資金割合による金利段階／女性・若者・シニアはさらに年0.1%優遇）。**利子補給（市が金利差額を後払いする型）ではない。** 現金直接補助でもない。
