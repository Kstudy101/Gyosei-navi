## 核心数値（原文対照）

出典は特記なき限り `01_main.txt`。流産・死産手続は `02`。

| 項目 | 原文の記載 |
|---|---|
| 枠組み | 伴走型相談支援と経済的支援（妊婦のための支援給付）を一体として実施 |
| 事業開始日 | **令和7年4月1日** |
| 支給対象 | 妊婦給付認定を行った妊婦。**令和7年4月1日以降に出産された方に限る** |
| 所得制限 | **なし** |
| 妊婦給付認定 | 医療機関受診・医師による妊娠の事実確認（**胎児心拍の確認**）が必要。**異所性妊娠（子宮外妊娠）は支給対象外** |
| 流産・死産等 | 流産・死産・人工妊娠中絶の場合も1回目・2回目の支給対象（面談不要）。電子申請（事前申請フォーム）で事前申請→書類郵送。妊娠届出前の流産等も心拍確認証明書で支給可能な場合あり。申請期限: 1回目=心拍確認日から2年、2回目=流産等が分かった日から2年（`02`） |
| 1回目 | **5万円**。妊娠届出時に妊婦給付認定申請書を記入し、本人確認書類・口座確認書類を提示。他自治体で1回目を受けていないこと。妊娠届出時に保健師・助産師等の面談 |
| 2回目 | **5万円（胎児1人あたり）**。出生後のこんにちは赤ちゃん訪問時（**生後4か月頃まで**）に申請。本人確認・母子健康手帳・口座確認書類。他自治体で2回目を受けていないこと |
| 給付時期 | 申請受付後 **約1か月～2か月後**に指定口座へ振込。毎月月末振込予定 |
| 転入 | 転入前自治体で1回目・2回目を申請していない方は、奈良市母子保健課に相談・面談後に妊婦給付認定・申請可能 |
| 転出 | 転出後に支給を受ける場合は転入先市町村で再認定が必要 |
| 伴走型相談 | 1回目=妊娠届出時面談（子育て応援プラン）。2回目=妊娠8か月前後（アンケート必須。令和8年6月16日以降届出者は電話で様子伺い）。3回目=出産後こんにちは赤ちゃん訪問 |

問い合わせ: 奈良市健康医療部母子保健課（はぐくみセンター3階） / 〒630-8122 奈良市三条本町13番1号 / Tel 0742-34-1978 / Fax 0742-34-5155
