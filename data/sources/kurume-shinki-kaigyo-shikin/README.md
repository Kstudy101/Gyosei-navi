## 対象自治体・制度

- 自治体: 福岡県久留米市（regions.ts code `40203` / slug `kurume`。kekkon記事で既登録）
- 制度名: 新規開業資金（久留米市中小企業融資制度の一種）
- 所管: 商工観光労働部新産業創出支援課（融資・証明書）。信用保証料・利子補給の申請先は商工政策課
- カテゴリ: sogyo（創業支援）
- 制度種別: **融資あっせん型**。現金直接補助ではなく、取扱金融機関からの借入に対し金利・信用保証料を優遇し、借入後1年間の支払利子全額を補給する制度
