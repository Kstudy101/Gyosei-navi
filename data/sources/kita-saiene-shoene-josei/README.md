## 確認された核心数値（原文根拠つき）

### 予算・受付（2026-09-18時点）
出典: `01_saiene-shoene.txt`
- 予算残額: **4,000,000円**（予定金額到達で受付終了）
- 交付申請期限: **令和9年2月26日（金）必着**
- 工事完了報告期限: **令和9年3月15日（月）必着**
- **着工前（原則7開庁日以上前）に交付申請**。着工後は不可
- LED照明器具の助成は**令和8年度で終了**
- 令和8年度変更: 工事完了報告時に契約書写し必須、高反射率塗料・窓断熱の要件変更、口座振替依頼書様式変更

### 一般用 助成額（区外業者 / 区内業者）
出典: `01` 金額表、`02_r8ippan.txt` P.4

| 対象機器 | 区外業者 | 区内業者 |
|---|---|---|
| 太陽光発電システム | 1kW当たり8万円（限度額20万円） | 1kW当たり9.6万円（限度額24万円） |
| 高効率給湯器（エコキュート・ハイブリッド） | 1台5万円 | 1台6万円 |
| 家庭用燃料電池（エネファーム） | 1台5万円 | 1台6万円 |
| 住宅用蓄電システム | 1kWh当たり1万円（限度額10万円） | 1kWh当たり1.2万円（限度額12万円） |
| HEMS | 経費の20%（限度額2万円） | 経費の24%（限度額2.4万円） |
| 高反射率塗料 | 経費の50%（限度額10万円） | 経費の60%（限度額12万円） |
| 窓の断熱改修 | 経費の20%（限度額5万円） | 経費の24%（限度額6万円） |

- 太陽光: 公称最大出力またはパワコン定格出力 **10kW未満**、JET認証等（`02`）
- 蓄電: 国が令和7年度以降に実施した補助事業でSII登録されたもの（`02`）
- 1,000円未満端数切捨て。助成対象経費は消費税除外（`02`）

### 中小企業者等用（事業用途のみ）
出典: `01`・`03_r8kigyou.txt` P.4
- 太陽光・エアコン・LED: 経費の20%（限度額100万円）／EMS認証取得事業所は30%（限度額150万円）
- エコキュート・エネファーム・蓄電等は一般用で申請可能（`01`表）

### 併用・手続き
出典: `01` FAQ・注意事項、`02`
- 国・都助成と併用可。ただし合計が助成対象経費を超えないこと
- 窓口持参が原則（郵送可だが投函だけでは受付完了にならない）
- 問合せ: 北区環境部 環境政策課 環境政策係 TEL 03-3908-8603、〒114-0002 北区王子1-12-4 TIC王子ビル2階
