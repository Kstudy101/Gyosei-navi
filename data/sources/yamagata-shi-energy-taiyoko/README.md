## 確認できた情報
- 接受状況: 「申請総額が予定していた補助金総額（25,099千円）に到達しましたので、令和8年度の受付を終了します」（令和8年9月14日更新）
- 金額（太陽光・市民）: 「7万円/kW、上限63万円（9kW）」
- 金額（太陽光・事業者）: 「5万円/kW、上限1,000万円（200kW）」
- 金額（蓄電池・市民）: 「1/3補助、上限5万円」（家庭用14.1万円/kWh工事費込税抜の1/3）
- 金額（蓄電池・事業者）: 「1/3補助、上限100万円」（業務用16.0万円/kWh工事費込税抜の1/3）
- 金額（EMS・市民）: 「2/3補助、上限5万円」
- 金額（EMS・事業者）: 「2/3補助、上限100万円」
- 対象: 市内に住所を有する個人・法人・社会福祉法人・学校法人・医療法人・NPO法人等（市税滞納なし、他補助金との重複なし）
- 設備要件: 「FIT・FIP制度の認定を取得しないこと」「一定割合（家庭用30%・業務用50%）以上自家消費すること」
- 受付期間（当初）: 「令和8年4月24日（金曜）～12月25日（金曜）（先着順）」
- 受付期間（仮受付）: 「申請総額が予算額に到達した日～7月17日（金曜）」
- 設置完了期限: 「令和9年2月12日まで」
- 申請先: 「市役所環境課窓口（10階）へ提出（郵送不可）」
