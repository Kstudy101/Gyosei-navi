|---|---|---|

| 補助対象工事の例 | 開口部止水板設置工事、床下換気口止水板設置工事、逆流防止弁・枡設置工事 | 03_leaflet |
| 補助率・上限額 | 防災減災工事に要する費用の1/2に相当する額（千円未満切り捨て）。ただし8万円を超えるときは8万円 | 01_yoko.pdf 第33条1項 |
| 契約先要件 | 県内に本店を有する建設業者等と工事請負契約を締結するもの | 01_yoko.pdf 第31条1項2号 |

| 令和8年度の制度拡充 | 補助対象工事費要件を10万円以上に引き下げ、補助率を1/2に引き上げ（上限8万円）※前年度から変更 | 00_top.txt「更新情報」 |
