## topic-scoutの報告との相違点（重要）

topic-scoutが懸念した通り、WebSearchスニペットには民間まとめサイト（hojyokin-portal.jp）が参照した**旧制度「2025年度 青森市地球温暖化対策実行計画推進事業補助金」（1kWあたり7万円・上限35万円）が混在するリスクがあった。しかし市公式ページ・要綱PDFで直接確認した結果、現在有効なのは指示文にあった通り\*\*「令和8年度青森市住宅用自家消費型太陽光発電設備等導入支援事業費補助金」\*\*であり、数値は次の通り確定した:

- 太陽光: **5万円/kW、上限25万円**（旧制度の「7万円/kW・上限35万円」ではない）
- 蓄電池: **対象価格の1/3、上限35万円**（上限単価14.1万円/kWh）
- 申請期間: **令和8年6月1日〜令和8年12月28日**

旧制度（2025年度・1kWあたり7万円・上限35万円）についての原文は本調査では取得していない（既に終了しており、市の現行ページにも記載がないため）。旧制度の詳細を記事で言及する必要がある場合は別途調査が必要。
