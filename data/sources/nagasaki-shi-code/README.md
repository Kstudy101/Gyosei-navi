# 長崎市 — 全国地方公共団体コード 一次情報

## 目的

長崎県長崎市を `src/config/regions.ts` の MUNICIPALITIES に登録するための、総務省公式の団体コード一次情報アーカイブ。
energy カテゴリ「太陽光発電設備等導入補助金」記事調査（`data/sources/nagasaki-shi-taiyoko-hatsuden-hojokin/`）に伴い取得。

## 確認した事実

- PDF 27ページ目、長崎県セクション: `422011 | 長崎県 | 長崎市 | ナガサキケン | ナガサキシ`
- `src/config/regions.ts` の他エントリ（横浜市14100、名古屋市23100、神戸市28100 等）の慣行に合わせ、検査数字を除いた5桁「42201」で登録した。
- 長崎市は政令指定都市ではないため（中核市）、区単位に分割せず市全体を1エントリとして登録する（青森市・津市・下関市等と同じパターン）。
- slugは県スラッグ「nagasaki」との混同を避けるため「nagasaki-shi」とした（さいたま市・京都市・熊本市等と同じパターン）。
