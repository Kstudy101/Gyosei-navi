# 福岡市 研究開発型スタートアップ成長支援事業補助金（令和8年度）— 原文アーカイブ

## 対象自治体・制度

- 自治体: 福岡県福岡市（政令指定都市、市全体で1エントリ登録済み・code 40130）
- 制度名: 令和８年度「福岡市研究開発型スタートアップ成長支援事業補助金」
- 所管: 福岡市経済観光文化局 創業推進部
- カテゴリ: sogyo（創業支援）
- 制度種別: **現金給付（経費助成）型**。融資あっせんではなく、研究開発型スタートアップの事業推進経費をコース別に補助する市単独の補助金。既存の「福岡市新規創業促進補助金」（登録免許税相当額の定額補助）とは別制度。
