# 杉並区【新耐震基準】木造住宅の耐震化に関する助成制度

## 制度概要

- 制度名: 【新耐震基準】木造住宅の耐震化に関する助成制度
- 対象: 昭和56年6月1日〜平成12年5月31日に建てられた杉並区内の木造住宅（在来軸組構法、基礎コンクリート造、2階建て以下、住宅用途（賃貸含む）、所有者が申請）
- 所管: 杉並区 都市整備部 市街地整備課 耐震改修担当（Tel 03-3312-2111）／簡易診断・区精密診断の窓口は「木造住宅等耐震化支援事務局」（一般社団法人杉並区建築設計事務所協会内、Tel 03-5335-7427、Fax 03-5335-7428）
- **重要**: これは「新耐震基準」（1981.6〜2000.5建築、いわゆる"新耐震の中でも接合部等が甘い時期"）向けの制度であり、区には別途「【旧耐震基準】木造住宅等の耐震化に関する助成制度」（1981.5以前建築対象）が存在する。両者は助成額体系が異なる可能性が高いため、本調査では新耐震基準版のみを対象とし、旧耐震版の数値（第三者サイトに出ていた精密診断上限11万円・改修1/2＆上限150万円等）は本制度に流用しない。

## 制度類型

現物給付ではなく、費用の一部を補助する**現金給付（補助金）型**。3段階（簡易診断→精密診断→耐震改修）の構成で、各段階に応じた助成。融資あっせん要素はなし。

## 確定した金額・要件（すべて `02_pamphlet_r8_4kaitei.pdf` 原文に基づく）

### 対象建築物（PDF p.1）
- 所在地: 杉並区内（所有者は区外でも可）
- 建築年月: 昭和56年6月1日〜平成12年5月31日
- 構造: 木造在来軸組構法、基礎コンクリート造、2階建て以下、住宅用途（賃貸含む）
- 対象外: 枠組壁工法・木質工業化住宅、一部が鉄筋コンクリート造/鉄骨造、過半が住宅以外の用途、3階建て住宅

### ①新耐震簡易診断（PDF p.3, p.5〜6）
- 費用: **無料**
- 木造耐震診断士を派遣し、新耐震基準の木造住宅耐震性能検証法「所有者等による検証」でチェック
- 判定NG（専門家による検証が必要）→精密診断助成の対象。判定OK（一応倒壊しない）→精密診断以降の助成は受けられない

### ②新耐震精密診断（PDF p.3, p.7〜8）
2種類のいずれかを選択：

**ア. 区精密診断**（区が診断士を派遣、契約不要）— 費用は延べ面積で決まる固定額、区助成額は一律**13万円**、差額が申請者負担（PDF p.7 表より）

| 建築物の延べ面積 | 診断費用 | 区助成額 | 申請者負担額 |
|---|---|---|---|
| 116㎡（約35坪）未満 | 18万円 | 13万円 | 5万円 |
| 116㎡以上166㎡（約50坪）未満 | 21万円 | 13万円 | 8万円 |
| 166㎡以上200㎡（約60坪）未満 | 23万円 | 13万円 | 10万円 |
| 200㎡以上250㎡（約76坪）未満 | 25万円 | 13万円 | 12万円 |
| 250㎡以上 | ※建築物形状により算定 | 13万円 | 算定額−13万円 |

**イ. 特定精密診断**（申請者が区登録の診断士を選び直接契約）— 助成額は **13万円または精密診断に要する費用のどちらか低い額**（PDF p.8）。費用が採用された場合、1,000円未満切り捨て。契約は助成金交付決定通知後に行う必要あり（事前契約は助成対象外）。

→ **精密診断の区助成額上限は「13万円」で共通**（区精密診断・特定精密診断とも）。第三者サイトにあった「11万円」は本制度（新耐震）の数値ではない（旧耐震基準制度の数値の可能性）。

### ③新耐震耐震改修（PDF p.3, p.9）
- 精密診断の結果、Iw値1.0以上とする耐震改修を行う場合に費用の一部を助成
- **耐震改修助成額 ＝「150万円（助成限度額）」または「耐震改修に要する費用の1/2」のどちらか低い額**（費用の1/2が採用の場合、1,000円未満切り捨て）
- **加算あり**: 以下1〜4のいずれかに該当し、改修前から「一戸建ての住宅」に居住しており、Iw値1.0以上の改修後も居住を継続する場合、上記の助成額に《耐震改修に要する費用の2/5（1,000円未満切り捨て）または160万円のどちらか低い額》を加算
  1. 身体障害者手帳をお持ちの方
  2. 愛の手帳をお持ちの方
  3. 精神障害者保健福祉手帳をお持ちの方
  4. 介護保険の要介護・要支援認定を受けている方
  （住民票等による居住確認あり）
- 対象外となる建築物・所有者（PDF p.4）: 他の耐震改修助成金を受給中の建築物、建築基準法に抵触する建築物（道路突出・接道なし・避難規定未達）、公共施設や大企業所有の建築物、共同住宅等で通行・避難上の規定を満たさない建築物、住民税（法人の場合は法人住民税）を滞納している所有者

### 令和8年度 申請受付期間（01ファイル・PDF表紙より）
- 耐震改修工事: 令和8年4月1日（水）〜12月18日（金）まで
- 特定精密診断: 令和9年3月上旬の審査申請に間に合うもののみ受付
- 簡易診断・区精密診断: 通年受付
- 注意: 耐震改修・特定精密診断は年度内（令和9年3月末まで）に助成金振込完了するもののみ受付（耐震改修工事は令和9年2月末までに完了、特定精密診断は結果説明後速やかに完了実績報告が必要）

### 申請方法
- 簡易診断: （1）パンフレット裏面はがき郵送/FAX、（2）インターネット申込フォーム（logoform.jp/form/Y4gR/221881・216291）、（3）申込書印刷して郵送/FAX、のいずれか
- 精密診断・耐震改修: 簡易診断結果報告書送付時／精密診断結果説明時に案内される書類一式を提出
