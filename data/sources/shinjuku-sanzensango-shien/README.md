## ⚠️ 서브에이전트 보고와의 차이(원문 재확인으로 정정)

조사 에이전트가 두 차례 WebFetch에서 産後ドゥーラ 단가를 각각 1,500円과 1,000円으로 다르게 추출해, 스스로 "원문 재확인 필요"라고 명시해왔다. `npm run source`로 원문을 직접 취득해 확인한 결과, **196줄에서 「産後ドゥーラ：1時間あたり1,500円」・「その他の事業者（ヘルパー）：1時間あたり1,000円」**임을 확정. 에이전트의 1,000円 보고가 오류였음.

## ⚠️ 원문에서 확인되지 않은 것

- 「受付終了」류 문구는 없음 — `subsidy.status: "ongoing"`으로 처리(수시신청).
- 이 제도는 **현금급부형이 아니라 서비스이용료 보조형**으로, 기존 shussan 5개구(출산비용급부・출산축하금)와 성격이 다름을 기사 본문에 명시함.
