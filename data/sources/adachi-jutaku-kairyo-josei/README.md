# 足立区 住宅改良助成制度

## 基本情報

- 自治体: 東京都足立区（slug: adachi、団体コード 13121、prefCode 13）
- カテゴリ: jutaku（住宅改修・バリアフリー系の現金給付型助成）
- 制度名: 住宅改良助成制度
- 所管: 足立区 建築室 建築防災課 耐震化推進第一・第二係（電話 03-3880-5317 / FAX 03-3880-5615）
- 公式ページ: https://www.city.adachi.tokyo.jp/k-bousai/machi/jutaku/kairyojose.html

## 制度タイプ分類

現金給付型（工事完了後の助成金交付）。融資あっせん型・現物支給型ではない。
事前申請必須（内定通知前の工事契約・着手は助成対象外）。

## 確定した制度内容（原文根拠あり）

### 対象
- 自己が居住する住宅（戸建・共同住宅の専有部分・分譲マンション専有部分を含む）に工事を実施する方
- 賃貸住宅も対象（ただし入居者自身または同居の親族が所有していない住宅に限る、第1号様式より確認）
- 賃貸等で所有者が申請者と異なる場合、第2号様式「足立区住宅改良工事実施申請書 兼 実施承諾書」により所有者の実施承諾が必要（申請様式PDFより確認）
- マンション共用部分の工事は管理組合が申請可能
- 区民税を滞納していない方（`02_juutakukairyou-tirasi.pdf` より）
- 世帯内に65歳以上の方、または要支援認定・要介護認定を受けている方がいる場合、該当メニューの一部が利用不可（下記「年齢・要介護要件の除外」参照）

### 助成金額（`01_kairyojose-top.txt` 39〜202行目）
以下3つを比較し、最も安価な額を助成：
1. 助成上限額 30万円
2. 助成対象工事費（消費税抜）の20%（千円未満切捨て）
3. 工事種類ごとの上限額（下表）

工事種類別の単価・上限額（原文の表そのまま）:

|---|---|---|
| 段差解消（浴室除く、工事後段差5mm以下） | 3万円/箇所 | 65歳以上・要支援/要介護がいる世帯は利用不可 |
| 段差解消（浴室部分、工事後段差2cm以下、浅型浴槽併用不可） | 14万円/箇所 | 同上 |
| 手すり設置（新規のみ、交換不可） | 3千円/m | 同上 |
| 和式→洋式トイレ変更（据置型は2万円/箇所） | 8万円/箇所 | 同上 |
| 畳から滑りにくい床材への変更 | 6千円/平方メートル | 同上 |
| 浅型浴槽への変更（段差解消・浴室部分との併用不可） | 5万円/箇所 | 要支援/要介護がいる世帯は利用不可 |
| 間取り変更（世帯人員増加が条件） | 1.5万円/平方メートル | なし（全世帯対象） |

追加メニュー（令和4年6月〜、`02_juutakukairyou-tirasi.pdf` より、上限額は表面のみ確認・詳細単価は未確認箇所あり）:
- 換気設備の設置工事（家屋内、居室内の主機能が換気の機器に限る）最大10万円
- 固定式宅配ボックスの設置工事（戸建住宅のみ）
- 玄関脇手洗い器の新設工事
- 在宅勤務のための間取り変更工事（家屋内）

### 年齢・要介護要件の除外
- 世帯内に65歳以上の方がいる場合 → 該当メニュー（65歳↓マーク付き: 手すり設置・洋式トイレ変更・滑りにくい床材変更・段差解消・浴室改修等）は本制度の対象外。「高齢者住宅改修事業」を利用する必要あり。
- 世帯内に要支援認定・要介護認定を受けている方がいる場合 → 「居宅介護住宅改修（介護予防住宅改修）」を利用する必要あり。
- 屋根の軽量化は公式ページ上「全世帯を対象とするもの」に分類（年齢・要介護要件なし）。

### 助成金算定例（原文どおり）
浴室段差解消（工事費80万円）＋浴室暖房設置（工事費14万円）＋屋根軽量化60㎡（工事費150万円）の場合:
- 段差解消: 80万円×0.2=16万円 → 工事別上限14万円を適用
- 浴室暖房: 14万円×0.2=2万8千円 → 上限3万円未満のためそのまま
- 屋根軽量化: 150万円×0.2=30万円 → 上限60㎡×3千円=18万円を適用
- 合計 14万円+2万8千円+18万円=34万2千円だが、助成上限額30万円を適用 → 助成金額30万円

### 申請要件・手続き（`02_juutakukairyou-tirasi.pdf` より）
- 工事契約前に申請が必要（内定通知前の契約・着工は助成対象外）
- 施工者は原則区内業者（新築時業者やマンション管理会社指定業者など一部例外あり）
- 同一改良で本助成を過去に受けたことがないこと
- 他の給付・助成を受ける工事でないこと
- 工事が建築基準法や関係法令に適合していること
- 申請の流れ: ①申請書提出→審査→内定通知→工事契約→工事着手→工事完了→②完了届提出→確認→交付決定通知→③請求書提出→支払い
  - 申請書提出後、内定通知まで概ね1週間程度
  - 完了届提出後、交付決定通知まで概ね1週間程度
  - 請求書提出後、支払いまで概ね2〜3週間
- 必要書類（持ち家の方）: 申請書（第1号様式）、委任状（本人以外申請の場合）、工事図面（工事前後）、見積書（内訳書含む）、現況写真、返信用封筒・切手（必要に応じて）、住民票（必要に応じて）、住民税納税証明書（必要に応じて、区外から転入等の場合）
- 完了届提出時: 工事等完了届・助成交付申請書（第8号様式）、契約書の写し、工事代金支払い証明書（領収書）、工事完了後の写真、家具を廃棄したことが分かる書類（作付け家具メニューの場合）
- 請求書提出時: 助成金交付請求書兼口座振替依頼書（第10号様式）

### 接受状況・予算
- 原文に「助成額が予算に達した場合は、申請の締め切りを行います。詳しくは、担当までお問い合わせ下さい。」と明記（`01_kairyojose-top.txt` 55行目・224行目、`02_juutakukairyou-tirasi.pdf` にも同旨）。
- 通年受付だが予算消化状況は原文からは不明。**現時点（2026年9月）で受付中か予算到達で締切済みかは公式サイト上に明示がなく未確認**。記事化時は「予算に達し次第終了」と明記し、最新の受付状況は自治体に直接確認するよう案内するのが安全。

## 代替候補との比較・不採用理由

「新耐震基準の木造住宅の耐震助成制度」（https://www.city.adachi.tokyo.jp/k-bousai/machi/taishinka/sintaisin.html）も同じ所管課が実施する現金給付型助成で、`04_sintaisin-comparison.txt` として原文取得済み。助成上限額は住宅改良助成より大きい（耐震改修工事で戸建最大150万〜200万円等）が、以下の理由で本記事の主制度としては不採用とした:

1. 対象建物が「昭和56年6月1日〜平成12年5月31日着工の木造軸組工法・2階建て以下」という新耐震基準特有の築年・工法条件に限定され、対象者が住宅改良助成制度より狭い。
2. 耐震診断→耐震改修→（必要なら）除却という多段階の手続きで、単純な「いくらもらえるか」を訴求する記事の題材としては住宅改良助成制度（工事種類ごとの単価表が明確）の方が原文の数値が具体的で読者に伝えやすい。
3. 「住宅改良助成制度」は追加メニュー・マンション管理組合向けメニューを含み対象工事の幅が広く、より多くの読者（高齢者除外はあるが全世帯対象メニューもある）に当てはまる。

→ 主制度として「住宅改良助成制度」を採用。耐震診断・改修助成は将来的に別記事の題材として使う想定で原文のみ保存。
