# とくしま創業促進費補助金（徳島県）— 原文アーカイブ

## 対象自治体・制度

- 自治体: 徳島県（都道府県レベル、regions.ts新規登録不要）
- 制度名: **とくしま創業促進費補助金**
  - 注：topic-scoutの事前調査note・officialUrl（`https://www.pref.tokushima.lg.jp/entrepreneur/policy/funds/subsidy/`）では「徳島県スタートアップ創出促進補助金」という名称で記載されていたが、実際にこのURL（起業・創業ポータルサイトの補助金一覧ページ）にその名称の制度は存在しない。ただし「デジタル技術を活用した地域の課題解決につながる効果的な創業を促進」という事前調査noteの説明文は、一覧ページに掲載されている「とくしま創業促進費補助金」の紹介文（L122前後）と完全一致し、補助上限額「最大200万円」（スタートアップ枠）も一致。同一制度を指していると判断し、正式名称「とくしま創業促進費補助金」として原文調査した。
- 所管: 公益財団法人とくしま産業振興機構（徳島県からの委託運営）、問い合わせ先は徳島県 経済産業部 企業支援課 スタートアップ・経営支援担当
- カテゴリ: sogyo（創業支援）
- 制度種別: **現金給付（定率・上限額補助）型**。融資あっせんではなく、補助対象経費の1/2以内・上限額（枠に応じ200万円/100万円/50万円）を直接交付する。
