## 核心数値（01原文より）

- 制度名: 高齢者住宅改造費助成事業
- 内容: 高齢者のために行う住宅改造（手すり、すべりどめの設置等）に対し、**15万円を上限**に助成
- 補助率の記載: 原文に「1/2」等の補助率表記はなし（定額上限15万円のみ）
- 対象者: 身体が虚弱な65歳以上の人がいる**所得税非課税世帯**
  - 介護保険で要支援・要介護の認定を受けた人は、介護保険の住宅改修制度の事前相談が必要（本制度と別建て）
- 申請要件: 着工前に申請すること。予算額に達した時点で当該年度の受付終了
- 関連制度: 住宅改修支援事業（リフォームヘルパー派遣事業）を利用する場合はそちらを先に申請
- 提出書類: 住宅改造費助成金交付申請書（PDF）、見積書・カタログ、図面、工事前後の写真、家屋見取図、（借家の場合）家主の工事承諾書
- 問い合わせ: 徳島市高齢介護課 高齢者いきがい係 電話088-621-5176
