# 神戸市 重度心身障害者タクシー利用券助成 — 原文アーカイブ

## 制度概要
神戸市が実施する、重度心身障害者のタクシー乗車料金の一部を助成するタクシー利用券制度。1枚500円の利用券を年度あたり最大72枚交付。
