## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 기준소득액은 원문에서도 "목안"이라 명시하고 "목안 소득액을 초과해도 심사 희망 시 신청 가능"이라고 되어 있음 — 기사에서 "이 금액을 넘으면 무조건 불가"로 단정하지 말 것.
- `02_ninteikijun-faq.txt`(FAQ 페이지)는 갱신일이 2024年4月8日로 되어 있고 "令和6年度 就学援助のお知らせ"를 참조하도록 안내되어 있다 — **이 FAQ 자체는 구정보일 수 있음**. 실제 令和8年度 기준소득액은 반드시 `03_r8-oshirase.pdf`(令和8年度판, 2026년 발행분)의 수치를 우선 사용할 것.
- 신입학학용품비의 "입학전지급"은 令和7年度분 접수가 이미 종료(令和8年3月31日)되었고 令和8年度분은 "令和8年12月以降に掲載"라고만 되어 있어 구체적 시기・금액은 이번 취득 원문에 없음 — 기사에서 다루려면 12月 이후 재확인 필요.
