# takasaki-fukushi-taxi

対象候補記事（topic-scout調査段階）: 群馬県高崎市「福祉タクシー利用券等の交付」（障害福祉課所管、在宅障害者向け）

## 制度の性質に関する重要な注記

高崎市は合併市（旧高崎市・旧倉渕村・旧新町・旧榛名町・旧吉井町・旧箕郷町・旧群馬町）であり、本制度は**旧高崎地域・倉渕地域・新町地域・榛名地域・吉井地域のみが対象**。箕郷地域（旧箕郷町）・群馬地域（旧群馬町）は交付対象者の範囲や助成内容が異なり、各支所への個別確認が必要（本ページには箕郷・群馬地域の詳細は掲載されていない＝unresearched）。記事化する場合は、この地域差を必ず明記する必要がある。
