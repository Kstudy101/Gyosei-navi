## 核心数値（原文対照）

出典は特記なき限り `01`。流産・死産の電子申請案内は `03`。

| 項目 | 原文の記載 |
|---|---|
| 対象者 | 妊娠している方。医療機関により**胎児心拍**が確認できたことをもって妊婦給付認定にかかる「妊娠」と定義。心拍確認後に住民票のある市区町村へ申請可 |
| 1回目 | **妊娠時・5万円の現金給付**。妊娠届出・妊婦給付認定の申請をした妊婦 |
| 2回目 | **原則出産後・妊娠していた子ども1人あたり5万円の現金給付**。出産し胎児の数を届け出て、**新生児訪問（赤ちゃんの家庭訪問）**を受けた産婦 |
| 申請方法 | 妊娠届出の面談及び新生児訪問の際に案内。**申請は電子申請** |
| 支給方法 | **妊産婦名義の銀行口座**へ振込。妊産婦以外の口座名義は指定不可 |
| 申請期限（1回目） | 妊娠が確定（医師による胎児心拍の確認）した日の**2年後の前日まで（必着）** |
| 申請期限（2回目） | **出産予定日の8週間前の日**から2年後の前日まで（必着） |
| 期間条件 | いずれも**令和7年4月1日以降に妊娠期間があった場合に限る** |
| 流産・死産等 | 流産・死産（・人工妊娠中絶）等も支給対象。産後間もなく子を亡くした方も申請可。ながの電子申請サービスから案内申込→メールで請求方法案内 |
| 電子申請（流産等）追加条件（`03`） | 令和7年4月1日以降に妊娠期間があった／**申請時点で長野市に住民票登録がある**。転出予定者は転出先自治体へ相談。受付開始 2025年4月18日0時〜（終了日の明示なし） |
