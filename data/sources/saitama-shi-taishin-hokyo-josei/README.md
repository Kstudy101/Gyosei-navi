### 제도 전체 구조

## 기사화 가능 여부

**원문 확보 성공.** 3건(耐震診断／耐震補強設計・工事／建替え工事) 모두 令和8年度 최신판을 `npm run source`로 아카이브 완료했으며, 전액・한도액・보조율・신청방법・예산소진시 조기마감 등 기사 작성에 필요한 핵심 수치를 모두 원문에서 확인했다. 3단계 제도구조가 명확하므로 비교표(진단／보강설계／보강공사／종합적보강공사／건체공사)를 그대로 기사에 활용 가능하다.
