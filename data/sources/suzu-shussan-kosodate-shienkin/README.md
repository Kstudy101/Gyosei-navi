## 確認された事実（記事に使える）

- 出産支援金（前期分）:
  - 対象: 珠洲市住民基本台帳に記録されている妊娠21週以内の妊婦
  - 給付額: 妊婦1人につき5万円
  - 申請先: こども家庭センター（必要書類: 出産支援金申請書、通帳等）
- 出産支援金（後期分）:
  - 対象: 珠洲市住民基本台帳に記録されている妊娠22週以降の妊婦
  - 給付額: 妊婦1人につき5万円
  - 申請先: こども家庭センター
- 子育て支援金:
  - 対象: 出生の届出をした方で珠洲市住民基本台帳に記録されている出生児の父または母
  - 給付額: 単胎5万円、多胎2人目から1人につき10万円
  - 申請先: こども家庭センター（必要書類: 子育て支援金申請書、母子健康手帳の出生届出済証明の写し、通帳等）
- 合計受取可能額の例: 単胎の場合、妊娠前期5万円＋後期5万円＋出産5万円＝最大15万円
- 所管: 珠洲市役所福祉課こども家庭センター（市役所1階(5)番窓口、TEL: 0768-82-7799）
