## 制度類型

**現物支給型（年額限度＋1割自己負担）** — 事業者が紙おむつ等を自宅配達。久留米市の定額給付券型（月3,000円）や北九州市の要介護度別限度＋原則1割負担型と比較可能な設計。仙台市は**要介護4・5限定**かつ**年7万5千円限度**。
