## ⚠️ 令和6年6月改正の3点（画像 `02_kaisei-3ten-image.png` を目視確認して確定）

topic-scoutがテキスト抽出できず「要確認」としていた「◆次の3点が変わりました」の具体内容は、ページ内の比較表画像を
直接取得・閲覧して次のとおり確定した（画像内の見出し「これまでの制度」「新しくなった制度」の対比表）。

| 項目 | これまでの制度（〜令和6年5月） | 新しくなった制度（令和6年6月〜） |
|---|---|---|
| ①申請の種類 | 補助金の交付申請 | **手術券の交付申請** |
| ②申請頭数 | 1回の申請で最大5頭まで申請可。年度内で最大5頭まで申請可 | **1回の申請で最大10頭まで申請可。年度内に最大10頭まで申請可** |
| ③費用負担 | 手術にかかった費用を、1頭あたり12,000円を上限に補助金を交付（事後精算・上限あり） | **手術にかかる費用（堕胎、ノミダニ駆除、抗生物質）の負担はなし（＝事前交付の手術券方式で自己負担ゼロ）** |

実施要綱（`04_jisshi-youkou.pdf`）附則でも「この告示は、令和6年6月1日から施行する」「奈良市飼い主のいない猫不妊去勢手術等
補助金交付要綱（令和2年奈良市告示第304号）は、廃止する」と明記されており、旧制度＝事後精算の補助金型（上限12,000円/頭）、
新制度＝事前交付の手術券型（自己負担ゼロ）への転換が原文で裏付けられた。記事化の際は「補助金」ではなく「手術券（無料）」
方式であることを明確に書き分けること。
