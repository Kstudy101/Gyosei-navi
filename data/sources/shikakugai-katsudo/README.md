## 주요 사실 (기사 검수용 메모)

- 근거: 入管法 19条2項 (許可)·3項 (取消) / 施行規則 19条5項1号: 「一週について二十八時間以内（留学…長期休業期間にあるときは、一日について八時間以内）」— 留学生은 「教育機関に在籍している間に行うものに限る」
- 手数料 없음 / 標準処理期間 2週間〜2か月 (16-8.html) / 온라인 신청은 変更·更新·取得 신청과 동시인 경우만
- 包括許可 대상 예: 留学·家族滞在·扶養 特定活動·継続就職活動 特定活動·地方公共団体 고용 教育/技人国/技能(스포츠)
- 個別許可: 인턴십 (대학 최종학년·9割 단위), 業務委託·請負로 노동시간 불명확, 個人事業主, 起業準備 등. 家族滞在 個別許可는 「在留期間の過半を超えない」 요건
- 風俗営業·性風俗·特定遊興飲食店 영업소 근무 불가 (접객 여부 불문)
- 罰則: 73条 (1年以下拘禁刑/200万円) · 70条1項4号 専ら (3年以下/300万円) · 24条4号イ 専ら → 退去強制 · 73条の2 不法就労助長 (고용주 3年以下/300万円, 과실 없는 경우 외 「知らなかった」 항변 불가)
- ★ 「どの曜日から起算しても28時間以内」 (복수 근무처 합산) 는 입관 실무 운용으로 널리 안내되나 **本次 취득 자료에서 원문 문언 미확인** — 기사에서는 단정 인용 없이 「実務上の取扱い」로 기술. 사람 검수 시 入管庁 Q&A 또는 地方局 안내 확인 요망
