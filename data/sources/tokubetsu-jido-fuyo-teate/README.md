## 原文アーカイブに関する注記（技術的補足）

`02_mhlw_huyou.txt` の取得元ページは HTML の meta タグで `charset=shift_jis` と宣言されたレガシーページで、`npm run source`（`scripts/fetch-source.ts`）が従来 UTF-8 固定でデコードしていたため文字化けが発生した。今回、`fetch-source.ts` に Content-Type ヘッダ／meta charset を判定してデコードする処理（`detectCharset()`）を追加し、原文どおりのテキストを取得できることを確認した上でアーカイブした（AGENTS.md 絶対規則7「原文アーカイブは加工しない」を満たすための修正）。

## 記事本文に反映した数値

- 支給月額: 1級58,450円／2級38,930円（令和8年4月より適用） — `02_mhlw_huyou.txt` 73〜77行目
- 支給要件: 20歳未満・精神または身体に障がいを有する児童を家庭で監護・養育する父母等 — 同69〜71行目
- 支払時期: 毎年4月・8月・12月（前月分までまとめて支給） — 同79〜81行目
- 所得制限: 受給資格者本人・配偶者・扶養義務者の前年所得が一定額以上で支給停止 — 同83〜85行目
- 申請先: 住所地の市区町村窓口 — 同167〜169行目

## 確認されていないこと

- 所得制限の具体的な限度額（扶養親族等の人数別の円単位の表）は、原文の表がテキスト抽出時に列構造が崩れて確実な対応関係を再現できなかったため、記事本文には具体額を掲載していない（`Callout`で「市区町村窓口で確認」を案内する形にとどめた）。表の正確な読み取りが必要な場合はPDF「特別児童扶養手当に関するお知らせ」を別途取得すること。
- 障害児福祉手当（hukushi.html）・経過的福祉手当（keizai.html）は今回未調査。将来的に別記事化する場合は個別に原文を取得すること。
