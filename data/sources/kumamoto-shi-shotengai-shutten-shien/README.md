## 제도 유형 분류

## 확인되지 않은 것

- R8 採択件数・残予算・次年度（R9）の再募集有無は入口・要領に記載なし。
- 補助上限50万円が「3メニュー合算」ではなく「各メニューごと」であることは入口HTMLの列挙で確認。要領本文は「補助限度額：50万円」と単記のため、複数メニュー同時申請の可否は要確認（入口はメニュー別に上限を列挙）。
- 商店街「地区」の全リストは入口に主要団体リンクのみ。対象可否は店舗住所を商業金融課へ照会する旨が原文に明記。
