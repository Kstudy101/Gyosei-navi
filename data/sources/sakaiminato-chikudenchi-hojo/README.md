# 境港市 定置用蓄電池設置補助金（令和8年度）

## 原文情報

## 制度概要
- 制度名: 境港市定置用蓄電池普及促進事業費補助金（令和8年度）
- 所管: 市民生活部 環境・ごみ対策課 脱炭素推進室
- 目的: 地球温暖化対策・脱炭素社会推進

## 核心数値（01_main.txt 57行目より）
| 項目 | 内容 |
|------|------|
| 補助額 | 1kWhあたり7万円（上限40万円） |
| 受付件数 | 40件（令和8年度当初分） |
| 受付開始 | 令和8年4月1日 |
| 申請窓口 | 環境・ごみ対策課脱炭素推進室（境港市清掃センター内） |

## 補助対象者
- 市内に自らが所有し居住する住宅（店舗・事務所併用含む）、または自らが事業用として利用する市内建物に定置用蓄電池を設置する方

## 主要条件（全て満たす必要あり）
1. 着工前であること
2. 未使用品（中古品不可）
3. 蓄電容量1kWh以上のシステムで国際規格（JIS・IEC等）適合
4. 10kW未満の太陽光発電設備と連係すること
5. 受注者・施工業者が共に県内事業者（本店または支店等が県内）
6. 市税の滞納がないこと

## 補助金額の計算方法（原文59行目）
「補助金の交付対象額から、国や他の団体からの補助金などを控除した額に3分の1を乗じて得た額」と「1kWhあたり7万円×容量」のいずれか低い方が上限。1,000円未満端数切捨て。

## 制度分類
- 種別: 現金給付型（補助金直接交付）
- 対象設備: 定置用蓄電池（太陽光連係型）
- 対象者: 個人・事業者（市内所有建物への設置）
