## ⚠️ 원문에서 확인되지 않은 것

1. **「区長が定める日時」の具体的な申請受付スケジュール**（実施要綱第10条2項）— 毎月特定の曜日・時間帯に窓口受付を行うのか、随時受付だが決定通知の発送日が決まっているだけなのか、原文からは断定できない。募集期限や予算到達による受付停止の有無（現時点で受付中か終了かの明示）も、取得したページには記載がなく**現時点の受付状況は不明**。要問い合わせ。
2. 申請時に住所確認書類の**提示が必須**と明記した文言は見当たらない（区記入欄に記載欄があるのみ）。運用上は求められると推測されるが、原文に「提示してください」という直接的な指示文はないため、断定を避けた。
3. 강습회 시청 후 실제로 어떤 형태로 "수강 완료" 확인이 이루어지는지(수강증 발급 여부 등)는 원문에 명시 없음。
4. 「地域協議会エリア（PDF：365KB）」は今回中身を読んでいない（一般申請の助成条件そのものには直接関係しないため）— 必要であれば別途取得可能。
5. 助成金の**支払総額の予算上限（円ベースの総枠）**は今回取得した原文には具体的な金額の記載がない（「予算の範囲内」「予算額に達したとき」という表現のみ）。
6. 마취만 실시하고 수술을 하지 않은 경우(上限3,000円)의 조성이 개인신청자에게도 적용되는지, 지역협의회 전용인지 — 실시요강 제9조1항의 문구 구조상 지역협의회(제7条1項2号)에만 적용되는 것으로 읽히나, 완전히 명확하지는 않음(개인 신청 페이지에는 마취관련 조성 언급이 전혀 없음 — 개인 신청에는 해당 없음으로 보이나 100% 단정은 보류).

## 千代田区와의 금액 차이 — 원문상 사실 확인

**千代田区와 豊島区의 조성액 차이는 원문상 실제 사실이며, 오독이 아니다.**

| 구분 | 千代田区（`pet-chiyoda-neko-funinkyosei`README 근거） | 豊島区（個人＝一般申請、본 조사） |
|---|---|---|
| 去勢（オス） | 17,000円 | **2,000円** |
| 不妊（メス、非妊娠） | 20,000円 | **4,000円** |
| 不妊（メス、妊娠中） | 25,000円（豊島区は妊娠有無による金額差なし） | 4,000円（妊娠有無を問わず同額） |

豊島区は実施要綱第9条で個人申請の金額を明文で「不妊手術4千円、去勢手術2千円」と定めており（メインページの表記と完全一致）、桁を読み違えた可能性はない。地域協議会向けの上限額（不妊20,000円／去勢10,000円）と比較しても、なお千代田区の個人向け金額（17,000円／20,000円〜25,000円）の方が高い。両区で助成対象事業のスキーム（個人申請 vs 協議会）が異なる可能性もあるため、記事中で比較する際は「豊島区は個人（一般申請）向け金額、千代田区も個人向け金額」という前提を明記した方が正確。
