## 核心数値（原文対照）

出典は特記なき限り `01_main.txt`。

| 項目 | 原文の記載 |
|---|---|
| 枠組み | 子ども・子育て支援法の「妊婦のための支援給付」と、児童福祉法の「妊婦等包括相談支援事業（伴走型相談支援）」を一体実施 |
| 事業開始 | **令和7年4月1日** |
| 市の支給タイミング | **妊娠時**と**出産予定日の8週間前以降**の2回 |
| 1回目 給付額 | **現金5万円**（申請後、給付まで2か月程度） |
| 1回目 対象 | 申請日時点で岐阜市に住民票がある方のうち、(1)令和7年4月1日以降に妊娠届出・妊婦給付認定申請をし認定を受けた妊婦、(2)令和7年3月31日までに妊娠届出をし出産応援ギフト未申請の産婦（令和7年4月1日時点で妊娠継続が必要） |
| 1回目 申請方法 | 妊娠届提出時の面談後に「お知らせ」を手交 → 二次元コードから**オンライン申請** |
| 1回目 申請期限 | 胎児心拍確認日を起算日として**2年を経過する日まで** |
| 2回目 給付額 | **胎児1人につき現金5万円**（申請後、給付まで2か月程度） |
| 2回目 対象 | 令和7年4月1日以降に出産し、申請時点（胎児の数の届出時点）で岐阜市に住民票がある妊産婦 |
| 2回目 申請方法 | 出産予定日の8週間前以降に「お知らせ」を**郵送** → 二次元コードからオンライン届出 |
| 2回目 申請期限 | 出産予定日の8週間前を起算日として2年（予定日より前に出産した場合は出産日が起算日） |
| 二重支給禁止 | 同一妊娠について他市区町村で1回目/出産応援ギフト、または2回目を受けた場合は岐阜市では給付不可 |
| 流産・死産等 | 令和7年4月1日以降の流産・死産・人工妊娠中絶等は対象。ただし令和7年4月1日時点で胎児心拍未確認は対象外。妊娠届出前でも心拍確認があれば診断書で申請可 |
| 旧制度 | 岐阜市出産・子育て応援ギフト（国の出産・子育て応援給付金）は**終了**（`02`/`03`） |
