## 확인되지 않은 것 / 주의

- ページにリンクされた交付要綱PDF（`04_kofu-yoko.pdf`）は平成28年4月1日施行ベースで、第6条に補助率23/100・上限50万円と記載されている。これは令和8年度の公式ページ・リーフレット（4/5・上限115万円）と不一致。**記事の数値はページ（2026-05-01更新）と令和8年度リーフレットに従う。** 要綱の最新改正文の有無は当該PDFからは確認できず。
- 予算到達による早期終了の明記はページ・リーフレットになし。募集件数「4件程度（先着順）」のため早期終了の可能性はあるが原文に「予算到達」文言はない → `subsidy.status: open`（periodEnd=2026-10-30）。
- 無料耐震診断の令和8年度募集期間（5/18～5/29）は本稿確認時点で終了済み。改修補助の前提診断として無料診断制度の存在は言及するが、診断募集そのものを募集中とは書かない。
