## 確認された事実（記事に使える）

- 対象: 東京23区在住（1年以上連続、かつ10年間で5年以上）→石川県への移住＋起業
- 令和6年4月1日以降に石川県に移住または移住予定の方
- 起業時期: 令和8年4月1日〜令和8年12月31日（個人事業開業届または法人設立）
- 補助対象経費: 人件費、店舗等借料、設備費、原材料費、謝金、旅費、広報費、外注費、委託費等
- 補助額: 最大200万円（補助率2分の1以内）
- 移住支援金との合計: 最大300万円
- 令和8年度の募集: 2026年4月1日〜2026年6月15日17時必着（終了済み）
- 申請先: 公益財団法人石川県産業創出支援機構（ISICO）コンサルティング事業部経営支援課（TEL: 076-267-1244）
- 所管: 商工労働部経営支援課（TEL: 076-225-1525）
