| 대상학교 | 国公立小・中学校（義務教育学校前期・後期、中等教育学校前期を含む）。私立・インターナショナルスクール・特別支援学校は対象外 | 01 |

| 要件4 | 児童扶養手当の支給 | 01 |
| 要件5 | 災害等（申請日から遡って半年以内） | 01 |

| 所得限度 6人 | 530万円 | 01 表 |

| 世帯・所得定義 | 昨年12月31日時点で生計同一。源泉「給与所得控除後の金額」または確定申告「12所得金額合計」 | 01・04 Q4 |
| 目安超過 | 限度額は目安。迷う場合は申請可 | 04 Q5 |
| 通常申請期限 | 令和8年5月29日（金） | 01 |

| 最終受付 | 令和9年2月26日（金）。申請月分から・支給金額減 | 01 |

| 審査結果 | 申請月の翌月下旬ごろ郵送 | 01 |
