- **根拠要綱**: 大田区要介護等高齢者紙おむつ等支給事業実施要綱（昭和58年8月2日 厚老発第977号、現行版は令和7年4月1日施行、令和12年3月31日まで効力）

## 確認できた最終数値・条件

### 対象者（01・03で一致確認）
区内に住民登録・現に居住し、失禁のため紙おむつを必要とする方のうち、いずれかに該当:
1. 要介護3〜5の認定を受けた方
2. 要介護1・2の認定を受け、傷病により医師が紙おむつを必要と認めた方（「紙おむつ使用証明書」を医師に記入してもらい提出。文書料は申請者負担）
3. 65歳以上で病院に入院しており、(1)(2)に相当する状態で紙おむつが必要な方

**除外**: 特別養護老人ホーム・老人保健施設・介護療養型医療施設・介護医療院に入所中の方／生活保護受給中の方／中国残留邦人等支援給付受給中の方（01・03要綱第2条ただし書きの両方で確認）。

要綱第2条には「区長が特に必要と認めた場合は対象者とすることができる」旨の裁量規定あり（03）。

### 紙おむつ支給（現物支給）
- **カタログの中から毎月500点の範囲内で自由に選択・組み合わせ可能。超過分は自己負担**（01本文に明記、2026-09-20取得時点で現行値と確認）。
- 要綱本文（03）第3条には「区が指定する支給限度範囲内」としか書かれておらず、**500点という具体的数値は要綱本文には記載がない**（内部基準・別途告示で運用されていると推定）。
- 毎月10日までの申請は当月から、11日以降の申請は翌月から支給開始（01・03の両方で確認、要綱では届出関連条文にも同趣旨の規定あり）。
- 委託業者（大田商業協同組合、電話03-3732-8500）が自宅等へ配送（01・02で確認）。
- 令和8年度（2026年4月分納品分）から個別商品の点数・一部商品名・パッケージが改定され、自己負担が新たに発生/増額する場合がある旨の告知あり（01・02で確認）。**ただし月間の上限点数500点自体が変更されるとの記載はなく、変更は個別商品ごとの点数配分のみ**（02のPDF内容から確認、例: 品番1101が197点→200点等）。

### おむつ代助成（入院者特例・現金給付）
- **区が支給する紙おむつを使用できない病院に入院している方に限り、月5,000円を限度に助成**。本人名義口座へ振込。（01本文・03要綱第3条2項の両方で「5,000円」を確認 — 一致）
- 申請時に本人名義口座がわかるもの（通帳等）と印鑑（朱肉使用）が必要（01）。
- 請求は年3回、各期の20日まで（01「3月・7月・11月」／03別表「請求期限: 3月20日・7月20日・11月20日」で一致、支給月はそれぞれ4月・8月・12月）。
- 申請月より前に遡って助成不可（01・03）。
- 同一月内での紙おむつ・おむつ代の併給は不可（03第3条4項のみに明記、01本文には記載なし）。

### 申請窓口
- 65歳以上: 居住地域を担当する地域包括支援センター
- 40歳〜64歳: 各地域福祉課高齢者地域支援担当（大森・調布・蒲田・糀谷羽田の4拠点、電話番号は01に記載）
