## 原文で確定した事実（記事根拠）

### A. FCV普及促進補助金 — 01（運用案内・最新）

| 項目 | 原文根拠 | 内容 |
|---|---|---|
| 制度名 | 01 表題 | 燃料電池自動車（FCV）普及促進補助金 |
| 2026年度対象 | 01 お知らせ／FAQ | **FCVのみ**。EV・PHV・HV・クリーンディーゼル・ミニカー・電気バイクは対象外 |
| 補助対象者 | 01「補助対象者」 | ①神戸市内に事務所・事業所を有する法人または個人事業主 ②**神戸市内に居住する個人**。いずれも経済産業省CEV補助金の交付決定が前提 |
| 個人事業主の申告要件 | 01 ※1-2 | 事業所得・不動産所得・山林所得について2025年または2026年分の確定申告。2026年1月1日以降開業は開業届出が初度登録以前であること |
| 車両要件① | 01 | 2025年12月1日〜2027年2月20日までにCEV補助金の交付額確定通知を受けること |
| 車両要件② | 01 | 初度登録時から神戸市内に使用の本拠の位置を置くこと（個人は自宅等） |
| 車両要件③ | 01 | 兵庫県ゼロエミッション車導入補助事業の補助対象車両であること。**ただし個人が導入するFCVは除く** |
| 補助額 | 01 表／要綱別表 | 国補助金交付額×1/3 と 上限額の低い方。上限 **29万円** |
| 申請方法 | 01 | 原則 e-KOBE。不可時は郵送（三宮プラザEAST3階・環境局脱炭素推進課） |
| 申請期限 | 01／FAQ | **2027年2月26日（金曜）必着**。予算がなくなり次第終了 |
| 台数上限 | 01 | 同年度原則10台まで。**個人の購入は1台まで** |
| 財産処分制限 | 01 | 交付決定日から**4年**。市外への本拠移動も処分に含む |
| 問い合わせ | 01 | 環境局脱炭素推進課（温暖化対策担当）。詳細はページのメール案内 |

### B. 個人向け索引 — 02

- 個人向けポータルから本制度（FCV）および国のCEV・高効率給湯器等が案内されている。
- 市独自の住宅用太陽光・エネファーム・蓄電池の新規設置補助金は掲載なし（終了済みは03へ）。

### C. 終了済み住宅設備補助金 — 03

| 終了制度 | 実施年度（原文） | 今後 |
|---|---|---|
| 住宅用太陽光発電システム設置補助金 | 2014〜2017 | 今後の実施予定なし |
| 家庭用燃料電池システム（エネファーム） | 2014〜2021 | 同上 |
| 家庭用蓄電池 | 2018〜2020 | 同上 |

### D. 要綱PDF — 04

- 要綱別表（乗用）: FCVは「国の補助金の額に1/3を乗じて得た額」・上限「29万円」で01と一致。
- 別表にはEV（上限10万円）・PHV（上限5万円）の行も残るが、**01の2026年度運用案内・FAQはFCVのみ対象と明記**。記事の対象車種は01に従う。

## 制度タイプ分類

- **国CEV上乗せ型・現金補助**（個人居住者も対象）
- 2026年度はFCV特化（EVは対象外）
- 住宅設備（太陽光等）の市単独設置補助は現行なし（共同購入支援のみ、補助金ではない）

## 受付状態

- **受付中（open）**。申請期限 2027-02-26 必着。予算到達で終了の旨あり。01最終更新 2026年8月4日。
