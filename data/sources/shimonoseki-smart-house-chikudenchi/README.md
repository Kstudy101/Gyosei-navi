## 확인되지 않은 것 / 주의

- 페이지의「指定機器」외부 링크 URL 자체는 원문 텍스트 아카이브에 절대 URL이 남지 않음（「下記のリンク先」「外部リンク」표기만）. 기사에서는 지정기기 확인이 필요하다고만 쓰고, 링크는 市公式ページ経由で案内。
- 보조대상경비의 세부 범위（기기本体・공사비 등 포함 여부）는 手引き「4.補助対象経費」절에 위임. 기사 금액 산식은 페이지・チラシ에 明記된 상한・1/5・kWh단가만 사용。
- 本稿確認時点（2026-09-22）は後期申請期間中。9月30日必着のため、期日経過後は status 再確認が必要。
- 脱炭素先行モデル地区（住宅）補助金（あるかぽーと・唐戸エリア限定）は別制度。本記事では扱わない。
- 山口県「ぶちエコやまぐち」共同購入は県事業のため本記事対象外。
