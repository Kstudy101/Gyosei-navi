## 制度類型

**耐震改修費補助型（定率＋上限）＋低料金診断支援型＋付帯工事上乗せ型** — 久留米市・北九州市・横浜市等の木造耐震改修助成と同類型。仙台市は建築時期が**平成12年5月31日以前**まで拡充され、改修補助の限度が**115万円**（対象工事費144万円の5分の4）と他市の定額上限（例: 久留米50万円）より高い点が差別化になる。
