## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 「利用者負担」의 소득구분별 정확한 월액 산정 세부기준(다단계 소득구간, 46만엔 산정방식의 상세 계산식)은 원문 04(참고자료 슬라이드)에 개요만 있고, 상세는 별도 고시(厚生労働省告示第528号「補装具の種目、購入等に要する費用の額の算定等に関する基準」)를 봐야 한다 — 이 고시 원문은 이번 조사에서 취득하지 않았다. 기사에서 세부 산정식을 단정하지 말 것.
- 개별 보장구 품목별 기준액(상한액)은 이번 조사에서 취득하지 않음 — 고시 528号 별표 참조 필요.
- 신청 창구(시구정촌)별 세부 양식・절차는 지자체마다 다를 수 있음 — 기사에서는 「거주 시구정촌에 확인」으로 안내.
