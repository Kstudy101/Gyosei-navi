## 확인되지 않은 것 (unresearched)

- **東淀川区 独自의 상승(上乗せ) 제도 유무**: `01_taiyoko-hojokin.txt` 원문 자체에는 東淀川区에 대한 언급이 전혀 없다(大阪市環境局이 24区 공통으로 소관). 이번 조사에서 WebSearch로 「東淀川区 太陽光発電 補助金 独自 上乗せ」및 「site:city.osaka.lg.jp 東淀川区 太陽光 補助」를 확인했으나 東淀川区 고유의 태양광 상승제도를 시사하는 결과는 없었고, 大阪市環境局의 보조금 카테고리 페이지(https://www.city.osaka.lg.jp/kankyo/category/3016-3-3-0-0-0-0-0-0-0.html)가 공통 창구로 확인됐다. 다만 이는 WebSearch(요약) 기반 정황 확인일 뿐, 東淀川区役所 공식 페이지를 npm run source로 직접 재취득해 "상승제도 없음"을 원문으로 확정하지는 못했다. 따라서 **"0건"으로 단정하지 않고 unresearched로 유지**하며, 다른 大阪市 24区 기사(淀川区 EV충전보조금 등)와 동일하게 "区独自の上乗せ制度は確認されていません"이라는 표현을 쓸 수 있다.
- 예산총액(태양광 상승보조금 전체 예산 규모): 01번 원문에 기재 없음.
- 併用제한(다른 보조금・税額控除 등과의 중복 수급 가부): 01번 원문에 명시적 기재 없음.
- 交付要綱・公募要領 등 PDF 첨부자료의 상세 내용(様式1〜17 등): 링크만 확인, PDF 미다운로드.
- 02/03번(EV충전설비) 원문은 이번 조사의 핵심 대상이 아니므로 재검증하지 않았다(기존 淀川区 기사에서 이미 검증된 상태로 판단).
