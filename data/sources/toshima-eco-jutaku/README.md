- 対象自治体: 東京都豊島区（slug: toshima, 総務省コード: 13116 — `src/config/regions.ts` 登録済み）
- カテゴリ: energy（太陽光・省エネ）
- 制度分類: **事後申請型の設備設置費助成（うちわ型）** ※太陽光・蓄電・エネファーム・HEMS・断熱改修窓・雨水貯水槽を同一事業で扱う。個人住宅向け。現金直接補助。

## 確認された核心数値（原文根拠つき）

### 補助額（令和8年度・個人住宅）
出典: `01_kojin.txt`、`05_pamphlet.txt`、`04_kofuyoko.txt`（三者一致）

| 設備 | 助成金額 |
|---|---|
| 住宅用太陽光発電システム | 出力1kWあたり2万円（上限8万円） |
| 蓄電システム | 蓄電容量1kWhあたり1万円（上限5万円）。太陽光またはエネファームと常時接続必須 |
| 雨水貯水槽 | 機器設置費用3万〜5万円未満:1万円／5万円以上:2万円 |
| エネファーム | 一律8万円 |
| HEMS | 機器本体価格（税抜）の3分の1（上限2万円） |
| 断熱改修窓 | 機器設置費用の4分の1（上限10万円）。新築・増築に伴う新設は対象外 |

### 受付・施工期間
出典: `01` / `05`
- 申請受付: **令和8年5月25日〜令和9年3月1日（必着）**。予算超過で早期終了。先着順（提出日基準）
- 施工完了対象: **令和8年2月1日〜令和9年1月31日**
- 交付予定額状況: **予算に対して42%（令和8年9月9日時点）** — 受付継続中
- 事後申請（施工・支払完了後）。交付申請から交付決定まで2〜3か月程度

### 併用・注意
- 国・都が併用を禁止していなければ併用可（区予算のみで運営）— `01` 備考2
- 区との連携を騙る訪問販売への注意喚起あり — `02`
- 問合せ: 環境政策課事業グループ 03-3981-2771／〒171-8422 豊島区南池袋2-45-1
