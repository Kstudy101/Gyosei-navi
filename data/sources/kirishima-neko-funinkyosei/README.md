## 補助対象外となる猫

以下の猫は補助対象外（01_neko-hojo.txt 81行）：
- 新たな飼い主（里親）に譲渡する予定の猫
- 飼い猫となる予定の猫
- 補助金の交付申請前に既に手術を受けている猫
- その他市長が適当でないと認めた猫

## 制度の分類

- **制度タイプ**: 現金補助（費用の一部助成）
- **対象**: 団体のみ（個人不可）
- **目的**: 地域猫活動における飼い主のいない猫の不妊去勢手術推進

## 接受状況

- **令和8年度**: 受付中（2026年4月1日〜2027年2月末）
