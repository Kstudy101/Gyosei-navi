## ⚠️ 원문에서 확인되지 않은 것（unresearched / 要確認）

- **소득기준 주의사항**: 범위가 넓은 것은 세대 구성원의 연령에 따라 차이가 발생하기 때문. 같은 세대인원이라도 연령구성에 따라 기준이 달라짐 — 원문(01_shugaku-enjo.txt L609)에 명시. 실제 판정은 개별 심사.
- **체육실기용구비(품목5)**: 「支給要件があります」라고만 기재. 구체적인 지급 요건 상세는 공식페이지 본문에 미기재 → 창구 확인 필요.
- **통학비(품목6)**: 「支給要件があります」라고만 기재 → 구체 요건 미확인.
- **의료비(품목12)**: 「支給要件があります」라고만 기재 → 구체 요건 미확인.
- **의무교육학교 표준복비(품목7)**: 의무교육학교 1학년 및 전기과정 전입생만 해당. 小学校・中学校は対象外.
