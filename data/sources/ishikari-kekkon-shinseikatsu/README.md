## topic-scout 要約との相違点

- **予算額**: topic-scout要約は「780万円」だったが、原文では **「768万円」** が正しい。要約の誤りを訂正。
- **対象期間の終期**: topic-scout要約の「令和9年2月26日」は原文と一致（婚姻届提出期限）。ただしWebSearchで見つかった同一URLの検索エンジンキャッシュには「(令和7年度)」というタイトルのスナップショットが残っていたが、`npm run source`で取得した現在の原文は明確に「(令和8年度)」であり、内容も令和8年度版に更新済みであることを確認済み。
- **金額区分の詳細**: topic-scout要約は「29歳以下の世帯は最大60万円、30歳以上で住宅取得の場合も最大60万円、それ以外は最大30万円」としており、これは原文と完全一致（相違なし）。
- **所得要件**: 「夫婦合算 令和7年分所得500万円未満」は原文と一致（相違なし）。
- **指定講座要件**: topic-scout要約通り、指定講座等の受講（または受講予定）が対象世帯の必須要件（4番目の要件）であることを原文で確認。講座の種類（ライフデザイン支援講座、プレコンセプションケアに関する講座、共家事・共育て講座、医療機関への妊娠・出産に関する相談）も原文に明記。
