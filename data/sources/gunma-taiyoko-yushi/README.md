# gunma-taiyoko-yushi

対象候補記事（government-researcher調査段階）: 群馬県「住宅用太陽光発電設備等導入資金」（環境にやさしい生活を応援します）

## 結論: 記事化スキップ対象（融資制度であり給付型補助金ではない）

原文で明確に「県と金融機関の連携により、住宅用太陽光発電設備等を導入する個人を対象とした**低利の融資制度**です。」と記載されている。返済不要の給付ではなく、金融機関からの借入（融資）であり、利用者は元利均等で償還する必要がある。

gyosei-navi は給付型の補助金・助成金を扱うメディアであり、この制度単体は**記事化対象から除外**する。

ただし、追加調査の結果、群馬県には別途**給付型（直接交付）の太陽光発電・蓄電池導入補助金**が存在することを確認した（`data/sources/gunma-saiene-hojokin/` に別途アーカイブ）。記事化する場合はそちらを主題とすべきである。
