## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **令和7年度(2025年度)판의 상세 조건**: こども家庭庁 활용상황 PDF에는 立川市가 令和7年度에도 이 사업을 실시(총사업비1,350만엔・보조율1/2)했다고 나오지만, 이번에 취득한 立川市 공식 페이지는 이미 **令和8年度판으로 갱신**돼 있어 令和7年度 당시의 정확한 신청기간・보조상한액이 동일했는지는 원문으로 재확인하지 않았다. 금액(최대30만엔)은 국가교부요건(39세이하 구간)과 일치하므로 큰 변동은 없을 것으로 추정되나 **추정일 뿐 확정 아님**.
- **실제 채택률・수급건수**: 페이지에는 예산액과 잔액만 있고, 실제 몇 세대가 수급했는지는 원문에 없음.
- **奨学金返還世帯의 공제 상세 계산식**: 「연간반환액을 소득에서 공제」라고만 돼 있고 구체적 계산예시는 원문에 없음.
