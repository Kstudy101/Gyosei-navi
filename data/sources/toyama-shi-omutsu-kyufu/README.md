## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **지급 매수・지급액・引換券의 구체적 금액換算**: 본 페이지 본문에는 기재 없음（申請書PDF・記入例PDF 내부에 있을 가능성 — 본 세션에서는 PDF 미취득）。
- **지급 빈도・지급주기**（월1회／연간 상한 등）: 본문에 기재 없음。
- **課税世帯・非課税世帯에 따른 차등**: 소득요건(1,000万円未満)만 기재되어 있고 단계별 차등 유무는 불명。
- **신청 접수기간**（통년 상시접수인지, 특정 접수기간이 있는지）: 불명（募集期限 표기 없음）。
- **物価高騰対応重点支援地方創成臨時交付金를 재원으로 한 임시사업인지, 상설사업인지**: 원문에 "臨時交付金を活用して"라는 표현이 있어 시한부 사업일 가능성이 있으나 종료일 등 명시 없음 — 기사 작성 시 "현시점 시행 중" 정도로만 서술하고 항구적 제도로 단정 금지.
- 申請書PDF/Word/記入例PDF는 미다운로드(본 세션에서는 HTML 원문만 아카이브). 금액 등 세부 수치가 필요하면 PDF를 추가로 취득해야 함.

## 富山市 총무성 전국지방공共団体코드 확인

- **富山県**（도도부현 코드・2자리）: `16`
- **富山市**（전국지방공공단체코드・검사숫자 포함 6자리）: `162019` → regions.ts 기존 등록 관례(검사숫자 제외 5자리)에 맞추면 **`16201`**
- 확인 방법: 総務省 공식 PDF 「全国地方公共団体コード」(URL: `https://www.soumu.go.jp/main_content/000925834.pdf`, 안내 페이지 https://www.soumu.go.jp/denshijiti/code.html )를 직접 다운로드하여(`data/sources/_shared-codes/zenkoku-chihokokyodantai-code.pdf`) 富山県 섹션에서 "162019 富山県 富山市 トヤマケン トヤマシ" 행을 원문 대조 확인함.
- `src/config/regions.ts`에 富山市를 등록할 때는 5자리 코드 `16201`（기존 등록된 横浜市`14100`・名古屋市`23100` 등과 동일 형식）과 총무성 정본 URL을 근거로 사용하면 됨. 본 태스크에서는 regions.ts 수정을 하지 않음.
