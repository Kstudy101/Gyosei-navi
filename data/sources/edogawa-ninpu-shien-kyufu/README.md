## 核心数値（原文対照）

出典は特記なき限り `01_ninpunokyuhu.txt`。

| 項目 | 原文の記載 |
|---|---|
| 実施開始 | 令和7年4月1日より一体実施 |
| 1回目 | 妊娠時 **5万円**（現金またはギフトカード）。令和7年4月1日以降にぴよママ相談を受けた方／令和7年3月31日までにぴよママ相談を受け出産応援ギフト未給付の方。**医師による胎児心拍確認が必要** |
| 2回目 | 出産後 **5万円**（現金またはギフトカード）。令和7年4月1日以降に出産し、新生児訪問を受けた方 |
| 東京都赤ちゃんファースト | 令和7年度は東京都が直接 10万円分ギフト（都HP参照） |
| 区独自 | ぴよママ相談時に **ぴよママギフト（1万円分）** と給付申請案内（`05_piyomama.html`） |
| 申請 | ママページの作成・申請が必要。転入で区母子健康手帳番号未取得ならぴったりサービスで番号取得申請（`03`） |
| 住民要件 | 申請時点で江戸川区に住民登録がない方へは給付不可 |
| 口座 | 現金は妊婦の口座（旧姓不可）。妊婦以外口座不可 |
| 方法変更 | 確定後は現金⇔ギフト変更不可 |
| 二重受給 | 複数自治体から受取不可。前住所地未受給を確認 |
| 流産等 | 令和7年4月1日以降の死産・流産・人工妊娠中絶等、同日以降に出生の子を亡くした方も申請可（`01`/`04`）。届出前はコールセンターへ |
| 旧制度 | 令和7年3月31日までに出産応援ギフト申請／出産した方向けページが別途（`08`）。旧ギフト初回登録最終期限は令和7年9月30日 |

問い合わせ: 江戸川区妊婦のための支援給付事業コールセンター 03-4446-4327（平日9–17時、英中越対応）
