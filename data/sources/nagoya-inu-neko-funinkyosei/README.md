## 원문에서 확정한 사실 (기사 근거) — 主制度: 飼い犬・飼い猫の避妊去勢補助

| 항목 | 원문 |
|---|---|
| 제도명 | 令和8年度 犬・猫の避妊・去勢手術の補助 |
| 목적 | 犬・猫の不必要な繁殖と周囲に対する危害・迷惑を防止するため、手術費用の一部を補助 |
| 대상자 | **市内において犬猫を所有している市内在住の方**。犬は狂犬病予防法に基づく登録が済んでいること |
| 방식 | **補助券（バウチャー）事前交付型**。保健センター又は動物愛護センターで補助券を受け取り、指定獣医師に提出すると手術費用が減額される |
| 補助券 유효기간 | 交付の日から起算して**14日間**（ただし交付した年度は超えない） |
| **犬 조성액** | 避妊（めす）: 名古屋市 3,200円 ＋ 名古屋市獣医師会 6,400円／去勢（おす）: 市 1,600円 ＋ 獣医師会 3,200円 |
| **猫 조성액** | 避妊（めす）: 市 2,100円 ＋ 獣医師会 4,200円／去勢（おす）: 市 1,050円 ＋ 獣医師会 2,100円 |
| 교부기간 | **令和8年4月1日（水）から交付開始、なくなり次第終了** |
| 토・일・祝 | 動物愛護センターのみ対応。12/29〜1/3 제외 |
| 신청 장소 | 各区保健センター又は動物愛護センター（**保健センター分室では発行しない**）。居住区に関係なく市内どの保健センターでも可 |
| 문의 | 健康福祉局 生活衛生部 食品衛生課 獣医務担当 052-972-2649 |

## 관련 제도 — TNR支援事業（03번: 名古屋市のら猫の避妊又は去勢手術支援事業）

| 항목 | 원문 |
|---|---|
| 성격 | 飼い主のいないのら猫のTNR活動支援。飼い犬・飼い猫向け補助券制度とは別制度 |
| **실시자 자기부담** | 避妊手術（めす）**4,000円**／去勢手術（おす）**2,000円**（一律） |

## 제도 유형 분류

- 主制度: **飼養犬猫向け・補助券減額型**（市＋獣医師会の二段助成）
- 関連1: マイクロチップ装着・補助券減額型（定額1,000円）
- 관련2: のら猫TNR・定額自己負担型（市が残額を支援する構造。市の負担額そのものは原문에 명시 없음）
- 관련3: 地域猫（なごやかキャット）・手術無料型（현물・서비스에 가깝다）

## ⚠️ 원문에서 확인되지 않은 것 (unresearched)

- 市負担額と獣医師会負担額を合算した「総助成額」表記は原문에 없음 — 기사에서는 원문대로 分記하고, 합계는 「合算すると〜」로 보조 설명할 수 있으나 원문이 합계를 공식 수치로 제시한 것은 아님을 명시
- 令和8年度指定獣医師名簿 PDF（避妊去勢・マイクロチップ・TNR）は未ダウンロード — 병원 목록 세부 미수록
- TNR에서 市가 부담하는 구체적 금액（병원 청구 총액 − 自己負担）은 원문에 없음
- 年間交付枚数・予算総額の具体数は原문에 없음（「なくなり次第終了」のみ）
- 飼い犬・飼い猫 제도가 のら猫에도 적용되는지는 원문상 **対象者が「所有している」市内在住者**로 한정되어 있어 のら猫는 별도 TNR 제도 대상
