## 확인되지 않은 것 / 주의

- **제2차 모집 종료일 불일치**: 상세 HTML(02、更新2026-09-15)・개요(01)・PDF표지(03 p.1)는 **8月31日（月）**, PDF Ⅴ모집기간(03 p.7付近)만 **8月28日（金）**. 제2차는 이미 종료이므로 기사 본문은 상세 HTML 기준(8/31 종료)으로 쓰고, 이 불일치를 README에만 기록.
- 연간 예산총액・채택 예정건수: 원문에 「選定件数：ー件」만 있고 구체 수치 없음.
- 「一定の要件」세미나별 증명서 교부 요건의 세부는 03 PDF에 있으나, 각 세미나의 **현재 수강 가능 여부・일정**은 별도 모집 페이지를 봐야 함(기사에서 단정하지 않음).
- 제3차 모집 개시 전(2026-09-22 시점)이므로, 예산 소진으로 제3차가 열리지 않을 가능성 — 원문이 「予告なしで終了する場合がある」고 명시.
