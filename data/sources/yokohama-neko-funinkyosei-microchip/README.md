## topic-scout 요약과 원문 대조 결과

대체로 topic-scout의 사전 요약(WebFetch 기반)은 원문과 일치했다. 다만 다음 1건은 원문 확인 결과 **정정 필요**:

- **犬에 대한 별도 마이크로칩 보조(1頭 1,500円)** — topic-scout 요약은 "犬에 대한 별도 마이크로칩 보조(1두 1,500엔)도 같은 페이지 내 있음"이라고 기재했으나, 원문(`01_castration.txt` L381)에는 **令和8年度부터 이 犬・飼い猫 대상 마이크로칩 장착 보조 자체가 폐지되고 「飼い猫にする猫」만 대상으로 통합되었다**고 명시되어 있다. 즉 "犬 별도 마이크로칩 보조"는 令和8年度 기준으로 더 이상 존재하지 않는다(과거 사업이었을 가능성). 기사 작성 시 이 문구를 참고용으로도 쓰지 말 것 — 존재하지 않는 제도를 언급하면 오정보가 된다.
- URL `shimin-funin.html`은 404. 다만 이 페이지가 다루려던 신청절차 내용은 `castration.html`(01) 안에 「申請の手順」섹션으로 전문 포함되어 있으므로 정보 공백은 없음.
- 나머지 수치(대상, 금액, 두수 상한 2,300頭, 신청기간, 시술기간, 담당창구, 예산조건부 문구)는 모두 원문에서 그대로 확인됨. topic-scout 요약과 실질적 차이 없음.

## 확인되지 않은 것

- `shimin-funin.html`의 실제 존재 여부/대체 URL(리다이렉트 등) — 404 확인만 했고 사이트 내 재탐색은 하지 않음. 신청절차 정보 자체는 castration.html에 포함되어 있어 기사 작성에는 지장 없음.
- 전자신청 시스템(横浜市電子申請・届出システン) 링크 URL 자체 — 본문에 "(외부사이트)"로만 표기되어 있고 실제 href는 HTML 태그 제거 과정에서 텍스트로는 확인 불가(원문 취득 방식이 태그 제거이므로 href 속성 미보존). 필요 시 별도로 원본 HTML raw를 확인해야 함.
- PDF 첨부자료(사업안내 전단지, 등록동물병원 명부, 각종 신청서 양식) 자체는 원문 텍스트 내 파일명·용량만 확인(L429-495 부근), PDF 실물은 이번 조사에서 다운로드하지 않음. 필요 시 추가 다운로드 요망.
- 모집(접수) 현재 상태 — 원문 최종更新日은 castration.html이 2026年8月26日, FAQ가 2026年2月27日이며, 취득일(2026-09-20) 기준 신청접수기간(令和8年5月7日〜令和9年3月5日) 내에 있음. 다만 "2,300頭 예산 소진 여부"는 정적 페이지에 실시간 반영되지 않을 수 있어 정확한 현재 소진 여부는 미확인(원문에 "예산 소진 시 조기종료" 조건만 명시되어 있을 뿐, 현재 잔여 두수 등 실시간 정보는 없음).
