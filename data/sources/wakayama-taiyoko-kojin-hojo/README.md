## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **募集期間（受付期間）の県内共通の最新状況**: 본 페이지는 시정촌별 실시상황 표만 제공하고, 각 시정촌 창구는 별도 URL(각 시정촌 HP)로 링크되어 있어 개별 접수기간・신청상한 등은 시정촌마다 다름 — 시정촌 단위 확인이 필요(municipality-researcher 위임 대상).
- **脱炭素先行地域住民の대상 제외 여부**: 원문에서 "脱炭素先行地域づくり事業又は重点대책가속화事業에 채택된 시정촌은 제외"라고 명시되어 있으나, 어느 시정촌이 이에 해당하는지(和歌山市・那智勝浦町 외 추가 여부)는 본문에서 명시적으로 열거되지 않음 — 상기 2개 시정촌만 별도 경로로 실시 중이라고 확인됨.
- **개인 신청자 기준 구체적 신청서류・신청방법**: 이 페이지는 "시정촌 대상 내용"이며 개인 안내는 각 시정촌 홈페이지 확인 필요 — unresearched(현 레벨 원문에는 없음).
- **予算残額 엑셀 파일의 구체적 수치**: 파일 링크만 확인, 파일 내용 미취득.
- **각 시정촌별 실제 보조금 교부요강・상한액**: 현 요강(7万円/kW, 1/3 상한47만엔, 1/2 상한30만엔)이 각 시정촌에 그대로 적용되는지, 시정촌 독자 가산이 있는지는 시정촌별 확인 필요.
