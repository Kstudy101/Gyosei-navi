## 原文から確定した数値・条件（記事に使用）

- 補助上限額: 婚姻日の年齢が夫婦ともに29歳以下 → 最大60万円／夫婦ともに39歳以下 → 最大30万円（01・02で一致）
- 婚姻日: 令和8年1月1日〜令和9年3月31日
- 所得: 夫婦の合計所得金額500万円未満（奨学金返済額は控除可）
- 定住意思: 今後**4年以上**（久留米市の3年と異なる）
- 対象費用支払期間: 令和8年4月1日〜令和9年3月31日（資格認定を受けた場合は翌年の費用も申請可）
- 住宅取得: 建物に係る費用の**2分の1**（土地代は対象外）
- 賃貸: 敷金・礼金（保証金等含む）・仲介手数料のみ。**月額家賃は対象外**（久留米市と異なる）
- 引越: 業者・運送業者への支払の**2分の1**
- リフォーム費用: 本制度の対象費用としては原文に記載なし（未対象と扱う）
- 締切: 令和9年3月31日（予算上限到達で早期終了の旨あり）
- 講座受講必須（夫婦とも・申請日まで）: ライフデザイン／プレコンセプション／医療機関相談／共家事・共育て のいずれか
- 併用: 「若年世帯家賃支援補助金」「マイホーム取得支援補助金」と同時申請可。「若年世帯引越費用支援補助金」「中古住宅取得支援補助金」とは併用不可（01・04）
- 申請先: 定住対策課 定住対策係（〒834-8585 八女市本町647番地）TEL 0943-24-8162

## 制度タイプ
現金直接補助型（新婚世帯の住居取得費・賃貸初期費用・引越費）。国の交付基準額（29歳以下60万／それ以外30万）を採用。対象費用の範囲は久留米市より狭く（家賃月額・リフォームなし）、定住意思は4年と長い。
