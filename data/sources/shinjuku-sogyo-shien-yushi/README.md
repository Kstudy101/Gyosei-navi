## ⚠️ 중요: 港区식 현금직접보조형은 신주쿠구에 없음(조사 에이전트가 정직하게 확인)

조사 에이전트가 「中小企業支援ガイド」PDF까지 확인한 결과, 사용자가 예시로 든 "創業助成金"류 현금직접보조는 전부 **도쿄도・국가・공익재단법인** 운영(예: 東京都中小企業振興公社 創業支援課)이고 新宿区 독자 제도가 아님을 확인. 新宿区가 독자로 제공하는 창업관련 금전지원은 **이 융자알선형 제도 1건뿐**. 千代田・品川・世田谷・渋谷와 같은 유형(융자알선형)이지만, 신주쿠구의 유일한 대안이므로 채택.

## (참고, 채택 안 했으나 원문에서 발견) 商店街空き店舗活用支援資金(空借)

원문78〜88줄에 별개특례 존재: 구가인정하는商店会/商店街振興組合구역내빈점포(1개월이상영업안한점포)를빌려창업하는경우, **이자+신용보증료전액보조**(創業資金보다유리). 商店会등가입등추가요건있음. 기사본문에 "함께알아두면좋은특례"로간단히언급만함, 별도기사화는하지않음.
