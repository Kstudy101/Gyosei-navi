## 確認された主な事実

- 制度名: 岐阜市重度障害者（児）タクシー利用料金助成
- 助成: 1回の乗車につき560円（乗車券1枚）。1年度あたり利用回数は48回限度（年間最大26,880円相当）
- 1回の乗車について乗車券は1枚のみ使用可
- 対象交通: 協定を結んだタクシー事業者、および本市区域の福祉有償運送
- 対象者（本市住所・在宅）:
  - 視覚障害1級又は2級
  - 下肢・体幹・乳幼児期以前非進行性脳病変による移動機能障害の1級又は2級
  - 内部障害（心臓・じん臓・呼吸器・ぼうこう・直腸・小腸・免疫・肝臓）1級
  - 療育手帳所持者で知能指数おおむね20以下（公式ページ表記: IQ20以下（A1））
- 除外: 自動車改造費助成・介助用自動車購入等助成・自動車税/軽自動車税減免を受けている者。公式ページは施設入所者も除外と明記
- 年度途中認定は月割枚数
- 乗車券の再交付なし
- 新規申請はオンライン可、更新は窓口/郵送（切手460円・簡易書留返信）
- 窓口: 障がい福祉課、柳津地域事務所福祉事務所柳津分室、南部東/西部/東部/北部/日光/南部西事務所
- 公式ページ更新日: 令和6年10月24日

## 確認されていないこと

- 精神障害者保健福祉手帳所持者の対象可否（要綱・公式ページに記載なし＝対象外と解されるが、精神手帳に関する言及自体がない）
