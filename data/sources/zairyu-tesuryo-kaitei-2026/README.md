### 법 상한(제67조)과의 관계

`npm run law` 로 조회한 **현재(취득시점 2026-08-29 기준) 시행 중인** 入管法 第67条는 「一万円を超えない範囲内」로 명시돼 있다 — 이는 **개정 전 상한**이다.
2026年5月29日 성립(令和8年法律第32号)한 개정법이 상한을 인상(보도상 변경・갱신 上限10万円/영주 上限30万円)했지만, **그 상한 인상 조항 자체도 2026-10-01 시행**이라 아직 e-Gov 조문에 반영되지 않은 것으로 보인다(관보에서 별도 확인 필요 — 미완료 항목).
→ 정령268호가 그 상한 범위 내에서 실제 징수액(위 표)을 정한 것.

### 경과조치 (부칙)

부칙에서 명시적으로 다루는 경과조치는 **特定在留カード・特定特別永住者証明書 관련 수수료 산정**뿐이다(부칙2・3조).
**제25조 본체(변경・갱신・영주・재입국) 수수료에 대한 별도의 「9/30까지 접수분은 구요금」 경과조치 조문은 관보 원문에서 확인되지 않았다.**
→ 수수료는 통상 **신청 접수 시 납부**하는 구조이므로, 시행일(10/1) 이후 접수분부터 신요금이 자동 적용되는 것으로 보인다(복수의 전문 행정서사 매체가 「2026年10月1日申請分」이라 보도 — 방향성 일치).
→ ⚠️ **기사화 시 이 해석을 단정하지 말고, 접수 vs 처분 기준 여부를 원문 재확인하거나 「申請時期にご注意ください」 정도로 헤지할 것.**
