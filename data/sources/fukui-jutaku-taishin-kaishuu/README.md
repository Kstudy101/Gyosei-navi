## 核心数値（01 福井市原文より）

- 制度名: 一戸建て木造住宅の耐震改修等工事、除却工事に対する補助制度（福井市木造住宅耐震改修促進事業補助金）
- 最終更新日: 2026年3月31日（原文表示）
- 対象住宅: 昭和56年5月31日以前に着工した一戸建て木造住宅（併用住宅は延床面積1/2以上が住宅用途）で、上部構造評点1.0未満（伝統診断法は評価指標30超）と判定されたもの
- 申込者要件: 住宅を個人所有し自ら居住、市税完納、1所有者につき1回限り
- 補助金額（上限額）:
  - 耐震改修: **140万円まで**（自己負担35万円）
    - 「高齢者世帯」または「令和7年度までに耐震診断を実施」の場合は上限175万円（自己負担なし）
    - 過去に補強プラン作成のみで工事に至らなかった世帯が新たにプラン作成・工事実施した場合は上限+10万円加算（上記175万円条件に該当しない場合のみ）
  - 耐震改修（伝統的構法）: 190万円まで（自己負担47.5万円）。高齢者世帯は上限237.5万円（自己負担なし）
  - 耐震シェルター: 30万円まで（自己負担7.5万円）。高齢者世帯は上限37.5万円（自己負担なし）
  - 除却（解体）: 30万円まで（工事費用の23％）
- 予算枠到達次第、受付終了
- 代理受領制度あり（施工業者が補助金を代理受領可能）
- 問い合わせ窓口: 福井市建設部建築指導課 電話0776-20-5574／〒910-8511 福井市大手3丁目10-1 市役所本館5階

**注意（topics-db記載との差異）**: `data/topics-db/fukui.json` のnoteには「最大120万円との情報あり（要原文確認）」とあったが、原文確認の結果、耐震改修の上限額は**140万円（条件により175万円）**であり、120万円という数値は原文に存在しない。記事執筆時は必ず140万円／175万円を用いること。
