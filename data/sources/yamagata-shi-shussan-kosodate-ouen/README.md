## 確認できた情報
- 制度移行: 「出産・子育て応援給付事業は令和7年3月末で終了し、『妊婦のための支援給付』へ移行」
- 給付金額（1回目・妊婦支援給付金）: 「妊婦給付認定申請後、5万円を支給」
- 給付金額（2回目・妊婦支援給付金）: 「胎児の数の届出後、胎児の数×5万円を支給」
- 流産・死産等の場合: 「医師による胎児の心拍確認がされていれば支給対象」
- 対象者: 「申請日時点で、山形市に住民票がある方のうち、令和7年4月1日以降に妊婦給付認定申請をした妊婦」
- 申請期限（1回目）: 「医療機関で妊娠が確定した日から2年を経過した日の前日まで」
- 申請期限（2回目）: 「出産予定日の8週間前の日から2年を経過した日の前日まで」
- 申請方法: 「妊娠届出時に申請書を配付。必要事項を記入、本人名義の口座情報の写しを添付し母子保健課へ提出」
- 申請先: 「山形市母子保健課（山形市保健所内）〒990-8580 山形市城南町一丁目1番1号（霞城セントラル3階）、電話023-647-2280」
- 経過措置（旧制度）: 令和7年3月31日までに出生したお子さんを養育している方には「子育て応援給付金」新生児1人5万円を引き続き支給
- 伴走型相談支援: 妊娠届出時・妊娠7-8カ月・産後赤ちゃん訪問時に保健師・助産師等が面談
