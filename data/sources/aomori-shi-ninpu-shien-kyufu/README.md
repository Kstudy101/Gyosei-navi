## 核心数値（原文対照）

出典は特記なき限り `01_ninpu-shien-kyufu.txt`。

| 項目 | 原文の記載 |
|---|---|
| 制度変更 | 令和7年4月1日から「出産・子育て応援給付金」→「妊婦支援給付金」に名称及び制度変更。流産・死産等も対象に |
| 支給構成 | （1）妊娠届出時の妊婦支援給付認定後 **5万円**、（2）出産予定日の8週間前の日以降の胎児の数の届出後 **妊娠しているこどもの人数×5万円** |
| 1回目対象 | 申請日に青森市に住民票があり、妊婦給付認定を受けたかた |
| 1回目申請 | 妊娠届出時、母子健康手帳交付の際に妊婦給付認定及び1回目申請を受付 |
| 1回目持参 | 振込口座確認書類（通帳またはキャッシュカード・**申請者本人名義に限る**）、マイナンバー確認書類 |
| 1回目申請時期 | 医療機関の受診により妊娠が確定した日から2年を経過する日まで |
| 2回目対象 | 申請日に青森市に住民票があり、妊婦給付認定を受けたかた |
| 2回目申請 | 出生届出時にお誕生カード提出→保健師等が家庭訪問で申請書と返信用封筒を手渡し→郵送 |
| 2回目必要書類 | 振込口座確認書類の写し（本人名義に限る） |
| 2回目申請期限 | 出産予定日の8週間前の日から2年を経過する日まで。流産・死産等は医療機関確認日から2年 |
| 流産・死産等 | 令和7年4月1日以降に経験されたかたも対象。妊娠届出前の場合は医師による胎児心拍確認の診断書等が必要 |
| 支給時期 | 受付日（郵送は市到着日）から2週間～1か月程度 |
| 転出 | 妊婦給付認定後に市外転出すると認定取消。転入先で再認定が必要。市外で1回目認定後に青森市転入し2回目申請する場合も青森市で再認定が必要 |
| 窓口 | あおもり親子はぐくみプラザ（017-718-2987）、健康福祉課・浪岡庁舎（0172-62-1114） |
| 問い合わせ | 青森市こども未来部あおもり親子はぐくみプラザ / 〒030-0962 青森市佃二丁目19-13 / 電話017-718-2987 |
