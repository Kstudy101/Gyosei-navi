## 制度類型
現金給付型（補助金・後払い、実績報告後に交付請求→交付）。融資あっせん型・現物支給型ではない。

## topic-scoutの要約との差異
- 要約は概ね正確だった。誤りは確認されなかった。
- 追加で判明した点：
  - 補助対象者から除外される具体的な欠格事由（市税滞納、他補助金重複受給、風俗営業・暴力団関係、フランチャイズ契約事業、政治・宗教活動目的事業等）は要約になかった。
  - 返還規定（3年未満での廃業等は期間案分での一部返還、不正の場合は全額返還）は要約になかった。
  - Q&A の8問（市外在住者の可否、既存事業者の別事業の扱い、給与収入との関係、法人成りの扱い、店舗兼住居の賃借料の扱い、汎用品の定義等）は要約になく、実務上の判断基準として重要。
