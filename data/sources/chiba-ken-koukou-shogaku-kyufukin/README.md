## 제도 유형 분류
**현금 직접 지급형(返還不要の給付金)**。授業料以外の教育費（教科書・教材・通学費等）負担軽減が目的。就学支援金（授業料）とは別制度。

## (2) 対象・要件（共通部分）
- 基準日 令和8年7月1日現在、就学支援金/学び直し支援金/専攻科支援金の受給資格（公立は「高校生等・新修学支援」も列挙）を有する高校生等がいる世帯（私立: 平成25年度以前入学者は除く）
- 保護者等が千葉県内在住（成人の専攻科生は本人）。県外在住は在住都道府県へ申請
- 生活保護（生業扶助）受給世帯、または保護者全員の道府県民税所得割＋市町村民税所得割合算が **182,500円未満**（年収約490万円未満相当）
- 専攻科で扶養する子3人以上: 264,500円未満（年収約600万円未満相当）
- 年収270〜490万円相当の区分は就学支援金【新制度】等の受給資格者のみ（公立原文）
- 私立のみ明記: 令和8年度からの新制度で日本国籍または特別永住者・永住者・日本人の配偶者等・永住者の配偶者等・定住者(永住意思認定)・家族滞在(一定条件)が対象。それ以外の外国籍・外国人学校生は生活保護（生業扶助）または住民税非課税世帯のみ（旧制度）
- 対象外: 児童福祉法の措置費等で見学旅行費/特別育成費が措置されている場合、基準日に休学中（12月1日までに復学すれば対象）。私立は市川市奨学生など同時受給不可の奨学金あり

## (4) 令和8年度の申請期間・方法
- 令和8年度から原則電子申請（「千葉県奨学のための給付金電子申請サービス」）。マイナンバーカード利用で課税証明書等が不要。紙申請も可（電子より遅い）
- 公立: 受付開始 令和8年7月1日。県内国公立は期限「学校が指定する期日」。茨城・埼玉・県外国公立は原則 令和8年9月3日、最終 令和8年12月25日（当日消印有効）。振込は令和8年10月末以降の予定（原文）
- 私立: 原則期限 令和8年9月18日（消印有効）、最終期限 令和8年12月18日。県内私立は学校ごとの対応。支給は今年度内に振込予定
- 提出先（県直接）: 公立分 〒260-8662 千葉市中央区市場町1-1 千葉県教育庁財務課育英班／私立分 〒260-8667 同所 総務部学事課私学振興班
- 新入生の一部早期給付の受付は終了（私立ページ）。家計急変世帯は別途受付（毎年度申請必要）
