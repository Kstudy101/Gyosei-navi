## 制度概要（原文根拠: 01_kamiomutsu.txt 106-122行）
- 制度名: 紙おむつ等の給付
- 対象: おおむね65歳以上の市民税非課税世帯に属し、寝たきりまたは失禁状態にあり紙おむつを必要とする方。**在宅の方に限る**（施設入所者は対象外）。
- 内容: 紙おむつ・尿とりパット・おむつカバーを毎月給付。品目・数量は自由に選択可能。
- 給付上限額: 対象者1人につき**月額8,000円**を限度。
- 自己負担: 給付額の**1割**。
- 申請方法: 地域包括支援センターによる調査が必須。詳細は高齢者支援課へ問い合わせ。
- 接受期限・予算枠: 原文に記載なし（通年の継続事業とみられるが明記なし）。
- 問い合わせ先: 健康福祉部 高齢者支援課 いきいき高齢者係 Tel 0428-22-1111（内線2157・2158）Fax 0428-22-3508

## 制度分類
- 現物給付型（介護用品支給）。他自治体の「紙おむつ支給」「介護用品支給」系（例: kawaguchi-kaigo-yohin-shikyu, ota-kaigo-kamiomutsu, sendai-kaigoyohin-kyufu）と同カテゴリ。
- 現金給付ではなく、月額上限8,000円分の現物（おむつ等）を給付し、利用者は1割自己負担する仕組み（介護保険の給付方式に近い）。
