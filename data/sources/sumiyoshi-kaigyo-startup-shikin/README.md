## 住吉区 고유 창업지원 세미나・전용 창구 조사 결과

WebSearch로 「住吉区役所 創業支援」「住吉区 創業支援 相談窓口」등을 조사했으나, 住吉区役所가 자체적으로 운영하는 창업지원 세미나나 전용 상담창구는 발견되지 않았다. 검색 결과 나온 창업지원 세미나(起業スタートアップセミナー 등)는 모두 大阪市経済戦略局産業振興部企業支援課／大阪産業創造館（大阪市中央区、大阪市 전역 공통 창구）가 주최하는 것이며, 住吉区 한정 프로그램이 아니다. 住吉区役所 대표 전화(06-6694-9986)나 조직 안내 페이지(`https://www.city.osaka.lg.jp/sumiyoshi/soshiki_list.html`)에서도 창업 전담 부서는 확인되지 않았다.

**이 조사는 WebSearch 요약 수준에 그쳤으며, `npm run source`로 住吉区役所 조직 안내 페이지를 원문 아카이브하지는 않았다.** 기사에서 "住吉区 독자의 창업지원 세미나・전용 창구는 확인되지 않음"이라고 쓸 경우 이 사실은 negative-confirmation(직접 검색 결과 부재)이지 원문 대조는 아니므로, 필요시 정확한 문구로는 "공식 사이트 검색 결과 확인되지 않음" 수준으로 표현할 것을 권장한다.
