## 制度の類型分類

**現金給付型（補助金）**。融資あっせん型・現物支給型ではない。市への申請・審査を経て補助金が交付される仕組み。ただし別途「特定創業支援等事業」（セミナー受講による証明書発行制度、01ファイル内で言及）を修了していないと申請資格自体を得られない、という前提条件付き。
