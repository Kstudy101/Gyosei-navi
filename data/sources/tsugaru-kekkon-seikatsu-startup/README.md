## 제도 유형 분류

**現金直接交付型**（つがる市が新婚世帯に直接補助金を交付する方式。融資あっせん型ではない）。国の「地域少子化対策重点推進交付金」（都道府県主導型市町村連携コース）を財源とする、いわゆる旧・結婚新生活支援事業の後継スキームに位置づけられる（04番資料に「事業開始年度：令和3年度」「新規／継続：継続」と明記）。

補助構造の特徴：
- 基本額（住宅取得・リフォーム・賃借・引越費用の合計に対する補助）：年齢区分により60万円 or 30万円
- 生活家電購入費用は**別枠加算**で最大10万円（基本額とは合算せず別枠上限）
- → 最大合計は「60万円＋10万円＝70万円」（29歳以下世帯）または「30万円＋10万円＝40万円」（それ以外）となるが、この合算表現（70万円/40万円）自体は原文に直接の記載がなく、あくまで2つの独立した上限額（基本額枠と家電枠）の合計として算出した値である点に留意。
