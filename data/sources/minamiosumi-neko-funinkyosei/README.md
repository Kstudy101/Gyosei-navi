## 確認できた数値・条件

### 対象者
- 町内に住所を有する個人および町内で活動する団体（自治会含む）

### 対象猫
- 町内を生息区域としている のら猫および飼い猫

### 対象経費
- 不妊・去勢手術代、耳カット、入院費等
- 手術以外の医療費（ワクチン・ノミ駆除薬等）は対象外

### 補助率・上限額
- 補助率: 対象経費の90%（1,000円未満切捨て）
- 上限額: オス 8,000円 / メス 16,000円（1頭あたり）
