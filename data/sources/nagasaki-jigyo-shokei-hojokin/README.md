## 根拠表（令和8年度）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 実施主体 | 長崎県 産業労働部 経営支援課（事業承継補助金担当）。制度上の位置づけは補助金。財源の一部に国の物価高騰対応重点支援地方創生臨時交付金を活用 | 01, 06 第1条, 07 |
| 事務局 | 独立の事務局の記載なし。県が直接受付。事業承継の相談先は長崎県事業承継・引継ぎ支援センター（長崎商工会議所内） | 01, 04 |
| 目的 | 物価高騰等での先行き不安による廃業を抑制し、雇用維持・技術技能の伝承につなげる。事業承継に向けた具体の取組と承継後を見据えた事業展開を支援 | 01, 04 |
| 対象者（要件） | ①県内に本店または主たる事業所を有する中小・小規模事業者等（承継時にそう見込まれる者を含む） ②長崎県事業承継・引継ぎ支援センターの支援を受け、今後5年以内の事業承継を目標に取り組む ③県税・法人税（個人は所得税）・消費税及び地方消費税の滞納なし（正式な猶予手続きは可） ④宗教・政治活動が主目的でない ⑤暴力団等でない ⑥債務超過でない等財務健全で承継後も県内で事業継続見込み | 04 二, 06 第3条 |
| 対象者の定義 | 中小企業支援法上の中小企業者、中小企業基本法上の小規模企業者、またはこれに準ずるものとして知事が認める者。「みなし大企業」は除く。小規模企業者は製造業・建設業・運輸業・宿泊業・娯楽業その他が従業員20人以下、卸売・小売・サービス業（宿泊・娯楽除く）が5人以下 | 04 別表1 |
| 承継区分 | (1)親族内承継（譲渡側）、(2)親族外承継（従業員等）（譲渡側・譲受側）、(3)第三者承継（M&A）（譲渡側=売手側・譲受側=買手側） | 01, 04 |
| 補助対象経費① | 課題整理の専門家活用に要する経費: 専門家への謝金・委託料等（企業価値算定、不動産・事業用資産の鑑定、課題分析、事業承継計画策定）、動産・不動産の登記費用、M&A仲介手数料等（謝金、委託料、デューデリジェンス費用）、知事が特に必要と認める経費 | 01, 04 三 |
| 補助対象経費② | 承継後を見据えた事業展開に要する経費: 新商品・サービス開発費（専門家謝金、デザイン料、調査研究費、委託料等）、施設改修費、設備投資費、知事が特に必要と認める経費 | 01, 04 |
| 経費区分ごとの対象 | 親族内承継は譲渡側が①②。親族外承継は譲渡側が①②、譲受側は①のみ。M&Aは譲渡側が①のみ、譲受側が①②（②は成約後の発注分に限る） | 01, 04 表 |
| 補助率 | 補助対象経費の1/2以内。小規模企業者は2/3以内 | 01, 04, 07 |
| 上限額 | 経費区分（①②）それぞれ50万円。交付申請額（①②の両方を申請する場合はその合計）の下限は10万円。なお区分ごと50万円なので、①②とも申請する場合の理論上の最大は合計100万円だが、合計上限を明記した記述は原文に見当たらず未確認 | 01, 04 表・注 |
| 端数 | 補助金額の千円未満切捨て | 06 第5条3項 |
| 対象外経費 | 公租公課（消費税及び地方消費税含む）、市場価格に比して著しく価格差のあるもの、M&A成約を条件とする仲介業者の成功報酬、後継者の代表者就任で新規作成する名刺作成費、収入印紙、消耗品購入費 等 | 01, 04 |
| 交付決定前発注 | 交付決定日以後に正式に発注した経費のみ対象（事前着手不可）。ただしM&A仲介手数料は、交付決定日前に契約済みでも、決定日以後に受けた支援分は認められる場合がある | 01, 04 六 |
| 交付できない場合 | 引継ぎ支援センターの支援を受けていない、実質的な事業実施主体でない、国・県等の他の補助金を受けている経費、決定日前発注の経費を含む、等 | 04 六 |
| その他の条件 | みなし同一法人は1社のみ申請可（別表2）。自社・関係会社からの調達は利益等排除（別表3、要綱別表4） | 04 六・別表2・3, 06 第8条, 07 |
| 公募（申請受付）期間 | 令和8年3月30日（月）～令和8年10月30日（金）【当日消印有効】。2026-09-24付で令和8年9月30日から10月30日へ延長。予算の上限に達した時点で受付終了 | 01, 04, 07 |
| 申請方法 | 郵送のみ。追跡できる方法（簡易書留・レターパック等）を指定。様式第1号ほか（事業者概要、事業計画書、収支予算書、確認書（センター確認要）、誓約書、納税証明書、決算書類、契約書・見積書写し、履歴事項全部証明書 等）各1部 | 01, 04 六, 06 第6条 |
| 見積書 | 「承継後を見据えた事業展開」の相見積可能な経費: 県内業者で1件30万円未満は1社、30万円以上は2者以上。県外業者は金額に関係なく複数見積と業者選定理由書 | 04 六 |
| 提出先 | 〒850-8570 長崎市尾上町3-1 長崎県 産業労働部 経営支援課（01は「団体・経営支援担当」、04は「事業承継補助金担当」と担当名の表記が異なる） | 01, 04 |
| 手続きの流れ | (1)経営支援課へ問合せ→(2)県が長崎県事業承継・引継ぎ支援センターへつなぐ→(3)交付申請→(4)確認（申請後1月程度、受付順）→(5)交付決定→(6)事業実施→(7)実績報告→(8)額の確定→(9)請求→(10)支払 | 01 四 |
