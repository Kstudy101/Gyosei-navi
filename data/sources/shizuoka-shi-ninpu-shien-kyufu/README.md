## 制度タイプ

現金給付型（合計10万円・1回目／2回目の2段階）。伴走型相談支援（妊娠後期訪問等）と併記されているが、本記事の主対象は経済的支援（給付）側。

## 確認されていないこと

- **1回目・2回目それぞれの内訳額**（他市では各5万円と明記されることが多いが、静岡市公式ページ本文には「合計10万円」のみで、各回5万円の記載はない）。記事では内訳を断定しない。
- 所得制限の有無（原文に記載なし）。
- 多胎時の加算の有無（原文に記載なし）。
- 振込口座の名義制限（原文に「妊婦本人名義」等の明記なし）。
- 旧制度（出産・子育て応援給付金）の個別金額・残申請可否の詳細。
- 産後ケア事業（02・04）は同カテゴリの別制度。本スラッグの主制度ではない（関連一次情報として保管）。
