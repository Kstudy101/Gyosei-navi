## 確認できた最終数値・条件

### 対象者（01）
次のすべてに該当する方、またはその方の属する世帯の生計中心者:
1. 福岡市内に居住する65歳以上の高齢者
2. 要支援1・2 または 要介護1〜5 の認定を受けていること
3. 介護保険第1号被保険者保険料の所得段階が第1段階〜第8段階であること

### 対象工事（01）
- 高齢者の自立助長・介護者負担軽減のための工事。訪問調査の上、身体状況に応じて必要な工事が対象。
- **介護保険住宅改修費の給付対象となる工事は原則、対象外**。
- ★印の工事（浴槽取替・段差解消目的、通路整備、屋外手すり等）は介護保険の利用を優先。
- 助成は原則として**1世帯につき1回**。

改造箇所の例: 玄関・廊下の拡幅／居室の間仕切り変更・撤去／階段昇降機／浴室（浴槽取替・拡張）／温水洗浄便座（排泄処理不可能な場合のみ）／車椅子対応洗面台／屋外通路・手すり／水栓変更 等。

### 支給額（01）
- 算定: 「工事に要した額」と「助成上限額（**30万円**）」の低い方 × 下記助成率
- 介護保険住宅改修の対象となる工事については、**この助成においては10万円が限度**

| 介護保険料段階 | 階層区分 | 助成率 |
|---|---|---|
| 第1段階【A】 | 生活保護受給者／市民税世帯非課税の老齢福祉年金受給者など | 100％ |
| 第1段階【B】 | 市民税世帯非課税 | 90％ |
| 第2・3段階 | 市民税世帯非課税 | 90％ |
| 第4・5段階 | 本人が市民税非課税 | 60％ |
| 第6・7段階 | 本人が市民税課税で所得200万円未満 | 35％ |
| 第8段階 | 本人が市民税課税で所得200万円以上300万円未満 | 10％ |
| 第9〜15段階 | 本人が市民税課税で所得300万円以上 | 助成対象外 |

※第1段階の【A】【B】は当該事業独自の区分（01明記）。

### 申請（01）
- **事前申請必須**（着工前に各区保健福祉センター福祉・介護保険課へ申込み）
- 必要書類: 介護被保険者証／申請書及び見積書様式／承諾書（借家・公営住宅等）
- 窓口: お住まいの区の保健福祉センター福祉・介護保険課 または 住宅改造相談センター
- 住宅改造相談センター: 福岡市中央区荒戸3丁目3-39 福岡市市民福祉プラザ3階／TEL 092-731-3511／FAX 092-731-5361
