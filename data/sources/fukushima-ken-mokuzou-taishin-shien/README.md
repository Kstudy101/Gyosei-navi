- 耐震診断補助上限: 23.4万円/戸
- 部分改修・簡易改修: 工事費の4/5かつ最大69万円（多雪地域84万円）
- 一般改修・現地建替: 工事費の4/5かつ最大115万円（多雪地域140万円）
- リフォーム工事: 工事費の1/2かつ最大20万円
- 引越費用: 補助対象経費の1/2かつ最大6万円
- ブロック塀耐震化: 工事費の2/3かつ最大12.5万円/件
