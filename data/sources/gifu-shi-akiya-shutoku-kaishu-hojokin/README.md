# 岐阜市「空き家取得費・改修費補助金」

- **所管**: 岐阜市 住宅・空家対策課 空家相談係（058-214-2258）／空家指導係（058-214-2180）
- **公式ページ更新日**: 令和8年7月13日（2026-09-20取得時点）
- **対象年度**: 令和8年度（2026年度）実施分

## 確認できた最終数値・条件

### 受付状態（重要・01・03）
- **令和8年度の岐阜市空き家取得費・改修費補助金は予算の上限に達したため受付を停止しております。**（01冒頭に明記、原文どおり）
- 「申請の受付は、全ての書類が不ぞろいなく揃った時点で受付となります。予算額に到達した時点で受付を終了します。」
- 申請受付期間（当初予定・03リーフレット記載）:
  - 取得事業: 令和8年5月18日から令和9年2月10日まで
  - 改修事業: 令和8年5月18日から令和8年12月25日まで
  - ※いずれも「予算額に到達した時点で受付を終了」の注記あり
- 再開予定・次年度以降の見通しについての記載は当該ページ上に確認できず（**unresearched**）。

### 補助金の額（01・03）
- **取得事業**: 取得費用の額（上限30万円）。取得をした空き家に係る売買契約書に記載された額に限る。1万円未満切り捨て。
- **改修事業**: 取得事業の額（上限30万円）＋ 改修費用の額×1/2（上限50万円）を加算した額。改修費用は1,000円未満切り捨て。
- **合計上限（03リーフレット表記）**: 取得事業 最大30万円／改修事業 最大80万円
- 他の助成金等の交付を受ける場合は、改修費用の額から当該他助成金の空き家改修に係る部分の額を控除する。

### 補助対象となる空き家（01）
一戸建て住宅又は店舗等併用住宅（居住スペースが1/2以上）で、以下すべてを満たすもの:
1. 電気・ガス・水道いずれかの使用停止／廃止、または宅建業者による空き家表示広告、または市空き家バンク登録等で空き家であることが確認できること
2. 申請しようとする者の世帯全員の3親等以内の親族から購入した空き家でないこと
3. 建築完了日から5年以上経過していること

### 補助対象者の要件（01・03）
2人以上の世帯に属する者で、次のいずれかに該当（A：申請者本人が定住者の場合。B：親等が定住者の場合は別要件あり）:
- ア 市外からの定住者（転入前1年市外に住民登録があった者）
- イ 市内の賃貸住宅からの転居者
- ウ 子育て世帯（申請日において義務教育終了前の子を含む世帯）
- エ 新婚世帯（申請日前2年以内に婚姻届出をした世帯）
- オ 空き家バンク登録空き家購入者
（取得事業・改修事業でア要件の細部表現がやや異なる。03リーフレット表にも「取得事業の者」「改修事業の者」で対象欄に差異あり=市外からの定住者・市内の賃貸住宅からの転居者の要件は改修事業のみ一部×表記があるため、記事化の際は原文表を再確認要）

共通要件:
- 住民登録要件（取得事業は申請日時点で世帯全員が住民登録済であること、改修事業は当該年度2月末日までに住民登録）
- 交付後3年以上継続して居住する意思
- 世帯全員が市税を滞納していないこと
- 世帯全員が当該補助金及び「岐阜市中心市街地新築住宅取得助成金」の交付を受けていないこと
- 世帯全員が暴力団員等でないこと
- 昭和56年5月31日以前に確認済証を受けた旧耐震の空き家は、耐震工事済または耐震工事実施意思が必要

### 改修事業の補助対象経費・対象外（01）
- 対象: 空き家の改修に係る費用／併設店舗等の住居転用改修費／併設店舗等躯体の改修費
- 対象外: 改築、増築、備品購入、設備整備、外構工事、耐震診断、耐震改修工事、不要物の処分、清掃等
- 改修工事業者は建設業許可業者に限る。交付決定前の契約・着工は対象外。
