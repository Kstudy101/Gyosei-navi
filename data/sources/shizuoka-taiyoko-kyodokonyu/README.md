# shizuoka-taiyoko-kyodokonyu

対象候補記事（未執筆・government-researcher調査段階、最終採用候補）: 静岡市「住宅向け太陽光パネル・蓄電池等の共同購入」（「みんなのおうちに太陽光」キャンペーン）

## 制度の性質に関する重要な注記

このページは静岡市公式サイト内の「環境関連支援制度」一覧に掲載されているが、**制度の実施主体は静岡市ではなく静岡県**（民間企業アイチューザー株式会社との共同購入事業。チラシに「静岡県×iChoosr」と明記、事業サイトURLも `switchtogether.jp/solar-and-battery/shizuoka`）。静岡市は自市の環境関連支援制度の一つとしてこの県事業を紹介・案内しているに過ぎない。
対象は「設置する建物が静岡県内にあれば、どなたでもご参加いただけます」であり、静岡市民限定ではなく静岡県内全域が対象。
記事化する場合はタイトル・本文で「静岡市の制度」ではなく「静岡県が実施し静岡市が案内する共同購入事業（静岡市民も参加可）」である旨を明確にする必要がある。

## 確認されていないこと

- 「参加登録」自体に静岡市在住・県内在住であることの証明書類が必要か（会員登録フォームの詳細は事業サイト `switchtogether.jp/solar-and-battery/shizuoka` 側にあり、市サイト・チラシからは確認できていない）→ unresearched。
- 施工事業者が静岡市内に対応可能な範囲でどの程度存在するか（全国52自治体累計の数値のみで静岡県・静岡市単独の参加実績件数は不明）→ unresearched。
- 「社会情勢の影響による太陽光パネル価格急騰等があった場合には、参加登録の募集を中止します」との注記があり、2026年9月20日時点で募集が継続しているかは本調査時点のスナップショットに過ぎない。記事化時は必ず公式サイトで最新の募集状況を再確認する必要がある。
- 他の自治体の補助金と併用できる「場合がある」とのみ記載があり、静岡市独自の太陽光補助金と併用可能かどうかは明記なし（静岡市には別途「グリーン電力地産地消設備整備事業補助金」があるが、これはPPA事業者向けであり住宅所有者が直接使える補助金ではないため、通常の個人住宅所有者が併用できる静岡市独自の補助制度があるかは本調査では確認できていない）→ unresearched。
