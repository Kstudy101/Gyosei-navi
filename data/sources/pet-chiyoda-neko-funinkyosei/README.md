## ⚠️ 원문에서 확인되지 않은 것

- **犬(개)의 불임거세 수술비 조성금 제도는 원문 어디에도 없다.** 千代田区 공식페이지(동물・펫 카테고리 전체 메뉴 목록에도 犬 관련 항목은 「飼い犬などが死亡した場合には」「犬を飼われている方へのお願い」「狂犬病の予防」등 뿐, 犬 불임거세 조성 항목은 존재하지 않음 — 페이지 하단 관련링크 목록에서 확인). **추측 아님, 목록 부재를 직접 확인한 사실.**
- **飼い猫(사육 고양이)에 대한 불임거세 조성 제도도 원문에 없다** — 제목부터 「飼い主のいない猫」로 한정되어 있으며, 平成30年 이후 방침 변경 여부 등은 千代田区 페이지 자체에 기술이 없어 확인 불가(타 구인 港区・新宿区의 경우 사육묘 제외/포함 방침이 명문화된 것과 대조적).
- 마이크로칩 관련 조성(별도 사업)은 이 페이지에서 언급되지 않음 — 千代田区가 마이크로칩 보조사업을 별도로 하는지는 이번 조사 범위에서 확인되지 않음(불명으로 남김, 없다고 단정하지 않음).
