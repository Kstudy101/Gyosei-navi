## 確定した事実
- 制度名: 福島県奨学資金
- 種別: 貸与型（返還必要）、無利息（延滞時は年10%）
- 対象: 福島県出身者で経済的理由により修学困難と認められる者
- 募集期間（在学採用）: 令和8年4月1日～12月11日（随時募集）
- 震災特例採用あり（原子力災害被災地域で被災した方）
- 貸与額（高等学校・専修学校高等課程）:
  - 国公立・自宅: 18,000円/月
  - 国公立・自宅外: 23,000円/月
  - 私立・自宅: 30,000円/月
  - 私立・自宅外: 35,000円/月
- 貸与額（大学・短期大学・高等専門学校）:
  - 国公立: 35,000円/月
  - 私立: 40,000円/月
  - 高専: 18,000円/月
  - 入学一時金（国公立）: 500,000円
- 返還方法: 卒業6か月後から半年賦（年2回）で全額返還
- 保証人: 連帯保証人（福島県内在住の親権者等）＋保証人（別生計の成年者）
- 申込方法: 在学する学校からの推薦を得て申請
