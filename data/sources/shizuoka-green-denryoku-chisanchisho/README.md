# shizuoka-green-denryoku-chisanchisho

対象候補記事（未執筆・government-researcher調査段階、最終的には不採用＝バックアップ候補として保管）: 静岡市「グリーン電力地産地消設備整備事業補助金」

## 制度の性質に関する重要な注記

本制度は静岡市が交付要綱（静岡市補助金等交付規則に基づく市独自の要綱）を定めて運用する、正真正銘の静岡市固有の現金交付型補助金である（この点は候補2の共同購入事業と異なる）。
ただし補助対象者は「PPA（電力販売契約）により電気を供給する事業者」に限られ、対象事業も「PPAの余剰電気及び環境価値の全てを脱炭素先行地域（清水駅東口・日の出・恩田原片山の3エリア）の需要家に供給する太陽光発電設備を設置する事業」という高度に事業者向け・専門的な制度である。
個人が申請者になれる場合も「市内に住所を有するPPA事業者」であることが要件であり、一般的な「自宅の屋根に太陽光パネルを設置したい個人」が対象ではない。実質的に太陽光発電事業に参入する個人投資家・法人向けの制度と判断される。
また、募集期間（公募期間）の具体的な記載が公式ページ・交付要綱ともになく、「（申請書を）別に定める日までに市長に提出」（交付要綱第7条）とあるのみで、現在申請受付中かどうか本調査では確認できなかった。

## 確認されていないこと

- 令和8年度（2026年度）の公募期間・受付開始/終了日。交付要綱第7条は「別に定める日までに」としているのみで、具体的な公募要領・スケジュールのページが本調査では見つからなかった（サイト内検索・Web検索いずれも該当ページなし）→ unresearched。
- 令和8年度の予算額・予算残額。公式ページ・交付要綱に記載なし→ unresearched。
- 一般の個人（自宅屋根への太陽光設置のみを目的とする住宅所有者）が「PPA事業者」として本制度に申請できる現実的な運用実績があるか（制度上は個人も対象者たりうるが、PPA契約の当事者・環境価値の卸供給という制度設計から見て、実質的には太陽光発電事業を営む法人・個人事業主が主な想定利用者と考えられる）→ unresearched、記事化する場合は必ず「事業者・投資家向け制度」である旨を明記する必要がある。
- `03_koufu-youkou.pdf`（PDF本体23ページ）と`04_koufu-youkou-page.txt`（HTML版条文）の内容の完全一致は逐条確認していない（HTML版で全条文は取得済みのため数値の相互確認には04を優先使用）。
