# 姫路市 飼い主のいない猫不妊手術助成 — 原文アーカイブ

## 制度概要
姫路市内に生息する飼い主のいない猫の不妊手術費用の一部を助成する市独自制度。飼い犬・飼い猫向けの不妊手術助成は行っていない（FAQで明示）。
