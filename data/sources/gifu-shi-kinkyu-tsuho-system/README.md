## 확인되지 않은 것

- 월액 이용료・보수 유무의 별도 금액표 — 원문은 설치비 무료・전화요금 자기부담만 명시. 월정액 이용료 유무는 원문에 없음 → 기사에서 단정하지 않음.
- 「ひとり暮らしに準ずると認められる人」「高齢者のみの世帯等」의 세부 판정 기준 — 원문에 열거 없음.
- 위탁 수신센터 사업자명・연락처 — 원문・PDF 도식에 명시 없음(또는 PDF 도식만).
- 접수 중단・예산 도달 여부 — 원문에 모집기간・예산도달 표기 없음(상시형으로 보이나 `ongoing` 판단은 원문 표현에 따름).
- 紙おむつ支給・家族介護慰労金 등 현금・현물 급부형 시 독자 제도 — 이번 스카우트에서 공식 「生活支援サービス」・「高齢者・介護」인덱스상 확인되지 않음(미조사와 미시행을 구분할 수 없으므로 단정하지 않음). 대안 후보로 はり・きゅう・マッサージ施術料助成・福祉器具給付事業은 별도 URL로 존재 확인만 함(본 슬러그 범위 밖).
