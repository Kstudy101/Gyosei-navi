## 確認できた核心情報

### 給付内容
- **出産応援給付金（妊婦支援給付金1回目）**: 妊婦1人あたり **5万円**
- **子育て応援給付金（妊婦支援給付金2回目）**: 妊娠した胎児1人あたり **5万円**

### 制度変更（令和7年4月1日〜）
- 令和7年3月31日までは旧「出産・子育て応援給付金」。令和7年4月1日以降は「妊婦のための支援給付」として国の法律に基づく制度に移行
- 旧制度での申請期限を過ぎた場合も新制度での扱いについては市に確認

### 対象者
**出産応援給付金（1回目）**: 申請時点で宮崎市に住民票があり、医師により胎児の心拍の確認がされた妊婦
**子育て応援給付金（2回目）**: 申請時点で宮崎市に住民票があり、令和7年4月1日以降に出産した産婦

### 申請期限
- 1回目: 医師による心拍確認日から2年以内
- 2回目: 出産予定日の8週間前から2年以内

### 留意事項
- 他自治体で同給付金を既に受けていない方が対象（転入者注意）
- 流産・死産・人工妊娠中絶・乳児死亡の場合も対象
