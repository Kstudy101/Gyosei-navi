## 制度概要

公益財団法人広島市産業振興センター（中小企業支援センター）が実施する創業支援。有望な事業計画に対し、専門家による計画策定・実行支援と、広島市制度融資「創業チャレンジ・ベンチャー資金」（限度額3,500万円・年0.5%）を組み合わせる。令和8年度第3回応募期間は令和8年9月7日〜10月16日（17:15まで）。
