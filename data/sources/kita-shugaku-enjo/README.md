# kita-shugaku-enjo — 東京都北区 就学援助

取得日: 2026-09-22
対象: 東京都北区（総務省コード 13117 / slug: kita）。大阪市北区（27127 / kita-osaka）ではない。

## 制度概要

- 制度名: 就学援助
- 実施主体: 東京都北区（教育委員会事務局教育振興部 学校支援課 学事係）
- 類型: 要保護・準要保護世帯向けの義務教育費援助（現金支給中心）
- 対象: 北区内に住民登録がある、国公立の小・中・義務教育・中等（前期）・特別支援（小・中学部）の児童生徒の保護者。生活保護受給、児童扶養手当受給、総所得が認定基準未満、または特別事情で教委が認めた世帯。私立は対象外。
- 通常申請期限: 令和8年4月30日（木）。以降も随時だが認定は申請月から。R7認定者はR8は自動審査（否認定・取消は再申請必要）
- 電子申請（新規）: https://logoform.jp/form/VNHo/1411973
- 公式ページ: https://www.city.kita.lg.jp/children-edu/schools/1003980/1003981.html （更新日 2026年4月6日）

## 根拠にした主な数値（原文対照）

### 所得目安（公式ページ・お知らせ PDF / 英語版）

| 世帯人数 | 構成例 | 年間収入額（給与）目安 | 総所得金額目安（R7.1.1〜R7.12.31） |
|---|---|---|---|
| 2人 | 親33歳・子小1 | 約458万円 | 約313万円 |
| 3人 | 親37・32歳・子小1 | 約501万円 | 約347万円 |
| 4人 | 親40・34歳・子中1・小3 | 約597万円 | 約424万円 |
| 5人 | 親50・45歳・子高2・中3・小4 | 約647万円 | 約464万円 |
| 6人 | 親42・35歳・子中1・小3・祖父母70・65歳 | 約692万円 | 約503万円 |

- 給与所得のみ: 源泉「給与所得控除後の金額」から10万円控除した額が総所得
- 事業所得: 収入から必要経費等を差し引いた額

### 新入学児童生徒学用品等購入費（入学前支給・公式ページ）

- 小学校: 91,600円（結果送付 R8年3月上旬、支給日 R8.3.13予定）。申請期間 R7.12.1〜R8.1.30
- 中学校（小6で既認定・国公立進学予定）: 101,000円（同支給日）。追加申請不要。私立進学可能性・進学先不明は対象外

### 申請・支給の運用

- 通常期限: 令和8年4月30日。転入者は転入日の翌月末
- 認定結果: 6月下旬に住民登録地の世帯主へ郵送（途中申請は1〜2ヶ月程度）
- 区立在籍: 振込は年5回。区外校在籍: 原則3月に1回（英語お知らせ）
- 区立は保護者負担軽減事業対象費目（給食費・宿泊校外・夏季施設・修学旅行・特支宿泊）は就学援助からは支給なし
