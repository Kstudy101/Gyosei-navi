## 確認されていないこと / 原文間の差異

- **パンフレットPDF（02）のエコジョーズ＋コレモ上限は「50万円」と記載**されているが、公式HTML（01）および交付要綱別表1（03）はいずれも「上限90万円」。記事の数値は要綱・HTMLを正本とし、パンフレットは旧記載の可能性があるため採用しない。
- 予算総額・想定件数の公式数値は原文に見当たらない（予算到達で終了とだけ記載）。
- エコジョーズ単独・コレモ単独での申請可否は、要綱別表が「エコジョーズ＋コレモ」と一体表記のため単独可否は未確認。
