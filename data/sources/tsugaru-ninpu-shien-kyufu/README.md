## 核心数値（原文対照）

出典は特記なき限り `01_ninpu-shien-kyufu.txt`（`02` と同一本文）。

| 項目 | 原文の記載 |
|---|---|
| 制度 | 妊婦給付認定を受けた方に「妊婦支援給付金」を支給。「妊婦のための支援給付」は面談や家庭訪問などと一体実施 |
| 1回目 | 妊娠届出後／妊婦一人あたり **5万円**。妊娠届出時に申請書を交付 |
| 2回目 | こども（胎児）の数の届出後／妊娠しているこども一人あたり **5万円**（流産・死産等含む）。出産後の面談（家庭訪問等）時に申請書を交付。出産前希望なら出産予定日の8週間前の日から申請可 |
| 1回目申請期限 | 医療機関で胎児の心拍確認が確認された日から2年以内 |
| 2回目申請期限 | 出産予定日の8週間前の日（流産・死産等はその日）から2年以内 |
| 支給方法 | 支給対象者（妊婦さん本人）の口座に振込。申請書類受理日から概ね1か月程度 |
| 必要書類 | 申請書、本人確認書類（運転免許証・マイナンバーカード等）、振込確認書類（通帳・キャッシュカード等）。2・3は写しも必要 |
| 転入 | 他市区町村で1回目認定済みでもつがる市で再申請が必要。転入手続き時に母子健康手帳を持参し子育て健康課へ |
| 流産・死産等 | 流産・死産・人工妊娠中絶等も対象。母子健康手帳で事実・胎児数を確認。届出前の場合は医師の胎児心拍確認診断書等が必要。「妊婦支援給付担当」へ連絡 |
| 対象時期 | 令和7年4月1日時点で妊娠されている方および令和7年4月1日以降に妊娠された方 |
| 二重支給禁止 | 同一妊娠で他市区町村から支給済みの場合は対象外。転入者で未支給なら対象 |
| 旧制度注記 | 令和7年3月31日までに出生した子がいる養育者には子育て応援給付金が支給される旨の記載あり（本記事の主制度ではない） |
| 窓口 | 健康福祉部子育て健康課（こども家庭センター）／〒038-3192 青森県つがる市木造若緑61番地1（市役所1階）／0173-42-2111（代表）／FAX 0173-42-3946 |
