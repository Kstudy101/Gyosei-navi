## ★ 기사 초안 검수 시 반드시 반영할 차이점 (2026-08-17 확인)

1. **締切은 「9月4日 0時0分」** — 마스터 플랜·기사 초안 2건의 「9月4日24時」는 오기. 실질 마감은 **9月3日 중**. 기사에서는 「9月4日0時（＝9月3日いっぱい）」로 명기할 것.
2. **적용 시기**: 「令和9年4月から（**収入に関する要素は本年10月施行**）」 — 연수입 요소는 **2026年10月** 선행 시행. 초안의 「2027年4月施行見込み」만으로는 부정확 → 2단계 시행으로 수정.
3. 개요에 명시된 포인트 중 초안 표에 없는 것: ①「永住者」의 위치 부여(「特に慎重な審査」 최초 명기) ② 国益要件「積極的かつ具体的に…利益をもたらす必要」 ③ 独立生計要件不要な類型(배우자·자녀·난민 등)도 公共負担 우려가 현실적이면 消極評価 ④「我が国の制度等の理解」가 부족하면 消極評価.
4. 개요에는 「実子 1年→3年」 언급 없음 → 본문(02) 원문에서 확인 후 표에 남길지 결정.
