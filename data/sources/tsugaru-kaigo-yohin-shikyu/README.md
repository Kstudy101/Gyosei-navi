## 確認できた主要事実（原文02が一次根拠。原文01は同PDFへの案内ページ）

### 制度名
- 介護用品支給事業（原文02「つがる市の高齢者福祉サービス」一覧表内の事業名）

### 対象（原文02）
- **65歳以上の要介護度4・5で非課税世帯の方を在宅で介護している方**

### 支給内容（原文02）
- 【支給用品】紙おむつ、尿取りパッド、使い捨て手袋、清拭剤、ドライシャンプー、口腔ケア用綿棒、とろみ剤
- 【年額】1人 **70,000円**まで
- 【料金】無料

### 問い合わせ（原文01・02）
- つがる市健康福祉部介護課（代表 0173-42-2111）／〒038-3192 青森県つがる市木造若緑61番地1（市役所1階）
