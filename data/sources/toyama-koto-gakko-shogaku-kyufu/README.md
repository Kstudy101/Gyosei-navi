## 기사화 대상 결론

**국공립 페이지(`01_kokukoritsu.txt`)를 1차 근거로 채택한다.**

이유:
- 국공립 페이지는 소득구간별 **실제 급부액 표**(전일제/정시제/통신제/전공과별, 엔 단위)를 명시하고 있어 기사에 구체적 수치를 인용할 수 있음.
- 사립 페이지는 소득구간별 **대상 요건(구분 1~5)만** 나열되어 있고, 급부액 자체는 원문에 표기되어 있지 않음(PDF 리플렛에만 있을 가능성 — 이 페이지 텍스트만으로는 사립 급부액을 인용할 수 없음).
- 두 제도 모두 소득기준(주민세 비과세/소득할합산액 구간)은 사실상 동일 체계이므로, 기사 본문에서는 국공립 표를 메인으로 쓰고 "사립고는 동일한 소득구간 체계를 적용하되 급부액은 학교 통해 확인" 식으로 보완 언급하는 방식을 권장.

두 원문 모두 저장했으므로, 사립 급부액이 필요할 경우 PDF 리플렛(`リーフレット(通常申請分)`)을 추가로 다운로드해야 함 — 이번 조사에서는 HTML 텍스트만 취득, PDF는 미다운로드.
