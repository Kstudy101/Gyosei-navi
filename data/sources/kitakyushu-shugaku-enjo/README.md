## 確認できた最終数値・条件（01）

### 対象学校
北九州市立小・中学校及び福岡県立中学校への就学が困難と認められる児童生徒の保護者（生活保護世帯に準ずる程度に経済的に困窮している世帯）。

### 対象となる方（申請理由1〜10）
1. 生活保護が廃止又は停止になった方
2. 世帯全員が市民税の非課税又は減免の取扱いを受けている方
3. 個人事業税の減免を受けている方
4. 固定資産税の減免を受けている方
5. 国民年金の掛金の減免を受けている方
6. 国民健康保険料の減免又は徴収の猶予を受けている方
7. 児童扶養手当を受けている方
8. 生活福祉資金の貸付を受けている方
9. 職業安定所登録日雇労働者である方
10. 上記1〜9に当てはまらないが経済的に困窮している方（令和7年の年間所得合計額が認定基準額以下）

### 認定基準額の目安（理由10・総所得）
| 世帯人数 | 総所得（認定基準額）目安 | 総収入額目安 |
|---|---|---|
| 2人 | 約192万円 | 約286万円 |
| 3人 | 約256万円 | 約375万円 |
| 4人 | 約299万円 | 約429万円 |
| 5人 | 約330万円 | 約468万円 |

※目安。超えても認定される場合・以下でも不認定の場合あり。該当可否の電話照会には応じない旨が原文に明記。迷う場合は申請提出を案内。

### 令和8年度 援助内容・金額（4月申請の場合／「予定」と原文表記）
| 費目 | 小学校 | 中学校 |
|---|---|---|
| 学用品費等 | 1年 13,230円／2〜6年 15,500円 | 1年 25,040円／2・3年 27,310円 |
| 新入学学用品費 | 1年 64,300円 | 1年 81,000円 |
| 学校給食費 | 支給なし（保護者負担軽減事業により保護者負担なし） | 対象経費の実費 |
| 修学旅行費 | 対象経費の実費 | 同左 |
| 宿泊を伴う校外活動費 | 交通費・見学料の実費（限度額 3,690円） | 同（限度額 6,210円） |
| 通学費 | 片道4km以上・公共交通・実費 | 片道6km以上・公共交通・実費 |

- 新入学学用品費の申請期限: 原則4月末。学校申請に限り5月末受付分まで支給。入学前支給受給者は対象外。
- 申請: 4月から随時。申請月分から支給。学校申請で5月末までなら年度当初から扱いにできる。
- 支給金は学校へ振込し、校納金の支払いに充当。
- 毎年度申請が必要。小・中両方に通学する場合は両校へ提出。
- 区役所（子ども・家庭相談コーナー）でも申請可だが、学校申請を推奨。

### 入学前支給（03・04）
- 対象: 令和8年4月に市立小中（特別支援学校除く）・福岡県立中学校へ入学予定で、申請時北九州市居住の保護者。
- 申請時期（原文）: 令和7年12月1日〜令和8年1月30日（この期間は2026-09-21時点で終了済み）。
- 金額: 小学校入学予定 64,300円／中学校入学予定 81,000円。
- PDF記載の当初締切は令和7年12月19日、入学しなかった場合は返還。
