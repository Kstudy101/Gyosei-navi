## 制度類型

- **現金（口座振込）・費目別援助型**（学用品費等は定額、給食費・修学旅行費等は実費）。学校集金の全額免除ではない（02原文）。
- 国の就学援助の枠組みを市が実施する市制度（要綱あり）。国家制度の単独紹介ではない。
