## 制度概要（現物給付型）
市内在宅の要支援・要介護認定者のうち、寝たきり（主治医意見書の寝たきり度B1以上）または認知症症状（認知度3a以上）がある方に、委託業者が紙おむつ等を月1回配達する現物給付事業。

## 対象者（1〜3すべて該当）
1. 立川市に住民登録があり市内在宅（有料老人ホーム・グループホーム・サ高住も含む）
2. 介護保険法の要支援・要介護認定を受けている
3. 寝たきり度B1以上、または認知度3a以上

※入院中・施設入所（老健・特養）の方は対象外。

## 支給内容・自己負担
- 月1回、委託業者がフラット型おむつ・尿吸収パッド・紙パンツ等から配達
- 1か月分費用の1割が自己負担
- 自己負担の上限額: **5,000円**（超過分は全額自己負担）
- 令和8年4月からおむつの単価変更予定（原文に記載、詳細はPDF「令和8年度給付商品一覧表」等）

## 申請方法
- 「高齢者おむつ給付助成申請書」「高齢者おむつ給付助成申込書兼変更届」を提出
- 受付窓口: 高齢政策課業務係（市役所1階）、各地域包括支援センター、各福祉相談センター
- 締切日: **毎月15日**（土日祝の場合は翌営業日）。締切後の申請は翌々月以降の配達
- 給付可否は「高齢者おむつ給付助成決定通知書」等で通知
- 立川市以外で介護認定を受けた場合は別途書類が必要（要問い合わせ）
