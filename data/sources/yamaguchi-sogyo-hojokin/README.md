## 原文根拠表

| 項目 | 内容 | 根拠 |
|---|---|---|
| 対象者 | 事業を営んでいない個人で、新たに事業を開始する者、または新会社を設立してその代表者となる者。県内居住または補助事業完了日までに県内居住、県内で開業届/法人登記。交付決定日以降～事業期間完了日までに開業届または設立を行うこと。県税滞納なし、みなし大企業でない、性風俗関連営業等でないこと 等 | 06 公募要領 p.2-3「(4)補助対象者」①～⑨／07 要綱 第4条 |
| 対象事業 | 「やまぐち未来維新プラン」関連の指定分野（31分野）の社会的事業の創業。社会性・事業性・必要性・デジタルの活用を全て満たすこと | 06 p.2「(2)対象」／別紙 |
| 補助率 | 1/2（要綱は「1/2以内」） | 06 p.2「(3)補助率等」／07 第3条2項／01 |
| 補助上限額 | 200万円（2,000千円） | 06 p.2／07 第3条1項／01・04 |
| 事業期間 | 交付決定日から令和9年2月末まで | 06 p.2／01 |
| 採択件数 | 11件程度（うち4件程度は三大都市圏の在住者等が対象）。申請状況で変更あり | 06 p.2／01（「11件程度」） |
| 対象経費 | 人件費、店舗等借料、設備費、原材料費、借料、知的財産権等関連経費、謝金、旅費、マーケティング調査費、広報費、外注費、委託費、その他 | 06 p.3-4／07 別表1 |
| 対象外経費（主なもの） | 交付決定日前発生経費、通信運搬費・光熱水費、消費税、汎用PC・タブレット、土地建物購入・新築・増築、中古品、車両購入（艤装した移動販売車等を除く）、事務所の敷金・保証金 等 | 06 p.4-5 |
| 人件費の留意点 | 従業員は県内在住、正規は月額35万円上限、パート・アルバイトは日額8,000円上限。代表者・役員、個人事業主本人と三親等以内親族の人件費は対象外 | 06 p.10-11 |
| 公募期間 | 令和8年4月30日（木）～6月18日（木）当日消印有効。原則郵送 | 06 p.5-6／01／04 |
| 申請前の事前連絡 | 申請前に電話またはメールで事前連絡が必要 | 06 p.5「注意事項」 |
| 提出書類 | 補助事業計画書（様式1表紙・様式2事業計画書：A4片面20枚以内・見積書等）、参考書類（住民票＝申請時点のもの、他） | 06 p.5-6 |
| 審査 | 書面審査（応募多数時は事前審査）＋プレゼンテーション審査（山口市内開催予定）。審査項目: 社会的事業、独創性、計画の明確性、実施体制、雇用創出・地域貢献 | 06 p.6-7 |
| 流れ（令和8年度予定） | 7月上旬 審査委員会・プレゼン／7月中旬 採択者決定／7月中旬～8月上旬 事務処理説明会／7月下旬～8月上旬 交付申請・交付決定・補助事業開始／3月10日迄 実績報告／3月上旬～中旬 完了検査／3月中旬 精算払請求／3月下旬 補助金支払。中間検査・現地視察あり | 06 p.7-8「７ 各種スケジュール」／01「7月上旬～中旬 審査委員会、採択者決定」 |
| 交付決定 | 採択通知は交付決定通知ではない。採択後に別途交付申請し、減額して決定されることがある | 06 p.5「３ 補助金の交付」／07 第5-6条 |
| 実績報告 | 事業完了日から10日経過日または3月10日のいずれか早い日までに実績報告書 | 06 p.9／07 第9条 |
| 事後義務 | 完了後5年間、毎会計年度終了後の事業化状況報告、書類5年保存、単価50万円以上財産の処分承認 等 | 06 p.9／07 第12-16条 |
| 申請先・問い合わせ | 〒754-0041 山口市小郡令和一丁目1番1号 公益財団法人やまぐち産業振興財団 経営企画部 Tel 083-902-3711 / Fax 083-902-9010 / keiei@yipf.or.jp（平日8:30～17:15） | 06 p.6, p.9／01／04 |
| 県側窓口 | 経営金融課経営支援班 〒753-8501 山口市滝町1番1号 Tel 083-933-3180 | 01 |
| 移住支援金 | 東京圏・中京圏（愛知）・近畿圏（京都・大阪・兵庫）・広島県・福岡県の在住者等が交付決定を受けた場合、別途移住支援金を申請できる場合あり（在住年数等の要件あり。詳細は移住予定の市町へ） | 01 「1 補助対象者」注記／06 p.5 |
| 制度趣旨 | 人口減少の克服に向け、社会的事業の創業を支援し県内中小企業数の減少を食い止める | 06 p.2 |
