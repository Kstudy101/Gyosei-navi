## 対象制度
- 制度名: 市営交通料金(市バス、地下鉄)の軽減 / 福祉特別乗車券の交付（および市バス・地下鉄料金の割引）
- 所管: 名古屋市 健康福祉局 障害福祉部 障害企画課（企画担当 TEL 052-972-2585／運賃支給関連・福祉担当 TEL 052-972-2587）／福祉特別乗車券コールセンター 052-766-6656

## 確認できた核心情報（原文一致）

### 福祉特別乗車券（01 / 02 / 03）
- 無料乗車区間: **市バス（メーグル含む）、地下鉄、あおなみ線、ゆとりーとライン** — チャージ不要で無料
- 運賃支給対象区間: **名鉄・JR東海・近鉄の鉄道の市内運行区間**、**名鉄バス(SRT含む)・三重交通の路線バスの原則市内運行区間**。特例: 稲葉地町〜大治西条、諸ノ木〜藤田医科大学病院
- 運賃支給区間では事前チャージが必要。2か月に1回集計し指定口座へ振込。臨時乗車証は運賃支給区間では利用不可
- 交付対象（本市住民）: 身体1〜4級／愛護1〜4度／精神1〜3級／特定医療費受給者証（指定難病）で日常生活が著しい制限を医師証明され福祉医療費助成（障害者医療・福祉給付金）受給中の方
- 介護者券: 身体1・2級又は3・4級の第1種／愛護1〜3度／精神1〜2級。本人と同乗時のみ有効
- 通用期間（しおり）: **令和8年10月31日まで**
- 申請: 区役所福祉課又は支所区民福祉課。申請書・障害者手帳
- 福祉タクシー利用券・リフト付タクシー利用券・敬老パス等との**選択制**（02）

### 市バス・地下鉄料金の割引（手帳提示・02）
- 対象: 身体1〜6級、愛護（療育）手帳、精神障害者保健福祉手帳交付者
- 例（しおり掲載・改定あり得る）: 市バス大人210円→100円、地下鉄1区大人210円→100円 など
