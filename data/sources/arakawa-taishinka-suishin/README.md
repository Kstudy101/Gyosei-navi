## 확인되지 않은 것

- **접수 마감일(periodEnd)**: 원문에 연간 접수 마감・예산소진 조기종료의 명시적 날짜 없음. periodEnd는 기사에 넣지 않음.
- **令和8年度 예산액・잔액**: 미기재.
- **要綱 전문(조문 PDF)**: 안내용 팸플릿・웹 표만 확보. 워드 요강양식집은 다운로드하지 않음(수치 근거는 팸플릿・공식표로 충분).

- **긴급수송도로 연도 건물 제도의 증액 상세**: 별도 제도. 이번 기사의 본문은 아님(링크로만 언급).

## 제도 유형

현금보조형（진단→설계→공사 단계형）. 木造는 旧耐震+新耐震(在来軸組) 모두, 非木造는 旧耐震. 고령자・장애인 한도 2배 우대 있음.
