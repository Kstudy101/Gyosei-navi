# 札幌市 産後ケア事業（宿泊型・日帰り型・訪問型）

## 制度分類
現物給付型（サービス利用料の公費補助＝自己負担額を軽減する形）。現金給付ではない。市が委託する産後ケア施設で助産師等のケアを受け、利用者は表の自己負担額を施設に支払う仕組み。上限回数を超えた利用は助成対象外となり、施設が定める料金の全額自己負担となる。

### 利用回数の上限
根拠: `01` L102-114、`02` 1頁
- 宿泊型・日帰り型: 合わせて**7日以内**（1泊2日の利用は2日間とカウント）
- 訪問型: **6回以内**（訪問型だけでカウント）
- 上限を超えて利用する場合は助成対象外となり、上記料金は適用されない（`01` L104／`02` 1頁「上記利用料金を超えて利用する場合は、施設が定める料金を支払う必要があります」）

### 申請・予約方法（令和8年3月〜）
根拠: `01` L120-152、`02` 2頁のフロー図
- 令和8年3月より産後ケア予約サービス「テオテ産後ケア」（https://postnatal-care.teote.jp/）による申込を開始。令和7年度と申込方法が異なる（`01` L122）
- 流れ: アカウント作成 → 妊娠・出産情報を入力し札幌市へオンライン利用申請（**妊娠28週から**申請可） → 市の承認通知メール（審査に数日） → テオテにログインして施設登録・予約 → 利用（利用後アンケート）
- 「あずかるこちゃん産後ケア」は令和8年4月1日より「テオテ産後ケア」に名称変更。既存利用者は再手続き不要（`01` L136）
- 市の承認前の利用は助成適用されず全額自己負担（`01` L140）
- 予約は利用希望日の**30日前から**開始（施設により異なる場合あり）。一度に予約できるのは**2回分まで**。妊娠中の予約は不可（`01` L144）
- 訪問型は対応エリア限定の場合あり（`01` L146）
- キャンセル: **前営業日（平日）の午前10時まで**。以降の中止は施設へ利用料金を支払う（`01` L148／`02` 2頁）
