## 確認結果

- PDF 1ページ目（北海道セクション）に以下の記載を確認:
  `012351　北海道　石狩市　ホッカイドウ　イシカリシ`
- 検査数字込み6桁の団体コードは **012351**。
- 既存登録慣行（札幌市 011002→01100 のように、末尾の検査数字1桁を除いた5桁を採用。ただし石狩市は011002ではなく012351のため、検査数字を除いた5桁は **01235**）に従い、石狩市は **`01235`** として登録する。
- slug は道内で既に `sapporo`（札幌市）が `src/config/regions.ts` に登録済みのため、同様のパターンで **`ishikari`** または政令市以外の慣行（さいたま市等ではなく岡山市・青森市のような一般市）に倣い **`ishikari-shi`** のいずれかを orchestrator/writer 側で選定する必要がある。石狩市は政令指定都市ではないため、市全体を1エントリとして登録する。
- 北海道としては札幌市（01100、既存登録）に続き2件目の市区町村登録となる。
