# 大阪市住宅省エネ改修促進事業（都市整備局）— 一次情報 원문

> 취득일: 2026-09-20 / 대상: 大阪市 전체 공통 제도(東淀川区 거주자도 이용 가능) / 용도(예정): `content/subsidy/jutaku/osaka-shi-shoene-kaishuu.mdx`

## 대상 지역 관련 메모

東淀川区(총무성코드27114, slug: higashiyodogawa)는 정령지정도시 大阪市의 행정구로 독자 예산권이 없음. 본 제도는 大阪市 都市整備局이 시 전체 공통으로 운영하며, 東淀川区 거주자를 포함한 大阪市 전역의 대상주택 소유자가 이용 가능. 東淀川区 홈페이지 독자 안내는 확인하지 않았음(시 공통제도이므로 필수 조사 대상 아님 — 필요 시 추후 municipality-researcher로 보완 가능, 현재 미실시).
