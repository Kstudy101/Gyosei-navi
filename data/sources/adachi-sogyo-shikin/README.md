## 제도 유형 분류

**融資あっせん型（利子補給＋信用保証料補助の併用）**。区が現金を直接交付する制度ではなく、区が契約する金融機関からの借入に対し、①利子補給（申告前2.9%、申告後は貸付利率の3分の2・上限1.9%）と②信用保証料補助（保証料の3分の2、上限50万円）の2種類の補助を組み合わせる方式。融資限度額（1,000万円/特定創業支援認定事業者2,000万円）自体は区が直接貸すのではなく、区のあっせんにより取扱金融機関が実行する。
