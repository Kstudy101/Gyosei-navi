## 確認できた数値・事実（原文一致）

- 補助額（別表第1・公式ページ・チラシ一致）:
  - 蓄エネルギー機器（蓄電池又はV2H）新設: **6万円**
  - ZEH化: **15万円**
  - 居住誘導加算: **5万円**
  - 断熱改修: **15万円**
  - 断熱改修（窓のみ）: **5万円**
- 上限ルール: 補助対象経費合計から国の補助合計を差し引いた額の**2分の1**が上限（**1000円未満切捨て**）
- 予算枠（別表第2）: 蓄エネ80件 / ZEH化60件 / 断熱改修50件 / 窓のみ50件
- 対象: 個人のみ（法人対象外）。市税滞納なし。市内住所・自ら居住予定の住宅。契約・支払いを行う者（同一世帯含む）
- スマートハウス枠: 蓄エネ機器＋住宅用太陽光の両方が必要（太陽光の新設・既設は問わない）。自家消費型太陽光補助金との蓄電池併用不可
- 断熱リフォーム枠: 国の断熱リフォーム支援事業または先進的窓リノベ事業の補助が必要。ZEH化との併用不可
- 予約申請期間（要綱附則）: **令和8年5月20日〜令和8年7月31日**／交付申請期限: **令和9年3月31日**
- 公式ページ更新日 **2026年8月14日**: 「今年度の予約申請の受付は終了いたしました。」→ 記事 `subsidy.status: closed`
