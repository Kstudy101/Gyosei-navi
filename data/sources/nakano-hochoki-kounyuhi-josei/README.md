## 制度概要（現金助成型）
加齢性難聴の高齢者を対象に、補聴器購入費用の一部を助成。**交付決定を受けてから購入した補聴器のみが対象**（購入済み補聴器は対象外、原文タイトルにも明記）。

## 対象者（L54-62）
以下すべてに該当する方
- 中野区の住民基本台帳に登録されている65歳以上
- 世帯全員の前年（1～6月申請は前々年）合計所得金額が350万円未満（世帯内に住民税・所得税未申告者がいる場合は助成不可）
- 中等度難聴（40dB以上70dB未満）と診断、または中等度に該当しないが耳鼻咽喉科医が装用必要と認めた方
- 除外：高度・重度難聴で障害者総合支援法の補装具費支給を受けられる方／過去5年以内に本事業の助成を受けた方（装用する耳が異なる場合は対象となることがある）

## 助成額（L72-75）
- 片耳：**上限45,000円**
- 両耳（医師が両耳装用必要と認めた場合）：**上限90,000円**

## 対象費用（L64-70）
補聴器本体（イヤモールド含む）購入費のみ。診察料・検査料・意見書文書料・修理費・付属品費は対象外。

## 申請の流れ（L77-124）
1. 申請書・医師意見書入手（区役所・地域包括支援センターまたはダウンロード）
2. 耳鼻咽喉科受診、医師意見書に検査結果添付（受診費・意見書文書料は自己負担、不助成でも返金なし）
3. 受診日から**3か月以内**に申請書・医師意見書・見積書（認定補聴器技能者在籍店舗発行）等を郵送/窓口/インターネット（LoGoフォーム）で提出
4. 交付決定通知
5. 交付決定後に認定補聴器技能者在籍店舗で購入、約4週間のアフターフォロー実施・記録
6. 購入店アフターフォロー終了後、請求書類（領収書は交付決定日以降の日付）を提出。**請求期限は交付決定日から1年以内**。振込は口座振替
