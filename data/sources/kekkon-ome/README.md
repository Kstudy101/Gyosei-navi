# 青梅市「おふたりOmeでとう！お祝い金等」 — 一次情報 원문

> 취득일: 2026-09-20 / 용도: `kekkon`(結婚) 카테고리 cluster 기사(실시 자치체 사례) 집필용 기초조사
> 소관: 青梅市 地域経済部 シティプロモーション課（東京都）

## ⚠️ 매우 중요 — 제도명 불일치 발견

こども家庭庁 令和7年度 활용상황 PDF(`data/sources/kekkon-shinseikatsu-shien/05_r7_tokyo.pdf`)에는
青梅市가 「**結婚新生活スタートアップ応援事業**」（총사업비434만엔・교부금소요액217만엔・보조율1/2）을
実施한다고 기재돼 있다（令和7年5月29日 시점）。

그러나 이번에 青梅市 공식 사이트에서 실제로 취득한 원문은 이 이름이 아니라
「**おふたりOmeでとう！お祝い金等**」（お祝い金＋くらし応援金의 2단구조）이며, 교부요강(02번 파일)에는
**令和7年4月15日부터 시행**한다고 명기돼 있다. 두 제도는 다음과 같이 성격이 다르다:

- こども家庭庁 PDF가 가리키는 것으로 추정되는 국가교부요건형（부부39세이하・소득500만엔미만 등 조건형, 家賃・引越費用等 실비보조）
- 실제 확인된 「おふたりOmeでとう」（**연령・소득 상한요건 없음**, 정액お祝い金2.2万円＋조건부応援金10万円+가산최대50万円, **파트너십 관계도 대상 포함**）

**원문상 이 둘이 동일 사업인지, 아니면 令和7年度 도중 제도를 완전히 개편(폐지→신설)한 것인지는
이번 조사에서 확정할 수 없었다.** 「おふたりOme」 요강(02번 파일) 자체에는 こども家庭庁 교부금과의
관계에 대한 언급이 없다（立川市 페이지와 달리 재원출처를 명시하지 않음）. 기사 작성 시 이 불일치를
반드시 명시하고, 청매시에 직접 확인 문의가 필요하다고 안내할 것.

## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **こども家庭庁 교부금 PDF상의 「結婚新生活スタートアップ応援事業」（총사업비434만엔, 令和7年5月29日시점）과 「おふたりOmeでとう」（令和7年4月15日 시행）의 관계**: 시행일이 겹치는 것으로 보아 후자가 전자를 대체했거나 확대개편한 것으로 추정되지만, **원문 어디에도 이 계승관계를 명시한 문구가 없다**. 구요강 원문을 확보하지 못해(404) 두 제도의 금액・요건을 직접 대조할 수 없었다.
- **「おふたりOmeでとう」가 こども家庭庁 교부금(국비)을 재원으로 하는지, 순수 시 독자재원인지**: 요강 원문에 재원 출처 언급 없음. 연령・소득상한이 없다는 점에서 こども家庭庁의 국가교부요건(39세이하・소득500만엔미만)과는 다른 설계로 보이나, 이는 추정이며 확정 아님.
- 파트너십 관계자의 구체적 재류자격 판정 기준의 실무 적용례는 원문에 조문만 있고 사례는 없음.
