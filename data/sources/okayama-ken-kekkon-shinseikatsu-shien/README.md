## 県ページ（01_pref.txt）で確認した事実

制度類型: **案内型 + 市町村実施**。県ページは概要・共通上限額・実施市町村一覧・問合せ先を載せる。実施主体は各市町村。「対象世帯、対象経費、上限額は実施市町村によって異なります」と明記。

| 항목 | 原文 |
|---|---|
| 対象世帯 | 世帯所得500万円未満、夫婦ともに婚姻日時点で39歳以下の新規婚姻世帯 |
| 対象経費 | 住宅取得・住宅賃借・リフォーム・引越 |
| 上限額（県ページ記載の目安） | 夫婦とも29歳以下60万円 / それ以外30万円 |

### topics-db note との差異

- note「29歳以下60万/30-39歳30万、所得500万未満」: 県ページの目安と一致。ただし市町村により異なる（赤磐市・真庭市は所得600万円未満、新見市は上限80万/40万、真庭市は世帯類型ごとに別上限）。
- note「パワーアップ+20万/+10万」: 原文は「上乗せ」ではなく、**県が市町村の独自事業経費を支援する際の対象世帯あたり上限 20万/10万**（対象経費に家電・家具を含む、所得要件の記載なし）。「県が住民に直接20万上乗せ」ではない。→ 原文に従い「市町村向けの財政支援。世帯への上乗せ額は市町村ごと」と表現すべき。
- note「18市町村」: 一致（県ページ一覧が18）。

### 制度類型の違い（記事化時の注意）
- 玉野・井原・高梁: 県標準型（60万/30万、所得500万未満、39歳以下）。
- 新見: 上限を拡大（80/40）し家電・家具も対象 → パワーアップ活用型。
- 赤磐・真庭: 所得600万未満に緩和、真庭は経費類型別の上限と50歳未満まで拡大 → 横並びでない。
- 美作: 対象経費が賃借・引越のみ。年齢表記が「29歳以下」でなく「30歳未満」。
- 共通: R8から講座受講等（ライフデザイン講座・プレコンセプションケア等）が必須要件（玉野・井原・高梁・新見・赤磐・真庭・美作で確認）。
