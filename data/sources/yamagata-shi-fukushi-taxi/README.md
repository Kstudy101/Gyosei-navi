## 確認できた情報
- 普通タクシー利用券（金額）: 「1枚あたり500円の券を、1年あたり24枚交付（年間12,000円相当）」
- 普通タクシー利用券（視覚障がい1級の場合）: 「1年あたり36枚交付（年間18,000円相当）」
- 普通タクシー利用券（対象者）: 「身体障がい者手帳1～3級、療育手帳A判定、精神障がい者保健福祉手帳1～3級」
- リフト付タクシー利用券（金額）: 「1枚あたり大型車2,870円、普通車2,450円の券を1年あたり24枚交付」
- リフト付タクシー利用券（対象者）: 「身体障がい者手帳所持者のうち、下肢、体幹、移動機能障がいの個別等級が1・2級の方」
- 福祉給油券（金額）: 「1枚あたり500円の券を、1年あたり12枚交付（年間6,000円相当）」
- 福祉給油券（対象者）: 「身体障がい者手帳1～3級、療育手帳A判定、精神障がい者保健福祉手帳1～3級」
- 申請先: 「山形市役所2階26番窓口または基幹相談支援センター窓口」
- 必要書類: 「所定の申請書、障がい者手帳」
- 制限: 普通タクシー利用券・リフト付タクシー利用券・福祉給油券・高齢者移送サービス事業はいずれか一つのみ利用可能（重複不可）
- 70歳以上の場合: 令和4年7月1日より山形市シルバー3ヶ月定期券との併用可能
