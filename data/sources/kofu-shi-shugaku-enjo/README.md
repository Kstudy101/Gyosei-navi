## 確定した事実
- 制度名：小中学校就学援助制度
- 目的：経済的な理由により義務教育を受けさせることが困難な保護者に、学用品費や修学旅行費など学校にかかる費用の一部を援助（収入審査あり）
- 対象者：(1)生活保護法に規定する保護を受けている方、(2)これに準ずる程度に生活困窮していると認められる方（同一生計の全員の収入で審査）
  - 措置費を支給されている施設入所児童・里親制度利用児童などは対象外
  - 令和5年度より収入審査方法を変更し対象者を拡大（小中学生のいる家庭は誰でも申請可能、援助可否は審査による）
- 援助内容：
  - (1)の場合：医療費・修学旅行費
  - (2)の場合：入学準備費・校外活動費・学用品費・医療費・修学旅行費
- 支給費目と時期：入学準備費（7月中旬〈入学後〉または3月中旬〈入学前〉、両方は不可）、学用品費（7月中旬・3月中旬）、修学旅行費（10月下旬）、校外活動費・宿泊あり（11月下旬）、校外活動費・宿泊なし（1月中旬）、医療費（医療券で窓口無料）
- 支給方法：口座振込または学校長払い
- 申請方法：新学期（4月）に学校から案内配布→申請書と必要書類を学校または学事課に提出。年度初めの期限後も随時受付（認定は申請月から）
- 結果通知：6月中旬に郵送
- 問い合わせ：教育総室学事課保健給食係 055-223-7322
