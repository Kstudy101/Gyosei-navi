## 確認できた最終数値・条件

### 対象者
- **01・03**: 本市にお住まいの介護保険で**要支援以上**の認定を受けた方又はその人が属する世帯
- **02（FAQ）**: 「本市にお住まいの**65歳以上**の方で、介護保険の要支援・要介護認定を受けた方がいる世帯」と記載（01本文・PDF表紙側の要約には65歳の明示なし。FAQとの文言差あり）
- **除外（01・02）**: 同居するすべての者の前年の課税所得金額の合計が**330万円**を超えるとき、又はこれらの者が納付すべき市税を滞納しているとき
- **市税の範囲（01）**: 市県民税、軽自動車税、固定資産税（土地・家屋）、都市計画税（FAQは都市計画税・軽自動車税も列挙）

### 対象経費・対象外（02）
- 既存の居室、浴室、洗面所、台所、便所、玄関、廊下その他特に必要と認められる設備及び構造等を高齢者等に適応するよう改造するための経費
- **対象外**: 新築、増築、**既に着工した工事**

### 助成額（01・02）
- 対象経費の**2分の1**
- **上限50万円**
- ただし**浴室改造30万円**、**便器交換（FAQ表記: 便器等）10万円**まで

### 介護保険との関係（02・03・04）
- 別途、介護保険の住宅改修費の支給（**20万円を限度**としてその**9割相当額**を支給、とFAQ記載／04では9割〜7割）がある
- **本制度と併用可能**
- 介護保険の住宅改修費の適用対象工事がある場合は**介護保険が優先**（02・03）

### 手続きの流れ（02）
申請 → 実態調査 → 審査会 → 決定通知 → 工事着工 → 完了報告書 → 確定通知 → 助成金交付

### 問合せ（01・02）
- すこやか長寿部長寿支援課 生きがい支援係: **099-216-1266**（FAX 099-224-1539）
- 福祉支援部谷山福祉課: **099-269-2145**（FAQ）

### 受付状態
- 募集期限・予算到達による受付停止の記載なし（01更新日2026-07-21、03は令和8年度版案内）。常設案内の体裁。
