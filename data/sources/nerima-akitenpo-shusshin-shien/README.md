## 제도 유형 분류

**現金直接交付型**（融資あっせんではなく、審査採択後に区から直接支援金・補助金を交付する制度）。3種の支援を組み合わせた構成：
1. 開店経費支援金＝定額100万円（開業一時金的性格）
2. 店舗改修費補助金＝実費補助・上限100万円（改修工事費用の補助）
3. 店舗賃借料補助金＝実費補助・月額上限5万円（家賃補助、継続的支援）

いずれも審査（一次：書類、二次：プレゼン）を経た採択事業者のみが対象で、対象商店会（武蔵関駅前通り商店会／下石神井商店街振興組合）のエリア内の特定空き店舗への出店に限定される「地区・物件限定型」制度である点が特徴。
