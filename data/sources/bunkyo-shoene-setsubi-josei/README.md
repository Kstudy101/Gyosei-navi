### 予算消化状況

### 申請方式・期間
出典: `01_josei.txt` 申請期間表、`02` p.4・p.11〜13
- **事後申請**: 設置完了・助成対象経費の全額支払後に申請
- 設備設置日の区分ごとに申請期間が設定（令和8年2月1日設置分から、最終申請期限は令和9年3月1日）
- 個人は年度内・同一住宅で設備設置による申請は1回のみ（`01` 主な変更点）

### 個人の対象者要件（要約）
出典: `02` p.4「6 助成対象者の要件」
1. 申請日において区内に住所を有する
2. 自ら居住する住宅に自ら使用する目的で設置
3. 申請日において助成対象経費を全額支払っている
4. 区税の滞納がない
（加えて設備ごとの要件・提出書類あり）
