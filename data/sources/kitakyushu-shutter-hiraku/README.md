# 北九州市 商店街空き店舗活用補助金（シャッターヒラクプロジェクト） — 原文アーカイブ

## 対象自治体・制度

- 自治体: 福岡県北九州市（政令指定都市、市全体で1エントリ。regions.ts code `40100` / slug `kitakyushu`）
- 制度名: 商店街空き店舗活用補助金（シャッターヒラクプロジェクト）／正式根拠名: 北九州市商店街等における空き店舗の有効利用に関する補助金（開業支援事業）
- 所管: 産業経済局地域経済振興部サービス産業政策課
- カテゴリ: sogyo（創業支援）
- 制度種別: **現金補助型**（開業時の改装費の一部補助）。既存記事 `kitakyushu-kaigyo-shien-shikin`（融資あっせん型）とは別制度。
