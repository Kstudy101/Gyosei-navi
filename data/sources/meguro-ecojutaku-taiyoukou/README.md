## 채택 토픽

**目黒区 住宅用再生可能エネルギー及び省エネルギー設備設置費助成**（우산형・設置後申請）

- 소관: 目黒区（municipality）/ 環境清掃部環境保全課温暖化対策係（03-5722-9034）
- 유형: 구민 개인 + 분양맨션 관리조합 대상의 **현금 조성(設置費の一部)**。설치・인도 완료 후 신청（事後申請）。
- EV車購入補助金・충전설비補助金는 본 페이지에서 확인되지 않음（`02_evsya`는 연계협정 기사）.

## 원문에서 확정한 사실

### 신청・설치 기간（HTML L117–119 / 手引き P1）
- 신청 접수: **令和8年6月1日〜令和9年1月29日**（선착순・예산 도달 시 종료）
- 대상기기 설치・인도: **令和8年1月1日〜12月31日**
- 令和8年度부터 절차 변경: 신청 시 필요서류 전부 제출. 설치장소=주민등록 일치 필요.

### 예산・접수 상황（HTML L228–242, 令和8年8月31日時点）
- 예산 총액 30,300,000円 / 교부신청액 19,560,000円（64.6%）
- エコ住宅: 18件/25件（残り7件）
- → `subsidy.status: open`

### 설비 조성액（HTML 표 + 手引き P8–10）
| 대상 | 산정 | 상한 |
|---|---|---|
| 太陽光発電システム | 1kWあたり3万円（小数点第2位以下切捨て） | 15万円 |
| 家庭用蓄電システム | 本体価格の1/3（千円未満切捨て、税抜） | 7万円 |
| 家庭用燃料電池（エネファーム） | 本体価格の1/3 | 7万円 |
| CO2冷媒ヒートポンプ給湯器（エコキュート） | 本体価格の1/3 | 5万円 |
| ハイブリッド給湯器 | 本体価格の1/3 | 5万円 |
| 分譲マンション共用部LED照明 | 本体価格の1/3 | 10万円 |

※ HTML 표는 에네팜・에코큐트 등을 「7万円」「5万円」으로만 적었으나, **手引き P8–10이 본체가격の1/3＋상한**으로 상세. 기사 수치는 手引き 기준.

### エコ住宅助成（HTML L194–220 / 案内PDF）
- 東京ゼロエミ住宅 또는 ZEH（国）의 **確定通知書** 발행일이 令和7年1月1日以降
- 1건 30万円 / **令和8年度（上限25件）をもって終了**
- エコ住宅을 신청하면 설비（太陽光等）신청 불가（상호배타）

### 대상자 요지（手引き P2）
- 구민: 설치장소에 거주・주민등록, 전년도 주민세 체납 없음, 신품・본인 구매（리스 불가）
- 동일 종류 설비・에코주택 조성 이력이 본인・동일세대에 없어야 함
- 관리조합: 구내 분양맨션 공용부 설치

## 확인되지 않은 것 / 불채택
- 구 독자의 EV購入・EV充電設備 조성금: 공식 페이지에서 미확인（협정 페이지만 존재）→ 본 기사 범위 외
- eco検定助成: 사업자 대상 → energy 주민 기사로 부적합
- 手引き PDF의 일부 기기 세부 성능 수치（에네팜 종합효율 80% 등）는 OCR이 분절되어 있으나, HTML의 참고 섹션・표 금액・기간은 HTML+표지/P8과 교차 확인 완료
