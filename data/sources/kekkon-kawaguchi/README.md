## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **국고보조율**: PDF에 寄付金その他の収入予定額(B)=0円, 差引額(A-B)=450万円만 있고, 国庫負担割合(1/2 등)을 직접 명시한 문구는 이번 취득 원문에서 발견하지 못함. こども家庭庁 전국개요(`data/sources/kekkon-shinseikatsu-shien/`)의 일반적 보조율(국가1/2)을 川口市에도 그대로 적용해도 되는지는 川口市 원문만으로는 단정 불가 — 필요시 こども家庭庁측 埼玉県분 PDF와 대조 요망.
- **令和7年度(2025年度)판의 상세 조건**: 令和7年度 전용 페이지(`48680.html`)는 이미 404로 삭제됨. PDF의 「令和7年度申請状況」란(참고치)으로 신청건수(33世帯見込)는 확인되나, 令和7年度 당시 補助上限額이 令和8年度와 동일(10万円)했는지는 이번 조사로 확정하지 못함 — 실시계획서 표제가 「（令和7年度予算分）」로 돼 있으나 표 내용의 実施期間은 「令和8年4月1日〜令和9年3月31日」로 표기돼 있어(교부금 예산연도와 사업실시연도가 어긋나는 국가보조금 특유의 표기), 이 PDF 자체가 사실상 令和8年度 사업 계획서로 보임 — 해석에 주의.
- **講座受講의 구체적 내용**: 「라이프디자인지원강좌」등 3종 강좌명만 확인되고, 각 강좌의 상세 커리큘럼・소요시간은 원문(링크처는 埼玉県HP로 이동)까지는 따라가지 않음.
- **実際의 令和8年度 채택건수・수급액 확정치**: PDF의 45世帯見込은 견적치이며 확정 실적이 아님.
- **申請書類チェックリスト・支払いが事実の分かる書類の例 등 첨부 PDF 상세**: 파일명・용량만 원문에 언급되고, 이번 조사에서는 実施計画書(R8keikaku.pdf) 외 첨부서류 PDF는 다운로드하지 않음(기사 집필 단계에서 필요시 추가 취득).
