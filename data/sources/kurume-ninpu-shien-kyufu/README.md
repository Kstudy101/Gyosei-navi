# kurume-ninpu-shien-kyufu

対象自治体: 福岡県久留米市（団体コード 40203／検査数字込み6桁 402036）
対象制度: 妊婦のための支援給付（妊婦支援給付金）。令和7年3月までに出産した方は前身の「出産・子育て応援給付金」対象
所管: 久留米市子ども未来部家庭子ども相談課
