## 채택 제도

**佐賀県地方創生移住支援事業（移住支援金）** ― 東京23区在住・通勤者を対象とした移住支援金制度。

topic-scoutが전달한 후보 2건（① 東京23区限定型, ② 全国対象型「未来につなぐさが移住支援事業」) 모두 원문을 `npm run source`로 취득해 대조한 결과, **①「佐賀県地方創生移住支援事業」을 채택**했다.

### 채택 이유 / 비채택 이유

- ①는 요건이 **1～5의 5가지 유형**으로 정리되어 있고, 실시市町별 담당창구표에 **18歳未満加算 유무・テレワーク要件 유무**까지 명시되어 있어 원문만으로 기사에 필요한 요건・금액・신청처를 빠짐없이 확인할 수 있었다.
- ②「未来につなぐさが移住支援事業」（全国対象）는 요건이 **子育て世帯要件(4種)＋重点分野の担い手要件(2種)＝6가지**로 갈라지고（就職／起業／農林漁業／空き家取得／伝統工芸／スポーツ振興）, 18歳未満世帯員 동반 필수 또는 59歳以下 등 조건이 서로 얽혀 있어 일반 독자 대상 단일 기사로 설명하기엔 원문 대비 구조가 복잡하다. 제도 자체는 원문에서 실재가 확인되나, **이번 기사에서는 비채택**（향후 별도 기사 후보로 남김）.
- 두 제도는 佐賀県が公式に相互リンクしており（①본문 하단에 ②링크, ②본문 하단에 ①링크 존재）, 별개의 독립 제도임이 원문에서 상호 확인된다.

## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **申請期限（受付終了日）の具体的な日付**は原文に明記されていない。「支援金申請総額が予算上限に達し次第、申請受付を終了する可能性があります」という定性的な注意書きのみで、締切固定日は確認できず。기사에서는 "예산 소진 시 조기 마감"으로만 기술하고, 정확한 마감일은 각 市町 창구 확인 필요로 명시할 것。
- **市町ごとの予算額・予算消化状況**（具体的な金額や執行率）は原文に記載なし（unresearched）。
- 各市町が個別に定める「関係人口」要件の詳細（17市町分の支給対象者要件・地域の担い手確保要件）は原文表で全文確認済みだが、記事本文で全17市町分を網羅すると冗長になるため、記事では代表例（佐賀市・唐津市等）の抜粋にとどめ、全文は原文リンクへ誘導する方針が妥当。
- 根拠要領（PDF「佐賀県地方創生移住・地域活性化等起業支援事業実施要領【2026.4.1改正後】」）の本文は今回ダウンロードしていない（unresearched）。金額・要件はすべてHTML本文の記載値を使用したため記事執筆には支障ないが、要領の細目（様式・添付書類詳細等）は未確認。
- 「移住支援金対象求人の探し方」PDF（480キロバイト）は未取得（unresearched）。
