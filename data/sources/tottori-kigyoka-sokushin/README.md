## 제도 유형 분류

**현금교부형(助成金)** — 先端技術分野の起業化・事業化に要する経費を全額助成。융자알선 아님.

## 원문에서 확정한 사실（01_r8_dai3kai.txt + 02_fund_overview.txt 대조）

| 항목 | 원문 |
