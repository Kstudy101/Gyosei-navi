## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- **令和8年度분 実施計画書（こども家庭庁提出用）の存在**: 本文ページ末尾の「実施計画書」リンクは `R7.pdf`（実施期間令和7年4月〜令和8年3月、令和6年度補正予算分）のみで、令和8年度単独の実施計画書PDFは本文ページから確認できなかった。国庫補助率（1/2等）を明示した令和8年度専用の記載は見つかっていない。ただし国基準・自治体独自基準・県単費上乗せの構造自体は令和8年度も同一と推定できる（チラシ・本文ページの金額が完全一致するため）が、「実施計画書PDFがR7版のみ現行ページに残っている」こと自体は確定事実として扱い、断定的推測はしない。
- **国庫補助率の具体的な割合**: 実施計画書PDFには総事業費・対象経費支出予定額・差引額のみ記載され、「補助率を乗じる前の額」との注記はあるが、国費1/2等の具体的な補助率の文言は本文に発見できず。
- **令和7年度（2025年度）当時の申請受付が実際にいつ終了したか**: 実施計画書の「令和6年度申請状況」欄に見込世帯数はあるが、実際に予算消化により早期終了したかどうかの確定情報はなし。
- **県のライフプラン講座の具体的開催スケジュール**: 「公益財団法人いきいき岩手支援財団のホームページでお知らせ」とのリンクのみで、講座自体の日程・回数などは北上市の一次情報からは確認していない（外部リンク先は未取得）。
