## 確認できた核心情報

### ⚠️ 令和8年度は受付終了（2026年7月6日更新）

### 2つのメニュー

#### （1）ビジネスプランコンテスト開催事業
- **補助率**: 対象経費の2分の1以内
- **補助上限額**: **300万円**
- **公募期間**: 令和8年5月1日〜6月15日（終了）
- **対象者**: 女性または若者（令和8年4月1日時点で35歳未満）で新たに起業・事業承継・第二創業する者
- **スケジュール**: ビジネスプランコンテスト（令和8年7月19日）→ 補助金交付（令和9年2月頃）

#### （2）地域魅力度アップによる女性・若者の県内定着応援事業
- **補助率**: 対象経費の2分の1以内
- **補助上限額**: **100万円**
- **公募期間**: 令和8年6月1日〜6月29日（終了）
- **対象者**: 性別・年齢制限なし。新たに起業・事業承継・第二創業する者

### 共通要件
- 宮崎県内に居住または補助事業期間完了日（令和9年2月1日）までに居住予定
- よろず支援拠点コーディネーターによるビジネスプランのブラッシュアップが必須
- 県税滞納なし

### 対象経費
人件費、店舗等借入費、設備費、原材料費、知的財産権等関連経費、謝金、旅費、外注費、委託費、マーケティング調査費及び広報費
