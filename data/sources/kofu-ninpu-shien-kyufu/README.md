# kofu-ninpu-shien-kyufu — 甲府市妊婦のための支援給付事業（shussan）

## 判定
**採用** — 甲府市「甲府市妊婦等包括相談支援事業 及び 妊婦のための支援給付事業」。
国の「妊婦のための支援給付」（令和7年4月以降の妊娠が対象、旧・出産子育て応援給付金の後継）を甲府市が実施する形。原文は2026年4月1日更新で最新性・具体性ともに高く、比較対象の富士吉田市（2025年1月6日更新）より新しい。

## 選定理由（甲府市 vs 富士吉田市の比較）
| 項目 | 甲府市 | 富士吉田市 |
|---|---|---|
| 原文更新日 | 2026年4月1日 | 2025年1月6日 |
| 金額 | 妊娠届出時5万円＋出産後（胎児1人につき）5万円 | 同左（妊婦一人5万円＋胎児一人5万円） |
| 申請期限の明記 | 妊娠の事実確認日から2年（明確） | 妊娠確定日から2年経過日の前日（明確だが令和7年度経過措置の記載あり＝やや古い） |
| 面談要件 | 記載なし（届出時に申請書記入） | 「妊婦本人が妊娠届出時に市の担当者との面談を受けた方」が対象要件に明記 |
| 問い合わせ | 母子保健課 055-237-8950 | 子育て支援課・こども家庭センター 0555-22-1111 |

両市とも国の「妊婦のための支援給付事業」の運用のため制度の骨格は同一。より新しい更新日と明確な記述を優先し、**甲府市を採用**。

## 確定した事実（甲府市）
- 制度名：甲府市妊婦等包括相談支援事業 及び 妊婦のための支援給付事業
- 経済的支援：妊娠届出時（1回目）5万円、出産予定日8週前以降の届出（2回目）胎児1人につき5万円
- 対象：甲府市内に住所を有する妊婦。他自治体から同制度の支給を受けていないこと
- 申請期限：妊娠の事実確認日（医師等が胎児心拍を確認した日）から2年
- 流産・死産・人工妊娠中絶の場合も対象になる旨を明記
- 旧・出産子育て応援給付金は令和8年3月30日で終了、現行制度に切り替わっている
- 窓口：甲府市子ども未来部母子保健課（055-237-8950）
