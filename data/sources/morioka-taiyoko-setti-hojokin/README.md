## 제도 유형 분류

**현금직접교부형（보조金直接交付）**。融資あっせん型ではなく、盛岡市が対象システムの購入・設置費に対して直接補助金を交付する仕組み。抽選制（新築・HEMS）と先着順（既築）の二本立てで運用されている点が特徴。
