## 원문에서 확정한 사실 (기사 근거)

福井県内には２つの類似制度があり、県ページでは両方を並記している。

### 1. 結婚新生活支援事業
| 항목 | 원문 | 출처 |
|---|---|---|
| 目的 | 婚姻に伴う経済的負担を軽減するため、新規に婚姻した世帯を対象に家賃や住宅購入などの支援 | 00_top.txt |
| 対象世帯 | 世帯所得500万円未満で夫婦ともに婚姻日における年齢が39歳以下の新規に婚姻した世帯 | 00_top.txt |
| 対象経費 | 住宅取得費用、住宅賃借費用、リフォーム費用、引越費用 | 00_top.txt |
| 上限額 | 60万円または30万円（※対象世帯・対象経費・上限額は市町によって異なる） | 00_top.txt |

### 2. 早婚夫婦支援事業
| 항목 | 원문 | 출처 |
|---|---|---|
| 目的 | 新規に婚姻した若い夫婦を対象に、結婚に伴う新生活のスタートアップのための支援金を給付 | 00_top.txt |
| 対象世帯 | 世帯所得500万円未満で夫婦ともに婚姻日における年齢が39歳以下でいずれかが29歳以下の新規に婚姻した世帯 | 00_top.txt |
| 支給額 | 30万円（いずれかが25歳以下であれば、10万円を加算＝最大40万円） | 00_top.txt |
