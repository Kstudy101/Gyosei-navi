## 核心数値（01原文より）

- 制度名: 飼い主のいない猫の不妊去勢手術費用一部の助成
- 対象者: 徳島市に住所を有し住民基本台帳に記録されている者、または徳島市内の町内会等で、飼い主のいない猫に不妊・去勢手術（耳のV字カット等を含む）を受けさせようとする者
- 対象猫: 徳島市内に生息する飼い主のいない猫（野良猫）のみ。**飼い猫は対象外**（他人の飼い猫の無断捕獲不可）
- 助成頭数: 90頭（個人・団体とも上限5頭）。超過時は抽選
- 助成金額: 1頭につき**上限1万円**
- 申請受付期間（令和8年度実績）: 令和8年8月1日（土）〜令和8年8月10日（月）※窓口は平日のみ、郵送は8月10日消印有効
  - **本原文取得時点（2026-09-22）で令和8年度の受付は既に終了・抽選も完了している**（8月20日公開抽選）。記事化する際は「例年○月頃に募集」という書き方に留め、次年度の具体的な期日は断定しない。
- 申請窓口: 環境政策課（徳島市役所本庁舎10階）、郵送可
- 交付までの流れ: 申請→（多数時抽選）→交付決定通知→通知日翌日起算60日以内に実施動物病院で手術→手術翌日起算14日以内に実績報告書（写真・領収書添付）提出→助成金額確定通知→請求書提出→交付
- 問い合わせ: 環境政策課 衛生係 電話088-621-5206
