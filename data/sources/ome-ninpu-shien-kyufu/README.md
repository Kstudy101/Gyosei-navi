## 核心数値（原文対照）

出典は特記なき限り `01_keizaishien.txt`。

| 項目 | 原文の記載 |
|---|---|
| 枠組み | 伴走型相談支援（妊婦等包括相談支援事業）＋経済的支援（「妊婦のための支援給付」および「出産・子育て応援事業」） |
| 1回目 | 妊婦支援給付金 **5万円**。対象: 青梅市に住民登録があり、医療機関で胎児心拍を確認し、**令和7年4月1日以降に妊娠届出**をした妊婦。妊娠初期面談で案内 |
| 2回目 | **胎児の数×5万円**。対象: 青梅市住民登録があり、青梅市で妊婦給付認定を受けている方。妊娠中期面談（妊娠6〜7か月頃）で案内。申請開始は**出産予定日の8週間前から** |
| 支給方法 | 現金（妊婦名義口座）またはデジタルギフト（コンビニATM現金受取・電子マネー・マタニティ/育児グッズ等ポイント交換） |
| 育児パッケージ | 出産・子育て応援事業。肌着・バスポンチョ・バスタオル・ウォッシュタオル・木のおもちゃ（青梅産材）。対象は妊娠6〜7か月ごろの妊婦。SMSで案内、面談後に交付 |
| バースデー育児パッケージ | 1歳誕生日時点のデジタルギフト。**第一子6万円／第二子7万円／第三子以降8万円**（同世帯18歳未満のうち何番目か）。対象児と養育者が青梅市同一世帯に住民登録 |
| 転入 | 前住地の妊婦給付認定は転出で取消。青梅市で再申請。母子健康手帳・前住地妊婦健診受診票を持参しこども家庭センターで手続き |
| 流産・死産等 | 支給対象となり得る。医師が胎児心拍を確認していた場合は対象。診断書が必要な場合あり（妊娠届出済みなら不要の場合も）。来所前に電話連絡 |
| 面談 | 初期（届出時）・中期（6〜7か月）は予約制。本人不在だと給付金案内不可 |
