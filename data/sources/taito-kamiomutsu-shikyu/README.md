## 원문에서 확정한 사실

| 항목 | 원문 |
|---|---|
| 제도명 | 紙おむつの支給 |
| 목적 | 상시 종이기저귀 사용 고령자 및 그 가족의 경제적 부담 경감 |
| 대상자 | 台東区내 거주하며 상시 종이기저귀 등 사용하는 자 중 (1) 개호보험 요지원1 이상 인정자(65세 미만 요개호인정자 포함) 또는 (2) 65세 이상으로 입원 중인 자. 단, 개호노인복지시설(특양)・개호노인보건시설(노건)・개호의료원 입소자, 생활보호수급자는 제외 |
| 급부종류 | 「현물배송」「구입보조권」「기저귀대」 중 택1(월 중복선택 불가) |
| 지급량(재택, 1개월 상당액) | 요지원1・2: 3,000円상당 / 요개호1・2: 5,000円상당 / 요개호3~5: 7,000円상당 |
| 입원(요개호인정 미보유, 65세이상) | 기저귀대 또는 현물배송(5,000円상당) 중 택1 |
| 기저귀대(입원・유료노인홈입소) | 요개호도 무관하게 월 5,000円 상한 보조, 신청 익월분부터 대상, 청구기한은 보조대상월로부터 2년 이내, 지급은 연4회(3・6・9・12월말), 수급자 본인명의 계좌 입금 |
| 자기부담금 | 현물배송: 3,000円상당→300円 / 5,000円상당→500円 / 7,000円상당→700円. 구입보조권: 1매당 100円. 주민세비과세세대는 자기부담 면제 |
| 구입보조권 | 1매 1,000円권을 지급량만큼 교부, 구내 협력약국・약점에서 사용 |
| 신청방법 | 수급자의 개호보험피보험자증 지참 후 高齢福祉課 또는 인근 지역포괄지원센터에서 수속. 신청일 익월분부터 급부개시(소급신청 불가) |
| 수급자격 상실 사유 | 개호보험 인정유효기간 만료, 비해당 판정, 생활보호 개시, 1년이상 수급정지, 특양/노건/개호의료원 입소, 요개호미인정자의 퇴원 재택복귀 등 |
| 문의처 | 高齢福祉課総合相談・給付担当, 電話 03-5246-1224 / FAX 03-5246-1229 |

## 제도 유형 분류

현물지급형 + 구입보조권형 + 실비보조형(기저귀대) 혼합 — 이용자가 3가지 급부방식 중 택1
