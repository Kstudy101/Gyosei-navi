## 確定した事実

- 県一覧は「令和7年度に本事業を実施する県内市町村」を明示列挙し、※で「上記以外の市町村でも、結婚新生活支援事業**以外**の結婚支援」がある場合があると注記 → 一覧非掲載は同事業（住居・引越の現金補助）非実施の強い根拠
- 市は同交付金を令和8年度も活用しているが、使途はKumarry運営等であり結婚新生活支援メニューではない（08原文）
- Kumarryは有料会員制の出会い支援であり、新婚世帯への住居費・引越費補助ではない（09原文）
