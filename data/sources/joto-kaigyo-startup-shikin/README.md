## 制度の位置づけ

城東区は大阪市の行政区であり、区独自の創業融資あっせん・現金直接補助は、区公式「消費生活・ビジネス支援・雇用・労働」カテゴリおよび生活案内ページ（経営資金援助→経済戦略局）の確認範囲では見当たらない。城東区で創業する人が使える資金支援は、**大阪府制度融資「開業・スタートアップ応援資金」を大阪市が窓口として取り扱う融資あっせん型**である（制度数値の正本は `data/sources/osaka-sogyo/`）。

- 経済センサスは**平成26年（2014年）時点**。令和3年経済センサス等のより新しい区別順位は未確認。
- 無保証人対応の保証料列の見出し文言は府ページ表組みに依存するため、申込時は取扱金融機関・大阪信用保証協会での最新確認が必要。
