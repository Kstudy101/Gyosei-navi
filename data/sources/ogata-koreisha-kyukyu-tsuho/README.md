## 確認できた事実（原文対照）

- **正式名称**: 高齢者救急通報システム（広報・チラシ表記）
- **対象**: 65歳以上で村内にひとり暮らしの方（05b）。04でも各類型に「対象者：65歳以上」
- **内容（いずれか選択）**:
  1. 自宅設置型（ペンダントと据置き）— 非常ボタンで通報、民間警備会社が状況に応じた対応（05b・04）
  2. 携帯型（みまもりホン）— ストラップ牽引で通報。親族はGPS位置確認・安否メール可（05b・04）
- **利用料**:
  - 住民税非課税世帯・生活保護世帯: **無料**（05b・04）
  - それ以外（05bは「住民税課税世帯」、04は「その他の世帯」）: **月額1,100円（税込）**
  - みまもりホンの発信通話料は利用者負担（受信無料）（05b・04）
- **申込・問合せ**: 福祉保健課 0185-45-2114 / 包括支援センター 0185-22-4321（04・05b・02）
- **現行チラシ(03)の追記事項**: 緊急ボタン押下で消防に緊急信号、電話での安否確認、必要時に電子錠開錠の記載あり。広報の「民間警備会社」表現とチラシの「消防」表現は併記し、推測で一本化しない。
