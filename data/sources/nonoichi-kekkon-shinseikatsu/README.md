## 確認された事実（記事に使える）

- 補助対象: 結婚を機に取得した自己名義の住宅の建物費用（購入費用・工事費用）のみ（賃料・リフォーム・引越し費は対象外）
- 対象婚姻期間: 令和8年1月1日〜令和9年3月31日に婚姻届が受理された夫婦
- 年齢要件: 夫婦双方の婚姻日における年齢が39歳以下
- 所得要件: 直近の夫婦の年間所得の合計額が500万円未満（貸与型奨学金の返済額は控除）
- 対象費用期間: 令和8年4月1日〜令和9年3月31日（原則婚姻後に支払った費用）
- 補助額: 最大30万円（夫婦双方29歳以下は最大60万円）
- 申請期間: 令和8年4月1日〜令和9年3月31日（予算上限で早期終了の可能性あり）
- ライフデザイン支援講座等の受講: 夫婦双方が交付申請日までに受講が必要
- 申請窓口: 野々市市子育て支援課 子育て支援係（TEL: 076-227-6077）
- 石川県内15市町が参加（県公式ページで確認）
