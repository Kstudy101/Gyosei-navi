# 曽於市 住宅リフォーム促進事業補助金 — 原文アーカイブ

## 対象自治体・制度

- 自治体: 鹿児島県曽於市（そおし）
- 担当課: 曽於市 まちづくり推進課 住まい政策係
- 制度名: 住宅リフォーム促進事業補助金
- カテゴリ: jutaku（住宅）
- 制度種別: 現金給付（補助金）型。市内リフォーム登録工事店への工事費用の一部を補助。空き家の移住活用にも対応。

## 制度種別の分析

- 「市外居住者 空き家リフォーム（上限50万円）」は移住促進型の特別枠。
- 「市内居住者 空き家リフォーム（上限30万円）」は一般的な空き家活用枠。
- 通常の住居リフォームは上限15万円と低め。
- 家財撤去補助（上限7万円）は空き家活用の前段階支援。
