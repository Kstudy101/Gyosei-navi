## ⚠️ 매우 중요 — 令和8年度(2026年度)부터 제도가 크게 바뀜

PDF 원문에 따르면, **令和8年度（2026年度）予算**부터 자유민주党・公明党・日本維新の会 三党合意(令和7年10月29日, 令和7年12月18日)에 근거해 **소득제한이 전면 철폐**된 신제도가 시행된다. 이는 서드파티 기사(에듀 미디어 등)에서 "2026년 고교무상화, 소득제한 철폐"라고 보도한 내용과 일치하며, 원문(문부과학성 공식 예산자료)으로 재확인됨.

**기사 작성 시 "구제도(소득기준 590만/910만엔)"와 "신제도(소득제한 없음)"를 혼동하지 않도록 반드시 시행연도를 명기할 것.**

## ⚠️ 원문에서 확인되지 않은 것 (기사에서 단정 금지)

- 「신제도(소득제한 없음)」이 실제로 몇 년도 재학생부터 적용되는지(재학생 경과조치 대상 범위의 세부 조건)는 이 PDF(예산 설명자료) 수준에서는 개략만 파악됨 — 상세 시행 요강(신청 서류, 스케줄)은 문부과학성이 별도로 발행하는 「事務処理要領」이나 도도부현 안내를 추가로 확인해야 함.
- 위 표의 「(괄호)금액은 실제로는 존재하지 않는 것」이라는 주석이 원문에 있음 — 기사에서 괄호 숫자를 그대로 인용하지 않도록 주의.
- 문부과학성 구제도 상세페이지(`detail/1342747.htm`, `1342674.htm`)는 취득 시점에 404였다 — 이 URL들을 기사에 링크로 걸지 말 것. 링크가 필요하면 재검색으로 유효 URL 확인 후 사용.
- 사립고 통신제/정시제의 신제도 지급상한액 세부표는 PDF에 포함되어 있으나(정시제 337,200엔 등), 본 README에는 대표값만 발췌함 — 기사 작성 시 원문 PDF 표 3(p.3)을 재확인해 학교종별 정확한 금액을 인용할 것.
