## 制度類型

**空き店舗改装費補助型（現金補助・定率＋上限／商店街限定）** — 融資あっせん型ではなく、出店改装費の一部を市が補助する現金補助。港区式の創業現金補助に近いが、対象が中央商店街の空き店舗改装に限定される点が差別化ポイント。
