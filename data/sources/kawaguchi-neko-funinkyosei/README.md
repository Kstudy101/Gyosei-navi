## 제도 유형 분류

**현금지급형（事후환급형 보조금）**. 신청자가 동물병원에서 수술비를 먼저 전액 지불한 뒤, 영수증 원본 등 서류를 갖춰 수술일로부터 90일 이내에 시에 신청하면 심사 후 상한액（불임9,000円／거세5,000円） 범위 내에서 현금이 교부되는 방식（交付要綱 第7条: 심사 → 교부결정통지 → 교부). 병원 창구에서 즉시 차감되는 방식이 아니라 **사후 환급형**임이 원문（요강 第6条・第7条의 신청→심사→통지→교부 흐름, 수술일부터 90일 기한）으로 명확히 확인됨. 현물지원형（시가 직접 무료수술 실시） 요소는 원문에 확인되지 않음.
