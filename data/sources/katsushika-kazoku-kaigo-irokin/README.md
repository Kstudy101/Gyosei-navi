## 注記
このページは「利用者負担の軽減制度」という総合ページで、以下の複数制度をまとめて掲載している:
1. 高額介護（予防）サービス費の支給
2. 介護保険施設での食費・居住費の負担額減額

本READMEは4.家族介護慰労金にフォーカスするが、原文には他制度の詳細（負担限度額表など）も含まれる。

## 家族介護慰労金の支給（現金給付型）

### 金額
年1回10万円（介護保険サービスを利用せず家族が介護を行った場合の慰労金）（原文548-550行目）

### 対象者（以下5条件をすべて満たす場合のみ）
1. 要介護4又は要介護5の認定を受けていること
2. 住民税が世帯全員非課税であること（介護している方が別世帯の場合、その世帯も同様）
3. 要介護認定後、1年間介護保険サービスを利用していないこと（7日以内のショートステイは除く）
4. 長期入院（3か月以上）した場合は、その期間を除く12か月間サービス未利用
5. 介護される方に滞納した介護保険料又は時効消滅した介護保険料がないこと
（原文552-568行目）

### 申請方法
介護保険課への申請が必要（原文570行目）。申請書様式・必要書類の詳細は原文に明記なし、電話等での問い合わせが前提の案内文。

## 制度タイプ分類
**現金給付型**（要件を満たした家族介護者への年1回定額慰労金。役務提供や現物支給ではない）
