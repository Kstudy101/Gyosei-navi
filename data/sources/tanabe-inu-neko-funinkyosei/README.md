## 確定した事実（原文01より）

- 制度名：田辺市犬及び猫の不妊去勢手術補助金（「田辺市犬及び猫の不妊去勢手術補助金交付要綱」に基づく）
- 実施期間：令和6年4月1日〜（令和6〜8年度の3年間を予定）
- 更新日：2026年07月17日（ページ表示）

### （1）飼い主のいない猫（田辺市内に生息する猫）
- 補助対象者：**団体登録制**。田辺保健所管内（田辺市・白浜町・上富田町・みなべ町・すさみ町を含む地域）に事務所等を有する市民団体で、あらかじめ市長の登録を受けたもの（営利・宗教・政治活動目的の団体等は除外）
- 対象手術：田辺保健所管内の動物病院で実施する不妊去勢手術
- **補助金額：手術1件につき3,000円**
- 申請：団体登録 → 毎月1回、前月分の補助金交付請求書を提出（実績一覧表・手術後の猫の写真・領収書添付）
- 遵守事項：終生屋内飼養者への譲渡に努める／耳カットによる不妊去勢済み識別措置
- 問い合わせ：環境課環境対策係 0739-26-9927

### （2）飼い犬・飼い猫
- 補助対象者：田辺市内に居住し住民基本台帳に記録されている飼い主（直接申請）
- 対象手術：田辺保健所管内の動物病院で実施する不妊去勢手術
- **補助金額：手術1件につき2,000円**
- 申請：環境課窓口に補助金交付申請書・誓約書を提出（手術後の犬猫の写真・領収書添付、印鑑・振込先口座情報も必要）
- **申請期限：手術を実施した日から30日以内**
- その他：犬の場合、狂犬病予防法に基づく登録が要件
