# data/watch/ — 新着キャッチ用の監視対象リスト

`data/sources/` とは性格が異なる。`data/sources/` は記事の根拠となる一次情報の原文アーカイブだが、
ここに置くのは「どのURLを毎日 diff 監視するか」という**監視対象リスト**であり、記事の直接の根拠にはしない
（このリストの変更検知が Issue になったら、記事化する前に必ず該当自治体の公式ページで原文を再確認する
— AGENTS.md 絶対規則7・9）。

## municipality-homepages.json

全国市区町村（1,718件、都道府県は含まない）の公式ホームページ トップページURL一覧。

- **出典**: [https://uub.jp/opm/ml_homepage.html](https://uub.jp/opm/ml_homepage.html)（民間運営、運営者・更新方針は非公開）
- **取得日**: 2026-09-21
- **公式出典が使えなかった理由**: 総務省「全国地方公共団体コード」一覧PDFは団体名・コードのみでURLを含まない。
  e-Gov ポータルの地方公共団体リンク集は都道府県・政令指定都市・東京23区の132件のみで、市区町村全件を
  カバーしない。1,718件全件を一括で持つ公式ソースが確認できなかったため、この民間サイトを出発点として採用した
  （2026-09-21 ユーザー確認済み）。
- **検証**: 総務省発表の市区町村数（1,718）とパース結果の件数が一致。ランダムサンプル3件
  （小樽市・留萌市・紋別市）を実際に fetch し、いずれも HTTP 200 で応答することを確認済み。
  ただし1,718件全件を個別に原文確認したわけではない — URLの死活・正確性は
  `src/lib/sources/monitor.ts` の日次監視が継続的に検証する（エラーが出たURLは要手動確認）。
- **形式**: `[{ pref: "北海道", name: "札幌市", url: "https://www.city.sapporo.jp/" }, ...]`
- **用途**: `scripts/watch-municipalities.ts` が、published subsidy 記事から自動収集した監視対象
  （169件、2026-09-21時点）に加えて、このリストの市区町村トップページも監視対象に加える。
  トップページ全体の diff のため、補助金と無関係な採用・災害・イベント告知等も変更として検知されうる
  （ノイズは運用しながら selector・ignorePatterns で絞り込む方針 — 2026-09-21 ユーザー確認）。
- **再取得方法**: `data/watch/README.md` のこの節を更新しつつ、上記URLから同じ表構造
  （`<tr class="al bw no">` 内の `class="bpref|bcity|btown|bvill"` と `<a href>`）を再パースする。
