新宿區創業資金貸款是區公所面向中小企業的制度性貸款之一，由區公所補貼大部分利息以及部分信用保證費，為區內預定創業者、創業未滿5年者斡旋低利率貸款。該制度以「創業等支援融資制度」的名義實施。

<SubsidyInfoCard />

## 本文結論

- 貸款限額為**2,000萬日圓**（預定創業者為1,000萬日圓，分公司化為1,500萬日圓）
- 利率2.1%以下中，區公所負擔1.9%以下，**本人負擔為0.2%以下**
- 信用保證費也會補貼已支付金額的**二分之一（上限26萬日圓）**

## 1. 對象者・補助條件

符合資格者為屬於以下任一情形者：

- 目前非事業主，計畫以法人或個人形式創業者
- 計畫透過分公司化方式創業者
- 以法人或個人形式創業、且創業未滿5年者
- 透過分公司化方式創業、且創業未滿5年者

以上情形均須從事東京信用保證協會保證對象行業，且未積欠住民稅・事業稅。法人須將總公司（營業主要據點）及總公司登記地址均設於區內同一地址；個人須將營業場所（營業主要據點）設於區內（若於區內居住滿1年以上，亦可在東京都內其他地區創業）。

僅用於「登記」或「收信」的虛擬辦公室，以及按次付費使用座位的合約辦公室，不屬於補助對象（個人事業主於區內居住滿1年以上者除外）。

## 2. 補助金額・計算方式

| 項目 | 內容 |
|---|---|
| 貸款限額 | 2,000萬日圓（預定創業者為1,000萬日圓，分公司化為1,500萬日圓） |
| 貸款期限 | 7年以內（寬限期12個月以內） |
| 利率 | 2.1%以下 |
| 本人負擔 | 0.2%以下 |
| 區負擔 | 1.9%以下 |
| 信用保證費補貼 | 補貼已支付信用保證費的1/2（上限26萬日圓） |

## 3. 申請方式

創業資金與一般貸款不同，需要接受多次、每次2小時的面談。

## 4. 值得一併瞭解的優惠制度

若租借區公所認可的商店會・商店街振興組合區域內的空置店鋪（歇業1個月以上的店鋪）進行創業，可利用「商店街空置店鋪活用支援資金（空借）」。除創業資金的條件外，還須符合加入商店會等條件，但**利息與信用保證費將獲得全額補貼**，是更為優惠的制度。
