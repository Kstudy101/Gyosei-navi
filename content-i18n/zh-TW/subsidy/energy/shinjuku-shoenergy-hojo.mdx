新宿區節能及創能設備等補助制度，是將太陽能發電、節能熱水器、家用燃料電池、高反射率塗裝、隔熱窗戶、蓄電系統這6類設備一併納入補助範圍的區獨立補助制度。與其他區多數制度不同，本制度的特色是**在施工與付款全數完成之後才申請的「事後申請型」**。

<SubsidyInfoCard />

## 本文結論

- 涵蓋6類設備的**綜合型補助制度**，各設備的補助金額不同
- 蓄電系統**每度（kWh）蓄電容量補助10,000日圓，上限10萬日圓**（以與太陽能發電或家用燃料電池常時連接為條件）
- 並非事先申請，而是**在工程與付款完成後才申請**的機制。全年設有4期受理期間，一旦達到預算上限，即使在該期期間內也會提前截止

## 1. 對象者・補助條件

符合條件者為於新宿區內設有住址、以自用為目的在該個人住宅安裝施工補助對象設備、且已全額付清款項者。於集合住宅設有住址者，僅限安裝施工隔熱窗戶的情況才符合條件。

蓄電系統須同時符合以下兩項條件：

- 為一般社團法人環境共創倡議（SII）指定的補助對象設備，或經認定為同等設備
- 與太陽能發電系統或家用燃料電池（ENE·FARM）保持常時連接

若過去曾就同一設備類別獲得過本制度補助、導入二手品或租賃設備、或施工完工日與付款完成日相隔超過1年，則不符合補助資格。

## 2. 補助金額・計算方式（個人住宅用6類設備）

| 補助對象設備 | 補助金額 |
|---|---|
| 太陽能發電系統 | 每瓩（kW）標稱輸出功率補助100,000日圓（上限300,000日圓） |
| CO2冷媒熱泵熱水器（ECO·CUTE） | 定額100,000日圓 |
| 家用燃料電池（ENE·FARM） | 定額100,000日圓 |
| 高反射率塗裝（屋頂・屋面） | 每平方公尺施工面積補助2,000日圓（上限200,000日圓） |
| 隔熱窗戶 | 安裝施工費用（未稅）的25%（上限100,000日圓） |
| 蓄電系統 | 每度（kWh）蓄電容量補助10,000日圓（上限100,000日圓） |

## 3. 申請期間・受理狀況

令和8年度的申請受理期間分為4期。補助對象期間（設備完工日）在各期均為令和8年4月1日至令和9年3月12日。

| 期別 | 受理期間 | 狀態 |
|---|---|---|
| 第1期 | 令和8年5月25日至7月31日（須寄達） | 已結束 |
| 第2期 | 令和8年8月17日至10月16日（須寄達） | 受理中 |
| 第3期 | 令和8年11月2日至12月25日（須寄達） | - |
| 第4期 | 令和9年1月12日至3月12日（須寄達） | - |

截至2026年9月14日，第2期的預計核定率為24%（預算剩餘率76%）。即使在受理期間內，一旦各期預算達到上限，當天即會截止受理。

## 4. 申請方式

太陽能發電系統與高反射率塗裝需要提供施工完工後的照片作為附件。請事先與施工廠商溝通，例如在拆除鷹架之前完成拍攝。
